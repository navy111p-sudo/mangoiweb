# MANGOI development
1. Identify affected routes, components, APIs, and tests.
2. Document baseline behavior, acceptance criteria, and rollback approach.
3. Make smallest maintainable change; preserve existing AI speaking, class, dubbing and admin flows.
4. Add unit/integration tests for modified behavior.
5. Run lint, typecheck, tests and build using commands actually present in the repository.
6. Report evidence, remaining risks, and create a PR; do not claim unrun tests passed.
