# MANGOI recovery
Collect sanitized logs, deployment identifiers and timestamps. Isolate client, API, WebRTC and provider failures. Assess impact, propose reversible mitigation, get human approval before rollbacks, D1 data changes or deletions (CLAUDE.md 4-1-1), and verify recovery. Never erase production data.
