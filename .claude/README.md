# `.claude/` — 팀이 함께 쓰는 클로드 코드 설정

이 폴더는 **깃에 올라가 있습니다.** 저장소를 클론한 사람은 누구나
여기 있는 설정·명령·에이전트를 **설치 없이 그대로** 쓰게 됩니다.

```
.claude/
├── README.md            ← 지금 이 파일
├── settings.json        ← 공유 권한 설정 (허용/금지 명령 목록)   ✅ 깃에 올라감
├── settings.local.json  ← 개인 PC 전용 설정                    ⛔ .gitignore
├── commands/            ← 공용 슬래시 명령 (/verify 처럼 씀)     ✅ 깃에 올라감
└── agents/              ← 공용 서브에이전트                     ✅ 깃에 올라감
```

저장소 루트의 **[CLAUDE.md](../CLAUDE.md)** 도 같은 원리입니다 — 클로드 코드가
작업할 때마다 자동으로 읽는 규칙서라서, 거기에 적힌 함정·금지사항이 팀 전원에게 적용됩니다.

---

## 1. 새로 합류한 사람이 할 일

```bash
git clone --depth 50 https://github.com/navy111p-sudo/mangoiweb.git
cd mangoiweb
claude
```

이게 전부입니다. `CLAUDE.md`·`.claude/settings.json`·`commands/`·`agents/` 가
**자동으로 잡힙니다.** 따로 복사하거나 설정할 것이 없습니다.

---

## 2. 무엇을 여기에 넣고, 무엇을 넣지 않나

| 넣습니다 ✅ | 넣지 않습니다 ⛔ |
|---|---|
| 팀 전체에 해당하는 권한 허용/금지 목록 | 내 PC에만 있는 경로 (`C:\Users\내이름\...`) |
| 반복 작업을 묶은 슬래시 명령 | API 키·토큰·비밀번호 — **어떤 형태로도 금지** |
| 조사·검토용 서브에이전트 | 배포 권한 (`deploy.ps1`) 허용 — 권한자만 자기 local 파일에 |
| 프로젝트 규칙 (`CLAUDE.md`) | 실험 중인 개인 설정 |

개인 설정은 **`.claude/settings.local.json`** 에 두세요.
그 파일은 `.gitignore` 되어 있어 남에게 안 갑니다.

> ⚠️ **MCP 연결(`.mcp.json`)은 일부러 넣지 않았습니다.**
> 이 저장소에서 쓰는 연결(깃허브·노션·구글 드라이브·클라우드플레어)은
> **각자 클로드 계정에 로그인해서 붙이는 방식**입니다. 저장소에 적어 두면
> 남의 계정 자격증명이 필요해져 오히려 안 됩니다. 연결은 각자 `/mcp` 에서 하세요.

## 3. 지금 들어 있는 슬래시 명령

| 명령 | 하는 일 |
|---|---|
| `/verify` | 코드 고친 뒤 필수 검증 (타입체크 + 회귀 하니스) — CLAUDE.md 4-4장 절차 |
| `/worklog` | 이번 작업에서 한 일을 `docs/작업기록/` 에 문서로 남김 (팀 공유용) |
| `/newdoc` | 새로 만든 문서를 `docs/INDEX.md` 목차에 등록 |

## 4. 지금 들어 있는 서브에이전트

| 에이전트 | 하는 일 |
|---|---|
| `trap-check` | 바꾼 코드가 `CLAUDE.md` 의 «금지사항·함정»을 밟았는지 대조 검사 (읽기 전용) |

---

## 5. 명령을 새로 추가하려면

`.claude/commands/이름.md` 파일을 만들고 커밋하면 끝입니다. 다음 사람은 `git pull` 만 하면 씁니다.

```markdown
---
description: 한 줄 설명 (슬래시 목록에 이 문구가 보입니다)
---

여기에 클로드가 할 일을 평소 말하듯 적습니다.
$ARGUMENTS 라고 쓰면 사용자가 명령 뒤에 붙인 말이 들어갑니다.
```

**팀 전체가 쓰게 되는 파일이니 PR로 올리고 상대에게 알려 주세요.**
