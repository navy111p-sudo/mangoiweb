지금까지의 작업 내용을 **팀원이 나중에 읽고 이해할 수 있는 기록**으로 남기세요.

클로드 코드의 대화 기록은 **내 계정 안에만 있고 팀원에게 자동으로 공유되지 않습니다.**
그래서 남길 가치가 있는 내용은 이렇게 저장소 문서로 옮겨야 합니다.

## 저장 위치

`docs/작업기록/YYMMDD_<짧은제목>.md`
(날짜는 오늘 날짜, 제목은 파일명에 쓸 수 있게 공백 대신 `_`)

제목 인자: $ARGUMENTS

## 반드시 담을 것

```markdown
# <제목>

- 날짜:
- 작업자:
- 브랜치 / PR:

## 1. 왜 했나
(어떤 제보·요청·증상에서 출발했는지. 이게 없으면 6개월 뒤에 아무도 이유를 모릅니다)

## 2. 무엇을 바꿨나
(파일 경로와 함께. 「어디를 보면 되는지」가 핵심)

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법
(가장 중요한 항목입니다. 다음 사람이 같은 길을 다시 파지 않게 합니다)

## 4. 확인한 방법
(타입체크·하니스 결과, 사람이 화면에서 본 것)

## 5. 남은 것 / 주의할 것
```

## 마무리로 할 것

1. 새로 발견한 함정이 있으면 **`CLAUDE.md` 2장 함정 표에도 한 줄 추가**하세요.
   작업기록은 사람이 찾아 읽어야 하지만, CLAUDE.md 는 AI 가 매번 자동으로 읽습니다.
2. `docs/INDEX.md` 에 새 문서를 등록하세요.
3. 사실만 적으세요. 확인하지 않은 것을 «됐습니다» 라고 쓰지 마세요.
