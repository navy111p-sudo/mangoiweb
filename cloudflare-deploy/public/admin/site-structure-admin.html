관리자 메뉴 구성표

관리자 화면 왼쪽 사이드바를 그대로 펼친 표입니다. 사이드바에 접혀 있어 한 번에 보이지 않던 대분류 → 중분류 → 소분류 세 단계를 번호를 붙여 한 장에 담았습니다. 번호는 실제 메뉴 순서 그대로입니다.

9대분류 (사이드바 그룹)
85중분류 (메뉴)
84소분류 (카드 안 탭)
16소분류를 가진 메뉴
3확인 필요
1 대분류 — 사이드바를 눌러서 펼치는 큰 묶음 1.1 중분류 — 누르면 그 카드로 이동 1.1.1 소분류 — 카드 안에서 다시 접혀 있는 탭

구조를 그리다 나온 것 3건

  • 메뉴 85개가 모두 카드로 가는 것은 아닙니다. 82개는 이 페이지 안의 카드로 스크롤하지만, 3개(3.10 연기 수업 현황 · 5.7 캐피타운 정산 · 9.14 사이트 구조도)는 location.href 로 다른 페이지를 엽니다(별도 페이지 표시). 그중 5.7 캐피타운 정산은 style="display:none" 이라 조건이 맞는 계정에만 보입니다 — 메뉴를 세다가 「없는데요?」 소리가 나오는 자리입니다.
  • 3.5 「🌙 근무·휴식·휴가 관리」 와 9.1 「📅 캘린더 관리」 는 이름은 다르지만 같은 카드 card-calendar 를 가리킵니다. 메뉴는 두 개, 도착지는 하나입니다.
  • 6.4 문의 관리 안의 「🪑 대기자 명단」 탭이 두 번 들어 있고, 두 칸 모두 id 가 sub-waitlist 로 같습니다. HTML 에서 같은 id 는 첫 번째만 잡히므로 두 번째 칸은 눌러도 첫 번째가 동작합니다.

찾는 메뉴가 없습니다. 다른 낱말로 찾아 보세요.
