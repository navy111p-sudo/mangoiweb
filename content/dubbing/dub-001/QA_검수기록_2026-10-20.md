## 4. 장면 하나를 «열기» 위한 체크리스트

화면은 아래가 **전부** 갖춰진 장면만 엽니다(`js/ai-dubbing.js` 의 `sceneProblems()` 가 빈 목록). 하나라도 빠지면 그 칸은 «영상 준비 중» 그대로입니다.

- [ ] 권리: 생성 영상의 상업 이용·학생 화면 게시가 가능한지(생성 서비스 약관) — **사람**
- [ ] 클립 → 장면 대응 결정(`clips.json` 의 `assignedScene`) — **사람**
- [ ] 무음 영상 1개(40초 안팎) — 우리 저장소/CDN 으로 옮기고 **`/…` 경로**(⛔ 생성 서비스 주소 금지 — 영구 보관이 아님)
- [ ] 배경음(`bgm`) — `/…` 경로
- [ ] 그 장면에 말하는 캐릭터 **전원**의 목소리 파일(`voices.<캐릭터>`) — `/…` 경로
- [ ] 대사 시각을 영상·입 모양에 맞춤 → `linesSynced: true`
- [ ] 영상 길이(`durationSec`) — 대사 끝이 그 길이를 넘지 않아야 함
- [ ] (선택) 썸네일 — `/…` 경로
- [ ] 사람이 미리 보기로 끝까지 보고 → 장면 `qaApproved: true`
- [ ] 에피소드 전체 `qaApproved: true`

적는 곳은 **[`release.json`](release.json) 하나**이고, 그다음은:

```bash
node scripts/build-dub-manifest.mjs dub-001     # 공개 자료 다시 만들기(손으로 고치지 말 것)
node test-harness/dubbing_episode_harness.mjs     # 승인한 장면의 파일이 실제로 있는지까지 봄
```

⚠️ 미디어 용량: 16개 원본만 253.6 MB 입니다. Cloudflare Workers 정적자산은 **파일 하나 25 MiB** 상한이라 무음 영상 한 개(40초)는 들어갈 수 있지만, 저장소가 **공개**이므로 원본을 `public/` 에 넣을지 R2 에 둘지는 사람이 정할 일입니다(R2 를 쓰더라도 화면에는 우리 도메인의 `/…` 경로로 줄 것).
