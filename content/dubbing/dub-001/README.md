# mangoi.ai A.i영화더빙 — dub-001 콘텐츠 인계

이 브랜치는 Claude가 담당하는 기존 화면 코드를 수정하지 않습니다. 6개 15초 생성 영상의 출처만 `video-sources.json`에 등록합니다.

## 현재 확인된 상태
- Kling 3.0 영상 생성 작업 6개: 완료 (합계 90초)
- 각 영상의 실제 품질 검수, 컷 병합: 미완료
- 목표 4분 분량 중 나머지 150초: 미제작
- 클로드 규격에 맞는 무음 `video.mp4`, `bgm.wav`, 캐릭터별 `voice-<id>.wav`, `preview.mp4`: 미제작
- 학생 녹음/음소거 및 발음 평가: 이 콘텐츠 브랜치에서 구현하지 않음

## 클로드 연동 순서
1. 6개 URL의 원본을 다운로드하여 권리와 재생 가능 여부를 확인합니다.
2. 6개 장면의 등장인물 외형과 스토리 연속성을 프레임 단위로 검수합니다.
3. 기존 화면의 더빙 규격을 유지하고 캐릭터별 음성·배경음악·효과음 스템을 준비합니다.
4. 6개 장면에 대사별 시작/끝 시간, 화자, 감정을 입력하고 자동 검사합니다.
5. 개인/그룹 역할 선택, 학생 음성 녹음, 발표 영상 합성을 테스트합니다.
6. 검수 완료 전에는 프로덕션에 배포하지 않습니다.

참고: 힉스필드의 생성 결과 URL은 영구 호스팅을 보장하지 않습니다. 정식 서비스용 영상은 별도 저장소 또는 CDN으로 옮겨야 합니다.
