# mangoi.ai A.i영화더빙 — 2편 학습 화면 연동 (검수 브랜치)

## 실제 완료한 작업

- `cloudflare-deploy/public/data/dubbing/dub-002.json` 생성: **6장면·240초·영어/한국어 48대사·4캐릭터**의 고유 영상/소리/대사타이밍.
- `cloudflare-deploy/public/data/dubbing/index.json`: 브랜치에서만 **2편 카드 ready**. 기존 1·3편 ready 보존.
- 각 장면에 H.264 720p 30fps **무음 영상**, **음악+효과음 트랙**, **Kai/Emma/Maya/Pip 캐릭터별 영어 음성** 연결. 타임라인 48kHz WAV 원본은 별도 제작 ZIP으로 보존하며, 웹용 오디오는 모바일에서 빠르게 재생할 수 있게 **MP3 48kHz**로 인코딩.
- `ai-dubbing.html`과 `ai-dubbing.js`: **① 먼저 듣고 보기(마이크 요청 없음) → ② 선택 장면 역할 더빙 → ③ 전체 발표 더빙** 버튼 추가. 기존 `ai-dubbing-core.js`의 역할 음소거/학생 차례 배정·발음 평가 엔진은 수정하지 않음.
- 기존 음소거의 핵심 조건: 고른 캐릭터 음성 gain=0, **다른 캐릭터 음성+BGM** gain=1. 여러 명이 같은 캐릭터를 골랐을 때 그 캐릭터의 대사를 번갈아 녹음하는 코어 정책 유지.
- 제작자의 임시 MP4/오디오/CDN 영상은 **운영 R2 장기 호스팅으로 이전하기 전의 스테이징 자산**임.

## **남은 작업 — 정식 «완성» 및 배포 전 필수**

**입 모양과 영어 음소(phoneme/viseme) 단위 동기화는 아직 검증되지 않았습니다.** 현재 `timing:"synced"`는 **음성과 장면의 말하기 구간을 정확히 맞춘다**는 뜻이지 캐릭터 입의 모양이 매 음소와 맞는다는 뜻이 아닙니다. 최종 립싱크를 주장하려면 캐릭터 3D 모델의 viseme 릭/음성 기반 립싱크 재렌더링과 사람이 보는 검수가 필요합니다.

또한 현재 업로드된 Higgsfield CloudFront 미디어 URL은 영구 운영 자산으로 보장되지 않습니다. **Cloudflare R2 또는 같은 오리진의 안정적 스토리지로 이전하고 URL을 교체**한 다음 다음을 완료하세요.

1. 실제 수업 환경 PC/태블릿/모바일에서 각 캐릭터 입·음성의 동기화 전수 검사.
2. 학생 실제 마이크 녹음, 권한 거절, 모바일 브라우저 재생, 완성 영상 저장, Azure 발음 평가 E2E 검수.
3. 1·3편과의 기능 회귀 검수(1·3편의 콘텐츠 파일은 이 PR에서 수정하지 않음).
4. `episode.status=preview`를 그대로 유지하다가 립싱크/실사용 검수 통과 후에만 `final`로 변경.
5. 최종 검수 후에만 PR 병합/Cloudflare 배포.
