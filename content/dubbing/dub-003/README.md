# mangoi.ai A.i영화더빙 — dub-003 영상 출처

3편 «친구들과 함께하는 모험! — 정글의 재규어 자야» 의 장면 영상 6개가 어디서 왔는지 남깁니다.

- 화면이 쓰는 파일: `cloudflare-deploy/public/media/dubbing/dub-003/scene-1..6.mp4` (매니페스트 주소에 `?v=2`)
- 클립 18개의 작업 번호·원본 주소: [video-sources.json](video-sources.json)
- 만든 방법: 장면 그림 12장(장면당 2장, 캐릭터 시트 `077a2aaf…` 기준)을 Kling 3.0 의 **시작·끝 프레임**으로 넣어
  장면마다 **A→A 10초 · A→B 15초 · B 15초** 를 만들고 이었습니다. 앞 클립의 끝 프레임이 다음 클립의 시작 프레임이라 이음매가 끊기지 않습니다.
- 다시 굽기: 원본 클립은 15초에 약 22MB 라 그대로 이으면 Workers 정적자산 한도(25MiB)를 넘습니다 → 1280×720 · 24fps · H.264 CRF 25 · 소리 없음.

⚠️ 원본 주소(생성기 CDN)는 영구 보관이 보장되지 않습니다. 매니페스트에는 우리 서버 경로만 넣으세요.
⚠️ 장면 영상을 또 갈아 끼우면 매니페스트 `?v=` 번호를 올리세요(`?v=` 붙은 주소는 1년 immutable).
