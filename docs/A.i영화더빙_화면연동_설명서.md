> 코드 수정 없이 바로 재생합니다. 마지막 갱신 2026-10-20(1편 완성본 연결 · 에피소드 목록 · «먼저 듣고 따라 말하기» · **6편 = 첫 «완성 · 동기 + 음성 파일» 편**).

| **Claude** | **1편·3편·6편** 의 대본·영상 연결 + mangoi.ai 화면 — 재생 · 학생이 고른 캐릭터만 음소거 · 학생 녹음 · 발음 평가 · 완성 영상 만들기 · 저장 |
| **사장님** | 두 쪽 사이 전달(대화가 직접 이어지지 않습니다) · 최종 확인 · 배포 승인 |

⛔ **같은 편의 영상을 두 번 만들지 않습니다.** 2편 영상은 ChatGPT 쪽만 만들고, Claude 는 그 편을 읽기만 합니다(2026-10-19 사장님 «2편은 GPT가 만들기로 했으니 1편은 너가 완성하고 나서 3편을 만들어줘»).

### 0-1. 모든 편이 따르는 기준 (2026-10-19 사장님 — GPT 2편 기준을 1·3편에도)
- 대상 **유치원 상급 ~ 초등**, 3D, **약 4분 · 6장면**.
- 영어 대사 **3~8낱말**, 학생이 말할 틈을 둠. 한 편 **36문장**, 장면마다 **캐릭터별 2줄 이상**.
- 캐릭터마다 **다른 목소리**(그래서 역할마다 음소거·더빙이 됨). 학생이 **1·2·3역할** 중 골라 맡음 · **2~3명 함께**.
- 흐름: **듣기 → 따라 말하기 → 역할 더빙 → 완성 영상 보기**. 평가는 발음·강세·억양·감정.
- 편마다 **다양한 인종의 아이들**로(편끼리 얼굴이 같을 필요는 없음 — 2026-10-19 사장님 «굳이 모든 편들의 아이들이 똑같이 생길필요없어 · 다양한 인종들로 · 편마다»).

## 1. 넘겨주는 것 — 매니페스트 JSON 한 개

- 파일: `cloudflare-deploy/public/data/dubbing/<에피소드id>.json`
- 화면 주소: `https://mangoi.ai/ai-dubbing.html?ep=<에피소드id>` (id 를 안 주면 `dub-001`)
- 에피소드 id 규칙: **소문자·숫자·`-` 만, 40자 이하** (`dub-001`, `dub-002-space`). 다르면 화면이 무시하고 `dub-001` 을 엽니다.

### 1-1. 맨 위 칸

| 칸 | 꼭? | 뜻 |
|---|---|---|
| `id` | ✅ | 에피소드 id (파일 이름과 같게) |
| `title` | ✅ | `{ "ko": "…", "en": "…" }` |
| `status` | ✅ | `"preview"`(미리보기) 또는 `"final"`(완성). final 이 아니면 화면이 «미리보기» 라고 말합니다 |
| `timing` | ✅ | `"synced"` = 아래 대사 시각이 **실제 영상에 맞춰져 있음**. 그 밖의 값(`"provisional"` 등)이면 시각을 믿지 않고 «차례 모드» 로 돕니다 |
| `characters` | ✅ | `{ "dino": { "name": {"ko","en"}, "emoji": "🦖", "ttsSpeaker": "aries" }, … }` — id 는 소문자·숫자·`_-` 24자 |
| `playable` | ✅ | 학생이 고를 수 있는 캐릭터 id 목록 (예: `["dino","mina"]`) |
| `level` | | 숫자(선택) |
| `note` | | `{ "ko","en" }` — 미리보기일 때 화면 위에 보이는 안내 |
| `baseUrl` | | 아래 경로가 상대경로일 때 앞에 붙일 주소 |

`ttsSpeaker` 는 **음성 파일이 아직 없을 때만** 쓰는 임시 AI 목소리입니다(서버 TTS 화자 이름).
남자: `aries`·`apollo`·`orion` / 여자: `thalia`·`asteria`.

### 1-2. 장면(`scenes[]`)

| 칸 | 꼭? | 뜻 |
|---|---|---|
| `no` | ✅ | 1부터 |
| `label` | ✅ | `{ "ko","en" }` |
| `video` | ✅ | 장면 영상 주소 (아래 2절 규격) |
| `poster` | | 장면 첫 그림(jpg) — 장면 카드 배경과 영상이 뜨기 전 화면에 씁니다. 없으면 이모지 카드 |
| `durationSec` | ✅ | 영상 길이(초) — **실제 파일 길이** |
| `videoAudio` | | `"clean"` = 영상 소리를 켭니다. **없거나 다른 값이면 끕니다**(2-2 참고) |
| `bgm` | | 배경음악·효과음 파일(대사 없음) |
| `voices` | | `{ "dino": "dino_s1.wav", "mina": "mina_s1.wav" }` — **캐릭터별 대사만 담긴 음성 파일**(3절) |
| `lines` | ✅ | 대사 목록(아래) |

### 1-3. 대사(`lines[]`)

| 칸 | 꼭? | 뜻 |
|---|---|---|
| `id` | | 고유 id (예 `s1-l1`) |
| `speaker` | ✅ | `characters` 의 id |
| `en` | ✅ | 영어 대사 (학생이 말하고 채점받는 문장) |
| `ko` | | 한국어 뜻 (자막 아래 줄) |
| `start`, `end` | synced 일 때 ✅ | **그 장면 영상 파일의 0초부터** 센 초. `start < end` · 장면 길이 안 · 앞 대사와 안 겹침 |
| `scored` | | `false` 면 채점 안 함(기본 true) |
| `emotion` | | 그 줄의 감정(예 `excited`·`worried`) — 지금은 대본 기록용이고 채점에는 안 씁니다 |

### 1-4. 에피소드 목록 — `data/dubbing/index.json`

화면 위 «이야기 고르기» 칸을 그리는 목록입니다. **새 편을 올릴 때 이 파일에 한 줄**을 더하세요.

```json
{ "episodes": [
  { "id": "dub-001", "no": 1, "status": "ready",
    "title": { "ko": "신나는 모험의 시작!", "en": "The Adventure Begins!" },
    "poster": "/media/dubbing/dub-001/scene-1.jpg" },
  { "id": "dub-002", "no": 2, "status": "coming",
    "title": { "ko": "예상치 못한 위기!", "en": "An Unexpected Danger!" } }
] }
```

- `status` 가 정확히 `"ready"` 일 때만 눌러서 열립니다. **모르는 값은 «준비 중»** 으로 봅니다(덜 된 편이 열리는 것보다 낫습니다).
- id 규칙은 위와 같고, 같은 id 가 두 번 있으면 뒤엣것을 버립니다. `no` 순서로 그립니다.
- 목록을 못 읽어도 화면은 지금 편을 그대로 재생합니다(목록 칸만 안 보입니다).

## 2. 영상 규격

### 2-1. 파일
- **MP4 (H.264 + AAC), 1280×720, 24fps**, `faststart`(앞부분에 색인). 장면 한 개 = 파일 한 개.
- **우리 서버에 둡니다** — `cloudflare-deploy/public/media/dubbing/<에피소드id>/scene-N.mp4` (+ 같은 이름 `.jpg` 첫 그림). 같은 오리진이라 CORS 걱정이 없고, 화면이 영상을 캔버스에 그려 «완성 영상» 을 만들 수 있습니다.
- ⛔ **생성기(힉스필드) 주소를 그대로 쓰지 마세요** — 그쪽이 지우면 화면에서 영상이 사라집니다(검사가 막습니다).
- ⚠️ **파일 하나 25MiB 한도**(Workers 정적자산). 장면 하나가 넘으면 배포가 막힙니다.
- ⚠️ 이 저장소는 **공개**입니다 — 올린 영상은 누구나 받을 수 있고 지워도 git 기록에 남습니다.
- ⚠️ 영상을 **같은 이름으로 갈아 끼우면** 7일 캐시 때문에 옛 영상이 보입니다 — 이름을 바꾸거나 `?v=` 를 붙이세요.

### 2-2. 영상 안 소리 — 지금 그대로는 못 씁니다
검수해 보니 생성기가 **대본에 없는 목소리**를 영상에 넣어 두었습니다(받아쓰기로 확인):

| 영상 | 들어 있는 소리 |
|---|---|
| 장면 1 | 4.1~5.1초 알아들을 수 없는 말 |
| 장면 3 | 12.1~14.1초 «Wait!» |
| 장면 6 | 3.0~5.0초 «Is Sam June Lur here?» |
| 추가 7 | «Come sit with us» |
| 추가 8 | «Huh, what is this?» |
| 추가 10 | «Look here!» · «I see them!» |
| 추가 11 | «Here, have a snack.» · «It's okay now.» |
| 추가 12 | «Helpy!» · «We can help you!» · «Let's go find it!» |
| 추가 13 | **한국어** «이거 괜찮아 / 나 좀 미끄러졌다 / 괜찮아 다 왔어» |
| 추가 16 | «Look at this little surprise!» |

그래서 화면은 **영상 소리를 기본으로 끕니다.** 소리를 쓰려면:
1. **대사 없는 영상**(또는 효과음만 남긴 영상)을 주고 그 장면에 `"videoAudio": "clean"`, 또는
2. 영상은 그대로 두고 **BGM·효과음을 `bgm` 파일로 따로** 주세요.

소리 크기도 영상마다 많이 다릅니다(장면 1~6: −29.3 ~ −23.0 LUFS · 추가 7~16: −32.5 ~ −19.7 LUFS). **모든 소리 파일을 −16 LUFS 안팎으로 맞춰** 주세요.

## 3. 캐릭터별 음성 파일(스템) — «선택적 음소거» 의 핵심

학생이 디노를 고르면 **디노 목소리만** 꺼야 합니다. 그래서 목소리를 **캐릭터마다 따로** 받습니다.

- 장면마다, 캐릭터마다 파일 1개: `voices: { "dino": "…", "mina": "…", "leo": "…" }`
- **길이 = 그 장면 영상 길이**, 0초 = 영상 0초. 그 캐릭터가 말하지 않는 구간은 **무음**.
- WAV(48kHz) 또는 MP3(192kbps 이상), 모노 가능, −16 LUFS 안팎.
- 그 장면에서 말하는 캐릭터 **전원** 의 파일이 있어야 합니다 — 하나라도 빠지면 화면이 그 장면을 임시 AI 목소리(TTS)로 돌립니다.
- 같은 주소에서 **CORS 허용** 이 필요합니다(완성 영상에 원어민 목소리를 담기 위해).

## 4. 화면이 고르는 재생 방식 (자동)

| 조건 | 방식 | 학생이 보는 것 |
|---|---|---|
| `timing:"synced"` + 시각이 전부 맞음 + 음성 파일 전원 (지금 `dub-006`) | **동기 + 음성 파일** | 영상·BGM·캐릭터 목소리가 함께 흐르고, 학생 캐릭터 목소리만 0. 그 대사 구간에 마이크가 열림 |
| 그 밖 (지금 `dub-001`·`dub-003`) | **차례 모드 + 임시 AI 목소리** | 영상은 소리 없이 배경으로 돌고, 대사가 한 줄씩. 학생 차례엔 «🎤 ○○ 차례예요!» 뒤 마이크 → 말이 끝나면(조용 1.3초) 다음 |

시각이 하나라도 이상하면(겹침·영상보다 김·없음) 그 장면은 **차례 모드로 떨어집니다** — 맞지 않는 시각에 억지로 맞추지 않습니다.

### 4-1. «먼저 듣고 따라 말하기» (차례 모드 · 기본 켬)
학생 차례가 오면 **그 줄을 원어민 목소리로 먼저 한 번 들려준 뒤** 마이크를 엽니다(«👂 먼저 들어 보세요» → «🎤 ○○ 차례예요!»).
화면의 체크(«👂 내 대사도 먼저 듣고 따라 말하기») 를 끄면 예전처럼 바로 마이크가 열립니다 — 연습이 끝난 뒤 «진짜 더빙» 할 때 끄면 됩니다.
- 이때 들려주는 원어민 목소리는 **완성 영상에 안 담깁니다**(그 동안 녹화를 잠깐 멈춥니다) — 완성 영상에는 학생 목소리만 남습니다.
- «⏭ 넘어가기» 를 누르면 **듣기만** 건너뛰고 곧바로 학생 차례가 옵니다(그 줄을 통째로 넘기지 않습니다). 소리를 아직 받는 중에 눌러도 받은 뒤 재생하지 않습니다.
- 켜져 있으면 장면을 시작할 때 학생 대사 소리도 미리 받아 둡니다(차례마다 멈칫하지 않게).
- 서버 목소리를 못 받아 기기 목소리로 들려줘도 «완성 영상에 안 담겼어요» 안내는 띄우지 않습니다(듣기 소리는 원래 안 담습니다).

## 5. 함께 하기 (1~5명)

- 학생 수 1~5명, 각자 캐릭터 하나. **고른 캐릭터만** 원어민 목소리가 꺼집니다. 안 고른 캐릭터는 원어민 그대로.
- 같은 캐릭터를 여러 명이 고르면 그 캐릭터 대사를 **번갈아** 말합니다(캐릭터가 2~3명뿐이어도 5명이 함께 할 수 있게).
- 그래서 **캐릭터마다 대사 수가 너무 치우치지 않게** 써 주시면 좋습니다(한 장면에 학생이 고를 수 있는 캐릭터 대사가 최소 1줄).
- **손님 캐릭터** — `characters` 에는 있지만 `playable` 에 없는 캐릭터는 학생이 고를 수 없고 **언제나 원어민 목소리**로 나옵니다(6편 위스커스 선장). 손님이 말하는 장면은 남은 줄을 고를 수 있는 캐릭터끼리 공평하게 나누고, 손님 대사는 그 장면의 **절반 이하**로 둡니다(검사 ⑥-14).
