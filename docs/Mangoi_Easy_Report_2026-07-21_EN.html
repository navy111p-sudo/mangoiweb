8. Glossary

#TermPlain explanation
1Cloud (Cloudflare)Instead of buying and maintaining our own server computers, we rent from a company that runs computers worldwide. We pay only for what we use; they handle breakdowns. We use "Cloudflare"
2Judgment TrainingOur own AI feature that trains "thinking and judging for yourself in the AI era" instead of memorization. Supports Korean/English/Chinese
3APIA doorway to one function inside a program. Think "370 functions"
4SRSThe document that describes the whole system — a "blueprint of the house" any developer can read to understand our system
5KmongA Korean marketplace website that connects companies with freelance developers and designers
6P2PPerson-to-person: the video call connects the student's and teacher's devices directly, without passing through a central server — so almost no server load
7ServerlessNot "no server," but "no server for US to manage." The cloud company scales computers up and down automatically. No overheating, no electric bills, no hardware failures for us
8SSHThe remote "key/passage" for logging into a server. This passage to our old Cafe24 server is currently blocked, holding up a few tasks
9NCPNaver Cloud Platform — the new home for the data on our aging Cafe24 server (a Korean data center, which also fits privacy-law requirements)
