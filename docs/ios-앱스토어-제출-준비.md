# 아이폰 앱 — 앱스토어 제출 준비

> 애플 계정(D-U-N-S) 대기 중에 미리 끝내둘 수 있는 것들. 코드가 아니라 **서류가 병목**이다.
> 코드·기술 사항은 [ios-app/README.md](../ios-app/README.md) 참조.

## 🔴 0. 지금 없는 것 — 개인정보처리방침 (제출 차단 항목)

**사이트 전체에 개인정보처리방침 페이지가 없다.** (`public/` 전수 검색 결과 0건)

이건 두 가지 문제다.

1. **앱스토어 제출 자체가 막힌다.** App Store Connect 는 개인정보처리방침 **URL 을 필수 입력**으로 받는다. 없으면 제출 버튼을 누를 수 없다.
2. **iOS 와 무관하게 이미 법적 의무다.** 개인정보보호법상 처리방침 수립·공개 의무가 있고, 우리는 **미성년자 29,000명의 이름·전화·학부모 전화·주소·음성·수업 녹화**를 다루고 있다.

→ 아래 1·2 절이 그 처리방침을 쓰는 데 필요한 재료다. **법인 정보(⬜)는 사장님이 채워야 한다.**

## 1. 실제로 수집하는 개인정보 (코드에서 확인한 것)

애플의 **App Privacy 신고**와 처리방침에 그대로 들어가는 항목이다.
추측이 아니라 `src/*.ts` 와 D1 스키마에서 확인했다.

| 구분 | 항목 | 근거 |
|---|---|---|
| 신원 | 이름(한글·영문), 아이디 | `students_erp.korean_name/english_name/username` |
| 연락처 | **본인 전화, 학부모 전화**, 이메일 | `phone`(288곳) · `parent_phone`(147곳) · `email`(85곳) |
| 인적사항 | 성별, 주소, 생년월일 | `gender`(20) · `address`(18) · `birthday`(3) |
| 학습 | 수업 이력·출결·평가서·숙제·퀴즈/게임 기록·포인트 | D1 전반 |
| **음성** | 발음 채점·말하기 연습 녹음 | 음성코칭·Speech |
| **영상** | **화상수업 녹화** | R2 `webrtc-class-recordings` |
| 결제 | 결제 내역 (카드번호는 저장 안 함 — 토스가 보유) | 토스페이먼츠 연동 |

**🔴 애플이 특히 깐깐하게 보는 지점:** 이용자 상당수가 **만 14세 미만 아동**이다.
아동 데이터 + 음성 + 영상 조합이라 App Privacy 신고를 **정확히** 해야 한다.
얼버무리면 반려가 아니라 **등록 후 삭제**까지 갈 수 있는 영역이다.

## 2. 개인정보를 넘기는 곳 (처리 위탁)

배포 로그의 바인딩·환경변수에서 확인한 실제 연동처다.

| 위탁받는 곳 | 무엇을 | 확인 근거 |
|---|---|---|
| Cloudflare | 호스팅·데이터베이스(D1)·녹화 보관(R2)·AI | `env.DB` `env.RECORDINGS` `env.AI` |
| 토스페이먼츠 | 결제 처리 | 결제 연동 |
| Solapi | 알림 문자(SMS) | `env.SOLAPI_FROM_PHONE` |
| 카카오 | 알림톡·상담 채널 | 알림톡 연동 |
| Resend | 안내 이메일 | `env.RESEND_FROM` |

⬜ **국외 이전 고지가 필요하다** — Cloudflare·Resend 는 서버가 국외다.
처리방침에 이전 국가·시점·방법·항목을 적어야 한다.

## 3. ⬜ 사장님이 채워야 하는 것 (제가 지어낼 수 없는 항목)

- ⬜ 법인명 / 대표자명 / 사업자등록번호 / 주소
- ⬜ **개인정보보호책임자** 성명·직책·연락처 (법정 필수 기재)
- ⬜ 개인정보 **보유·이용 기간** (수업기록 몇 년? 녹화 몇 개월?) — 운영 정책의 문제라 결정 필요
- ⬜ **화상수업 녹화 보관 기간과 동의 방식** (아동 영상이라 가장 민감)
- ⬜ 만 14세 미만 **법정대리인 동의**를 지금 어떤 절차로 받고 있는지

이 5개가 정해지면 처리방침 초안을 바로 완성해 페이지로 올리겠다.

## 4. 그 밖의 제출물 체크리스트

| 항목 | 상태 |
|---|---|
| 개인정보처리방침 URL | 🔴 **없음 — 최우선** |
| App Privacy 신고 답변 | 🟡 재료는 위 1·2절에 준비됨, ⬜ 보유기간 확정 필요 |
| **심사용 테스트 계정(ID/PW)** | 🟡 준비 필요 — **빠뜨리면 100% 반려** (로그인 없이는 화면이 안 보임) |
| 앱 스크린샷 (6.7인치 아이폰 필수) | ⬜ 실기기 빌드 후 촬영 |
| 앱 이름·부제·설명·키워드 | ⬜ |
| 연령 등급 설문 | ⬜ 아동 대상이라 정확히 |
| 지원 URL / 마케팅 URL | 🟢 `test.mangoi.co.kr` 활용 가능 |
| 앱 아이콘 1024px (알파 없음) | 🟢 **완료** — `ios-app/.../AppIcon-1024.png` |
| 수출규제 답변 | 🟢 **완료** — Info.plist 에 `ITSAppUsesNonExemptEncryption=false` 선기재 |
