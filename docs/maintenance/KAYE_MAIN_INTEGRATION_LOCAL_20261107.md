# Kaye 교재 공유 — 최신 main 로컬 통합

> 아래 내용은 최초 로컬 통합 시점의 기록입니다. 이후 main 통합·게시·배포 상태는 별도 릴리스 실행 결과를 확인해야 합니다.

통합 기준 main은 `0cd11c8ec0f2a794511065519cf15b27c27e70ee`, 원본 로컬 검증 체크포인트는 `af8b3e4e5b92c315edecb34589dd34d04f7560d4`입니다. 원본 브랜치와 미완성 모델 파일은 그대로 보존합니다. 이 통합은 로컬 검증 단계이며 운영 배포·원격 게시를 수행하지 않습니다.

## 충돌 처리

- 최신 main의 칠판/PDF batched KV 로그, 참관 서명/답장, 탭 복원, 자동 ping 시각 판정과 20초 순단 유예를 보존합니다. 기존 저장 정책 자체를 이번 통합에서 다시 설계하지 않습니다.
- `recordLegacyWb`/`recordLegacyPdfAnno`로 기존 main 기록 경로를 유지합니다. 실험 SQL 스냅샷은 기존 로컬 생성자 옵션 아래에 분리합니다. 일반 런타임은 실험 SQL 저장소를 열지 않습니다.
- 실험 PDF epoch 프로토콜은 로컬 생성자 옵션과 플래그가 함께 있어야 합니다. 환경 플래그만으로 켜지지 않습니다. 보호 프로토콜은 세대 증명이 없는 기존 PDF 로그를 새 공유에 수입하지 않으며, 기존 칠판 로그 복원은 유지합니다.
- PDF 로더의 account/room/connection/share epoch 보호와 main의 load generation 보호를 함께 유지합니다. 수동 선택 뒤 늦은 이전 공유 응답이 새 문서를 덮어쓰거나 재시도하지 않도록 합니다.
- 번역 실패/시간 초과는 자동 원문 전송을 하지 않습니다. 초안과 전송 안 됨/재시도 안내를 남깁니다. 성공 시 번역 중 버튼을 해제합니다. 명시적으로 번역을 끄면 기존 원문 전송을 사용할 수 있습니다. 이는 기존 main의 실패 시 자동 원문 전송과 구분되는 의도된 동작입니다.
- main의 기존 자산 원장 해시는 유지하고, 통합된 main/chat 스크립트는 각각 v84/v5로 분리합니다. 로컬 미게시 v74/v75 및 chat v3 충돌은 운영 main 이력을 우선합니다. 기존 원본 해시는 원본 커밋에서 보존됩니다.

## 검사 방법과 범위

`node test-harness/kaye_class_issues_261104_harness.mjs`는 최신 main의 저장/재입장/탭/순단 검증과 현재 번역 계약을 실행합니다. `vc_pdf_share_epoch_room_harness`의 추가 검사는 보호 프로토콜 재구성 시 기존 PDF 로그가 재분류되지 않고 기존 칠판 로그는 복원되는지 확인합니다. 두 격리 경로를 제거한 변형 소스는 이 검사에 실패합니다.

기존 main의 PDF lifecycle/race 하니스에는 현재 loader가 요구하는 계정/연결 모형을 추가했습니다. 직접 join 테스트는 async main 계약대로 await합니다. Windows에서 file URL pathname을 직접 경로로 쓰던 두 하니스는 fileURLToPath로 바꿨습니다.

첫 화면 예산은 올리지 않았습니다. 이번에 수정한 PDF 함수 6개의 긴 주석 6,913바이트를 실행 파일에서 분리했으며 TypeScript AST printer의 주석 제외 출력 동등성을 확인했습니다. 원 주석은 검토 증거의 `relocated-pdf-comments.json`에 보존합니다.

## 한계와 보류

- 동일 URL의 중지/재공유 뒤 지연 패킷을 구분하는 새 프로토콜은 여전히 로컬 전용입니다. 이 통합만으로 운영의 동일 URL 재공유 문제가 해결됐다고 주장하지 않습니다.
- 기존 main 로그의 쓰기/삭제 실패 및 수업 신원 증명 정책 전체를 다시 보장한 것은 아닙니다. 실험 SQL 영속화/자동 복원은 활성화하지 않습니다.
- 합성 소켓/DOM/번역/DB 및 로컬 Miniflare 검증을 운영 수업 재현으로 해석하지 않습니다. 실제 브라우저 실행 파일 부재, 실기기·실수업 미검증 상태를 유지합니다.
- Wrangler는 로그인되지 않았습니다. 이번 단계는 인증을 설정하거나 운영 배포를 실행하지 않습니다. PG/SMS/메일/운영 DB/실계정/마이크 접근도 하지 않습니다.
- Claude AI 말하기/아바타, 결제/환불 및 Eric 읽기 전용 확인 작업은 변경하지 않습니다. 최종 검사 결과와 로그는 별도 인계 자료에 포함합니다.
