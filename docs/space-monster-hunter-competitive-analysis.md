# 🎮 Space Monster Hunter — 경쟁사 벤치마킹 분석

## 🔍 참고 게임 분석

### **1. House of the Dead 시리즈 (1996~현재) ⭐⭐⭐⭐⭐**

**핵심 메커닉** (우리가 채택):
- ✅ **1인칭 라이트건 뷰**: 화면 하단에서 괴물 출현
- ✅ **원근감 있는 접근**: 멀리서 작게 → 점점 커지며 중앙으로
- ✅ **실시간 반응**: 마우스/터치 클릭 → 즉시 피드백
- ✅ **스테이지 진행**: 3~5개 구간으로 난이도 상승
- ✅ **보스 몬스터**: 최종 보스 특별 처리
- ✅ **멀티플레이어**: 동시 플레이 가능 (우리는 싱글 플레이)

**비주얼 특징**:
- 3D 그래픽 (arcade) → 우리는 **2.5D (프레임 기반 스프라이트)**
- 어두운 배경 (화면 대비): 플레이어 중앙 집중 ✅ 반영
- 괴물은 화면 중앙에서 **가장 크게** 나타남 ✅ 반영
- 효과음 + 음성 (위협감 강화): 우리는 **TTS 영단어** ✅

**학습점 적용**:
```
House of the Dead:     |  Space Monster Hunter:
조준 + 사격 = 점수    →  조준 + 클릭 = 영단어 학습
스테이지 클리어       →  Stage 1~3 + 단어 마스터
보스 등장              →  최종 괴물 (PHANTOM)
```

### **2. Vampire Survivors (2022) ⭐⭐⭐⭐**

**혁신 요소** (채택 X, 참고만):
- 🎮 **무한 웨이브**: 끝나지 않는 적 (우리는 3 스테이지)
- 🎮 **자동 공격**: 플레이어만 움직임 (우리는 수동 클릭)
- 🎮 **화려한 VFX**: 화면 가득 이펙트
- 🎮 **진화/업그레이드**: 게임 중 강화

**우리가 참고한 것**:
- ✅ **최소한의 UI**: 점수, 시간, 생명력만 표시 (군더더기 제거)
- ✅ **빠른 속도**: 2~3초마다 새 괴물 출현
- ✅ **피드백**: 히트 시 이펙트 + 점수 즉시 표시

## 🎯 우리의 설계 철학 (모든 결정의 근거)

### **1. "최소한의 UI, 최대의 집중"**
```
House of the Dead: 화면 중앙에만 괴물 출현
                 ↓ (학습 원리 적용)
우리: 괴물은 크고, UI는 화면 가장자리만
     = 학생의 시선이 영단어에 집중
```

### **2. "영화급 실사 + 심플 메커닉"**
```
경쟁사: 복잡한 3D 엔진 (비용 높음)
우리: Higgsfield AI 영상 (자동화 가능)
     + CSS 애니메이션 (간단한 원근감)
     = 품질 ↑, 비용 ↓, 개발 시간 ↓
```

### **3. "클리어 가능한 게임 (교육용)"**
```
arcade 게임: 무한 웨이브 → 최고 점수 추구
우리: 3 스테이지 → 명확한 끝 → 성취감
     (학생이 "이 게임을 다 깼다!" 느낌)
```
