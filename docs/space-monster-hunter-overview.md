# 🛸 Space Monster Hunter — 기획안 개관

## 📌 프로젝트 개요

**목표**: 망고아이 플랫폼에 **House of the Dead 스타일의 고퀄리티 라이트건 슈팅 게임** 추가  
**타겟**: 초등~중학생 영어 학습자 (재미 + 학습 병행)  
**핵심 차별점**: 모든 크리처·배경을 **Higgsfield AI 실사 영상** 기반으로 제작  
**론칭 예정**: 2~3주 내 (개발 + 배포)

---

## 🎮 게임 메커닉

### **1인칭 라이트건 뷰 (First-Person Shooter)**
```
┌──────────────────────────────────┐
│                                  │
│         🛸 우주 괴물            │  ← 멀리서 작게 시작
│           (작음)                │
│                                  │
│                                  │
│   🛸    🛸         🛸           │  ← 점점 커지며 다가옴
│                                  │
│                                  │
│  🛸🛸🛸🛸🛸 🛸🛸🛸🛸🛸          │  ← 가까워짐 (클릭 시 점수)
│                                  │
│        ⊕ (크로스헤어)            │  ← 중앙에서 조준
│                                  │
└──────────────────────────────────┘

화면 하단: 점수, 스테이지, 타이머, 생명력 ❤️❤️❤️
```

### **게임플레이 흐름**
```
Stage 1 (60초) → Stage 2 (90초) → Stage 3 (120초) → 게임 끝

각 스테이지:
  • 우주 괴물 3~4마리 동시 접근
  • 멀리서 작게 → 점점 커지면서 중앙으로
  • 클릭해서 맞추면: +100점 + 히트 이펙트
  • 못 맞추고 통과하면: -1 생명력
  • 생명력 0 = 게임 오버
```

## 🎨 시각 콘셉트

### **배경**
- **Primary**: 미래형 우주선 내부 (금속 벽, 네온 조명, 영점 중력)
- **Secondary**: 깊은 우주 (별, 성운, 은하)
- **실사**: Higgsfield AI로 생성 (4K, 영화풍)

### **괴물 8종 (각 1인칭 정면 카메라)**

| # | 이름 | 영어 단어 | 설명 | 난이도 |
|---|---|---|---|---|
| 1 | 트리포드 | TRIPOD | 세 다리 외계생물, 생체 발광 | ⭐ |
| 2 | 스라임 | BLOB | 투명한 젤러티 괴물 | ⭐ |
| 3 | 스파이더 | SPIDER | 금속 거미, 8개 다리 | ⭐⭐ |
| 4 | 사이클롭스 | CYCLOPS | 거대 눈, 근육질 인형형 | ⭐⭐ |
| 5 | 플라이어 | FLYER | 박쥐형 날개, 부유 생명체 | ⭐⭐ |
| 6 | 텐터클 | TENTACLE | 문어형, 빛나는 촉수 | ⭐⭐⭐ |
| 7 | 아머 | ARMOR | 크리스털 갑옷, 기하학적 | ⭐⭐⭐ |
| 8 | 팬텀 | PHANTOM | 유령형, 반투명 에너지 | ⭐⭐⭐ |

## 📊 학습 요소

### **단어 학습 구조**
```
Stage 1: 기초 3개 단어
  TRIPOD, BLOB, SPIDER
  → 반복적 노출 (시각 + 청각)

Stage 2: 중간 3개 단어
  CYCLOPS, FLYER, TENTACLE
  → 난이도 ↑ (빠른 속도)

Stage 3: 심화 3개 단어
  ARMOR, PHANTOM, (+1 보너스)
  → 고급 어휘 (도전)
```

### **영어 접근법**
- **정확성**: 원어민 발음 TTS (Aura 목소리)
- **빈도**: 매 괴물 출현 시 단어 음성 + 텍스트
- **보상**: 맞춘 괴물 = 해당 단어 ✅ 표시 + 포인트

| **배포** | deploy.ps1 | 자동 라이브 배포 |
