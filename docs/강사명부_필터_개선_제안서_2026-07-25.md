## 1. 지금 문제 (사장님 캡처)

| # | 문제 | 근거 |
|---|---|---|
| 1 | **필터 칩 3줄**(구분 3 + 상태 4 + 그룹 **10개**) = 산만, 눈 둘 곳 모름 | 캡처 |
| 2 | **"— 34"** 이름 없는 그룹 그대로 노출 | 그룹 행 |
| 3 | **"전체 227" 줄마다 반복** | 각 필터 행 |
| 4 | **퇴사 161명 > 재직 32명** → 첫 화면이 퇴사자로 뒤덮임 | 상태 행 |
| 5 | 집계 경고문 인라인("…현재값과 다를 수 있음") = 어수선 | 상단 |

## 2. 업계 기준 (벤치마킹)

- **긴 목록(8+)은 드롭다운**이 공간 효율적·명확. 칩 나열은 값이 적을 때(2~4개)만. (Bricx, Pencil&Paper)
- **적용된 필터만** 결과 바로 위에 칩으로 표시 → 지금 뭐가 걸렸는지 한눈에. (Aufait UX)
- **즉시 적용**(선택 즉시 반영, 저부담 상호작용). (SaaSUI)
- 값이 많은 축은 **패싯(faceted) 드롭다운**, 표는 필요 시 열 단위 필터.

## 3. 개선안 (시안 그대로)

### 한 줄 툴바
```
[🔍 이름·닉네임·그룹 검색] [구분▾] [상태▾] [그룹▾] [정렬▾]        표시 32 / 총 227 ⓘ
```
- 구분·상태·**그룹(10개)**을 전부 **드롭다운**으로 → 3줄 칩이 한 줄로.
- **인원수는 오른쪽 한 곳**("표시 N / 총 227")으로 통합. 줄마다 반복 제거.
- 집계 경고문 → **ⓘ 툴팁**(호버 시).

### 적용된 필터 칩 (활성 시만)
```
적용된 필터  [상태: 재직 ✕]  [그룹: 중국어 강사 ✕]   모두 해제
```
- 걸린 필터만 결과 위에 칩. ✕로 개별 해제, "모두 해제".

### 기본값·라벨 정리
- **기본 상태 = 재직** (퇴사 161명이 첫 화면을 덮지 않게). 필요 시 상태▾에서 전체/퇴사.
- **"—" 그룹 → "미분류"** 로 명확히 표기.
- 드롭다운 옵션 안에 인원수 병기 가능(예: "중국어 강사 40").

### 한/영 병기 (필수)
- 라벨·옵션 전부 KO/EN (필리핀 강사·직원). 예: 구분/Type · 상태/Status · 그룹/Group · 재직/Active · 미분류/Ungrouped.

## 4. 효과
- 3줄 → **1줄** (세로 공간 ⅓). 첫 진입이 깔끔.
- "지금 뭐가 걸렸나"가 칩으로 명확 → 헷갈림 제거.
- 퇴사자에 덮이지 않는 기본 화면.

## 5. 구현 메모 (실착수 시)
- 필터바 위치: `adm-p2.js`/`adm-q6.js`(로드/렌더 분리됨). 기존 필터 상태값 재사용.
- 목록 재조회: `loadTeacherProfiles()`(adm-core.js:2231)는 이미 status/group 파라미터 받음 → 드롭다운 값 연결.
- 그룹 목록은 데이터에서 동적 수집(현재 칩 생성 로직 재사용). "" 그룹 → "미분류".
- 검증: 인라인 JS 문법 하니스 + 실세션에서 필터 조합 클릭 + 한/영.
