## 🥇 안건 1. 서버 이전(NCP) — ⭐⭐⭐ 오늘 회의의 핵심 (기한: 8/15, D-25)

**상황(쉽게):** 우리 데이터가 사는 카페24 서버의 **임대 계약이 8월 15일에 끝난다.** 게다가 건물 자체(CentOS 7)가 지원종료라 어차피 이사는 필수. 이사 갈 곳(네이버클라우드 NCP)과 이사 계획서(무엇을 옮길지 목록·순서)는 **우리가 이미 문서로 다 만들어 놨다.** 옮길 짐 = MySQL(결제·회원 원본), Neo4j(그래프 DB), 야간 자동작업 2개(동기화·백업), (선택) 옛 PHP 사이트. **Cloudflare 쪽(실서비스)은 이사와 무관하게 그대로 돌아간다.**

**질문:**

1. ⭐⭐⭐ "8월 15일 계약 만료 전에 이전을 끝내려면 **언제 시작해야** 하나요? 귀사가 맡으면 **총 비용과 기간**은요?" (항목별로: 서버 셋업 / DB 이전 / 검증 / 예비일)
2. ⭐⭐⭐ "두 가지 방식 중 뭘 추천하나요? **A) 귀사가 이전 주도** vs **B) 우리가 이사 계획서대로 직접 하고 귀사는 검수·비상 대기만.** 각각 비용은요?"
   - 🟢 B도 가능하다며 검수 단가 제시 → 유연한 파트너
   - 🔴 A만 되고 금액이 크다 → 다른 견적과 비교 필요
3. ⭐⭐ "이전 중 **서비스 중단**이 있나요? 실서비스(Cloudflare)는 그대로니까, 밤 시간 몇 시간이면 되지 않나요?"
4. ⭐⭐ "만에 하나 8/15까지 못 끝내면 **카페24 계약 단기 연장**이 가능한가요? 연장 절차·비용을 아시나요?"
5. ⭐ "이전 후 새 서버(NCP)의 **월 유지비**는 대략 얼마로 보시나요?"

## 🥈 안건 2. 서버 SSH 접속 복구 — ⭐⭐⭐ 모든 작업의 선행 조건

**상황(쉽게):** 지금 카페24 서버에 **원격 접속(SSH)이 안 된다.** 그래서 서버 안에서만 할 수 있는 작업 3가지가 전부 멈춰 있다. 이사(안건 1)도 접속이 돼야 시작한다.

**질문:**

1. ⭐⭐⭐ "SSH 접속이 막혀 있습니다. **원인이 뭘까요?** (카페24 정책 차단? 방화벽? 접속 정보 변경?) **누가 복구 권한**을 갖고 있고, **며칠이면** 뚫리나요?"
2. ⭐⭐ "복구되면 저희가 바로 할 일이 3가지입니다 — ① 결제↔학생 연결표 추출(아래 안건 3) ② 전화번호 암호 해제(복호화 명령어는 우리가 준비해 둠) ③ 백업 자동작업 점검. **이 작업들을 함께 봐줄 수 있나요? 건별 비용은요?**"
3. ⭐ "카페24 쪽 **관리 계정(호스팅 콘솔·root 비밀번호·도메인/DNS)** 정보를 우리가 전부 갖고 있는지 같이 점검해 줄 수 있나요?" (이사 전 필수 체크)

## 🥉 안건 3. 결제 매출 귀속 — ⭐⭐ 돈 계산이 안 맞는 문제

**상황(쉽게):** 결제 데이터는 다 옮겨왔는데(11,398건), "이 결제가 **어느 학생 것인지** 연결하는 표"가 옛 서버 MySQL에만 있다. 그래서 지금 새 시스템에서 **7월 매출의 79%가 주인 없는 돈**으로 잡힌다. 표만 뽑아오면 해결된다(우리가 진단 도구까지 만들어 둠).

**질문:**

1. ⭐⭐ "카페24 MySQL에서 **회원↔학생(원생) 연결이 어느 테이블**에 있는지 아시나요? 그 표를 **CSV로 뽑는 작업**을 SSH 복구 직후 바로 해줄 수 있나요?"
   - 🟢 테이블 구조를 바로 안다 → 옛 시스템을 실제로 잘 아는 팀
   - 🔴 모른다/봐야 안다 → 옛 시스템 이해도 낮음 (이사 견적도 보수적으로 봐야)
2. ⭐ "옛 시스템(PHP)이 **앞으로 새 결제**를 만들면 그 연결은 어디에 기록되나요? 이사 후에도 계속 만들어지는 데이터인가요?"

## 안건 4. 옛 PHP 홈페이지(www.mangoi.co.kr) 거취 — ⭐⭐ 지난번 이어서 결론 내기

**질문:**

1. ⭐⭐ "옛 PHP 사이트에서 **아직 실제로 쓰이는 기능**(결제 생성? 회원 가입? 관리자 업무?)이 뭐가 남았나요? **완전히 끄면 무엇이 멈추나요?**"
