현황 진단 — 왜 15개인데 6~7개처럼 느껴지나

02

설계 원칙 — 두 마리 토끼는 어떻게 잡는가

재미와 학습을 각각 늘리는 게 아니라, 하나로 합치는 것이 핵심입니다.

지금 구조의 한계 — "재미 껍데기 + 퀴즈 알맹이"

현재 게임 대부분은 이런 구조입니다.

단어를 맞히면 → 적이 폭발한다
여기서 언어는 관문이고, 재미는 보상입니다. 둘이 분리되어 있습니다.
그래서 껍데기(전차·비행기·좀비)를 아무리 바꿔도 알맹이(단어 맞히기)가 같으면 금방 질립니다. 학생 입장에선 "폭발 보려고 단어 맞히는 것"이 되고, 학습은 재미의 비용으로 인식됩니다.

제안하는 구조 — "언어 자체가 게임 조작 수단"

내가 만든 문장대로 게임 세계가 실제로 바뀐다
언어가 관문이 아니라 조종간이 됩니다. 더 좋은 문장을 쓰면 더 좋은 결과가 나옵니다.
이때 학생은 이기려고 언어를 더 정교하게 쓰게 되고, 학습은 재미의 비용이 아니라 수단이 됩니다.

이 원칙에 따라 신규 게임을 설계했습니다. 아래 4가지 기준으로 각 게임을 검증했습니다.

  1. 승리 조건이 언어 능력인가 — 반사신경이나 운이 아니라 언어가 실력을 가르는가
  2. 기존 9종과 인지 방식이 다른가 — 또 다른 어순 조립이면 탈락
  3. 실패가 학습이 되는가 — 틀렸을 때 왜 틀렸는지 즉시 알 수 있는가
  4. 기존 자산으로 만들 수 있는가 — 이미 있는 API·엔진 재사용 가능한가
활용 가능한 기존 자산 (이미 작동 중)
약점 단어 추적 /api/games/weak · 발음 점수 /api/games/shadow · 맞춤 추천 /api/games/recommend · AI 영작 첨삭 /api/ai/write-correct · AI 대화 /api/ai/chat-friend · 원어민 음성합성 · 음성인식(7개 게임에서 이미 사용) · 3D 엔진(탱크대전·구조선에서 검증) · 교재 레슨 연동 · 포인트·배지·연속출석

즉, 신규 게임 대부분은 백엔드를 새로 만들 필요가 없습니다.
03

신규 게임 6종 기획

현재 비어 있는 학습 영역(쓰기·대화·듣기받아쓰기·순간반응·기억)을 채웁니다.
1 마법 그림책 Story Painter 쓰기 · 작문

그림이 한 장 주어집니다. 학생이 그 장면을 영어 문장으로 씁니다. 쓴 문장대로 그림이 실제로 바뀝니다. "The cat is on the box"라고 쓰면 고양이가 상자 위로 올라갑니다. 틀린 문장을 쓰면 엉뚱한 그림이 나오고(고양이가 상자 아래 있음), 학생은 웃으면서 자기 실수를 봅니다.

승리 조건
목표 그림과 똑같이 만들기 — 정확한 문장을 써야만 가능
재미 요소
내 문장이 세계를 바꾸는 창작 쾌감 · 엉뚱한 결과의 유머 · 완성작 갤러리 저장·자랑
학습 효과
조립이 아닌 생성 — 현재 0개인 영역. 전치사·어순·시제를 스스로 선택해야 함
실패=학습
틀린 문장의 결과를 그림으로 즉시 봄. 설명 없이도 이해됨
기술
AI 영작 첨삭 API(기존) + 요소별 사전 생성 이미지 조합(고양이·상자·나무 × 위치)
흥미도 ★★★★★학습효과 ★★★★★개발난이도 중추천순위 1순위
2 망고 카페 알바 Mango Cafe 실전 대화

학생이 카페 직원이 됩니다. 손님(AI)이 말로 주문하고, 학생이 말로 응대합니다. 제대로 알아듣고 응대하면 손님이 만족하고 팁을 줍니다. 못 알아들으면 손님이 다시 말해주거나, 화를 냅니다.

승리 조건
하루 영업 마감까지 손님 만족도 유지 — 듣고 즉시 응대해야만 가능
재미 요소
진상 손님·단골·바쁜 러시아워 등 상황 변화 · 팁으로 카페 꾸미기 · 손님 캐릭터 수집
학습 효과
듣기와 말하기를 동시에 — 실제 대화에 가장 가까움. 현재 0개 영역
실패=학습
못 알아들으면 손님이 천천히 다시 말함 = 자연스러운 반복 노출
기술
AI 대화 API(기존) + 음성인식(기존) + 음성합성(기존). 백엔드 신규 개발 거의 없음
흥미도 ★★★★★학습효과 ★★★★★개발난이도 중추천순위 2순위
3 비밀 무전 해독 Radio Intercept 듣기 · 받아쓰기

적의 무전을 감청합니다. 잡음 섞인 음성을 듣고 받아쓰면 암호가 풀리고 적 기지 위치가 지도에 드러납니다. 난이도가 오르면 잡음이 커지고 말이 빨라집니다.

승리 조건
제한 시간 안에 메시지 해독 — 정확히 들어야만 가능
재미 요소

학습 효과

틀린 글자만 빨갛게 표시 후 그 부분만 다시 재생 = 집중 교정
기술
음성합성(기존) + 잡음 합성(Web Audio, 기존 코드 재사용) + 단어 은행 선택식(저학년) / 타이핑(고학년)
흥미도 ★★★★학습효과 ★★★★★개발난이도 하추천순위 3순위

4 단어 반사신경 Word Reflex 순간 판단 · 유창성

단어나 짧은 문장이 빠르게 지나갑니다. 맞으면 O, 틀리면 X를 즉시 누릅니다. "He go to school" → X. 생각할 시간이 없습니다. 연속으로 맞히면 속도가 빨라지고 배점이 올라갑니다.

승리 조건
연속 판단 기록 — 문법 감각이 자동화돼야만 가능
재미 요소
리듬게임 같은 몰입 · 개인 최고기록 갱신 · 짧아서 부담 없음(1회 60초)
학습 효과
자동화 — 아는 것과 즉시 쓰는 것은 다름. 유창성의 핵심이며 현재 0개 영역
실패=학습
틀린 문항만 모아 라운드 끝에 느린 속도로 재출제
기술
약점 단어 API(기존)로 개인별 출제 — 자주 틀리는 것 위주로 자동 구성
흥미도 ★★★★학습효과 ★★★★개발난이도 하 (가장 저렴)추천순위 4순위
5 단어 금고 털기 Vault Heist 기억 · 회상

금고 화면에 단어가 잠깐 나타났다 사라집니다. 기억해서 순서대로 입력해야 금고가 열립니다. 단계가 오를수록 단어가 늘고 노출 시간이 짧아집니다. 경보가 울리기 전에 털어야 합니다.

승리 조건
기억한 단어를 정확히 재현 — 눈으로만 봐서는 안 되고 머리에 남겨야 함
재미 요소
하이스트 긴장감 · 경보 카운트다운 · 단계별 금고 등급(구리→금고왕)
학습 효과
인출 연습 — 보고 고르는 것보다 기억해서 꺼내는 쪽이 장기기억에 훨씬 효과적
실패=학습

흥미도 ★★★학습효과 ★★★★★개발난이도 하추천순위 5순위

04

기존 9종 정리 — 없애지 않고 각자 다르게

이미 만든 게임을 버리는 것은 낭비입니다. 대신 각 게임에 고유한 문법 역할을 부여합니다.

겉모습은 그대로 두고 출제 규칙만 바꿉니다. 학생은 "탱크는 어순, 전투기는 시제"처럼 게임마다 다른 훈련을 하게 되고, 개발 비용은 출제 로직 교체 수준으로 작습니다.

게임새 전담 영역구체적 변경
셔먼 탱크대전어순 (대표작 유지)현행 유지 — 어순 훈련의 간판
P-38 라이트닝시제 변형적기에 go / went / will go 표시. 상황에 맞는 시제만 격추
단어 테트리스품사 분류블록 색 = 품사. 명사줄·동사줄을 맞춰 쌓아야 지워짐
워드 파이터전치사 · 관사좀비가 in / on / at을 들고 등장. 맞는 것만 유효타
망고 구조선단수 · 복수구조 대상이 1명이면 a friend, 여럿이면 friends
문법 피자문장 성분현행 유지 — 이미 주어·동사·목적어 구분 중
낚시 + 말하기뜻 매칭현행 유지 — 이미 다름
중국어 슈팅성조 · 병음중국어 고유 영역으로 특화
문장 벽돌통합 검토테트리스와 기능 중복 — 통합 또는 정리 대상
기대 효과
게임 수는 그대로인데 체감 다양성이 6~7종 → 14~15종으로 올라갑니다. "다 해봤다"는 학생에게 "탱크는 했는데 시제 훈련은 안 해봤네"라는 새로운 목표가 생깁니다.
05

공통 엔진 분리 — 앞으로의 개발 속도

눈에 보이지 않지만, 위 두 가지를 실행하려면 먼저 해결해야 하는 문제입니다.

현재는 공통 기능(음성합성·말하기연습·난이도·학습기록·교재연동)이 9개 파일에 각각 복사되어 있습니다. 그래서:

  • 발음 기능 하나 고치려면 9곳을 똑같이 수정해야 합니다
  • 한 곳을 빠뜨리면 그 게임만 다르게 동작합니다 (실제로 발생해 온 문제)
  • 신규 게임을 만들 때마다 이 덩어리를 또 복사하게 됩니다

공통 부분을 엔진 파일 1벌로 분리하고 각 게임은 자기 규칙만 갖게 하면, 앞으로 9번 할 일이 1번이 됩니다. 위의 "기존 9종 정리"도 이 작업 후에 하면 훨씬 빠르고 안전합니다.

순서가 중요합니다
엔진 분리를 먼저 하지 않고 게임 9개의 출제 규칙을 각각 바꾸면, 그 작업을 9번 반복하게 됩니다. 엔진 분리 → 규칙 차별화 순서를 권합니다.
06

단계별 실행안

한 번에 다 하지 않습니다. 효과가 빨리 보이는 것부터 배치했습니다.

1단계 · 빠른 효과 확인

신규 게임 2종 · 백엔드 신규 개발 없음

단어 반사신경과 비밀 무전 해독을 먼저 만듭니다. 둘 다 개발 난이도가 낮고 기존 API만으로 동작합니다. 여기서 "인지 방식이 다른 게임이 실제로 더 오래 플레이되는가"를 데이터로 확인합니다.

확인 지표 · 1인당 평균 플레이 시간 · 재방문율 · 기존 게임 대비 이탈률

2단계 · 구조 정리

공통 엔진 분리 · 사용자에게 보이는 변화 없음

1단계 결과가 긍정적이면, 본격 확장 전에 엔진을 분리합니다. 이 단계는 학생 화면에 변화가 없지만, 이후 모든 작업 속도를 좌우합니다. 기존 게임이 그대로 동작하는지 회귀 검증이 핵심입니다.

3단계 · 간판 게임

마법 그림책 · 망고 카페 알바

가장 차별화되고 학부모에게 보여주기 좋은 두 게임입니다. "우리 아이가 영어로 문장을 만들면 그림이 바뀐다", "AI 손님과 영어로 대화한다"는 상담·홍보에서 바로 쓸 수 있는 이야기가 됩니다.

4단계 · 기존 9종 차별화

엔진 위에서 출제 규칙만 교체

P-38=시제, 테트리스=품사, 워드파이터=전치사 등으로 각 게임에 고유 역할을 부여합니다. 엔진이 분리된 상태이므로 게임당 작업량이 작습니다.

5단계 · 지속 장치

반 대항 리그 · 단어 금고 털기

라인업이 충분히 다양해진 뒤에 리그를 엽니다. 게임이 적을 때 리그를 열면 같은 게임만 반복하게 되므로, 순서상 마지막입니다.

비용 측면
신규 6종 중 5종은 기존 API·엔진 재사용으로 백엔드 신규 개발이 거의 없습니다. 그래픽 자산도 AI 생성으로 조달 가능합니다(현재 크레딧 잔량은 별도 확인 필요). 가장 큰 비용은 개발 시간이며, 엔진 분리(2단계)가 이후 모든 단계의 시간을 줄입니다.
08

요약

  1. 문제는 게임 수가 아니라 인지 방식의 중복입니다. 15개 중 9개가 같은 훈련이고, 코드상으로도 서로의 복사본입니다.
  2. 재미와 학습을 합치는 방향으로 설계합니다. 언어를 관문이 아니라 조종간으로 — 내 문장이 게임 세계를 바꾸게 만듭니다.
  3. 비어 있는 영역부터 채웁니다. 쓰기·대화·받아쓰기·순간반응·기억은 현재 게임이 하나도 없는 영역입니다.
  4. 기존 게임은 버리지 않고 역할을 나눕니다. 출제 규칙만 바꿔 체감 다양성을 두 배로 만듭니다.
  5. 작게 시작해 데이터로 검증합니다. 1단계 2종을 먼저 만들고 지표를 확인한 뒤 확장 여부를 결정합니다.
