# 💳 결제·수업 규칙 질문지 (매니저용) — 2026-07-21

목적: 옛 시스템의 "결제하면 수업이 자동으로 잡히는" 규칙을 새 시스템에 그대로 옮기기 위해, **규칙의 정답지**를 만드는 문서입니다.
작성 방법: 아는 대로 빈칸을 채워주세요. 정확한 숫자를 모르면 "대략 ~였던 것 같다"도 좋습니다. 예외가 있으면 꼭 적어주세요.

---

## 1. 상품(수강권) 구성

| 질문 | 답변 |
|---|---|
| 판매 중인 수강권 종류는? (예: 주1회×1개월=4회, 주2회×3개월=24회 …) 전부 적어주세요 |  |
| 각 수강권의 가격은? (정가/할인가 따로) |  |
| 수업 1회 길이는? (20분/25분/30분 — 상품마다 다르면 구분) |  |
| 형제·자매 할인, 재등록 할인 등 특별 가격이 있나요? |  |
| 체험 수업(무료/유료) 상품이 있나요? 규칙은? |  |

## 2. 결제할 때 학생(학부모)이 고르는 것

| 질문 | 답변 |
|---|---|
| 요일은 어떤 조합에서 고르나요? (예: 월수금 / 화목 / 월~금 매일 / 자유선택?) |  |
| 시간은 몇 분 단위로 고르나요? 가능한 시간대 범위는? (예: 14:00~22:00, 30분 단위) |  |
| 강사는 학생이 직접 고르나요, 배정해 주나요? 고른다면 어떤 기준 목록에서? |  |
| 시작일은 자유롭게 고르나요? (예: 다음 주 월요일부터만? 아무 날이나?) |  |
| 결제 완료 후 수업이 자동으로 몇 주치까지 잡히나요? (예: 결제한 회차만큼 전부? 4주씩?) |  |

## 3. 회차 연장(재결제) 규칙

| 질문 | 답변 |
|---|---|
| 재결제하면 기존 요일·시간·강사가 그대로 이어지나요? |  |
| 마지막 수업 전에 재결제하면 언제부터 연장되나요? (예: 마지막 수업 다음 회차부터 자동) |  |
| 남은 회차가 있는데 재결제하면 어떻게 되나요? (회차 합산?) |  |

## 4. 미결제·종료 규칙

| 질문 | 답변 |
|---|---|
| 몇 주(또는 며칠) 동안 재결제가 없으면 "종료" 처리했나요? (예: 3주) |  |
| 종료 처리는 자동이었나요, 매니저가 버튼을 눌렀나요? |  |
| 종료되면 그 학생의 시간대(슬롯)는 바로 다른 학생에게 열렸나요? |  |
| 종료 전에 학부모에게 안내(문자·전화)를 했나요? 언제, 몇 번? |  |

## 5. 변경·연기·보강 규칙

| 질문 | 답변 |
|---|---|
| 수업 연기(당일 취소)는 몇 시간 전까지 무료였나요? 그 후에는? ※ 현 정책: 30분 전 무료 — 옛 규칙과 같은가요? |  |
| 연기하면 보강은 언제·어떻게 잡았나요? (예: 빈 슬롯에서 학생이 선택 / 매니저가 지정) |  |
| 요일·시간 변경은 얼마나 자주 허용했나요? |  |
| 지각·결석 처리 규칙은? (예: 지각 +2분 대기, 결석 +10분 — 현 정책과 같은가요?) |  |

## 6. 중복 방지·특수 상황

| 질문 | 답변 |
|---|---|

| 공휴일·강사 휴가 때 수업은 어떻게 처리했나요? (자동 순연? 보강?) |  |
