## 4. 정책 (제안)

1. **휴강일** = «공휴일 정본» 에 있는 날 (6-①에서 정함).
2. **예외(수업 그대로)** = 중국어 수업. 지금 기준: 담당 강사가 **예외 강사 목록**(기본값 원부 29 «중국어 강선생님»)에 있는 수업.
3. 휴강 수업은:
   - 학생 홈: 벨 **안 울림**, 카드 대신 「🎌 오늘은 공휴일(한글날) 휴강입니다 · Holiday — no class today」 한 줄(소리 없음).
   - 학생 입장: 오늘 수업방으로 **안 보냄** + 같은 안내. (⛔ 방 자체를 잠그지는 않음 — 사장님·관리자 시험 입장과 회의방은 그대로)
   - 강사 포털: 「휴강」 회색 배지, 입장 버튼 대신 안내.
   - 30분 전 문자·결석 감지·노쇼 알림: **안 보냄 / 기록 안 함**.
   - 관제탑·지금 수업: «휴강 N건» 으로 따로 셈(수업 건수에 안 섞음).
4. **데이터는 안 바꿈** — `class_schedules` 를 취소·이동하지 않고 «읽을 때» 가립니다. 그래서 공휴일을 잘못 넣어도 지우면 바로 원래대로 돌아옵니다.
5. 기존 «수업 밀기» 와의 관계: 밀기는 그대로 둡니다(밀린 수업은 그날 없으니 충돌 없음). 휴강 판정은 «밀리지 않고 남은 수업» 을 가리는 안전망입니다.

## 6. 사람이 정할 것 (정해야 시작합니다)

1. **공휴일 출처** — 어느 표를 «휴강일» 로 볼까요?
   - **(추천) `holidays` 공식 한국 공휴일 자동 + 관리 화면에서 «이날은 수업함» 예외 지정.** 이유: 오늘처럼 사람이 `enroll_holidays` 에 안 넣으면 또 울립니다. 휴강은 «읽을 때 가리기» 라 되돌리기 쉬워 자동이어도 위험이 낮습니다.
   - (대안) `enroll_holidays` 만 — 사람이 넣은 날만. 넣는 것을 잊으면 오늘과 같은 사고.
   - ⚠️ 필리핀 공휴일은 제외(한국 공휴일만).
2. **중국어 수업 판별** — 지금은 «강사 29번(중국어 강선생님)» 뿐입니다. 중국어 강사가 늘면 목록에 추가하는 방식으로 충분한지, 아니면 수업마다 «언어» 칸을 새로 둘지.
3. **강사 급여** — 휴강 수업은 급여에서 빼는 게 맞는지(지금은 카페24 급여 기준이라 이 계획으로 바뀌지 않습니다).
4. **카페24** — 오늘 156건 대부분이 카페24 미러(`c24-mirror`)입니다. 카페24 쪽에서도 공휴일 예약을 안 만들게 할지(근본 정리)는 카페24 담당과 별도로.
