## 3. 크몽 회의 분석 (녹음 49분 전사 + 회의 메모 종합)

### 3.1 그들의 제안

- 기존 시스템을 자사 기술(Spring Boot·Next.js·PostgreSQL)로 **이관(=재개발)** + AI 기능 1개 = 최소 6천만 원. AI 포함 전체는 최소 3억 원 / 6개월+.
- 화상수업은 자체 개발 대신 **외부 상용 솔루션 구매** 권장.
- 크몽이 예산 옵션별 서면 제안서를 이메일로 발송 예정(**현재 대기 중** — 도착 시 본 보고서에 대조표 추가).

### 3.2 검증 결과 — 동의 vs 비동의

**동의하는 지적 (우리가 개선할 것):**

| 지적 | 우리의 대응 |
|---|---|
| 화면·기능이 너무 복잡, IT 제품 느낌이 안 남 | 첫 화면 단순화(3버튼 구조) + 신기능 기본 숨김 + 온보딩 안내 추진 |
| 좋은 기능도 안 쓰인다(챗봇 사례) | 메뉴 사용률 측정 → 하위 기능 정리·통합 |
| 개발팀 없이는 위험(비상 상황) | 건별 비상 대응 계약(보험)으로 해결 — 월 고정비 최소화 |
| 단계적·지속적 개발이 생존 조건 | 이미 매일 개발→검증→배포 중. 원칙 유지 |

**동의하지 않는 주장 (사실과 다름):**

| 주장 | 사실 |
|---|---|
| "화상 자체 개발은 불안정·과부하·발열·고비용" | 우리는 P2P+서버리스 구조 — 영상이 우리 서버를 거치지 않아 과부하 개념 자체가 없음. 이미 실수업 운영·검증 완료(자동복구·저대역 폴백 포함) |
| "동접 20만은 어려운 기술" | 우리 수업은 1:1·소그룹, 방 단위 자동 확장. 20만 동접은 우리와 무관한 숫자 |
| "AI 비서는 큰 프로젝트, 고비용" | AI 운영비서·상담직원·웜업·판단력 훈련 등 이미 10여 곳 가동 중 |
| "AI를 얹으려면 시스템을 다시 설계해야" | AI가 이미 얹혀 돌아가는 시스템 — 전제 자체가 성립 안 함 |
| 그들이 제안한 "AI 1기능"(수업 후 자동 보고서) | **이미 구현·운영 중**(강사 AI 코칭 + 월간 리포트 + 판단력 성장 리포트) |

참고: 회의 발언 대부분은 **구 시스템(2019년 PHP+세하 화상+KCP 결제)** 기준이었으며, 새 시스템(Cloudflare)은 깊이 검토되지 않았음(상대측이 우리 핵심 기술을 처음 접함).

### 3.3 예산 평가

- 6천만~3억 원의 실체 = **이미 완성된 것을 버리고 다시 만드는 비용**. 결과물은 현재 기능의 일부만 재현될 가능성이 큼.
- 6개월 재개발은 정작 급한 **8/15 서버 계약 만료를 해결하지 못함**.
- 권고: 재개발 ❌ / ✅ 건별 비상 계약 + 서버 이전 별도 견적 + (선택) UX 컨설팅 소액 발주로 실력 검증.
