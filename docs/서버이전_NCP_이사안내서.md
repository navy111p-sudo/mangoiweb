## STEP 2 — 새 서버 기본 세팅
Rocky Linux 9 최신화 → MariaDB·Neo4j(·PHP) 기존과 같은 메이저 버전 설치 → fail2ban → cloudflared.
**전부 제가 명령어로 만들어 드리고, 사장님은 붙여넣기만.**

## STEP 3 — 데이터 이관 (무손실)
1. 기존: `mysqldump`로 DB 통째 백업 → 압축
2. 새 서버로 복사 → 복원
3. **Neo4j는 새로 만들 필요 없음** — `mangoi-sync.sh`를 새 서버에서 한 번 돌리면 MySQL에서 자동 재생성 (매일 밤 하던 그 작업)
4. 새 서버에서 관리자 화면·데이터 **시운전** (기존 서버는 계속 켜둠 = 안전망)

## STEP 4 — 전환 (새벽, 이용 적은 시간)
- **cloudflared 터널**을 새 서버에서 실행 → `neo4j.mango-i.com` 주소 그대로 재연결 → **워커 설정 변경 불필요**
- 옛 PHP 사이트 이사 시: **DNS A레코드** `mangoi.co.kr → 새 IP`, **SPF TXT**도 새 IP로
- 전환 후 즉시 검증

## STEP 5 — 검증 & 마무리
- 관리자 대시보드에서 카페24 데이터 정상 표시 확인
- 강사매칭·이탈분석(Neo4j) 정상 확인
- **기존 서버 2~4주 보존** 후 카페24 해지/폐기
