📌 세 줄 요약
① 미팅에서 말씀하신 성적표(카톡 발송 + 인쇄 + 오각형 그래프)는 대부분 이미 있는 기능을 다듬는 일이라 새로 만드는 부분이 많지 않습니다.
② 준비하면서 확인해보니, 지금 나가는 AI 문구가 강사 확인 없이 학부모께 자동 발송되고 있었습니다. 이번에 같이 고칩니다.
③ ✅ 아래 5가지 결정이 2026년 7월 25일 모두 확정됐습니다 — 전부 비용·경량·속도 원칙에 맞는 쪽으로 결정. 이제 개발을 시작할 수 있습니다.

1. 무엇이 바뀌나

지금바뀌는 것
오각형 그래프 없음, 인쇄 버튼 없음발음·어휘·문장·태도·참여도 5가지를 오각형 그래프로 + 인쇄 버튼 추가
AI 문구가 강사 확인 없이 바로 학부모께 발송됨AI가 초안을 쓰고, 강사가 확인 버튼을 눌러야만 발송됩니다
문구가 딱딱한 보고서 톤낮은 점수도 "부족함"이 아니라 "성장 중"으로, 항상 희망적인 문장으로
학부모만 봄학생 본인도 같은 리포트를 볼 수 있음(카톡 발송은 이미 됨)
✅ 이건 결정 사항이 아니라 그냥 넣습니다 — "AI가 쓰고 강사가 확인 후 발송"은 예전에 비슷한 기능에서 AI 오탈자로 학부모 컴플레인을 걱정해 공개를 미룬 적이 있어서, 안전을 위해 무조건 넣는 걸로 진행합니다.
🎯 사장님 지시(비용·경량·속도 원칙) — "비용은 적게, 사이트는 가볍게, 속도는 빠르게"에 맞춰 추천드렸고, 원장님이 5가지 전부 추천안대로 확정하셨습니다.

2. 확정된 결정 5가지 (2026-07-25)

① 발송 주기
2개월 1회확정강사 부담·카카오 발송비용이 절반
(미채택) 월 1회 — 더 자주 소식이 가지만 강사 부담 큼
② 반 평균 비교 표시
안 보여준다확정우리 아이의 성장(저번 대비)만 표시 — 더 심플하고 경쟁 느낌 없음
(미채택) 반 평균을 점선으로 참고 표시
③ 어휘·문장 점수 기준
일단 시작확정반 평균 대비 상대평가로 우선 출시, 절대 기준표는 추후 커리큘럼팀과 별도 확정
(미채택) 기준표부터 만들고 시작 — 정확하지만 시작이 늦어짐
④ 인쇄물 형태
지금처럼 인쇄창에서 PDF 저장확정추가 비용·개발 없음, 사이트도 안 무거워짐
(미채택) 버튼 한 번에 PDF 다운로드 — 신규 외부 코드 필요
⑤ 엑셀 파일 형태
CSV (꾸밈 없음)확정엑셀에서 바로 열림, 추가 비용·개발 없음
(미채택) 색·서식 있는 진짜 엑셀 파일 — 새 라이브러리 필요
