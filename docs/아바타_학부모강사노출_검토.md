## 결론 먼저

**지금은 반쪽만 가능합니다.** 그리고 나머지 반쪽은 **이미 알려진 그 한 가지**에 걸려 있습니다 —
아바타 게임의 "고른 캐릭터가 기기 간 안 이어짐" 문제와 **똑같은 원인**입니다.

즉 이건 별개의 새 작업이 아니라, **같은 하나를 열면 같이 열리는 일**입니다.

| | 지금 가능? | 이유 |
|---|---|---|
| 성장 단계(Lv.1~5)·진행률 표시 | ✅ 가능 | 점수가 서버에 있음 |
| 이번 주 미션 횟수·연속 학습일 | ✅ 가능 | 서버에 있음 |
| **어떤 캐릭터인지(판다/여우/드래곤/강아지)** | ❌ 불가 | **학생 폰에만 저장돼 있음** |
| 캐릭터 그림 보여주기 | ❌ 불가 | 위와 같은 이유 |

---

## 왜 캐릭터를 못 보여주나

실측으로 확인한 내용입니다.

- 학생이 고른 종족은 `mangoi_avatar_species` 라는 값으로 **학생 브라우저 안에만** 저장됩니다.
  이 값을 쓰는 파일은 게임 화면 단 하나뿐입니다(`student-game-avatar.html`).
- 학부모 화면(`parent.html`)은 자녀의 ID 를 알고 있고 게임 API 도 이미 쓰고 있어서
  **점수는 얼마든지 가져올 수 있습니다.** 하지만 종족은 서버 어디에도 없습니다.

> ⚠️ **여기서 하면 안 되는 선택**
> "그럼 일단 판다로 보여주자"는 안 됩니다. 아이가 드래곤을 키우고 있는데
> 엄마 화면에 판다가 뜨면, 그건 없는 정보를 지어내 보여주는 것입니다.
> 학부모는 그 화면을 **자녀의 실제 기록으로 믿습니다.**

---

## 그래서 무엇을 추천하나

### 1순위 — 서버 저장부터 (담당자 협의 필요)

`student_avatar` 저장 공간 하나와 통로 하나를 만들면, **이 검토서의 모든 항목이 한꺼번에 해결**됩니다.

- 학생: 폰을 바꿔도 캐릭터가 그대로
- 학부모: 자녀 캐릭터를 그림까지 정확히
- 강사: 담당 학생 캐릭터 확인

작업 자체는 작습니다(저장 공간 1개·통로 1개). 다만 **서비스 전체가 지나가는 핵심 파일**에
등록해야 해서, 규칙상 **배포 권한자만** 만질 수 있습니다. 화면 쪽은 이미 준비돼 있습니다.

### 2순위 — 그 전까지 할 수 있는 것 (원하시면 지금 가능)

학부모 리포트에 **캐릭터 그림 없이 성장 상태만** 넣는 것은 지금도 됩니다.

> 🌱 **우리 아이 학습 친구** — 성장 5단계 중 **3단계**
> 이번 주 미션 12회 · 연속 학습 4일

- 전부 서버에 있는 진짜 값입니다.
- 캐릭터 이름·그림은 넣지 않습니다(모르는 것을 지어내지 않기 위해).
- 서버 저장이 열리면 이 자리에 그림과 이름을 채워 넣기만 하면 됩니다.

**다만 솔직히 말씀드리면** — 아바타의 힘은 "내 캐릭터"라는 데서 나옵니다.
그림 없이 숫자만 있는 건 기존 학습 지표와 크게 다르지 않습니다.
**1순위를 먼저 하시는 편이 낫다고 봅니다.**

## 화면별 검토

### 학부모 리포트 (`parent.html`)

| 항목 | 내용 |
|---|---|
| 자녀 ID | 이미 알고 있음(`?uid=`) |
| 게임 API | 이미 사용 중(`/api/games/recommend`) |
| 추가 서버 작업 | **없음** — 기존 통로로 점수 조회 가능 |
| 개인정보 | 학부모는 본인 자녀만 조회(토큰 확인 기존 구조 그대로) |
| 재등록 효과 | 자녀가 매일 뭘 하고 있는지 **눈에 보이는** 지표 |

### 강사 화면 (`teacher.html`)

| 항목 | 내용 |
|---|---|
| 상태 | ⚠️ **지금 다른 작업자가 이 파일을 작업 중** — 손대기 전 협의 필요 |
| 활용 | 수업 시작 때 "이번 주 몇 단계 올랐네!" 한마디의 근거 |
| 주의 | 강사 화면은 필리핀 회선을 고려해 **가볍게 만든 화면**입니다.<br>캐릭터 그림(장당 약 20KB)을 넣을 때 무게를 다시 재야 합니다 |

## 하지 말아야 할 것

- **학생 간 비교로 만들지 말 것.** "○○이는 5단계인데 우리 아이는 2단계"는
  아이에게도 학부모에게도 좋지 않습니다. 자기 성장만 보여줍니다.
- **학부모 화면에서 아바타를 조작하게 하지 말 것.** 아이 것입니다.
- **없는 값을 채워 넣지 말 것.** 위의 "일단 판다로" 같은 선택.

---

## 필요한 결정

1. **1순위(서버 저장)를 진행할지** — 진행하면 학생·학부모·강사가 한꺼번에 해결됩니다.
   배포 권한자와의 협의가 필요합니다.
2. **2순위(그림 없는 성장 표시)를 먼저 넣을지** — 지금 바로 가능하지만 효과는 제한적입니다.
3. 강사 화면은 **현재 작업자와 일정 조율** 후 진행합니다.
