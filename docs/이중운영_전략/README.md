# 이중운영 전략 — 새 사이트 / 옛 사이트 동시 운영

새 망고아이 사이트와 기존 사이트를 당분간 **함께 운영**하는 계획을 정리한 작업 폴더입니다.
학생·대리점이 새 사이트에 익숙해질 때까지의 전환 기간을 다룹니다.

## 파일

| 파일 | 설명 |
|---|---|
| `망고아이_두사이트_동시운영_설명서.pdf` | **최종 산출물.** A4 12쪽, 한국어, 10세 수준 |
| `망고아이_두사이트_동시운영_설명서.html` | PDF 원본. 내용을 고칠 때는 **이 파일만** 고칩니다 |
| `build.sh` | HTML → PDF 재생성 스크립트 |
| `도메인_조사결과.md` | 도메인 조회 원자료 (2026-08-15) |

## PDF 다시 만들기

```bash
cd docs/이중운영_전략
./build.sh
```

Chromium 헤드리스로 렌더링합니다. 한글 폰트(`fonts-nanum`, `fonts-noto-cjk`)가 필요합니다.

```bash
sudo apt-get install -y fonts-nanum fonts-noto-cjk
```

## 문서 요약

### 결론

학생 29,000명 규모라 **동시 운영이 맞는 선택**입니다. 단 두 가지를 반드시 지켜야 합니다.

1. **종료일을 먼저 정한다** — 3개월 권장. 날짜가 없으면 영구 이중 운영이 됩니다.
2. **쓰기는 새 사이트 한 곳에서만** — 옛 사이트는 읽기 전용. 숙제·포인트·출석이 양쪽에
   저장되면 나중에 정본을 특정할 수 없습니다.

### 현재 주소 상태 (2026-08-15 실측)

| 주소 | 실제 | 조치 |
|---|---|---|
| `test.mangoi.co.kr` | Cloudflare Worker (신규, 운영중) | `test` 제거 — 1순위 |
| `mangoi.co.kr` / `www.mangoi.co.kr` | 118.219.234.180 (구 서버) | 안내 배너 → 종료 후 리다이렉트 |
| `mangoi.com` / `www.mangoi.com` | 121.78.235.40 (별개) | 신규 사이트로 리다이렉트 정리 |
| `mango-i.com` | NXDOMAIN | 옛 문서의 오기. 안내에서 삭제 |

> `test.` 서브도메인이 운영 주소로 노출되는 것이 현재 가장 시급한 문제입니다.
> 도메인 신규 구매보다 우선순위가 높습니다.

### 12개 보완 항목

1순위 — 종료일 확정 / 쓰기 단일화 / 옛 사이트 안내 배너 / SSO(로그인 1회) / `test` 제거
2순위 — 대리점 교육 / 단계별 전환 / 주간 사용률 계측 / 문의 창구 단일화 / 구 서버 보안 점검
3순위 — 전체 백업 / 종료 후 리다이렉트 최소 1년 유지

전환 계획은 4단계 13주. 종료 전 **하루짜리 사전 차단 리허설**을 넣었습니다.
