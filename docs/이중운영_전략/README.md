### ⛔ 정정 (2026-08-15) — www 재지정은 병행 운영과 양립 불가

초판에서 「`www.mangoi.co.kr` 를 신규 Worker 에 붙여 0원으로 `test` 문제 해결」이라고
적었으나 **이는 틀렸습니다.** `www.mangoi.co.kr` 에는 구 사이트가 서비스 중이며,
DNS 이름 하나는 목적지 하나만 가리킵니다. 재지정하는 순간 구 사이트가 그 주소를 잃고,
그 시점이 곧 하드 컷오버가 되어 **병행 운영 계획 자체가 무너집니다.**

- **가능**: 이름 여러 개 → Worker 하나 (`test.mangoi.co.kr` + `mangoi.ai` 동시 연결)
- **불가능**: 이름 하나 → 사이트 두 개

따라서 전환 기간 중 신규 사이트에는 **별도 주소**를 붙이고, `www` 재지정은
**종료일 당일 작업**으로 미룹니다. `mangoi.ai` 구매가 이 문제의 해법이 됩니다
(구 사이트를 전혀 건드리지 않음).
