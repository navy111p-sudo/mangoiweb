# 도메인 조사 원자료

- **조사일**: 2026-08-15
- **방법**: DNS `NS` 레코드 질의 (dnspython). `NXDOMAIN` = 위임 없음 = 미등록 가능성 높음,
  `NOERROR` + NS 존재 = 등록됨
- **한계**: DNS 기반이므로 **등록만 하고 네임서버를 설정하지 않은 도메인**은 미등록으로
  보일 수 있습니다. 실제 구매 전 등록업체(가비아·후이즈·Cloudflare·Namecheap)에서
  재확인 필수. RDAP/WHOIS 는 이 환경의 egress 정책상 조회 불가였습니다.

## 핵심 답: `www.mangoai.ai`

**NXDOMAIN → 미등록 가능성 높음. 구매 가능해 보입니다.**

다만 권장하지는 않습니다.

| 이유 | 내용 |
|---|---|
| 비용 | `.ai` 는 레지스트리(Anguilla) 규정상 **최소 2년 등록**. 연 $65~$90 수준이라 초기 약 $150~$180 |
| 상표 충돌 | "MangoAI" 사용 주체 다수. **MangoAI(영상광고 스타트업)가 2026-02 Canva 에 인수**됨. Mango Animate 의 "Mango AI" 영상 생성기도 존재 |
| 철자 변경 | 현 브랜드는 `mangoi`. `mangoai` 는 i 가 하나 늘어 구전·전화 안내 시 혼동 |

`.ai` 를 꼭 쓴다면 **`mangoi.ai`** 가 브랜드 철자를 유지하므로 더 낫습니다 (역시 미등록).

## 현재 망고아이 주소 실측

```
mangoi.co.kr        NS walt.ns.cloudflare.com, paityn.ns.cloudflare.com  (존은 Cloudflare)
test.mangoi.co.kr   A  104.21.28.253, 172.67.147.240   (Cloudflare proxied — 신규 운영 사이트)
mangoi.co.kr        A  118.219.234.180                 (구 서버)
www.mangoi.co.kr    CNAME → mangoi.co.kr               (구 서버)
new.mangoi.co.kr    A  101.79.28.176                   (제3의 호스트 — 정체 불명)
mangoi.com          A  121.78.235.40                   (별개 호스팅)
www.mangoi.com      A  121.78.235.40
mango-i.com         NXDOMAIN                           (존재하지 않음 — 옛 문서 오기)
```

### 와일드카드 발견 — `*.mangoi.co.kr` → `118.219.234.180`

존재할 수 없는 이름들도 전부 구 서버 IP 로 응답합니다.

```
zzqq9x7.mangoi.co.kr               -> 118.219.234.180
asdf-nonexistent-1234.mangoi.co.kr -> 118.219.234.180
claude-test-probe.mangoi.co.kr     -> 118.219.234.180
```

`app` / `class` / `study` / `my` / `old` / `legacy` / `lms` 등도 같은 IP 인데, 이는 개별
레코드가 아니라 **와일드카드 통과로 보입니다.** 실제로 구 LMS 가 이 이름들을 쓰는지는
DNS 만으로 판별 불가 — 구 서버 담당자 확인이 필요합니다.
(이 환경은 HTTP egress 가 차단되어 실제 응답 본문은 확인하지 못했습니다.)

**함의**

1. 신규 서브도메인을 쓰려면 **명시적 레코드**를 만들어야 합니다. 안 만들면 조용히 구 서버로 갑니다.
2. 오타 주소가 404 가 아니라 **구 사이트**로 뜹니다. 전환 막바지에 혼선 요인.
3. 종료일 작업에 **와일드카드 목적지 재지정**을 반드시 포함해야 합니다.
   빠뜨리면 옛 사이트를 내려도 트래픽이 계속 그쪽을 향합니다.
4. `new.mangoi.co.kr` 은 와일드카드가 아닌 **별도 A 레코드**입니다. 새 사이트 주소 후보로
   쓰기 전에 무엇이 물려 있는지 먼저 확인하세요.

### ⛔ www 재지정에 대한 정정

`www.mangoi.co.kr` 를 신규 Worker 로 재지정하면 **구 사이트가 그 주소를 잃습니다.**
DNS 이름 하나는 목적지 하나만 가리키므로, 이는 «0원 개선»이 아니라 **하드 컷오버**입니다.
병행 운영 기간에는 하면 안 되고, **종료일 당일 작업**으로 배치해야 합니다.

반대 방향(이름 여러 개 → Worker 하나)은 제약이 없습니다. Cloudflare Worker 에 커스텀
도메인을 복수로 붙이는 것은 정상 구성이며, `test.mangoi.co.kr` 를 유지한 채
`mangoi.ai` 를 추가하는 것이 권장 경로입니다.

## 권장 순서 (2026-08-15 개정)

1. **약 22만원(2년) / 지금** — `mangoi.ai` 등록 후 신규 Worker 에 커스텀 도메인으로 연결.
   `test.mangoi.co.kr` 는 **유지**(즐겨찾기 보호). 구 사이트는 전혀 건드리지 않음.
   → `test` 노출 문제와 병행 운영이 동시에 해결됩니다.
2. **약 4만원 / 이번 달** — `mangoai.co.kr` + `mangoai.kr` 오타 방어 등록.
3. **0원 / 종료일 당일** — `www.mangoi.co.kr` + 와일드카드를 신규 Worker 로 재지정,
   구 서버는 `old.mangoi.co.kr` 명시 레코드로 이전.

무료 서브도메인(예: `class.mangoi.co.kr`)으로 1번을 대체할 수도 있으나,
와일드카드 때문에 **해당 이름이 구 LMS 에서 이미 쓰이는지 먼저 확인**해야 합니다.

다중 도메인을 보유하더라도 **정본은 하나**로 두고 나머지는 301 리다이렉트만 겁니다.
그러지 않으면 검색엔진에서 자기 도메인끼리 경쟁(중복 콘텐츠)합니다.
