## 왜 사장님이 주신 한글판을 «그대로» 올리지 않았나 (2026-10-28)
사장님이 4쪽 한글판 PDF 를 주셨는데, 그대로 올리지 않고 **같은 구성·같은 문구로 다시 만들었습니다.**
1. 로그인 화면 사진에 **실제 대리점의 로그인 아이디**가 찍혀 있었습니다(`src/api-admin.ts` 주석에 나오는 실제 학원 아이디).
   `/library/` 는 로그인 없이 누구나 받고 저장소도 공개라 실제 계정을 내보낼 수 없습니다 → `sample01` 로 찍었습니다.
2. 「얼마인가요? … **(2쪽 표)**」 인데 단가표는 4쪽에 있었습니다 → 「(끝쪽 표)」.
3. 자료실은 «한글 / English» 두 줄이 짝이라 영어판이 필요했고, 원본(HTML·캡처)이 없어 영어판을 같은 모양으로 만들 방법이 이것뿐이었습니다.
   (FAQ 의 화면 문구는 실제 화면 글자 「본사가 아직 **A.i 컨텐츠** 결제를 열지 않았습니다」에 맞췄습니다.)
⛔ 원본 PDF 는 같은 이유(실제 아이디)로 저장소에 넣지 않았습니다.
