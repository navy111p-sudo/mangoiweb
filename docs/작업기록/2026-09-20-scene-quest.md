# 장면 탐험대 / Scene Quest

## 요청과 범위
그림이나 동영상 속 영어 단어·구문을 직접 입력하면 다음 장면을 통과하는 게임을 학생 게임 허브에 추가한다.

- 새 게임: `public/student-game-scene-quest.html`, 전용 데이터/로직 JS 2개.
- 사용자 추가 요청에 따라 Higgsfield에서 실사 스타일 이미지 12장과 각 이미지 기반 6초 요청 영상 12편을 새로 제작했다. 기존 영작용 미디어는 수정하지 않는다. 실행 중 AI 호출은 없다.
- 신비/일상/자연 3개 세계와 전체 무작위 선택, 단어/구문/문장 난이도.
- 4개 장면의 열쇠를 모은 뒤 이전 장면을 한 단계 확장하는 최종 문제. 문장 단계는 같은 난이도 복습.
- 보너스 시간, 콤보, 단계별 힌트, 정답 학습, 오답 복습, 한영 UI, 결과 복사.
- 제한시간 종료는 보너스만 종료하며, 정답 공개 후 통과는 0점 연습으로 기록한다.
- 점수는 이번 탐험에만 적용되며 지갑 코인/DB에는 적립하지 않는다. 탐험 완료는 기존 허브 postMessage 규약으로 퀘스트에 전달한다. 복습은 재전송하지 않는다.
- 새 카드는 마지막에 추가해 기존 퀘스트 해금 순서를 보존한다. 카드별 이미지 경로가 있으면 사용하고 기존 게임은 원래 경로 그대로 둔다.
- 이 게임은 영어 쓰기용이다. 게임 카드/첫 화면에 명시하며 한국어·영어 안내 UI를 제공한다.

## 판단
- 자유 AI 첨삭 대신 미션별로 검토한 정답 변형을 인정한다. 대소문자·공백·문장부호와 일부 축약형을 정규화한다. 구문 단계에서는 올바른 완전한 문장도 인정한다.
- 아무 내용이나 핵심어를 포함하면 통과시키는 부분 일치와 오타 자동 통과는 사용하지 않는다. 반대 의미나 무관한 긴 문장의 오판을 피하기 위해서다. 정답 목록 밖의 타당한 표현도 있을 수 있으므로 이를 영어 자체가 틀렸다고 단정하지 않고 '이 미션의 목표 표현'을 힌트로 안내한다.
- 한 번에 한 장면만 보이고 영상은 명시적인 클릭 후 불러온다. 자동 재생·무한 반복·마이크·WebRTC·백엔드 변경은 없다.
- 탭/부모 iframe이 숨겨지면 영상, 발음, 보너스 타이머를 멈추며 사용자가 이어하기를 눌러 재개한다.

## 검증
- `node test-harness/scene_quest_harness.mjs`: 354개 assertion 통과. 실제 정답 판정과 이벤트 핸들러를 실행한다.
- 정답 변형, 오타/부정문/무관한 입력, 중복 제출 방지, 정답 공개 시 0점, 최종 구문 문제, 복습 보상 중복 방지, 타이머 일시정지/만료, 영상 재생 실패와 늦은 재생 콜백 정지 확인.
- 전용 JS 두 파일 `node --check` 통과.
- 전용 정적 자산 24개 존재 및 데이터 경로 대조. WebP 총 1,197,256 bytes, MP4 총 6,046,781 bytes. MP4는 편당 약 0.28–0.91MB.
- 12개 MP4 모두 ffprobe로 H.264/yuv420p, 1280×720, 5.875초, 오디오 없음 확인. faststart 적용. 6초 요청에 대한 모델 출력의 실제 길이는 5.875초다.
- 이미지 12장과 영상별 0.5/2.5/4.5초 추출 화면을 시각 검토해 목표 대상과 행동 확인. 도서관은 여자아이로 생성되어 남자아이 문장 정답을 제거했다.
- 제작 모델, 원본 URL, 작업 ID, 장면/행동 프롬프트, 실제 파일 정보: `docs/scene-quest-media.json`. Recraft v4.1 → Hailuo 2.3 이미지 기반 영상. 24개 작업 모두 성공.
- 초기 구현 커밋 f86700f의 전체 PR CI 통과. 실사 자산 추가 커밋은 별도 PR CI 결과로 확인한다.
- 전체 TypeScript 및 기존 회귀 하니스는 부분 체크아웃 환경에서 실행하지 않았으며 PR CI 결과로 확인한다.
- **실제 브라우저/모바일 시각 검증 미완료.** Cloud Browser가 로컬 HTTP 화면을 `ERR_BLOCKED_BY_CLIENT`로 차단했고 공유 파일 경로도 브라우저 정책상 허용되지 않았다. 우회하지 않았다. DOM adapter 테스트는 화면 검증이 아니다.

- 초기 PR CI에서 발견한 공통 한자 글꼴 연결 누락과 관리자 게임 구성표 등록 누락을 수정했다. 게이트/예외 목록은 변경하지 않았다.

## 배포 전 사람이 확인할 것
1. PC와 390px 세로 모바일에서 게임 시작 → 답 입력 → 다음 장면이 잘 보이고 가로 스크롤이 없는지.
2. 브라우저에서 영상 재생·다시 보기·그림 전환 확인. 단어/구문/문장 각 한 판.
3. 첫 오답 → 힌트 → 정답, 정답 공개 → 직접 입력(0점), 결과 → 오답 복습.
4. 영상 재생 중 일시정지/탭 숨김/게임 종료 시 재생이 멈추는지. 재개는 사용자 클릭으로만.
5. 허브 카드에서 열기, 뒤로가기, 기존 퀘스트 해금 및 완료 전달 확인. 영어 안내로 전환해 재확인.

브라우저 확인 전에는 운영 반영 완료로 보고하지 않는다.
