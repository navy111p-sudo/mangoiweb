# AI 친구 입력창의 버튼/자동 말하기 선택

사용자가 AI 말하기 화면과 같은 `🎤 버튼으로 / ✨ 자동으로` 전환을 AI 친구 입력창 바로 위에 요청했다.

기존 MangoiVoice 녹음/Whisper 전사와 sendMsg/SSE 낭독을 재사용했다. 자동 모드는 전체 답변 낭독 뒤 700ms 후에 듣기를 열며, 낭독 중/답변 대기 중에는 열지 않는다. 새 음성인식 엔진이나 상주 폴링은 추가하지 않았다. 무음 전사와 취소된 녹음 결과는 버리고, 무음 두 번/권한 오류/타이핑/화면 숨김/얼굴 대화 진입은 자동 듣기를 쉰다. 저장된 선택은 페이지 재진입 때 녹음 허가로 쓰지 않는다.

공용 녹음기와 다른 페이지의 자동 모드는 수정하지 않았다. 얼굴 대화 진입에서 인라인 자동 녹음만 정리해 두 모드의 마이크 충돌을 막았다.

검증: TypeScript 무출력 정상 종료. 실제 Chromium에 페이지를 열고 음성/TTS/API를 대역으로 제어한 19개 동작 검사 통과. JSON/SSE 답변 대기, 무음, 취소, 권한 거절, 수동 모드 유지, 얼굴 모드 전환, PC 1440px/휴대폰 390px 입력창 배치와 재진입을 확인했다. 실제 학생 마이크·실서비스 AI 음성 품질은 이 자동 검사 범위 밖이다.
