# AI 친구 아바타 응답 대기 줄이기

요청: 얼굴 확대 대화에서 대답과 다음 질문까지 기다리는 시간을 줄여 달라는 요청.

- 자동/얼굴 대화에서 말끝 무음 대기를 2500ms → 1500ms로 줄였다. 수동 버튼 입력의 2500ms와 AI 스피커 잔향 방지 700ms는 유지했다.
- 재생 중 말을 중단할 때 TTS.stop()은 onend를 부르지 않는다. 얼굴 대화의 pending 카운터가 남아 최대 25초 안전망을 기다리는 경로를 실제 Chromium에서 재현했다. 정지 시 카운터를 즉시 정리하고, 세대 번호로 옛 완료 콜백이 새 발화를 끝내지 못하게 했다.
- via=voice 요청에는 짧은 관련 응답 + 질문 최대 하나(보통 두 문장, 약 20단어) 지침을 추가했다. 답변 우선/레벨/교정 규칙과 기존 모델·JSON 토큰 예산은 유지했다. 강제 글자 자르기나 말속도 변경은 하지 않았다.

검증: 수정 전 실제 페이지 테스트에서 2.5초 안에 마이크가 열리지 않아 실패. 수정 후 중단→얼굴 모드 마이크 약 773ms, 늦은 콜백 격리, 자동1500ms/수동2500ms 전달 검증 통과. 수치는 제어된 음성/TTS 대역 테스트이며 실제 서비스 종단 지연 측정이 아니다. 네트워크·음성인식·AI·TTS 서버 지연은 별도로 남는다.
