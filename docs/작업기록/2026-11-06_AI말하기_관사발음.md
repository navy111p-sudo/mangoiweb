# AI 말하기: a home run 관사 발음 보정

- 요청: Emma가 `I hit a home run`의 관사 a를 "에이"로 읽는다는 제보. 수정 및 배포 요청.
- 변경: ai-friend.html의 공통 speakText 진입점에서 음성 합성용 문자열만 `a home run` → `uh home run`으로 보정한다. 스트리밍·다시 듣기 모두 같은 함수를 사용한다. 화면·대화 기록·교정 목표 문장은 바꾸지 않는다.
- 범위: 제보된 구절만 적용한다. 다른 관사 전체의 발음을 해결했다고 주장하지 않는다. 모든 a를 치환하는 방법은 알파벳·성적·이름과 실제 관사를 정확히 구별할 수 없어 제외했다.
- 근거: Deepgram 공식 문서 https://developers.deepgram.com/docs/text-to-speech-prompting 는 Aura의 발음 제어 API 대신 음성용 표기 보정을 안내한다. 기존 목소리를 유지하기 위해 엔진 교체는 하지 않았다.
- 캐시: 보정된 문자열 자체가 공용 TTS로 전달되므로 브라우저/R2의 기존 원문 키와 달라진다. 기존 캐시 삭제나 DB 쓰기는 하지 않는다. 기기 음성 폴백에도 같은 문자열이 전달된다.
- 검증: ai_friend_article_harness.mjs가 실제 speakText 함수를 실행해 제보 문장·반복·대문자·알파벳 예외·화면 원문·화자·속도·완료 콜백을 검사한다. 전체 검사 및 배포 결과는 PR/Actions에 남긴다.
- 한계: 첨부는 이미지로 실제 제보 음성을 듣지는 못했다. `uh` 표기는 음성 엔진의 발음 유도이며 최종 청감은 실제 기기에서 확인해야 한다.
