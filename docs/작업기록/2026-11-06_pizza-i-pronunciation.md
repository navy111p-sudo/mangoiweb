# 문법 피자 단독 I 발음 (2026-11-06)

- 제보: 재료에 표시된 I를 누르면 아이 대신 이상한 발음이 들림.
- 확인: 단독 I를 그대로 서버/앱/기기 음성에 전달. 서버 공통 처리는 I.로 끝맺기만 하므로 문맥 없는 단일 글자 합성에 의존함. 제보된 소리의 실제 녹음은 없어 정확한 음성 생성 결과는 확정하지 않음.
- 수정: 영어의 단독 I(끝맺음 포함)에만 동음어 eye(/aɪ/)를 합성 입력으로 사용. 문장 속 I, 화면 표시, 채점, 중국어는 원래대로. 미리받기도 같은 변환을 사용하여 기존 I 음성 캐시를 피하고 클릭 때 재사용.
- 서버 공통 규칙 변경은 다른 화면과 약어 발음에 영향을 주므로 피함. 한국어 아이를 영어 음성에 보내는 방식도 피함.
- 검증: pizza_i_pronunciation_harness에서 서버 요청, 미리받기/캐시 재사용, 브라우저 폴백, Android 경로를 실행하고 문장/다른 단어/중국어 보존 확인. 기존 pizza_audio_quality_harness 통과. 전체 검증·배포 결과는 PR에 기록. 실제 귀로 듣는 확인은 미수행.
