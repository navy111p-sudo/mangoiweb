## 1. 왜 했나

수정사항 프롬프트 블록 8번: **손익계산서를 월 단위로만 볼 수 있으니 「2026 1분기」 형태의
분기별 조회를 붙여 달라**(분기 = 3개월 합산, PDF/Excel 도 동일 동작).

작업을 배포한 뒤 사장님이 실화면을 확인하다 두 가지가 더 나왔다:

- 사이드바 「회계 › 4 손익·재무」를 누르면 **엉뚱한 칸**(국가별 강사료 환전 / 지점·가맹점 정산)이
  열렸다 — 손자 메뉴가 문자열이라 «카드 안 N번째 details» 로 점프했는데 그 순서가 실제와 달랐다.
- 손익/재무제표 카드가 회계관리 **16칸 중 13번째**라 스크롤로는 사실상 못 찾는다
  → 「메뉴에서 안 보인다」는 제보. 사장님 지시로 **첫 칸**으로 올렸다.

## 2. 무엇을 바꿨나

### 서버 — `cloudflare-deploy/src/accounting-reports.ts` (#232)

- `GET /api/admin/reports/statement` 의 `period` 가 `YYYY-MM` 과 **`YYYY-Qn`** 을 둘 다 받는다.
  해석은 `statementPeriod()`, 합산은 `statementBasis()` — 위치는 `statementReport()` 바로 위.
- **분기 = `monthPL()`/`monthCash()` 를 3번 돌려 더한 것.** 분기 전용 SQL 은 없다.
- ⚠️ **잔액성 항목(통장 월말 잔액·미지급 강사급여)은 더하지 않는다** — 분기 **마지막 달** 기준
  (`.bind(lastMonth)`). 재무상태표 라벨도 「2026 N분기 말 기준」.
- 표기는 「2026 1분기 (1~3월 합산)」. 손익계산서 매출 첫 줄에 «3개월치 합산» 안내를 넣었다.
- bs/cf/tb 도 분기를 받는다(분기를 고른 채 보고서 유형만 바꿔도 안 깨지게).

### 화면 — `cloudflare-deploy/public/admin.html` + `public/js/adm-core.js` (#232·#269·#280)

- 「월별/분기별」 토글(`#acc-fs-mode`)과 분기 드롭다운(`#acc-fs-quarter`, JS 가 채움 — 지난 3년,
  아직 안 온 분기는 제외, 보던 달이 속한 분기가 기본 선택). JS 는 `adm-core.js` 의
  `accFsModeChange`/`_fsFillQuarters` 부근.
- **생성·PDF·Excel 이 원래 `_statementUrl()` 하나만 쓰므로 거기만 고쳐 셋이 같이 분기를 따라간다.**
- 도구줄을 **두 줄로 고정**(#269): 위 = 조회 조건, 아래 = 생성·PDF·Excel.
  6칸이 되면서 1500px 즈음에서 Excel 만 혼자 줄바꿈되던 것을 없앴다.
- 카드 블록을 통째로 잘라 회계관리 **첫 칸 앞으로**(#280). 내용·id(`acc-financials`)·JS 무변경이라
  사이드바 점프·`#acc-financials` 해시 주소·분기 조회가 전부 그대로 동작.

### 사이드바 — `public/js/adm-r25.js` (#275)

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **분기용 SQL 을 따로 쓰기** → 버림. 규칙이 두 벌이 되는 순간 월 화면과 분기 화면의 숫자가
  갈라진다(케이씨피M·시드 제외 같은 규칙이 이 파일에서 벌써 여러 번 갈라졌다 붙은 역사).
  월별 계산을 3번 돌려 더하면 **구조적으로** 어긋날 수 없다. D1 왕복이 3배지만 관리자용
  단발 조회라 감수.
- **부가세를 「분기 매출 합 ÷ 11」 로 한 번에** → 버림. 달마다 `÷11` 후 반올림한 것의 합과
  1~2원 어긋난다. 월 화면 합계와 1원도 다르지 않게 **달마다 계산해 더한다**.
- **잔액(통장·미지급급여)도 합산** → 당연히 버림. 잔액은 시점값이라 더하면 3배가 된다.
  분기 **마지막 달** 기준. `.bind(period)` 를 그대로 두면 `'2026-Q1'` 이 문자열 비교에
  들어가 조용히 엉뚱한 값이 나온다 — 하니스 ②가 이걸 감시한다.
- **기존 `quarterlyReport`(분기 보고서 API) 재사용** → 버림. 그건 요약 보고서라 손익계산서의
  섹션 구조(I~VII·현금흐름 참고)를 못 만든다. 대신 그 파일의 `quarterRange()` 는 재사용.
- **도구줄 줄바꿈을 `flex-wrap` 에 맡기기** → 버림. 창 폭마다 줄바꿈 자리가 달라져
  Excel 버튼만 혼자 내려가는 폭(≈1500px)이 생긴다. 「볼지/할지」 두 줄로 고정.
- **사이드바 수리를 «순서 index 맞추기» 로** → 버림. 카드에 칸을 하나만 끼워 넣어도 다시
  어긋나는 구조 자체가 병인이다. 앵커(id) 방식으로 바꿨고, #273 이 이를 전 카드로 확장했다.

  cancelled 로 정리되고 **마지막 run 하나가 최신 main 을 통째로 배포**한다. 내 커밋이 나갔는지는
  run 의 결론이 아니라 `git merge-base --is-ancestor <내 커밋> <배포된 head>` 로 확인.
