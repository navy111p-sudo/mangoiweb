## 1. 왜 했나

사장님 요청: **「이거 최근에 수정한 것들이 많으니 반영해서 영어, 한국어 판 수정해줘.
10세 수준으로 내용을 만들어줘. 관리자페이지 화면들 캡쳐도 잘 크게 해주고」**

안내서(자료실 · 관리자 화면의 슬라이드 뷰어)의 그림이 **2026-08-13 판**이었다.
그 뒤 일주일 사이에 매일 쓰는 조작이 바뀌었는데 안내서에는 하나도 없었다.

- 사이드바가 **「메뉴 ▸ 자식 ▸ 손자」 3단**으로 바뀜 (PR #317·#318·#321·#328)
- **「메뉴 지도」** 가 사이드바 맨 위에 생김
- 묶음 이름이 **「본사·지사·대리점」** 으로 바뀜 (PR #324)
- 옛 안내서의 ② 화면 설명 그림은 **9그룹짜리 옛 사이드바**였다 (지금은 IA6 8그룹 43항목)

캡처도 슬라이드 오른쪽 아래에 작게 들어가 **글자가 안 읽혔다.**

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

### ① 실서비스(mangoi.ai) 화면을 찍는다 → **버림. 프록시가 막는다**

CLAUDE.md 4-1-1 에 적힌 그대로, 이 컨테이너에서는 배포된 화면을 못 본다.
대신 **배포될 `cloudflare-deploy/public/` 을 그대로 로컬 서버로 띄우고**
컨테이너에 이미 있는 크로미움(`/opt/pw-browsers/chromium-1194/…`)으로 렌더했다.
(CLAUDE.md 2장 마지막 함정 항목의 방법 — 2026-08-18 에 버그 2건을 찾았던 그것)

- 로그인은 `localStorage` 의 `mangoi_admin_session` **과** `admin_session` 둘 다 심어야 한다.
  뒤쪽은 오른쪽 위 사용자 모달(`adm-r21` ph115)이 보는 키다.
- 영어판은 `mangoi_lang`·`mangoi_lang_by='user'` 만으로는 안 바뀐다.
  **`mangoi_lang_uid` 가 지금 세션 uid 와 같아야** `adm-lang-boot.js` 가 「사용자가 직접 고름」으로 인정한다.

### ② 표에 예시 학생·예시 금액을 채워 넣는다 → **버림**

빈 표가 보기엔 허전하지만, **안내서에 실제가 아닌 숫자가 들어가면 그게 사실로 읽힌다.**
「불러오기」를 누르기 전 화면 그대로 찍고, 소개 장(2쪽)에 «표를 열면 불러오기를 눌러야
자료가 채워진다» 고 적었다. 실제로 그 화면들은 버튼·검색칸·컬럼 이름이 다 보여서
«어디를 눌러야 하나» 를 가르치는 데는 오히려 낫다.

### ③ 카카오 알림톡 카드를 ⑫ 알림 장의 그림으로 쓴다 → **버림**

로컬 렌더에는 API 키가 없어 **«미연동 / ×API키 / ×시크릿»** 으로 나온다.
운영 화면과 다르고 «고장 난 것처럼» 보여 오해를 부른다 → 「공지 스튜디오」(포스터→팝업)로 교체.
같은 이유로 Web Push 카드(VAPID 키 설명)도 뺐다 — 10세 수준 안내서에 넣을 내용이 아니다.

### ④ 「오늘」 장의 그림으로 «실시간 수업 현황» 을 쓴다 → **스텁을 고쳐서 살림**

처음엔 표에 `로딩 실패: rooms.slice is not a function` 이 찍혔다.
스텁이 `{ok:true, items:[]}` 만 돌려줘서 `rooms` 가 `undefined` 였던 것.
→ `_shot.mjs` 의 스텁이 흔한 목록 키(`rooms`·`students`·`teachers`·…)를 **빈 배열**로 준다.
⚠️ **스텁 때문에 나는 TypeError 를 진짜 버그로 착각하지 말 것** (CLAUDE.md 2장 경고 그대로).

### ⑤ `page.pdf()` 로 PDF 를 뽑는다 → **버림. 두 배로 커진다**

크로미움 인쇄는 슬라이드 PNG 를 그대로 심어 **7.9MB** 가 됐다.
같은 그림을 JPEG(q=88)로 묶으니 **5.0MB**, 눈으로는 차이가 없다 → `deck/topdf.py`(Pillow).

### ⑥ 세로로 긴 사이드바 캡처를 가로 슬롯에 `contain` 으로 넣는다 → **버림**

좌우가 텅 비고 그림이 작아진다. 그 장만 **오른쪽 칸을 470px 로 좁힌 전용 배치**(`.cols.tall`)를
쓰고, 캡처할 때 **사이드바를 「강사」 묶음이 맨 위에 오도록 스크롤**해서 손자 두 줄까지 한 화면에 담았다.

### ⑦ 제목 이모지 🧑‍🏫 → **🎓 로 교체**

ZWJ 조합이라 Win10 에서 두 글자로 쪼개진다. 슬라이드 그림은 여기서 렌더되니 상관없지만,
`adm-s18.js` 의 `titles` 는 **사장님 브라우저에서 그려진다.** (CLAUDE.md 1-4 「Unicode 13 이상 금지」의 형제)

### ⑧ 「케이씨피M」·운영자금 이야기는 **한 줄도 넣지 않았다**

CLAUDE.md 1-3 — «제외했습니다» 라고 적어 주는 것도 「아직 남아 있다」로 읽힌다.
회계 장(⑬)은 손익계산서 뽑는 법만 적었다.
