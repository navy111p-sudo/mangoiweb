## 1. 왜 했나

사장님이 관리자 화면 「품질·이력 ▸ 3 보고서 양식 관리」를 보시고 물으셨습니다 —
**「이것과 새로 만든 결재 시스템은 같은 것이냐, 다른 것이냐. 다르면 하나로 해야 하지 않나」.**

조사해 보니 **같은 일을 하는 두 벌**이었고, 한쪽은 껍데기였습니다.

| | 「보고서 양식 관리」(ph107, 2026-05-25) | 전자결재 `/work` (2026-08-05·08-16) |
|---|---|---|
| 데이터 | 표 두 줄이 **HTML 에 손으로 박은 고정 행** | D1 `approval_requests` |
| 편집·보관·신규등록 | **「준비 중입니다」 알림창만** — 저장할 서버가 없음 | — |
| 분류 | 휴가 계획서 · 기안/지출서 **2종** | **7종** (`approval-policy.ts` `TYPES`) — 휴가·지출 둘 다 이미 포함 |
| 기능 | 종이 양식 미리보기 | 금액별 자동 결재선 · 마감(SLA) · 대결 · 첨부/OCR · 오프라인 재전송 · 멱등성 |

즉 「양식 관리」의 두 양식은 전자결재에 **이미 둘 다 있었습니다.**

곁가지로 확인한 사실 — 그 카드는 2026-08-17 에 이미 한 번 정리된 적이 있습니다.
원래는 서버에 아무것도 안 보내 놓고 **「결재 상신 완료」라고 거짓말**을 하던 코드였고
(사장님·직원은 결재가 올라간 줄 알고 창을 닫음 = 결재가 영영 사라짐),
그때 「있는 척」만 걷어내고 **카드 자체는 남겨 둔 상태**였습니다. 그 잔재가 이번 질문의 원인입니다.

## 2. 검토했다가 버린 방법

| 버린 방법 | 왜 버렸나 |
|---|---|
| **양식 CRUD 백엔드를 새로 만들어 카드를 살린다** | 결재 분류 7종과 정면으로 겹칩니다. 휴가 신청 창구가 두 개가 되고, 그때부터 「어디로 올려야 하나요」가 시작됩니다. 종이 양식처럼 칸을 더 받고 싶으면 **`TYPES` 에 입력칸을 늘리는 쪽**이 정본입니다(코드에 주석으로 남김) |
| **카드를 통째로 삭제** | 양식 미리보기 자체는 쓸모가 있습니다(어떤 칸을 적어야 하는지 미리 봄). 사이드바 항목까지 없애는 것은 되돌리기 어려운 변경이라 남겼습니다 |
| **`/work` 에 양식 목록 화면을 옮겨 붙인다** | `/work` 는 **필리핀 회선을 위한 초경량 화면**입니다. 관리자용 표를 옮기면 만든 이유가 사라집니다 (admin.html 결재 배지 주석에 「결재 목록·승인 버튼을 여기에 만들지 말 것」이 이미 못 박혀 있음) |

## 3. 무엇을 했나

1. **`/work` 가 `?type=` 을 받습니다** — `/work?type=leave` 로 들어오면 휴가 결재 폼이 바로 열립니다.
   - 예전에는 `/work` 로 보내기만 해서 도착해서 분류를 **또** 골라야 했습니다.
   - 쓰다 만 초안이 있으면 **그쪽이 우선**입니다(`restoreDraft` 가 이미 `PICK` 을 잡았으면 손대지 않음). 덮어쓰면 쓰던 글이 사라집니다.
   - 올릴 수 없는 분류(강사의 지출 등)는 서버가 `types` 에서 아예 빼고 주므로, 조용히 넘기지 않고 **한 줄 안내**합니다 — 「눌렀는데 아무 일도 안 일어난다」 방지.
2. 양식 표의 액션을 **「✍️ 이 양식으로 결재 올리기」** 로 (휴가 → `type=leave`, 기안·지출 → `type=expense`)
3. 안내문 정정: 「템플릿을 관리합니다」 → 「**실제 결재는 전자결재에서 올립니다**」
4. **죽은 버튼 3개 제거**(편집·보관·➕ 신규 양식 등록) + **사이드바 손자 이름표(`data-gc`)도 함께** 정리.
   자리에는 「🧾 전자결재 화면 열기」 바로가기를 둡니다.
   - ⚠️ 손자 이름표를 안 지우면 사이드바에 **「갈 곳 없는 손자」** 가 남습니다(`admin_grandchild_menu_harness` 가 FAIL).
5. 미리보기 모달의 「📤 결재 상신」도 같은 딥링크로. 양식번호 → 분류 짝은 `adm-r17.js` 의 `FORM_TO_TYPE` **한 곳**입니다.
   - ⚠️ `rfCloseModal()` 이 `currentFormId` 를 지우므로 **닫기 전에 번호를 챙겨** 두고 이동합니다.
