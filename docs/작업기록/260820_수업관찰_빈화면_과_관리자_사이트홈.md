## 1. 왜 했나

필리핀 매니저가 스크린샷과 함께 두 가지를 적어 보냈습니다.

1. **「전체 메뉴 › 수업 관찰(Class Observer)」에 수업이 하나도 안 뜬다.**
   같은 시각 관리자 대시보드에는 수업 두 건(Ma'am Mai 가 만든 것 1건, 본인이 만든 것 1건)이
   분명히 보이고 있었고, 실제로 수업도 진행 중이었습니다(수업 화면 스크린샷 포함).
   그런데 전체 메뉴에서 「수업 관찰」을 누르면 **검은 화면에 「연결 중…」만** 떠 있었습니다.
2. **관리자 대시보드에 「뒤로」도 「홈」도 없다.** 들어가면 나올 길이 안 보인다.

둘 다 재현되는 코드 문제였습니다. 원인은 서로 다릅니다.

---

## 2. 무엇을 바꿨나

### ① `cloudflare-deploy/public/admin/ghost-view.html` — 방 번호가 없으면 «수업 고르기»

- 이 화면은 **방 하나를 보는 뷰어**입니다. `?room_id=` 를 읽습니다(그 파일의 `const roomId`).
- 전체 메뉴 타일(`public/js/idx-allmenu.js` 의 `{name:'수업 관찰', url:'/admin/ghost-view.html'}`)은
  **파라미터 없이** 이 화면을 엽니다. 그래서 `roomId = ''` 로 열리고,
  채팅·참가자·알림 조회가 **빈 방 번호로** 나가 전부 비고, 영상 칸은 「연결 중…」에서 멈춥니다.
  → 쓰는 사람 눈에는 «수업이 하나도 없다» 입니다. **에러는 안 납니다.**
- 고침: `roomId` 가 없으면 뷰어(`#ghd-viewer`)를 감추고 **`#ghd-picker`(수업 고르기)** 를 그립니다.
  - 🔴 지금 화상방 — `/api/active-rooms` (+ 이름은 `/api/admin/live-classes`, 실패해도 표는 그림)
  - 📅 예약 기준 지금 수업 — `/api/admin/classes-now` (강사 계정은 403 → **구역째 감춤**)
  - 줄마다 문 두 개: **[🎥 라이브 화면]** = `/?observe=<방번호>` (진짜 영상), **[👁 채팅·참가자]** = 이 화면
  - 어느 쪽이든 **`/api/admin/ghost/start` 로 참관 기록을 먼저** 남깁니다(실패해도 이동은 진행 —
    `js/adm-core.js` 의 `observeRoom()` 이 같은 판단을 했습니다).
- 덤 ②: 뷰어의 「⚠ 실제 영상은 GM-4 단계에서」 안내 아래에 **[🎥 라이브 화면 열기]** 버튼(`ghdOpenLive`)을 뒀습니다.
  안내만 있고 문이 없어서 「연결 중…」이 장애로 읽혔습니다.
- 덤 ③: `.header` 왼쪽 여백 62px(모바일 56px) — `js/back-nav.js` 가 띄우는 동그란 ← (fixed)가
  제목 「👀 수업 관찰」 위에 그대로 겹쳐 앉아 있었습니다(1280×900 실측).

### ② `cloudflare-deploy/public/manager.html` (1214행 부근) — `?room=` → `?room_id=`

매니저 화면의 「Observe(관찰)」 링크가 **`?room=`** 로 넘기고 있었습니다. 뷰어는 `room_id` 만 읽습니다.
즉 매니저가 그 버튼을 눌러도 ①과 똑같은 빈 화면이었습니다.
(`js/adm-s1.js`·`js/adm-s5.js` 는 `room_id` 로 제대로 넘깁니다 — **세 곳 중 한 곳만** 어긋나 있었습니다.)

### ③ `cloudflare-deploy/public/admin.html` — 계정 도크에 「🏠 사이트 홈」 한 줄

관리자 화면에 나가는 문이 **로그아웃뿐**이었던 이유가 세 겹입니다.

- `js/back-nav.js` 는 `/admin.html` 을 «홈이라 갈 곳이 없다» 며 **일부러 제외**합니다(11행).
- 옛 상단바(`.top-header`)는 2026-08-15 에 없어졌고, 컨트롤은 도크(`#ph162-dock`)로 왔는데
  **홈 링크는 따라오지 않았습니다**(도크에는 🩺진단·🌐EN·👤계정만).
- 2026-08-19 에 생긴 경로 줄(`#mi-crumb`)의 「🏠 홈」은 **대시보드 첫 화면**이고,
  그 줄은 첫 화면에서 `mi-crumb-off` 로 **감춰집니다**(`js/adm-crumb.js`).

→ 도크 **맨 아래 한 줄 전체**로 `<a id="ph162-sitehome" href="/">🏠 사이트 홈</a>` 를 넣었습니다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

| 버린 방법 | 이유 |
|---|---|
| **전체 메뉴 타일의 목적지를 `/admin.html#card-admin-ghost` 로 바꾸기** | 가장 짧지만 `idx-allmenu.js` 는 홈(학생 29,000명) 계열이고, admin.html 은 해시로 카드를 여는 경로가 따로 없습니다. 무엇보다 **빈 뷰어는 그대로 남아** 매니저 화면·북마크·옛 링크로 들어오면 똑같이 재현됩니다. 도착지 한 곳을 고치는 쪽이 새는 구멍이 없습니다 |
| **ghost-view 를 지우고 «진짜 영상» 화면(`/?observe=`)으로 리다이렉트** | 이 화면은 채팅·참가자·알림·귓속말·평가·녹화까지 붙어 있는 별개 도구입니다. 리다이렉트하면 그게 통째로 사라집니다. 그리고 방 번호가 없으면 리다이렉트할 대상 자체가 없습니다 |
| **영상 칸을 `/?observe=` iframe 으로 채우기** | 화상수업(`src/video-call-room.ts`)은 공동 금지구역이고, 참관자는 mesh 라 **동시 2명 제한**이 있습니다. 목록 화면이 열릴 때마다 방에 붙는 구조는 사고 반경이 큽니다 → 「새 창으로 여는 버튼」으로 뒀습니다 |
| **`/api/active-rooms` 를 «예약 수업까지 포함» 하도록 서버에서 합치기** | 두 목록은 뜻이 다릅니다(«방에 붙어 있는 사람» vs «예약»). 합치면 「접속 확인/기록 없음」 구분이 사라집니다. 화면에서 **나란히** 보여 주는 쪽이 사실에 가깝습니다(관리자 「🔴 실시간 수업 현황」이 이미 그렇게 합니다) |
| **관리자 도크에 홈을 넣지 않고 `back-nav.js` 의 제외를 푸는 것** | admin.html 은 한 페이지에서 카드만 바꾸는 구조라 브라우저 히스토리와 어긋납니다. 그래서 `adm-crumb.js` 를 따로 만든 것입니다 |
| **도크 CSS(`admin-inline-c.css`)를 고쳐 4칸으로 만들기** | 그 파일은 진단·EN·🔊음성 토글의 2칸/3칸 배치를 함께 정합니다(`#ph162-dock.has-voice`). 인라인 `grid-column:1/-1` 한 줄이면 CSS 를 안 건드리고 같은 결과입니다 |

- `cd cloudflare-deploy && node node_modules/typescript/bin/tsc --noEmit` → **종료코드 0**
  (⚠️ `npm ci` 가 안 돼 있어 먼저 `npm ci --legacy-peer-deps` 로 설치했습니다 — Node 22 환경)
- 리포 루트 `node test-harness/run.mjs --fast` → **PASS 188 · SKIP 20 · FAIL 0**
- `bash test-harness/ci-gates.sh` → **배포 게이트 4종 전부 통과**
- **헤드리스 크로미움으로 실제 렌더**(로컬 정적 서버 + API 스텁, CLAUDE.md 2장의 그 방법):
  - 파라미터 없이 열기 → `#ghd-picker` display:block, `#ghd-viewer` display:none, 제목 「수업 선택」,
    수업 목록 2건 + 예약 2건이 그려짐. 1280px·500px 둘 다 가로 넘침 없음
  - `?room_id=meet-123&obs_id=7` → 고르기 숨김, 뷰어·액션 버튼 종전 그대로, 새 [🎥] 버튼 존재
  - admin.html 도크 실측: 새 링크 `display:flex`·`visibility:visible`·`grid-column 1/-1`,
    도크 맨 아래(자식 순서 diag→lang→voice→계정→**sitehome**), 문서 폭 1427 ≤ 창 1440
- ⚠️ **배포된 실서비스 화면은 확인하지 못했습니다.** 작업 컨테이너 프록시가 `mangoi.ai` 를 막습니다.
  화면이 바뀌는 작업이므로 **병합·배포 뒤 사람이 한 번 봐야 끝난 것**입니다(CLAUDE.md 4-1-1).

## 5. 남은 것 / 주의할 것

- **`ghost-view.html` 의 영상 칸은 여전히 «메타데이터·채팅·참가자» 전용**입니다(파일에 「GM-4 단계」로 적혀 있음).
  진짜 영상은 `/?observe=` 뿐이라, 이번에 그 문을 붙였을 뿐 화면이 완성된 것은 아닙니다.
- 「📅 예약 기준 지금 수업」이 **전부 «접속 기록 없음»** 인 것은 버그가 아니라
  카페24 예약 수업이 망고아이 화상방을 안 거친다는 사실입니다(CLAUDE.md 2장).
- 전체 메뉴 타일(`js/idx-allmenu.js`)은 **일부러 안 건드렸습니다.** 홈 계열 파일이고,
  도착지에서 이미 닫았기 때문입니다. 나중에 타일을 옮기더라도 이 화면은 그대로 동작합니다.
- 이번에 밟은 하니스 함정: **`admin_lazyload_harness` ②-3(한자 폰트 983KB)은 CSS 주석을 안 벗깁니다.**
  `<script>` 와 HTML 주석만 지우므로, `<style>` 안 주석에 홑낫표(U+300C·U+300D)를 쓰면 FAIL 납니다.
  (CLAUDE.md 2장에 한 줄 추가했습니다.)
