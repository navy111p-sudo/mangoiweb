# 2026-08-22 — 게임 미리보기에 «진짜 플레이 화면» 넣기 (자동 캡처)

> 앞선 작업([260822_사이드바_배경투명_게임잠금_미리보기.md](260822_사이드바_배경투명_게임잠금_미리보기.md), PR #415)에서
> 잠긴 게임의 «미리보기 창»을 만들었지만 **보여 줄 사진이 없어** 카드 홍보 사진 한 장으로
> 그리고 있었습니다. 사장님 지시로 그 자리를 실제 플레이 화면으로 채웠습니다.

---

## 왜 했나

사장님 지시문의 미리보기 요구는 「**실제 게임 플레이 화면 캡처** or 짧은 클립」이었습니다.
그런데 저장소에는 게임당 **카드 홍보 사진 한 장**(`/img/games/<mode>.webp`)뿐이고,
플레이 클립도, 연속 스크린샷도 한 장도 없었습니다.

카드 사진은 «이 게임이 무슨 분위기인가»는 알려 주지만 **«무엇을 하는 게임인가»는 못 알려 줍니다.**
피자 사진만 보고는 「문장 어순대로 재료를 올린다」는 걸 알 수 없습니다.
미리보기의 목적이 기대감을 만드는 것인데, 그 목적을 절반만 달성하고 있었습니다.

## 어떻게 했나 — 손으로 찍지 않고 스크립트로 굽는다

**게임이 21개입니다.** 그리고 게임 화면이 바뀌면 사진도 다시 찍어야 하는데,
사람이 21판을 다시 도는 것은 한 번은 몰라도 반복할 수 없습니다.

`test-harness/manual/game-preview-capture.mjs` (신규)

1. `cloudflare-deploy/public/` 을 로컬 http 서버로 띄운다
   (⚠️ `file://` 로 열면 `<script src="/js/…">` 가 전부 404 — CLAUDE.md 2장)
2. 게임을 헤드리스 Chromium 으로 연다
3. **시작 화면을 눌러 넘긴다** — 게임마다 다르므로 `HINTS` 로 «이 글자를 먼저 눌러라»를 준다
4. 플레이 화면을 **2장** 찍는다 (시작 직후 + 3.5초 뒤 → 슬라이드에 «움직임»이 생긴다)
5. **720×450 WebP** 로 구워 `img/games/preview/<mode>-1.webp`, `-2.webp` 로 저장

한 번 실행: `PW_DIR=/tmp/pw node test-harness/manual/game-preview-capture.mjs`

### 게임이 «시작 화면»에서 안 넘어가는 문제

로그인도 서버 데이터도 없으니 대부분의 게임이 시작 화면에서 멈춥니다. 해결한 것:

| 막힌 것 | 푼 방법 |
|---|---|
| 단어·문장 데이터가 없다 | `/api/games/*` 를 **가짜 단어 16개 · 문장 8개**로 스텁. ⚠️ 운영 DB 는 안 봅니다 |
| 헤드리스에 음성합성·마이크가 없어 «말하기» 게임이 기다리다 멈춘다 | `addInitScript` 로 가짜 `speechSynthesis`·`SpeechRecognition` 을 심음 |
| 시작 버튼이 안내 모달 **아래쪽**에 있어 «화면 안» 판정에 걸려 안 눌렸다 | 보이기 판정에서 `top`/`bottom` 을 빼고 `offsetParent` 만 봄 + `scrollIntoView` |
| 「보호자 확인」 체크박스를 켜야 «계속»이 살아난다 (워드 파이터) | 누르기 전에 보이는 체크박스를 전부 켬 |
| 선택지가 `<button>` 이 아니라 `<div>` 다 (아바타 캐릭터 고르기) | 후보 선택자를 `li·label·[class*=card]` 등으로 넓힘 |
| WebP 로 굽고 싶은데 ImageMagick 이 없다 | **브라우저 canvas** 로 변환 (`toDataURL('image/webp', .72)`) |

## 검토했다가 버린 방법

- **미리보기에서 실제 게임을 30초 돌려 주기** — 지시문이 「실제 플레이 **대신**」이라고 못 박았고,
  그러면 잠금 자체가 무의미해집니다. 하니스가 「미리보기가 잠긴 그 게임을 바로 실행하지 않는다」로
  못 박아 두었습니다.
- **카드 사진을 확대해서 슬라이드로 쓰기** — 같은 그림 한 장이라 슬라이드가 될 수 없고,
  「무엇을 하는 게임인가」도 여전히 안 보입니다.
- **찍힌 것을 전부 넣기** — `tank` 의 초록 배경처럼 **실제와 다른 인상**을 주는 사진이 섞입니다.
  미리보기는 학생에게 「이런 게임이야」라고 약속하는 화면이라, 틀린 약속을 하면 안 됩니다.
- **캡처를 CI 게이트에 넣기** — 게이트가 브라우저를 요구하게 됩니다(`manual/` 규약이 그래서 있습니다).
  게임 화면을 크게 바꿨을 때 **사람이 부릅니다.**
