# 「관리자 페이지 쉬운 사용법」 21장 — 화면 새로 찍고, 글을 10세 수준으로 다시 씀

## 1. 왜 했나

사장님이 휴대폰으로 그 안내(관리자 ▸ 📘 쉬운 사용법, 21장)를 열어 스크린샷과 함께
「**이거 새로 캡쳐 넣고 글 수정해줘. 10세 수준으로 해서 만들어줘**」라고 지시하셨습니다.

열어 보니 두 가지가 실제로 틀려 있었습니다.

1. **화면 그림이 옛것**이었습니다. 2장의 사이드바 설명이 「9개 묶음」인데 지금 화면은
   **7묶음 44항목**(`adm-ia6.js`)입니다. 그림 속 사이드바도 지금과 다른 세대였습니다.
2. **주소가 틀렸습니다.** 4장·18장이 `admin.mangoi.co.kr` 을 안내하는데
   **그런 도메인은 이 저장소 어디에도 없습니다.** 정본은 `mangoi.ai`(→ `/admin`)입니다
   (`src/site-url.ts`, CLAUDE.md 0장). 사람에게 엉뚱한 주소를 안내해서 「안 보여요」 제보가
   생긴 전례가 이미 있습니다(2026-08-17).

덤으로 발견한 것:

- **2장이 겹쳐서 깨져 있었습니다** — 막대그래프가 카드 위로 올라타 글자를 덮고 있었습니다.
- **17장(「한눈에 보는 데이터」)의 숫자는 근거가 없는 값**이었습니다. 막대(학생·학부모 9,
  평가서 7 …)와 원그래프가 무엇을 센 숫자인지 어디에도 없습니다. 안내문에 **지어낸 숫자**를
  두는 것이 「자주 쓰는 메뉴 순위」로 읽히므로 그대로 두지 않았습니다.
- **18장(FAQ)이 넘쳐서 마지막 문답이 잘려** 있었습니다.

## 2. 무엇을 했나

### 2-1. 글 — 21장 전부 다시 씀 (10세 수준)

- 한 문장을 짧게. 어려운 말(항목·조회·열람·발송·등록)을 **것·보기·보내기·넣기**로.
- 순서가 있는 일은 **반드시 1·2·3**. 화면에서 누를 순서 그대로.
- 장마다 **「이렇게 하세요」 → 「이것만 기억하세요」 → 조심할 것 / 쉬운 방법** 한 틀로 통일.
- 17장을 **「막혔을 때 이렇게 하세요」**(검색칸 → A.i 상담사 → 카카오 채널 3단계 +
  「누르기 전에 물어볼 것」)로 갈았습니다. 지어낸 숫자 대신 실제로 쓸 수 있는 순서입니다.
- 16장은 **「메뉴 한눈에 보기」** — 지금의 7묶음을 `adm-ia6.js` 의 `GROUPS` 에서 그대로 옮겼습니다.

### 2-2. 화면 그림 — 12장 새로 찍음

로컬 서버(`public/`) + 컨테이너 크로미움으로 **배포되는 그 파일들을 그대로** 렌더해서 찍었습니다.
로그인 · 대시보드 · 메뉴검색(「공지」 친 상태) · 평가서 · 공지 · 학생 명부 ·
학부모 소통 · 강사 명부 · 결제 · 자료실 · 사이트 홈 · 계정 창(로그아웃).

### 2-3. 다시 만들 수 있게 소스를 저장소에 둠

`docs/관리자안내_소스/` — `slides.mjs`(글 정본) · `capture.mjs`(화면 찍기) · `build.mjs`(굽기).
**지금까지 이 21장은 소스가 저장소에 없었습니다.** 그래서 「글 한 줄 고치기」가
「21장을 통째로 다시 만들기」였고, 그 결과 틀린 주소가 오래 남았습니다.

`build.mjs` 는 마지막에 **`adm-s18.js` 의 한국어 제목이 `slides.mjs` 와 같은지 대조**합니다 —
한쪽만 고치면 그림은 맞는데 쪽 제목만 옛것으로 남고 **에러가 안 나기** 때문입니다.

## 3. 검토했다가 버린 방법

| 버린 것 | 왜 |
|---|---|
| **글만 고치고 그림은 그대로 두기** | 지시가 「새로 캡쳐」였고, 실제로 사이드바 세대가 달라 **그림이 글과 어긋나** 있었습니다 |
| **원본 PPT/디자인 도구를 찾아서 고치기** | 저장소에 없습니다. 21장 jpg/webp/pdf 만 있고 **어떻게 만들었는지 아무 데도 안 적혀 있습니다.** 그래서 소스를 새로 만드는 쪽을 골랐습니다 |
| **캡처 원본(PNG 12장)도 커밋** | 2.4MB 인데다, 넣어 두면 **다음 사람이 «옛 화면»을 다시 쓰게** 됩니다. `capture.mjs` 로 언제든 다시 찍는 쪽이 항상 최신입니다(`.gitignore`) |
| **17장 숫자를 «맞는 값»으로 채우기** | 그 숫자를 셀 근거가 없습니다. 메뉴 클릭 로그가 없어서 「자주 쓰는 메뉴」를 셀 수 없습니다. 없는 것을 그럴듯하게 채우는 대신 **장을 갈았습니다** |
| **`test.mangoi.co.kr` 도 함께 안내** | 사람에게 안내하는 주소는 `mangoi.ai` 하나로 통일돼 있습니다(CLAUDE.md 2장). 그 도메인은 앱·스모크·워치독이 쓰는 것이지 안내용이 아닙니다 |
| **영어판(24장)도 같이** | 지시 범위 밖이고, 한국어 21장과 장 구성이 다릅니다(24장). 손대면 두 벌이 어긋납니다 → **그대로 두고** README 에 옮기는 법만 적어 뒀습니다 |
| **이모지로 제목 꾸미기(옛 제목의 🔐🖥🔎…)** | 새 그림은 번호·화살표를 CSS 로 그립니다. 제목에만 이모지를 남기면 화면과 안 맞고, Win10 두부 위험(CLAUDE.md 1-4)도 있습니다 |

## 4. 밟은 함정 (다음 사람을 위해)

- **`.toc div` 가 «칸» 자체에도 걸려** `align-items:center` 가 세로 칸의 가로 정렬이 되면서
  차례 줄이 계단처럼 밀렸습니다. 줄 규칙은 `.toc .col > div` 로 좁혀야 했습니다.
- **`object-fit:cover` 로 두면 정작 보여 줄 곳이 잘립니다.** 계정 창 그림에서 맨 아래
  「로그아웃」 버튼이 잘렸습니다(그 장의 **요점이 그 버튼**입니다). `contain` + 상자 높이 고정으로 고쳤고,
  계정 창은 아예 **그 창 요소만** 찍도록 했습니다(900px 창에는 안 들어갑니다).
- **빈 브라우저는 «첫 방문자»** 라 환영 안내(`#aw-overlay`)가 스크롤·클릭을 막습니다 →
  `localStorage` 로 «본 것» 표시 먼저(CLAUDE.md 2장에 이미 있는 함정).
- **`npm ci` 가 ERESOLVE 로 죽습니다** — Node 22 라서입니다(CLAUDE.md 2장).
  `--legacy-peer-deps` 로 임시로 넘겼습니다. 이걸 안 하면 하니스 6종이
  「esbuild 없음」으로 **FAIL 처럼** 보입니다(실제로 처음에 그렇게 보였습니다).
