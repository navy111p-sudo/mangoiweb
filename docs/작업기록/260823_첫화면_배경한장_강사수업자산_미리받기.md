# 첫 화면 가볍게 — 배경 한 장만 먼저 + 강사 화면에서 수업 자산 미리 받기

- 날짜: 2026-08-23
- 작업자: Claude (사장님 지시, navy111p)

## 1. 왜 했나

「한국은 무거워도 괜찮은데 필리핀이 문제다. 필리핀만 최대한 가볍게 뺄 건 뺄 수 없나.
 필리핀 교사들은 학생 홈페이지를 아예 다른 걸 들어간다든가」 (2026-08-23 사장님).

실측으로 확인한 것:

- 강사는 `teacher.html`(blocking 145KB, 외부 파일 0개)을 보다가 「수업 들어가기」를 누르면
  `teacher.html:2031` 이 **학생 홈**(`/?vc_autojoin=1&vc_role=teacher&vc_room=…`)으로 보낸다.
  그 화면은 첫 그림 전에 **1,557KB(파일 24개)** 를 받아야 한다.
- 첫 방문 전송량(gzip): index.html 260KB + js 24개 408KB + css 약 15KB + 배경 이미지 187KB ≈ **870KB**.

## 2. 무엇을 바꿨나

### `cloudflare-deploy/public/index.html` (⚠️ 공동 금지구역 — 사장님 지시로 진행)

홈 배경을 **두 장 다** preload 하던 것을 **쓸 한 장만** 먼저 받도록.

- 예전: `<link rel="preload" as="image">` 두 줄(밝은 147KB + 어두운 40KB).
  첫 화면에 쓰이는 건 «언제나 한 장뿐» 이라 나머지는 버려지는 다운로드였다.
- 지금: `<head>` 인라인 스크립트가 `?home=` → `localStorage(mangoi_home_theme_mode)` →
  «자동은 6~18시가 밝음» 으로 **이번에 쓸 한 장**을 골라 preload.
  나머지 한 장은 `load` + `requestIdleCallback` 에서 `rel=prefetch` 로 조용히.
- 절약: 밤(어두운 테마)이면 **147KB**, 낮이면 40KB 를 첫 화면 경로에서 뺀다.

### `cloudflare-deploy/public/teacher.html`

강사가 수업을 기다리는 «노는 시간» 에 수업용 js 6개를 미리 받아 둔다
(`idx-main.js?v=34` + `idx-vc-*` 5개). 누르는 순간엔 이미 캐시에 있다.

- `[data-join]`(수업 카드의 입장 버튼)이 화면에 생겼을 때만 = **오늘 수업이 있을 때만**.
- `navigator.connection.saveData` 면 하지 않는다.
- 사파리(iOS)는 `prefetch` 미지원 → `relList.supports('prefetch')` 로 판별해
  `fetch(cache:'force-cache')` 로 대체.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **나라별로 다른 HTML 을 내려보내기(`request.cf.country`)** ← 버렸다.
  「필리핀은 한 장, 한국은 두 장」이 사장님의 원래 요청이었지만,
  ① 첫 화면에 쓰이는 배경은 어느 나라든 **한 장뿐**이라 한국도 나머지 한 장은 낭비였다.
  ② 두 장 받는 유일한 이득(테마 칩을 눌렀을 때 즉시 전환)은
     «나중에 조용히 받기» 로 **그대로 유지**된다.
  ③ 화면이 나라별로 갈리면 「필리핀에서만 나는 버그」가 시작되고 한국에서 재현이 안 된다
     (CLAUDE.md 2장 — 관리자 화면 4벌 함정).
  → 나라를 가르지 않고 **순서만** 바꿨다. 결과는 두 나라 모두 이득.

- **캐시 헤더를 손보기** ← 할 것이 없었다. `src/index.ts:2150` 이 `?v=` 붙은 js/css 를
  1년 immutable 로 이미 주고 있고(2026-07-22, 주석에 「필리핀 저속·고지연 회선 대책」),
  이미지·폰트도 2026-08-14 에 챙겨져 있었다. **먼저 확인하지 않았으면 이미 된 일을 또 할 뻔했다.**

- **수업 전용 가벼운 페이지 신설** ← 이번엔 안 했다. `idx-main.js` 851KB 안에 홈과 수업이
  섞여 있어(함수 451개 중 154개가 `vc*`, 어림 322KB) **파일을 가르는 것이 전제**다.
  파일을 «복사» 해서 만들면 화면이 두 벌이 되어 「화면마다 답이 다른」 사고가 시작된다.
  며칠짜리 별건 작업으로 남긴다.

- **`index.html` 에서 `idx-vc-*` 5개를 defer 로 내리기** ← 이번엔 안 했다. 로드 순서를 바꾸다
  홈 전체가 먹통이 된 전례가 있다(`js/idx-vc-screenmode.js` 머리말, 2026-07-14).
  곁다리로 하지 말고 따로 검증해야 한다.

- **teacher.html 에서 `/?vc_autojoin=1` 문서 자체를 prefetch** ← 안 된다.
  실제 입장 주소는 `vc_room`·`vc_name` 이 붙어 **URL 이 매번 다르므로** 캐시가 안 맞는다.
  URL 이 고정된 **js 만** 미리 받는 것이 맞다.
