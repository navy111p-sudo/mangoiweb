# 홈 화면 오프닝 사운드 — 웹오디오 합성 (2026-08-23)

## 1. 왜 했나

사장님 요청: 「유튜브 영상 처음부터 1:20 까지를 망고아이 홈페이지 오픈 음악으로 켜면 어떨까?」
이어서 「우주인 3명 인트로에서 나올 때 그들 배경음악은 없애고 이걸 틀어 줘」.

## 2. 요청 그대로는 못 한 이유 — 두 가지

### 2-1. 유튜브 음원은 쓸 수 없다 (저작권)

> 🔴 **이 절은 아래 2-3 에서 일부 정정된다.** 막히는 것은 «그 녹음» 이지 «그 곡» 이 아니었다.

기술 문제가 아니다. 망고아이는 학생 29,000명이 쓰는 **영리 서비스**라,
남의 저작물을 배경음악으로 올리면 유튜브 ToS 위반 + 저작권 침해가 된다.
국내는 웹사이트 배경음악도 KOMCA 사용 승인 대상이다.
(덤으로 이 작업 컨테이너는 프록시가 유튜브를 막아 영상 확인조차 안 된다.)

### 2-2. 인트로의 «배경음악만» 뺄 수 없다

우주인 3명이 나오는 인트로는 `intro.mp4` **영상 파일 한 개**(4.1MB)다.

- 내레이션(「우주에서 가장 신나는 공부 모험…」)과 배경음악이 **한 오디오 트랙에 섞여** 구워져 있다
- 분리하려면 원본 편집 프로젝트가 있어야 한다 — 이 저장소엔 완성본 mp4 만 있고, 컨테이너에 ffmpeg 도 없다
- 영상을 음소거하면 **내레이션 목소리도 같이 사라진다**

### 2-3. 🔴 정정 — 곡이 무엇인지 알고 나서 판단이 바뀌었다

**처음 판단은 부정확했다.** 나는 곡이 무엇인지 모르는 채 「유튜브 음원 = 저작권 문제」
라고만 말씀드렸다. 사장님이 「슈트라우스의 짜라투스트라는 이렇게 말하였다」라고
알려 주시고 나서 다시 보니, **갈라서 봐야 할 것이 둘**이었다.

| | 상태 | 결론 |
|---|---|---|
| **작곡** (1896년 작, 슈트라우스 1949년 몰) | 사후 70년 경과 → **퍼블릭 도메인** | **연주는 자유롭다** |
| **그 유튜브 영상의 녹음** | 실연자·음반제작자의 저작인접권이 살아 있음 | **가져다 쓸 수 없다** |

즉 **「곡은 되고, 그 녹음만 안 되는」** 것이었다. 「곡 자체를 못 쓴다」는 처음 설명은
틀렸다. 길이 열려 있었는데 내가 닫아 놓고 있었던 셈이다.

📌 **교훈** — 「저작권 때문에 안 된다」고 말하기 전에 **무슨 곡인지부터 확인할 것.**
클래식은 작곡이 PD 인 경우가 많고, 그때 막히는 것은 **녹음뿐**이다.
그리고 막힌 것이 녹음뿐이라면 **직접 연주하면 뚫린다.**

### 2-4. 진짜 오케스트라 녹음을 못 넣은 이유 (이건 순수하게 환경 문제)

PD 녹음(Musopen·archive.org 등)을 받아 넣는 길도 있었지만 이 컨테이너에서는 막혔다.

- `archive.org` · `musopen.org` · `upload.wikimedia.org` → **프록시가 전부 차단**(응답 000)
- `ffmpeg` 은 있으나 **playwright 전용으로 깎인 빌드**라 오디오 코덱이 **하나도 없다**
  (`-encoders` 에 오디오 0건, 먹서는 webm 뿐) → 자르기·인코딩 불가

→ 그래서 **직접 연주(웹오디오 합성)** 로 갔다. 사장님이 PD 음원 파일을 주시면
그때는 `<audio>` 로 바꿔 끼우면 된다(1~2MB 를 «소리를 켤 때만» 받도록 지연 로딩).

## 3. 검토했다가 버린 방법

| 방법 | 버린 이유 |
|---|---|
| 유튜브 음원 추출 | 저작권·ToS. 논의 대상이 아니다 |
| **A안** 인트로 영상 통째 음소거 + 새 음악 | 내레이션 목소리가 사라진다. 자막 9줄이 있어 성립은 하지만 손실이 크다 → 사장님이 B안 선택 |
| **C안** 원본 편집본에서 음악 교체 후 mp4 재납품 | 저장소 밖 편집 작업이 필요. 나중에 원하시면 파일만 갈아 끼우면 된다 |
| Higgsfield 로 음악 생성 | **막혀 있다.** `generate_audio` 는 음성(TTS) 전용이고, 음악 모델(`sonilo_music`)은 게임 생성 파이프라인 전용이라 단독 사용 금지 |
| mp3 를 만들어 R2 에 올리기 | 컨테이너에 ffmpeg·numpy 가 없어 인코딩 불가. 그리고 학생 29,000명이 그 바이트를 받는다 |
| 상주 `setInterval` 로 상태 감시 | 홈에 머무는 학생 폰을 계속 깨운다. 끝이 있는 확인(최대 30초)으로 대신 |
| body class 를 `MutationObserver` 로 감시 | ⛔ 2026-07-14 홈 전체 먹통의 뿌리. `showView` 를 감싸는 방식으로 대신 |

## 4. 채택 — B안 + 웹오디오 합성

**인트로는 한 줄도 건드리지 않았다.** 인트로가 끝난 뒤 홈에서 오프닝 사운드가 한 번 울린다.

- 새 파일 `cloudflare-deploy/public/js/idx-home-opening.js`
- `index.html` 에는 **`<script defer>` 한 줄만** 추가

### 왜 «합성» 인가

1. **저작권** — 웹오디오 오실레이터로 그 자리에서 계산한다. 100% 우리 것이다.
2. **첫 화면 무게** — 음원 파일이 **0바이트**다. blocking 1557KB 그대로, defer 만 956→975KB.

### 소리

**슈트라우스 「짜라투스트라는 이렇게 말했다」 서주 «일출» — 약 82초**
(사장님이 지정하신 «처음부터 1분 20초까지»)

낮은 도(C1·C2) 지속음이 오르간 페달로 깔리고, 그 위로 **«도–솔–도»** 가 세 번 올라간다.
올라갈 때마다 단3화음이 장3화음으로 열리고 팀파니가 친다. 세 번째가 가장 크고,
마지막 화음이 길게 남으며 끝난다.

악기는 전부 오실레이터로 만들었다 — 오르간 페달(사인 배음 4겹) · 금관(톱니파 3겹 디튠 +
로우패스 + 비브라토) · 팀파니(사인 «둥» + 짧은 밴드패스 잡음 «탁»). 홀 울림은 피드백 딜레이.

⛔ **반복하지 않는다.** 한 번 울리고 끝이다.

> 📜 **처음엔 다른 곡이었다.** 곡이 무엇인지 모르던 동안에는 6.4초짜리 「망고 일출」
> (F 장조 펜타토닉 종소리)을 만들어 배포했다(PR #429). 사장님이 곡명을 알려 주신 뒤
> 위 2-3 의 정정에 따라 짜라투스트라 서주로 바꿨다.

#### 🛡️ 리미터를 넣은 이유

마지막 화음은 금관 8성부 × 디튠 3겹 = **톱니파가 20개 넘게** 겹친다. 그대로 두면
합이 1.0 을 넘어 스피커에서 지직거린다.

⚠️ **피크를 수치로 확인하지 못했다.** `OfflineAudioContext` 로 렌더해 재려 했으나
헤드리스 크로미움의 가상시간(`--virtual-time-budget`) 안에 `startRendering()` 이
끝나지 않았다(60초 예산으로도 결과가 안 나옴).

→ 그래서 **«재서 맞추는»** 대신 **«넘을 수 없게 막는»** 쪽을 택했다.
출력단 `DynamicsCompressor` 를 리미터로 설정(threshold −3dB · knee 0 · ratio 20 ·
attack 3ms)해 천장을 만들었다. 마스터 볼륨은 0.40(아이들 화면이라 낮게).

### 끄는 길이 둘 (사장님 지시 「둘 다」)

1. **화면 아무 데나 클릭·터치** → 0.18초 페이드아웃 후 정지
2. **🔊 버튼** (왼쪽 아래) → 켬/끔 설정을 뒤집는다. 끄면 `localStorage` 에 기억돼 다음 방문에도 안 울린다

⚠️ 버튼은 처음에 «재생 중이면 끄기 / 멈춰 있으면 다시 듣기» 로 갈랐는데,
화면을 눌러 끈 뒤에는 🔊 아이콘이 그대로인 채 «다시 듣기» 가 되어
**끄려고 누른 사람에게 소리가 다시 났다**(헤드리스 실측으로 잡음).
아이콘이 곧 현재 설정이고 누르면 뒤집히는 단순 토글로 바꿨다.

### 🇵🇭 필리핀 회선에서 무거워지지 않게

사장님 확인 요청: 「최대한 가볍게 해서 필리핀에서 열어 쓰는 데 문제 없게 할 수 있지?」

| 항목 | 값 |
|---|---|
| 추가된 JS | **25,800 B** (gzip **9,187 B**) |
| 추가된 음원 바이트 | **0 B** — 소리를 파일로 받지 않고 그 자리에서 만든다 |
| 첫 화면 blocking | **1557KB → 1557KB (변화 없음)** — defer 라 파싱을 안 막는다 |
| 비교: `idx-main.js` | 871KB (gzip 262KB) — 이 파일은 그 **3.5%** |
| 비교: `intro.mp4` | 4.25MB — 이 파일은 그 **0.22%** |

즉 **학생이 실제로 더 받는 것은 gzip 9.2KB 한 번**이고, `immutable` 캐시라 다음 방문엔 0이다.
음악을 mp3 로 넣었다면 (1분 20초 기준) 최소 1~2MB 를 매번 받아야 했다 — 그걸 피한 것이 이 방식의 요점이다.

거기에 더해 **약한 기기·데이터절약에서는 스스로 울리지 않는다**(`thrifty()`):

- `html.lite-mode`(저사양 모드)
- `navigator.connection.saveData === true`(사용자가 «데이터 절약» 을 켬)
- `effectiveType` 이 `2g`·`slow-2g`

이때도 🔊 버튼은 남겨 둔다 — 듣고 싶으면 누르면 된다.
⚠️ 이 판정은 **저장하지 않는다.** 회선이 좋아지면 다음 방문엔 정상으로 울려야 하기 때문이다.

### 안 울려야 할 때

- **수업 중**(`body.vc-in-call`) — 수업 소리와 겹치면 그 자체로 사고다
- **인트로가 떠 있는 동안** — 인트로에 자기 내레이션이 있다
- 탭이 백그라운드일 때
- 한 세션에 한 번만

### 밟지 않으려고 특별히 챙긴 함정 (CLAUDE.md 2장)

- `MutationObserver` 로 body class 를 보지 않는다 → `showView` 를 감쌌다
- 스타일을 `document.head` 가 아니라 **`document.body` 끝**에 붙였다
- 버튼 z-index 를 «A.i 상담사» 위젯(2147483000) **아래**(2147482900)로 뒀다
- 버튼 자리를 `#mg-fab-wrap`(left:16, bottom:20)·`#ph52-cache-fab` 위로 비켰다(bottom:76)
- hover 로 크기를 바꾸지 않는다(색만)
- 이모지는 🔊 U+1F50A · 🔇 U+1F507 — 둘 다 Unicode 6.0 이라 Win10 에서 두부가 안 된다
- 버튼 라벨에 `data-ko`/`data-en` 을 함께 박고 `mangoi:lang-changed` 에서 다시 입힌다

## 7. 🔴 배포 후 사장님 실측 — 「아무 음악소리도 안 들린다」 (2026-08-23 밤)

**실제 화면에서 소리가 전혀 나지 않았다.** 원인은 둘 다 내 코드였다.

### 7-1. 클릭 한 번이 이벤트 «둘» 을 낸다 — 시작시킨 클릭이 자기를 껐다

정지 신호를 `pointerdown·mousedown·touchstart·keydown` 네 곳에서 받는데,
**마우스 클릭 한 번은 `pointerdown` + `mousedown` 둘을 연달아 낸다**(터치는 `pointerdown`+`touchstart`).

1. `pointerdown` → 재생 전이니 **시작** (그 이벤트 객체를 «시작 신호» 로 기억)
2. `mousedown` (같은 클릭) → 이미 재생 중 + 기억해 둔 객체와 **다른 객체** → **즉시 정지**

소리가 1ms 나고 꺼졌고, 정지가 `markDone()` 까지 불러 **그 세션엔 다시 안 울렸다.**
📜 CLAUDE.md 의 「게임 허브 안내음성 — pointerdown 자동정지와 click 토글이 서로를 뒤집던」
함정과 **같은 뿌리를 같은 날 또 밟았다.**

✅ 고침 — 이벤트 «객체 동일성» 이 아니라 **«시작한 지 얼마나 지났나»**(700ms 유예)로 판정.
한 손짓이 만드는 형제 이벤트가 몇 개든 전부 덮인다.

### 7-2. `resume()` 은 약속(Promise)이다 — 자동재생 판정이 늘 «실패» 로 읽혔다

```js
ctx.resume();                          // 비동기 — 바로 안 풀린다
if (ctx.state === 'suspended') { ... } // 언제나 참 → 컨텍스트를 닫아 버림
```
✅ 고침 — 약속이 풀린 «뒤에» `state === 'running'` 을 보고 이어서 시작(`begin()`).
재시도 때 이전 컨텍스트가 안 새게 `drop()` 정리도 추가(페이지당 개수 제한이 있다).

### 7-3. 왜 내 검사는 못 잡았나

- 자동재생 정책을 **끄고**(`--autoplay-policy=no-user-gesture-required`) 재서
  «클릭으로 시작 → 형제 이벤트가 끔» 경합 자체가 안 생겼다
- 정지 검사에 `pointerdown` **한 개만** 보내 진짜 클릭의 연쇄를 재현하지 못했다

✅ 이번엔 «pointerdown+mousedown 연쇄» 로 재현 검사를 만들었다(`__dblclick.html` 방식) —
고친 코드에서 «시작 클릭 유지 ✅ · 뒤 클릭 꺼짐 ✅».
⚠️ 자동재생이 «막힌» 경로는 헤드리스로 못 잰다 — `dispatchEvent` 합성 이벤트는
사용자 활동으로 인정되지 않아 잠금이 안 풀린다. 이 경로는 사람 확인이 필요하다.

### 7-4. 같은 김에 — «고음이 없다 · 더 웅장하게» (사장님 추가 요청)

- 금관 로우패스를 더 열어 쨍한 윗배음을 살림 (상한 9.5kHz)
- 2·3번째 «도–솔–도» 에 **한 옥타브 위 트럼펫**(C5→G5→C6) 겹침
- 장3화음이 열릴 때 **심벌즈** «촤아» (2번째부터, 3번째가 가장 길게)
- 화음 위에 **높은 현**(E5·G5·C6) 반짝임, 마지막 여운까지
