## 1. 왜 했나

사장님 지시 — 「강사교육 매뉴얼 수정해줘. 캐릭터도 Mr.Mango 넣어주고 좀 더 이해하기 쉽고
설득력 있게 영어·한국어 모두 잘 만들어줘. 차트나 다이어그램, 이미지 등등 다양하게 넣어서
흥미롭게 만들어줘. 오타 수정, 문맥 잘 만들어줘.」

받은 화면(`/teacher-training.html`)을 열어 보고 확인한 문제:

| 문제 | 실제 상태 |
|---|---|
| **회사 이름 오타** | 화면·제목·본문 **16곳**이 「망고아이」가 아닌 다른 표기였다. 게다가 표지·사이클 **PNG 안에 그림으로 박혀** 있어 HTML 만 고쳐서는 안 고쳐진다 |
| **캐릭터가 우리 것이 아님** | 표지·사이클 그림의 캐릭터가 **아무 오렌지 도형**이었다. 공식 마스코트 Mr.Mango(`/img/mango-char.png`)는 상단바 아이콘 한 곳에만 있었다 |
| **언어 토글이 두 개** | 화면 오른쪽 위에 이 화면 자체 토글(한글/English)과 `adm-lang-boot` 이 붙이는 미니 토글(🌐 EN)이 **같이** 떠 있었다 |
| **그림이 전부 PNG** | 10종 × 2언어 = 20장. 언어를 바꾸면 이미지 파일을 갈아 끼우는 방식이라 **오타 하나 고치려면 그림을 다시 구워야** 했다. «현장 수업 사진 삽입 위치» 라고만 적힌 빈 액자도 4장 있었다 |
| **내용이 «지침»에 그침** | 원칙 5가지·6단계·연령별 표는 있었지만, 강사가 **수업 중에 그대로 쓸 수 있는 것**(영어 문장, 상황별 대처)이 없었다 |

## 2. 무엇을 했나

한 파일을 v3.0 으로 다시 썼다(1,036줄 → 약 1,530줄 / 72KB → 92KB).

### 2-1. 오타·문맥
- 회사 이름 표기를 **「망고아이」로 통일**(16곳). 그림 속 글자도 SVG 라 함께 고쳐졌다.
- 한국어·영어 본문을 전부 다시 썼다. 「~해야 합니다」식 지시문 대신 **왜 그런지 → 그래서 무엇을**
  순서로 바꾸고, 화면 감쇠 30~40%·첫 5분·발화 60%·나이=집중분 같은 **숫자를 근거로** 삼았다.
- 영어는 번역투를 걷어내고 필리핀 강사가 읽는 문장으로 새로 썼다(직역 대응이 아니라 같은 뜻의 다른 글).

### 2-2. Mr.Mango
공식 캐릭터를 **네 자리**에 넣었다 — 상단바, 표지 히어로, **몰입 사이클 다이어그램 한가운데**,
그리고 각 장 끝의 **«MR.MANGO» 말풍선**(핵심을 한 줄로 다시 짚어 주는 자리, 7곳).

### 2-3. 그림 — PNG 20장 → 인라인 SVG 6종
| 그림 | 내용 |
|---|---|
| 몰입도 곡선 | 25분 동안의 몰입도. 「첫 5분에 훅이 있는 수업」 대 「설명부터 시작한 수업」 두 선 |
| 발화 비율 도넛 | 아이 60% / 강사 40% + 목표선 |
| 연령별 막대 | 5~7세 6분 · 8~10세 9분 · 11~13세 13분 · 14세+ 18분 |
| 25분 배분 띠 | 4·2·7·5·4·3 분 누적 막대 + 눈금 + 범례 |
| 몰입 사이클 | 6단계 원형 + 화살표, 가운데 Mr.Mango |
| 6항목 레이더 | **루브릭 점수와 실시간 연동** — 고르면 육각형이 바로 바뀐다 |

### 2-4. 새로 넣은 내용
- **바로 쓰는 수업 영어** — 오프닝 30초 / 칭찬 12가지 / 기다림·도와주기 / 전환·마무리 (영어 문장 + 한국어 뜻)
- **바꿔 말하기 표** — 「No, that's wrong.」 → 「Almost! Listen once more.」 5쌍, 왜 그런지까지
- **상황별 대처법 6가지** — 대답 없음 / 카메라 끔 / 산만함 / 난이도 / 부모 동석 / 연결 끊김. 각 4단계
- **강사 성장 로드맵** — 입문 → 안정 → 우수 → 마스터
- 체크리스트 8 → **10항목**, 루브릭은 **가장 낮은 항목을 «이번 달 목표»로 짚어 준다**

### 2-5. 언어 토글
이 화면의 토글에 **`data-mangoi-lang-toggle`** 을 달아 `adm-lang-boot` 의 미니 토글이 덧붙지 않게 했다.
또 `window.__ADM_BOOT_LANG` 을 읽어 **해외 강사는 열자마자 영어**로 뜨고, 고른 언어는
`mangoi_lang`(`by='user'`)에 저장돼 다른 관리자·강사 화면에서도 이어진다.

## 3. 검토했다가 버린 방법

1. **PNG 를 다시 구워서 오타만 고치기** — 20장을 다시 만들어야 하고, 다음에 문장 한 줄만 바꿔도
   같은 일을 또 해야 한다. 언어별로 두 벌이라 한쪽만 고치는 사고도 난다. → **SVG 로 갈아탐**.
2. **Tailwind 클래스로 새 디자인 쓰기** — `/css/tailwind-build.css` 는 이 화면과 `suspect-mystery.html`
   에 «그때 쓰인 클래스만» 뽑아 구운 **정적 빌드**다(파일 머리 주석). 새 클래스는 **조용히 스타일이 빠진다**.
   빌드를 다시 돌리려면 `npx tailwindcss` 가 필요하고 앞으로도 계속 필요해진다.
   → **이 화면 전용 `tt-` CSS 를 직접 씀**(Tailwind 링크 제거). 다음 사람이 빌드를 몰라도 손댈 수 있다.
3. **`chart.js` 등 차트 라이브러리** — 이 저장소는 이미 Chart.js 로 「카드 밖으로 한없이 길어지는」
   사고를 낸 전력이 있다(CLAUDE.md 2장). 여기 그림은 전부 **값이 고정된 설명용**이라 라이브러리가
   필요 없다. → 손으로 그린 SVG. 인쇄에서도 글자가 안 깨진다.
4. **빈 사진 액자 4장 유지** — 2년째 「현장 수업 사진 삽입 위치」로 남아 있었다. 채울 사진이 없으면
   비어 있는 것보다 **빼는 게 낫다**고 보고 자리를 실제 내용(스크립트·대처법)으로 바꿨다.
   ⚠️ 사진이 준비되면 그 자리에 넣자고 사람에게 물을 것.
5. **PNG 파일 20장을 남겨 두기** — 참조가 0건이 된 뒤에도 남겨 둘까 검토했지만,
   **회사 이름 오타가 그림에 박힌 파일이 계속 서비스에 올라가 있으면** 나중에 누가 다시 가져다
   쓸 위험이 있다. → **사장님 확인 뒤 20장 전부 삭제**(`public/img/teacher-training/`, 936KB).
   되돌릴 일이 생기면 `git show <이 커밋>^:경로` 로 꺼낼 수 있다.
6. **총점만으로 «최고 등급» 주기** — v2 로직 그대로면 한 항목이 1점이어도 총점 15점이면
   「여섯 항목이 고르게 높습니다」가 나온다. → **1점짜리가 하나라도 있으면 최고 등급을 주지 않는다.**

## 4. 밟은 함정 (다음 사람이 또 밟을 것들)

- 🔴 **Tailwind 정적 빌드** — 위 2번. 「클래스를 썼는데 아무 스타일도 안 먹는다」로 나타난다.
- 🔴 **lucide 아이콘의 인라인 style 이 사라진다** — `lucide-local.js` 는 `<i data-lucide>` 를
  **`<svg>` 로 갈아 끼운다.** `<i>` 에 적은 `style="width:16px"` 은 새 요소로 옮겨지지 않아
  기본 24px 이 나오고, 버튼이 아이콘 하나로 가득 찬다. → **CSS(`.tt-btn svg{width:16px}`) 로 못 박을 것.**
- ⚠️ **SVG 안에 `font-family` 를 적지 말 것** — `hanzi_font_harness` 가 모든 `font-family` 의
  맨 앞이 `MangoiHanSC` 인지 검사한다. SVG `<text>` 는 body 에서 상속받으면 된다.
- ⚠️ **붙어 있는 머리줄이 폰에서 화면을 먹는다** — 처음엔 390px 에서 **163px**(화면의 19%)였다.
  토글을 «줄바꿈» 하면 그만큼 본문이 밀리므로 **가로 스크롤 한 줄**로 바꿔 95px 로 줄였다.
- ⚠️ **SVG 를 그냥 넣으면 카드 폭만큼 커진다** — 도넛이 1,000px 넘게 그려졌다. `.tt-fig svg{max-width}` 필요.
