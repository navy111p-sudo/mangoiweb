# 웜업 «뜻 보기» — 「수업 전에 따뜻하게하자」 직역을 의역으로 (2026-08-24)

## 왜 했나

사장님 제보(스크린샷): 수업 전 AI 웜업(`warmup.html`)에서 첫 인사말
"Hi! I'm your Mangoi AI friend 🥭 Let's warm up before class. How are you today?" 의
「뜻」 버튼을 누르면 **「안녕하세요!나는 당신의 Mangoi AI 친구입니다 수업 전에 따뜻하게하자.」**
가 나왔다. "warm up" 이 «따뜻하게 하다» 로 직역된 것 — 다른 문장들도 전반적으로 직역투.

뿌리: 「뜻 보기」는 `/api/translate` 를 **모드 없이** 불렀고, 그 기본 경로는 번역 전용 모델
**m2m100** 이라 구어 관용구에 약하다. 화상수업 채팅이 정확히 같은 이유로 이미
`mode:'chat'`(언어모델+맥락)으로 갈아탄 전례가 있다(2026-07-29, 「숙제」→job 오역).

## 무엇을 했나

1. **서버 `api-mango.ts` — `/api/translate` 에 `mode:'learn'` 추가**
   - AI 튜터의 말을 학생(초·중등)이 이해하도록 **의역**하라는 전용 프롬프트로
     언어모델(llama-3.3-70b) 번역. "warm up ≠ 따뜻하게" 를 예시로 박아 둠.
   - 어투는 친근한 **해요체 고정**(반말 금지, 딱딱한 합니다체도 금지).
   - 기존 chatTranslate 파이프라인을 공유(따옴표 벗기기·어미 중첩 교정·목표언어 검증·실패 시 m2m100 폴백).
     단, 채팅과 달리 **여러 문장 말풍선**이라 «첫 줄만 취하기» 대신 줄을 이어 붙인다.
   - KV 캐시 접두사 **`trl1:`** 신설 — 옛 직역 캐시(`tr:`)와 안 섞이고, 프롬프트를 고치면 번호를 올린다.
   - ⚠️ 새 경로가 아니라 기존 엔드포인트의 모드 추가라 `src/index.ts` 게이트는 **안 건드렸다**
     (그 게이트가 `path === '/api/translate'` 정확 일치라서 — chat 모드 때와 같은 이유).

2. **화면 `warmup.html`**
   - `fetchMeaning` 이 `mode:'learn'` 으로 호출.
   - **고정 인사말은 손으로 다듬은 의역을 내장**(`curatedMeaning`) — 모델 운에 안 맡긴다.
     주제 구간(`Today's topic is "X".`)만 동적이라 정규식으로 맞춘다:
     > 안녕하세요! 저는 망고아이 AI 친구예요 🥭 (오늘의 주제는 "X"예요.) 수업 전에 저랑 같이
     > 가볍게 입을 풀어 봐요. 오늘 기분이 어때요?

3. **하니스 `subtitle_meaning_harness.mjs` ⑤절에 검사 4건 추가** —
   화면 `mode:'learn'`·`curatedMeaning`, 서버 `mode==='learn'`·`trl1:` 접두사.
   화면과 서버가 짝이라 한쪽만 지워지면 직역으로 되돌아가는 것을 잡는다.

## 검토했다가 버린 방법

- **서버 KV 의 옛 번역 캐시를 지우기** — 지울 필요가 없다. 접두사를 갈랐으니 옛 캐시는
  그냥 안 읽히고 180일 뒤 알아서 사라진다. KV 를 훑는 작업 자체가 별건 사고 위험.
- **`mode:'chat'` 재사용** — 프롬프트 맥락이 «직원·강사 사무 채팅»이라 대상이 다르고,
  응답에서 **첫 줄만** 취해서 여러 문장 말풍선의 뜻이 잘린다.
- **인사말 영어 원문 자체를 바꾸기** — 제보는 한국어 «뜻» 품질이지 영어가 아니다. 범위 밖.
- **`ai-friend.html` 도 같이 전환** — 같은 구조(`fetchMeaning`)라 한 줄이면 되지만,
  이번 지시는 웜업 화면이라 범위를 지켰다. 다음에 같은 제보가 오면 `mode:'learn'` 만 붙이면 된다.

## 확인한 방법

- `tsc --noEmit` 통과(exit 0), `node test-harness/run.mjs --fast` PASS 198 · FAIL 0.
- `curatedMeaning` 을 실제 함수로 돌려 인사말 3형(주제 없음/있음/다른 문장)이
  기대대로 나오는 것 확인 — 문자열 검사만 믿지 않았다.
- ⚠️ 언어모델이 실제로 만드는 의역 품질은 배포 뒤 실서비스에서 「뜻」을 눌러 봐야 안다
  (프록시가 mangoi.ai 를 막아 Claude 는 배포 화면을 못 본다). 고정 인사말은 내장 의역이라 확정.
