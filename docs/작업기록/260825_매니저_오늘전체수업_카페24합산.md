# 「오늘 전체 수업」이 늘 비어 있던 것 — 카페24 예약을 합쳐서 준다

- 날짜: 2026-08-25
- 출발: 필리핀 매니저 8/25 보고서 「NEW TEACHER'S PAGE PROBLEM」 5건 중 ②③⑤ (+ ① 일부)
- 범위: `/api/admin/classes/today` · `admin.html` 카드 · `manager.html` 새 카드

---

## 1. 왜 했나

보고서 ②는 「매니저 페이지에 오늘 전체 수업을 보여 달라」였다. 그런데 대조해 보니
**그 카드는 이미 있었다** — `admin.html` 의 「🚪 오늘 수업 (바로 입장)」.
보고서에 첨부된 스크린샷이 바로 그 우리 화면이었고, [Load] 를 누른 결과가
**「No classes scheduled for today」** 였다.

같은 보고서 5번 스크린샷(관리자 「Live Classes」)에는 같은 시각 이렇게 찍혀 있었다:

```
Scheduled now 6 · In a Mangoi room 0 · Starting soon 12
"The classes below are running on cafe24 — 'No connection record' is normal"
```

즉 **수업은 돌고 있는데 목록만 비어 있었다.**

원인은 하나였다. `/api/admin/classes/today` 가 `class_schedules` 만 읽는다.
실제 운영 수업은 카페24가 정본이고, 카페24 예약은 그 표에 **한 줄도 안 들어온다**
(`cafe24-sync.ts` 는 `attendance` 에 `c24-{class_id}` 씨앗으로만 넣는다).
⚠️ 에러가 안 났다 — 화면은 «정상 문구» 를 띄웠다. 그래서 「기능이 없다」로 접수됐다.

## 2. 한 일

| 보고서 | 한 일 |
|---|---|
| ② 오늘 전체 수업 | `classes/today` 가 `class_schedules` + `attendance(c24-%)` **두 갈래를 합쳐서** 준다. 출처는 `source` 로 구분 |
| ③ 완료된 수업 기록 | 같은 API 에 `?date=YYYY-MM-DD`. 날짜만 바꾸면 지난 기록이 된다 |
| ⑤ 매니저가 입장 | `manager.html` 에 「오늘 전체 수업」 카드 신설 — 망고아이 방이 있는 줄에는 [입장] |
| ① 학생 정보 | 줄마다 **레벨 · 교재 배정 여부**. 옛 LMS 의 「TEXTBOOK 배정 없음」 배지에 대응 |

그리고 **강사 차단 + 지사·대리점 스코프 격리**를 함께 넣었다(아래 3-2).

## 3. 검토했다가 버린 방법

**3-1. 카페24 줄에도 [입장]·[참관] 버튼을 준다 → 버렸다.**
카페24 수업은 망고아이 화상방을 거치지 않는다(실측 8/20: `c24-*` 방 실접속 전 기간 0건).
버튼을 주면 **아무도 없는 방**이 열리고, 매니저는 「수업이 깨졌다」로 읽는다.
동기화가 가져오는 속성에도 강의실 URL 이 없다 — `cafe24-sync.ts` 의 Cypher 가 받는 것은
`class_id · user_id · start_ms · end_ms · date · class_state · teacher_id · teacher_name` 여덟 개뿐이다.
→ 버튼 대신 **「LMS」 표시와 «왜 입장이 안 되는지»** 를 그 자리에 적었다.
⏳ 남은 것: 카페24 `:Class` 에 입장 URL 속성이 **있는지** 확인. 있으면 링크만 실으면 된다.

**3-2. 「강사도 어차피 자기 수업만 보니 괜찮다」 → 틀렸다.**
`scopeStudentCond` 는 `scope.type='none'`(내부직원·교사)에 **빈 조건**을 준다 = 제한 없음.
즉 스코프로는 강사를 못 막는다(CLAUDE.md 2장 `canEditOrg` 함정과 같은 뿌리).
→ 핸들러 첫 줄에서 `isTeacher` 403 + `index.ts` 차단목록 등재(이중 방어).
그리고 지사·대리점은 **스코프로 자른 뒤에만** 허용목록에 올렸다.

**3-3. 조인이 깨지면 조건 없이 다시 조회 → 그대로 두면 유출이다.**
`students_erp` 는 스키마 드리프트가 있어 폴백 조회가 원래 있었다. 그런데 스코프 조건이
그 폴백에서 사라지면 **지사에게 남의 학생이 나간다.** → 스코프가 걸린 요청은 폴백 대신
빈 목록을 준다(하니스 ⑬로 못 박음).

**3-4. `manager.html` 카드를 별도 `defer` 파일로 → 버렸다.**
그 화면은 **외부 JS 가 0개**이고 외부 리소스가 CSS 하나뿐이다. 파일을 빼면 요청이
1 → 2 개가 된다 — 필리핀 회선에서 RTT 가 바이트보다 비싸다. → 인라인.

**3-5. 자동갱신에 태우기 → 버렸다.** 하루 143건 조회가 주기적으로 돌면 D1 읽기가 계속 는다.
[Refresh] 와 날짜 변경 때만 다시 받는다.

## 5. 밟은 함정

- **하니스가 «앞에서 4000자» 만 봤다.** 핸들러가 길어지자 뒤쪽이 잘려
  「is_level_test 가 없다」는 **거짓 실패** 2건. 깨진 것은 보호가 아니라 **자[尺]** 였다
  → 다음 핸들러 앞까지로 바꿈.
- **러너가 요약 줄 «모양» 을 본다.** `PASS 28    FAIL 0` 이라고 쓰면 `28` 이 실패 건수로 잡혀
  전부 통과인데 FAIL 로 분류된다(`([1-9]\d*)\s*FAIL`). 다른 하니스와 같은 모양(`⚠ FAIL 0`)을 쓸 것.
- **「미배정」 경고가 회색으로 나왔다.** 코드에는 앰버(`#b45309`)라고 적혀 있었는데
  `.muted` 상자 안에 넣어 `rgb(122,135,148)` 로 보였다. 브라우저 검사가 잡았다.
- **날짜 입력칸 크기를 인라인으로 못 정한다.** `admin-inline-c.css` 의
  `details.menu-card input{padding:8px 12px!important;font-size:13.5px!important}` 이 이긴다(실측).
  이 줄은 flex-wrap 툴바라 커져도 안 밀리므로 전역 규칙을 따르고, **주석에 그렇게 적었다**
  (인라인에 남겨 두면 「코드만 보면 작은 줄 아는」 거짓말이 된다).
- **`npm ci` 가 죽는다** — Node 22(npm 10)의 peer 충돌. `.nvmrc` 는 24. `--legacy-peer-deps` 로 우회.
