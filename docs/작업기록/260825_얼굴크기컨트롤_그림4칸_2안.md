## 1. 왜 했나

사장님 제보 — 「얼굴화면 크기 조절 기능이 너무 많아. 지면을 너무 차지해서 헷갈려서 그래.」
4안을 만들어 제시(→ [얼굴화면_크기조절_UI_4안_2026-08-25.html](../얼굴화면_크기조절_UI_4안_2026-08-25.html))했고
**2안(레이아웃 그림 4칸)** 으로 진행 지시를 받았다.

### 손대기 전 실측

| | |
|---|---|
| 한 줄에 든 버튼 | **7개** — `flex-wrap:wrap` 이라 좁아지면 **두 줄** |
| 폰 **세로** | 바 전체가 `display:none` → 크기를 바꿀 방법이 **0개** (하단 독 시트를 여는 길뿐) |
| 폰 **가로** | 우상단 고정 + 글자 **8.5px**, `1/4`·`3/4` 를 숨겨 겨우 4개 |
| 같은 기능 중복 | 하단 독 「화면 분할」 시트에 **10개 항목**(`vcScreenSet`) |
| 얼굴 폭 규칙 | breakpoint 별로 **CSS 8개 블록**에 분산 |

핵심은 **버튼 7개가 성격이 다른 두 가지를 섞고 있었다**는 것 —
앞의 넷(`1/4·1/2·3/4·전체`)은 «얼굴이 차지하는 공간» 하나의 축이고,
뒤의 셋(`PIP·솔로·자유`)은 크기가 아니라 수업 중 거의 안 쓰는 특수 모드다.

| **하단 독 시트 10개 항목 이름 통일** | 제안서의 다음 단계이지만 **지시 범위 밖**이라 하지 않았다. 지금 바와 시트의 어휘가 다르다(아래 6장) |

## 4. ⚠️ 폰 세로에 바를 되살린 것 — 일부러 없앴던 것이다

2026-06-02 「휴대폰 세로 수업화면 정리」에서 **일부러** `display:none` 한 것이다.
이유는 «지면을 너무 차지» 였고 **그때는 버튼이 7개에 두 줄**이었다.
그림 4칸은 **한 줄 22px** 이라 그 이유가 사라졌고, 그동안 폰 세로에는 크기를 바꿀 길이 아예 없었다.

- 세로에서 네 크기가 실제로 동작하는 CSS 는 **이미 있었다** — `#vc-portrait-split-modes`(22vh/46vh/64vh/전체).
  하단 독 시트용으로 만들어져 있었을 뿐이다.
- ⏪ **되돌리려면 `<style id="vc-sizebar-2an">` 의 `@media (max-width:900px) and (orientation:portrait)` 블록 하나만 지우면 된다.** 나머지에 영향 없음.

## 5. 밟은 함정 — 문자열 하니스가 하나도 못 잡은 것들

브라우저 실측(`test-harness/manual/vc-sizebar-4seg-browser.mjs`, **90건**)이 잡았다.
타입체크·회귀 하니스 198건은 그동안 **전부 초록불**이었다.

1. 🔴 **`nth-child` 가 «부모 기준»이다.** 옛 규칙
   `body.vc-in-call .video-size-bar button:nth-child(1),(3){display:none!important}`(폰 세로)은
   «바의» 1·3번째가 아니라 **자기 부모의 1·3번째 버튼 아무거나**를 잡는다.
   «⋯»(`.vsb-more-wrap` 의 첫 자식)과 메뉴의 📌PIP(1번째)·⤡자유(3번째)가 **폰 세로에서 조용히 사라졌다.**
2. 🔴 **특이도를 잘못 셌다.** `.video-size-bar.vsb2` 는 클래스가 «2개» 라 **(2,2,0)** 인데,
   옛 규칙 `body.vc-in-call #vc-main-row > #vc-video-pane .video-size-bar` 는 **(2,2,1)** —
   **element 하나 차이로 진다.** `position` 은 먹는데 `flex-wrap:nowrap` 만 안 먹어
   «두 줄로 접힘» 이 그대로 남을 뻔했다. → `.vsb2.vsb2` 로 (2,3,0). 이 저장소에 같은 선례가 있다(`#vc-video-grid#vc-video-grid`).
3. 🔴 **색을 `!important` 로 잡았더니 라이트 테마를 이겼다.** 내 특이도(2,4,0)가
   `css/mango-theme-light.css`(0,2,1~0,4,1)를 이겨 **흰 배경에 흰빛 글자**가 됐다.
   → **색은 내가 정하지 않는다.** 이 블록은 «자리와 크기» 만 갖고 색은 두 테마에 맡긴다.
4. 🔴 **라이트 강조색이 원래 안 읽혔다.** `--mlt-sky-deep`(#0ea5e9) + 흰 글자 = **2.77:1**(본문 기준 4.5 필요).
   옛 7버튼 시절에도 같았지만, 2안에서는 «지금 어느 칸인가» 를 이 색 하나가 지고 간다.
   → 이 컨트롤에만 `#0369a1`(5.93:1). **공용 테마 파일은 안 건드렸다.**
5. 🔴 **`vcScreenSet` 은 «수업에 들어갈 때» 만들어진다.** 부팅 시점엔 `undefined` 라 그냥 감싸면
   **조용히 아무 일도 안 한다**(독 시트로 크기를 바꿔도 바 표시가 안 따라왔다).
   → `Object.defineProperty` 접근자로 대입 순간에 감싼다.
6. `asset_version_harness` — 파일을 고친 뒤 `?v=` 를 안 올려 FAIL. 아직 배포된 적 없는 새 파일이라
   원장 항목을 최종 내용으로 다시 기록했다.

## 10. 🔴 이름을 맞추다 발견한 «거짓 중복» 둘

이름만 바꾸려 했는데, **같은 이름이 서로 다른 동작**을 가리키는 자리가 둘 있었다.

### ① 「솔로」가 두 개, 그런데 **반대 동작**이다

| | 어디 | 실제 동작 |
|---|---|---|
| 시트 「솔로」 | `vcScreenSet('solo')` | `video-solo` → **얼굴 영역이 통째로 사라지고 교재만** 남는다 |
| 바 ⋯ 「👤 솔로」 | `vcToggleSolo()` | **다른 참가자만 숨기고 내 얼굴은 남긴다** |

한쪽은 «내 얼굴을 없애는 것», 다른 쪽은 «내 얼굴만 남기는 것» 이다. 이름이 같아 오래 헷갈렸다.
→ 시트 **「영상 끄고 교재만 (Video off)」** · 바 **「👤 내 얼굴만 (Only me)」** 으로 갈랐다.

### ② 「PIP」도 두 개

| | 어디 | 실제 동작 |
|---|---|---|
| 시트 「PIP」 | `vcScreenSet('pip')` | **레이아웃** — 교재가 전체, 얼굴은 구석 작은 칸 |
| 바 ⋯ 「📌 PIP」 | `vcTogglePip()` | **오버레이** — 끌어 옮기고 크기 조절하는 떠 있는 창 |

→ 시트 **「교재 전체 + 작은 얼굴 (PIP)」** · 바 **「📌 얼굴 띄우기 (Float faces)」**.

⚠️ **동작은 하나도 안 바꿨다.** 이름만 갈랐다. 어느 쪽이 더 나은 UI 인지는 별개 문제다.

## 14. 🪤 하니스가 잡아 준 것 — `teacher.html` 이 같은 파일을 미리 받고 있었다

`idx-main.js` 내용이 바뀌어 `index.html` 의 `?v=35 → 36` 을 올렸더니

⛔ **`idx-main.js` 버전을 올릴 때는 `teacher.html` 의 preload 목록도 같이 봐야 한다.**
