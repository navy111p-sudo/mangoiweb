# 포인트샵 브랜드 표기 — 🥭 이모지를 Mr.mango 캐릭터로 (2026-08-25)

## 왜 했나

사장님이 관리자 «정산·매출 ▸ 포인트» 상품 목록 스크린샷에서 「🥭 망고아이」의 이모지에
빨간 동그라미를 치시고 「캐릭터를 Mr.mango로 바꿔줘」라고 지시하셨다.
CLAUDE.md 0장 — **Mr.mango(`/img/mango-char.png`)가 사이트 전용 캐릭터·공식 로고이고,
마스코트 자리에는 🥭 이모지를 쓰지 않는다**(2026-08-23 지시, `enroll.html` 부터 적용).

관리자 화면을 먼저 고쳐 배포(PR #470)한 뒤, 사장님이 「학생 홈도 바꿔줘」라고 이어
지시하셔서 학생 포인트샵까지 같은 규칙으로 맞췄다. 이 문서는 두 번째 건이다.

## 브랜드가 나오는 자리는 «셋» 이고, 그중 하나는 HTML 이 아니다

`js/idx-user-session.js` 에서 브랜드 문자열이 화면에 닿는 곳:

| 자리 | 함수 | 성격 |
|---|---|---|
| 상품 카드의 브랜드 칩 `.ps-brand` | `psLoadCatalog` | HTML |
| 교환 내역 줄 `.ps-hist-name` | `psLoadHistory` | HTML |
| **교환 확인 대화상자** | `psStartRedeem` 의 `prompt`/`confirm` | **글자만** |

세 번째가 함정이다. `prompt`·`confirm` 은 브라우저가 그리는 대화상자라 `<img>` 를 넣을 수
없다 — 태그를 넣으면 글자 그대로 `<img src=…>` 가 보인다. 그래서 판정 함수를 둘로 갈랐다.

- `psBrandHtml(b)` — HTML 자리용. 이모지를 16×16 Mr.mango `<img>` 로 갈아 끼운다.
- `psBrandText(b)` — 대화상자용. **이모지만 떼고 글자만** 남긴다.

## 검토했다가 버린 방법

**① D1 `gift_catalog.brand` 를 UPDATE 해서 이모지를 지우기** — 안 했다.
개발·운영이 같은 DB 라 실제 학생 데이터에 UPDATE 를 도는 것은 CLAUDE.md 1-1 금지다.
표시 계층에서 풀면 되돌리기도 쉽고, 관리자 화면(PR #470)과 같은 방식이라 일관된다.

**② 시드 문자열(`seedGiftCatalog`)을 `'망고아이'` 로 바꾸기** — 안 했다.
시드 멱등 검사가 `WHERE brand=? AND name=?` 라, 브랜드를 바꾸면 이미 있는 행을 못 찾아
**「수업료 전환」 상품이 한 벌 더 INSERT** 된다.

**③ 카드 큰 그림을 `/img/Mangoi_Character.png` → `/img/mango-char.png` 로 통일하기** — 안 했다.
둘은 같은 캐릭터이고 이미 Mr.mango 가 나오고 있다(이모지가 아니다). 그런데 `mango-char.png`
는 여백이 적은 «바짝 자른» 판이라 같은 104px 에 넣으면 캐릭터가 더 크게 그려진다 —
아래 ④의 잘림이 **더 심해진다**. 고치려면 `index.html` 의 CSS 를 건드려야 하는데 그쪽은
공동 금지구역이라, 지시 범위 밖에서 손대지 않았다.

**④ 휴대폰에서 카드 그림이 잘리는 것 고치기** — 안 했다(별건으로 보고만).
`@media(max-width:640px)` 가 `.ps-thumb{height:90px}` 로 줄이는데
`.ps-thumb-mango img{height:104px}` 는 그대로여서, **폰에서 캐릭터가 14px 잘린다**
(실측 390px: 그림 127×104 / 상자 172×90, `overflow:hidden` 이라 조용히 잘림).
이 변경 «전부터» 그랬고, 고치려면 `index.html` CSS 를 건드려야 한다.

**⑤ 칩 아이콘을 14px 로 두기** — 16px 로 올렸다.
12·14·16·18px 을 실제로 그려 놓고 비교했다. 14px 이하는 헤드폰·손이 뭉개져 «노란 덩어리»
로 보이고, 18px 은 10.5px 글자보다 커서 칩을 지배한다. 16px 이 알아볼 수 있으면서
칩 높이를 18→20px 밖에 안 늘린다.

## 밟을 뻔한 함정

- **`/g`(`/gu`) 정규식의 `.test()` 는 `lastIndex` 가 남는다.** 두 번째 호출에서 조용히
  거짓이 되어 «표를 다시 그리면 캐릭터가 사라지는» 형태로 터진다. 판정은 `indexOf` 로 했다.
- **`alt` 에 「망고아이」를 쓰면 안 된다.** `admin-inline-c.css` 2240행이
  `img[alt*="망고아이!"]` 를 `display:none` 으로 지운다(홈 히어로 배너용 규칙).
  관리자 쪽에서 먼저 걸린 함정이라 학생 쪽도 `alt="Mr.mango"` 로 맞췄다.
- **첫 화면 무게 예산.** `idx-user-session.js` 는 `defer` 가 없는 **blocking** 파일이라
  학생 29,000명이 첫 화면에서 통째로 받는다. 작업 시작 시점 여유가 **1,441바이트**뿐이었다.
  주석을 줄여 최종 **753바이트** 증가로 맞췄고, **남은 여유는 688바이트**다.
  그래서 「왜 이렇게 짰나」를 코드에 길게 적지 않고 이 문서로 뺐다(코드에는 두 줄 포인터).
  → ⚠️ **다음 사람에게**: 이 파일에 무언가 더할 때는 반드시
  `node test-harness/first_paint_budget_harness.mjs` 를 먼저 돌려 보라.
