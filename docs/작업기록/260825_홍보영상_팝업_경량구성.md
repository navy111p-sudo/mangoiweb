**안 누르면 0 바이트.**

## 3. 검토했다가 버린 방법

- **① 인트로 영상을 홍보영상으로 교체** — 이론상 가장 좋다(추가 무게 0, 첫 방문자 노출 100%).
  버린 이유는 **길이**다. 지금 인트로는 29초인데 새 영상은 1분 35초라 3배 오래 붙잡는다.
  20~30초 짧은 판이 먼저 있어야 하고, `idx-x1.js` 의 자막 9줄도 새로 맞춰야 한다.
  게다가 영상 교체는 R2 업로드(배포 권한)와 `index.html`(공동 금지구역) 한 줄이 필요하다.
  → **사장님이 짧은 판을 주시면 그때 하는 별건**으로 남긴다.
- **팝업의 `video_url` 에 영상을 직접 넣기** — 가장 쉬웠지만, 홈 팝업 렌더러가
  `<video preload="metadata">` 를 그린다. 영상을 볼 생각이 없는 학생에게도 앞부분이 내려간다.
- **영상 파일을 저장소(`public/video/`)에 커밋** — 배포마다 19MB 를 함께 올리게 되고,
  더 나쁜 것은 **Workers Assets 가 Range 를 무시**한다는 점이다(그래서 인트로는 R2 로 옮겼다).
  iOS 사파리는 구간 요청으로 재생을 시작하므로 큰 mp4 가 아예 안 나올 수 있다.
  → 업로드는 **R2(팝업 미디어)** 로 가고, 그 경로에 Range 를 붙였다.
- **새 API `/api/promo` 를 만들어 영상 주소를 알려 주기** — `src/index.ts` 세 곳 등록이 필요하다
  (인증 게이트·라우팅 허용목록·위임 가드). 공동 금지구역이라 안 건드리고, 주소는 `?src=` 로 넘긴다.
- **홈(`index.html`)에 배너를 직접 넣기** — 첫 화면 예산이 1562KB 로 **상한과 같아 여유 0**이다.
  그리고 공동 금지구역이다. 그래서 홈은 한 글자도 안 고쳤고, 연결은 **기존 팝업 시스템**이 한다.
- **우하단 토스트 팝업** — 그 자리에 AI 상담사 위젯(z-index 2147483000)이 있어 겹치면
  클릭이 위젯으로 간다. 피하려고 올리면 「수업 입장」 버튼을 가린다.

## 4. 일부러 이렇게 한 것

- 만들어지는 팝업은 **꺼진 상태**(`enabled:false`). 켜진 채로 만들면 확인 없이 학생 29,000명에게 뜬다.
- `?src=` 는 **같은 출처의 mp4/webm/mov 만** 받는다. `//evil.com/x.mp4`(프로토콜 상대 주소)도 막는다.
- 영상이 없거나 못 받으면 **검은 화면 대신 안내**를 띄우고 재생 버튼을 되돌린다.
- 포스터는 영상에서 뽑지 못했다(아래 5장) → **HTML 로 그려 크로미움 스크린샷**으로 만들었다.

### ⚠️ 확인하지 못한 것

**영상이 실제로 재생되는지는 이 환경에서 확인할 수 없습니다.** 컨테이너의 크로미움은
H.264 를 못 재생합니다(`canPlayType` 이 빈 문자열). 파일도 있고 서버도 200 을 주는데
`error` 가 나서 한참 헤맸고, CLAUDE.md 2장에 함정으로 적어 두었습니다.
**사람이 진짜 브라우저에서 한 번 눌러 봐야 끝난 것입니다.**
