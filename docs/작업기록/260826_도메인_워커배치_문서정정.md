## 4. 하니스 — «적어 두었는가» 를 «서로 같은 말을 하는가» 로 바꿨다

옛 검사는 이랬다:

```js
/test\.mangoi\.co\.kr[\s\S]{0,300}-prod/     // 도메인 근처에 «-prod» 라는 글자가 있는가
```

**거짓 문장이 오히려 이 검사를 통과했다.** 「`-prod` 워커입니다」라고 적혀 있었으니까.

이 하니스는 대시보드를 볼 수 없으므로 «사실» 은 판정할 수 없다. 대신 판정할 수 있는 둘로 바꿨다:

1. **근거 강제** — 코드 밖 상태를 적을 때 `(YYYY-MM-DD 대시보드 실측)` 를 문장에 박게 한다
2. **교차 대조** — `CLAUDE.md` · `MAINTENANCE.md` · `wrangler.toml` 세 곳의 배치 줄이 **같은 워커를
   지목하는지** 비교한다. 어긋나면 «사실» 을 몰라도 «하나는 틀렸다» 가 확정된다
3. **본문–배치 줄 대조** — 배치 줄이 «기본» 인데 본문이 「`-prod` 워커입니다」라고 단정하면 FAIL
   (= 8/19 사고의 정확한 형태)

### 되돌려서 실제로 잡히는지 확인했다

| 배치 줄까지 `-prod` 로 바꿔 세 곳을 어긋나게 함 | ❌ FAIL — 「세 곳이 같은 워커를 지목한다」 |

## 5. 검토했다가 버린 방법

- **`wrangler.toml` 에 `routes` 로 도메인을 못 박기** — ⛔ `routes` 는 «전체 목록» 이라 적지 않은
  도메인이 다음 배포에 지워진다(`mangoi.ai` 가 내려간다). 덤으로 `workers_dev` 가 `false` 로
  추론돼 `deploy.yml`(164·174행)·`deploy.ps1`(77행)·`deploy-full.ps1`(130행)이 깨진다.
  CLAUDE.md 2장에 이미 있는 금지 사항이라 그대로 지켰다.
- **하니스가 Cloudflare API 로 실제 배치를 조회하게 하기** — 토큰이 CI 에 없고, 하니스가 외부
  네트워크에 의존하면 오프라인에서 못 돈다. «세 곳 교차 대조» 로도 이번 사고는 잡힌다.
- **`test.mangoi.co.kr` 을 코드에서 일괄 치환** — 앱 시작 URL·스모크·워치독이 붙박이로 쓴다.
  별건이고 사람이 결정할 일이다.
- **문서에서 8/19 서술을 그냥 지우기** — 「왜 두 번이나 같은 사고가 났나」가 함께 사라진다.
  **틀렸다는 사실과 그 이유를 남기는 쪽**을 택했다.
