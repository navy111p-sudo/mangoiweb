# 교재 업로더 — 「001」 이라는 이름 없는 묶음이 생기던 것 수리 (2026-08-27)

> 브랜치 `claude/uploader-not-working-3b9rv4` · 파일 `cloudflare-deploy/public/textbook-uploader.html`

---

## 1. 왜 했나

「업로더가 안 된다」는 제보만 있고 증상 문구가 없었습니다. 그래서 **업로더가 정말 안 도는지부터**
브라우저로 확인했습니다(로컬 정적서버 + 컨테이너의 크로미움 + CDP 직접 구동 — 이 컨테이너에는
`node_modules` 가 없어 playwright 를 못 씁니다).

결과: **업로더는 «돕니다». 다만 교재 이름을 틀리게 붙입니다.**

```
넣은 폴더                          그전 교재명      고친 뒤
BTS 2/001/Slide1.JPG            →  001         →  BTS 2 001
BTS 2/002/Slide7.JPG            →  002         →  BTS 2 002
BTS 2/034/Slide7.JPG            →  034         →  BTS 2 034
BTS 3/001. Welcome/Slide1.JPG   →  001. Welcome →  BTS 3 001. Welcome
Phonics/A/Slide1.JPG            →  Phonics(*)  →  Phonics A
```
(*) 글자 폴더는 `RX.textbook` 의 길이 비교가 우연히 구제해 주고 있었습니다 — 숫자는 못 받았습니다.

### 뿌리

`classifyFile` 은 교재명을 **2단계 폴더명**에서 가져옵니다. 그래서 `001` 이 곧 교재 이름이 됩니다.
2026-08-14 에 「숫자 폴더를 유닛으로 인정해 **「BTS 2 001」** 로 만든다」는 규칙을 넣었고 주석에도
그렇게 적혀 있는데, 그 규칙은 유닛 번호를 **교재 이름에 없을 때만** 붙입니다:

```js
if (textbook && textbook.indexOf(unitLabel) < 0) textbook = textbook + ' ' + unitLabel;
```

교재 이름 자체가 이미 `001` 이라 `indexOf('001') < 0` 이 **늘 거짓** → **한 번도 붙지 않았습니다.**
즉 「고쳤다」고 적혀 있었지만 그 경로는 죽은 코드였습니다.

### 왜 반경이 넓은가

공용 자료실(서버)의 묶음 이름은 **파일명 앞 [대괄호] 하나뿐**입니다
(`js/idx-x3.js` `_serverFilesToBooks`). 업로더가 보내는 이름은 `[교재명] 레슨 / 파일명` 이고
**출판사는 안 실립니다.** 그래서

- **BTS 2 의 001 과 BTS 3 의 001 이 서버에서 같은 「001」 묶음으로 합쳐집니다.**
- 그런데 내 PC(IndexedDB)에서는 `publisher||textbook||level` 로 묶으므로 출판사가 달라 **갈라집니다**
  → 올린 사람 화면에서는 **멀쩡해 보입니다.** 이래서 발견이 늦습니다.

브라우저 실측으로 서버에 나가는 문자열을 직접 확인했습니다:
`[001] 제1과 / Slide1.JPG` → 고친 뒤 `[BTS 2 001] 제1과 / Slide1.JPG`.

### 사고를 «굳힌» 두 번째 원인 — 고칠 틈이 없었다

분류 결과 카드에는 교재명 입력칸이 있습니다(고칠 수 있게 만들어 둔 것). 그런데 ph241 자동 저장이
**2초 뒤 무조건 `btn.click()`** 이었고, 바로 위 `cr.scrollIntoView({behavior:'smooth'})` 가
카드를 화면에 들여오는 데만 0.5초쯤 씁니다. 즉 **이름을 읽을 시간조차 없었습니다.**
분류가 틀렸을 때 사람이 개입할 방법이 사실상 없었고, 틀린 이름이 그대로 쌓였습니다.

## 2. 검토했다가 버린 방법

| 버린 방법 | 왜 |
|---|---|
| **폴더 이름을 이렇게 쌓아라» 문서만 고친다** | CLAUDE.md 2장·`docs/중국어교재_과별_재업로드_절차_2026-08-26.md` 가 이미 이 함정을 «절차» 로 우회하고 있었습니다. 그런데 **업로더 화면의 팁은 여전히 옛 구조를 안내**하고, 문서를 안 읽은 사람은 그대로 밟습니다. 코드가 약속한 동작(주석)이 실제와 다른 것을 그냥 두는 것은 「하기로 한 것이 했다로 적힌」 그 문제와 같은 뿌리입니다 |
| **`RX.textbook` 의 길이 비교를 고친다** (`tbMatch[1].length > textbook.length`) | 글자 폴더가 우연히 구제되던 경로가 여기입니다. 하지만 이 비교는 **교재명 전체를 갈아치우므로** 정규식에 없는 교재(다락원 …)에서 무슨 일이 날지 예측이 어렵습니다. 사고 반경이 «교재 이름 전체» 라 손대지 않았습니다 |

| **대기 시간만 늘린다(2초 → 30초)** | 길게 두면 «폴더 하나 올리고 딴 일 하는» 흐름이 느려집니다. 8초 + **만지면 멈춤** 이면 «고칠 사람은 고치고, 안 만지면 그냥 올라간다» 가 됩니다 |
| **이미 DB 에 들어간 「001」 묶음을 고친다** | ⛔ 개발·운영이 같은 D1 이고 UPDATE 는 사람 승인 사항입니다(CLAUDE.md 1-1). 게다가 이 컨테이너는 D1 에 닿지 못해 **실제로 몇 건인지 세지도 못했습니다.** 정리 수단은 이미 있습니다 — `POST /api/admin/textbook-files/rebook`(dry_run 기본·본사 전용, 이름만 바꿈) |

## 3. 고친 것

### ① 유닛뿐인 2단계 폴더는 «책 이름» 이 아니다 (`classifyFile`)

```js
const unitOnlyPat = /^(\d{1,3}|[A-Za-z])(?:\s*[.\-_)]\s*.+)?$/;
// 2단계가 유닛뿐이면 → 상위 폴더 이름 + 그 폴더 이름
textbook = String(dirParts[0]).trim() + ' ' + d1;   // 「BTS 2 001」
```

- 네 자리(`2019` = 연도)는 **일부러 안 걸리게** 뒀습니다(2026-08-14 결정 유지).
- 「Mangoi Phonics A」처럼 이름이 함께 있는 폴더는 구분자가 없어 안 걸립니다
  → 그 폴더명이 권 이름이 되는 8/14 결정 그대로.
- 「제1과」·「Unit 1」은 기존 `lsnOnlyPat` 이 먼저 잡으므로 **다락원 교재 분류는 안 바뀝니다.**

### ② 자동 저장이 검토를 앞지르지 않게 (ph241)

- 2초 → **8초**, 버튼에 남은 초 표시
- **분류 카드를 만지면 멈춤**(`focusin`·`input`·`change`) — 리스너는 `wrap.__ph241Bound` 로 한 번만 묶음
  (이 함수는 업로드마다 다시 돌아 그냥 달면 리스너가 쌓입니다)
- 이미 저장된 뒤(`!pendingGroups.length || btn.disabled`)에는 **다시 누르지 않음**
  → 사람이 먼저 눌렀을 때 «✅ 저장 완료» 직후에 뜨던 **«⚠️ 저장할 교재가 없습니다»** 오알림 제거
- ❌ 취소가 카운트다운 타이머까지 끔

### ③ 완료 알림이 «어디까지 갔는지» 를 말하게

- 저장한 **교재 이름**을 적습니다(틀린 이름으로 들어갔는지 그 자리에서 알아채도록)
- **공용 자료실: 새로 N개 · 이미 있어 건너뜀 M개 · 실패 K개** 를 적습니다
  (그전에는 버튼 글자에만 있었는데, 알림을 닫는 순간 버튼이 되돌아가 아무도 못 읽었습니다)
- 공용 자료실에 **한 장도 못 올렸으면 머리글을 «완료» 라고 쓰지 않습니다**
  (403 경로에서 「이 컴퓨터에만 저장되었습니다」 바로 뒤에 「✅ 저장 완료!」가 또 떠서 앞말을 지웠습니다)

## 5. 재확인하지 못한 것 — 추론과 측정을 갈라 적음

- **측정한 것**: 브라우저에서 분류기가 `001` 을 교재명으로 내놓았고, 서버로 나가는 문자열이
  `[001] …` 이었다. 고친 뒤 `[BTS 2 001] …` 로 바뀌었다.
- **추론한 것**: 「그래서 운영 DB 에 이름 없는 묶음이 쌓여 있을 것이다」. **세어 보지 못했습니다** —
  이 컨테이너는 D1 에 닿지 못합니다. 확인은 다음 한 줄입니다:

```sql
SELECT substr(name,2,instr(name,']')-2) AS book, COUNT(*) n
FROM textbook_files WHERE active=1 AND name LIKE '[%'
GROUP BY book HAVING book GLOB '[0-9]*' ORDER BY n DESC;
```
