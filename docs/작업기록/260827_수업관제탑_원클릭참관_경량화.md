## 3. 「최대한 가볍게」를 어떻게 지켰나

사장님 추가 지시: 「관리자페이지가 너무 무거워지는 건 아니지? **끊김없이 안전하게** 진행하게
경량화하고 코드도 잘 정리할 수 있지?」

무게가 갈리는 지점은 사실상 **하나**였다 — 「전 방 영상을 상시로 트느냐」.

| 항목 | 무게 | 채택 |
|---|---|---|
| 방 목록·상태 타일 | JSON 몇 KB / 15초 | ✅ (기존 실시간 현황 카드가 이미 하던 일) |
| 품질 점수 표시 | 이미 쌓는 `vc_quality` 재사용 | ⏳ STEP 3 (미착수) |
| **전 방 영상 썸네일 상주** | 방마다 WebRTC 연결 = DO·강사 업로드 회선 부담 | ❌ **기각** |

지킨 방법 다섯 가지:

1. **admin.html(1.3MB)에 카드를 얹지 않았다** — 별도 한 파일 **18KB**(인라인 CSS/JS).
   `manager.html`(초경량 매니저 화면) 선례를 그대로 따랐다. admin.html 에는 진입 링크 한 줄만.
2. **탭이 숨겨지면 폴링이 멈춘다**(`document.hidden` 스킵 + `visibilitychange` 복귀 시 즉시 갱신).
   하루 종일 켜 두어도 서버·PC 부담이 없다.
3. **영상은 골라서만 연다** — 이상 신호가 색으로 뜨니 빨간 타일만 눌러 보면 된다.
   참관은 방당 동시 2명 제한이 있어 «상시 표시» 는 서버 쪽으로도 위험하다.
4. **새 서버 API 0개** — 기존 4개(`active-rooms`·`classes-now`·`alerts`·`live-classes`) 조합.
   화상수업 DO·`src/index.ts`(공동 금지구역)를 **한 줄도 건드리지 않았다.**
5. **학생 첫 화면 예산과 무관** — 관리자만 여는 별도 경로라 `first_paint_budget` 에 영향 0.

## 4. 검토했다가 버린 방법 ← 가장 중요

### ❌ 보다처럼 모든 방 영상 썸네일을 상시 표시
가장 «관제탑다운» 그림이지만, 방마다 WebRTC 연결이 상주해야 한다.
`src/video-call-room.ts`(공동 금지구역) 수정이 필요하고, mesh 구조라 **강사 업로드 회선이
관리자 수만큼 더 나간다** — 수업 품질을 직접 갉아먹는다. 사장님 요구가 「수업에 문제 없도록」
이었으므로 이건 요구와 정면 충돌한다. 목록+지표로 9할을 얻고 영상은 클릭 시에만 연다.

### ❌ admin.html 에 카드 하나 더 추가
가장 손이 적게 가지만 1.3MB 파일을 더 키운다. 8/8 「관리자 메뉴 간소화·경량화 제안서」
방향과도 반대다. 별도 페이지는 **admin.html 무게를 1바이트도 안 늘린다**.

### ❌ `/admin/monitor-wall.js` · `.css` 로 파일 분리
보통은 이게 «정리된 코드»지만 이 저장소에서는 **틀린다**. `src/index.ts` 의 `isAdminPath`
주석이 명시한다 — 「`public/admin/` 아래는 .html 뿐이라 로그인 게이트가 자산 로딩을 막지 않는다.
**새로 자산을 넣지 말 것.**」 넣었으면 로그인 게이트가 그 js/css 요청을 가로채
**화면이 조용히 반쪽**이 됐을 것이다. 그래서 인라인이 정답이고, 하니스 ②가 이를 못 박는다.

### ❌ `src/index.ts` 에 라우팅 등록
`/admin/` 은 `startsWith` **default-deny** 라 무등록이 맞다(2026-07-27 보안 근본수정).
CLAUDE.md 2장 「새 화면을 만들었는데 홈 화면이 뜸」 함정은 **확장자 없는 주소**에만 해당하고,
우리는 `.html` 을 그대로 쓰므로 걸리지 않는다. 금지구역을 안 건드리는 쪽을 택했다.

### ❌ 언어 키로 `localStorage['adminLang']` 사용 (한 번 썼다가 되돌림)
처음에 `adminLang` 키를 읽고 **쓰도록** 만들었는데 `trap-check` 가 🔴 로 잡았다.
그 키는 **저장소 어디에서도 `setItem` 하지 않는 죽은 키**이고, 대신 **읽는 코드가 9~10곳
잠들어 있었다**(`adm-ia6`·`adm-crumb`·`adm-s1` 등). 지금은 아무도 안 써서 전부 「항상 KO」로
자고 있는데, **관제탑에서 EN 을 한 번 누르는 순간 그 9곳만 깨어나 반쪽 언어 화면**이 된다.
→ 읽기는 정본 `mangoi_lang`, 토글은 **저장하지 않음**(화면 안에서만)으로 바꿨다.
이 발견이 별건 수리로 이어졌다: [260827_관리자언어_죽은키_adminLang_9곳수리.md](260827_관리자언어_죽은키_adminLang_9곳수리.md) (PR #570).

> 🪤 교훈: 내가 단 주석 「admin.html 과 같은 키(adminLang)」는 **사실이 아니었다**
> (admin.html 이 쓰는 것은 `window.adminLang` **변수**). 규칙서 2장의
> 「주석에 적힌 것 ≠ 실제로 그런 것」이 내 손에서 그대로 재현됐다.

### ❌ 「지금 진행 중인 수업이 없습니다」를 그대로 두기
비어 보이는 것이 사실은 「카페24에서 돌고 있다」는 정보다. 화면이 침묵하면 「오늘 한가하네」로
읽힌다(CLAUDE.md 2장에 이미 기록된 오독). 두 숫자를 **나란히** 놓아 갈라지는 것 자체를 정보로 만들었다.

### ❌ 카페24 수업도 참관되게 만들기
불가능하다 — 그 수업들은 망고아이 화상방을 열지 않으므로 참관할 «방» 자체가 없다.
넓히려면 수업을 망고아이 방으로 옮겨야 하고 이건 개발이 아니라 **운영 결정**이다.
화면에는 「참관 버튼이 생기지 않는 것이 정상」이라고 적어 두었다.
