### 2-3. 🔴 실제 결함 2건째 — 대체강사 배정이 **「요일 나열·한글 요일」 수업을 거절**하고 있었다

`enroll-ops.ts` 는 다른 도메인을 import 하지 않는 원칙이라, `NOT_PLACEHOLDER` 문자열을 복제해 둔 것과 같은 방식으로 같은 판정을 옆에 둔다.

### 2-4. 🔴 trap-check 서브에이전트가 **결함 2건을 더** 잡았다

브라우저로 못 보는 것을 규칙서 대조로 잡았다. 둘 다 실측 근거가 있다.

**① 🔄 버튼 클래스 이름이 «-btn» 으로 끝났다** — `class="tc-act tc-sub-btn"` 은 **속성값 전체가**
`-btn` 으로 끝나므로 `admin-inline-c.css` 의
`html[data-admin-theme="ivory"] [id^="card-"] [class$="-btn"]:not(…)×8` **(0,11,1)** 이
표 칩 규칙 `button.tc-act:not(…)×6` **(0,7,1)** 을 이긴다.

| | 🔄 대체(`tc-sub-btn`) | 👁 참관(`tc-act-observe`) |
|---|---|---|
| background | `rgb(255,255,255)` | `rgba(139,92,246,0.16)` |
| color | `rgb(52,64,84)` | `rgb(109,40,217)` |

즉 **혼자 흰 버튼**이었다. 그 파일이 9503·9710·9737 행에 「⛔ 클래스 이름을 «-btn» 으로 끝내지 말 것」을
**세 번** 적어 둔 바로 그 함정이다. `tc-sub-act` 로 바꿨다.
⚠️ 크기·패딩·인디고 그라데이션은 `.tc-act` 가 이겨서 정상이었기 때문에 **처음 브라우저 검사 45종은 통과했다** —
검사가 «옆 칩과 같은 계열인가» 를 안 봤기 때문이다. 그 검사를 추가했고, 되돌리면 흰색을 잡는 것까지 확인했다.

**② 요일 판정을 넓힌 것이 반쪽이었다** — `subScheduleDow`(「그 날짜에 열리나」)만 고쳤고, 정작
**«그 강사가 그 시간에 비었나» 를 보는 네 곳**은 그대로 `DOW[앞 세 글자]` 였다:
`enrollConflicts` · `busyTimesForTeacher` · `teachersFreeAt` · 긴 수업 하루 정원.

| day_of_week | 고친 판정 | 안 고친 네 곳 |
|---|---|---|
| `'4'` · `'Thursday'` | 4 ✅ | 4 ✅ |
| `'목'` · `'목요일'` | 4 ✅ | `'목'`·`'목요'` → **건너뜀** |
| `'1,3,5'` · `'Mon,Thu'` | 매칭 ✅ | `'1,3'`·`'mon'` → **누락·오판** |

⟹ 그런 반복수업을 가진 강사가 후보 목록에 **🟢(그 시간 가능)** 으로 나오고 충돌검사도 통과해
**이중배정**이 된다(에러 없음). 판정을 **`enrollDowList()` 한 곳**으로 모으고 네 곳이 전부 그것을 쓰게 했다.
나열은 여러 날을 다 돌려주므로, 그동안 조용히 빠지던 충돌(수강신청 쪽 포함)도 이제 잡힌다.

함께 수리한 것(같은 지적):

- `api-admin.ts` 의 **방어 CREATE 옆에 UNIQUE 인덱스**도 만든다 — 그쪽이 먼저 도는 새 DB 에서
  인덱스 없는 표가 생기면 UPSERT 가 「하루 한 명」을 못 지킨다.
- 오버레이 조회에 **원 수업의 `status='active'`** 추가 — 수업이 취소돼도 그 대체가 남아 다른 강사에게
  «그 시간 바쁨» 으로 잡히던 것.
- 대체강사 모달에 **`overflow-y:auto` + 자식 `margin:auto`** — 세로가 짧은 폰에서 맨 아래 [배정] 이
  잘려 못 눌리던 것(폰 390×640 검사 3종 추가).
- 구글폼 URL 의 **`ouid`**(폼 소유자 구글 계정 id) 제거 — 없어도 열린다.

**왜 필요했나** — 새 API 는 `/api/pay/enroll/admin/*` 이라 `src/index.ts` 의 스코프 차단

**어떻게 막았나 — 서버와 화면 둘 다** (한쪽만 두면 서버만: «눌러도 안 되는 버튼»이 남고,
