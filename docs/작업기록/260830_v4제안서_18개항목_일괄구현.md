## 2. 검토했다가 버린 방법

- **05 를 CSS 로만 덮기** — `.home-bright` 규칙 7곳을 미디어쿼리로 무력화하려 했으나
  «다크 기본값» 을 일일이 되살려야 해 깨지기 쉬웠다. 저장값을 바꾸는 쪽이 한 줄이고 확실하다.
- **06 을 새 API 경로로** — `/api/passkey/admin/*` 이 자연스럽지만 index.ts 의 정규식
  허용목록을 고쳐야 한다(금지구역). 같은 경로 + `scope` 로 갈랐다.
- **07 을 실제 화면 제어까지** — 만들지 않았다. 화면 제어는 Quick Assist·Chrome 원격
  데스크톱이 이미 하고 있고, 우리가 더할 값은 «허락 기록» 뿐이다.
- **12 에서 RBAC 역할 키(hq_exec/hq_mgr/…)를 6대로 개명** — `CARD_POLICY`·`.rbac-hide`·
  서버 스코프까지 전부 걸린다. **표시용 6대 역할**만 새로 만들고 권한 체계는 안 건드렸다.
- **15 에서 D1 의 teacher_id 를 «맞춰 넣기»** — 개발·운영이 같은 DB라 되돌릴 수 없다.
  번호를 잇는 것은 사람이 결정할 일이라, 코드는 «두 갈래를 다 보여 주는» 데까지만 했다.

## 3. 하니스를 고친 곳 — 왜 «검사» 를 바꿨나

`parent_attendance_source_harness` 는 옛 판정(`status==='attended'` 로 정시)을 문자열로
못 박고 있었습니다. 그 판정이 **실측상 틀린 것**이었으므로(0.06%), 하니스를 새 계약으로
다시 썼습니다 — 이제 문자열이 아니라 **정본 함수(`summarizeAttendance`)를 esbuild 로 번들해
실제로 돌립니다**(32건). 「못 잰 값을 0% 로 말하지 않는다」를 그 안에 못 박아 두었습니다.

⚠️ 부정 검사(옛 패턴 미복귀)는 **주석을 벗겨 낸 사본**으로 판정합니다 — 이 문서와 같은
설명 주석에 옛 패턴을 인용해 두면 검사가 자기 주석을 잡습니다(실제로 한 번 밟았습니다).
