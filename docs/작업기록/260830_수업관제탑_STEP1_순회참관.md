참관이 되는 모양이었습니다.

⚠️ **먼저 확인한 사실 하나** — 그 화면의 「지금 진행 중인 수업이 없습니다.」 문구는
**8월 27일 이전 코드에만** 있습니다(`d435595` 이후로는 「지금 망고아이 화상방에 접속해 있는
사람이 없습니다.」). 즉 8/27 에 넣은 원클릭 참관·관제탑이 **사장님 화면에 아직 안 보이는
상태**였을 가능성이 높습니다(캐시로 추정 — **단정 아님**, 확인법은 5절).
그래서 이번 작업은 「없는 것을 만드는 일」이 아니라 **「있는데 안 쓰이는 화면을 쓸 만하게
만들고 입구를 늘리는 일」** 로 잡았습니다.

두 번째로 보내주신 **보다(Voda) 「모니터링 > 개설된 룸 목록」** 화면을 기준으로 대조했습니다.

## 2. 무엇을 했나

### 2-1. 관제탑을 「보다식 표」로 (`public/admin/monitor-wall.html`)

- **표 + 열**: 상태 / 시각 / 수업(강사·학생) / 강의실 / 인원 / 회선 / 액션
- **검색칸** — 강사·학생·방 번호·참가자 이름 어디에 걸려도 걸러집니다
- **정렬** — 심각한 것부터(기본) · 시작 시각 · 인원 · 이름
- **자동 새로고침 주기** — 안함 / 10 / 15 / 30 / 60초 (고른 값은 그 브라우저에 기억)
- **줄마다 버튼 3개** — 👁 참관 · 🚪 입장(보임) · 🛑 종료
- **회선 신호등** — 최근 5분 RTT·손실을 🟢🟡🔴 로. 표본이 없으면 **«—»**
- **맨 위 상태등** — 예약 수업 수 · 화상방 수 · 이상 알림 · **영상 중계(TURN) 정상/이상**
- **강사 계정 차단** — `classes-now` 가 `forbidden_teacher` 로 답하면 **목록 자체를 안 그립니다**

### 2-2. 🔁 순회 참관 (보다에 없는 것)

창 하나가 정해진 초(15/20/30/60)마다 **방을 옮겨 다닙니다.** 10개 반이면 20초씩 3분 20초에
한 바퀴. 탭을 여러 개 열 필요가 없습니다.

- 조작: **⏸ 이 방에 머물기 · ⏭ 다음 방 · ⏹ 정지**, 현재 위치와 남은 초를 표시
- **방을 옮길 때마다 참관 기록을 남깁니다** — 기록 없이 들어가는 길은 만들지 않았습니다
- 사람이 그 창을 닫으면 순회도 멈춥니다

### 2-3. 입구 3곳

| 자리 | 파일 |
|---|---|
| 사이드바 「오늘 ▸ 수업 관제탑」 | `js/adm-ia6.js` (`?v=52`) |
| ⚡ 자주 쓰는 기능 「수업 관제탑」 | `js/adm-quick-access.js` (`?v=14`) |

### 2-4. 서버 — 새 «경로» 는 만들지 않았습니다

`GET /api/admin/vc/quality` 에 **`?live=1&mins=5` 모드**만 더했습니다(방 단위 집계).
새 경로가 아니라 이미 관문 3곳에 등록된 `/api/admin/vc/` 밑이라 **등록 누락 404 함정**에
걸리지 않습니다(실측: `index.ts:421`·`1253`, `api-mango.ts:1456`).

## 4. 밟은 함정 (다음 사람을 위해)

1. 🔴 **`window.open(url, '_blank', 'noopener')` 는 «null 을 돌려줍니다»** (웹 표준).
   순회 참관은 그 창의 주소를 계속 바꿔야 하는데, 처음에 공용 헬퍼(`openTab`)를 그대로 쓰면
   **창은 열리는데 손잡이가 없어** 순회가 통째로 죽습니다 — 에러도 안 납니다.
   → 순회용 창만 `window.open('about:blank', 'mangoiObserveRotate')` 로 이름을 주어 엽니다.
   감시는 `monitor_wall_harness` ⑬.
2. **사이드바 `href` 항목은 역할 필터를 못 받습니다** — 강사·지사에게도 칸이 보입니다.
   그래서 **화면이 스스로 막게** 했습니다(`forbidden_teacher` → 목록 미표시).
   덤으로 주소를 직접 아는 강사도 이제 목록을 못 봅니다.
3. **회선 평균에 음수 손실(-1)을 넣으면 안 됩니다** — 그건 «영상이 없던 틱» 이라,
   넣으면 **영상이 죽은 방이 «회선이 제일 좋은 방»** 이 됩니다. 서버 집계에서 `avg_loss >= 0`.
4. **`novideo` 칸은 `ALTER` 로 나중에 붙은 것**이라 첫 로그 전에는 없습니다 — 읽지 않았습니다.
5. **카운트를 못 박은 하니스 둘이 함께 깨졌습니다** — ⚡ 자주 쓰는 기능(11→12개)과
   사이트 구성표(중분류 45→46). 둘 다 «사이드바와 다른 곳이 같은 말을 하는가» 를 지키는
   검사라, 검사를 끄지 않고 **구성표에 항목을 실제로 추가**하고 개수를 맞췄습니다.
6. **CDP `/json/new` 로 새 탭을 만들면 페이지 스크립트가 안 돕니다**(이 컨테이너).
   `/json/list` 로 기존 탭을 잡아 `Page.navigate` 해야 합니다 — 안 그러면 멀쩡한 화면을
   「JS 가 죽었다」로 오진합니다.
