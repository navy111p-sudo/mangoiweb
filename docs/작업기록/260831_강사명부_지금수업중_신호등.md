## 1. 왜 했나

사장님이 **강사 명부 화면 스크린샷**과 함께 제보하셨습니다.

> 「수업 관찰 들어가려고 하는데 어떤 강사가 수업 중인지 아닌지를 모르겠어」
> → 이어서 「현재 수업중인 강사를 확인해서 수업관찰 들어가려고 하는데
>   **계속 눌러볼 수 없고 바로 전체에서 확인** 할 수 있는 방법이 있을까?」

스크린샷에는 `mangoi.ai` 경고창 **「지금 진행 중인 수업이 없습니다. (수업이 시작되면 이
버튼으로 바로 관찰할 수 있습니다.)」** 가 떠 있었습니다.

그 문구는 고장이 아니라 **정상 동작**입니다. 강사 명부 액션 열의 👁 버튼(`tpGhostObserve`,
2026-08-30 v4 제안서 09)은 **누른 뒤에야** `/api/admin/classes/today` 를 불러 그 강사의
수업을 찾습니다. 즉 명부에는 «지금» 을 말해 주는 표시가 **한 칸도 없었고**, 수업 중인
강사를 고르려면

> 눌러본다 → 「없습니다」 → [확인] → 다음 강사 → …

를 **강사 수만큼** 반복해야 했습니다(실측 명부에 강사 30명 안팎).

⚠️ **먼저 확인한 사실** — 「전체를 한 표로」 자체는 **이미 있었습니다.**
`/admin/monitor-wall.html`(수업 관제탑, 2026-08-27 신설 → 8/30 STEP 1 + 순회 참관)이
열린 방 전부를 표로 보여주고 줄마다 참관·입장·종료까지 합니다. 입구도 셋입니다
(사이드바 «수업·콘텐츠 ▸ 수업 관제탑» · 자주 쓰는 메뉴 · `admin.html` 두 곳).
그래서 이번 작업은 **「없는 것을 만드는 일」이 아니라 「명부에서 강사를 고르는 사람에게도
그 사실을 보여주는 일」** 로 잡았습니다. 두 화면은 쓰는 사람이 달라 **둘 다 남깁니다.**

사장님께 세 갈래(관제탑 안내만 / 신호등만 / 신호등 + 필터)를 물었고
**「명부에 신호등 + 「수업 중만 보기」」** 로 결정하셨습니다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

### ① 🟢/🟡 를 한 색으로 합치기 → **버림**

`/api/admin/classes/today` 의 `join_open` 은 «들어갈 수 있는 시간대»(정규 수업 시작 10분 전
~ 종료 15분 후, 레벨테스트는 30분 전)이지 **«실제로 접속해 있다» 가 아닙니다.**
한 색으로 합치면 화면이 **모르는 것을 아는 척**하게 됩니다. 그래서 `/api/active-rooms` 를
겹쳐 보고 «방이 실제로 열렸나» 를 따로 표시합니다.

### ② 카페24 수업을 「수업 중」에 함께 넣기 → **버림**

`c24-*` 방은 망고아이 화상방이 아니라 **참관이 구조적으로 불가능**합니다(전 기간 실접속 0건).
「수업 중」으로 표시하면 CLAUDE.md 2장의 **「배지는 있는데 눌러도 안 되는 버튼」** 이 그대로
재현됩니다. ⚪ 로 갈라 놓고 **툴팁이 이유를 말하게** 했습니다.

### ③ 「수업 중만 보기」에서 카페24를 빼기 → **버림**

거르면 그 강사가 명부에서 사라져 «한가하다» 로 읽힙니다. **남기고 배지로 구분**합니다.

### ④ 강사 번호(id)로 수업 잇기 → **버림**

강사 번호는 세 벌입니다 — 카페24 9~196 · 원부 `teachers.id` 1~29 · 프로필 4~37.
**겹치는 자리에서 서로 다른 사람**이라(카페24 24 = Teacher Mariane, 원부 24 = HANNAH)
번호로 이으면 조용히 **남의 수업이 «수업 중» 으로** 뜹니다. 에러도 안 납니다.
→ **이름 완전일치만**(`_tpNormName`), 못 찾으면 «—». 추측하지 않습니다.

### ⑤ 새 API 만들기 → **버림**

필요 없었습니다. 다만 **강사 수만큼 부르지 않는 것**이 중요해서 조회를 «표당 한 번» 으로
모았습니다(👁 를 30번 누르면 30번 부르던 것과 대비).

### ⑥ 관제탑을 안내만 하고 끝내기 → **버림**

관제탑은 «전체 현황을 보는 사람» 의 화면이고, 사장님이 계셨던 곳은 «강사를 고르는» 화면입니다.
같은 사실을 두 화면이 각자 필요한 모양으로 보여 주는 편이 맞다고 판단했습니다(사장님 결정).

### ⑦ 표를 45초마다 다시 그리기 → **버림**

행을 갈아치우면 **조준한 👁 버튼이 마우스 아래에서 움직입니다**(2026-08-12 방 목록에서
실제로 났던 사고). 그래서 **칸만 칠하고**, 마우스가 표 위에 있으면 아예 건드리지 않습니다.

## 4. 밟지 않으려고 조심한 함정 (CLAUDE.md 2장)

| 함정 | 이번에 한 것 |
|---|---|
| 카드 안 글자를 `#101828 !important` 가 덮음 | 배지 색을 **인라인 `!important`** 로 (`color:#16a34a !important`) |
| 아이콘 버튼에 `data-ko`/`data-en` → 34px 상자에 문장이 들어앉음 | 👁 설명은 **`data-ko-title`/`data-en-title`** 로만 |
| JS 로 그린 라벨이 🌐 를 안 따라옴 | 배지·요약·토글에 **그릴 때 `data-ko`/`data-en` 을 함께 박음** |
| `mangoi:lang-changed` 가 안 불림 | 관리자 화면은 **`document`** 발행 + `bubbles:false` → **document·window 둘 다** 청취 |
| body class MutationObserver·상주 폴링 (홈 정지 전력) | 안 씀. 45초 타이머에 가드 넷(`off` · `document.hidden` · 카드 닫힘 · 마우스) |
| 404 가 「Not Found」로 안 보임 (`ok` 칸 없음) | **«성공이라고 말했는가»**(`r.ok && d.ok === true && Array.isArray(d.sessions)`)로 판정 |
| 표 검색창이 두 개 | `tp-list-table` 은 `ph-frn-filter-js` 의 `TABLES` 목록에 **없음**을 확인 |
| 그리드 칸이 내용보다 안 작아져 가로 넘침 | 칸을 하나 늘린 뒤 `documentElement.scrollWidth <= innerWidth` 를 **실제로 잼** |
| `?v=` 를 안 올려 옛 파일이 캐시에 남음 | `adm-core.js?v=180` + `test-harness/asset-versions.json` **함께 커밋** |

그 밖에 판단한 것:

- **조회가 실패하면 직전 값을 그대로 둡니다** — 지우면 멀쩡한 수업이 화면에서 사라집니다.
- **403(강사·지사 계정)이면 «모른다» 고 적고 다시 묻지 않습니다**(`_TP_LIVE.off`).
  조용히 «수업 없음» 으로 그리면 그것이 거짓말이 됩니다.
- `/api/active-rooms` 만 실패하면 🟡 로 떨어집니다(예약 정보는 살아 있음).
