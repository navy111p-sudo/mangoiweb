## 1. 왜 했나

사장님 「목소리는 바뀌었는데 얼굴이 안 바뀌었어」 · 「lily와 Noah 얼굴이 안바뀌었어」 ·
「아직도 얼굴이 iliy와 noah가 바뀌지 않는 이유가 뭐지????」 — **같은 제보가 세 번** 왔습니다.

원인은 코드가 아니라 **파일 누락**이었습니다. 캐릭터 표(`CHARACTERS`)는 새 얼굴을
가리키는데 그림이 저장소에 없어서, 화면이 설계대로 **조용히 폴백**(옛 성인 얼굴)으로
돌아가고 있었습니다. 404 도 에러도 안 나므로 「안 바뀌었네」로만 보입니다.

⚠️ **이 조용함이 문제의 핵심입니다.** 폴백은 「얼굴 자리가 빈 카드로 남는 것이 제일 나쁘다」는
판단으로 일부러 넣은 것이라 그 자체는 옳습니다. 다만 그것 때문에 **누락이 사고로 보이지
않았고**, 저는 세 번째 제보를 받고서야 「파일이 없다」를 확인했습니다.

## 2. 검토했다가 버린 방법

| 버린 것 | 왜 |
|---|---|
| **제가 배경을 직접 지워서 만들기** | 플러드필 배경 제거가 Lily 의 크림색 스웨터와 피부까지 갉아먹었습니다(tolerance 14). «투명 픽셀 80%» 라는 숫자로는 멀쩡해 보였고 **눈으로 보고서야** 알았습니다. 사장님이 Higgsfield 로 만든 투명본을 쓰는 것이 맞습니다 |
| **PNG 로 넣기** | 640×800 PNG 가 장당 600KB → 한 친구당 1.8MB 를 학생이 받습니다. 필리핀 회선을 지키는 이 저장소 원칙에 어긋납니다 |
| **팔레트 양자화(256색) PNG** | 600KB → 85KB 로 줄지만 **피부에 심한 얼룩**이 생깁니다. 확대해 보고 버렸습니다 |
| **파일명은 .png 로 두고 내용만 webp** | Content-Type 이 어긋납니다. 브라우저가 대개 알아보지만 «조용히 다르게 동작하는» 자리를 만들 이유가 없습니다 |
| **입모양 3장을 한 장씩 따로 자르기** | 입이 바뀔 때마다 얼굴이 흔들립니다. 세 장의 알파 경계 **합집합**으로 같은 좌표계를 잡았습니다 |
| **채팅으로 받은 사본 쓰기** | 사장님이 GitHub 에 올려 주신 원본(1856×2304)을 나중에 발견했습니다. 채팅본(1611×2000)은 손실 압축을 한 번 거친 사본이라 **원본에서 다시 뽑았습니다** |

## 3. 한 것

- **`/img/{lily,noah}-{closed,mid,wide}.webp`** — 640×800(카드 비율 4:5) 투명 WebP,
  장당 44~67KB. WebP q=86 은 확대해도 원본과 구별되지 않습니다.
- 표 경로를 `.png` → `.webp`, 세 화면의 `?v=15` → `?v=16`.
- 사장님이 올리신 원본 PNG 12장(약 79MB) 정리 — **승인을 받고** 지웠습니다.
  그중 7장(48MB)은 `public/img/` 라 매 배포마다 실서비스로 올라가고 있었습니다.
  깃 이력(`409bd76`·`000a337`·`9b5651f`)에 남아 있어 언제든 되살릴 수 있습니다.

## 4. 재발 방지 — 세 가지

1. **자동 하니스가 「표가 가리키는 그림이 저장소에 실제로 있는가」를 검사합니다**(+300KB 이하).
   ⛔ `fallback` 이 있다고 이 검사를 빼면 안 됩니다 — 폴백은 «런타임 사고» 대비,
   이 검사는 «커밋 누락» 대비로 **서로 다른 방어**입니다.
2. 브라우저 하니스가 그림을 치우는 곳을 **`public/` 밖(OS 임시폴더)** 으로 옮겼습니다.
   `deploy.ps1` 은 `public/` 을 통째로 올리므로, 하니스가 중간에 죽은 상태로 배포가
   나가면 «얼굴 없음 + 쓰레기 업로드» 가 실서비스로 갑니다. 게다가 `.gitignore` 가
   `public` 밑의 `.bak` 을 무시해서 「git status 에 보이니 괜찮다」는 전제 자체가 틀렸습니다.
3. 비율 검사가 **아무것도 못 가르는 상태**였습니다 — 그림이 640×800 = 정확히 0.8 이고
   선언값도 0.8 이라 `setAspect` 가 안 돌아도 통과합니다. 비율이 다른 캐릭터
   (jake 512×496 = 1.03)로 바꿔 캔버스가 실제로 움직이는지 함께 봅니다(실측 0.8 → 1.032).

- **로컬 브라우저에 실제로 그려서 눈으로 확인** — 얼굴이 Lily·Noah 로 바뀌고,
  말할 때 입모양 3장이 번갈아 쓰이고, 얼굴이 흔들리지 않습니다
- 타입체크는 이번에 `.ts` 를 한 개도 안 고쳤고 이 컨테이너에 `node_modules` 가 없어
  **돌리지 못했습니다** — 환경 사유이지 코드 판정이 아닙니다
- ⏳ **배포된 실제 화면은 못 봅니다**(프록시 차단). 화면이 바뀌는 작업이라
  **사장님이 한 번 보셔야 끝난 것**입니다. 옛 `?v=15` 가 immutable 캐시라
  안 바뀌어 보이면 새로고침이 필요할 수 있습니다.

## 6. 그밖에 밟은 함정

- **주석 안에 route glob 을 적어 블록주석이 거기서 닫혔습니다** — 별표+슬래시.
  CLAUDE.md 2장이 이미 못 박아 둔 것을 그대로 밟았고, `node --check` 가 잡았습니다.
- **부정 검사가 자기 주석을 잡는** 형제 함정도 앞선 PR 에서 밟았습니다
  (CSS 주석의 홑낫표 → 한자 폰트 검사 FAIL).
