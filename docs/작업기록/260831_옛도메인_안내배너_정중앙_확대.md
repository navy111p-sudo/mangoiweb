# 옛 도메인 안내 배너 — 화면 정중앙 · 약 3배 크게 (2026-08-31)

## 1. 왜 했나

사장님이 `test.mangoi.co.kr` 화면 사진을 주시며 「이거 안내 문자를 중앙에, 지금보다 3배 더 크게 만들어줘. 그게 더 잘 보일 것 같아」.

그 배너는 2026-08-28 에 넣은 «옛 주소로 들어왔다» 안내(`js/idx-legacy-domain-notice.js`)이고,
그때는 **우상단 320px 짜리 작은 카드**였습니다. 사진에서 보이듯 화면 오른쪽 위 구석이라
큰 우주 배경 그림에 묻혀 눈에 안 들어옵니다 — 그래서 옛 주소로 계속 들어오는 사람이 그대로 남습니다.

⚠️ 이 배너를 **없애면 안 되는 이유**는 그대로입니다(CLAUDE.md 0장): `test.mangoi.co.kr` 을
`mangoi.ai` 로 리다이렉트하면 그 도메인에 등록된 **패스키 6건이 무효화**되고 앱 사용자의
`localStorage` 로그인이 날아갑니다. 그래서 「인지만 시킨다」가 2026-08-28 결정이고,
「바로가기」 링크도 일부러 안 둡니다. 이번에도 그 결정은 건드리지 않았습니다.

## 2. 무엇을 했나

| | 전 | 후 |
|---|---|---|
| 자리 | 우상단 `top:16px;right:16px` | **화면 정중앙**(`left/top:50%` + `translate(-50%,-50%)`) |
| 상자 폭 | 320px | `min(780px, 92vw)` |
| 제목 | 13px | `clamp(21px,4.6vw,38px)` → PC **38px** · 폰 21px |
| 본문 | 12px | `clamp(15px,3.4vw,27px)` → PC **27px** · 폰 15px |
| 배경 | `rgba(15,23,42,0.72)` | `rgba(15,23,42,0.94)` |
| 닫기 | ✕ 버튼 | ✕ · **상자 아무 데나 탭** · touchend · 같은 id 를 전부 제거 |

- 배경을 진하게 한 이유: 가운데는 홈 첫 화면의 **밝은 우주 영상 위**라 0.72 로는 글자가 그림에 섞입니다(제목 대비비 실측 12.38).
- 폰 세로에서 상자가 화면을 넘지 않도록 글자를 전부 `clamp` 로 줬습니다(고정 큰 값 금지).

## 3. 검토했다가 버린 방법

1. **글자만 키우고 자리는 우상단 유지** — 우상단은 칩 한 줄(`#ph50-chip-row`: 밝기·포인트·EN·관리자)이
   있는 자리라, 크게 만들수록 그 줄을 덮어 「보이는데 안 눌린다」가 됩니다(2026-08-30 에 그 사고로
   회피 로직을 넣었던 자리). 무엇보다 사장님이 원한 것은 «가운데» 입니다. → 버림
2. **z-index 를 올려 A.i 상담사 위젯·➕ FAB 위로** — 폰 가로에서 그 둘 밑에 깔리는 문제를
   z-index 로 풀 수 있지만, CLAUDE.md 2장이 못 박습니다: `#mg-fab-wrap`(2147483200)·
   `#vc-reconnect-banner`(2147483646)는 **이 배너보다 위에 있어야** 합니다(재연결 안내가 가려지면
   수업이 끊긴 것을 모릅니다). → 버리고 **«비켜서는 쪽은 배너»** 로: `@media (max-height:520px)` 에서
   상자를 `min(560px,84vw)` 로 줄이고 글자도 한 단계 낮춥니다.
3. **자동으로 사라지는 타이머(20초)** — CLAUDE.md 2장 「닫아도 안 사라짐」 함정이 안전망으로 권하는
   ④번입니다. 그런데 이 배너는 «인지시키는» 것이 전부라 못 본 사이에 사라지면 취지가 없어집니다.
   → 대신 **닫는 길을 넷으로** 늘려 「안 닫히는」 쪽만 막았습니다(그 판단을 파일 주석에 적어 뒀습니다).
4. **`place()`/`TOP_SEL`(우상단 칩 회피) 유지** — 가운데로 옮긴 순간 그 줄과 겹칠 일이 없어져 지웠습니다.
   ⚠️ 다시 우상단으로 되돌린다면 **그 회피 로직도 함께 되살려야** 합니다 — 파일 머리말과
   CLAUDE.md 그 항목에 각각 적어 뒀습니다.

## 4. 새로 밟은 함정 (CLAUDE.md 2장에 추가)

**「화면 한가운데에 있는가」를 `innerWidth` 로 재면 정중앙인데도 FAIL 이 납니다.**
`position:fixed` 요소의 기준은 «초기 컨테이닝 블록» 이라 **세로 스크롤바 폭(15px)만큼 좁습니다** —
1280 창에서 정확히 가운데 놓은 상자의 중심이 **632.5**(=(1280−15)/2)로 나옵니다.
`document.documentElement.clientWidth` 로 바꿔도 안 됩니다(헤드리스에서는 1280 으로 나옵니다).
✅ 같은 조건의 «자»(`position:fixed;left:0;right:0;top:0;bottom:0` 인 빈 div)를 잠깐 놓아 재고 치웁니다.
