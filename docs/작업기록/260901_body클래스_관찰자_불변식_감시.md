## 3. 🔬 브라우저에서 직접 재서 «아무도 안 적어 둔 것» 을 찾았습니다

임시 HTML 을 만들어 관찰자 발화 횟수를 셌습니다.

| 호출 | 관찰자 발화 |
|---|---|
| `remove(없는 토큰)` | **1회** (저장소가 아는 것) |
| **`add(이미 있는 토큰)`** | **1회** ← **아무도 안 적어 둠** |
| `toggle(토큰, force)` 상태 그대로 | 0회 |
| `contains` 로 막은 remove | 0회 |

규칙서·소스 주석은 **`remove()` 만** 경고하고 있었습니다. `add()` 도 똑같이 위험합니다.

ℹ️ DOM 명세와도 일치합니다 — `add`/`remove` 는 토큰이 안 바뀌어도 update steps 를 돌려 속성을 다시 set 하고, `toggle(token, force)` 는 상태가 같으면 그 전에 return 합니다. (`js/mango-worldclock.js` 주석에 toggle 쪽은 이미 독립적으로 적혀 있었습니다 — 그쪽은 «새 발견» 이 아니라 «재확인» 입니다.)
