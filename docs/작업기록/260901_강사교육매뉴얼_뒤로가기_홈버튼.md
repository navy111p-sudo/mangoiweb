# 강사 교육 매뉴얼 — 뒤로가기·홈 버튼 (2026-09-01)

## 1. 왜 했나

같은 날 「나가는 문」 전수 점검에서 `teacher-training.html`(강사 교육 매뉴얼 v3.0)이
**뒤로도 홈도 없는** 화면으로 나왔습니다. 그때는 「학습 화면이 아니라 강사 화면」이라
범위 밖으로 남겨 두었는데, 사장님 「teacher-training.html도 뒤로가기 홈버튼 넣어줘」.

이 화면으로 들어오는 길은 **`teacher.html`(강사 화면)과 `js/adm-p1.js`(관리자 화면)** 이고,
들어오면 **나갈 길이 하나도 없었습니다**(드로어도 공용 바도 안 싣습니다).

## 2. 이 화면은 앞의 것들과 조건이 달랐습니다

| | 이 화면 | 그래서 |
|---|---|---|
| 공용 i18n(`mango-i18n.js`) | ❌ 안 싣는다 | 우상단 [🏠 홈][🌐 EN] 바가 없다 → 홈이 아예 없었다 |
| `data-ko`/`data-en` | **0건** | 그 방식으로 라벨을 달면 번역이 안 된다 |
| 자체 사전 | `T.ko`/`T.en` + `renderAll()` 이 id 로 `textContent` 를 그린다 | 라벨을 그 사전에 넣고 `renderAll` 에서 갱신해야 한다 |
| `lucide-local.js` 아이콘 | **6종뿐**(download·edit-3·file-text·layout-grid·printer·sheet) | 화살표·집 아이콘이 없다 → 글자(←·🏠)로 |
| 헤더 | `header.tt-head.tt-no-print`, 문서 흐름 안 sticky | 고정 버튼을 띄우는 대신 **헤더 안**에 두는 것이 맞다(인쇄 매뉴얼이라 `tt-no-print` 로 인쇄물에서 자동 제외) |

## 3. 무엇을 했나

- 헤더 왼쪽(`.tt-head-in` 의 첫 자식)에 `<nav class="tt-nav tt-no-print">` 로
  **[← 뒤로][🏠 홈]** 을 넣었습니다. 모양은 이 화면의 토큰(`--tt-line`·`--tt-o-l`·`--tt-o-d`)으로.
- **뒤로 판정은 복제하지 않고 정본**을 부릅니다 — `window.mangoiGoBack`(`js/back-nav.js`).
  `else{location.href='/'}` 는 판정이 아니라 안전망입니다(그 파일이 defer 라 아직 안 왔거나
  캐시에 옛 사본일 때 «홈으로는 간다»). 홈은 `<a href="/">` 라 네이티브 폴백이 있습니다.
- 라벨은 사전 두 벌에 `navBack`·`navHome` 을 더하고 `renderAll()` 에서 갱신합니다
  (KO 「뒤로」·「홈」 / EN 「Back」·「Home」). 안 그러면 언어를 바꿔도 한국어로 남습니다.
- `back-nav.js` 를 안 싣고 있어 한 줄 추가했습니다. ⚠️ 헤더에 보이는 ← 가 있으므로
  그 파일은 **자기 동그란 ← 를 넣지 않습니다**(`hasVisibleBack`) — 화살표가 둘이 되지 않습니다.

## 4. 🔴 밟은 것 — sticky 헤더가 64 → 112px 로 커졌습니다

항목이 셋(나가는문·브랜드·도구)이 되자 **768px 에서 도구 줄이 두 번째 줄로 밀려**
헤더가 64 → **112px** 이 됐습니다. sticky 헤더라 그만큼 본문이 **늘** 가려집니다.

실측으로 원인을 셌습니다 — 컨테이너 753px vs 항목 합 82+250+413 + 간격 24 = **769px**
(16px 부족). 그래서 **그 폭에서만** 라벨을 접고(`≤1024px`) 나가는 문의 여백·헤더 간격을
줄여 맞췄습니다(여유 10px). ⛔ 브랜드·도구는 건드리지 않았습니다.

또 `.tt-head-in` 이 `justify-content:space-between` 이라 항목이 셋이 되면 **브랜드가
가운데로 밀립니다** → `flex-start` + `.tt-head-tools{margin-left:auto}` 로 바꿨습니다
(이 저장소가 flex `space-between` 으로 라벨이 밀린 사고를 이미 겪었고, 권장 패턴이 이것입니다).

✅ 결과: **헤더 높이가 변경 전과 모든 폭에서 동일**합니다 —
390·430=94 · 700=94 · 760·768·860·1023·1024·1280=64 (변경 전과 하나씩 대조).

## 5. 검토했다가 버린 방법

| 버린 방법 | 왜 |
|---|---|
| 공용 바(`mango-i18n.js`)를 싣기 | 이 화면은 **자체 언어 토글**을 갖고 있고(`data-mangoi-lang-toggle`) v2.0 에서 언어 버튼이 두 벌 뜬 전력이 주석에 적혀 있습니다 |
| `position:fixed` 로 화면에 띄우기 | 인쇄 매뉴얼입니다. 헤더는 `tt-no-print` 라 인쇄에서 자동으로 빠지는데, 고정 버튼은 따로 챙겨야 하고 sticky 헤더와도 겹칩니다 |
| lucide 아이콘 사용 | 이 화면 로컬본에 **6종뿐**이라 화살표·집이 없습니다. 없는 이름을 쓰면 콘솔 경고 한 줄만 남고 **자리가 조용히 빕니다** |
| `data-ko`/`data-en` 로 라벨 달기 | 이 화면에는 그 사전이 **0건**입니다(자체 `T` 사전을 씁니다) |
| 768px 에서 두 줄을 그냥 두기 | sticky 헤더가 48px 커지면 본문이 계속 가려집니다. 사장님이 요청한 것은 «버튼 추가» 이고 헤더 재배치가 아닙니다 |
| 브랜드 글자·도구를 줄여 자리 만들기 | 이 화면 디자인을 손대는 일이 됩니다. 나가는 문 쪽만 줄여 맞췄습니다 |
