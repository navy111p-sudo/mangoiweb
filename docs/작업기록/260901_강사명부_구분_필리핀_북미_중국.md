# 강사 명부 — «구분» 칸 (필리핀 · 북미 · 중국)

- **날짜** 2026-09-01
- **지시** 사장님 — 「국가 추가해서 **필리핀, 북미, 중국**, 이렇게도 나눠줘」 / 「**구분칸 추가해줘**」
  (스크린샷에서 「전체 그룹」 드롭다운 옆자리를 빨간 동그라미로 짚어 주셨습니다)
- **이어지는 작업** 같은 날 [PR #657](https://github.com/navy111p-sudo/mangoiweb/pull/657)
  「상태를 명부에서 그 자리에 바꾸기」 — 그 인라인 메뉴 장치를 그대로 씁니다.

---

## 1. 먼저 «있는 데이터» 를 셌습니다 (추측이 아니라 실측)

```sql
SELECT COALESCE(NULLIF(TRIM(nationality),''),'(빈칸)') nat, COUNT(*) FROM teacher_profiles GROUP BY nat;
-- (빈칸) 32 · PH 1        ← PH 는 「테스트강사」 한 명뿐
```

**국적 칸은 사실상 비어 있었습니다.** 대신 `origin_region` · `active_region` 에 한글로 들어 있습니다 —
필리핀 24 · 미국캐나다 2 · 중국 2 · (빈칸) 4~5.

⟹ 그래서 **국적 «만» 보고 나누면 강사 32명이 전부 「미지정」** 으로 뜹니다.
   화면에 칸만 만들어 두고 전원이 「미지정」이면, 그건 기능이 아니라 «빈 칸» 입니다.

---

## 2. 검토했다가 버린 방법

| 버린 것 | 왜 |
|---|---|
| **국적(`nationality`)만 보고 나누기** | 위 실측대로 32명이 「미지정」이 됩니다. 「데이터를 먼저 채운 뒤에」는 33명을 손으로 고르라는 말이라, 오늘 쓸 수 없습니다. |
| **`nationality` 에 「NA」(북미)를 저장하기** | 북미는 «미국·캐나다를 묶은 칸» 입니다. 저장해 버리면 **어느 나라인지 모르면서 아는 척**하게 되고, 화면 언어 판정 등 그 칸을 ISO 2글자로 읽는 다른 코드와도 어긋납니다. → 메뉴에는 **나라**를 늘어놓고, 표에는 **묶음**을 그립니다. |
| **SQL `WHERE` 로 구분을 거르기** | 판정이 국적 코드뿐 아니라 지역 «글자» 까지 봅니다. 같은 규칙을 SQL 로 옮겨 적는 순간 정본이 두 벌이 되고, 이 저장소는 그걸로 여러 번 사고를 냈습니다. → 서버가 읽은 뒤 TS 정본으로 거릅니다(이 목록은 쪽나눔이 없어 전체 33행이라 안전합니다). |
| **화면(js)에서 지역 글자를 읽어 구분을 정하기** | 같은 이유. 화면은 서버가 준 `t.region` 을 **그리기만** 합니다. |
| **지역 글자가 애매할 때 «그럴듯한 쪽» 으로 몰기** | 한 칸에 두 구분이 잡히면 그 칸은 **안 씁니다**. 아무 쪽에 몰아주면 그게 곧 오답입니다(가맹점 정산의 「같은 이름 지사」와 같은 규칙). 끝까지 못 읽으면 «미지정» 입니다. |
| **국기 이모지(🇵🇭 등)로 칸 꾸미기** | Win10 은 국기를 「PH」 같은 **글자 두 개**로 그립니다. 안 씁니다. |
| **강사 명부 밖(급여·배정 등)까지 구분으로 나누기** | 지시 범위 밖입니다. 손대지 않았습니다. |

## 3. 만든 것

### 3-1. 판정 정본 한 곳 — `cloudflare-deploy/src/teacher-region.ts`

읽는 순서가 곧 «믿는 순서» 입니다.

1. `nationality`(ISO 2글자) — `PH`→필리핀 · `US`·`CA`→북미 · `CN`→중국 · 그 밖의 **아는 코드**→기타 국가
2. `origin_region` → 3. `active_region` → 4. `group_name` 의 **글자**
   (한글은 그대로, 짧은 영문 약자는 **낱말 경계로만** — `ph` 를 부분일치로 찾으면 `Alpha` 가 걸립니다)
5. 아무 단서도 없으면 **`''` = 미지정.** 지어내지 않습니다.

실측 33행을 그대로 넣어 돌린 결과: **필리핀 26 · 북미 2 · 중국 2 · 미지정 3 (합 33)**.

### 3-2. 서버 — `src/api-admin.ts`

- `GET /api/admin/teacher-profiles` 가 행마다 **`region` 을 실어** 내려줍니다.
- `?region=PH|NA|CN|ETC|__none__` 으로 거릅니다.
- `PATCH` 로 국적을 바꾸면 **서버가 다시 판정한 `region`** 을 응답에 실어 줍니다
  (화면이 같은 판정을 한 벌 더 갖지 않게 하려는 것입니다).

### 3-3. 화면 — `admin.html` · `js/adm-core.js` · `css/admin-inline-c.css`

- 「전체 그룹」 옆에 **「전체 구분」 드롭다운**(필리핀 / 북미 / 중국 / 기타 국가 / — 미지정).
- 표에 **「구분」 칸**(「지금」 뒤, 「그룹」 앞). 배지를 **누르면 그 자리에서** 나라를 바꿉니다
  — 상태 칸과 같은 메뉴·같은 5초 되돌리기입니다.
- 국적이 비어 있는데 구분이 잡혀 있으면 메뉴가 **「지금은 출신·활동 지역 «글자» 로 읽고 있습니다」**
  라고 말해 줍니다. 안 적으면 「고르지도 않았는데 필리핀이라고 나온다」가 됩니다(실측 32명이 그 상태).

## 4. 밟을 뻔했던 함정 (전부 CLAUDE.md 2장에 이미 적혀 있던 것)

| 함정 | 어떻게 피했나 |
|---|---|
| 표에 칸을 늘리고 **빈 표 `colspan` 을 안 늘림** | 머리 칸 16 · `colspan` 16 을 하니스가 **세어서** 대조합니다(`admin.html` 1곳 + `adm-core.js` 2곳). |
| 필터를 만들었는데 **`change` 배선을 빠뜨림** → 골라도 조용히 아무 일도 안 함 | 그 한 줄을 하니스가 못 박습니다. 빼고 돌려 보니 실제로 **FAIL** 했습니다. |
| 배지 배경을 `background:#f…` 로 주면 옛 다크 규칙이 **투명하게 덮음** | `background-color:` 로 줍니다(브라우저 검사에서 computed 로 확인). |
| 글자색 페인터 셋(`adm-s12`·`adm-s13`·`adm-light-surfaces`)이 배지 색을 눌러 **세 구분이 구분 안 됨** | 이미 예외 등재된 클래스 `tp-st-badge` 를 함께 답니다. 브라우저 검사가 «네 칸의 색이 전부 다른가» 를 잽니다. |
| 아이콘 버튼에 `data-ko`/`data-en` → **본문이 문장으로 갈아끼워짐** | 트리거 버튼에는 달지 않고 설명은 `data-ko-title` 로만. |
| `body{zoom:1.3}` 때문에 메뉴가 엉뚱한 데 뜸 | 기존 `_tpStPlace` 를 그대로 씁니다(브라우저 검사가 버튼 바로 아래인지 잽니다). |
| 상태 메뉴와 **같은 상자**를 써서 「상태 → 구분」으로 옮겨 누르면 닫히기만 함 | 메뉴 열쇠에 `rg:` 접두사. 브라우저 검사 ⑥절. |
| 「되돌리기」가 **조용히 아무 일도 안 함**(성공 뒤 재조회가 행 캐시를 비움) | 되돌릴 값·이름을 **닫힘으로** 넘깁니다(9/1 숨기기에서 실제로 밟았던 함정). |
| 좁은 칸에서 배지가 **낱글자로 쪼개짐** | `white-space:nowrap` + 브라우저에서 «한 줄인가» 를 `lineHeight` 로 잽니다. |
