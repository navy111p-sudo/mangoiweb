## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

### ⛔ `index.ts` 의 `handleRecordingDownload`(blob 통로)를 고쳐 206 문제를 해결
`index.ts` 는 **공동 금지구역**이고, 무엇보다 **이미 «저장 전용» 통로가 있습니다**(2026-08-15 에 같은 사고로 만든 `dl=1`). 고치면 같은 일을 하는 통로가 두 벌이 되어 다음에 또 «한쪽만 고쳐지는» 상태가 됩니다.

### ⛔ 화면에서 URL 을 조립 (`'/api/recording/play?id=' + r.id + '&dl=1'`)
**화면은 그 녹화가 실제로 재생 가능한지 모릅니다.** `play` 는 `file_url`/`filename` 으로 키를 풀고 `status`·`storage`·만료까지 보고 404 를 냅니다. 화면이 조립하면 그 조건을 통과 못 하는 행에도 버튼이 붙어 **「눌러도 404 나는 버튼」** 이 생깁니다. → 서버가 같은 판정을 한 번 하고, 못 풀면 URL 자체를 안 줍니다.

### ⛔ `<a download>` 속성만 믿고 `&sig=` 생략
PC 브라우저는 same-origin 다운로드에 쿠키를 싣지만, **카톡 인앱 브라우저·안드로이드 WebView 는 저장을 쿠키 없는 다운로드 관리자에 위임**합니다(2026-08-13 «휴대폰 저장 안 됨» 선례). 그러면 401 로 조용히 실패합니다.

### ⛔ 서명 TTL(6시간)을 늘려 링크를 오래 쓰게 하기
미성년자 수업 영상의 **노출 창을 넓히는 정책 판단**이라 사람이 정할 일입니다. 대신 **화면이 만료 시각을 말하게** 했습니다 — 감추면 「보냈는데 안 열린대요」가 됩니다.

### ⛔ 서버에서 webm → mp4 로 변환해 «파일 전송» 을 되게 만들기
Workers 에서 ffmpeg 를 돌릴 수 없습니다. Cloudflare Stream 은 **비용이 생기는 사장님 결정 사항**입니다. **링크를 보내면 형식(webm)·용량(195MB) 제약을 통째로 비켜 갑니다** — 그래서 링크를 골랐습니다.

### ⛔ PC 에서도 `navigator.share` 를 쓰기
윈도우 공유 시트에는 **카카오톡이 없는 경우가 많습니다.** 「시트는 떴는데 카톡이 없다」가 되므로 **터치 기기(`navigator.maxTouchPoints > 0`)에서만** 시트를 쓰고 PC 는 복사로 떨어집니다.

### ⛔ `window.open` 으로 링크 열기
카톡·문자앱 인앱 브라우저는 새 창을 못 열고 **예외도 안 던진 채 null 만** 돌려줍니다(CLAUDE.md 2장).

### ⛔ 빨리감기를 재생 화면에서 «근사» 로 구현
D1 `duration_ms` 로 진행바를 그리고 Range 로 바이트 위치를 추정해 이동할 수는 있지만, WebM 특성상 **키프레임에 안 붙어 정확하지 않습니다.** 임시방편이라 넣지 않고, **형식 문제로 정직하게 남겼습니다**(아래 5장).

### ⛔ 이 컨테이너에서 mp4 지원 여부 재기
여기 크로미움은 **H.264 가 빠져 있어** `MediaRecorder.isTypeSupported('video/mp4;codecs=avc1…')` 가 거짓으로 나옵니다(CLAUDE.md 2장). 재면 **없는 결론**을 냅니다.

## 5. 남은 것 / 주의할 것

### 🔴 「빨리감기가 안 된다」는 **아직 그대로입니다**

이번 변경과 **별건**입니다. MediaRecorder 의 WebM 은 «언제 끝날지 모르는 스트림» 이라 파일 안에 **총 길이(Duration)도 탐색 색인(Cues)도 없습니다.** 휴대폰의 `--:--` 가 그 지문입니다.

⚠️ 관리자 목록의 「21:06」을 근거로 «파일에 길이가 있다» 고 읽지 마세요 — 그건 D1 `recordings.duration_ms` 입니다.

**다음 사람이 할 일 순서:**
1. 강사 **실제 브라우저**에서 `MediaRecorder.isTypeSupported('video/mp4;codecs=avc1.42E01E,mp4a.40.2')` 한 줄 재기 (⛔ 이 컨테이너에서 재지 말 것)
2. 참이면 mp4 로 찍고 **미지원 브라우저는 webm 폴백**
3. ⚠️ **mp4 로 바꿔도 fragmented mp4 라 총 길이가 없을 «수» 있습니다** — 실제 파일 하나로 확인하기 전에 「이러면 풀린다」고 적지 말 것
4. 그래도 안 되면 Cloudflare Stream 등 변환·HLS — **비용이 생기므로 사장님 결정**

### 공유 링크 유효기간 **6시간**

`auth-token.ts` 의 `REC_DL_TTL_MS` 그대로입니다. 늘리는 것은 미성년자 영상 노출 창을 넓히는 **정책 판단**이라 사람이 정할 일로 남겼습니다.

### 파일 크기

195MB / 21분 ≈ 1.2Mbps(설정은 `videoBitsPerSecond: 2_500_000`). 낮추면 용량이 줄지만 **화질이 걸린 별건**입니다.

### ⚠️ 담당 영역

`adm-core.js`·`admin.html` 은 **배포 권한자(A) 영역**입니다(CLAUDE.md 4-2). 알리고 손댔습니다.
