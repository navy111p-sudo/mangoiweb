# 동의 기록에서 「안 물어봤다」와 「거절했다」를 갈라 적음 (2026-09-01)

## 1. 왜 했나

2026-08-28 무인증 전수점검에서 남긴 8건 중 다섯 번째 — 「`kakao_ids` 야간 전원 삭제(`kakao_consent=1` 을 쓰는 코드가 없음)」.

파 보니 제목이 정확하지 않았습니다. 진짜 결함은 **「안 물어봤다」와 「거절했다」가 같은 값 `0`** 이라는 것이었습니다.

동의 화면(`js/mango-consent.js`)은 **녹화·출석만** 묻고 `voice_analysis`·`reward`·`kakao` 는 **키 자체를 안 보냅니다.** 그런데 서버가 `b.kakao ? 1 : 0` 으로 적어서 그 셋이 **구조적으로 늘 0** 이었습니다. 그 0 을 읽는 쪽들이 「거절」로 읽고 있었습니다.

## 4. 검토했다가 버린 방법

| 버린 방법 | 왜 |
|---|---|
| 파기 조건(clause 2)을 통째로 지운다 | 진짜로 «거절» 한 사람의 카카오 ID 는 파기해야 합니다(개인정보). 구멍을 반대 방향으로 뚫는 셈 |
| 기존 11행을 D1 UPDATE 로 NULL 로 정정 | 운영 DB 변경은 사람 판단(CLAUDE.md 1-1). 그리고 아래 ②로 **DB 를 안 건드리고** 같은 보호가 됩니다 |
| 동의 화면에 카카오 항목을 추가 | 제품·법무 판단이지 제 판단이 아닙니다. 그리고 화면이 물어도 **이미 행이 있는 사람에게는 다시 안 묻습니다**(`askedBefore()` 가 `consent_version` 을 비교하지 않습니다) |
| NULL 수리만 한다 | **기존 11행을 못 지킵니다** — 그 학생이 나중에 카카오를 연결하면 그날 밤 지워집니다 |

## 5. 한 것 — 막는 방법을 «둘» 두었습니다

**① 앞으로 들어올 행** — `api-mango.ts` `POST /api/consents` 가 그 세 칸을 `b.X == null ? null : (b.X ? 1 : 0)` 로 적습니다.
「안 물어봄」 = **NULL**, 「거절」 = 0, 「동의」 = 1. 녹화·출석은 실제로 묻는 항목이라 그대로 0/1 입니다.

**② 이미 쌓인 행** — `retention.ts` 파기 조건에 `AND c.raw_payload LIKE '%"kakao"%'` 를 더했습니다.
`raw_payload` 에 그때 보낸 본문이 그대로 남아 있어 **「그때 화면이 실제로 물었는가」** 를 가릴 수 있습니다.
⚠️ `raw_payload` 가 NULL 이면 LIKE 결과도 NULL 이라 그 행은 파기 대상에서 빠집니다 — **모르면 안 지운다**는 안전한 방향이라 그대로 뒀습니다.

**③ 화면** — `admin/student.html` 이 안 물어본 항목을 «— 안 물어봄»(회색)으로 그립니다. 한/영 사전(`consentUnknown`)을 씁니다.

**신설 `test-harness/consent_not_asked_harness.mjs`**(31건) — 서버의 «값 정하는 식» 을 소스에서 오려 내 **세 칸 모두 실제로 평가**하고, 파기 SQL 을 오려 내 **진짜 SQLite 에 돌려** 여섯 상태를 확인합니다.

## 6. trap-check 가 잡아 준 것 (전부 반영)

1. 🔴 **「지워진 행은 없다」는 증명 불가** — 근거로 댄 것은 «현재 상태» 인데 주장은 «과거 사실» 이었습니다. 게다가 그 문장을 **세 곳**(retention.ts·api-mango.ts·하니스 머리말)에 적어 뒀습니다. 셋 다 「잰 것 / 판단」으로 갈라 고쳤습니다.
2. **하니스가 검사 범위를 «길이» 로 잘랐습니다** — A절 창(900자)은 이미 `save()` 를 305자 넘어 옆 함수를 물고 있었습니다. 중괄호 짝으로 자르고, D절에는 「그 줄들이 범위 «안에» 있다」는 **긍정 검사**를 함께 넣었습니다(부정 검사만 두면 창 밖으로 밀려나도 참이 됩니다).
3. **B절이 카카오 한 칸만 실제로 평가**하고 나머지 둘은 정규식이었습니다 — 뒤가 뒤집혀 있어도 통과합니다. 세 칸 모두 돌리게 고쳤습니다.
4. **`=== undefined` 는 명시적 `null` 을 못 잡습니다** → `== null` 로 넓혔습니다.
5. **`askedBefore()` 가 다시 묻지 않는다**는 조건을 주석에 함께 적었습니다.
6. **«—» 에 이유가 없다** → 한/영 사전으로 «안 물어봄» 을 붙였습니다.
7. **기존 11행 보호** → 위 ②(`raw_payload`)로 D1 을 안 건드리고 해결했습니다.
