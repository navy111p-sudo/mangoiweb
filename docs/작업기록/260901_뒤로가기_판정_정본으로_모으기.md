# 뒤로가기 판정 — 복제본 5개를 정본 하나로 (2026-09-01)

## 1. 왜 했나

앞선 두 작업([4곳 화살표 수리](260901_학습화면4곳_화살표를_뒤로가기로.md))에서 정본
`window.mangoiGoBack`(`js/back-nav.js`)을 만들면서, **같은 판정을 각자 복제한 화면 5개**를
「손댈 일이 생기면 모으세요」로 남겨 두었습니다. 사장님 「나머지 5개도 정본으로 모아줘」.

복제본이 정본보다 **나빴다**는 것이 이 작업의 근거입니다 — 정본에는
「히스토리가 없으면 같은 오리진 `referrer` 를 직전 페이지로 본다」가 있는데,
복제본 4개는 `if(history.length>1){history.back()}else{location.href='/'}` 뿐이라
그 구제가 없었습니다.

## 2. ⚠️ 먼저 확인한 것 — 5개가 «같은 판정» 이 아니었습니다

갈아치우기 전에 각 화면이 실제로 어디로 가는지 읽었습니다. 두 곳이 달랐습니다.

| 화면 | 그전 판정 | 다른 점 |
|---|---|---|
| `micro-quiz` · `judgment` · `student-games` | history → `/` | referrer 구제 없음(정본보다 약함) |
| **`game-learning-science`** | history → **`/student-games.html`** | 🔴 폴백이 홈이 아니라 **게임 허브**. 그대로 정본을 부르면 학생이 허브가 아니라 홈으로 튕깁니다 |
| **`warmup`** | **같은 오리진 referrer «그리고» history** → back, 아니면 `/` | 🔴 「앞 화면이 우리 사이트일 때만 되돌아간다」는 **의도된 정책**(그 파일 주석에 그렇게 적혀 있습니다). 정본은 referrer 와 무관하게 back 합니다 |

⟹ 그래서 «판정을 하나로» 모으되 **화면마다 다른 것은 인자로** 넘겼습니다.

## 3. 무엇을 했나

정본 시그니처를 넓혔습니다(`js/back-nav.js`):

```js
goBack(fallbackUrl, opts)   // window.mangoiGoBack
// fallbackUrl : 히스토리도 referrer 도 없을 때 갈 곳 (안 주면 홈, /admin* 은 /admin.html)
// opts.sameOriginOnly : true 면 «앞 화면이 우리 사이트일 때만» 뒤로
```

🔴 **폴백은 «문자열일 때만» 인정합니다.** 이 파일 안에 `b.onclick = goBack` 자리가 있어
**첫 인자로 Event 가 들어옵니다**(리스너 첫 인자는 항상 truthy — 이 저장소가 이미 밟은
함정). 그대로 쓰면 `location.href = <Event>` 가 됩니다.

화면 5개는 이렇게 바뀌었습니다.

| 화면 | 지금 |
|---|---|
| `micro-quiz` · `judgment` · `student-games` | `window.mangoiGoBack()` |
| `game-learning-science` | `window.mangoiGoBack('/student-games.html')` |
| `warmup` | `goBackOrHome()` 안에서 `window.mangoiGoBack('/', { sameOriginOnly: true })` |

- `judgment`·`student-games` 는 `back-nav.js` 를 안 싣고 있어 **한 줄 추가**했습니다.
- `<button>` 은 `href` 폴백이 없으므로 `else{location.href='…'}` 안전망을 남겼습니다.
  ⚠️ 그것은 «판정» 이 아니라 «어딘가로는 보낸다» 입니다 — 거기에 판정을 다시 적으면
  복제가 되살아납니다.

## 4. 🔴 내가 저지른 결함 — 브라우저 검사가 잡았습니다

설명 주석을 스크립트로 «그 줄 앞» 에 끼워 넣었는데, `judgment`·`game-learning-science` 는
`onclick=` 이 **태그 도중의 줄**이었습니다(`<button type="button" class="tn-btn" …` 다음 줄).
그 앞에 주석을 넣자 `<button` 과 `>` **사이**에 들어가 **버튼이 DOM 에서 사라졌고**,
`back-nav.js` 가 「보이는 ← 가 없다」고 판단해 자기 동그란 ← 를 하나 더 넣어
**화살표가 둘**이 됐습니다.

⚠️ **에러가 안 났습니다** — HTML 파서가 조용히 복구하고, 하니스 246건도 전부 초록이었습니다.
✅ 잡은 것은 「그 버튼이 DOM 에 있나 · 화살표가 둘이 아닌가」 브라우저 검사입니다.
✅ 고침: 위로 올라가 **`<button` 이 시작하는 줄**을 찾아 그 앞에 넣습니다. 검사는
`<(?:button|a)\b[^>]*<!--` 정규식 한 줄이면 됩니다.
📌 CLAUDE.md 2장에 함정으로 등재했습니다.
