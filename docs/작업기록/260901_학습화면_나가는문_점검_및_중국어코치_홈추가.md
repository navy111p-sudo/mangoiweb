# 학습 화면 「나가는 문」 전수 점검 + 중국어 음성코치 홈 버튼 (2026-09-01)

## 1. 왜 했나

전날 `speech-coach.html`(AI 음성 코칭)에 홈 버튼을 되살린 뒤, 사장님 「다른 학습 화면들도
뒤로가기·홈 버튼 있는지 확인해줘」.

## 2. 어떻게 확인했나 (⚠️ 정적 grep 은 답을 틀리게 줍니다)

`back-nav.js`·`mango-i18n.js` 문자열을 세는 방식으로는 **못 가립니다.**

- `back-nav.js` 의 ← 는 **조건부**입니다 — 홈 화면에서는 안 넣고, 「이미 보이는 ← 가 있으면」
  건너뜁니다(`hasVisibleBack`).
- 공용 [🏠 홈][🌐 EN] 바는 `mango-i18n.js` 가 넣지만 `<meta name="mangoi-no-global-bar">`
  로 꺼져 있을 수 있습니다.
- 🔴 그리고 **게임 16개는 «iframe 자식»** 이라, 파일만 보면 「나가는 문이 하나도 없다」로
  나오지만 실제로는 허브가 문을 갖고 있습니다(아래 4장).

✅ 그래서 **로컬 HTTP 서버 + 컨테이너 크로미움(CDP)** 으로 화면 31개를 실제로 그려서,
보이는 `a`·`button` 을 훑어 ←/🏠 후보를 찾고 **`elementsFromPoint` 로 «맨 위에 있나»**
까지 재습니다(폰 390 · PC 1280 양쪽).

## 4. 게임 16개의 «없음» 은 정상입니다 (거짓 경보였습니다)

`student-games.html` 은 게임을 **`<iframe>`** 으로 엽니다(`_hubIframeSrc`). `speaking-quiz`·
`suspect-mystery`·`battle-3d` 도 같은 `src:function(){…}` 목록에 있어 **전부 iframe 자식**
입니다. 홈 첫화면(`js/idx-main.js` `#game-suite-frame`)도 같은 방식입니다.

✅ 실측(허브에서 `_questMode=false` 로 잠금을 풀고 실제로 게임을 연 상태): 좌상단이
**「← 게임 선택」**(폰 8,3 88×27 · PC 8,3 106×38)으로 바뀌고 **둘 다 눌립니다.**
⚠️ 그때 허브의 🏠 는 사라집니다 — 게임 안에서 홈까지는 **2탭**(← 게임 선택 → 🏠)입니다.
⚠️ 게임 «주소로 직접» 들어오면 나갈 길이 없습니다. 다만 정상 경로에서는 주소창이 바뀌지
않으므로(iframe) 학생이 그 주소를 얻을 일이 거의 없습니다 — 지금 고칠 것으로 보지 않았습니다.

## 5. 고친 것 — `speech-coach-cn.html` 에 [🏠 홈]

사장님 선택으로 **이 한 화면만** 고쳤습니다.

- 어제 한국어판과 **같은 방식**: 왼쪽 위 ← 오른쪽에 고정 알약, 자리는 스크립트가 ← 를
  **재서** 붙입니다(숫자 복사 금지 — back-nav.js 는 480px, 이 화면 CSS 는 640px 기준).
- ⛔ **옛 `header.hero .home`(hero 안 우상단)을 되살리지 않았습니다** — 그 자리는 문서 흐름
  안이라 **스크롤하면 사라집니다.** 이 화면은 레벨·단원 목록이 길어서 정작 나가고 싶은
  순간에 화면 밖입니다. 한국어판과 모양·자리도 달라집니다.
- ℹ️ 한국어판과 달리 **제목 폭을 비우는 코드가 없습니다** — 이 화면 제목은 왼쪽 정렬이고
  `header.hero` 가 폰에서 **y=50 부터** 시작해 버튼 띠(8~42)와 겹치지 않습니다(실측).
- ℹ️ 이 화면은 **공용 i18n 엔진을 안 싣습니다** → `data-ko`/`data-en` 이 동작하지 않으므로
  달지 않았습니다. 화면 글자가 한국어(「중국어 발음 교정」·「단원 선택」)라 라벨도 한국어.
