## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

### 🔴 내가 두 번 틀린 답을 드린 경위 (가장 중요)

**첫 번째 답(틀림)** — 「강사 명부의 퇴사 배지가 페인터에 눌려 파랗다」.
근거로 `adm-light-surfaces.js:53` 의 실측 주석(`#991b1b` → `rgb(55,92,129)`)을 들었고,
브라우저에서 재 보니 빨강이라 「이미 고쳐졌다」고 했습니다.
🔴 **그 측정이 틀렸습니다 — 배지를 `document.body` 에 붙여, 즉 카드 «밖» 에서 쟀습니다.**
이기는 규칙이 `html[data-admin-theme="ivory"][data-admin-tone="slate"] [id^="card-"] .sub-body :is(…)`
라 **카드 안에서만** 걸립니다.

**두 번째 답(정정)** — 카드 «안» 에서 다시 재니 `.tp-st-badge` 도 글자가 **검정 `rgb(16,24,40)`**.
파랑은 아니지만 빨강도 아니었습니다. 여전히 사장님이 보신 것이 아니었습니다.

**세 번째(찾음)** — 추측을 멈추고 **카드 안 요소 861개를 전수로 훑어** 파랑을 셌습니다.
퇴사 행에만 나오는 파랑은 **없었고**, `tp-act--view`(파랑)와 영문 이름 글자
`rgb(48,74,105)`(페인터 `darken()` 결과)가 **세 상태 행에 똑같이** 있었습니다.
그래서 후보를 측정값과 함께 제시하고 사장님께 **한 번만** 여쭤 확정했습니다.

> **교훈**: 관리자 화면의 색은 반드시 **그 카드 «안» 에서** 재야 한다.
> 그리고 세 번째 추측을 하느니 측정값을 들고 한 번 묻는 편이 빠르다.

### 버린 것 ①: 배지 색을 다른 값으로 바꿔 «파랑을 피하기»

원인이 색 선택이 아니라 **이기는 규칙**이라, 값을 바꿔도 같은 규칙에 다시 눌립니다.
조상 id 를 앞에 붙여 **특이성으로 이기는** 쪽이 정답입니다.

### 버린 것 ②: 테마 규칙(`#101828 !important`) 자체를 고치기

관리자 화면 전체의 글자색이 걸립니다. 그 규칙은 「어두운 면 위 흰 글자」 구제책입니다.

### 버린 것 ③: 페인터 한 곳만 예외 등재

글자색을 인라인 `!important` 로 덮는 페인터가 **셋**이라 한 곳만 하면 나머지 둘이 덮습니다.

### 버린 것 ④: 퇴사 강사의 버튼을 **없애기**

지난 수업 확인이 걸려 있고, 이 저장소는 「감추면 아무도 정리하지 않는다」를 반복해 밟았습니다.

### 버린 것 ⑤: `disabled` 로 막기

「보이는데 안 눌린다」가 되면 그것대로 고장으로 읽힙니다.
흐리게 + 툴팁으로 이유를 말하고, 눌리면 기존 안내가 사실대로 답하게 뒀습니다.

### 버린 것 ⑥: 「직원 명부」·「교재 명부」 배지도 함께 고치기

같은 사정이지만 **지시 범위 밖**이라 손대지 않았습니다(아래 5장).

### ⚠️ 하니스가 내 결함을 잡은 자리

화면 판정을 새로 적으면서 옛 별칭 **「재직」** 을 빠뜨렸습니다.
정본은 「재직 = 활동중」인데 제 함수는 false 를 돌려줘, 그대로 뒀으면
**「재직」으로 저장된 강사 전원의 버튼이 흐려질 뻔했습니다.**
하니스가 두 함수를 **나란히 돌려 대조**하도록 짜 둔 덕에 잡혔습니다
(문자열 검사였으면 못 봤습니다).
