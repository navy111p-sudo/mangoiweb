# 강사 스케줄 주간 캘린더 — 겹침 수리 (요일 접기 + 강사별 열 + 빈 시간) · 2026-09-02

> Teacher weekly calendar — overlap fix (accordion week + per-instructor columns + free-time markers)

## 1. 왜 했나 / Why

사장님 화면 캡처(관리자 › 강사 › 강사 명부 › 강사 스케줄 주간 통합 캘린더, 「전체 강사(25명)」 보기):
**수업들이 겹쳐 있어서 보기가 힘들다 — 겹치지 않고 한눈에 모두 정확하고 깨끗하게.**

원인은 배치 규칙이 «없는» 것이었습니다. `js/adm-q6.js` `ph54EventCard` 가 모든 카드를 요일 칸의
**전체 폭**(`admin-inline-c.css .ph54-ev{left:3px;right:3px}`)에 절대배치해서, 강사 25명이 한 요일에
모이면 20:00 에 6명의 수업이 정확히 같은 자리에 쌓이고 맨 위 한 장만 보였습니다. 색·글자 규칙은
문제가 없었습니다.

## 4. 검토했다가 버린 것 / Rejected

- **모든 열을 한꺼번에 lane 으로 나누기(샘플 A)** — 강사 6명이 몰리면 카드가 «허…» 로 잘림. 사장님이 B 선택.
- **열 전체를 겹침 수만큼 나누기** — 한 시각에만 겹쳐도 그 열의 «모든» 카드가 반쪽이 됨. 군집(cluster) 단위로만 나눔(하니스 A② 가 되돌리면 FAIL).
- **주간 전체를 강사 열로 펼치기(B-2)** — 18~25명 × 5일이면 2,300px 가로 스크롤. 요일 접기로 한 화면.
- **접힌 요일 밀도를 div 수십 개로** — 요소 수가 늘어 느려짐 → `linear-gradient` 한 장(모든 20분 칸에 stop 을 둬야 사이가 번지지 않음).
- **`ph54C24Card(s, lay)` 로 인자 늘리기** — `c24_mirror_harness` I절이 `function ph54C24Card(s){` 모양을 오려 내 검사. `s.__lay` 로 넣고 곧 지움.
- **다른 강사 열에 놓으면 강사도 바꾸기** — PATCH 계약(요일·시각)을 넓히는 별건. 지금은 «강사는 그대로» 라고 토스트로 말함.
- **body class MutationObserver·상주 setInterval** — 홈 정지 전력(CLAUDE.md). 클릭 때만 다시 그림.

## 5. 밟은 함정 / Traps hit

- 🪤 **부정 검사가 자기 주석을 잡음** — `ph54C24Card` 주석에 «data-idx·draggable» 이라고 적자 `c24_mirror_harness` 두 건이 FAIL. 낱말을 풀어 씀.
- 🪤 **원장(asset-versions.json)의 중간 hash** — ?v=14 를 기록한 뒤 주석을 고쳐 hash 가 어긋남 → 배포된 적 없는 v=14 줄을 원장에서 빼고 다시 기록(번호를 올리지 않음).
- 🪤 **관리자 화면 zoom 1.3** — 브라우저 검사에서 px 상수 비교가 1.3배로 어긋남 → «앞 카드 아래» 와의 상대 위치로 판정.
- 🪤 **20분 카드의 최소 높이 22px(=26분)** — 빈 자리 칸이 카드 «아래» 보다 몇 px 위에서 시작하는 것이 맞음(카드가 위에 덮임). 검사 허용 폭 −10~+6px.
- 🪤 **playwright-core 1.47 + Chromium 1194** — `--headless=old` 가 제거된 크로미움이라 launch 실패. `playwright-core@latest`(1.62) 로.
