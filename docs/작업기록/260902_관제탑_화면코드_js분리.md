## 1. 왜 했나

A안을 넣으면서 `admin/monitor-wall.html` 이 **42.6KB** 가 됐고, 자체 상한 44KB 에
여유가 **1,387 B** 밖에 안 남았습니다. 사장님이 「관제탑 파일에서 뭘 뺄지 제안해줘」라고
물으셔서 먼저 **재 봤습니다.**

| 구성 | 바이트 | 비중 |
|---|---:|---:|
| `<script>` | 33,669 | **77%** |
| `<style>` | 5,546 | 13% |
| 나머지 HTML | 4,422 | 10% |
| *(그중 주석)* | *9,699* | *22%* |

무게의 77%가 **화면 코드**였습니다. 그런데 그 파일 머리말에 이렇게 적혀 있었습니다 —

> ⚠️ /admin/ 밑에는 js·css 정적자산을 두지 않는 규칙(index.ts isAdminPath 주석) **→ 전부 인라인.**

🔴 **그 「→ 전부 인라인」이 과잉 해석이었습니다.** 규칙은 **`public/admin/` 디렉터리에만** 걸립니다:

```ts
// src/index.ts isAdminPath
if (path.startsWith('/admin/')) return true;   // ← 여기까지만
```

`/js`·`/css` **루트는 게이트 밖**입니다. 그리고 **그 화면이 이미 그렇게 쓰고 있었습니다** —
`<link rel="stylesheet" href="/css/mangoi-han.css?v=2">`. `admin.html` 의 JS 도 전부
공개 `/js/` 에 있습니다(`adm-core.js`·`adm-ia6.js` 등). **새로운 노출 경로가 아닙니다.**

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

| 버린 것 | 왜 |
|---|---|
| **강제 종료 빼기**(~2.5KB) | `adm-core.js` 에 같은 API 가 있어 «중복» 은 맞습니다. 그런데 이건 **바이트 문제가 아니라 정책 문제**입니다 — 한 반 전원 연결을 끊는 가장 위험한 버튼인데 관제탑은 «보는» 화면입니다. 사람이 정할 일이라 손대지 않았습니다 |
| **카페24 예약 목록 빼기**(~2KB) | 지금도 유효한 후보이고 잃을 것이 거의 없습니다. 다만 1번(옮기기)이 상한 문제를 **구조적으로** 끝내므로 굳이 기능을 지울 이유가 없었습니다 |
| **머리말 주석 지우기**(2.3KB) | ⛔ 「왜 이 화면이 가벼운가」를 적어 둔 자리입니다. 바이트 벌자고 지우면 다음 사람이 여기에 admin.html 을 얹습니다. 오히려 이번에 **늘렸습니다** |
| **상한 44 → 48·52KB 로 올리기만 하기** | 그건 문제를 미루는 것이고, 이 저장소에서 «넘칠 때마다 올리기» 는 금지에 가깝습니다 |

## 6. 이어서 나온 것 — 「브라우저가 새 창을 막았습니다」는 **거짓말이었습니다**

배포 뒤 사장님이 관제탑·수업 관찰을 눌러 보시고 화면을 보내 주셨습니다:

> ⚠ 브라우저가 새 창을 막았습니다 — 아래 링크를 누르면 열립니다.

**팝업이 막힌 게 아니었습니다.** 브라우저에서 직접 쟀습니다(크로미움):

```
window.open(u,'_blank','noopener') → 반환 null   · 탭 1→2 (실제로 열림)
window.open(u,'_blank')            → 반환 object · 탭 2→3 (실제로 열림)
```

🔴 **`noopener` 를 «기능 문자열» 로 주면 표준상 탭은 열리는데 반환값이 `null`** 입니다.
그런데 `mangoiOpenTab`(`adm-core.js`)은 `if (w)` 로 성공을 판정합니다 →
**언제나 «막혔다»** 로 떨어집니다. 즉 **탭은 이미 열렸는데 경고가 뜨고, 그 링크를 누르면
탭이 하나 더** 열립니다. 같은 함정이 **방금 배포한 관제탑에도** 있었습니다
(`openTab` → 참관·귓속말·소리만을 누를 때마다 헛경고 alert).

### 더 나쁜 변종 — 「탭이 열리고 + 지금 화면까지 이동」

`ghost-view.html`·`adm-promo-setup.js`·`manager.html`·`t.html` 은 폴백이
`if (!w) location.href = url` 이라 **탭이 열린 뒤 현재 창까지 그 주소로 갑니다.**

### 고침

`window.open(url, '_blank')` 로 열고 **`w.opener = null`** 로 같은 보호를 겁니다
(원래 코드도 `w.opener = null` 을 하려 했는데 `w` 가 null 이라 한 번도 안 돌았습니다).
브라우저 실측: 반환 `object` · `w.opener` `null` · **헛경고 0건**.

고친 곳 — `adm-core.js`(2곳) · `monitor-wall.js` · `ghost-view.html` ·
`adm-promo-setup.js` · `manager.html` · `t.html` · `idx-grid-menu.js` · `vc-dock.js`
