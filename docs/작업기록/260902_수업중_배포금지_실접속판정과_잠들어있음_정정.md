## 1. 왜 했나

사장님 질문 **「수업하고 있는데 배포하면 수업에 문제가 생기니?」** 에서 출발했습니다.

답은 **「생깁니다」** 였고, 근거는 Cloudflare 문서입니다:

> Code updates disconnect all WebSockets. Deploying a new version restarts every Durable Object,
> which disconnects any existing connections.
> — [Durable Object Lifecycle](https://developers.cloudflare.com/durable-objects/concepts/durable-object-lifecycle/) (2026-09-01 확인)

화상수업은 `VideoCallRoom` Durable Object 위에서 돌므로 예외가 없습니다.
⚠️ 「무중단 재연결」(`VC_STICKY_UID='on'`)도 **이 경우엔 안 걸립니다** — 그 장치는 «같은 clientId 의 옛
소켓이 서버에 아직 살아 있을 때» userId 를 물려받는 것인데(`src/video-call-room.ts` sticky 절), DO 가
통째로 재시작되면 물려받을 옛 소켓이 하나도 없습니다 → 새 userId → 화면이 `room-joined` 에서
«정체성이 바뀌었다» 로 판정해 `vcCleanupAllPeers()` 로 PeerConnection 을 전부 버리고 다시 협상합니다.

그 뒤 지시가 두 번 바뀌었습니다.

1. 「**mangoi.ai 에서 테스트 수업할 때는 배포를 멈추게** 해줘 — 카페24 말고」
2. 「**배포 멈추는 것은 화요일과 목요일 14시부터 23시까지만** 해줘. 그때가 테스트 수업 중이라서 수업의 질을 위해서」

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

### ⛔ 「카페24 예약(`class_schedules`)으로 판정」 — 버림

그건 «오늘 수업이 잡혀 있다» 이지 **«지금 사람이 들어와 있다»** 가 아닙니다. 그리고 카페24 수업은
우리 화상방(DO)을 안 거치므로 **배포해도 안 끊깁니다.**

판정 근거로 고른 것은 **`attendance.last_seen_at`** — 화상방에 들어와 있는 브라우저가 30초마다 보내는
`/api/speaking-time` 이 **서버에 도착한 시각**입니다(`js/mango-attendance.js` → `src/api-mango.ts`).
클라이언트 값이 아니라 서버 시각이라 위조도 과다계상도 안 되고, 이 저장소가 이미
「씨앗과 실접속을 가르는 **유일하게 확실한 표시**」로 못 박아 둔 값입니다(`src/api-admin.ts`).

### 🔴 그 판정으로 «옛 창» 의 근거가 틀렸다는 것을 찾음

`#708` 이 「매일 13:00~01:20」을 정할 때 쓴 시간별 접속수에 **카페24 씨앗이 섞여 있었습니다.**

### ⛔ 「별도 게이트를 `deploy.yml`·`deploy.ps1` 에 넣기」 — 처음에 그렇게 만들었다가 **버림**

작업 중 `#708`→`#730` 이 같은 일을 하는 게이트를 먼저 병합했습니다. 게이트가 둘이면 이 저장소가
반복해서 밟은 **「판정이 두 벌」** 함정이라, **정본 하나(`class-window.mjs`)에 합치는 쪽으로 다시 썼습니다.**
그 과정에서 제가 만들었던 창·크론·주석 수정은 전부 **뺐습니다**(main 쪽이 더 나았습니다).

### ⛔ 「조회 실패하면 막기」 — 버림

「수업 없음」이 아니라 **「모름」** 입니다. 고장 난 감시견이 모든 배포를 영구히 막으면 급한 수정도
못 나갑니다. **막지 않되 조용히 넘기지 않습니다**(로그·요약에 크게 남김). 실제로 그 설계 덕분에
403 을 바로 찾았습니다.

### ⛔ 「wrangler 로 D1 조회」 — 버림

판정 step 이 **`npm ci` 앞에서** 돌아 wrangler 가 없습니다. **D1 REST + `fetch`** 로 갔습니다.

### ⛔ 「창 안에서도 실접속 조회」 — 버림

창 안이면 어차피 보류라 왕복이 낭비고, D1 이 흔들릴 때 **보류인데도 8초를 더** 기다립니다.

### ⛔ 「실접속 판정 코드를 지우기」 — 버림(사장님 선택)

다른 요일에도 테스트 수업을 하게 되면 **권한 한 줄로 되살릴 수 있고** 검사가 이미 갖춰져 있습니다.
대신 **깨우면 정책이 바뀐다**는 경고를 코드 주석과 `CLAUDE.md` 두 곳에 박았습니다.
