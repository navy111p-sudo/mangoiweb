### 2-2. 접속 코드 양방향 전달 (#713)

브라우저에는 «남의 기기를 조작하는» API 가 없습니다(보안상 일부러 없음).
그래서 **실제 조작은 Quick Assist·AnyDesk 가 하고, 우리는 접속 코드를 날라다 줍니다.**
그 «나르는» 자리가 이 흐름에서 제일 자주 깨지던 곳이었습니다 — 전화로 6자리를 불러 주고 받아 적기(아이 · 한국어를 못 읽는 필리핀 강사).

**방향이 둘이고 서로 정반대입니다.**

| | 도구 | 누가 코드를 만드나 | 만든 것 |
|---|---|---|---|
| **PC** | Quick Assist · Chrome 원격 데스크톱 | **직원**이 만들고 학생이 입력 | 직원이 붙여넣으면 **학생 화면에 38px 로 크게** + [복사] |
| **폰** | AnyDesk | **학생 기기**가 갖고 직원이 접속 | 학생이 보내면 **직원 화면에** 뜸 |

서버 — `cloudflare-deploy/src/api-mango.ts` (⚠️ `/api/class/` 는 `src/index.ts` 라우팅에 **이미** 올라와 있어 공동 금지구역 무수정)

| 경로 | 방향 | 인증 |
|---|---|---|
| `POST /api/class/remote-support/helper-code` | 직원 → 학생 | 관리자 세션 |
| `POST /api/class/remote-support/student-code` | 학생 → 직원 | 세션 토큰 |
| `GET /api/class/remote-support/pin-status` | 직원이 «학생이 넣었나» 확인 | 관리자 세션 |
| `GET /api/class/remote-support/status` | 학생이 «코드가 왔나» 확인 | 세션 토큰 |

- 새 칸 7개는 **지연 ALTER**(`attendance.host` 와 같은 방식). 키를 `remote_support_pins_v2` 로 바꿔 배포 뒤 한 번은 반드시 돌게 했습니다.
- 화면: `js/idx-remote-support.js`(학생) · `js/adm-remote-pin.js` + `admin.html` `#rsc-relay`(직원)

### 2-3. 배포 주석 정정 (#721)

`deploy.yml` 의 「보류된 커밋은 위 schedule(**23:35 KST**)이 몰아서 내보낸다」가 사실이 아니었습니다(실제 크론은 01:30 KST).
창을 01:20 까지 늘리며 크론은 옮겼는데 그 주석만 남은 것이라, **「보류된 배포가 언제 나가는지」를 거짓으로 말하고 있었습니다.**

⚠️ 저장소의 다른 `23:35` 언급 네 곳은 전부 **경위 서술**이거나 하니스 시험값이라 맞습니다 — **틀린 것은 그 한 줄뿐**이었습니다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

### 3-1. ⛔ 「404 카드를 고친다」 (사장님이 처음 지시하신 것)

제가 「카테고리 모달의 `<a href="/remote.html">` 가 404 난다」고 보고했고, 사장님이 「그것도 고쳐줘」라고 하셨습니다.
**고치려고 브라우저로 확인해 보니 그 카드가 화면에 존재하지 않았습니다.**
고쳤다면 «고쳤습니다» 인데 화면에는 아무 변화가 없는 — 이 저장소가 반복해서 경계하는 그 상태가 됐을 것입니다.
⟹ 대신 **실제로 사람이 닿는 자리**에 입구를 만들었습니다.

### 3-2. ⛔ B안(학생 화면공유 «보기») — 사장님이 고르셨지만 만들지 않았습니다

사장님이 **A+B** 를 고르셨습니다. 만들기 전에 값을 재 보니 **B 는 값이 없었습니다.**

- `js/idx-main.js:952` 가 직접 「**컴퓨터의 크롬이나 엣지에서 사용해 주세요**」라고 말합니다 — **모바일 브라우저는 `getDisplayMedia` 를 지원하지 않습니다.**
- PC 에서는 A(Quick Assist)가 **조작까지** 되므로 «보기» 는 열등합니다.

⟹ **A 가 되는 곳에선 열등하고, A 가 안 되는 곳에선 불가능**합니다.
B 를 고르신 이유가 «모바일을 덮는 것» 이라고 보고, 모바일을 **실제로** 덮는 «학생 → 직원 번호 전달»(AnyDesk 방향)을 대신 만들었습니다.
**대체한 사실과 근거를 그 자리에서 보고**했습니다(PR #713 본문에도 적혀 있습니다).

### 3-3. ⛔ 독(dock)에 8번째 버튼

수업 중 입구를 독 버튼으로 만들려다 버렸습니다 — 독은 폭이 `96vw` 로 꽉 차 있어 **좁은 폰에서 줄이 넘칩니다**(CLAUDE.md 기존 함정).
⟹ 설정 시트 안의 한 줄로. 하니스가 「독 버튼 개수 7 그대로」를 못 박습니다.

### 3-4. ⛔ 수업 중에 눈에 띄는 자리

원격지원은 Quick Assist 를 **지금부터 깔고 코드를 주고받는** 일이라, 20분 수업 중에 시작하면 수업이 끝납니다.
수업 중에 필요한 것은 카톡 상담과 마이크·소리 확인이고, 원격은 **수업 «전»** 에 잡아 두는 도구입니다.
⟹ ④는 설정 시트 안의 **조용한 뒷자리**.

### 3-5. ⛔ 학생 쪽 조회를 PIN 으로 열기

`GET status` 를 PIN(6자리)으로 열면 **`claim` 의 시도 5회 제한을 우회**해 번호를 무제한 찍어 볼 수 있습니다.
⟹ `claim` 이 **32자 세션 토큰**을 발급하고 그 뒤로는 그것만 씁니다.

### 3-6. ⛔ 코드를 자유 문자열로 받기

그 값은 상대 화면에 그대로 그려집니다. ⟹ **숫자 4~12자리만**(Quick Assist 6 · AnyDesk 9~10 · Chrome 원격 12 을 덮습니다).

### 3-7. ⛔ 학생이 PIN 을 넣기 전에도 직원이 «보내기»

보낼 곳이 없는데 «보냈다» 고 답하면 직원은 기다리기만 합니다.
⟹ 서버가 `not_claimed` 로 거절하고, **화면도 학생이 넣기 전에는 버튼을 잠급니다.**

### 3-8. ⛔ 전체메뉴 타일 `href="#"`

자바스크립트가 죽으면 「눌러도 아무 일도 없음」이 됩니다. ⟹ `href="/?menu=remote"`(폴백이 진짜로 동작).

### 3-9. ⛔ `deploy.yml` 주석에 시각을 숫자로 다시 적기

그게 애초에 이 문제를 만든 방식입니다. ⟹ 크론을 **가리키게** 두고, 왜 그런지를 함께 적었습니다.

## 5. 남은 것 / 주의할 것

### 사람이 확인해야 하는 것

1. **홈 ➕** (PC 왼쪽 아래 / 폰 오른쪽 아래) → 세 번째에 **🛠 원격 도움받기** 가 뜨는지
2. **관리자 › 학생관리 › 🛠 원격 수리 / 점검 센터** → PIN 만들기 → 학생이 넣으면 **「✅ 학생이 번호를 넣었습니다」로 바뀌고 보내기 잠금이 풀리는지**
3. **실제 Quick Assist 로 PC 두 대 연결** — 여기서 확인한 것은 «코드가 오간다» 까지입니다. **조작이 실제로 되는지는 기기로 해 봐야** 압니다.
4. **아이폰** — 애플이 서드파티에 화면 조작 권한을 주지 않는다는 것은 **제가 아는 플랫폼 사실이고 이번에 잰 것이 아닙니다.** 실제 기기로 확인이 필요합니다.

### 안 한 것

- **`fix-v19` 는 그대로 뒀습니다.** `index.html:14675` 가 `#grid-menu`·`#cat14-modal`·`#v11-modal` 을 `display:none !important` 로 통째로 감춥니다. 일부러 감춘 것인지 사고인지 확인되지 않았고, 반경이 홈 첫 화면이라 별건입니다.
- **B안(화면공유)** — 위 3-2 참고. 원하시면 별건으로 넣을 수 있습니다.

### 주의

- 이 기능은 **우리 서버가 학생 화면을 조작하지 않습니다.** 코드를 나르기만 합니다. 그런 코드를 여기에 붙이지 마세요.
- PIN 은 **10분 · 1회용 · 시도 5회 제한**입니다. 코드 조회는 **반드시 세션 토큰으로** — PIN 으로 열면 그 제한이 무의미해집니다.
- `js/idx-main.js` 는 blocking 849KB 라 손대지 않았습니다. 홈 ➕ 항목은 **defer 파일에서 밖에서 끼워 넣습니다** — `index.html` 은 `?v=` 만 바뀌어 **바이트 변화 0**(첫 화면 예산 무영향).

절반만 풀린 상태였습니다 — 컴퓨터가 안 되는 사람에게 스무 칸을 훑게 하는 것은 여전했습니다.

### 무엇을 바꿨나 (`js/idx-allmenu.js`, `index.html` 은 `?v=` 한 줄)

- `ALLMENU_ITEMS` 그리드 목록에서 **빼고**, 그리드 «위» 에 **전폭 강조 카드**(`#mgam-remote`)로 그립니다.
- 강조는 앰버 그라데이션 + 2px 테두리 + 은은한 펄스. **기본 그림자를 «항상 보이는» 값으로** 두고
  펄스는 그 위에만 얹었습니다 — 백그라운드 탭·저전력에서 애니메이션이 멈춰도 강조가 사라지지 않습니다.
- `href="/?menu=remote"` 폴백과 `data-remote-help` 모달 배선은 **그대로 옮겼습니다**(2장의 계약).
- 라벨은 KO/EN 둘 다. 판정은 `getLang()` 우선(`index.html` 은 i18n 엔진이 둘입니다).

### 왜 그렇게 풀었나 — 검토했다가 버린 방법

| 방법 | 왜 안 했나 |
|---|---|
| **그리드 목록에서 첫 번째로 올리기만** | 「가장 먼저」는 되지만 「별도·강조」가 안 됩니다. 같은 크기·같은 색이라 여전히 스무 칸 중 하나입니다 |
| **그리드에도 남기고 + 위에도 강조 카드** | 「별도 넣어줘」를 그렇게 읽을 수도 있었지만, **한 화면에 같은 것이 둘**이 됩니다. 이 저장소가 「레벨 테스트 타일」에서 이미 한 번 정리한 형태라 하나로 뒀습니다 |
| **폰에서도 「지금 도움받기」 라벨 유지** | 390px 에서 부제가 3줄로 늘어 카드가 커집니다. 라벨을 접고 **화살표만** 남겼는데, 그 화살표는 `::after` 가상요소로 그립니다 — `data-ko/data-en` 이 `textContent` 를 통째로 갈아끼워도 살아남습니다(CLAUDE.md 「표 머리글에 정렬 화살표」와 같은 뿌리) |
| **부제에 「접속 코드로」 유지** | 폰 KO 에서 3줄이 됐습니다. 코드 안내는 모달 안에서 어차피 나오므로 부제를 줄였습니다 |
