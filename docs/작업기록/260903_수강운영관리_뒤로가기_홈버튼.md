## 1. 왜 했나

사장님이 「수강 운영 관리」 화면 캡처(크롬 「창으로 열기」 — 주소창이 없는 창)를 주시며
**「뒤로가기 화살표, 홈버튼 만들어줘」**.

`/enroll-ops.html` 은 관리자 사이드바(`adm-ia6.js` 「수강 운영」)에서 **새 창처럼 열리는 독립 페이지**인데,
- 공용 [🏠][🌐] 바(`js/mango-i18n.js`)를 안 싣고
- 공통 뒤로가기(`js/back-nav.js`)도 안 싣고 있어서

**나갈 길이 하나도 없었습니다.** 주소창이 없는 창·앱에서 열면 그 화면에 갇힙니다
(CLAUDE.md 2장 「화면을 통째로 덮는 «먼저 고르는» 화면을 만들었더니 나갈 길이 하나도 없음」과 같은 뿌리).

## 2. 무엇을 바꿨나

파일 **하나**: `cloudflare-deploy/public/enroll-ops.html` (+33줄)

| 자리 | 내용 |
|---|---|
| `<style>` `.nav` | 제목 위 알약 버튼 줄. 기존 `.tab` 과 같은 모양(흰 바탕·앰버 글자·`white-space:nowrap`) |
| `<nav class="nav">` (h1 바로 위) | `<a id="lnk-back" href="/admin.html">← 뒤로</a>` · `<a id="lnk-home" href="/admin.html">🏠 관리자 홈</a>`. 둘 다 `data-ko`/`data-en`·`title` |
| 스크립트 꼬리 | `lnk-back` 클릭 → `window.mangoiGoBack('/admin.html')` 이 **있으면** 그것으로(`preventDefault`), 없으면 `href` 그대로. `localStorage['mangoi_lang']==='en'` 이면 `.nav [data-en]` 의 글자를 영어로 |
| 맨 끝 | `<script src="/js/back-nav.js" defer>` 추가 |

- ← 는 **직전 화면**(히스토리 → 같은 오리진 referrer → 폴백 `/admin.html`), 🏠 는 **관리자 홈**.
- 글자가 `←` 로 시작하므로 `back-nav.js` 의 `hasVisibleBack()` 이 참이 되어 **자기 동그란 ← 를 안 넣습니다**(화살표 두 개 방지).

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

| 버린 것 | 이유 |
|---|---|
| `back-nav.js` 만 싣고 끝내기(동그란 ← 자동 주입) | 홈 버튼이 없고, 좌상단 고정 동그라미가 제목과 겹칩니다. 그리고 이 화면 톤(앰버 알약)과 안 맞습니다 |
| 공용 `mango-i18n.js` 글로벌 바([🏠][🌐]) 싣기 | 그 바의 🏠 는 **학생 홈(`/`)** 으로 갑니다. 관리자 화면에서는 `/admin.html` 이어야 합니다. 그리고 그 엔진은 `[data-ko],[data-en]` 요소의 `textContent` 를 통째로 갈아끼우는데, 이 화면의 탭·카드가 그 속성을 안 쓰고 있어 혼재가 생깁니다 |
| 뒤로 판정을 이 화면에 새로 적기(`history.back()` 등) | CLAUDE.md 2장 정본 규칙 — 판정은 `back-nav.js` 의 `mangoiGoBack` **하나**. 복제하면 한쪽만 고쳐집니다. 카톡 링크로 바로 들어온 사람에게 `history.back()` 은 무반응이라 그 판정(referrer 폴백)이 필요합니다 |
| 아이콘만 두고 `title` 로 설명 | 폰에는 hover 가 없어 설명이 안 뜹니다(2장 함정). 글자를 함께 그렸습니다 |
| `data-ko`/`data-en` 만 달고 엔진에 맡기기 | 이 화면에는 i18n 엔진이 없습니다. `adm-lang-boot.js` 도 안 실으므로 정본 키 `mangoi_lang` 을 직접 읽었습니다(⛔ `'adminLang'` 은 죽은 키) |
| 🏠 를 `mangoiGoBack` 없이 순수 링크로만 | 그대로 했습니다 — 홈은 판정이 필요 없습니다 |
