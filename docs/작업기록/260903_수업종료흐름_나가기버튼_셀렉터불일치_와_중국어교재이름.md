# 「중국어 복습퀴즈도 설문조사도 안 나온다」 — 원인 두 가지와 수리

- 날짜: 2026-09-03
- 제보: 사장님 (2026-09-02 `class-849-20260902` 중국어 수업 직후)
- 브랜치: `claude/chinese-quiz-survey-missing-61ye2h`

## 1. 왜 했나

수업 화면 스크린샷과 함께 「중국어 수업 후에 왜 중국어 복습퀴즈가 나오지 않고 설문조사도 안 나오는지」 질문을 받았습니다.
조사해 보니 **원인이 둘이고 서로 다른 것**이었습니다.

- 「설문조사」 = 수업 종료 평가 모달(⭐ 7점 + 태그 + 📝 파일럿 구글폼)
- 그 모달과 복습퀴즈는 **평가 → 퀴즈 «직렬»** 이라, 앞에서 끊기면 둘 다 사라집니다

## 2. 원인 ① — 「나가기」가 종료 흐름에 이어져 있지 않았다

`index.html:4309` 의 `endOfClassFlow()` 를 깨우는 방아쇠는 둘뿐입니다.

| 방아쇠 | 상태 |
|---|---|
| ⓐ 나가기 버튼 클릭(4325행 `isExitBtnEl`) | 🔴 죽어 있었음 |
| ⓑ 강사 퇴장 후 10초(4408행) | ✅ 동작 |

ⓐ가 찾는 셀렉터는 `a#vc-exit-btn-v34, … , button.ctrl-btn.danger, a.ctrl-btn.danger` 인데,
화면에 실제로 보이는 빨간 「나가기」는 **하단 독이 그리는 `button#vc-dock-leave.leave`**
(`js/vc-dock.js` `mk('leave',…)`)라 **한 셀렉터에도 안 걸렸습니다.**
게다가 `vc-dock.js:106` 이 옛 버튼(`#vc-exit-btn-v34`)을 `display:none !important` 로 숨깁니다.

⟹ **사실상 ⓑ로만 뜨고 있었습니다.**

## 3. 원인 ② — 학생 화면은 「이 수업이 중국어」인 걸 알 방법이 없었다

복습퀴즈가 교재·언어를 읽는 자리는 `window.__mangoiCurrentBookId` 하나(`js/idx-x8.js` 의 `ctx()`)인데,
그 값을 채우는 곳이 저장소 전체에 **두 곳뿐이고 둘 다 `js/idx-x3.js` = 「내가 라이브러리에서 직접 고를 때」** 였습니다.
교재 공유를 **받는** 쪽(`pdf-share` 수신 → `vcApplySharedPdf`)에는 채우는 코드가 **0곳**.

⟹ 교재를 고르는 사람(강사)은 퀴즈를 안 풀고, 푸는 사람(학생)은 교재 이름을 가진 적이 없습니다.
그래서 서버의 zh 승격(`api-games.ts:1889`, 2026-08-26 수리)이 **발동할 근거를 못 받아 라이브에서 한 번도 닿지 못했습니다.**

## 4. 검토했다가 버린 방법

- **`endOfClassFlow` 를 defer 파일에서 직접 부르기** — 그 함수는 IIFE 안이라 밖에서 못 부릅니다.
  전역으로 노출된 `window.mangoShowRating()` 은 «미리보기» 용이라 `after` 가 빈 함수 → 복습퀴즈로 안 이어집니다.
- **독 버튼 클릭 때 옛 버튼에 합성 이벤트 보내기** — 강사 경로에서 v29/v32/v34 가 그 합성 이벤트를 잡아
  `location.replace` 로 홈에 보내 버립니다(방 정리 없이 튕김).
- **`ctrl-btn danger` 클래스를 그냥 달기** — 브라우저 실측 결과 `css/vc-refresh.css:29` 의
  작성자 `!important` 가 이겨 **연빨강(.18) → 진빨강(.96)+흰글자**가 됐습니다.
  사장님이 지시하지 않은 시각 변경이라 독 CSS 에서 `!important` 로 되돌렸습니다.
- **`isStudentInClass` 를 defer 에서 복제** — 판정이 두 벌이 되어 조용히 어긋납니다. 하지 않았습니다.
- **교재명을 url·R2 키에서 짐작** — 난수라 단서가 없습니다. 파일명의 `[교재명]` 만 씁니다.

### 🔴 터치(폰)는 따로 한 줄이 더 필요했습니다

학생 방아쇠는 `touchend` 를 안 잡는데 v29·v34 는 그것을 캡처합니다.
**함정 대조 서브에이전트가 이걸 잡아 줬습니다** — 안 그랬으면 「고쳤다」로 보고하고
폰 학생(대다수)에게는 그대로였을 것입니다. 사장님 승인을 받아 `'touchend'` 를 더했습니다.

## 7. 🪤 이 작업에서 밟은 함정 (CLAUDE.md 2장에 추가함)

1. **서비스워커가 변이시험을 «통과» 시켰습니다.** `Network.setCacheDisabled` 는 HTTP 캐시만 끕니다.
   고침을 되돌려도 브라우저가 새 사본으로 동작해 **「고쳐졌다」를 확인한 검사가 실은 아무것도 안 보고 있었습니다.**
   → `Network.setBypassServiceWorker` 를 함께 켜야 합니다.
2. **폰 검사를 마우스로 재서 거짓 초록이 났습니다.** 폭만 좁히고 `dispatchMouseEvent` 를 썼더니 통과했는데,
   실제 터치(`dispatchTouchEvent`)로는 실패했습니다.
3. 회전 안내 오버레이(`#vc-orientation-overlay`)·독 접힘(`#vc-dock-more`) — 둘 다 CLAUDE.md 에 이미 있던 함정입니다.
