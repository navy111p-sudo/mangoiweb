## 3. 검토했다가 버린 방법

| 안 한 것 | 왜 |
|---|---|
| **통화를 환산해 하나의 숫자로** | 환율을 우리가 모릅니다. 지어내면 그 숫자가 그대로 판단 근거가 됩니다. → **통화별로 나란히** (PHP · KRW) |
| **승인·대기·반려를 합쳐 「이번 달 지출」** | 대기는 아직 안 쓴 돈, 반려는 안 쓴 돈입니다. 합치면 그 문장이 거짓이 됩니다 → 갈라서 적고 **반려는 어느 합계에도 안 넣습니다** |
| **금액 없는 건을 0원으로** | 「모른다」와 「0원」은 다른 사실입니다 → 합계에서 빼고 **「금액 없음 N건」**으로 따로 말합니다 |
| **항목 없는 건을 「기타」로** | «안 고름» 과 «기타를 고름» 은 다른 사실입니다. 섞으면 기타가 부풀어 「기타가 제일 크다」가 됩니다 → **「항목 없음」** 줄로 따로, 그리고 맨 뒤에 |
| **SQL `GROUP BY` 로 집계** | 빠르지만 **`canView` 를 못 겁니다** — 인사·급여가 합계에 섞입니다. → 행을 읽어 코드로 세고, **상한(2,000행)**을 두고 넘으면 「잘렸다」고 말합니다 |
| **새 API 경로** | 관문이 셋이고 그중 둘이 공동 금지구역입니다(A안과 같은 이유) → 기존 `GET /api/approval/requests` 에 `view=report` 만 |
| **새 화면(`/spending` 등)** | 확장자 없는 주소는 `src/index.ts` 세 곳에 등록해야 합니다(금지구역) → `/work` 안의 접이 패널 |
| **첫 화면에서 미리 부르기** | 이 화면은 「첫 화면 API 한 번」 설계입니다 → 접혀 있다가 **누를 때만**, 그리고 한 번만 |
| **기간을 비워 두고 전 기간** | 「이번 달 얼마 썼나」에 답을 못 합니다 → 기본이 **이번 달 1일부터** |
| **금액 순 정렬** | 통화가 여럿이면 비교할 공통 잣대가 없습니다(환산 금지) → **건수 순**, 그다음 이름순 |
| **화면에서 통화를 더하기** | 서버 규칙을 화면이 무너뜨립니다 → 화면은 나열만 |

## 4. 검사 쪽에서 걸린 것 — 제 검사가 **두 번 헛돌았습니다**

변이시험(되돌려 보기)에서만 드러났습니다. 둘 다 **통과하는데 아무것도 안 보고 있던** 상태입니다.

### ① 「`canView` 뒤에 집계하는가」가 언제나 참이었습니다

`api-approval.ts` 전체에서 `indexOf('if (!canView(actor')` 를 했는데 그 문자열이 이 파일에
**네 곳**(828·861·1249·1414행) 있고 **첫 번째가 훨씬 앞**입니다. 그래서 집계를 canView
**앞으로** 옮겨도 늘 «뒤» 로 판정됐습니다 — 인사·급여가 합계로 새는 변이가 통과했습니다.

→ **그 라우트만 중괄호 짝으로 잘라** 그 «안» 에서 비교합니다.
⚠️ 그때 앵커를 `path === '…/requests'` 로 잡으면 **POST 라우트가 먼저** 걸립니다(941행) —
메서드까지 넣어야 합니다.

### ② 「모르는 것을 말하는가」가 자기 문구를 잡고 있었습니다

`/no_category/.test(work)` 였는데, 조건을 `if (false)` 로 죽여도 **안내 문구 안에 그 이름이
그대로 남아** 통과했습니다. → **조건 자체**(`if (s.no_category)`)를 봅니다.

### ③ 브라우저 검사도 하나 — 「반려 금액이 안 보인다」

`t.indexOf('99,999') < 0` 이었는데, 반려가 승인에 **더해지면** 103,499 가 되어 그 글자가
사라집니다. → **승인 칸의 값 자체**를 봅니다.

> 📌 그리고 **변이시험 자체가 틀렸던 것도 한 번** 있었습니다 — `normCurrency(currency)` 를
> 바꾸려 했는데 그 문자열이 파일에 세 곳 있어 **엉뚱한 줄**(248행)이 바뀌었습니다.
> 「변이를 넣었는데 FAIL 이 안 난다」면 **변이가 정말 그 자리에 들어갔는지**부터 보세요
> (그래서 변이 스크립트마다 `assert` 를 답니다).
