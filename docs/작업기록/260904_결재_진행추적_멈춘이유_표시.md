## 2. 무엇을 했나

### 서버 — `src/api-approval.ts`

* **`approverCounts()` 신설** — 「이 건들을 **지금 결재할 수 있는 사람이 몇 명인가**」를 센다.
  기존 `approversFor()` 와 같은 규칙(`canDecideStage` + 기안자 제외)을 쓰되
  **계정 조회는 한 번만** 한다.
* `/api/approval/home` 의 `mine` 중 **대기 중인 건에만** `approver_count`·`blocked` 를 얹는다.
* **ETag 에 hq 계정 수를 넣었다**(`a3-` → `a4-`) — 안 넣으면 경영진을 추가해도
  「바뀐 것 없음(304)」으로 옛 화면이 최대 1시간 남는다.

### 화면 — `public/work.html`

* **진행바**(`trackHtml`) — 올림 → 단계마다 → 완료. 상태별 색(승인 초록 · 진행 앰버 ·
  반려/멈춤 빨강). **내가 올린 건에만** 그린다.
* **「N일째」** — 「대기 중」만으로는 며칠 지났는지 알 수 없어 숫자를 함께 적는다.
* **「이대로는 처리되지 않습니다」**(`stuckHtml`) — 서버가 «0명» 이라고 알려 준 건에만.
  막힌 단계 이름과 이유(본인 결재 금지)를 함께 말한다.
* **「멈춤」 칩** + `hot` 테두리 — 지연(`Overdue`)과 **다른 사실**이라 따로 센다.

### 6-2. 「Document 를 눌렀는데 파일 올릴 버튼이 없다」

**원래부터 없었습니다** — `doc` 은 만들어질 때(2026-09-02, `3e3cd0c`)부터 `wantsFile: false`

🔴 **`wantsFile` 한 칸이 두 가지를 겸하고 있었습니다**:
① 화면에 첨부 버튼을 그릴까 ② 없으면 「영수증 첨부 없음」 경고를 낼까.

✅ 축을 갈랐습니다 — **`wantsFile`**(붙일 수 있는가) · **`requiresFile`**(반드시 있어야 하는가).
`runChecks` 는 이제 `requiresFile` 만 봅니다. 화면 문구도 그것으로 가릅니다

⚠️ **OCR 도 갈랐습니다** — 일반 문서 사진에 `/api/approval/ocr` 을 부르면
「영수증을 읽는 중」·「금액을 직접 넣어 주세요」라는 엉뚱한 문구가 뜨고 **돈이 나갑니다.**
`requires_file` 가 아니면 첨부만 하고 건너뜁니다.

⚠️ **워드·한글은 아직 못 붙입니다** — 서버가 파일 «내용»을 보고 jpg·png·webp·pdf 만

⚠️ **범위를 안 넓혔습니다** — 고객 불만·휴가는 그대로 첨부 없음입니다. 필요하면 말씀해 주세요.

### 무엇을

* **함(트레이)** — 내가 올린 것(전체) · 진행 중 · 승인 완료 · 반려,

* **기간·분류·상태** 필터, **더 보기**(20건씩), **엑셀 내려받기**.

### 어떻게 (설계에서 지킨 것)

| 지킨 것 | 왜 |
|---|---|
| **새 API 경로를 안 만들었다** | 이미 등록된 `GET /api/approval/requests` 에 **쿼리 파라미터만** 얹었다. 새 경로는 관문이 셋이고 그중 둘이 공동 금지구역이다(CLAUDE.md 4-2) |
| **`LIKE` 를 안 썼다** | D1 의 LIKE 패턴 한도는 **50자**다(CLAUDE.md 2장 실측). 제목·내용은 더 길 수 있고, 이름 속 `%`·`_` 를 와일드카드로 오해한다 → **`instr()`** |
| **판정을 순수 함수로 뺐다** | `buildFindQuery()`(`approval-policy.ts`). 라우트 안에 두면 하니스가 «글자» 로밖에 못 본다 — 부등호를 뒤집어도 그 줄은 그대로다 |
| **총 건수를 안 내려준다** | 열람등급(`canView`)으로 한 번 더 거르므로 SQL `COUNT` 와 어긋난다. 「1-20 / 총 50건」이 거짓말하느니 **「더 보기」** 가 낫다 |
| **`limit+1` 로는 «있는가» 만 판정** | 그것으로 «몇 건 남았는지» 를 말하면 언제나 «1건» 이 되어 거짓이 된다 |
| **단계를 한 번에 읽는다** | 예전 코드가 행마다 `chainOf` 를 불렀다 — 목록 20건에 D1 조회 20번. `stepsByRequest` 로 1회 |
| **첫 화면은 그대로 API 한 번** | 문서함은 **접혀 있다가** 사람이 «찾기» 를 눌렀을 때만 서버를 부른다 |
| **CSV 수식 차단** | 셀이 `=` `+` `-` `@` 로 시작하면 엑셀이 **수식으로 실행**한다. 결재 제목은 사람이 적는 값이라 그대로 넣으면 남의 컴퓨터에서 수식이 돈다 → 앞에 `'` |
| **CSV 에 BOM** | 없으면 한국어 엑셀이 UTF-8 을 못 알아보고 한글이 깨진다 |
| **CSV 도 `canView` 를 지난 것만** | 인사·급여가 파일로 새면 화면보다 더 나쁘다. `Cache-Control: private, no-store` 도 함께 |
| **`window.open` 을 안 썼다** | 카톡·문자 인앱 브라우저는 새 창을 못 열면서 **예외도 안 던지고 null 만** 돌려준다(CLAUDE.md) |

### 이번에도 검사 쪽에서 두 번 걸렸습니다

1. **`location.href` 후킹** — 엑셀 검사를 그렇게 짰더니 크롬이 재정의를 **조용히 무시**해
   진짜로 파일을 받으러 가면서 검사가 죽었습니다(CLAUDE.md 2장에 있는 그 함정).
   `page.route` 로 가로채고, 그 절을 **맨 뒤로** 옮겼습니다(네비게이션이 페이지 상태를 흔듭니다).
2. **버튼이 없을 때 `click()`** — 타임아웃으로 검사가 통째로 죽어 무엇이 깨졌는지 안 보였습니다.
   없으면 «못 눌렀다» 고 **깔끔한 FAIL** 로 남깁니다.
