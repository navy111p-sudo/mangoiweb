## 3. 두 편 «다» 바꾼 이유

지시는 「아까 만든 동영상」 하나였지만 **두 편 다** 바꿨습니다 — 한 편만 바꾸면 사이트에
목소리가 두 개 도는 상태가 되고, 두 영상이 같은 화면(홈 「망고아이란?」·`today.html`)에서
나란히 안내되기 때문입니다.

⚠️ **긴 판의 옛 나레이션은 지우지 않았습니다** — `video5` 브랜치의 `.video/narration.mp3`(8MB)에
있습니다. 되돌리려면 그 파일과 `_video_build.yml` 로 다시 돌리면 됩니다.
**(2026-09-05 `git ls-remote --heads origin video5` 로 브랜치 실재 확인 — `1bad9363`.)**
⚠️ 그 브랜치를 지우면 되돌릴 근거가 함께 사라집니다.

## 4. 배경음악 — 「시작과 끝에」를 어떻게 넣었나

짧은 판은 나레이션이 **t=0 부터** 시작합니다. 그래서 음악을 «시작과 끝에만 켜고 중간엔 끄는»
방식으로 하면 켜지고 꺼지는 것이 그대로 들립니다. 대신 **볼륨 봉투**를 썼습니다 —

```
0 → 1.0s   페이드인 0 → 0.20   (≈ −14dB)
1.0 → 4.5s 0.20 유지            도입부: 들린다
4.5 → 7.5s 0.20 → 0.05 로 낮춤
… 말하는 동안 0.05 (≈ −26dB)    깔리기만 한다
T−8 → T−5.5  0.05 → 0.18 로 올림  마무리: 다시 들린다
T−2 → T     0.18 → 0 페이드아웃
```

⛔ **이 값을 올리지 마세요.** 「음악이 잘 안 들린다」보다 「말이 안 들린다」가 훨씬 나쁩니다.

### 검토했다가 버린 것

- **음악을 시작·끝 구간에만 붙이기** — 중간에 뚝 끊겼다 다시 시작하는 것이 들립니다.
- **긴 판에도 같은 음악 깔기** — 긴 판은 이미 시그널(6.0초)·엔딩(7.0초) 음악이 있습니다
  (`.video/music.sh` — ffmpeg 사인파 합성이라 저작권 걱정이 없습니다). 이미 「시작과 끝에」가
  만족돼 있어 손대지 않았습니다.
- **ffmpeg 사인파 패드를 짧은 판에도 쓰기** — 그건 «시그널» 소리지 «잔잔한 배경음악» 이 아닙니다.

## 5. 밟은 함정

### 5-1. 프록시가 CloudFront 를 막는다
생성된 wav 를 이 컨테이너에서 받으려니 `connect_rejected` 였습니다. 러너에서 받아야 합니다
(기존 방식 그대로 `narration.json` 에 URL 만 담아 넘김). 대신 러너에서 **받은 것이 진짜 오디오인지**
`ffprobe` 로 한 줄씩 확인합니다 — 404 본문이 `.wav` 이름으로 저장돼도 `curl` 은 성공하기 때문입니다.

### 5-2. seed_audio 429 (rate limit)
한 번에 12줄을 넣으면 몇 개가 `submission_failed (429)` 로 떨어집니다. **6줄 안팎으로 나눠**
넣고 실패한 index 만 다시 넣었습니다. `submitted_count` / `failed_count` 를 꼭 보세요.

### 5-3. 필터식의 쉼표
음량 봉투가 `if(lt(t,a),b,c)` 중첩이라 쉼표가 많습니다. 셸 따옴표로 넘기면 새기 쉬워
**`-filter_complex_script` 파일**로 넘겼습니다.

### 5-4. 「몇 분 지났나」를 배경 sleep 으로 세지 말 것
CLAUDE.md 에 이미 있는 함정을 그대로 밟을 뻔했습니다 — 러너 로그의 08:58 을 보고 «10분째 멈췄나»
싶었는데 `date -u` 를 찍으니 실제로는 **2분**이었습니다. 경과 시간은 반드시 시계로 재세요.

### 5-5. 길이가 바뀌면 화면 문구도 바뀐다
`today_plan_harness` ⑨절이 **화면이 말하는 길이 ↔ mp4 `mvhd` 실제 길이**를 ±5초로 대조합니다.
목소리가 바뀌면 길이가 바뀌므로 다음 **6개 파일**을 함께 고쳐야 합니다 —
`promo.html`(프리셋 2개의 `len`·KO/EN 제목) · `js/idx-about.js`(카드 제목·설명·버튼) ·
`today.html` · `js/today-page.js` · `admin.html`(자료실 설명). 안 고치면 그 검사가 FAIL 납니다.

🪤 **여섯 번째가 `test-harness/manual/video-entry-browser.mjs` 였습니다** — 그 검사가
`'3:35'`·`/3분 35초/`·`'0:39'`·`/39초/` 를 **글자 그대로** 못 박아 두어, 길이가 바뀌자
**보장은 그대로인데 검사만 6건 깨졌습니다**(`manual/` 은 게이트가 안 물어 가서 CI 는 초록 —
다음에 사람이 돌릴 때 빨간불 6개를 보고 «감시를 안 믿게» 되는 쪽으로 썩습니다).
✅ 이제 그 검사는 **`promo.html` 의 프리셋을 읽어** 기대값을 만듭니다 —
물어야 할 것은 «몇 분인가» 가 아니라 **«`len` 과 화면 문구가 서로 같은 말을 하는가»** 입니다.
(변이시험: 제목만 옛 길이로 되돌리니 실제로 1건 FAIL.)
