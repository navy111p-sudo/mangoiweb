# 안내 영상 입구 두 곳 — A안 + B안 (2026-09-05)

> 사장님 지시 — 「이 영상을 여기 적당한 곳에 넣었으면 좋겠어. 처음 들어오는 사람들이
> 들어보고 이해하게. 3가지 안을 알려줘」 → 3안을 드렸고 **A안 + B안 둘 다** 고르셨습니다.

## 먼저 잰 것 — 이것이 «어디에 넣을까» 의 답을 바꿨습니다

**① 이 영상은 «선생님·원장님께» 말합니다.**
대본 실제 문장 — 「**선생님은** 그 아이를 깨우는 데 시간을 쓰십니다」 · 「**선생님이** 하실 일은
교재를 고르는 것 하나입니다」 · 「이 도구만 도입해도 되느냐고 **물으시면**」. 아이를 3인칭으로 부릅니다.
⟹ 사장님이 보내주신 화면(`today.html`)은 **학생 화면**이라, 그대로 넣으면 초등학생이
자기 이야기가 아닌 3분 35초를 듣게 됩니다. **그래서 두 입구 모두 문구에 대상을 적었습니다** —
「원장님·선생님께 드리는 안내예요. 부모님과 함께 보셔도 좋아요.」

**② 24.4MB 입니다.** 이 저장소는 이미 그 판단을 해 뒀습니다 —
`adm-promo-setup.js` 주석: 「볼 생각이 없는 학생에게도 앞부분이 내려간다. 포스터 그림 + 링크로 간다.」
⟹ 두 입구 모두 **누르기 전엔 영상 0바이트**(포스터 26KB 만 그립니다). 브라우저로 실측했습니다.

## A안 — 홈 「망고아이란?」 맨 앞 영상 카드

`js/idx-about.js` 의 `BENEFITS` 맨 앞에 카드 한 장. 상세에 포스터 + 「▶ 영상 보기(3분 35초)」.

**왜 여기인가** — 그 오버레이를 여는 사람이 곧 「이게 뭐 하는 곳이냐」고 묻는 사람입니다.
원장·학부모·새 선생님이 섞여 있어 영상의 대상과 맞습니다. 홈 검색·드로어·전체메뉴에서
이미 여러 길로 열립니다.

⚠️ **`index.html` 은 공동 금지구역이라 `?v=2` → `?v=3` 한 토큰만** 고쳤습니다(캐시 원장 규칙).
첫 화면 무게는 안 늘었습니다 — 카드는 `idx-about.js`(defer) 안에 있습니다.

⚠️ 카톡·문자앱 인앱 브라우저는 새 창을 **못 열고 null 만** 돌려줍니다(예외도 안 납니다).
⛔ 기능 문자열에 `noopener` 를 주면 표준상 반환이 늘 null 이라 «막혔다» 판정이 **항상 참**이 됩니다
→ 빼고 연 뒤 `w.opener = null` 로 같은 보호를 걸고, 못 열면 `location.href` 로 갑니다.

## B안 — today.html 첫 방문자에게만 한 줄

인사 카드 «아래», 「오늘 할 일」 «위».

🔴 **«처음 온 사람» 을 무엇으로 가릴지에서 한 번 틀렸습니다.**
처음에는 서버가 준 `plan.band` 하나(= 아직 레벨이 없다)로 했습니다. 그런데 함정 대조 지적을 받고
**D1 을 직접 세니 `students_erp.level` 이 29,481명 중 «1명»** 만 채워져 있었습니다
(CLAUDE.md 2장 「나이·학년으로 자동 분류」와 같은 사정 — 8/24·8/31 에도 0명으로 실측돼 있었습니다).
⟹ 그 조건은 사실상 **«로그인한 학생 전원»** 이라 «처음» 을 하나도 못 거릅니다.
하필 내용이 「원장님·선생님께 드리는 안내」라 대상 불일치가 그만큼 커집니다.

✅ 그래서 실제로 거르는 것은 **이 화면을 연 횟수**(기기별, 처음 3번)로 바꿨습니다.
⛔ `p.band` 를 빼지는 않았습니다 — 레벨이 채워지기 시작하면 «레벨 있는 사람» 은 그날부터
바로 안 보게 되는 것이 맞습니다. 지금은 아무것도 안 거를 뿐입니다.

- 닫기(✕)를 누르면 다시 안 뜹니다(`mangoi_today_intro_v1`).
- ⛔ 그 값을 못 읽어도 **«안 뜨는» 쪽으로 실패하지 않습니다** — 못 읽으면 그냥 보여 줍니다.
- ⛔ 상자를 `display:flex` 로 감싸지 않았습니다 — 짧은 문장이 낱글자로 쪼개집니다(2장 함정).

🪤 **값 하나에 두 뜻을 담았다가 밟았습니다** — 「`'1'` = 닫음, 숫자 = 연 횟수」로 썼더니
**첫 번째로 세는 순간 그 값이 `'1'` 이라 «닫았다» 로 읽혀 한 번만 뜨고 그쳤습니다.**
브라우저 검사가 `[true,false,false,false]` 로 잡았습니다 — 문자열 검사로는 안 보입니다.
닫음은 숫자가 아닌 표시(`'closed'`)로 못 박았습니다.

📌 **범위를 조금 넓혔습니다** — **로그인 «전»** 카드에도 같은 줄을 하나 넣었습니다.
진짜 «처음 들어오는 사람» 은 그 화면에 먼저 닿는데, 안 넣으면 지시의 절반이 빕니다.

## 재생 페이지 — promo.html 에 «프리셋 표»

그전에는 제목·부제·길이 배지·포스터가 **1분 35초 홍보영상용으로 하드코딩**이었습니다.
`?src=` 로 주소만 바꾸면 **3분 35초짜리를 틀면서 「1분 35초에 담았습니다」라고 말합니다.**

그래서 주소·길이·포스터·제목·부제·CTA 가 **한 줄에서** 나오는 `PRESETS` 표를 넣고
`?v=ai-tools` 로 고릅니다. ⛔ 표를 쪼개면 그 거짓말이 되살아납니다.

- 기본(`promo`)은 지금 그대로입니다.
- `?src=`(관리자 팝업 설정 `adm-promo-setup.js`)는 **그대로 살아 있습니다** — 프리셋의 주소만 덮습니다.
- CTA 도 프리셋에서 옵니다 — 학생용 「무료 레벨테스트 신청」이 원장 대상 영상에 뜨면 어색해서
  ai-tools 는 「🤖 AI 학습도구 둘러보기」(`/?menu=aitools`)입니다.

## 감시

**자동**(`today_plan_harness` ⑨절 신설 · 126 → **144건**) — «그 글자가 있는가» 로 끝내지 않았습니다:

1. **가리키는 파일이 실재하는가** — 영상·포스터를 `existsSync` 로. 그림을 커밋에 안 담는 사고 선례가 있습니다.
2. 🔴 **화면이 말하는 길이가 영상의 진짜 길이와 같은가** — mp4 헤더(`mvhd`)를 읽어 `3:35` 와 ±5초로 대조.
   숫자를 정규식으로 못 박지 않았으므로, 영상을 갈아 끼우면 이 검사가 어긋남을 알려 줍니다.
3. **누르기 전 0바이트인가** — 어느 입구도 mp4 를 직접 걸지 않았는지.
4. 포스터 120KB 이하 · window.open 폴백 · noopener 금지 · 「원장님·선생님」 문구 · 카드 순서 · 판정식.

**브라우저**(`test-harness/manual/video-entry-browser.mjs` **27건**, 자동으로 안 돕니다) —
보이는가·눌리는가·무엇이 덮는가·몇 줄로 쪼개지는가·닫으면 다시 안 뜨는가,
그리고 **짝 검사**(「레벨이 있으면 안 뜬다」)까지.

## 함정 대조가 짚어 준 것 (전부 반영)

1. 🔴 **위 «처음» 판정** — 가장 큰 지적이었습니다(D1 로 직접 재서 확인·수정).
2. **닫기 ✕ 가 26×26** 이었습니다 — 링크에는 44px 을 요구하면서 닫기에는 안 걸었습니다.
   보이는 크기는 그대로 두고 «누르는 자리» 만 44×44 로 넓혔습니다.
3. **대비를 재는 검사가 없었습니다** — 「색이 맞는지 다 통과했는데 글자가 안 보임」의 자리입니다.
   브라우저 검사에 WCAG 대비를 넣었습니다(반투명 층을 아래에서 위로 합성 — 안 하면 거짓 실패).
   실측 제목 6.09 · 설명 7.32 · 닫기 4.76.
4. **포스터 주소가 두 곳에 하드코딩**(promo 프리셋 · about 카드의 `<img>`)인데 검사는 한쪽만
   `existsSync` 했습니다 → 「두 곳이 같은 파일을 가리키는가」 한 줄 추가.
5. **promo.html 새 주석이 과장**이었습니다 — 고쳐진 것은 `?v=` 경로뿐인데 「이제 안 거짓말한다」로
   읽힐 수 있어 한 줄 덧붙였습니다.
6. 포스터·브라우저 검사 파일이 **untracked** 라는 지적 — `git add` 했습니다.

## 검사 쪽에서 두 번 걸렸습니다

1. 「영상 카드가 맨 앞인가」를 **앞 1200자 안에 그 글자가 있나**로 봤더니, 설명 주석이 길어
   `교사와 A.I` 가 그 범위 밖으로 밀려 **멀쩡한 코드가 FAIL** 났습니다
   → 카드 «객체» 의 모양(`{ic:…, t:…}`)으로 찾으니 주석은 애초에 안 걸립니다.

   **`function renderIntro(p) {` 라는 «선언» 이 잡혀** 호출을 통째로 지워도 통과했습니다
   (변이시험에서 실제로 놓쳤습니다) → «그 줄 하나짜리 문장» 인지로 고쳤습니다.
