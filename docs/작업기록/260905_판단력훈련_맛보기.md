# 판단력 훈련도 맛보기로 — 2026-09-05

사장님 「판단력 훈련도 맛보기로 열어줘」 (같은 날 「오늘의 학습」 맛보기에 이어서)

---

## 먼저 잰 것 — 막고 있던 것은 «화면 한 줄» 이었습니다

서버의 세 API(`growth` · `scenario` · `answer`)는 **예전부터 게스트를 통과시키고 있었습니다.**
`auth-admin.ts` 의 `resolveOwnerScope` 가 `/^guest/i` 를 `'guest'` 로 판정하고,
2026-08-28 에 IDOR 을 막을 때도 「게스트는 종전대로 통과한다」고 주석에 적어 두었습니다.

막고 있던 것은 `judgment.html` 의 이 한 줄뿐이었습니다.

```js
if(!UID){ applyStatic(); renderNoLogin(); return; }
```

D1 실측이 그것을 뒷받침합니다 — `judgment_events` **194행 / 학생 13명 / 게스트 0행.**
서버는 열려 있었는데 화면이 막아 **한 번도 안 쓰인** 경로였습니다.

---

## 1. 화면 — 게스트 아이디를 만들어 주면 열립니다

- 아이디는 반드시 **`guest_`** 로 시작해야 합니다(서버가 그 모양만 토큰 없이 통과시킵니다).
- 창은 기기별 **처음 연 시각부터 24시간**. 지나면 원래 로그인 안내로 돌아갑니다.
- **저장이 막힌 기기(사생활 보호 창)에서는 «열어 주는» 쪽으로** 실패합니다 —
  못 보여주면 고치려던 그 벽이 그대로입니다.
- 노란 배너가 **«🍯 맛보기로 보고 있어요»** 라고 직접 말합니다.
  ⛔ 감추면 여기서 쌓은 기록이 «내 기록» 으로 이어지는 줄 압니다.

---

## 2. 🔴 비용 — 이 경로는 요청 한 번에 LLM 을 한 번 돌립니다

판단력 문항은 문제은행이 아니라 **Workers AI 가 요청마다 생성**합니다(주석의 운영 실측 평균 11초).
화면을 여는 것은 곧 **그 호출을 로그인 없는 사람에게 여는 일**입니다.

그래서 상한을 **정본(서버)** 에 걸었습니다 — `SAMPLE_SCENARIO_CAP = 12` / 게스트 / KST 하루.

- ⛔ **상한을 화면에 두지 않습니다** — 본문 한 줄로 깨집니다(CLAUDE.md 「비용이 나가는 API」).
- ⚠️ **로그인한 학생에게는 한 글자도 안 걸립니다.**
- ⚠️ 세는 자리는 **생성 «앞»** 입니다 — 뒤에 두면 실패한 요청이 안 세여 재시도로 빠져나갑니다.
- ⚠️ KV 가 안 되면 **막지 않는 쪽으로** 실패합니다. 그러면 «고치기 전»(게스트가 이미 통과하던
  상태)과 같아질 뿐이고, 맛보기가 통째로 죽는 것보다 낫습니다.
  같은 파일의 `judg:ic:rl` 가드와 같은 방식입니다.
- 12로 잡은 근거: 레벨 찾기(배치)가 **6문항**이라, 그것을 끝내고도 몇 문제 더 풀어
  «어떤 도구인지» 를 알기에 충분한 값입니다. 「하루 종일 쓰라」는 값이 아닙니다.

**화면이 그 실패를 «고장» 이 아니라 «오늘 몫» 이라고 말합니다** — 「🍯 오늘 맛보기는 여기까지예요」.
⛔ 「다시 시도」 버튼을 두지 않았습니다 — 눌러도 같은 답이 오고, 그때는 진짜 고장으로 읽힙니다.

## 3. 🔴 함께 막은 것 — 게스트가 «학생» 으로 리포트에 올라올 뻔했습니다

맛보기로 문제를 풀면 `judgment_events` 에 `student_uid='guest_xxxxxxx'` 행이 쌓입니다.
그런데 `decision-graph.ts` 의 ETL 이 그 표를 **학생 구분 없이 통째로** 읽어 Neo4j 로 보냅니다.

```sql
FROM judgment_events e JOIN judgment_analysis a ON a.event_id = e.id
ORDER BY e.created_at DESC LIMIT 3000      -- ← 학생 필터가 없었다
```

그대로 뒀으면 **`guest_ln8iu2j` 라는 «있지도 않은 학생» 노드와 취약 스킬 집계**가 생기고,
그것을 선생님이 봅니다. → ETL 에서 게스트를 제외했습니다.

⚠️ 이건 «맛보기를 여는 것» 자체가 만드는 부작용이라, 화면만 고치고 끝냈으면 못 봤을 자리입니다.

## 4. 🪤 브라우저 검사가 실제로 잡은 것 두 가지

문자열 검사로는 둘 다 안 보입니다. 진짜 브라우저에 그려서 잰 값입니다.

### ① 배너가 첫 설정 카드의 «선택지» 를 화면 밖으로 밀어냈습니다

첫 배너는 **137px** 이었습니다. 360×640 폰 실측:

| | 배너 | 카드 top | 첫 선택지 top | 화면 |
|---|---|---|---|---|
| 처음 | 137px | 528 | **739** ❌ | 640 |
| 한 줄로 | 43px | 426 | **637** ✅ | 640 |

CLAUDE.md 2장 「첫 화면에 «정하세요» 카드를 띄웠는데 아무도 안 고름」 그대로입니다 —
**위에 상자를 하나 더 얹으면 정작 고를 것이 스크롤 밖으로 밀립니다.**

고침: 첫 설정 화면(`view==='setup'`)에서는 배너를 **한 줄로만** 그립니다.
「지금 푼 것은 저장되지 않아요」는 어차피 **풀기 시작한 뒤에** 뜻이 생기므로 그때 붙입니다.

### ② 상자를 조이다가 로그인 버튼이 «못 누르는» 크기가 됐습니다

배너를 줄이는 과정에서 버튼이 **27px** 이 됐습니다 — 보이지만 손가락으로 누르기 어렵습니다.
높이는 **상자 자신의 여백에서 갚아** 33px 로 되돌렸습니다(배너 전체는 43px 유지).

> 「보인다」·「눌린다」·「첫 화면 안에 있다」는 전부 다른 값입니다.

### ③ 🪤 CSS 주석에 「 」 를 썼다가 CI 가 빨간불

`admin_lazyload_harness` ②-3 은 **`<style>` 안 CSS 주석까지 세어** 홑낫표가 있으면
「이 화면이 983KB 한자 폰트를 받는다」로 판정합니다. 제가 배너 CSS 주석에
`「첫 화면에 …」` 라고 적어 그대로 걸렸습니다(장식 2자).

**CLAUDE.md 2장에 이미 적혀 있는 함정인데 그대로 밟았습니다** — 그 항목이 말하는 대로
`« »` 로 바꿔 고쳤습니다. 코드·JS 주석은 괜찮고 **`<style>` 안에서만** 안 됩니다.
