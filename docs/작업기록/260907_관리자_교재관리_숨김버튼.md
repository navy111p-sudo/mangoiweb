# 관리자 교재 관리 화면에 «숨김» 버튼 넣기 (2026-09-07)

## 1. 왜 했나

사장님이 관리자 › **📖 교재 콘텐츠 관리 ▸ 📚 컨텐츠 교재 관리** 표를 캡처해 보내시며
「I can't find the hide button sir · 숨김 버튼을 찾지 못하겠어 경로알려줘」.

찾아보니 **그 화면에는 숨김이 원래 없었습니다.** 숨김은 2026-08-13(마이마이 8/13 ①)에
`/textbook-uploader.html` 아래쪽 「🙈 라이브러리에서 숨길 교재」 상자로만 들어갔고,
관리자 교재 표는 등록·목록 보기만 했습니다. 그 페이지를 모르면 찾을 길이 없습니다.

→ 경로를 안내드린 뒤 사장님 지시 「관리자 교재 관리 화면에도 숨김 버튼 넣어줘」로 이어졌습니다.

## 2. 무엇을 했나

교재 표에 마지막 칸 **「숨김」**을 붙였습니다. 버튼을 누르면 그 교재가 강사·학생
라이브러리에서 빠지고, 한 번 더 누르면 즉시 되살아납니다.

- API 는 **그대로 재사용**합니다 — `GET/POST /api/admin/textbook-hidden-books`.
  새로 만들지 않았습니다(정본이 둘이 되면 두 화면이 다른 말을 하기 시작합니다).
- 그래서 `src/index.ts`(공동 금지구역)와 서버 코드는 **한 줄도 안 건드렸습니다.**
- 업로더 페이지의 숨김 상자도 **그대로 둡니다** — 그쪽은 교재 묶음 전체 목록을 검색까지
  하며 한 번에 정리하는 자리이고, 이쪽은 「표를 보다가 그 줄에서」 하는 자리입니다.

### 화면이 말하는 것

| 상태 | 칸 | 왜 |
|---|---|---|
| 라이브러리에 보임 | **👁 보임**(초록) | 누르면 숨긴다 |
| 숨겨져 있음 | **🙈 숨김**(빨강) | 누르면 되살린다 |
| 그 이름으로 서버에 올라온 파일이 없음 | **—** + 툴팁 | 숨길 대상이 없다 |
| 본사·관리자가 아님(403) | **—** + 툴팁 | «모른다» 고 말한다 |

안내 줄에 「묶음 N개 · 숨김 M개」를 함께 적습니다.

## 3. 검토했다가 버린 방법

- **표의 모든 행에 버튼 달기** — 숨김의 단위는 «교재 묶음 이름»(`textbook_files` 파일명 앞
  `[대괄호]`)입니다. 수동 등록만 되어 있고 파일이 없는 교재에 버튼을 달면 **눌러도 라이브러리에서
  사라지는 것이 없어** 「눌렀는데 아무 일도 안 일어난다」가 됩니다. 그래서 묶음과 맞는 행에만 답니다.
- **이름이 비슷하면 이어 주기** — 안 했습니다. 엉뚱한 묶음을 숨기면 강사가 쓰는 교재가 통째로
  사라집니다. **정확일치 먼저**, 없으면 대소문자만 다른 후보를 보되 **유일할 때만** 잇습니다.
- **권한이 없을 때 조용히 «보임» 으로 그리기** — 안 했습니다. 그건 거짓말입니다. «—» 와 사유를 답니다.
- **여기에 «지우기» 도 넣기** — 안 넣었습니다. 되돌릴 수 없는 일은 이 자리에 만들지 않습니다.
- **버튼 색을 인라인 style 로 주기** — 안 됩니다. `admin-inline-c.css` 의 전역 룰
  `details.menu-card button{ 인디고 그라데이션 !important; padding:9px 18px !important }` 이
  인라인을 이겨 **큰 파란 알약**이 되고 옆 칸을 밀어냅니다(CLAUDE.md 2장). ID 접두 블록으로 되살렸습니다.

## 4. 밟을 뻔한 함정

- **`body{zoom:1.3}`** — 브라우저 검사가 버튼 높이를 39px 로 재서 처음에 FAIL 이 났는데,
  CSS 문제가 아니라 관리자 화면 배율이었습니다. CSS 픽셀로 나눠서 재도록 검사를 고쳤습니다.
- **`?v=` 는 admin.html 만이 아닙니다** — `adm-light-surfaces.js` 를 고치자 그 파일을 싣는
  **하위 관리자 화면 17개**의 `?v=` 도 함께 올려야 했습니다(하니스가 잡아 줬습니다).
- **배포된 적 없는 중간 번호** — 주석을 한 번 더 고치느라 같은 번호의 내용이 바뀌어서,
  원장(`asset-versions.json`)에서 `v=71`·`v=18` 항목을 지우고 다시 기록했습니다.
- **`colspan`** — thead `<th>` · 한 줄 `<td>` · `colspan` 네 자리를 전부 6 → 7 로 맞췄습니다.

- 변이시험(되돌리면 진짜로 빨간불이 나는가): CSS 블록 제거 → ❌5 · 파일 없는 행에도 버튼 → ❌2 ·
  저장 실패인데 화면 바꾸기 → ❌1.

  을 위한 예약이고, 그러니 **이 검사는 그 등재를 지켜 주지 못합니다.** 사실대로 주석에 적었습니다.
- ⚠️ **사장님 화면에서 눈으로 보는 것은 아직 안 됐습니다** — 이 컨테이너는 프록시가 `mangoi.ai` 를
  막아 배포된 화면을 못 봅니다(CLAUDE.md 4-1-1). 병합·배포 뒤 한 번 봐 주세요.
