## 2. 무엇을 바꿨나

### 새 파일 — `cloudflare-deploy/src/owner-sms-mute.ts` (판정 정본)

순수 함수 셋. 하니스가 **실제로 돌릴 수 있게** 별도 파일로 뺐습니다.

- `OWNER_MUTE_KV_KEY = 'owner_alert_mute'` — KV(SESSION_STATE) 스위치 이름
- `ownerMuteFromKv(v)` — **기본이 «음소거»**. 값이 `'off'` 일 때만 보냅니다(대소문자·공백 무시)
- `isOwnerPhone(to, owner)` — 숫자만 남기고 `+82` 를 `0…` 으로 맞춰 비교.
  **둘 중 하나라도 비면 false**(= 막지 않음)

### `cloudflare-deploy/src/solapi-client.ts` — 게이트 한 곳

`sendPlainSms` **첫머리**, 어떤 `fetch` 보다 앞:

```ts
if (isOwnerPhone(toPhone, env.OWNER_ALERT_PHONE)) {
  let muted = true;   // ⚠️ KV 를 못 읽어도 «안 보냄» — 끄라는 지시로 만든 스위치다
  try { muted = ownerMuteFromKv(await env.SESSION_STATE?.get(OWNER_MUTE_KV_KEY)); } catch {}
  if (muted) {
    console.warn('[owner-sms] 음소거로 보내지 않음(KV owner_alert_mute=off 로 되켬):', …);
    return { ok: false, mode, muted: true, message: '운영자 문자 음소거(owner_alert_mute)' };
  }
}
```

`SolapiEnv` 에 `OWNER_ALERT_PHONE?`·`SESSION_STATE?` 를 더했고, 반환 타입에 `muted?: boolean`.

## 4. 왜 그렇게 풀었나 — 검토했다가 버린 방법

### ⛔ 버림 ① — `OWNER_ALERT_PHONE` 시크릿을 지우기

가장 빠릅니다. 한 줄이면 17군데가 한꺼번에 조용해집니다. **그래서 안 했습니다.**

- **되돌리기가 어렵습니다** — 시크릿은 값이 안 보이므로 다시 넣으려면 번호를 사람이 기억해야 합니다.
- **「결제만 다시 켜기」 같은 선택이 원리상 불가능**해집니다. 번호가 없으면 전부이거나 전무입니다.
- CLAUDE.md 1-3 이 9/6 작업 때 이미 이 방식을 **금지**로 못 박아 두었습니다.

### ⛔ 버림 ② — 호출부 17군데를 각각 막기

「어느 알림을 끌지 골라 끌 수 있다」는 장점이 있지만,
**나중에 새 알림이 생기면 조용히 새어 나갑니다.** 이번 사고가 정확히 그 모양입니다 —
9/6 에 한 곳만 막았더니 이틀 뒤 다른 곳이 울렸습니다.
그래서 **«문자를 실제로 보내는 정본» 한 곳**(`sendPlainSms`)에 두었습니다. 새 알림도 자동으로 걸립니다.

### ⛔ 버림 ③ — 알림을 만드는 코드를 지우기

되돌릴 길이 없어집니다. 그리고 그 코드들은 **잘못된 것이 아닙니다** — 지금은 알림이 필요 없다는
사장님 판단일 뿐이라, 코드가 아니라 **스위치**로 표현하는 것이 맞습니다.

### ⛔ 버림 ④ — 「관리자 계정만 빼기」(보고서의 «가» 안)

보고서에서는 이것을 권했지만(선생님이 해외에서 로그인할 때 조용해지므로) 사장님이
**「일단 모두」** 를 고르셨습니다. 지시대로 했습니다. 나중에 그 안으로 좁히려면
`owner-sms-mute.ts` 에 «어떤 알림인가» 를 한 축 더 두면 됩니다.

### ✅ 기본값을 «음소거» 로 둔 이유

지시가 「끄라」이므로, **KV 를 못 읽어도 안 보내는 쪽**이 이 자리에서 맞는 실패 방향입니다.
반대로 두면 KV 가 흔들릴 때마다 문자가 다시 옵니다. 배포만으로 꺼지는 이득도 있습니다.

🪤 **하니스를 만들다 밟은 함정** — 함수 몸통을 중괄호 짝으로 자르는 `bodyOf()` 가
`): Promise<{ ok: boolean; … }>` 의 **반환 타입 중괄호**를 몸통으로 잘못 잡아 7건이 FAIL 했습니다.
「전제: 몸통을 잘라 냈다」 검사를 미리 박아 둔 덕에 바로 드러났고, 괄호·꺾쇠 깊이를 함께 세도록 고쳤습니다.
