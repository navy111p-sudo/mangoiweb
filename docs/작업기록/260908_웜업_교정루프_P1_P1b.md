## 1. 왜 했나

사장님이 「Cloudflare Workers AI 로 아바타 실시간 언어 교정」 4단계 구상을 주셨다.
저장소를 전수 대조해 보니 **셋은 이미 웜업이 쓰고 있었다** — Workers AI 바인딩(모델 12종·
호출 49곳), Whisper 전사(`mangoi-voice-input.js`), Aura-2 TTS + 아바타 입모양.

빠진 것은 **③ 교정** 한 칸뿐이었다. `warmupSystem()` 12줄에 `[칭찬]`·`[막혔을 때]`·`[재미]`는
있는데 `[교정]`이 **한 줄도 없어서**, 학생이 "I go to school yesterday" 라고 해도 아바타는
칭찬하고 다음 질문으로 넘어갔다.

## 2. 검토했다가 버린 방법

| 버린 것 | 왜 |
|---|---|
| **교정용 LLM 을 따로 한 번 더 부르기** | 왕복이 하나 더 붙어 한 턴이 두 배가 된다. 지금 한 턴이 2.5~4.5초인데 3초를 넘으면 아이는 안 기다린다. → 답장과 **같은 호출**에서 JSON 으로 함께 받는다(추가 지연 0초) |
| **프롬프트에 「문법 고쳐 줘」만 넣고 끝내기** | 이 저장소의 반복 실측이 「지시만으로는 안 지켜진다」(단어 수·문법·구두점). 모델은 학생이 쓰지도 않은 문장을 `was` 에 넣는다 → 결정론 게이트를 짝으로 뒀다 |
| **매 턴 교정하기** | 2026-09-03 AI 영어친구에서 「주제를 벗어나지 마」를 세 겹으로 넣었다가 벨잉글리시 원장님 「정해진 문장 안에서만 한다」 제보로 되돌린 전례. 교정도 같다 — 자주 고치면 말문이 막힌다 |
| **틀린 것을 «두 번째부터만» 보여주기(단일 규칙)** | 짧은 웜업(5~10턴)에서는 거의 안 뜬다 = 「기능이 있는데 아무도 못 씀」. → 심각도로 갈랐다: 뜻이 달라지면 바로, 작은 실수는 두 번째부터 |
| **교정 문장을 코드가 고쳐 쓰기** | 아이가 그대로 따라 읽는 문장이다. 통과시키거나 버리기만 한다 |
| **P2(발화 D1 저장)를 같이 하기** | 미성년자 발화 기록이라 **보관기간·동의 문구가 코드보다 먼저**다. 사람이 정할 일이라 뺐다 |
| **`.fix-line` 에 `display:flex`** | 처음에 그렇게 짰다가 되돌렸다 — 문장이 흐르는 줄에 flex 를 쓰면 좁은 폰에서 낱글자로 쪼개진다(CLAUDE.md 2장의 그 함정) |

## 3. 무엇을 만들었나

- **`src/warmup-correction.ts`** (새 파일, 판정 정본)
  - `WARMUP_CORRECTION_RULE` — `[교정]` 절 + JSON 출력 계약
  - `parseWarmupOutput()` — JSON → `"reply"` 정규식 → 원문, **3단 폴백**. 못 읽으면 빈 문자열
    (학생 화면에 중괄호를 절대 안 내보낸다 — 기존 «잠깐의 딸꾹질» 문구가 받는다)
  - `verifyWarmupFix()` — `was` 가 원문에 글자 그대로 있는가 · 낱말 겹침 ≥ 0.5 · 한글 섞임 금지
    (`english-only.ts` 정본 재사용) · `why_ko` 필수 · 길이 상한
  - `decideWarmupFixShow()` / `warmupShouldOfferRepeat()` — «언제 보여 줄 것인가»
- **`src/index.ts`** (공동 금지구역, `handleWarmupChat` 안으로 한정 +57/−5)
  - 추출 자리 **5곳을 `takeWarmupReply` 한 곳으로** 모았다
  - 검증 게이트(통째로 try/catch — 여기서 던지면 멀쩡한 대화가 500 이 된다) + 응답 `fix`·`repeat`
  - KV `warmupfix:<sid>` 6시간 — **발화가 아니라 «무엇을 몇 번 틀렸나»만**
- **`public/warmup.html`** — 교정 카드(하늘색, 「대답 보기」 초록·「질문 추천」 노랑과 구분) +
  「🔊 들어보기」 · 「🎤 따라 말해 보기」(소리가 끝나면 마이크를 연다)

### 만들면서 실제로 밟은 것 (셋)
1. **하니스 앵커를 라우터 분기에 잡았다** — `path === '/api/warmup/chat'` 이 위쪽 라우터에도
   있어서 무관한 3,600줄이 딸려 들어와 남의 `AI.run` 까지 셌다. 앵커를 «핸들러 함수» 로 바꿨다.
2. **`silent_catch_harness` 가 내 조용한 catch 를 잡았다** — KV 메모 저장이 조용히 실패하면
   «연달아 교정하지 않기» 가 통째로 풀려 매 턴 교정이 뜨는데 화면은 멀쩡해 보인다. 로그 한 줄 추가.
3. **대비 3.94:1** — 제목 색을 눈대중으로 골랐다가 브라우저 측정에서 걸렸다(기준 4.5).

## 6. 함정 대조가 잡은 것 (커밋 뒤 · 병합 전)

`trap-check` 를 돌렸더니 **커밋한 뒤에 진짜 결함이 나왔습니다.** 병합 전에 고쳤습니다.

### 🔴 잘린 출력이 «생 JSON» 으로 학생 화면·TTS 에 그대로 나갔습니다

파서가 `const e = body.lastIndexOf('}'); if (s >= 0 && e > s)` 라, **닫는 중괄호가 없으면
블록을 통째로 건너뛰고 원문을 그대로** 돌려줬습니다. 직접 재현했습니다:

```
입력: {"reply":"Oh, you went to school yesterday! …","fix":{"was":"I go to sch
출력: 그 문자열 그대로  → 🔴 중괄호가 말풍선에 그려지고 TTS 가 읽음
```

**가장 흔한 실패 모양이었습니다** — `max_tokens: 200` 은 그대로인데 그 안에 이제 JSON
껍데기와 교정(한국어 설명 포함)이 함께 들어가 본문 예산이 줄었고, **잘리면 정의상 닫는
중괄호가 없습니다.** 하류 안전망(`replyRejectReason`)도 그 덩어리를 «정상» 으로 통과시켰습니다.

**⚠️ 더 나쁜 것은 제가 세 곳에 「중괄호를 절대 안 내보낸다」고 완료형으로 적어 둔 것입니다**
(소스 주석 · 하니스 B-5 · 이 문서 §3). 닫는 중괄호가 «있는» 입력 하나만 시험하고 그렇게
적었습니다. CLAUDE.md 2장의 「문서에 「고쳤다」고 적혀 있는데 같은 사고가 또 남」 그대로입니다.
→ 이 함정을 **CLAUDE.md 2장에 새 줄로 넣었습니다.**

### 🔴 하니스 3건이 «이름이 약속한 것» 을 안 보고 있었습니다

| 검사 | 헛돌던 이유 | 되돌려 확인 |
|---|---|---|
| C-2 | `/fixCardClear\(\)/` 가 **선언에도 매치** → 호출을 전부 지워도 통과 | 이제 잡음 |
| C-4 | `_fixLabel(v,…)` **한 모양**만 봄 → `setAttribute('data-ko')` 로 직접 달면 통과 | 이제 잡음 |
| A-3 | `takes === runs + 1` 의 `+1` 이 **코드가 아니라 주석** → 주석 괄호만 떼도 FAIL | 주석 벗기고 셈 |

C-2 는 CLAUDE.md 2장 「선언 줄이 함께 잡혀 호출 하나를 지워도 통과」의 **세 번째** 재현입니다.

### 🟡 함께 고친 것

- **버려진 재시도의 교정이 화면에 남았습니다** — 파싱하자마자 `rawFix` 를 덮어써서, 이름·반복
  재시도가 «거절» 되면 답장은 옛것인데 카드만 새것이었습니다 → `commitFix()` 로 **채택할 때만** 확정.
- **「못 알아들었어」 옆에 교정 카드가 붙을 수 있었습니다** — 무너진 답장을 버릴 때 그 교정도 함께 버립니다.
- **`was` 대조가 낱말 조각을 통과시켰습니다** — `'o to sch'` 가 `'I go to school'` 에 걸렸습니다 → 낱말 경계로.
- **곱슬 아포스트로피** — 모델은 `’`, 학생은 `'` 를 쓰면 대조가 조용히 어긋났습니다 → `normEn` 에서 통일.
- **흔한 교정이 묻혔습니다** — 낱말 겹침 0.5 만 보면 `"I don't went" → "I didn't go"` 가 0.33 으로 버려집니다.
  [잰 것] 통과해야 할 교정 9종의 **글자유사 0.48~0.96** 대 막아야 할 창작 **0.00~0.09** — 간격이 다섯 배라
  0.35 로 가르고 «낱말 겹침 0.5 **또는** 글자유사 0.35» 로 바꿨습니다. 창작 차단은 짝 검사로 유지.
- **죽은 가드** `if (parsed.fix !== undefined)` — 항상 참이라 지우는 것처럼 읽혔습니다.

### 아직 «사람이 정할 일» 로 남긴 것

- **`max_tokens: 200` 을 올릴지** — 파서 수리로 «샘» 은 막았지만, 잘리면 본문이 문장 중간에서
  끊기는 것은 그대로입니다. 올리면 지연과 맞바꿉니다.
- **「🎤 따라 말해 보기」가 마이크를 열면 그 발화가 다음 턴으로 «자동 전송» 됩니다** —
  설계 의도로 보이지만, 아이가 눌러 보기만 해도 턴이 하나 소모됩니다.
- **실제 모델이 이 JSON 계약을 얼마나 지키는지 · 잘림이 실제로 얼마나 잦은지** — 이 환경에서
  못 잽니다(프록시가 운영 도메인을 막습니다). 배포 뒤 사람이 봐야 합니다.
