# 화상수업 «사무실 모드» — 옆자리 교사 목소리 줄이기 (2026-09-08)

## 1. 왜 했나

사장님 「망고아이 사무실에서 주변 교사들의 목소리가 들리지 않게 노이즈 캔슬링 할 수 있는 방법을 알려줘」
→ 확인해 보니 **이미 켜져 있는 잡음 제거로는 원리상 안 되는 일**이었습니다.

- 수업 마이크는 `noiseSuppression: true` 로 이미 켜져 있고(`js/idx-main.js:424`),
  독 ⚙️ 설정의 「잡음 제거」 토글도 기본 켜짐(`vc-dock.js:725`)입니다.
- 그런데 브라우저·WebRTC 의 노이즈 억제는 **에어컨·팬·키보드 같은 «일정한 잡음»** 을 겨냥한 것입니다.
  옆자리 교사 목소리는 그 엔진에게 «지워야 할 잡음» 이 아니라 **«지켜야 할 음성»** 으로 분류됩니다.
- 게다가 `autoGainControl: true` 라, 교사가 말을 쉬는 동안 마이크 감도를 자동으로 올려
  **옆 소리를 오히려 키우고** 있었습니다.

사장님이 「사무실 모드 스위치 넣어줘」로 이어서 지시하셨습니다.

## 2. 무엇을 넣었나

수업 화면 하단 독 ⚙️ **설정 › 마이크 › 「사무실 모드」** 스위치 하나. 켜면 셋을 합니다.

| 무엇 | 왜 |
|---|---|
| ① 자동 게인(AGC) 끄기 | 말을 쉴 때 옆자리 소리를 키우는 주범 |
| ② 하이패스 120Hz | 방 웅웅거림·책상 진동 제거(사람 목소리 기본 주파수 아래) |
| ③ 노이즈 게이트 | 바닥 소음보다 충분히 큰 소리(=내 목소리)만 통과, 그 아래는 **줄임** |

정본은 **`cloudflare-deploy/public/js/idx-vc-officemode.js`** 하나입니다(defer).

- ⛔ 게이트는 **완전 무음이 아니라 감쇠**까지만(그때 -22dB → **지금 -30dB**, §9) — 완전히 끊으면 교사가 조용히 말할 때
  첫 음절이 사라져 고치려던 것보다 나쁩니다.
- ⛔ 문턱을 고정 숫자로 두지 않습니다 — 사무실마다 바닥 소음이 다릅니다. 조용한 구간의 바닥을
  배워 그 위 12dB. ⚠️ **위로는 아주 느리게만** 따라갑니다(시끄러운 값을 «평소» 로 배우면
  게이트가 스스로 열려 아무 일도 안 하게 됩니다).
- ⛔ 탭이 숨으면 게이트를 **활짝 열고 손을 뗍니다** — 타이머가 느려진 사이 «닫힌 채 굳어»
  목소리가 안 나가는 것을 원천 차단합니다.

## 3. 검토했다가 버린 것

- **Krisp·NVIDIA Broadcast 를 코드로 붙이기** → 불필요합니다. 가상 마이크 «장치» 로 잡히므로
  설정 › 마이크에서 고르면 끝이고, 코드를 한 줄도 안 고쳐도 됩니다.
- **해상도·비트레이트 손대기** → 이 문제와 무관합니다.
- **잡음 제거 토글을 더 세게 만들기** → 그 엔진은 사람 목소리를 못 지웁니다(1장).
- **`idx-main.js` 에 직접 넣기** → 849KB blocking 이고 첫 화면 예산 여유가 116바이트입니다.
  defer 파일에서 전역 함수를 감싸는 방식으로 했습니다(`index.html` 은 script 1줄 + `?v=` 만).

## 4. 밟은 함정 — 브라우저 검사가 잡았습니다

🔴 **끄면 소리가 아예 안 나가는 상태**를 한 번 만들었습니다.

`restorePlainMic()` 이 «지금 트랙» 에서 마이크 장치 id 를 읽었는데, 켜져 있는 동안 그 트랙은
WebAudio 가 만든 **가공 트랙**이라 장치 id 가 없습니다. 그것을 `deviceId:{exact:…}` 로 넘겨
`OverconstrainedError` 가 났고, 되돌리기가 통째로 실패해 **무음 가공 트랙이 그대로 남았습니다.**

- ⚠️ 회귀 하니스 281건이 **전부 초록**이었습니다. 함수도 값도 다 «있고» 틀린 것은
  «무엇을 읽는가» 뿐이라 문자열 검사로는 원리상 안 보입니다.
- ✅ 고침: 켤 때 «진짜» 장치 id 를 기억(`srcMicId`) + 되돌리기에 **2단 폴백** + 마지막 안전망.
- CLAUDE.md 2장에 함정으로 남겼습니다.

🪤 곁가지 — **`#vc-dock-settings` id 가 «둘»** 입니다(`vc-dock.js:603` 팝오버 · `848` 버튼).
`querySelector` 가 먼저 나오는 쪽을 집어 검사가 회차마다 들쭉날쭉했습니다.
**기존 저장소의 id 중복이라 이번에 고치지 않았습니다**(그 id 로 찾는 다른 코드가 있으면
동작이 바뀝니다 — 사람이 결정할 일). 검사만 그것에 안 기대게 고쳤습니다.

## 4-2. 함정 대조가 **4건을 더** 찾았습니다 (커밋 뒤)

브라우저 검사 34종이 «전부 통과» 하면서 아래 넷을 하나도 못 잡고 있었습니다.
「보인다·눌린다·켜진다」만 재고 **«언제 걸리는가»·«무엇을 읽는가»** 를 안 봤기 때문입니다.

| | 무엇 | 왜 안 보였나 |
|---|---|---|
| ① | **죽은 키** `mangoi_vc_mic` (정본은 `mangoi_vc_mic_id`, 게다가 `vcSavedMicId()` 함수가 이미 있었음) | 읽으면 늘 null — 에러 없이 «교사가 고른 마이크» 대신 기본 마이크를 잡음 |
| ② | **진입 배선이 한 번도 안 돎** — `showView` 가 `vc-in-call` «보다 먼저» 도는데(`idx-main.js:2869~2870`) 훅에서 `inCall()` 로 판정 | 퇴장은 순서가 반대라 «끄기» 만 정상 동작 → 켜기만 조용히 죽음 |
| ③ | **퇴장 때 저장값이 지워짐** — `disable()` 이 «사람이 껐다» 와 «수업이 끝났다» 를 안 가름 | ②와 서로를 가림(안 읽고 + 남지도 않음) |
| ④ | **`vcSwitchMic` 직접 호출 2곳이 래퍼 우회** | 상태가 «켜짐» 인 채 가공 트랙만 사라짐 + 타이머·AudioContext 누수 |

추가로 **마이크 자가치유가 원리상 못 도는** 문제도 나왔습니다 — `vcHealLocalMic` 은
「살아 있는 트랙이 있으면 그만둔다」인데 **WebAudio 가공 트랙은 원본이 죽어도 `live`** 입니다.
USB 를 뽑으면 교사가 조용히 무음이 됩니다 → 원본 트랙의 `ended` 를 듣고 스스로 손을 떼게 했습니다.

🪤 **그리고 제 검사가 «재지 않은 전제» 위에 있었습니다.**
「가공 트랙에는 `deviceId` 가 없다」로 판정했는데 **재 보니 있습니다**(`WebAudio-<uuid>`).
그래서 ⑦은 **늘 통과**했고 ⑮는 **정상 코드를 «모순» 으로 오판**했습니다.
지금은 `deviceId` 접두사 + `label` 두 신호로 판별하고, **「판별식이 두 상태를 실제로 가르는가」**
를 전제 검사(⑥-2)로 박아 두었습니다.

⚠️ 부정 검사가 **자기 주석을 잡는** 것도 한 번 밟았습니다(죽은 키 이름을 설명 주석에 남겨서).
주석을 벗겨 낸 사본으로 판정하도록 고쳤습니다 — ⛔ 블록주석을 정규식 한 줄로 지우지 않고
줄 단위로 «지금 블록주석 안인가» 를 추적합니다.

## 6. 남은 것 (사람이 정할 일)

- 🔴 **가장 확실한 대책은 코드가 아니라 붐 마이크 헤드셋**(입에서 3~5cm)입니다.
  근접 효과로 내 목소리와 2m 밖 목소리의 크기 차이가 20dB 이상 벌어집니다. 교사 1인당 3~5만원.
  사무실 모드는 그 **보조**입니다 — 이것만으로 옆 소리가 완전히 없어지지는 않습니다.

  지금은 «덜 자르는» 쪽으로 잡아 두었습니다(첫 음절이 잘리는 것이 더 나쁩니다).
- ~~학생 화면에도 이 스위치가 뜹니다~~ → ✅ **선생님 전용으로 막았습니다**(사장님 「선생님만 쓰게 막아줘」).
  아래 §6-2 참고.
- **`#vc-dock-settings` id 가 둘입니다**(`vc-dock.js:603` 팝오버 · `848` 버튼) —
  기존 저장소의 id 중복이라 **이번에 고치지 않았습니다**(그 id 로 찾는 다른 코드가 있으면
  동작이 바뀝니다). 검사만 그것에 안 기대게 했습니다.

## 6-2. 선생님 전용 (같은 날 추가 지시)

사장님 「선생님만 쓰게 막아줘」 — 학생 화면에서는 그 줄이 아예 안 보입니다.

- 판정은 **정본 `vcIsStaffNow()` 하나**만 봅니다(그 주석이 「강사 전용 기능은 전부 이걸 쓴다」).
- ⛔ **«강사가 아니면 학생»(`!vcIsStaffNow()`)으로 판정하지 않았습니다** — 그 판정은
  **역할이 아직 확정되지 않은 강사를 학생으로 오판**합니다(`vcIsStudentNow` 주석의 8/10 사고:
  그때 강사 카메라가 탭 전환마다 꺼졌습니다).
- 그래서 오판이 «교사가 못 쓰는» 쪽인데, 두 가지로 견딥니다:
  · 설정을 **열 때마다** 다시 판정합니다(역할이 늦게 오면 다시 열면 보입니다)
  · 수업 진입 자동 적용은 **«교사가 될 때까지» 기다립니다**(폴링)
- ⛔ **거절할 때 저장값을 지우지 않습니다** — 역할이 늦게 온 강사의 설정이 그 한 번의 오판으로
  사라지면 «다음 수업에도 안 켜지는» 상태가 굳습니다. 저장값은 사람이 스위치를 눌렀을 때만 바뀝니다.
- ⛔ `el.hidden` 으로 감추지 않았습니다 — `.sg-row{display:flex}` 가 브라우저 기본
  `[hidden]{display:none}` 을 이깁니다(CLAUDE.md 「el.hidden 인데 그대로 보임」).
- ℹ️ **보안 게이트는 아닙니다** — 자기 마이크만 가공하므로 학생이 콘솔로 불러도 남에게 영향이
  없습니다. 목적은 «학생 화면을 어지럽히지 않는 것» 입니다.

검증: 브라우저 **57/57**(⑯·⑯-2 신설) · 변이 **Ⓕ~Ⓘ 4종 전부 실제 FAIL**
(감추기 무력화 · 정본 가드 제거 · **«전부 감추기»** · 거절이 저장값을 지우게) · `--fast` 회귀 0건.

⚠️ 검사에 **「선생님에게는 보인다」를 짝으로** 두는 것이 핵심이었습니다 — 없으면 «전부 감추기»
변이가 그대로 통과합니다(Ⓗ 로 실제 확인).
🪤 그리고 검사를 쓰다 **템플릿 리터럴 안 주석에 백틱**을 넣어 문법이 깨졌습니다(그 자리에서
리터럴이 닫힙니다) — 그 안에서는 «·» 나 따옴표를 쓰세요.

### 8-2. 무엇을 바꿨나

**① 보이는 조건을 «둘» 로 — `cloudflare-deploy/public/js/idx-vc-officemode.js`**

```js
function hasAdminLogin() {            // 관리자 로그인이 있는가
  var s = JSON.parse(localStorage.getItem('mangoi_admin_session') || '{}') || {};
  return !!String(s.uid || '').trim();
}
function isStaff() { return vcIsStaffNow() || hasAdminLogin(); }

```

- `mangoi_admin_session` 은 교사·본사·지사가 **관리자 화면에 로그인할 때만** 생깁니다.
  학생 로그인은 `mangoi_logged_user` 라 **키 자체가 다릅니다** — 진짜 학생 브라우저에는 없습니다.
  같은 키를 같은 뜻으로 이미 읽는 곳: `idx-main.js:2626`.
- ⛔ **역할 정본 `vcIsStaffNow()` 는 한 줄도 안 건드렸습니다** — 그 값에는 화면공유·교재 넘김·
  장치 도우미 «권한» 이 함께 걸려 있어, 거기를 넓히면 사무실 모드와 무관한 것까지 열립니다.
- ℹ️ 보안 게이트가 아닙니다(자기 마이크만 가공) — 목적은 «화면을 어지럽히지 않기» 입니다.

**② 기본값 = 켜짐 — 같은 파일**

저장값을 **셋**으로 읽습니다: `'1'`(켬) · `'0'`(사람이 껐음) · **없음(아직 안 정함 → 켬)**.

```js
function pref()   { return localStorage.getItem(KEY); }     // '1' | '0' | null
function wantOn() { return pref() !== '0'; }                // ← 기본 켜짐
function forget() { localStorage.removeItem(KEY); }
```

- 「교사인가」는 **여기서 묻지 않습니다** — 이 함수가 불리는 시점에는 역할이 아직 안 왔을 수 있습니다.
  실제로 거는 자리(`armOnce`)가 `isStaff()` 를 **폴링하며** 봅니다. 학생 브라우저에서도 `armOnce` 는
  돌지만 20초 뒤 아무것도 안 하고 끝납니다.
- **켜기 실패 처리를 바꿨습니다** — `remember(false)`(='0') → **`forget()` + 페이지 안 표시 `autoFailed`**.
  성공하면 `autoFailed = false`.

**③ `?v=` 두 줄 — `cloudflare-deploy/public/index.html`** (🚫 공동 금지구역)
`idx-vc-officemode.js?v=1→2` · `vc-dock.js?v=26→27`. **로직은 한 줄도 안 건드렸습니다.**
서비스워커가 `?v=` 붙은 js 를 **cache-first** 로 주므로 이 두 줄이 없으면 고침이 브라우저에 안 닿습니다.

## 9. 세기 한 단계 올림 (2026-09-09) — 「옆자리 목소리가 아직 조금 들려」

### 9-1. 왜

배포·기본 켜짐까지 확인된 뒤 사장님 「**옆자리 목소리가 아직 조금 들려. 문턱 좀 더 세게 해줘**」.
§6 에 「실제 사무실 소리를 듣고 정할 값」으로 남겨 둔 바로 그 자리입니다 — 이번이 그 «사람이 듣고 정한» 1회차입니다.

### 9-2. 무엇을 바꿨나 — 네 값이 «한 벌» 입니다

`js/idx-vc-officemode.js` 의 상수 넷만 바뀝니다(로직 0줄).

| 값 | 전 | 후 | 뜻 |
|---|---|---|---|
| `OPEN_DB` | 12 | **16** | 바닥 + 이만큼 커야 «내 목소리» — 옆자리 소리로는 게이트가 덜 열립니다 |
| `DUCK` | 0.08 (−22dB) | **0.03 (−30dB)** | 닫혔을 때 남기는 크기 — 8dB 더 줄입니다 |
| `HYST_DB` | 6 | **8** | **닫는** 문턱(= 바닥 + OPEN_DB − HYST_DB)이 바닥+6 → 바닥+**8** |
| `HOLD_MS` | 260 | **300** | 문턱 아래로 떨어져도 이만큼은 열어 둠 |

🔴 **「되갚는」 값은 `HOLD_MS` 하나뿐이고 나머지 셋은 전부 «세게» 쪽입니다.**
처음에 저는 「HYST_DB 를 올려 «한 번 열리면 더 잘 버티게» 해 위험을 되갚았다」고 적었는데
**산술이 반대였습니다** — 닫는 문턱은 `바닥 + OPEN_DB − HYST_DB` 라 12−6=**6** → 16−8=**8** 로
**올라갑니다**(= 더 «빨리» 닫힙니다). 함정 대조가 잡았습니다.

| 값 | 하는 일 | 대가 |
|---|---|---|
| `OPEN_DB` ↑ | «여는» 문턱 — 옆소리로는 덜 열림 | 내가 **조용히** 말하면 그 말이 게이트를 못 엶 |
| `HYST_DB` ↑ | «닫는» 문턱 — 한 번 열린 뒤 **옆사람이 계속 떠들어도 붙잡고 있지 못하게** 함 | 내 **말끝**이 더 일찍 줄어듦 |
| `HOLD_MS` ↑ | **이것만 되갚는 값** — 말 사이 공백에서 깊어진 `DUCK` 이 티나지 않게 | (없음) |
| `DUCK` ↓ | «닫혔을 때만» 작동 → **내 말을 자를 위험이 없음** | 잘못 닫힌 순간이 더 크게 티남 |

⟹ 그래서 **「너무 세다」의 증상이 실제로 나올 수 있습니다**(§9-6). 되돌릴 값을 상수 옆에 적어 두었습니다.

### 9-3. 왜 이 크기인가 (그리고 왜 더는 안 올렸나)

- 사장님 마이크는 사진상 **책상 마이크(Elgato Wave)** 입니다 — 헤드셋이 아니라 입에서 30~50cm.
  옆자리(2~3m)와의 차이가 **원리상 12~18dB** 밖에 안 됩니다(거리 제곱 + 방 반사).
  ⟹ 문턱을 그 차이(약 16dB)보다 **더** 올리면 옆소리보다 **내 목소리가 먼저 잘립니다.**
- 그래서 **여는 문턱은 16 에서 멈추고**, 위험이 없는 쪽(`DUCK` = «닫혔을 때만» 작동)을 **8dB 더** 내려
  체감 감소분을 벌었습니다. 닫는 문턱(바닥+8)은 «한 번 열린 뒤 옆사람이 붙잡고 있지 못하게» 하는 몫입니다.
- ⛔ **내가 말하는 «동안» 옆소리는 이 방식으로 못 줄입니다** — 게이트가 열려 있으니 함께 나갑니다.
  줄어드는 것은 «내가 말을 쉬는 사이» 입니다. 그 이상은 코드가 아니라 **붐 마이크 헤드셋**(§6)입니다.

### 9-4. 검토했다가 버린 것

| 버린 것 | 왜 |
|---|---|
| `OPEN_DB` 를 20~22 로 | 책상 마이크의 거리 차(12~18dB)를 넘어섭니다 — 옆소리보다 **내 말이 먼저** 잘립니다 |
| `DUCK` 을 0(완전 무음)으로 | 잘못 닫힌 순간 첫 음절이 통째로 사라집니다(§2 의 원래 결정). 0.03 도 «들리는» 크기입니다 |
| `ABS_DB` −55 → −50 | 조용한 방에서만 걸리는 값이라 «사무실» 이 문제인 이번 건과 무관하고, 조용히 말하는 교사만 손해입니다 |
| `TICK_MS` 25 → 20 (반응 빠르게) | 수업 중 CPU 는 화질 인코더와 나눠 씁니다. 효과는 40ms → 35ms 수준이라 값이 안 맞습니다 |
| 세기 3단계 스위치 | 지시는 「더 세게」였지 「고르게 해 달라」가 아닙니다. 화면에 손잡이를 늘리면 되돌리기가 더 어려워집니다 |
| `localStorage` 숨은 조정 손잡이 | 배포 없이 맞출 수 있어 솔깃하지만, 아무 데도 안 적힌 조작이 하나 늘어납니다 |
