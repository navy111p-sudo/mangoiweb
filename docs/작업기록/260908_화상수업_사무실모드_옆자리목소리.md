# 화상수업 «사무실 모드» — 옆자리 교사 목소리 줄이기 (2026-09-08)

## 1. 왜 했나

사장님 「망고아이 사무실에서 주변 교사들의 목소리가 들리지 않게 노이즈 캔슬링 할 수 있는 방법을 알려줘」
→ 확인해 보니 **이미 켜져 있는 잡음 제거로는 원리상 안 되는 일**이었습니다.

- 수업 마이크는 `noiseSuppression: true` 로 이미 켜져 있고(`js/idx-main.js:424`),
  독 ⚙️ 설정의 「잡음 제거」 토글도 기본 켜짐(`vc-dock.js:725`)입니다.
- 그런데 브라우저·WebRTC 의 노이즈 억제는 **에어컨·팬·키보드 같은 «일정한 잡음»** 을 겨냥한 것입니다.
  옆자리 교사 목소리는 그 엔진에게 «지워야 할 잡음» 이 아니라 **«지켜야 할 음성»** 으로 분류됩니다.
- 게다가 `autoGainControl: true` 라, 교사가 말을 쉬는 동안 마이크 감도를 자동으로 올려
  **옆 소리를 오히려 키우고** 있었습니다.

사장님이 「사무실 모드 스위치 넣어줘」로 이어서 지시하셨습니다.

## 2. 무엇을 넣었나

수업 화면 하단 독 ⚙️ **설정 › 마이크 › 「사무실 모드」** 스위치 하나. 켜면 셋을 합니다.

| 무엇 | 왜 |
|---|---|
| ① 자동 게인(AGC) 끄기 | 말을 쉴 때 옆자리 소리를 키우는 주범 |
| ② 하이패스 120Hz | 방 웅웅거림·책상 진동 제거(사람 목소리 기본 주파수 아래) |
| ③ 노이즈 게이트 | 바닥 소음보다 충분히 큰 소리(=내 목소리)만 통과, 그 아래는 **줄임** |

정본은 **`cloudflare-deploy/public/js/idx-vc-officemode.js`** 하나입니다(defer).

- ⛔ 게이트는 **완전 무음이 아니라 -22dB 감쇠**까지만 — 완전히 끊으면 교사가 조용히 말할 때
  첫 음절이 사라져 고치려던 것보다 나쁩니다.
- ⛔ 문턱을 고정 숫자로 두지 않습니다 — 사무실마다 바닥 소음이 다릅니다. 조용한 구간의 바닥을
  배워 그 위 12dB. ⚠️ **위로는 아주 느리게만** 따라갑니다(시끄러운 값을 «평소» 로 배우면
  게이트가 스스로 열려 아무 일도 안 하게 됩니다).
- ⛔ 탭이 숨으면 게이트를 **활짝 열고 손을 뗍니다** — 타이머가 느려진 사이 «닫힌 채 굳어»
  목소리가 안 나가는 것을 원천 차단합니다.

## 3. 검토했다가 버린 것

- **Krisp·NVIDIA Broadcast 를 코드로 붙이기** → 불필요합니다. 가상 마이크 «장치» 로 잡히므로
  설정 › 마이크에서 고르면 끝이고, 코드를 한 줄도 안 고쳐도 됩니다.
- **해상도·비트레이트 손대기** → 이 문제와 무관합니다.
- **잡음 제거 토글을 더 세게 만들기** → 그 엔진은 사람 목소리를 못 지웁니다(1장).
- **`idx-main.js` 에 직접 넣기** → 849KB blocking 이고 첫 화면 예산 여유가 116바이트입니다.
  defer 파일에서 전역 함수를 감싸는 방식으로 했습니다(`index.html` 은 script 1줄 + `?v=` 만).

## 4. 밟은 함정 — 브라우저 검사가 잡았습니다

🔴 **끄면 소리가 아예 안 나가는 상태**를 한 번 만들었습니다.

`restorePlainMic()` 이 «지금 트랙» 에서 마이크 장치 id 를 읽었는데, 켜져 있는 동안 그 트랙은
WebAudio 가 만든 **가공 트랙**이라 장치 id 가 없습니다. 그것을 `deviceId:{exact:…}` 로 넘겨
`OverconstrainedError` 가 났고, 되돌리기가 통째로 실패해 **무음 가공 트랙이 그대로 남았습니다.**

- ⚠️ 회귀 하니스 281건이 **전부 초록**이었습니다. 함수도 값도 다 «있고» 틀린 것은
  «무엇을 읽는가» 뿐이라 문자열 검사로는 원리상 안 보입니다.
- ✅ 고침: 켤 때 «진짜» 장치 id 를 기억(`srcMicId`) + 되돌리기에 **2단 폴백** + 마지막 안전망.
- CLAUDE.md 2장에 함정으로 남겼습니다.

🪤 곁가지 — **`#vc-dock-settings` id 가 «둘»** 입니다(`vc-dock.js:603` 팝오버 · `848` 버튼).
`querySelector` 가 먼저 나오는 쪽을 집어 검사가 회차마다 들쭉날쭉했습니다.
**기존 저장소의 id 중복이라 이번에 고치지 않았습니다**(그 id 로 찾는 다른 코드가 있으면
동작이 바뀝니다 — 사람이 결정할 일). 검사만 그것에 안 기대게 고쳤습니다.

## 6. 남은 것 (사람이 정할 일)

- 🔴 **가장 확실한 대책은 코드가 아니라 붐 마이크 헤드셋**(입에서 3~5cm)입니다.
  근접 효과로 내 목소리와 2m 밖 목소리의 크기 차이가 20dB 이상 벌어집니다. 교사 1인당 3~5만원.
  사무실 모드는 그 **보조**입니다 — 이것만으로 옆 소리가 완전히 없어지지는 않습니다.
- 문턱(바닥 +12dB)·감쇠(-22dB)는 실제 사무실에서 써 보고 조정할 값입니다.
  지금은 «덜 자르는» 쪽으로 잡아 두었습니다(첫 음절이 잘리는 것이 더 나쁩니다).
