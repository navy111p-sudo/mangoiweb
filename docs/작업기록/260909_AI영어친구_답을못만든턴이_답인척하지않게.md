## 2. 무엇을 바꿨나

### PR #896 — 폴백이 «답» 인 척하지 않게

화면의 그 두 줄은 **LLM 답이 아니라 `src/api-ai.ts` 의 «모델 3개가 다 실패했을 때» 고정 폴백**이었습니다.

| 자리 | 무엇을 |
|---|---|
| `src/api-ai.ts` 폴백 블록 | `usedFallback` 표시를 두고 응답에 **`ai_unavailable`** 을 밝힘. 폴백이면 `fix`·`repeat` 도 끔(둘 다 «AI 가 한 말» 이라는 전제 위에 있음) |
| `src/api-ai.ts` 저장부 | 폴백은 `ai_friend_chats` 에 **assistant 로 저장하지 않음.** ⛔ 학생 발화는 그대로 남김 |
| `public/ai-friend.html` | 그 턴은 **전용 알림 `appendNotice()`** 로 그림 — 말풍선이 아니라 알림, **교정 카드·TTS 없음** |

### PR #897 — 실패 «사유» 를 우리 쪽에 남기기

정본 **`src/ai-failure-log.ts`** 의 `recordAiFailure` / 표 `ai_failure_log`.
남기는 것은 **마지막 예외 문장 · 시도한 모델 · JSON 모드 여부 · 평문/빈응답 횟수 · 단계**뿐입니다.

⛔ 학생 발화·AI 답변은 **한 글자도** 싣지 않습니다(진단용 표이지 개인정보를 담는 곳이 아닙니다).
⛔ 통째로 `try/catch` — 기록이 실패해도 대화가 안 끊깁니다.

## 3. 왜 그렇게 풀었나 — 원인 셋 · 검토했다가 버린 방법

### 왜 «이해를 못 한다» 로 보였나 — 셋이 겹쳤습니다

| # | 무엇이 | 왜 안 보였나 |
|---|---|---|
| ① | 서버가 폴백을 **`ok:true`** 로 줌 | 화면에 이미 있던 「⚠️ 잠시 응답이 지연되고 있어요」 경로로 **안 갑니다.** 그냥 말풍선으로 그려지고 **TTS 가 소리내어 읽기까지** 했습니다 |
| ② | 그 문구가 `ai_friend_chats` 에 **«AI 가 한 말» 로 저장** | 다음 «정상» 턴이 오면 모델이 그것을 자기 직전 발언으로 봅니다 |
| ③ | 문구 자체가 주제를 안 봄 | 공룡 이야기 중에 「오늘 뭐 먹었어?」 |

### 버린 방법

- ⛔ **폴백 문구를 «주제에 맞게» 지어내기** — 2장 「측정할 수 없는 값을 그럴듯하게 채우고 싶을 때」와 같은 뿌리입니다. 모르면 모른다고 말합니다.
- ⛔ **폴백을 아예 없애기** — 소리가 아예 안 나오는 것보다 안내라도 있는 편이 낫습니다.
- ⛔ **`wrangler.toml` 의 `head_sampling_rate` 를 올려서 로그를 늘리기** — 공동 금지구역이고, 관찰 가능성 이벤트 요금도 걸립니다.
- ⛔ **학생 발화까지 실패 기록에 남기기** — 진단에 도움은 되지만 그 표가 개인정보 저장소가 됩니다. 변이시험에 그 경우를 넣어 **빨간불이 나게** 해 뒀습니다.
- ⛔ **웜업(`src/index.ts`) 쪽도 같이 고치기** — 공동 금지구역입니다. 참고로 웜업 폴백은 이미 «주제 중립» 한 문장이라 이 사고가 성립하지 않습니다.
