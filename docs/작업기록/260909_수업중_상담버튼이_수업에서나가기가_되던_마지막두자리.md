# 수업 중 「상담」이 «수업에서 나가기» 가 되던 마지막 두 자리

**앞선 작업** [260902_관제탑_화면코드_js분리.md](260902_관제탑_화면코드_js분리.md) — 같은 함정을 8개 파일에서 고친 건

---

## 1. 왜 했나

2026-09-02 에 사장님이 관리자 「수업 관찰」 화면 사진을 보내 주셨습니다 —
**참관 탭은 이미 열렸는데** 「⚠ 브라우저가 새 창을 막았습니다」 상자가 떠 있었고,
그 안의 링크를 누르면 **탭이 하나 더** 열렸습니다.

브라우저에서 직접 재 보니 원인은 팝업 차단이 아니었습니다.

| 호출 | 반환값 | 탭 |
|---|---|---|
| `window.open(u,'_blank','noopener')` | **null** | 1 → 2 (**열림**) |
| `window.open(u,'_blank')` | object | 2 → 3 |

`noopener` 를 **«기능 문자열»** 로 주면 표준상 탭은 열리는데 반환값이 `null` 입니다.
⟹ 반환값으로 «막혔나» 를 판정하는 코드는 **언제나 «막혔다»** 가 됩니다.

그때 8개 파일을 고쳤지만 **`public/index.html` 두 자리는 못 고쳤습니다** —
CLAUDE.md 4-2 의 **공동 금지구역**이라 배포 담당 승인이 필요했습니다.
그래서 신설 하니스가 그 두 자리를 «사람 결정 대기» 로 **이름을 찍어 출력**하게 두었고,
2026-09-09 에 사장님이 **「그래」** 로 승인해 주셨습니다.

### 반경이 왜 컸나

`window.openKakao` 를 부르는 곳이 **홈과 수업 화면 둘 다**입니다
(`js/vc-dock.js` 의 「💬 상담」·`js/idx-grid-menu.js` — 둘 다 그것으로 early-return).
그런데 이 두 자리의 폴백이 하필 **더 나쁜 변종**이었습니다.

```js
if (!w) { try { location.href = url; } catch(_){} }
```

`w` 가 **항상** null 이므로 이 줄이 **항상** 돌았습니다 ⟹
**카톡 탭이 열리고 + 보던 화면까지 카톡으로 이동.**
수업 중이면 그것이 곧 **«수업에서 나가기»** 였습니다.

⚠️ **다만 이것은 코드·브라우저 실측에서 나온 판단이고, 실제로 그 때문에 수업을 나간
제보가 있었는지는 확인하지 못했습니다.** 잰 것과 거기서 내린 판단을 갈라 적습니다.

## 2. 무엇을 고쳤나

`cloudflare-deploy/public/index.html` 두 자리 — `toKakao()` 와 `window.openKakao`.

```diff
-    try { w = window.open(url, '_blank', 'noopener'); } catch(e){}
-    if (!w) { try { location.href = url; } catch(_){} }
+    try { w = window.open(url, '_blank'); } catch(e){}
+    if (w) { try { w.opener = null; } catch(e){} } else { try { location.href = url; } catch(_){} }
```

앞서 8개 파일에 적용한 것과 **똑같은 두 줄**입니다.

- 기능 문자열에서 `noopener` 를 빼고 **`w.opener = null`** 로 같은 보호를 겁니다.
  고치기 전 코드도 그 보호를 하려 했는데 `w` 가 null 이라 **한 번도 안 돌았습니다.**
- **인앱 브라우저 폴백은 그대로 살립니다** — 카톡·문자앱은 진짜로 null 을 돌려줍니다.
  바뀐 것은 「이제 그 null 이 **진짜** 다」는 것뿐입니다.

### 손대지 않은 것

| 자리 | 왜 |
|---|---|
| `rel="noopener"`(11300·14111행, HTML **속성**) | 무해합니다. 함정은 «기능 문자열» 쪽이고 ①절 검사도 속성은 안 잡습니다 |
| 17387행 `window.open(...,'noopener')` | **반환값을 안 씁니다.** 안 쓰는 호출은 그대로 둬도 무해합니다 |

## 8. 곁가지 — 원격 브랜치가 «이미 병합된 이력» 이었습니다

푸시가 non-fast-forward 로 거절됐습니다. 원격 브랜치에 일주일 전 커밋 두 개가
남아 있었는데, 그 내용은 이미 **squash 로 main 에 들어가 있었습니다**
(squash 병합이라 해시가 main 어디에도 없습니다 — CLAUDE.md 「커밋 해시로 판정하면」).

버리기 전에 **그 커밋이 추가한 줄이 지금 main 에 실제로 있는지** 파일별로 세었습니다
(`?v=` 도 v=34·v=27 로 이미 그보다 앞서 있었습니다). 잃을 것이 없음을 확인하고
`--force-with-lease` 로 밀었습니다.

⛔ 해시가 없다고 «안 한 것» 으로 읽지 마세요 — **지금 코드를 보는 것**이 판정입니다.
