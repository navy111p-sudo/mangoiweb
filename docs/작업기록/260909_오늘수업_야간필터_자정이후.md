# 관리자 「🚪 오늘 수업」 — «🌒 야간»(자정 이후 포함) 거르기 (2026-09-09)

## 1. 왜 했나

어제(9/8) 넣은 **「🌙 23시 이후」** 필터가 **자정을 넘긴 수업을 통째로 빠뜨립니다.**
그날 보고에 그 사실을 적었고, 사장님이 「자정 이후까지 보는 야간 필터도 만들어줘」로 정하셨습니다.

**왜 빠졌나** — 이 목록은 **하루치**입니다. 그래서 00:10 수업은 «23시 뒤» 가 아니라
**그 날짜 목록의 맨 앞**에 있습니다. 「23시 이후」는 뒤쪽 끝만 보니까 구조적으로 못 봅니다.

📊 **[잰 것]** CLAUDE.md 배포창 항목의 실측 — 00:00~00:20 접속 **22건** · 00:40~01:10 도 있음.
그것이 어제 필터에 안 걸리던 바로 그 수업들입니다.

## 3. 왜 이렇게 했나 — 갈림길과 버린 길

### 3-1. 「야간」의 뜻 — «하루의 양 끝» (23:00~23:59 + 00:00~05:59)

이 목록의 하루에는 밤이 **두 조각** 있습니다.

```
 00:00 ─ 05:59        06:00 ─────────── 22:59        23:00 ─ 23:59
 새벽(전날 밤의 꼬리)      아침·낮·저녁                  밤(그날 밤의 머리)
 └───── 🌒 야간 ─────┘                                └── 🌙 23시 이후 ──┘
                                                     └───── 🌒 야간 ─────┘
```

- **06시를 끝으로** 둔 것은 실측(01:10)을 넉넉히 덮으면서 아침 수업과 안 섞이는 자리라서입니다.
- 「23시 이후」는 **그대로 남겼습니다** — 어제 사장님이 그걸로 정하셨고, 야간은 그것을 품는 더 넓은 갈래입니다.

### 3-2. 체크박스 두 개 vs 선택칸 하나 → **선택칸**

두 범위가 **포개져** 있어서 「23시 이후만 ☑ + 야간 ☑」 의 뜻이 모호합니다.
선택칸은 그 상태가 **구조적으로 못 생깁니다.**
⛔ 체크박스 둘로 되돌리지 마세요.

### 3-3. ⚠️ 못 한 것 — «자정을 넘겨 이어지는 한 판» 은 여전히 두 날짜로 갈립니다

오늘 23:40 수업의 이어지는 **00:20 은 «내일 날짜» 목록**에 있습니다(서버가 날짜로 자릅니다).
야간 필터는 «그 날짜 안» 의 밤 두 조각을 모을 뿐입니다.

**감추지 않고 화면이 말하게** 했습니다 — 야간을 고르면 목록 위에 한 줄:

> 🌒 야간 = 이 날짜의 새벽 N건(00:00~05:59) + 밤 M건(23:00~23:59) 입니다.
> 자정을 넘겨 이어진 수업은 «다음 날짜» 목록의 새벽에 있습니다 — 날짜를 하루 넘겨 보세요.

⛔ 이 줄을 지우지 마세요. 지우면 「오늘 23:40 수업의 새벽이 안 보인다」가 그대로
「필터가 빠뜨린다」는 제보가 됩니다(그리고 그건 **사실**입니다 — 필터가 아니라 목록의 성질입니다).

**두 날짜를 한 화면에 합치는 것**(내일 날짜를 함께 불러 잇기)은 안 했습니다 — 그러면
`_rows` 에 두 날짜가 섞여 «전체 N건»·«카페24 N건» 같은 숫자가 전부 뜻이 바뀝니다.
필요하면 **별건**으로 하는 것이 맞고, 사람이 정할 일입니다.

### 3-4. 🔴 새로 생긴 함정 — «모름»(-1)이 새벽으로 둔갑

시각을 모르는 줄은 `kstHour()` 가 **-1** 을 돌려줍니다. 그런데 새벽 판정을
`h < NIGHT_UNTIL_HOUR` 로만 쓰면 **-1 이 그 조건을 그냥 통과**합니다 —
「23시 이후」쪽과 **정반대 방향**의 사고입니다(그쪽은 «모르면 안 걸림» 이 안전한데,
이쪽은 «모르는 것이 새벽» 이 되어 버립니다).

```js
function isDawn(s) { var h = kstHour(s.start_ts); return h >= 0 && h < NIGHT_UNTIL_HOUR; }
//                                                       ^^^^^^ 이 짝이 없으면 -1 이 새벽
```

⛔ `h >= 0` 을 빼지 마세요. 하니스 ⑦-2 가 **그 변이를 실제로 잡습니다.**
