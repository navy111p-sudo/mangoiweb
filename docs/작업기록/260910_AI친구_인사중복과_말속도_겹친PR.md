# AI 영어친구 — 인사 중복 수리, 그리고 「말 속도」를 남에게 넘긴 이야기

**날짜** 2026-09-10 · **PR** [#918](https://github.com/navy111p-sudo/mangoiweb/pull/918) ·
**파일** `cloudflare-deploy/public/ai-friend.html` · `test-harness/ai_friend_character_help_harness.mjs` ·
`test-harness/manual/ai-friend-greet-browser.mjs`(신설)

---

## 1. 왜 했나

사장님이 `mangoi.ai/ai-friend.html` 화면을 캡처해 주셨습니다. 둘이 보였습니다.

1. Emma 인사 **「Hi! I'm Emma. What do you want to talk about today?」가 두 줄**
2. 콘솔에 빨간 **503** 한 줄(`ai-friend.html:1`)

이어서 말씀하셨습니다 — 「인사 중복 고쳐줘」 · 「Emma 말이 너무 빨라… **임모양이 아니라 말이** 너무 빨라서 느리게」.

> ⚠️ 두 번째 말씀은 **방향을 바로잡아 주신 것**입니다. 그 직전 작업(PR #902)이 «입모양 전환 속도» 였기 때문에
> 저는 같은 자리를 또 볼 뻔했는데, 사장님이 「입모양이 아니라 말」이라고 못 박아 주셔서
> 아바타 타이밍이 아니라 **TTS `playbackRate`** 로 갔습니다.

## 2. 잰 것 / 거기서 내린 판단

**[잰 것 — D1 `mango-db`, SELECT 만]**
- `ai_friend_chats` 에 **인사가 한 줄도 없습니다.** ⟹ 「서버에 두 벌」이 아니라 **화면에만 쌓인 것**입니다.
- `ai_failure_log` 표가 **없습니다.** ⟹ chat-friend 폴백이 한 번도 안 돌았습니다.

**[판단 — 추론이지 측정이 아님]**
- 503 의 출처가 `ai-friend.html:1` 이라 「문서가 직접 부르는 자원」으로 보입니다.
  정적 자원은 저장소에 전부 실재합니다(주제 아이콘 10개 포함). **어느 주소인지는 못 찾았습니다** —
  프록시가 `mangoi.ai` 를 막아 제가 그 화면을 못 엽니다. 사장님 Network 탭이 필요합니다.

## 3. 고친 것 — 인사 중복 하나

`setFriend(v, true)` 가 친구 카드를 **누를 때마다 그냥 덧붙였습니다.**

```js
// 전
if (greet) { appendMsg('ai', f.hi); if (isSoundOn()) speakText(f.hi, null, null); }
```

인사는 「지금 누구를 골랐나」를 알리는 **확인 줄**이라 한 번에 하나만 있으면 됩니다.
그래서 **맨 끝에 붙어 있는 인사만** 지우고 새로 답니다(`dataset.friendGreet`).

- ⛔ 지우는 범위를 넓히면 **대화 도중에 친구를 바꿀 때 학생이 쓴 말이 사라집니다.**
  앞 인사는 그 시점의 기록이라 그대로 둡니다.
- ✅ 목소리는 누를 때마다 다시 들려줍니다 — 「들어 보고 고르는」 것이 이 인사의 목적입니다.

## 4. 🔴 검토했다가 «통째로 버린» 것 — 말 속도

만들어서 검증까지 끝냈는데 **병합 직전에 전부 뺐습니다.**

제 안은 「시작 칸」 하나를 1 → 0.8 로 옮기는 것이었습니다(웜업이 2026-07-23 부터 쓰는 값과 맞춤).
그런데 **CI 를 기다리는 사이 다른 세션이 PR #917 을 먼저 병합**했고, 그쪽이 더 나았습니다.

| | 제 안(버림) | #917(이미 병합) |
|---|---|---|
| 방식 | 「시작 칸」만 1 → 0.8 | 다섯 칸을 **통째로** 한 칸씩 내림(0.5/0.65/0.8/1/1.25) |
| 이미 속도를 골라 둔 학생 | **안 닿음**(그 선택이 이깁니다) | 저장값을 «칸 번호» 로 한 번만 옮겨 **전원이 한 칸 느려짐** |
| 사장님 지시와의 거리 | 「처음 오는 학생」만 | 「**모두** 말하게」 |

⟹ 제 것을 그대로 병합하면 **그 작업을 되돌립니다.** 그래서:

- `ai-friend.html` 충돌 두 곳 → **전부 main 쪽 채택**
- `listening_speed_harness` → **main 판으로 되돌림**(제 검사 5종은 #917 이 없앤 `AF_START_RATE` 를 읽어 헛돕니다)
- 브라우저 하니스에서 속도 절 3종을 덜어내고 이름을 `ai-friend-greet-browser.mjs` 로
  (속도 감시는 #917 이 `listening_speed_harness` 와 `manual/ai-friend-header-browser.mjs` 두 곳에 두었습니다)

> 📜 이건 CLAUDE.md 2장 「작업하는 사이 다른 세션이 같은 일을 먼저 병합함」에 **이미 적힌 함정**입니다.
> 그 항목이 「겹치는 부분이 크면 PR 을 «main 에 아직 없는 것만» 으로 다시 쓰는 편이 낫습니다」라고
> 적어 둔 그대로 했습니다 — **새로 넣을 줄은 없습니다.**

### 버린 이유를 굳이 남기는 까닭

「시작 칸만 옮기기」는 **틀린 방법이 아니라 좁은 방법**입니다.
나중에 「처음 오는 학생만 다르게」가 필요해지면 그때는 이 방식이 맞습니다.
지금 버린 이유는 **사장님 지시가 「모두」였기 때문**이지 방식이 나빠서가 아닙니다.
