작업 시각이 **2026-09-10(목) 14:24 KST** 라 `class-window.mjs` 가 `hold=true`(화·목 14:00~23:00)를
돌려줍니다. 병합해도 배포는 **창 밖의 몰아 배포**로 밀립니다.

⚠️ 다만 몰아 배포는 실측상 **124~177분 늦게** 옵니다(CLAUDE.md 2장). 「23시 직후」가 아니라
**그날 밤~다음 날 새벽**으로 보는 것이 맞습니다. 급하면 사람이 `force_now` 로 내보냅니다.

## 2. 왜 그렇게 고쳤나 — 버린 방법

- **① `accept` 에 `image/*` 를 넣기** → 버렸습니다. 서버가 받는 것은 `pdf·jpg·png·webp` 뿐이라
  HEIC·GIF 를 **고를 수는 있는데 안 올라가는** 상태가 됩니다. 게다가 그 값 끝의 «슬래시+별표» 가
  하니스 주석 제거기를 열어 **무관한 검사 3건을 거짓 FAIL** 로 만들었습니다(CLAUDE.md 2장에 추가).
- **① 폴더용 input 을 파일용으로 바꾸기** → 버렸습니다. 폴더 업로드가 이 화면의 주 경로입니다.
  대신 **새 라벨만** 자기 상자 안에서 클릭을 받게 하고(`z-index`), 빈 자리는 예전처럼 폴더 선택입니다.
- **② 중복이면 숨김을 «자동으로» 풀기** → 버렸습니다. 숨긴 데는 이유가 있습니다(MES 교재 등).
  조회가 상태를 바꾸면 **누가 왜 바꿨는지 아무도 모릅니다.** 사람이 버튼을 누를 때만 풉니다.
- **② 숨김 조회 실패를 `false`(숨김 아님)로 떨어뜨리기** → 버렸습니다. 「모름」을 「아니오」로 채우면
  화면이 엉뚱한 곳을 찾게 합니다. `null` 로 두고 화면이 「확인하지 못했습니다」라고 말합니다.
- **③ 서버 게이트를 느슨하게(이름 확인 없애기)** → 버렸습니다. 되돌릴 수 없는 조작입니다.
  `textbook-purge-gate.ts` 는 **한 줄도 안 건드렸습니다.** 바꾼 것은 «어디서 묻는가» 뿐입니다.
- **③ 확인을 체크박스 하나로** → 버렸습니다. 이름 확인은 「BTS 2」와 「BTS 22」를 가르는 장치입니다.
  대신 **[📋 복사] 버튼**을 두고, **왜 잠겼는지**(앞뒤 빈칸까지) 화면이 말합니다.
- **④ 파일명에서 「BTS 2」까지 알아내게 분류기 고치기** → **안 했습니다.** 분류 규칙은 폴더 업로드
  전체가 걸려 있어 반경이 큽니다(하니스 49종). 사람이 이름을 «보고 고치게» 하는 쪽을 먼저 했습니다.
  ⟹ 남은 과제입니다.

## 6. 🪤 함정 대조가 잡은 것 — **진짜 결함 4건을 이 커밋 안에서 고쳤습니다**

첫 판은 하니스가 전부 초록이었는데도 아래가 틀려 있었습니다.

1. 🔴 **«모름(null)» 이 원리상 만들어지지 않았습니다.** 숨김 여부를 `loadHiddenBooks()` 로 물었는데
   그 함수는 **몸통 전체가 try** 라 절대 던지지 않고 실패하면 **빈 Set** 을 줍니다 → `.has()` 가
   **false**(=「숨김 아님」 확정)가 되고 제 `catch` 는 **도달 불가능한 죽은 코드**였습니다.
   바로 위 주석은 정반대(「false 가 아니라 null」)를 단언하고 있었습니다.
   ✅ 그 자리에서 **직접 조회**하도록 바꿔 D1 이 흔들리면 진짜로 `null` 이 나옵니다.
2. 🔴 **그 검사가 헛돌고 있었습니다** — 선언문 «글자» 만 봤습니다.
   ✅ 정본을 **오려 내 가짜 D1 로 실제로 돌립니다**(찾는다 · 안 숨김 · **던지면 null** · 표 없음).
   변이 2종(옛 `loadHiddenBooks` 되돌리기 · `catch` 를 false 로) **전부 실제 FAIL** 확인.
3. 🔴 **`#cr-name-hint` 를 지우는 코드가 없어** 파일 → 폴더 순서로 올리면 버튼은 「N초 뒤 자동 저장」,
   바로 위 상자는 「자동 저장을 **멈췄습니다**」 — **한 화면이 두 가지**를 말했습니다.
   ✅ 렌더 때마다 지웁니다 + 브라우저 검사에 그 순서를 못 박았습니다.
4. 🔴 **[👁 보이게 하기] 가 강사에게 «눌러도 안 되는 버튼»** 이었습니다
   (`/api/admin/textbook-hidden-books` 는 `TEACHER_BLOCKED_PREFIXES`). 「실패 1개」만 뜨고 **왜인지
   한 글자도 없었습니다.** ✅ 403 이면 「본사 계정만 — 본사에 요청하세요」라고 말합니다.

   「크롬 대화상자 차단이 **원인이었다**」로 썼습니다. ✅ 「잰 것 / 판단(재지 않음)」으로 갈랐습니다.

곁들여 고친 것 — **ZIP 한 개를 끌어다 놓으면 거짓말**을 했습니다(풀기 전에는 «/» 가 없어 «파일 하나»로
보이지만 풀면 폴더 구조가 생깁니다) → 판정을 **`processFiles` 안 한 곳**(압축 푼 뒤)으로 모았습니다.
