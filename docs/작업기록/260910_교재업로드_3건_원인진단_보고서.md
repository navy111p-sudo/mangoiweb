## ① PDF·JPG 파일을 고를 수가 없다

**증상** — [📁 폴더 선택] 을 누르면 창에 파일이 하나도 안 보이고 폴더만 보입니다.

**원인** — `public/textbook-uploader.html:186` 의 파일 입력이 **하나뿐이고 폴더 전용**입니다.

```html
<input type="file" id="folder-input" webkitdirectory directory multiple>
```

`webkitdirectory` 가 붙으면 브라우저는 **표준상 폴더만** 보여 줍니다. 즉 「PDF 를 인식 못 한다」가
아니라 **파일을 고르는 버튼이 애초에 없습니다.** 제보자가 「전에도 안 됐다」고 한 것과 맞습니다.

**드래그는 됩니다** — 실측: 그 PDF 는 이 경로로 2026-09-01 17:39 에 실제로 올라갔습니다(아래 ②).

**제안** — [📄 파일 선택] 버튼을 **하나 더** 답니다(`accept=".pdf,.jpg,.jpeg,.png,.webp"`).
분류·업로드 경로는 지금 것을 그대로 씁니다. 폴더 버튼은 건드리지 않습니다.
⚠️ 다만 파일 하나만 올리면 아래 ②의 «이름» 문제를 그대로 만나므로 **②와 함께** 고쳐야 뜻이 있습니다.

## ③ 숨긴 교재를 «완전 삭제» 할 수 없다

**기능은 있습니다** — 2026-09-07 에 「묶음 통째 영구 삭제」를 넣었고, **1단계(세기)는 실제로 동작합니다**
(제보 화면: 「30장 · 1.7 MB」 + 파일 예시 3개까지 정상 표시).

### 결정적 근거

[잰 것 — 운영 D1 `admin_audit_logs`]

| action | 건수 | 마지막 |
|---|---|---|
| `ghost_join` | 76 | 2026-09-10 13:44 |
| `teacher_status_change` | 3 | 2026-09-01 11:01 |
| **`textbook_purge_book`** | **0** | — |

이 표는 **지금도 살아서 기록되고 있습니다**(오늘 13:44 기록 있음). 그런데 교재 삭제만 **0건**입니다.
삭제 실행 경로는 반드시 이 로그를 남기므로 ⟹ **2단계 삭제 요청이 서버에 한 번도 도달하지 않았습니다.**
(권한 문제가 아닙니다 — 권한이 없으면 1단계 세기부터 막힙니다. 세기는 됐습니다.)

### 그럼 어디서 끊겼나

2단계는 브라우저 `prompt()` 로 **교재 이름을 정확히 타이핑**해야 넘어갑니다
(`textbook-uploader.html:1676`). 여기서 끊길 수 있는 길이 둘이고, **둘 다 서버에 요청을 안 보냅니다.**

- **[가장 유력 — 추론]** 크롬의 「이 페이지에서 추가 대화상자를 만들지 않도록 차단」.
  확인창을 여러 번 거치면 이 체크가 뜨고, 켜지면 **`prompt()` 가 아예 안 뜨고 `null`** 을 돌려줍니다.
  코드는 `if (typed === null) return;` 으로 **아무 말 없이 끝납니다** ⟹ 사람에게는 「눌러도 아무 일도 안 일어난다」.
- **[가능 — 추론]** `004. I visited my grandparents` 를 한 글자라도 다르게 치면 「이름이 다릅니다」.

⚠️ 어느 쪽인지는 **그 화면에서 사람이 한 번 봐야** 확정됩니다(우리 쪽 로그로는 «도달 안 함» 까지만 압니다).

### 덤 — 「삭제」가 두 종류라 헷갈립니다

- 라이브러리 표의 빨간 **[삭제]** = **이 컴퓨터(IndexedDB)만** 지웁니다. 서버는 한 줄도 안 건드립니다.
- 서버에서 지우는 것은 아래 «📚 공용 자료실 교재» 의 **[🗑 삭제]** 입니다.

**제안**
1. 2단계 확인을 **브라우저 대화상자에서 화면 안 확인 상자로** 옮깁니다.
   이름은 화면에 **복사·붙여넣기 가능**하게 두거나 자동으로 채우고, 사람은 [삭제] 를 한 번 더 누릅니다.
   ⟹ 브라우저가 대화상자를 막아도 삭제가 됩니다. 진행률·결과도 화면에 남습니다.
2. ⛔ **안전장치는 유지합니다** — 되돌릴 수 없는 조작이라 «세기 → 확인 → 실행» 2단계와 본사 전용 제한은 그대로.
3. 라이브러리 표의 [삭제] 를 **[이 PC 에서 삭제]** 로 이름을 바꿔 혼동을 없앱니다.
