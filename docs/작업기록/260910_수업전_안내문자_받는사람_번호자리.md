「테스트 명단에 사전 문자를 보낼 수 있나」를 조사하다 **결론이 뒤집혔습니다.**

### 그 3건이 길을 알려 줬습니다

나간 3건은 전부 `lt15`·`lt16`·`lt18` — 레벨테스트 **신청서에서 번호를 직접 받아**
`students_erp` 에 넣은 체험계정이었습니다. 즉 **우리 화면에서 번호를 받으면 문자는 나갑니다.**

그런데 지금 그 세 계정을 조회하면 번호가 **사라져 있고 `created_at` 이 카페24 센티넬**입니다.

들어 있어 **매일 밤 03:00 KST 에 덮였습니다.** (DELETE 보존 목록에도 번호는 없습니다.)

⟹ **번호를 받는 것과 두는 것을 갈라야 한다** — 받는 것은 우리 화면에서,
두는 것은 동기화가 안 건드리는 자리에.

## 2. 검토했다가 버린 방법

| 버린 방법 | 왜 버렸나 |
|---|---|
| **`students_erp` 에 번호를 넣기** | 하룻밤이면 사라집니다. 체험계정 3개가 실제로 그렇게 잃었습니다. 이게 이 사고의 원인 그 자체입니다 |
| **새 API 경로 신설**(`/api/admin/student-phone` 류) | `src/index.ts` 가 공동 금지구역인데 라우팅 허용목록에 한 줄이 필요합니다. `student-override.ts` 머리말이 이미 「새 /api 경로는 만들지 않는다」고 못 박아 두었습니다 → **이미 등록된 `/api/admin/enrollments`(POST·PATCH)에 얹었습니다.** `src/index.ts` 를 한 줄도 안 건드렸습니다 |
| **`student_retention` 의 번호를 쓰기** | 219행 중 195행에 번호가 있지만 «이탈위험 스냅샷» 이라 잘 다니는 학생은 원리상 없고, 스냅샷에서 빠지면 DELETE 됩니다. 명단 9명은 **0건**이었습니다 |
| **`parent_notify_queue` 에 넣기** | INSERT 만 있고 **읽어서 보내는 코드가 0곳**입니다(죽은 큐). 넣으면 「보냈다고 하는데 아무 데도 안 감」이 됩니다 |
| **알림톡(카카오)으로 먼저 전환** | 알림톡은 사전 승인 템플릿만 나갑니다(검수 1~2일). 번호가 없으면 어차피 0건이라 **순서가 뒤**입니다. 문자로 먼저 열고 뒤에 전환합니다 |
| **번호를 필수 입력으로** | 지금 등록되는 학생 중에 번호를 모르는 경우가 실제로 있습니다. 필수로 만들면 «번호 때문에 등록이 안 되는» 새 사고가 됩니다 → **선택 입력** |
| **리마인더 안에서 번호를 직접 SELECT** | 판정이 두 곳으로 갈립니다(`no-show-truth.ts` 가 그 선례). 정본 `phonesForStudent` 하나만 고쳤습니다 |

### 왜 «목록에도» 넣었나

등록 화면의 칸은 **앞으로 등록되는** 학생용입니다. 명단 9명은 이미 등록을 마쳤으므로
그 칸으로는 번호를 못 넣습니다 — 그대로 뒀으면 **1번을 다 만들고도 정작 9명에게는
못 쓰는** 상태가 됐을 것입니다. 목록 행의 `📵` 를 누르면 그 자리에서 넣습니다.

## 4. 조심한 것 (규칙서 함정)

- **`src/index.ts` 무수정** — 이미 라우팅에 있는 `/api/admin/enrollments` 와
  `/^\/api\/admin\/enrollments\/\d+$/` 에 얹었습니다
- **표 칸 늘리기** — 좁은 화면은 12칸 그리드라 **줄마다 합이 정확히 12** 여야 합니다.
  기존 세 줄(3+3+4+2 / 4+4+4 / 6+6)을 안 건드리려고 새 칸은 `span 12`(한 줄 통째)로 뒀고,
  `order` 를 안 주면 기본값 0 이라 맨 앞으로 튀어나오므로 `order: 10` 을 함께 줬습니다
- **fail-open 방향** — 번호 «조회» 실패는 통과(명부로 떨어짐 → 예전과 같음),
  번호 «저장» 실패는 **사람에게 말함**(조용히 넘기면 「넣었는데 왜 안 가지」)
- **D1 바인드 100개 한도** — 목록 조회는 공용 `selectInChunks` 를 씁니다
- **한 칸만 고쳐도 다른 칸이 안 지워지게** — `COALESCE(NULLIF(?, ''), …)`.
  「아직 안 받았다」와 「지웠다」는 `clear` 로 가릅니다
- **인라인 `onclick` 이 부르는 이름은 전역에서 찾습니다** — `enEditPhone` 을 최상위에 뒀고
  하니스가 **중괄호 깊이 0** 인지 검사합니다
- **`?v=`** — `adm-core.js` 204→206 · `admin-inline-c.css` 74→75.
  원장(`test-harness/asset-versions.json`)도 함께 커밋
