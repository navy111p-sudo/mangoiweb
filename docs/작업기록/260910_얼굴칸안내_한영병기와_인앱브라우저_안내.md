## 1. 무엇을 고쳤나

### ① 상대 얼굴칸 안내를 한/영 병기로

같은 자동 음성전용(AAO)인데 **자기 화면 토스트는 한/영 병기**(2026-08-08 사장님 지시)이고
**상대 타일 안내만 한 언어**였습니다. `class-1896-20260910` 에서 한국인 원장님이
「Weak connection — audio only for now」만 받으셨습니다.

- `js/idx-main.js` `vcApplyRemoteCamHint()` — `var en = miIsEn();` 와 삼항 두 개를 없애고
  **한국어 + `<i>영어</i>`** 로 함께 그립니다. 「상대가 카메라를 껐어요 / Camera is off」도 같습니다.
- `css/vc-refresh.css` — `.vc-camoff-hint i`(블록·11px·굵게·`opacity:.82`)와
  `.vc-camoff-hint{overflow:hidden}`. ⛔ 인라인 style 금지(첫 화면 예산이 비쌉니다).

### ② 카톡 등 인앱 브라우저 안내가 수업 화면에서도 뜨게

배너는 `js/inapp-escape.js` 에 **이미** 있었는데 선제 조건이
`location.pathname` 에 `/video-call` 이 있거나 `window.MANGO_VIDEO_PAGE === true` 였고,
그 값은 **`precheck.html` 한 곳에만** 있었습니다(전수 확인).
수업은 `/`(index.html)에서 돌아가므로 그 배너는 **`getUserMedia` 가 실패할 때만** 떴습니다
— 카메라가 정상이면 영영 안 뜹니다. 원장님이 그 경우였습니다.

- `js/inapp-escape.js` — `window.MangoEscape` 에 **`showBanner` 를 내보냅니다**(+24B).
- `js/idx-vc-mobilefix.js`(**defer** — 첫 화면에 0바이트) 에 ⓬절 추가:
  인앱이면 **홈에서** 배너를 띄우고, 닫으면 그 세션 동안 안 띄우고,
  **수업에 들어가면 치웁니다.**

## 2. 왜 그렇게 골랐나 (버린 것)

| 버린 것 | 왜 |
|---|---|
| **수업 «중» 에 배너 띄우기** | 배너가 `top:0` 고정인데 수업 툴바는 **36px**(`body.vc-in-call .toolbar`) 이라 「나가기」·언어 버튼을 통째로 덮습니다 |
| **자동 이동(`openExternal`)** | 브라우저가 바뀌면 `localStorage` 가 달라 **학생 로그인이 안 넘어갑니다**(「로그인했는데 또 로그인하래요」). 안내만 하고 **사람이 고르게** 합니다 |
| **`index.html` 에 `MANGO_VIDEO_PAGE=true` 넣기** | 공동 금지구역이고, 그 순간 **안드로이드에서 홈 방문자 전원이 크롬으로 자동 이동**합니다(기존 선제 분기가 `setTimeout(openExternal,600)` 을 함께 합니다) |
| **배너를 defer 에서 새로 그리기** | 같은 배너가 두 벌이 됩니다. 이미 있는 것을 **내보내서** 씁니다 |
| **안내 문구 고치기** | 한/영 병기라 그대로 두었습니다. 문구를 고치면 blocking 바이트가 한국어 3B/자로 비쌉니다 |

⚖️ **맞바꿈(아는 채로 고름)**: 인앱으로 **홈에 들어온 사람 전원**에게 한 번 뜹니다.
수업이 아니어도 뜨지만 — 이 저장소는 인앱 브라우저를 카메라만이 아니라
**세션 쿠키 미반환·새 창 못 엶**으로도 이미 «부적합» 으로 못 박아 두었고, 닫으면 그 세션 동안 안 뜹니다.

## 4. 밟은 함정 (둘 다 검사가 잡았습니다)

### 🪤 ㉠ 앵커를 «첫 번째 일치» 로 잡아 중첩 함수 안에 코드를 넣었다

스크립트로 절을 끼워 넣을 때 `s.index("  try { console.log('[mobilefix] ")` 를 썼는데
그 문자열이 **가면(⑦절) 안쪽에 먼저** 있었습니다. 그래서 새 절이 **깊이 3의 중첩 함수 안**에
들어가 **한 번도 실행되지 않았습니다.**
⚠️ `node --check` 통과 · 회귀 하니스 통과 · 콘솔 오류 0 — **브라우저로 재고서야** 드러났습니다
(`window.showView.__mgInApp` 이 `false`). ✅ `rindex` 로 «마지막» 앵커를 잡고
**넣은 뒤 중괄호 깊이가 1인지** 확인해야 합니다.

### 🪤 ㉡ `?v=` 를 올릴 HTML 을 한 파일만 보고 놓쳤다

`inapp-escape.js` 는 `index.html`·`precheck.html` 에서는 **`?v=` 없이** 실리는데
**`video-call/index.html` 만 `?v=20260805c`** 로 부르고 있었습니다.
`index.html` 만 grep 해서 놓쳤고 `asset_version_harness` 가 잡았습니다.
✅ `?v=` 는 **저장소 전체 HTML 을 grep** 해서 올립니다.

📌 그리고 검사를 돌리는 사이 **배포된 적 없는 중간 버전 `mobilefix?v=27`** 이 원장에 기록돼,
CLAUDE.md 처방대로 **28로 올리고 27 항목을 원장에서 뺐습니다**(남겨 두면 «나갔던 버전» 으로 읽힙니다).
