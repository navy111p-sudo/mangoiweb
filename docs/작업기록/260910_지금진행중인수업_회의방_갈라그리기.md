# 관리자 「지금 진행 중인 수업」 — 회의방을 «수업» 줄과 갈라 그리기 (A안)

## 1. 왜 했나

관리자 › 수업 관찰 카드의 「🔴 지금 진행 중인 수업」에 `meet-1234` 가
**「⚠ 혼자 대기중」 경고가 몇 시간이고 켜져** 있었습니다.

진단 결과 **화면은 사실을 말하고 있었습니다** — `/api/active-rooms` 는 KV 목록을 그냥
뿌리지 않고 **방마다 Durable Object 에 직접 물어 인원 0이면 그 자리에서 지웁니다.**
즉 그 줄이 있었다는 것은 «그 순간 소켓이 실제로 붙어 있었다» 는 뜻입니다.

문제는 그 사실이 아니라 **화면이 그것을 「수업」이라고 부른 것**이었습니다.

- 그 카드 제목은 「지금 진행 중인 수업」인데 `/api/active-rooms` 는 **방 종류를 가리지 않습니다.**
- 회의방은 예약이 없어 «수업» 칸이 「—」이고, **끝나는 시각도 없습니다.**
- 서버의 죽은 소켓 청소(120초)는 **브라우저가 죽었을 때만** 돕니다 —
  탭이 살아 있으면 25초마다 ping 이 가므로 «정상 접속» 이 맞습니다.
- ⟹ **탭을 닫기 전에는 사라지지 않고**, 그동안 그 경고가 계속 켜져 있었습니다.

## 2. 무엇을 했나 (화면 한 파일)

`cloudflare-deploy/public/js/adm-s1.js` 의 `ghLoadLive()` 를 쪼갰습니다.

| 새 함수 | 하는 일 |
|---|---|
| `_ghIsMeetRoom(roomId)` | `/^meet-/i` — 회의방인가 (판정은 이 한 곳뿐) |
| `_ghRoomRow(rm, sched, en, isMeet)` | 방 한 줄. 수업방·회의방이 **같은 함수**를 쓰고 «회의방인가» 만 다르게 그림 |
| `_ghRoomsTable(list, sched, en, isMeet)` | 표 한 벌 |
| `_ghMeetHtml(list, sched, en)` | 접힌 «회의방» 구역(`<details>`, 기본 닫힘) |

바뀐 것은 셋입니다.

1. **회의방을 접힌 구역으로 내렸습니다** — 「👥 회의방 N개 · 수업 아님 (눌러서 열기)」
   + 「예약이 없어 «끝나는 시각» 이 없고, 마지막 탭을 닫아야 사라집니다」 한 줄.
2. **회의방에서는 경고를 낮췄습니다** — `⚠ 혼자 대기중` → `혼자`.
   ⛔ «혼자» 라는 사실 자체는 지우지 않았습니다.
3. **개수를 갈라 셉니다** — `· 화상방 1개` → `· 수업방 0개 · 회의방 1개 · 예약 수업 6건`.

`admin.html` 은 `?v=10` → `?v=11` **한 줄**만 바꿨습니다.

## 3. 검토했다가 버린 방법

| 버린 안 | 왜 버렸나 |
|---|---|
| **회의방 줄을 아예 안 그리기** | 참관·직접입장이 회의방에서도 필요합니다. 감추면 「기능이 없어졌다」가 됩니다(녹화 목록에서 이미 밟은 함정) |
| **「N분째 혼자」 표시** (B안) | DO `/status` 에 **입장 시각이 아예 안 실려** 화면이 알 방법이 없습니다. 실으려면 `video-call-room.ts`(공동 금지구역)를 고쳐야 해서 **별건**입니다 |
| **혼자 N시간이면 자동으로 방 닫기** (C안) | ⛔ 오판하면 **수업 중에 끊깁니다.** 잃을 것이 너무 큽니다 |
| **`meet-` 을 소문자로만 판정** | `MEET-1234` 는 대소문자를 구분하는 **다른 방**인데(`idFromName`), 그것도 회의방으로 보여야 합니다. `/i` 로 둡니다 |
| **서버(`handleActiveRooms`)에서 거르기** | `src/index.ts` 는 공동 금지구역이고, 서버가 미리 지우면 「회의방도 보고 싶다」를 되돌릴 길이 사라집니다 |

## 4. 확인한 방법

- **새 하니스** `test-harness/meet_room_split_harness.mjs` — **51종**(두 화면 모두).
  관제탑도 `node:vm` 가짜 DOM 으로 **통째로 실행해** 표·칩·접힌 구역을 갈라서 봅니다.
  ⑪절은 **두 파일의 판정을 각각 오려 내 전수 표본에서 같은 답을 내는지** 대조합니다.
  ⛔ 「그 글자가 있는가」로 묻지 않습니다. `node:vm` 에 **가짜 DOM·가짜 fetch** 를 깔고
  `adm-s1.js` 를 **통째로 실행해** 나온 HTML 을 `<details>` 안팎으로 갈라서 봅니다.
  판정(`_ghIsMeetRoom`)은 **소스에서 오려 내 실제로 돌립니다**(하니스에 다시 적지 않음).
  - ⚠️ **짝으로** 물었습니다 — 「회의방엔 그 경고가 없다」 옆에 **「수업방엔 그대로 있다」**,
    「회의방이 접힌 구역에 있다」 옆에 **「수업방은 위쪽 표에 그대로」**,
    「meet- 은 회의방」 옆에 **「class-·c24-·demo-·room-·mangoi-class 는 안 건드린다」**.
    한쪽만 두면 «전부 감추기»·«전부 회의방으로» 도 통과합니다.
- **변이시험 4종 — 전부 실제 FAIL** (⛔ `git checkout` 이 아니라 `cp` 사본으로 되돌렸습니다)

## 4-2. 🗼 관제탑도 함께 갈랐습니다 (사장님 「관제탑도 같이 갈라줘」)

「같은 판정이 두 곳이면 한쪽만 고쳐진다」가 이 저장소가 반복해서 밟은 함정이라,
`/admin/monitor-wall.html` + `js/monitor-wall.js` 도 **같은 방식**으로 갈랐습니다.

- `isMeetRoom` · `splitRooms` 를 두고 `visibleRooms()`(수업방) / `visibleMeetRooms()` 로 나눔
- 칩: `🎥 화상방 N` → **`🎥 수업방 N` + `👥 회의방 M`**,
  **「⚠ 혼자 대기」 칩은 수업방만** 셉니다(회의방을 함께 세면 그 칩이 늘 켜져 있습니다)
- 회의방은 접힌 `<details id="meet-sec">` 구역으로. 회의방 배지는 `.badge.mute` 회색
- **🔁 순회 참관에서 회의방을 뺐습니다** — 「수업 돌아보기」가 회의방에서 시간을 버립니다
  (회의방은 그 줄의 [👁 참관] 으로 봅니다. 안내 문구도 «수업방» 으로 고쳤습니다)

⚠️ 그 화면에는 **HTML 12KB · HTML+JS 50KB 상한**(`monitor_wall_harness` ①)이 있습니다.
처음에 주석을 길게 달아 **49.66KB(여유 348B)** 까지 갔다가 줄여 **48.92KB(여유 1,107B)** 로 되찾았습니다.

🪤 **`list.map(rowHtml)` 함정** — `rowHtml(rm, isMeet)` 로 인자를 늘렸는데 `map` 에 그대로 넘기면
**둘째 인자가 «순번»** 이라 둘째 줄부터 전부 회의방이 됩니다. `function` 으로 감싸 부르고,
하니스 ⑬이 그것을 못 박습니다 — ⚠️ 그 검사가 처음엔 **제가 쓴 경고 주석 자신**을 잡아 FAIL 났습니다
(「부정 검사는 주석을 벗겨 낸 사본으로」 — 블록주석은 정규식 한 줄이 아니라 **줄 단위 상태추적**으로 벗깁니다).

## 4-3. 🔴 함정 대조가 잡은 진짜 결함 — 「회색으로 낮췄다」가 화면에서 거짓이었습니다

`trap-check` 가 브라우저로 재 보니 **두 표시의 계산된 색이 똑같은 `rgb(16,24,40)`** 이었습니다.

```
html[data-admin-theme="ivory"][data-admin-tone="slate"] [id^="card-"] :is(p,span,div,…)
  { color:#101828 !important }        ← (0,3,1) 작성자 !important 가 인라인을 이긴다
```

⟹ 코드 주석·커밋 메시지·규칙서 **세 곳**이 「회색으로 낮췄다」고 말하는데 **화면에서는 아니었습니다.**
이 저장소가 네 번 사고로 못 박은 「거짓 문장이 규칙서에 박혀 아무도 다시 안 본다」 그 형태입니다.

🔴 **덤 — 고치기 «전» 에도 그 경고는 노란색이 아니었습니다.** 사장님이 보신 신호는 색이 아니라
`⚠` 글리프와 문구였습니다. 진단 보고서·작업기록·CLAUDE.md 의 「노란불」 서술을 **전부 정정**했습니다.

✅ 고침은 CLAUDE.md 의 처방 그대로 — **인라인 색을 버리고 클래스**로 주고
`admin-inline-c.css` 맨 끝에서 **조상 id 를 앞에 붙여**(1,1,0) 되살렸습니다
(같은 파일 `.tr-st-badge` v=63 이 같은 사정의 선례입니다).

| | 고치기 전 | 고친 뒤 (브라우저 실측) |
|---|---|---|
| 수업방 `⚠ 혼자 대기중` | `rgb(16,24,40)` | **`rgb(180,83,9)`** · 대비 5.02 |
| 회의방 `혼자` | `rgb(16,24,40)` | **`rgb(71,84,103)`** · 대비 7.69 |

⛔ 앰버 `#fbbf24` 로 되돌리지 마세요 — 흰 카드 위 **대비 1.67** 이라 안 읽힙니다.
⚠️ 색은 **둘째 신호**입니다 — 글리프(`⚠`)·문구·굵기(800/700)가 먼저입니다.

**감시는 브라우저 검사** `test-harness/manual/meet-split-color-browser.mjs`(8종, 자동으로 안 돕니다).
그중 ④가 **되돌림 대조**입니다 — 옛 «인라인 색» 방식으로 넣은 두 span 이 **지금도 같은 색**임을
함께 재서, 이 검사가 «원래 늘 갈리는 것» 을 재는 게 아님을 증명합니다.
