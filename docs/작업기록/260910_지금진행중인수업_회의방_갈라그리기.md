# 관리자 「지금 진행 중인 수업」 — 회의방을 «수업» 줄과 갈라 그리기 (A안)

## 1. 왜 했나

관리자 › 수업 관찰 카드의 「🔴 지금 진행 중인 수업」에 `meet-1234` 가
**「⚠ 혼자 대기중」 노란불로 몇 시간이고 켜져** 있었습니다.

진단 결과 **화면은 사실을 말하고 있었습니다** — `/api/active-rooms` 는 KV 목록을 그냥
뿌리지 않고 **방마다 Durable Object 에 직접 물어 인원 0이면 그 자리에서 지웁니다.**
즉 그 줄이 있었다는 것은 «그 순간 소켓이 실제로 붙어 있었다» 는 뜻입니다.

문제는 그 사실이 아니라 **화면이 그것을 「수업」이라고 부른 것**이었습니다.

- 그 카드 제목은 「지금 진행 중인 수업」인데 `/api/active-rooms` 는 **방 종류를 가리지 않습니다.**
- 회의방은 예약이 없어 «수업» 칸이 「—」이고, **끝나는 시각도 없습니다.**
- 서버의 죽은 소켓 청소(120초)는 **브라우저가 죽었을 때만** 돕니다 —
  탭이 살아 있으면 25초마다 ping 이 가므로 «정상 접속» 이 맞습니다.
- ⟹ **탭을 닫기 전에는 사라지지 않고**, 그동안 노란 경고가 계속 켜져 있었습니다.

## 2. 무엇을 했나 (화면 한 파일)

`cloudflare-deploy/public/js/adm-s1.js` 의 `ghLoadLive()` 를 쪼갰습니다.

| 새 함수 | 하는 일 |
|---|---|
| `_ghIsMeetRoom(roomId)` | `/^meet-/i` — 회의방인가 (판정은 이 한 곳뿐) |
| `_ghRoomRow(rm, sched, en, isMeet)` | 방 한 줄. 수업방·회의방이 **같은 함수**를 쓰고 «회의방인가» 만 다르게 그림 |
| `_ghRoomsTable(list, sched, en, isMeet)` | 표 한 벌 |
| `_ghMeetHtml(list, sched, en)` | 접힌 «회의방» 구역(`<details>`, 기본 닫힘) |

바뀐 것은 셋입니다.

1. **회의방을 접힌 구역으로 내렸습니다** — 「👥 회의방 N개 · 수업 아님 (눌러서 열기)」
   + 「예약이 없어 «끝나는 시각» 이 없고, 마지막 탭을 닫아야 사라집니다」 한 줄.
2. **회의방에서는 노란 경고를 회색으로 낮췄습니다** — `⚠ 혼자 대기중` → `혼자`.
   ⛔ «혼자» 라는 사실 자체는 지우지 않았습니다.
3. **개수를 갈라 셉니다** — `· 화상방 1개` → `· 수업방 0개 · 회의방 1개 · 예약 수업 6건`.

`admin.html` 은 `?v=10` → `?v=11` **한 줄**만 바꿨습니다.

## 3. 검토했다가 버린 방법

| 버린 안 | 왜 버렸나 |
|---|---|
| **회의방 줄을 아예 안 그리기** | 참관·직접입장이 회의방에서도 필요합니다. 감추면 「기능이 없어졌다」가 됩니다(녹화 목록에서 이미 밟은 함정) |
| **「N분째 혼자」 표시** (B안) | DO `/status` 에 **입장 시각이 아예 안 실려** 화면이 알 방법이 없습니다. 실으려면 `video-call-room.ts`(공동 금지구역)를 고쳐야 해서 **별건**입니다 |
| **혼자 N시간이면 자동으로 방 닫기** (C안) | ⛔ 오판하면 **수업 중에 끊깁니다.** 잃을 것이 너무 큽니다 |
| **`meet-` 을 소문자로만 판정** | `MEET-1234` 는 대소문자를 구분하는 **다른 방**인데(`idFromName`), 그것도 회의방으로 보여야 합니다. `/i` 로 둡니다 |
| **서버(`handleActiveRooms`)에서 거르기** | `src/index.ts` 는 공동 금지구역이고, 서버가 미리 지우면 「회의방도 보고 싶다」를 되돌릴 길이 사라집니다 |

## 4. 확인한 방법

- **새 하니스** `test-harness/meet_room_split_harness.mjs` — **21종.**
  ⛔ 「그 글자가 있는가」로 묻지 않습니다. `node:vm` 에 **가짜 DOM·가짜 fetch** 를 깔고
  `adm-s1.js` 를 **통째로 실행해** 나온 HTML 을 `<details>` 안팎으로 갈라서 봅니다.
  판정(`_ghIsMeetRoom`)은 **소스에서 오려 내 실제로 돌립니다**(하니스에 다시 적지 않음).
  - ⚠️ **짝으로** 물었습니다 — 「회의방엔 노란불이 없다」 옆에 **「수업방엔 그대로 있다」**,
    「회의방이 접힌 구역에 있다」 옆에 **「수업방은 위쪽 표에 그대로」**,
    「meet- 은 회의방」 옆에 **「class-·c24-·demo-·room-·mangoi-class 는 안 건드린다」**.
    한쪽만 두면 «전부 감추기»·«전부 회의방으로» 도 통과합니다.
- **변이시험 4종 — 전부 실제 FAIL** (⛔ `git checkout` 이 아니라 `cp` 사본으로 되돌렸습니다)

  **TypeScript 를 한 줄도 안 건드립니다**(`.js` 자산 + `.html` 한 줄) — CI 가 봅니다.
- ⚠️ **브라우저로는 못 봤습니다** — 프록시가 `mangoi.ai` 를 막습니다.
