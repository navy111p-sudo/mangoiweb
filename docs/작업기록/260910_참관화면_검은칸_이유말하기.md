# 참관 화면의 «검은 칸» 이 왜 검은지 말하게 하기

- 날짜: 2026-09-10
- 제보: 사장님 — 「👁 바로 참관」으로 `class-1896-20260910` 에 들어갔더니 검은 화면이 나온다.
  이어서 「학생과 선생님도 참관자가 들어온 걸 알게 되는 것 아니냐」는 걱정.
- 바꾼 것: `cloudflare-deploy/public/js/vc-observe-guard.js` ⑪절 신설 ·
  `public/index.html` 의 `?v=9 → v=10` 한 줄 · `test-harness/observer_camera_guard_harness.mjs` I절

## 1. 왜 했나 — 걱정의 «전제» 부터 확인했다

제보를 그대로 받으면 「참관이 새고 있다」가 되지만, 코드를 재 보니 그 전제가 성립하지 않았다.

**[잰 것]**

- 서버는 참관자를 «입장한 사람» 목록에 넣지 않고 **방송을 한 건도 하지 않는다**
  (`src/video-call-room.ts` `handleJoinObserve` — `joined:false · role:'observer'`).
  그래서 참여자 수·입장 알림·참가자 목록 어디에도 안 나온다.
- 얼굴 칸은 2026-09-01(⑩절)에 이미 막혀 있고 그 수리는 `origin/main` 에 그대로 있다
  (가드 4곳·서버 3곳). `observer_camera_guard_harness` H절을 **실제로 돌려** 확인했다(PASS).
- 사장님이 보신 화면은 `?observe=` 였고 참여자 수도 2명이었다.

**⟹ 그 검은 칸은 참관자 «자신» 의 화면이고 두 사람에게는 가지 않는다.**
고칠 것은 「참관이 새는 것」이 아니라 **「참관 화면이 이유를 말하지 않는 것」** 이었다.

## 2. 무엇이 비어 있었나

칸을 만들 때 「📷 연결 중…」(`index.html` 의 `.vc-connecting-hint`)을 함께 그린다 —
**즉 안내가 없는 것이 아니라 이미 있다.** 그런데 그것은 **영상이 도착하는 순간
`vcAddRemoteVideo` 가 지운다.** 그래서 그 «뒤» 에

- 상대가 카메라를 끄거나 (원격 비디오 트랙이 `muted` 로 바뀐다)
- 영상이 얼어붙으면 (트랙은 `live` 인데 프레임이 안 는다)

**아무 설명 없는 검은 칸**만 남는다. 참관자는 그것을 «고장» 으로 읽는다.

> ⚠️ 저는 처음에 「연결 중 안내가 없으니 넣자」고 사장님께 말씀드렸다. **틀렸다.**
> 코드를 열어 보고서야 이미 있는 것을 알았고 제안을 정정했다.
> 「없다고 단정하고 새로 만들지 말 것」(CLAUDE.md 2장)을 그대로 밟을 뻔했다.

## 3. 검토했다가 버린 방법

| 버린 방법 | 이유 |
|---|---|
| 「연결 중」 안내를 새로 만든다 | **이미 있다**(위 2장). 두 벌이 되면 같은 말을 두 번 한다 |
| `index.html` 에 CSS·마크업을 넣는다 | 공동 금지구역이고 첫 화면 예산 여유가 **186바이트**뿐. CSS 는 JS 에서 주입(이 파일 ⑦절의 방식) |
| `js/idx-main.js` 에 넣는다 | blocking 849KB — 학생 29,000명이 첫 화면에서 받는다 |
| 수업 화면(강사·학생)에도 같은 배지를 단다 | 반경이 학생 전원. 그쪽에는 이미 다른 안내가 있고, 이번 제보와 무관하다 |
| `MutationObserver` 로 칸 상태를 감시한다 | 홈이 통째로 멎은 전력 2회(2026-07-14·08-27) |
| «끝이 있는 확인» 몇 번으로만 본다 | 카메라를 껐다 켜는 것은 수업 내내 일어난다 — 몇 번으로는 못 잡는다 |

## 4. 무엇을 했나 — ⑪절

`vc-observe-guard.js` 끝에 새 IIFE 를 붙였다.

- **🔒 주소에 `?observe=` 가 없으면 곧바로 반환한다.** 수업 화면에는 한 줄도 돌지 않는다 —
  이것이 이 절의 안전장치 전부다.
- 참관 화면에서만 2초 타이머를 돌리고, **참관이 아니게 되면 스스로 끈다**
  (`js/idx-vc-qlog.js` 의 수신 계측 타이머와 같은 방식).
- 판정(`stateOf`)은 DOM 을 읽기만 한다 — 하니스가 이 함수를 오려 내 실제로 돌린다.
  - 비디오 트랙이 없다 → 「🎤 소리만 오는 중」
  - 트랙이 `muted` 이거나 `live` 가 아니다 → 「📷 상대가 카메라를 껐습니다」
  - 프레임이 4초째 그대로 → 「⏳ 영상이 멈췄습니다 — 다시 받는 중」
- **모르면 말하지 않는다** — 프레임 수를 못 재는 브라우저(`-1`), `<video>` 가 `paused`
  (자동재생 정책 — 기존 「소리 켜기」 배너가 담당), 영상이 아직 안 붙음,
  「📷 연결 중…」이 살아 있음 → 전부 **판정 보류**. 틀린 설명은 설명이 없는 것보다 나쁘다.

⛔ `vcRemovePeer(id,'left')` 는 부르지 않는다(학생 화면에 「수업이 끝났어요」).

## 4-2. 함정 대조(trap-check)가 잡은 것 — 첫 판의 결함 둘

자동 하니스는 전부 초록이었는데 **문자열·실행 검사가 원리상 못 보는 자리** 둘이 걸렸다.

### 🔴 ① 「상대가 카메라를 껐습니다」는 **이미 있는 기능이고, AAO 에서는 틀린 말**이었다

`idx-main.js` 의 **`vcApplyRemoteCamHint()`** 가 이미 `.vc-camoff-hint` 를 그리고, 그것은
서버가 실어 준 사유로 **«사람이 껐다(user)» 와 «회선이 약해 시스템이 내렸다(aao)» 를 갈라**
말한다(`window.vcRemoteCamOff[uid]`). 참관 화면도 `vc-in-call` 이 붙고 `cam-state` 방송을
그대로 받으므로 **그 정본이 참관에서도 돈다.**

⟹ 내 첫 판은 `t.muted` 만 보고 «사람이 껐다» 고 단정해서, **AAO 일 때 기존 힌트(「음성만
전송 중」) 옆에 «사실이 아닌» 말을 하나 더** 붙일 뻔했다. 같은 절이 「틀린 설명은 설명이
없는 것보다 나쁘다」고 적어 놓고 그 자리를 만든 것이다.

✅ 고침 — 정본이 **아는** 칸(`vcRemoteCamOff` 가 있거나 `.vc-camoff-hint`/`.vc-black-hint` 가
붙어 있음)에서는 **손을 뗀다.** 정본이 모르는 채로 영상만 끊긴 자리에서만, 그것도
**단정하지 않는 문구**로 말한다 — 「📷 상대 영상이 오지 않습니다」.

📌 다만 **전부 중복은 아니었다.** 아래 둘은 기존 코드가 원리상 못 보는 진짜 빈자리다.
- `stall` — `vcRemoteBlackWatch` 는 `v.videoWidth > 0` 로 보는데 **얼어붙어도 videoWidth 는 0 이 안 된다.**
- `nocam` — 영상 수신자가 없으면 「상대가 영상 안 보냄 = 개입 금지」로 그 자리에서 반환한다.

### 🔴 ② `[id^="vc-video-"]` 가 «칸이 아닌 것» 둘을 함께 잡았다

`index.html` 에 같은 접두사인데 칸이 아닌 요소가 둘 있다 — **`#vc-video-pane`(8440행)**·
**`#vc-video-grid`(8498행)**. 둘 다 안에 `<video>` 를 갖고 있어 칸으로 오인되고,
한 사람이 카메라를 끄면 알약이 **최대 세 곳**에 그려진다.

이 저장소가 이미 아는 함정이다 — `idx-main.js:1442` 가 `id === 'pane'` 을 따로 거르고,
6922행 주석이 「접두사를 `vc-video-` 와 겹치지 않게 할 것」이라고 못 박아 두었다.

✅ 고침 — 정본 `vcRemoteBlackWatch` 와 같은 방식으로 **그리드의 직계 `.video-box` 만** 훑는다.

### 🟡 함께 고친 곁가지 넷

- **화면 공유 타일은 `stall` 판정에서 뺀다** — 교재 한 장을 띄워 두면 새 프레임이 없다.
  판별은 이 저장소가 이미 쓰는 `.vc-ss-badge`. ⚠️ **실제 프레임 간격은 재지 않았다.**
- **배경 탭에서는 말하지 않는다**(`document.hidden`) — 관제탑 순회 참관은 창을 재사용해
  배경으로 둔다. 그러면 멀쩡한 영상이 「멈췄다」가 된다. ⚠️ 이것도 **재지 않았고** 구조로 막았다.
- 언어 폴백에서 **구버전 키 `mango_lang` 제거**(공통 키는 `mangoi_lang`).
- 알약이 **별점 버튼**(오른아래 `z-index:7`)을 가리지 않게 왼쪽 정렬 + 그 폭만큼 자리 비움.

### 🪤 그리고 하니스 자신의 결함 둘

- **I절이 파일 «끝까지» 를 자르고 있었다** — 바로 위에서 H절의 같은 사고를 고쳐 놓고
  I절에 그대로 썼다(「적어 둔 것 ≠ 한 것」). ⑫절이 붙는 순간 거짓 FAIL 이 났을 것이다.
- **부정 검사가 자기 주석을 잡았다** — 「«껐다» 로 단정하지 않는다」를 원본으로 판정했더니
  **왜 그렇게 했는지 적은 내 주석**에 그 낱말이 있어 FAIL. `strip()` 사본으로 고쳤다.

## 덧붙임 (2026-09-11) — ⑫절: 이름을 «지어낸» 상대의 얼굴 칸은 만들지 않는다

### 왜 했나
사장님 「왜 이렇게 계속 참가자가 보여?」 → 「이거 자체가 아예 나타나지 않게 해줘」 →
「**관찰을 하더라도** 저게 아예 나타나지 않게 해줘」(스크린샷에 빨간 X 로 그 칸을 표시해 주심).

### 잰 것
- 「참가자」는 사람 이름이 아니라 **서버가 «이름을 모를 때» 채우는 글자**다 —
  `handleOffer`: `fromUsername: fromObserver ? '' : (usernameOf(userId) || '참가자')`.
- `usernameOf` 는 «입장(joined)한 소켓» 이 없으면 `null` (재접속으로 밀려난 소켓·닫힌 소켓).
- `handleJoinRoom` 이 `if (!username) → error` 로 막으므로 **정상 입장자는 이름이 반드시 있다.**
  ⟹ 이름 없이 오는 상대는 ⓐ 참관자 ⓑ 끊긴 소켓 둘뿐이고 **둘 다 영상을 안 보낸다.**
- 녹화 배지 `👤N명` 은 사람 수가 아니라 `collectVideos().length`(화면 칸 수) — 유령을 같이 센다.
- 관리자 「직접 입장」은 **배제**: `vcAutoJoinFromParams` 가 이름 기본값 **「교사」** 를 넣고,
  D1 에 그 이름으로 들어간 기록이 실제로 있다(`meet-1234 / username=교사 / 09-10 13:44:38`).

### 무엇을 했나
`vc-observe-guard.js` **⑫절** — 이름을 모르는 상대는 **영상이 실제로 올 때까지 칸을 만들지 않는다.**
진짜 참가자는 ① 명단이 진짜 이름으로 부를 때 ② 영상이 도착할 때, 둘 중 하나로 반드시 생긴다.
