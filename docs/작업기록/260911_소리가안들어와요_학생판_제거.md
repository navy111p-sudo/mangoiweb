# 「🔇 소리가 안 들어와요」 — 학생·관찰자 안내 배지 제거 (2026-09-11)

## 1. 무엇을 왜

사장님이 수업 화면 스크린샷에 **「🔇 소리가 안 들어와요」** 를 빨갛게 지우시며 「안 나오게 해줘」라고 하셨습니다.

그 배지는 `vcMarkNoSound()`(`cloudflare-deploy/public/js/idx-main.js`)가 얼굴 타일 우하단(소리 아이콘 바로 위)에
그리는 것입니다. 2026-08-07 Kaye 강사 건의 1(「학생이 말을 안 하는 건지 마이크가 죽은 건지 모르겠다」)로 들어간 기능입니다.

**뜨는 조건이 문제였습니다.** 음량 루프(`idx-main.js`)의 판정은 이렇습니다.

```js
if (muted || talking) mon.soundAt = _now;
const dead = !muted && (_now - (mon.soundAt || _now) > 8000);
```

즉 **«마이크는 켜져 있는데 8초 동안 소리가 안 들어왔다»** 이지 «고장났다» 가 아닙니다. 그런데 수업에서
8초 침묵은 아주 흔합니다 — 학생이 문제를 푸는 동안 **강사 타일**에, 강사가 설명을 듣는 동안 **학생 타일**에
그대로 뜹니다. 사장님 화면이 정확히 그 상황이었습니다(교사가 듣고 있는 중). **«듣고 있는 중» 이 «고장» 으로 읽혔습니다.**

## 2. 한 것

`vcMarkNoSound()` 에서 **학생·관찰자용 안내 문구 판을 아예 안 그립니다.**

```js
const staff = (typeof vcIsStaffNow === 'function') ? vcIsStaffNow() : false;
if (!(staff && uid)) return;          // ← 새 게이트
```

**강사 화면의 「🔇 소리 없음 · 눌러서 고치기」 버튼은 그대로 남깁니다** — 누르면 학생 브라우저가 마이크를
다시 잡는(`vcRequestMicFix` → 서버 `device-fix`) **실제 조치 수단**이라 없애면 강사가 학생 마이크를 원격으로
손볼 유일한 입구가 사라집니다.

⚠️ **지우는 경로는 안 건드렸습니다** — `if (!on) { if (b) b.remove(); return; }` 가 새 게이트보다 «앞» 이라,
이미 떠 있던 배지는 그대로 사라집니다.

## 3. 검토했다가 버린 방법

| 방법 | 왜 버렸나 |
|---|---|
| 배지를 통째로 없애기 (`vcMarkNoSound` 호출 제거) | 강사가 학생 마이크를 원격으로 다시 잡는 **유일한 입구**가 함께 죽습니다(8/7 건의 1). 지시는 «그 문구» 하나였습니다 |
| CSS `display:none` 으로 감추기 | 죽은 코드가 남고 JS 는 계속 DOM 을 만듭니다. 다음 사람이 「왜 안 보이지」로 헤맵니다 |
| 8초 → 30초로 늘리기 | 빈도만 줄고 **여전히 침묵에 뜹니다.** 30초 침묵도 수업에선 흔합니다 |
| 「한 번이라도 말한 적이 있어야 dead」로 조건 바꾸기 | 처음부터 무음인 **진짜 마이크 고장**을 못 잡게 됩니다. 그리고 한 번 말한 뒤의 침묵에는 그대로 뜹니다 |

## 4. 하니스 — 옛 단정을 새 경계로 옮겨 적었습니다

`test-harness/teacher_kaye_feedback_260807_harness.mjs` 가 **그 문구를 글자 그대로 못 박고** 있었습니다.

```js
check('경고 문구가 한/영', /No sound coming in/.test(html) && /소리가 안 들어와요/.test(html));
```

이건 «검사가 헛돈 것» 이 아니라 **그 검사가 지키던 전제를 사람이 바꾼 것**이라, 그냥 느슨하게 풀지 않고
**새 경계로 옮겨 적었습니다**(CLAUDE.md 2장 「기준이 바뀌었을 때」).

이제 **글자가 아니라 `vcMarkNoSound` 를 오려 내 가짜 DOM 으로 실제로 돌립니다.**

- 「학생·관찰자에게는 안 그린다」
- **「그래도 강사에게는 그린다」(짝)** — 이게 없으면 «전부 끄기» 도 통과합니다
- 강사 배지 문구는 한/영 두 벌 · 누를 수 있는 버튼이다
- uid 를 못 구하면 아무에게도 안 그린다
- 「잘라 냈다」 **전제 검사** — 못 자르면 아래가 빈 문자열을 보고 조용히 통과합니다
- 부정 검사(옛 문구가 안 남았다)는 **주석을 벗겨 낸 사본**으로 판정
