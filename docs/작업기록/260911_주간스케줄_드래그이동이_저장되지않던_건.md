# 주간 스케줄 «드래그 이동» 이 서버에 저장되지 않던 건 (2026-09-11)

> 사장님 「분명히 마이마이와 2시20분 수업을 예약했는데 왜 강선생님이 뜨지?」
> → 「이렇게 이동시켰어. 강선생님에서 Mai로」 → 「15시로 다시 바꿨어」

---

## 1. 무엇이 일어났나

홈 화면 「수업 입장」 카드가 **「오후 02:20 · 강사 중국어 강선생님」** 을 가리켰습니다.
사장님은 관리자 **「주간 전체 스케줄」**(`admin/weekly-schedule.html`)에서 그 수업을
**강선생님 → MAIMAI** 로 드래그해 옮기신 뒤였습니다.

**홈이 맞고 스케줄 화면이 거짓말을 하고 있었습니다.**

`confirmMoveDo()` 가 하는 일이 전부였습니다.

```js
delete SLOTS[slotKey(...)];        // 브라우저 메모리에서 지우고
addSlot(ctx.dstTeacher.id, ...);   // 메모리에 다시 넣고   ← addSlot = SLOTS[key]=s 한 줄
showDndToast('✅ 강선생님 → MAIMAI … 이동됨');
render();
```

**`fetch` 가 한 줄도 없습니다.** 이 화면의 요청 목록에도 등록(POST)·삭제(DELETE)·
휴가·자리표시 정리만 있고 **«이동» 을 저장하는 PATCH 가 아예 없었습니다.**
게다가 확인 모달은 누르기 전에 「⚡ 담당 교사도 함께 변경됩니다」라고 **약속**까지 합니다.

| `class_schedules` 2332 (오늘 14:20) | `teacher_id='29'` = **중국어 강선생님**, `source='adm-enroll:103'` |
| 신청서 `enrollments` 103 | `teacher_name='중국어 강선생님'` (14:14:03 접수 → 14:14:05 확정) |
| MAIMAI(id 27)로 된 활성 예약 | **저장소 전체 0건** (옛 레벨테스트 3건은 전부 `cancelled`) |

⟹ **이름이 바뀐 사고가 아닙니다.** 서버에 도착한 값 자체가 처음부터 강선생님이었고
드래그는 그것을 한 글자도 바꾸지 못했습니다. (CLAUDE.md 2장 「남의 이름이 뜸」과
뿌리가 다릅니다 — 그쪽은 «강사 번호가 세 벌», 이쪽은 «저장이 안 됨».)

## 3. 고친 것

### 화면 (`cloudflare-deploy/public/admin/weekly-schedule.html`)

- `PATCH /api/admin/class-schedules/:id` 를 **실제로** 보냅니다.
- **저장 성공 뒤에만** 화면을 옮깁니다. 실패하면 사유를 말하고 `reloadAndRender()` 로
  서버에서 다시 읽습니다 — 부분 성공일 수 있어 손으로 옮기지 않습니다.
- 판정은 **«성공이라고 말했는가»**(`r.ok && d.ok===true`). 종단 404 본문에는 `ok` 칸이
  아예 없어 `d.ok===false` 로는 `undefined===false` 가 거짓이라 그냥 통과합니다.
- **그룹 수업**은 서버에 «학생마다 한 행» 이라 슬롯이 `ids` 배열을 들고 전부 보냅니다.
  하나만 옮기면 수업이 쪼개지는데 **화면은 한 칸이라 그 사고가 눈에 보이지도 않습니다.**
- **반복은 `day_of_week`, 일회성은 `scheduled_date`.** 섞으면 `sessions/today` 가
  날짜를 우선하므로 반복 행에 날짜가 붙으면 **«매주» 가 죽습니다.**
- 요일은 **UTC 로 파싱**합니다 — 로컬 시간대에 하루가 밀리면 「월요일로 옮겼는데 일요일」.
- 근무불가 차단(`type==='blocked'`)은 다른 표(`teacher_unavailability`)라 사실대로 거절합니다.
- 이제 진짜로 저장되므로 확인 모달이 **「🔁 매주 반복 — 모든 주가 함께 바뀝니다」를
  누르기 전에** 말합니다.

### 서버 (`cloudflare-deploy/src/api-admin.ts`)

- PATCH 가 **`teacher_id` 를 아예 안 받고 있었습니다**(요일·시각·길이·날짜뿐).
  화면만 고쳐서는 강사가 영영 안 바뀝니다.
- 급여가 걸린 조작이라 그 필드에만 게이트를 뒀습니다:
  **강사 거절 → `admin_scope.scope_type` 재조회(못 읽으면 막는 쪽으로 실패)
  → `isOrgScopedRole` → 실재하지 않는 강사 번호 거절.**
- ⛔ **`canEditOrg()` 는 쓰지 않았습니다** — scope `'none'`(내부직원·**교사**)에 true 라
  강사를 못 막습니다(CLAUDE.md 2장).
- 이 PATCH 는 `TEACHER_BLOCKED_PREFIXES` 에 없어 **강사도 부를 수 있습니다.** 그래서
  강사가 남의 수업을 자기에게 가져오거나 남에게 떠넘길 수 있었습니다.
- `teacher_id` 가 **실제로 바뀔 때만** 게이트를 타므로 **기존 시각 이동 권한은 한 톨도
  안 좁혔습니다.**
- 감사 이력(`class_audit_log`)에 강사 변경을 남깁니다 — 안 남기면 급여가 걸린 변경이
  아무 데도 안 남습니다.

## 5-2. 🔴 함정 대조(trap-check)가 잡은 것 — 첫 판은 **새 사고를 만들 뻔했습니다**

### ① 반복 수업의 «매주» 를 죽일 뻔했습니다 (치명)

첫 판은 `slot.recurring` 으로 반복/일회성을 갈랐습니다. 그런데 **그 칸은 진짜 수업에
실리지 않습니다** — `/api/admin/schedules` 의 `base` 객체에 없고, `recurring` 을 싣는 곳은
`teacher_unavailability` 쪽 두 줄뿐입니다(그 블록은 드래그가 이미 막습니다).

⟹ **진짜 수업은 예외 없이 `recurring === false`** → 언제나 `scheduled_date` 를 보냅니다.
`sessions/today` 는 `if (s.scheduled_date) … else if (day_of_week) …` 라 **날짜가 이기므로**
반복 행에 날짜가 박히면 **그 하루만 열리고 나머지 주는 「오늘 예약된 수업이 없어요」 →
공용방 폴백**입니다. PATCH 에는 그 칸을 **비우는 길이 없어** 화면으로 되돌릴 수도 없습니다.

✅ 고침: **«어느 칸을 고치는가» 를 서버가 내려줍니다**(`move_field`). 화면이 판정을
복제하면 서버의 `kind === 'one_off' || r.scheduled_date` 와 한 글자만 어긋나도 조용히
틀린 칸을 고칩니다. **모르면 넘겨짚지 않고 안 옮깁니다.**
서버 PATCH 에도 2차 방어(`moveFieldConflict`)를 뒀습니다.

### ② 같은 일을 하는 입구가 «셋» 이었습니다

- `confirmMoveDo` (드래그) ← 첫 판이 고친 것
- **`rscConfirm`** (우클릭 → 「수업 연기/변경」 — **담당 강사 탭 포함**)
- `confirmMove` (「이동」 모달)

**셋 다** 저장 없이 「✅ 👨‍🏫 담당 강사 변경: MAIMAI」·`alert('시간이 변경되었습니다')` 를
띄우고 있었습니다. 한 곳만 고치면 **다음에 우클릭으로 옮기는 순간 사고가 그대로
재현됩니다.** → 저장을 **`persistSlotMove` 한 곳**으로 모았습니다.

### ③ 감사 이력을 요청 본문으로 위조할 수 있었습니다

상태를 `(body as any).__teacher_to_name` 에 끼워 넘겼는데 `body` 는 `request.json()` 입니다.
클라이언트가 그 칸을 그대로 보내면 강사 변경이 없어도 `class_audit_log` 에
`· 담당 강사 29 → 아무개` 가 남습니다. **이 PATCH 는 강사도 부를 수 있어** 급여 근거
기록이 오염됩니다. → 지역 변수로 바꿨습니다.

### ④ 행을 못 읽으면 카페24 미러 도장이 조용히 빠졌습니다

`_pchRow` 가 `.catch(() => null)` 이라, D1 이 한 번 흔들리면 「사람 손이 이긴다」 도장
(`source='c24-mirror:manual'`)이 빠진 채 UPDATE 만 나갑니다. 미러 UPDATE 는 `teacher_id` 를
통째로 되돌리므로 **「옮겼는데 밤에 되돌아감」이 급여까지 끌고 갑니다.**
→ 담당 강사 변경은 **행을 못 읽으면 거절**합니다(요일·시각만 옮기는 요청은 예전대로).

### ⑤ 하니스가 네 번 헛돌았습니다

| 헛돈 방식 | 고침 |
|---|---|
| 부정 검사가 **제가 적은 ⛔ 주석**을 잡음 | 주석을 벗겨 낸 사본으로 판정 + 「주석 제거가 이상하면 FAIL」 전제 |
