# 주간 스케줄 «일간 뷰» 구분선 — 격자 + 줄무늬 (2026-09-11)

**한 줄**: 교사 25행이 한 덩어리로 보이던 일간 뷰에 가로 실선 · 정시 세로선 · 행 줄무늬를 넣었습니다.
사장님이 시안 4종 중 **B(격자) + C(줄무늬)** 를 고르셨습니다.

- 화면: 관리자 › 📅 주간 전체 스케줄 → 요일 머리 클릭(일간 뷰)
- 파일: `cloudflare-deploy/public/admin/weekly-schedule.html` **한 개**(CSS 5줄 + 변수 3개 + 클래스 1개 + 주석)

---

## 1. 왜 했나

사장님 제보 — 「얇은 실선이 필요할 것 같아, 잘 구분이 되지 않아」(스크린샷에 빨간 원으로 중앙부 표시).

**선이 «없던» 게 아니라 «안 보이던» 것이었습니다.**

| 잰 것 | 값 |
|---|---|
| 그리드 선 색 | `--bd: #E9ECEF` |
| 셀 배경 | 흰색 |
| 둘의 대비 | **1.05 : 1** (사실상 같은 색) |

여기에 두 가지가 겹쳤습니다.

- 수업 칸에 배경색이 없습니다 — ivory 테마에 있는 것은 `.slot-1on1`·`.slot-group`·`.slot-temp` 뿐인데
  일간 뷰가 쓰는 `s.type` 은 대개 `regular` 라 **글자만 공중에 뜬** 상태였습니다.
- 행 높이 27px × 교사 25명 × 10분 칸 84개 — 눈이 가로줄을 따라갈 근거가 하나도 없었습니다.

## 2. 무엇을 했나

```css
/* :root — 반투명 «한 벌» */
--grid-line:rgba(15,23,42,.20);   /* 행 가로선 */
--grid-hour:rgba(15,23,42,.34);   /* 정시 세로선 */
--stripe:rgba(15,23,42,.045);     /* 짝수 행 줄무늬 */

.dgv td.slot{border-right-color:transparent;border-bottom:1px solid var(--grid-line)}
.dgv td.slot.dg-hour-edge{border-left:1px solid var(--grid-hour)}
.dgv .tl-td-name{border-bottom:1px solid var(--grid-line)}
.dgv tbody tr:nth-child(even){background:var(--stripe)}
.dgv tbody tr:nth-child(even) .tl-td-name{box-shadow:inset 0 0 0 100vh var(--stripe)}
```

그리고 일간 뷰 컨테이너를 `<div class="tl-scroll dgv">` 로 바꿨습니다.

> ℹ️ `.dgv` 는 **주석에만 있고 어디에도 안 붙어 있던 클래스**였습니다(「주간 뷰(.tlv) / 일간 뷰(.dgv)」).
> 이번에 일간 쪽에 실제로 붙여 주석을 사실로 만들었습니다. 주간 뷰(`.tl-scroll`)는 건드리지 않았습니다 —
> 거기는 요일 7칸이라 원래 잘 읽히고, 사장님 지적도 일간 뷰였습니다.

## 3. 검토했다가 버린 방법

### (가) 시안 A(가로선만) · C(줄무늬만) · D(격자 + 수업 칸 알약)
4종을 같은 데이터·같은 행 높이로 그려 비교 이미지와 전환 HTML 로 보여 드렸고 사장님이 **B+C** 를 고르셨습니다.
D(알약)는 수업이 덩어리로 잘 보이지만 화면이 알록달록해집니다.

### (나) 10분 칸마다 세로선 — ⛔ 버림
한 시간이 6칸이라 세로선이 **84줄**이 됩니다. 구분이 아니라 방해가 됩니다. 정시(:00)에만 뒀습니다.

### (다) 줄무늬를 `td` 에 칠하기 — ⛔ 버림
`.dgv tbody tr:nth-child(even) td.slot` (0,3,3)이 `.tl-scroll td.slot.col-today` (0,3,1)을 특이성으로 이겨
**짝수 행에서 «오늘 열» 강조가 사라집니다.** `tr` 에 칠하면 셀의 반투명 앰버가 그 위에 겹쳐 둘 다 삽니다.

### (라) 테마별 «불투명» 색 두 벌 — ⛔ 실제로 만들었다가 되돌림
처음엔 규칙서대로 ivory/다크 짝을 만들었습니다(`#F4F6F8` / `#171D2E`). 그런데 렌더해 보니:

```
DARK :  홀수 행 rgb(230,236,244)  ← 밝음(페인터가 칠함)
        짝수 행 rgb(23,29,46)     ← 내 다크 값
        대비 14.12               ← 얼룩말이 아니라 «검은 줄»
```

**이 페이지는 테마가 `dark` 여도 `adm-light-surfaces.js` 페인터가 화면을 밝게 칠해 두는 모순 상태**입니다.
거기에 «다크용 어두운 색» 을 주면 그 행만 검게 남습니다. 그래서 «지금 화면이 무슨 색이든 그보다 조금 어둡게» 인
**반투명 한 벌**로 바꿨습니다. 덤으로 테마 두 곳을 짝으로 관리할 짐도 사라졌습니다.

### (마) 페인터 `SKIP_SEL` 에 등재 — ⛔ 만들었다가 되돌림
등재하면 `js/adm-light-surfaces.js` 와 그것을 부르는 **HTML 18개의 `?v=`** 까지 건드려야 하고,
검사가 `el.closest(SKIP_SEL)` 이라 «tr 만» 적어도 **그 행의 셀까지 글자 구제가 꺼집니다.**
페인터 코드를 읽어 보니 **알파 0.35 이하는 애초에 건드리지 않습니다**(119행) — 반투명(0.045)이면 등재가 필요 없습니다.
→ 페인터 파일과 `?v=` 18곳을 전부 되돌렸고, 최종 변경 파일은 **1개**입니다.

### (바) 이름칸 줄무늬를 `background-image` 로 — ⛔ 버림
이름칸은 sticky 라 **불투명**해야 해서(반투명이면 스크롤 때 셀이 비칩니다) 배경색 위에 얹어야 하는데,
페인터는 `backgroundImage` 의 **알파를 안 보고 색 휘도만** 봅니다(127~139행) → `rgba(15,23,42,.045)` 를
«어두운 면» 으로 읽어 밝게 덮습니다. `box-shadow: inset` 은 배경을 바꿀 때만 건드리므로 안전합니다.

## 4. 확인한 방법

로컬 서버 + 헤드리스 크로미움으로 **실제 파일**(`?demo=1`)을 그려서 쟀습니다.

🔴 **`getComputedStyle` 로는 못 쟀습니다** — 줄무늬·선이 반투명이라 합성 결과가 화면에만 있습니다.
처음엔 그걸 모르고 재서 「줄무늬 대비 **1.00**(안 보임)」이라는 **거짓 실패**를 얻었습니다.
CLAUDE.md 가 일러둔 대로 **스크린샷 픽셀을 직접 읽어**(`node:zlib` 로 PNG 해제) 다시 쟀습니다.

| 자리 | 고치기 전 | 지금 |
|---|---|---|
| 행 가로선 | 1.05 (안 보임) | **1.52** |
| 정시 세로선 | — | **2.14** |
| 줄무늬(셀) | — | **1.08** |
| 줄무늬(이름칸) | — | **1.09** ← 셀과 이어짐 |

- ⚠️ 이 페이지는 `zoom` 이 걸려 있어 1px 테두리가 정수 좌표와 어긋납니다 — 한 점만 찍으면
  안티앨리어싱된 가장자리를 재서 **1.08** 로 나옵니다(실제 1.52). 주변 ±2px 을 훑어 가장 어두운 픽셀로 판정했습니다.
- **ivory·dark 두 테마에서 픽셀이 동일**합니다 → (라)의 «검은 줄» 사고가 사라진 것을 확인.
- 「오늘 열」 강조가 짝수 행에서도 살아 있습니다(`rgba(251,191,36,0.07)`).
- 이 파일을 읽는 하니스 **8개**를 `origin/main` 기준선과 대조 → **새 FAIL 0건**.
  (⚠️ 남은 2건은 기준선에도 있습니다. 하나는 `node_modules` 없음이라 환경 사유이고,
  다른 하나는 **제가 세는 방식이 헛돈 것** — 요약줄의 「❌ 0 실패」를 FAIL 로 셌습니다. 실제로는 109/109 통과입니다.)

## 5. 곁가지로 찾은 것 — 아직 안 고침 (사람이 정할 일)

**아바타 동그라미 색이 페인터에 지워지고 있습니다.** 제 변경과 무관한 기존 현상입니다.

```
페인터 켜짐 : native rgb(246,244,251) / home rgb(244,251,248)   ← 인라인 !important, 거의 흰색
페인터 꺼짐 : native rgb(139,92,246)  / home rgb(16,185,129)    ← 원래 색
실측 11개 중 8개가 «흰색처럼»
```

그 색은 **홈/오피스/네이티브/매니저 구분 정보**(`.tl-ava.home` 등)인데 화면에서 사라집니다.
고치려면 `adm-light-surfaces.js` 의 `SKIP_SEL` 에 `.tl-ava` 한 줄이면 되지만,
그 파일과 `?v=` 18곳을 건드리는 별건이라 **사장님 판단을 기다립니다.**

📄 판별법: `/admin/weekly-schedule.html?demo=1&nolight=1` 로 열면 페인터가 꺼져 원래 색이 보입니다.
