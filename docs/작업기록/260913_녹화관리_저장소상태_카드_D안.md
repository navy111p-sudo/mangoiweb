# 녹화 관리 — 「저장소 상태」 카드를 D안(주의 우선 배치 + 구역 탭)으로 키움

- 날짜: 2026-09-13
- 지시: 사장님 「너무 작아서 좀 크게 만들어줘」 → 「대시보드 카드들을 잘 보이고 디자인 좋게 4가지 샘플로」
  → 샘플 4종(아티팩트) 중 **「D로 적용해줘」**
- 화면: 관리자 › 수업·콘텐츠 › 녹화(`#card-recording-storage`, `admin.html`)

## 1. 왜 했나 — 글자가 «작게 박혀» 있었다

카드 자체가 아니라 **글자 크기**가 문제였습니다. `css/admin-inline-c.css` 의 `.rs-kpi` 규칙이
라벨 **11px** · 숫자 **20px** 이고, 녹화 카드 안에서는 폰 규칙이 **10.5px / 18px** 로 한 번 더
줄였습니다. 「📊 저장소 상태」·「🎬 영상 목록」 머리글도 **11.5px** 였습니다. 사장님 화면(PC,
zoom 1.3)에서도 «찾기 어렵다» 가 나올 크기입니다.

## 2. 검토했다가 버린 것 (샘플 4안)

| 안 | 무엇 | 왜 안 골랐나 |
|---|---|---|
| A 큰 숫자 + 왼쪽 상태 줄 | 배치 그대로, 글자만 키움 | 반경은 제일 작지만 «봐야 할 것» 이 다른 칸과 같은 무게 |
| B 큰 아이콘 + 비율 막대 | 완료율·실패율 막대 | 막대가 «전체 대비» 를 말하는데 사장님이 찾는 것은 «실패가 있나» 하나 |
| C 어두운 한 줄 스트립 | 44px 숫자 넷 + 빨간 경고 띠 | 관리자 화면은 ivory 고정이라 어두운 면 하나가 튐 |
| **D 주의 우선 + 탭 머리글** | 「저장 실패」 맨 앞·빨강, 구역 탭 | ✅ 사장님 선택 |

또 버린 것:
- **감추는 탭**(구역을 `display:none`) — 사이드바 손자(`data-gc`) 점프가 숨은 상자로 가서 «아무 일도
  안 일어난다»(CLAUDE.md 2장). 그래서 탭은 **그 구역으로 내려가는 링크**이고 세 구역이 전부 보입니다.
- **R2 값을 «28.1 + GB» 두 칸으로 나누기** — 브라우저 하니스가 `#rs-r2-size` 의 글자를 `'3.5 GB'` 로
  그대로 읽습니다. id 8개와 JS 가 쓰는 글자는 손대지 않고 감쌌습니다.
- **페인터 3종(`adm-s12`·`adm-s13`·`adm-light-surfaces`) SKIP 등재** — 빨강 `#b91c1c` 위 `#fee2e2` 는
  대비 5.9 라 셋 다 안 건드립니다(s12 는 밝은 글자만, s13/light-surfaces 는 대비 <3·<4.5 만).
  등재하면 JS 3벌 + HTML 18곳 `?v=` 가 걸립니다.
- **인라인 `color`** — `[id^="card-"] :is(…){color:#101828!important}` 에 눌립니다(옛 코드의
  `fv.style.color='#b91c1c'` 가 정확히 그 상태였습니다). 색은 CSS 꼬리 블록 + 클래스(`.rs-attn`/`.rs-ok`).
- **「전체」 칩을 무조건 누르기** — 그 칩은 **토글**(열림이면 닫음)이라 목록이 닫혀 있을 때만 누릅니다.

  hover `translateY` 제거(1-3). 꼬리 블록 `#card-recording-storage …` 로 색·탭·버튼(전역 인디고 알약
  !important 를 id 접두로 되살림, `[hidden]` 은 `display:none!important`). PC 는 zoom 1.3 이라
  **1500px 미만은 2×2**(4 across 는 「28.1 GB」가 두 줄로 꺾였습니다 — 실측).
