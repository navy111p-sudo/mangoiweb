- `<style>` 블록 교체: 바탕 `#fff7e0`, 흰 카드 + 노란 테두리·밑그림자(`box-shadow:0 4px 0`), 헤더는 망고 그라데이션 띠

- **색은 `:root` 토큰 `--pd-*` 한 곳** — 본문·JS 렌더의 인라인 `style` 에 있던 hex/rgba 를 스크립트로 전부 `var(--pd-…)` 로 치환(다음에 톤 바꿀 때 한 곳만)
  - 예외로 남긴 hex: 버튼 그라데이션 위 진한 글자·카카오 브랜드색·공용 바(`mango-i18n.js`)·우하단 오디오 토스트(떠 있는 다크 상자)

- 폰: 우상단 공용 바(🔊·홈·EN) 아래로 제목이 오게 `.wrap{padding-top:60px}`
- 배경 사진 `home-bg-dark.webp` preload 제거(B 는 사진 배경을 안 씀)

**안 바꾼 것**: 기능·`id`·`data-ko/data-en`·API 호출·로그인 흐름. `diff` 로 `id=`·`function`·`onclick`·`data-ko` 집합이 main 과 동일함을 함정 대조가 확인.

## 4. 검토했다가 버린 것
- **Google Fonts(Jua) 로 제목 글꼴** — 시안 B 에는 썼지만 실제 화면에는 안 넣음. 중국 회선(강선생님·학생)에서 구글이 막히고, 한자 폰트 규칙(`font-family` 맨 앞 `MangoiHanSC`)과도 충돌. 굵기 900 으로 대신.
- **인라인 색을 CSS 클래스로 전부 옮기기** — 렌더 문자열이 30곳 넘고 diff 가 커져 되돌리기 어려움. 토큰 치환으로 «한 곳» 원칙은 지키면서 구조는 그대로 둠.
- **`#fbbf24` 를 글자색으로 유지** — 흰 바탕 대비 1.67 이라 못 씀(CLAUDE.md 2장). 글자는 `#b45309`, 채움은 `#d97706`.
- **미획득 배지를 `opacity:.35`(옛값)/`.6` 으로** — 타일 전체를 흐리면 글자 대비가 2.3 으로 떨어짐(함정 대조 지적) → 아이콘만 흑백·흐림, 글자는 muted 그대로.
