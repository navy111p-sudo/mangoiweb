# 2026-09-14 — 「마이 페이지」(parent.html) 학생·학부모 공용 문구로 중립화

## 1. 왜

사장님 제보(캡처): `mangoi.ai/parent.html` 을 열면 맨 위는 「마이 페이지 (My Page)」인데 바로 아래 배지가
「👨‍👩‍👧 학부모 전용 화면」, 제목이 「자녀의 학습 한눈에 보기」, 입력 라벨이 「자녀의 학생 ID」였다.
「학생·학부모 페이지인데 왜 학부모 전용으로 나오지?」 → 「고학년 학생과 성인에게는 맞지 않는다」.

### 원인 — 이름표가 두 벌인 한 페이지
- `parent.html` 은 처음부터 «학부모가 자녀를 본다» 전제로 쓰였다 — `<title>학부모 대시보드`, 카카오 공유 문구,
  안내 음성(`/audio/학부모대시보드.wav`), 입력 라벨, 비밀번호 설명, 배지 카드 제목(「자녀의 배지」),
  전환 버튼(「다른 자녀 조회」), 가정 안내 TIP(「자녀에게 …를 권해주세요」)까지 전부. 역할로 문구를 가르는 코드는 0줄.
- 그런데 홈은 같은 주소를 **「👤 마이페이지」** 로도 쓴다 — `index.html`·`js/mg-sidebar.js` 의 `mypage → /parent.html`,
  전체메뉴(`js/idx-allmenu.js`)에는 「마이페이지」·「학부모 페이지」 타일이 **둘 다 같은 주소**, AI 홈 검색도 둘 다.
  학생이 로그인한 채 「마이페이지」를 누르면 `openParentDashboard()` 가 **학생 본인 아이디**로 이 페이지에 보낸다.
- 그래서 학생이 들어와도 화면 본문이 «자녀» 를 말했다. 브랜드 줄만 「마이 페이지」였고(9/10 이전부터), 9/14 새벽의
  «망고 카드» 디자인 교체(#954)도 문구는 그대로 옮겼다. **고장이 아니라 한 화면이 두 말을 하던 것.**

## 2. 결정 (사장님, 2026-09-14)
세 가지 중 **1번 — 학생·학부모 공용 「마이 페이지」로 통일.** «자녀» 를 빼고 중립으로.
(2번 «학부모 전용으로 두고 홈 이름만 정리» 는 학생용 «내 정보» 화면이 따로 없어 학생이 갈 곳이 사라지고,
3번 «로그인 역할로 문구 가르기» 는 학생 세션이 없는 성인·고학년(홈 통합 로그인 → 관리자 폴백 등)에서 여전히 «자녀» 가 뜬다.)
