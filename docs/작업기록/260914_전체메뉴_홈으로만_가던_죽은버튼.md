# 「전체메뉴」가 눌러도 홈으로만 가던 것 — 주소를 내 주어 수리 (2026-09-14)

## 1. 무엇이 일어났나

사장님 제보 — **「이거 왜 전체 메뉴 누르면 홈화면으로만 가? 전체메뉴는 안보여」**
(스크린샷: 공용 왼쪽 사이드바 「기타」 묶음의 **🏠 전체메뉴 ★★★**).

에러도 경고도 없었습니다. 누르면 홈으로 «가기는» 하고, 그 자리에서 끝났습니다.

## 2. 왜 그랬나 — 코드 한 줄

왼쪽 메뉴는 이 저장소에서 **정본이 둘**입니다.

| | 어디 | 어떻게 움직이나 |
|---|---|---|
| ① | 홈 `index.html` 안의 `#mg-drawer` | `mgGo(x)` = **홈 안의 카드 버튼을 대신 클릭** |
| ② | 그 밖 25개 화면 `js/mg-sidebar.js` | `mgGo(x)` = **`location.href = URLS[x]`(주소 이동뿐)** |

「전체메뉴」는 홈에서만 도는 **함수**(`window.openAllMenuOverlay()`)라 ②에 줄 주소가
없었습니다. 그래서 주소표에 이렇게 적혀 있었습니다 — `js/mg-sidebar.js`:

```js
'about':'/', 'all-menu':'/', 'home':'/',
```

②는 주소로만 옮겨 갈 수 있으니 **홈에 도착하는 것이 전부**였고, 도착한 뒤 오버레이를
열어 주는 사람이 아무도 없었습니다. CLAUDE.md 2장이 이미 못 박아 둔 함정
(「⛔ 주소 없이 목록에 넣지 마세요 — `mgGo` 가 `URLS[go] || '/'` 라 «보이는데 눌러도
홈으로 가는» 버튼이 됩니다」)의 **변종**입니다. 주소가 «없는» 것이 아니라 «홈» 이었습니다.

## 3. 검사 셋이 나란히 초록불이었다

`sidebar_menu_parity_harness`(2026-09-13 신설)가 이 항목을 세 절에서 지나쳤습니다.

| 절 | 무엇을 물었나 | 왜 통과했나 |
|---|---|---|
| ① | 홈과 공용이 같은 주소인가 | **양쪽 다 `/`** 라 «일치» |
| ③ | 갈 곳 없는 버튼이 없는가 | `URLS['all-menu']` 가 `'/'` = **truthy** |
| ④ | 옮길 주소가 없는 메뉴 (사람 결정 대기) | 「갈 곳이 있다」며 **건너뜀** |

⟹ **«도착지가 홈» 은 세 절 어느 쪽도 볼 수 없는 세 번째 결함 종류**였습니다.

## 4. 고친 것

| 파일 | 무엇을 | 금지구역 |
|---|---|---|
| `js/idx-allmenu.js` (defer) | `?menu=all-menu` 를 받는 절 추가 | 아님 |
| `js/mg-sidebar.js` | `'all-menu':'/'` → `'/?menu=all-menu'` | 아님 |
| `index.html` | `idx-allmenu.js?v=13` → `?v=14` | 🚫 **사장님 승인 뒤** |

- 주소 방식은 이 저장소가 이미 쓰던 것입니다 — `?menu=leveltest`(`idx-grid-menu.js`) ·
  `?menu=remote`(`idx-remote-support.js`) · `?menu=aitools`(`index.html`).
- 받는 절은 **`menu` 만** 지웁니다. `pathname` 으로 통째로 갈아치우면 `index.html` 이
  수업으로 되돌아올 때 쓰는 `?room=` 과 다른 쿼리·해시까지 조용히 잃습니다.
- **defer 라 기다리는 타이머가 없습니다** — 상주 `setInterval`·body class
  `MutationObserver` 는 홈을 통째로 멎게 한 전력이 있어 쓰지 않았습니다.
- `?v=` 는 `13` → `14` 로 **글자 수가 같아 첫 화면 예산에 0바이트**입니다
  (실측 1,060,176 → 1,060,176). 안 올리면 `asset_version_harness` 가 CI 를 빨간불로
  만들고, 이미 홈을 연 사람은 옛 파일을 immutable 캐시에 최대 1년 붙들고 있습니다.

## 5. 검토했다가 버린 길

| 안 | 왜 안 했나 |
|---|---|
| **공용 사이드바에서 「전체메뉴」 줄을 빼기** | 기능을 «없애는» 쪽입니다. 25개 화면에서 전체메뉴로 가는 길이 통째로 사라집니다 |
| **`mg-sidebar.js` 가 `openAllMenuOverlay` 를 «직접» 부르기** | 그 함수는 `js/idx-allmenu.js` 안에 있고 그 파일은 **홈 밖 화면에 실리지 않습니다**. 25개 화면에 새로 실으면 화면마다 40KB 배경·별 필드가 따라붙습니다 |
| **`index.html` 의 `?menu=` 핸들러에 한 갈래 더 넣기** | 그 스크립트는 **blocking** 이라 첫 화면 예산(여유 9바이트)을 그 자리에서 넘깁니다. 실제 코드는 전부 defer 파일에 들어가야 합니다 |
| **`js/inapp-escape.js`·`js/session-guard.js` 에 얹기** | 홈이 버전 없이 싣는 파일이라 `?v=` 를 안 올려도 되지만, 「인앱 탈출」·「세션 지킴이」와 무관한 코드가 섞여 스파게티가 됩니다 |

## 6. 남은 것 — 「망고아이란?」도 같은 모양입니다 (사람이 정할 일)

`'about':'/'` 도 **똑같은 결함**입니다. 홈에서는 퀵버튼이 `openAboutMangoi()` 를 여는데,
공용에서는 홈으로 «가기만» 하고 그 모달은 안 열립니다.

- 고치는 값은 같습니다 — `js/idx-about.js`(defer)에 `?menu=about` 절 + `index.html` 의
  `idx-about.js?v=8` → `?v=9`(역시 **0바이트**) + 주소표 한 줄.
- 이번 지시(「전체메뉴」)의 범위 밖이고 `index.html` 은 공동 금지구역이라 **손대지
  않았습니다.** 하니스 ⑤절이 이름을 찍어 출력하므로 잊히지 않습니다.

## 7. 다시 안 나게 못 박은 것

### 자동 — `test-harness/sidebar_menu_parity_harness.mjs`

- **⑤절** 「공용 주소가 `/` 뿐인 항목」 = 죽은 버튼 → **FAIL**.
  `HOME_ONLY_ALLOW` 에 이름과 «왜 아직 그대로인가» 를 적은 것만 넘어갑니다(지금 `about` 하나).
- **⑥절** ⑤의 뒷면 — `?menu=X` 로 **보내 놓고 받는 절이 없는** 경우를 잡습니다.
  받는 절만 지우면 ③·⑤는 「갈 곳이 있다」며 그대로 통과하기 때문입니다(짝).
