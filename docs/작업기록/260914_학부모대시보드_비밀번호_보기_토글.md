# 2026-09-14 학부모 대시보드 — 비밀번호 «보기/가리기» 토글

## 1. 왜 했나
- 2026-09-13 B(망고 카드) 디자인 병합 뒤 사장님 「**비번보기도 추가해줘**」.
- 학부모 로그인 2단계(`#pw-input`)는 폰에서 치는 경우가 대부분이라, 입력이 틀렸는지 확인할 길이 없었다(4자 이상 규칙 + 첫 설정 때는 두 번 확인 칸도 없음).

## 2. 무엇을 바꿨나 — `cloudflare-deploy/public/parent.html` 하나
| 자리 | 내용 |
|---|---|
| CSS | `.pw-wrap`(입력칸 감싸는 상자) · `.pw-eye`(입력칸 «안» 오른쪽 끝 알약 버튼, 높이 36px, 토큰 `--pd-tint`/`--pd-gold`/`--pd-line-strong`) |
| HTML | `#pw-input` 을 `.pw-wrap` 으로 감싸고 옆에 `<button id="pw-eye" type="button">` — 아이콘 `<span id="pw-eye-ico">👁</span>` + 글자 `<span id="pw-eye-txt" data-ko="보기" data-en="Show">` |
| JS | `pdSetPwVisible(show)` — `type` 만 `password`↔`text` 로 바꾸고 아이콘·글자·`data-ko/en`·aria·title·`aria-pressed` 를 함께 갱신. `pdTogglePw()` 가 버튼에 연결. `pdShowPwStep()` 끝에서 `pdSetPwVisible(false)` — 단계가 다시 열릴 때는 늘 가린 상태 |

- `autocomplete="current-password"` 도 함께 달았다(브라우저 자동완성 힌트 — 동작 변경 없음).
- 로그인 흐름(`pdPwGo`·Enter 제출·`/api/student/login`·`set-password`)은 한 줄도 안 건드렸다 — 바뀐 것은 입력칸의 `type` 뿐.

## 3. 검토했다가 버린 것
- **버튼 자체에 `data-ko`/`data-en`** — i18n 엔진이 `textContent` 를 통째로 갈아끼워 아이콘이 사라진다(CLAUDE.md 「아이콘 버튼에 달았더니」). 글자 span 에만 달고 버튼에는 `data-ko-title`/`data-en-title`·`data-ko-aria`/`data-en-aria`.
- **아이콘만 있는 동그란 버튼** — 폰에는 hover 가 없어 `title` 툴팁이 안 뜬다. 「보기/가리기」 글자를 함께 그린다.
- **체크박스(「비밀번호 표시」) 한 줄** — 이미 「30일 유지」 체크박스가 그 밑에 있어 체크박스 두 줄이 되면 뜻이 섞인다. 입력칸 안 버튼으로.
- **보임 상태를 기억해 두기** — 보안상 다음 방문·다음 단계에서는 늘 가린 채 시작하는 것이 맞다.
