# 홈 «내 수업» 카드 — 수업 한 건 = 한 줄 (샘플 A) — 2026-09-14

## 왜 했나
사장님 캡처: 홈 「수업 입장」 아래 알약이 「매주 화·수·목·금 오후 7:20 · 중국어 강선생님」이라고 말했는데,
실제로는 강사·시간이 다른 수업 여러 개가 잡혀 있었습니다.
`js/idx-my-schedule.js` 의 `__nccNoClassToday` 가 **모든 수업의 요일을 한 줄로 합치고**
시간·강사는 **`list[0]` 것 하나만** 붙이고 있었습니다 → «없는 수업» 을 말하는 카드.

## 무엇을 골랐나
디자인 캔버스로 4가지 샘플(A 세로 목록 · B 다음 수업+접기 · C 주간 띠 · D 강사별 카드)을 보여 드렸고,
사장님이 **A(세로 목록)** 를 고르셨습니다. 추천 근거: 한 건 = 한 줄이라 구조적으로 섞일 자리가 없고,
폰에서 한 번에 다 보이며, 수업이 늘어도 줄만 더 붙습니다.
- 검토했다가 버린 것: B 는 나머지 수업이 한 탭 더 필요 · C 는 같은 요일 2회 수업을 한 칸에 못 넣음 ·
  D 는 강사 4명 이상이면 칸이 좁아짐.

## 무엇을 바꿨나
- `cloudflare-deploy/public/js/idx-my-schedule.js` — `buildRows()`(순수 함수): 같은 «시각 + 강사» 의
  반복 수업만 한 줄로 합침(화 7:20 강선생님 + 목 7:20 강선생님 → 「화·목 7:20」), 그 외는 절대 안 합침.
  다음 수업이 가장 가까운 줄이 맨 위 + 앰버 강조 + 「다음 · 9/15」. 날짜를 못 구한 줄은 맨 아래.
  일회성(`scheduled_date`) 수업은 요일 칸에 날짜를 한 번만. 강사 이름은 DB 값이라 `esc()`.
  머리글 「📅 내 수업 · 매주 N회」 + 오른쪽 「강사 N명」(2명 이상일 때만). 스타일은 `#nms-style` 로 자체 주입
  (hover 확대 없음 — 1-3 규칙).
- `cloudflare-deploy/public/index.html` — 그 스크립트 `?v=1` → `?v=2` **한 글자**(공동 금지구역이지만
  `asset_version_harness` 가 요구. 첫 화면 예산 0바이트 — 1,060,176B 그대로).
- `test-harness/asset-versions.json` 원장 갱신.
- 서버(`/api/class/schedule/mine`)는 안 건드렸습니다 — 이미 수업마다 강사·시간·다음 날짜를 따로 내려줍니다.
