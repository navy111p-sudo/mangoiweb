## 3. 검토했다가 버린 것
- **화면(JS)에 CEFR 이름표·글자 배열을 적기** — 정본이 두 벌이 되면 어긋난다(CLAUDE.md 「같은 판정이 두 곳이면 한쪽만 고쳐진다」). 서버가 만들어 내려주고 화면은 그리기만.
- **C1 «고급» / C2 «최상급» 으로 이름 나누기** — 시안(아티팩트)에는 그렇게 적었지만, 저장소 정본(`bandFromCefr`)은 C1·C2 를 **둘 다 밴드 8 «최상급»** 으로 이어 놓았고 AI 영어친구 화면도 C1 을 «최상급» 으로 부른다. 새 이름을 지으면 화면마다 답이 달라진다 → 이름은 정본 그대로 두고 **게이지(5/6 대 6/6)로 갈리게** 했다. 나누려면 `AI_FRIEND_CEFR`·`BAND_SPECS` 를 함께 손보는 별건 — **사람이 정할 일**.
- **큰 글자에 `<small>C2</small>` 넣기(시안 모양)** — `put()` 이 `textContent` 로 쓰는 `[data-ko]` 요소라 HTML 을 못 넣고, 넣으려면 i18n 두 엔진과 싸운다. C2 는 아래 줄로.
- **게이지에 `data-ko`/`data-en`** — 두 엔진이 `textContent` 를 갈아끼워 자식(막대·라벨)이 사라진다. 게이지는 글자가 언어 중립(A1…C2)이라 달지 않았다.
- **`index.html` 에 CSS 추가** — 공동 금지구역 + 첫 화면 예산. defer 파일에서 `<style>` 주입.
