## 2. 잰 것 (운영 D1 실측)

### 2-1. SIU 업로드는 성공했다
`textbook_files` 에서 `[SIU BASIC%` 로 묶어 세니 **29권 · 438장 · 전부 active**(2026-09-15 19:11~19:18 업로드).
권별 파일 수를 전부 더하니 **438** — 업로더가 말한 숫자와 1장도 안 틀립니다.

### 2-2. 「두 덩어리」는 고장이 아니다
`js/idx-x3.js` 실측:
- `_serverFilesToBooks()` 가 **서버** 교재의 `publisher`·`textbook` 을 **대괄호 이름 그대로** 넣고,
  `_srvGuessCategory()` 가 이름에 `siu` 가 있으면 분류를 **"SIU"** 로 만듭니다 → `📁 SIU (29)`
- `classifyFile()`(업로더)은 **상위 폴더명**을 출판사로 써서 로컬(IndexedDB) 쪽은 `SIU BASIC (31)`

⟹ **같은 교재의 «내 PC 판»과 «서버 판»이 나란히 보이는 것**입니다. 다른 선생님에게 보이는 것은 서버 쪽 29권뿐.

### 2-3. 🔴 아직 남은 것

### 6-1. 검사가 헛돌던 것 — 함께 고침
1. **`bookIdOf is not defined`** 로 자동 하니스가 **9건 크래시** → 새 헬퍼를 소스에서 오려 내 주입
2. 브라우저 검사가 **「교재 버튼 33개」** 로 개수를 못 박아 거짓 FAIL → 「표에 있는 교재가 안 빠졌는가」로,
   기대값은 **소스에서 읽기** + 「표를 읽었다」 전제 검사
3. `no(...)` 는 브라우저 하니스에 없음 → **크래시**(결과줄조차 안 나옴) → `t(..., false)` 로
4. 「지금 교재 줄이 SIU 라고 말한다」를 **이름만으로** 물어 SIU 판정을 죽여도 통과(93/0) → **📗 표시**를 짝으로

### 6-2. 정정
- `String(a)===String(b)` 를 `===` 로 되돌리는 것은 **등가 변형**입니다(`bookIdOf` 가 이미 정규화).
  처음엔 「⛔ === 로 견주지 마세요」라는 **사실이 아닌 주석**을 코드에 적었다가 변이시험에서 드러나 고쳤습니다.
  「변이 N종 전부 FAIL」의 N 에 **넣지 않았습니다.**
