# 웜업 «연령·수준 다시 고르기» 를 찾기 쉽게 — 2번+3번 적용

**날짜** 2026-09-15 · **파일** `cloudflare-deploy/public/warmup.html` 한 개
**지시** 사장님 「PC에서 너무 밑에 있어서 잘 보이지 않고, 오른쪽 카드에서도 찾기가 힘들어.
이거 샘플4개로 해서 찾기 쉽고 보기쉽게 보여줘.」 → 시안 4종 제시 → 사장님 **「2번 + 3번」** 선택 → 「진행해」

## 1. 왜 했나 — 제보는 «안 보인다» 였지만, 재 보니 «화면 밖» 이었다

⋮ 설정 카드 높이가 **792px 로 고정**이라 카드 아래 끝이 **853px** 입니다. 브라우저 창 세로가
그보다 짧으면 맨 아래 「🎚️ 연령·수준 다시 고르기」가 잘려 나가는데, **카드에 스크롤이 없어
끌어내릴 수도 없었습니다.**

### [잰 것 — 2026-09-15, 진짜 Chromium 으로 좌표 측정]

| 화면 | 카드 아래 끝 | 「다시 고르기」 | 판정 |
|---|---|---|---|
| 1920×1080 | 853px | 792~834px | 보임 (여유 246px) |
| 1440×900 | 853px | 792~834px | 겨우 보임 (여유 66px) |
| **1280×800** | 853px | 792~834px | **화면 밖** — `elementFromPoint` 가 `null` |
| **1366×768** | 853px | 792~834px | **화면 밖** |

**중국어 선생님 칸(메이·룽)이 보이는 학생은 카드가 926px** 라 **1440×900 에서도 잘렸습니다.**

설정 화면의 파란 「이 설정으로 계속하기」는 `position:sticky` 라 **보이기는 했습니다**
(바닥에서 44px, `elementFromPoint` 로 맨 위인 것 확인). 그쪽은 «눈에 안 들어오는» 문제였습니다.

## 2. 무엇을 했나

### 2번 — 상단바에 🎚️ 지름길 (`#setupBtn`)
⋮ 를 열지 않고 **한 번에** 설정 화면으로 갑니다. 카드 길이·화면 크기와 무관해집니다.
노란색(`#fbbf24`)이라 다른 아이콘과 구분됩니다.

### 3번 — 카드 안쪽만 스크롤 + 버튼 바닥 고정
- `.menu-panel` 에 `display:flex; flex-direction:column` + `max-height:calc(100svh - 76px)`
- 설정 그룹들만 새 래퍼 `.menu-scroll`(`overflow-y:auto; min-height:0`) 안에서 구름
- `.menu-reopen` 은 그 «밖» 이라 **늘 카드 바닥에** 남고, 회색 → **파란 강조색**

### 덤 — 설정 화면 확정 버튼을 «띠»로
`.wus-ctabar` 가 sticky 로 바닥에 붙어 뒤 내용을 덮습니다(「여기서 끝」이라고 말해 줌).
그 아래 **「고른 것: 초급 · 초등 고·중」** 한 줄을 넣어 누르기 «전에» 무엇으로 시작하는지 보여줍니다.

## 3. 검토했다가 버린 것

### 「2번만 하면 되지 않나」 — 재 보니 모자랍니다
2번을 하면 카드에서 그 줄을 빼게 되어 56px 짧아집니다. 그것만으로 충분한지 쟀습니다.

| 화면 | 2번만 했을 때 | 중국어 학생일 때 |
|---|---|---|
| 1440×900 | 여유 103px | **−26px 잘림** |
| 1280×800 | 여유 **3px** | **−126px 잘림** |
| **1366×768** | **−29px 잘림** | −158px 잘림 |

1366×768 은 **여전히 잘리고**, 1280×800 은 여유 3px 라 설정이 하나만 늘어도 재발합니다.
⟹ 2번은 «입구»를, 3번은 «카드 자체의 잘림»을 고치는 것이라 **서로 다른 문제**입니다.

### 1안(맨 위로) — 3번과 겹칩니다
3번이 버튼을 바닥에 고정하면 맨 위로 올릴 이유가 없고, 여전히 ⋮ 를 먼저 열어야 합니다.

### 4안(지금 설정 요약 카드) — 지금은 안 했습니다
카드에 내용을 **더하는** 것이라 3번 없이 얹으면 잘림이 심해집니다. 3번이 들어간 지금은
얹어도 안전하지만 **사장님이 고르신 범위 밖**이라 하지 않았습니다.
(확정 띠의 「고른 것」 한 줄이 그 취지를 일부 담습니다.)

### 카드 «전체» 에 `overflow` 주기 — 안 됩니다
말풍선 꼬리(`.menu-caret`)가 카드 밖 `top:-7px` 에 있어 **통째로 잘립니다.**
그래서 안쪽 `.menu-scroll` 만 굴립니다.
