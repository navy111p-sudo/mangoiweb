- **시킨 것**: 「순서대로 해줘」 — ① 026 중복 정리 ② BASIC 3,000문장의 성격 재기
- **바꾼 코드**: **0줄** (CLAUDE.md 2장 한 행 + 이 문서)

## 1. 왜 했나

앞선 작업에서 「SIU ADVANCE 는 웜업 게이트(80자)를 한 문장도 못 넘는다」까지는 확정했지만,
**BASIC 3,000문장은 게이트를 100% 통과**해서 「붙일 수 있다」로 남아 있었습니다.
그런데 CLAUDE.md 에 「그 문장이 교재 원문인지는 **안 쟀습니다**」가 그대로 있어서,
다음 사람이 그 줄을 읽고 **붙이는 쪽으로** 갈 수 있는 상태였습니다.

## 2. ① 026 겹공백 중복 — 이미 정리돼 있었습니다

「숨김」이 겹공백짜리만 걸리는지부터 코드로 확인했습니다.

- 판정: `hidden.has(String(g.book))` = **`Set` 정확일치** (`api-admin.ts:14550`)
- 묶음 이름: `BOOK_EXPR` = `substr(name,2,instr(name,']')-2)` — **TRIM 도 공백축약도 없음**
- ⟹ 27자(겹공백)와 26자(정본)가 서로 다른 값이라 **한쪽만** 걸립니다

정본 제목 대조: `speech-data-siu-basic.js:2698` 이 `title: "Should You"` — **공백 한 칸이 맞습니다.**

D1 을 보니 **이미 숨겨져 있었습니다** — 같은 날 **PR #1010** 이 한 일입니다.

| 항목 | 값 |
|---|---|
| book | `SIU BASIC 026 - Should  you` (27자) |
| hidden_by | `claude-dup-cleanup-20260916` |
| 적힌 때 | 2026-09-16 **15:43:20 KST** |

효과 재측정(SELECT 만): 자료실에 보이는 SIU BASIC **30묶음 · 453장** — 겹공백만 빠지고 정본 이름은 그대로.

🔴 **제가 여기서 「그 기록이 git 어디에도 없다」고 단정할 뻔했습니다.** 로컬 `main` 이
두 커밋 뒤처져 있어서 PR #1010 이 안 보였을 뿐이고, 그 PR 은 CLAUDE.md 에 「지우지 말고
숨기세요」까지 적어 두었습니다. CLAUDE.md 2장 「고쳐야 한다고 보고했는데 알고 보니 이미
고쳐져 있었음」 그대로입니다 — **«없다» 를 말하기 전에 `git fetch origin main` 부터.**
커밋 직전에 `origin/main` 이 움직인 것을 보고 잡았고, 그 거짓 문장을 CLAUDE.md·INDEX 에서
지웠습니다. 이 문서가 더한 것은 **«그 숨김이 왜 겹공백만 거는가» 라는 근거**입니다.

## 3. ② BASIC 3,000문장 — 쟀습니다. 교재 원문이 아닙니다

정본 파일을 실제로 파싱하고, 셸(`grep | sort -u`)로 **두 번째 방법으로 교차검증**했습니다.

| 잰 것 | 값 |
|---|---|
| 문장 합계 | 3,000 (30과 × 100) |
| **서로 다른 문장** | **310개** |
| 한 과 «안» 중복 | 0 |
| 310개가 나타나는 과 수 | 최소 3 · 중앙 10 · **최대 17** |
| **한 과에만 나오는 문장** | **0개** |
| 과끼리 겹침 | 21~44% (평균 32%, 쌍 435개) |
| 과 주제 낱말 적중률 | **0~8%** |

⟹ 과마다 «그 과의 문장» 이 있는 것이 아니라 **310개짜리 공용 더미를 30과에 섞어 나눠 둔 것**입니다.

눈으로도 확인했습니다.

```
■ SIU Basic 27 — "Weather and Seasons" / "Climate / Seasons / Weather Activities"
   1. I sent my friend abroad a package of Korean traditional sweets.
   2. She offered me a different point of view on the situation.
   3. The shop owner gave us a discount because we were regular customers.
   4. The teacher assigned us a group project about climate change.
   5. He wrote his mother a heartfelt letter on Mother's Day.
```

날씨가 한 글자도 없고, 「Money」 과와 **33문장을 같이 씁니다.**

**ADVANCE 도 같은 모양**입니다 — 2,000 → **210개**. 즉 앞서 적은
「번호 일치 4/20 · 이름 일치 6/20」은 **애초에 이을 값이 없던 것**이었습니다.

## 4. 그래서 내린 판단 — 붙이지 않습니다

바로 전에 제가 제안한 두 길이 **둘 다 무의미해졌습니다.**

| | 판단 |
|---|---|
| A안 `review_quizzes` INSERT | ⛔ 하지 않음 |
| B안 새 모듈 + `index.ts` 한 줄 | ⛔ 하지 않음 |

붙이면 AI 가 **그 교재와 무관한 문장을 «오늘 배울 문장» 이라고 학생에게 말합니다.**
CLAUDE.md 2장 「측정할 수 없는 값을 그럴듯하게 채우고 싶을 때」와 같은 뿌리이고,
**비어 있는 것보다 나쁩니다.**

**진짜 교재 문장을 넣는 길은 올라온 453장을 OCR 하는 것 하나뿐**이고, 비용이 드는 별건입니다.

## 5. 검토했다가 버린 것

- **번호로 잇기** — 이미 ⛔ 였는데, 이번 측정으로 «이을 값 자체가 없다» 가 되어 완전히 닫혔습니다.
- **주제가 맞는 문장만 골라 붙이기** — 적중률이 0~8% 라 과당 0~8문장이고,
  그 8문장도 다른 과와 공유합니다. 고를 만한 덩어리가 없습니다.
- **발음 코칭 파일을 지우기** — ⛔. 거기는 «따라 읽을 영어 문장» 이면 되고
  교재 원문일 필요가 없습니다. 그대로 씁니다.

## 6. 확인한 방법

- D1 은 **SELECT 만**(CLAUDE.md 1-1). 이번에 D1 에 쓴 것은 **없습니다.**
- 문장 측정은 정본 파일 파싱 + 셸 `sort -u` **두 방법이 같은 값**(3,000 / 310).
- CLAUDE.md 편집은 스크립트로 했고, ① `grep -c` 로 **세 앵커가 각각 1곳**인 것을 먼저 세고
  ② 그 행 «안에서만» 치환하고 ③ `git diff` 로 **바뀐 줄이 내 행 하나**인 것을 확인했습니다.
- ⚠️ 그 과정에서 한글을 `\uXXXX` 로 손으로 적었다가 실패했습니다 —
  CLAUDE.md 가 경고한 바로 그 함정이라, 옛 글자·새 글자를 **전부 파일로** 넘겨 다시 했습니다.
