## 1. 왜 했나

사장님 「BTS교재가 맨 뒤에 있어서 찾기가 어려워. 차라리 **교재로 웜업** 이란 부분을
화면 상단에 놔두는게 어떨까? 이거 4가지로 안과 샘플 만들어줘」 → 시안 4종 중 **3안** 선택.

### 잰 것 — 말씀보다 더 안쪽이었다

교재 칸(`#wusBooksSec`)이 시작하는 자리를 진짜 브라우저로 쟀다:

| 화면 | 교재 칸 top | 첫 화면 안? |
|---|---|---|
| PC 1920×1040 | 1380px | ❌ 340px 내려야 |
| 노트북 1280×800 | 1380px | ❌ 580px 내려야 |
| 폰 390×844 | 1577px | ❌ 733px 내려야 |

⚠️ **더 큰 문제는 따로 있었다** — 폰 첫 화면에는 교재는커녕 «대화 수준» 조차 안 보인다.
나이대를 고르다 화면이 끝나는데 🚀 시작 버튼은 sticky 라 늘 보여 **스크롤할 이유가 없다.**
그대로 누르면 자유 대화로 시작된다.

ℹ️ 2026-09-15 에 넣은 하단 「지금은 교재 없이 자유 대화 · 고르기 ↓」 줄은 실측상
**세 화면 모두 첫 화면에 보이고 있었다**(`bookNowVisible` = true). 그런데도 못 찾으셨다 —
시작 버튼 부속처럼 보여 «안내문» 으로 읽힌 것으로 **보인다(추론, 측정 아님)**.

## 2. 무엇을 바꿨나

전부 `cloudflare-deploy/public/warmup.html` 한 파일이다(서버는 한 줄도 안 고쳤다).

### 배치
- `#wusBooksSec`(교재 칸)을 **수준 목록 아래 → 언어 칸 바로 다음**으로 옮겼다.
- 그 앞에 **두 갈래 카드**(`#wusTwoSec` / `#wusTwoWay`)를 넣었다:
  「📘 교재로 웜업」 · 「💬 자유 대화」.
- 교재 칸은 **기본이 접힘**이고 「교재로 웜업」 을 눌러야 펼쳐진다.

⚠️ **언어보다 위로 올리지 않은 이유** — 언어를 중국어로 바꾸면 교재 칸이 통째로 사라진다.
교재를 언어 «위» 에 두면 「방금 고른 교재가 없어졌다」가 된다(교재는 영어 전용).

### 함수
| 이름 | 하는 일 |
|---|---|
| `_btsOpen` / `btsBooksOpen()` | 지금 화면에서 교재 칸을 펼쳤는가 (**저장하지 않는다**) |
| `_btsSortLv` / `btsSortLevel()` | **펼친 순간의 수준**을 붙잡아 둔다 — 재정렬 방지 |
| `btsOpenBooks(scroll)` / `btsCloseBooks()` | 펼치기 / 접으며 교재 비우기 |
| `renderTwoWay()` | 두 카드 그리기 — `.on`(갈래)와 「지금」(실제 상태)을 **가른다** |
| `btsListHtml(sortLv, hideFree)` | 정렬 기준을 **인자로 받고**, 목록 안 «자유 대화» 줄을 끌 수 있다 |

### 그 밖에
- 하단 줄 화살표 `고르기 ↓` → `고르기 ↑`(교재가 이제 위에 있다).
- `data-jump='books'` 가 **펼친 뒤** 데려간다 — 접힌 자리는 `display:none` 이라
  스크롤만 하면 브라우저가 통째로 무시해 «눌러도 아무 일 없는» 버튼이 된다.
- 중국어에서 두 갈래·교재 칸·하단 줄을 **짝으로** 감춘다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

### ⛔ 「그냥 위로 올리기」 — 이게 금지였던 이유를 살려 두었다

`CLAUDE.md` 2장과 `warmup.html` 의 `.wus-booknow` 주석이 **「교재 섹션을 위로 올리지 말라」**
고 못 박아 두고 있었다. 이유: `btsListHtml()` 이 고른 수준(`_warmLevel`)으로 권을 near/rest 로
가르므로, 교재가 수준 «위» 에 있으면 **수준을 고르는 도중 위쪽 목록이 눈앞에서 재정렬된다.**

→ 그냥 올리는 대신 **«펼친 순간» 의 수준을 `_btsSortLv` 에 붙잡아** 두었다.
수준을 8단계로 바꿔도 위쪽 순서가 그대로인 것을 브라우저로 실측했다.
「자유 대화」 로 접으면 고정이 풀려, 다시 펼칠 때는 **그때의 수준**으로 정렬한다.

### ⛔ 「지금」 배지를 «펼친 갈래» 로 두기 — 화면이 거짓말을 한다

처음엔 `open` 하나로 `.on` 과 「지금」 을 같이 그렸다. 그러면 **펼치기만 하고 아직 교재를
안 고른 사람에게 「교재로 웜업 · 지금」** 이라 말하는데, 그 상태로 시작하면 실제로는 자유 대화다.
하단 줄은 「자유 대화」 라고 하고 있어 **한 화면이 두 말을 했다.**

→ **«보고 있는 갈래»(`.on`)와 «실제로 무엇으로 시작하는가»(「지금」 = `_btsVol`)를 갈랐다.**
안 골랐으면 카드가 「아래에서 교재를 골라 주세요」라고 말한다.
(CLAUDE.md 2장 「상태가 셋인데 저장이 둘이면」 의 형제 자리다.)

### ⛔ 목록 안 「교재 없이 자유 대화」 줄을 남겨 두기 — 같은 말을 두 번

위에 「자유 대화」 카드가 생겼는데 목록 첫 줄에도 같은 항목이 있었다.
`btsListHtml(sortLv, hideFree)` 로 껐다. **인자를 안 주면 예전처럼 그린다** — 이 함수를
오려 내 돌리는 자동 하니스(`warmup_bts_book_harness` ⑨절)를 깨지 않으려고 그렇게 두었다.

### ⛔ 「펼쳤다」를 저장하기

`_btsOpen` 을 localStorage 에 남기면 «아직 안 정함» 과 «사람이 골랐음» 이 같아진다.
저장하는 것은 **고른 교재(`_btsVol`) 하나**뿐이다.

### 버린 것 — 1·2·4안
- **1안**(맨 위 배너만): 재정렬 위험 0 이지만 «고르려면 여전히 스크롤».
- **2안**(시리즈 탭): 재정렬이 원리상 사라지지만 «내 수준에 맞는 권» 자동 추천을 잃는다.
- **4안**(고른 것 접기): ⛔ 를 안 건드리지만 수준을 바꿀 때 한 번 더 눌러야 한다.
