## 8. 함정 대조가 잡은 것 — 제가 만든 회귀 하나 (같은 날 후속 수리)

병합·배포 뒤 `trap-check` 가 🔴 0건 · 🟡 3건을 보고했고, 그중 **1번은 제가 만든

### 🔴 `<details>` 접힘 라벨이 «이 변경 때문에» 어긋났습니다

갈래(`near`/`rest`)만 3단으로 고치고 **`<summary>` 는 2단 그대로** 두었습니다:

```js
+ (siuFirst ? '📘 BTS 교재도 보기' : '📗 SIU 회화 교재도 보기')
```

| 단계 | 안내 줄(고쳤음) | summary(안 고쳤음) | 접힌 쪽 **실제 내용** |
|---|---|---|---|
| 5·6 | 📗 SIU BASIC 29권 | 📘 BTS 교재도 보기 (**52권**) | BTS 32 + **ADVANCE 20** |
| 7·8 | 📕 SIU ADVANCE 20권 | 📘 BTS 교재도 보기 (**61권**) | BTS 32 + **BASIC 29** |

**이 변경 «전» 에는 그 라벨이 정확했습니다**(5~8단계의 `rest` 가 BTS 뿐이었음).
⟹ 7단계 학생이 바로 아래 난이도인 BASIC 29권을 찾으려 해도 라벨에는 «BTS» 만
적혀 있었습니다 — 2장 「기능이 «있는데» 아무도 못 씀 — 이름표가 사실과 다름」.

⚠️ **「접어 둔다」 규칙 자체는 안 깨졌습니다** — 모든 권이 여전히 선택 가능했고
하니스의 「접힌 채 고를 수 있다」 검사도 통과했습니다. 깨진 것은 **라벨의 정확성**뿐입니다.

🪤 **그 자리를 보는 검사가 두 하니스 모두 0건**이었습니다 — 자동은 `openPart()` 로
`<details` **앞만** 잘라 보고, 브라우저는 `.wus-hint` 만 읽었습니다.

세 단계 × 시리즈 3 + 권 수 = **자동 15종**, 브라우저 3종. 물어보는 것은
**「라벨에 적혔는가」가 아니라 「접힌 쪽에 든 것과 맞는가」** 입니다 —
⛔ 「다 적혔는가」만 두면 **세 시리즈를 늘 다 적어도 통과**하므로
**「없는 것은 라벨에도 없는가」를 짝으로** 두었습니다.

## 10. 「문장 붙이기」 다시 재기 — ADVANCE 는 **넣어도 0문장**입니다

§9 가 「번호로 이으면 16권이 남의 과 · 이름 완전일치로만」으로 맺었습니다.
저는 거기에 길이 이야기를 덧붙이려다 **하루에 두 번 결론을 뒤집었고**, 세 번째에야
**진짜 게이트**를 찾았습니다. 그 과정을 그대로 남깁니다.

### 10-1. 🔴 진짜 게이트는 «낱말 수» 가 아니라 «글자 수 80자» 입니다

```ts
export function isEnglishText(raw: unknown, maxLen = 80): boolean {
  const s = …; if (!s || s.length > maxLen) return false;
```

**[잰 것 — 2026-09-16, 그 게이트를 오려 내 두 파일에 실제로 돌림]**

| | 문장 | 글자 최소 | 중앙 | 최대 | **게이트 통과** |
|---|---|---|---|---|---|

### 10-2. ⚠️ 제가 두 번 틀렸습니다 (그 과정을 남깁니다)

| 판 | 무엇이라 적었나 | 왜 틀렸나 |
|---|---|---|
| 첫 커밋 | 「ADVANCE 는 이름이 맞아도 **길이 때문에** 못 쓴다」 | **결론은 맞고 근거가 틀림** — 낱말 수로 쟀습니다 |
| 두 번째 | 「길이는 막는 이유가 **아니다**」 | **결론까지 뒤집혀 틀림** — `WARMUP_WORD_CAP` 과 견줬는데 그 상수는 **AI 답변** 안전망(`replyTooLongFor`)이고 교재 예시 문장은 시스템 프롬프트에 **그대로 주입**되어 그 상수를 한 번도 안 지납니다 |
| 이번 | 「**글자 80자 게이트에서 0/2000**」 | 정본 게이트를 **오려 내 실제로 돌린** 값 |

⛔ **`WARMUP_WORD_CAP` 으로 예시 문장을 재지 마세요** — «다른 것끼리» 견주는 것입니다.

### 10-3. ✅ BASIC 은 통과합니다 — 다만 여유가 **3자**뿐입니다
