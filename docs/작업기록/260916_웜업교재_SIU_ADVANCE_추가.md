## 3. 무엇을 했나

`cloudflare-deploy/public/warmup.html`

- **`SIU_ADV_BOOKS`** 20권 신설 — `v:'adv001'`~`'adv020'`, `s:'SIU'`, `book`/`en`/`ko`
- **`SIU_ADV_BAND_MIN = 7`** 신설 — 7단계(상급)부터 ADVANCE 가 목록 위로
- `allBooks()` 에 `.concat(SIU_ADV_BOOKS)` — ⚠️ 이 한 줄이 빠지면 ADVANCE 를 골라도
  «자유 대화» 로 조용히 떨어집니다(변이시험에서 실제로 재현)
- `btsListHtml()` 을 2단 → **3단**으로: `advFirst` → `siuFirst` → BTS
- 안내 줄에 📕 갈래 추가

## 4. 검토했다가 버린 방법

| 버린 것 | 왜 |
|---|---|
| **`SIU_BOOKS` 에 ADVANCE 를 그냥 이어 붙이기** | CLAUDE.md 「시리즈를 한 목록에 섞지 마세요」. ADVANCE 주제가 Politics·Crime·Philosophy 라 중학생 목록 맨 앞에 올라옵니다. 그리고 「📗 SIU BASIC 29권」 안내 문구가 거짓이 됩니다 |
| **권마다 난이도 매기기** | BASIC 때와 같은 이유 — 그럴 자료가 없습니다(지어내는 것). `SIU_ADV_BAND_MIN` 한 줄로 «이 단계 이상에서 먼저 보인다» 만 정합니다 |
| **id 를 `siua001` 로** | 기존 검사들의 `/^siu/` 정규식에 ADVANCE 도 함께 걸려 「BASIC 만」을 묻던 검사가 조용히 흐려집니다. **`adv001`** 로 해서 기존 검사 대부분이 한 글자도 안 바뀌게 했습니다 |
| **D1 의 020 겹공백을 고치고 표에 깨끗한 이름 적기** | ① D1 변경은 승인이 필요하고 ② 9/15 에 그렇게 했다가 026 이 두 묶음이 됐습니다. **D1 을 안 건드리고 `book` 에 겹공백을 그대로** 적었습니다 |
| **`item()`·`applyBtsBook`·`bookTitleOf` 고치기** | `b.s === 'SIU'` 분기가 ADVANCE 에도 그대로 맞습니다. 한 글자도 안 건드렸습니다 |

### `book` 과 `en` 이 다른 이유

- `book` = **D1 이름 그대로**(`Relationship  and Love`) — 나중에 복습퀴즈가 생기면
  서버 `warmupLessonContext` 가 `LOWER(textbook)=LOWER(?)` **정확일치**로 찾습니다
- `en` = 화면·AI 에 가는 **깨끗한** 이름(`Relationship and Love`)

⛔ D1 을 고치는 날 **이 표도 함께** 고쳐야 합니다.

### 🪤 하니스가 원리상 못 잡는 것

**「`book` 이 D1 이름 그대로인가」는 이 하니스가 못 잡습니다 — D1 을 모릅니다.**
변이 Ⓓ(020 의 겹공백을 «다듬기»)를 넣었더니 **그대로 통과**했습니다. 처음 만든
검사는 「겹공백이 든 권」을 찾아 쓰는 구조라, 변이가 그 겹공백을 없애면
**검사가 스스로 비켜났습니다**(CLAUDE.md 「그룹에 있으면 건너뛴다」 함정과 같은 형태).

대신 잡을 수 있는 것으로 두 줄을 더했습니다:
- `book` 과 `en` 이 **같은 책을 가리키는가**(공백만 다를 수 있음) → Ⓘ 를 잡음
- **id 번호와 book 번호가 맞는가** → Ⓙ 를 잡음

### 🔴 제가 밟은 함정 — 한글을 `\uXXXX` 로 적음

CLAUDE.md 가 「한글을 `\uXXXX` 로 손으로 적지 마세요 — 조용히 다른 낱말이 됩니다」라고
적어 둔 그 함정을 그대로 밟았습니다. 실제로 주석 두 곳이 깨졌습니다:

- 「복습**퀵**즈」 ← 복습퀴즈
- 「한 목록에 **섮**지」 ← 섞지

표의 ko 칸 20줄은 무사했습니다. `git diff | grep '^+'` 로 새 한글을 눈으로 읽어 잡았고,
두 번째 편집부터는 파이썬 문자열에 한글을 **직접** 적었습니다.

## 6. 사람이 정할 일 (아직 안 함)

1. **`SIU_ADV_BAND_MIN = 7`** — 「8단계 중 상급 두 칸」이라는 제 제안입니다.
   6 이나 8 로 정하시면 그 숫자 **한 줄**만 바꾸면 됩니다(주석에 적어 뒀습니다).
2. **BASIC 026 두 묶음 정리** — 되돌릴 수 없는 삭제라 승인이 필요합니다.
   숨김 처리 / D1 이름 통일 / 그대로 두기 중 고르셔야 합니다.
3. **ADVANCE 020 겹공백** — D1 을 고치면 이 표의 `book` 칸도 함께 고쳐야 합니다.
4. **BASIC 012** — Mai 가 아직 안 올렸습니다.
5. **문장 붙이기** — `review_quizzes` 에 SIU 문장이 0건이라 ADVANCE 도 «주제만»
   붙습니다. 교재 OCR 이나 사람 입력이 필요하고 비용·별건입니다.
