## 3. 「없애자」에 절반만 동의한 이유 — 버린 길

검토한 4안: **A 접기(우상단 🔍 칩 + Cmd+K 팔레트)** · **B 얇게(420×42, CTA 아래)** ·

비교 문서(아티팩트)는 사장님께 별도로 드렸습니다.

### ⛔ 완전히 없애는 길(A안)을 권하지 않은 이유 둘

**① 얼마나 쓰이는지 잴 방법이 없습니다.**
검색어는 대부분 브라우저 안 규칙 40개(`js/idx-ai-home.js`)로 처리되고, 서버
`/api/student/ai-command` 는 **못 알아들었을 때만** 탑니다. 그래서 「며칠에 몇 번 쓰는가」를
알려 주는 기록이 어디에도 없습니다. ⟹ **「안 쓰니까 빼자」의 근거가 우리에게 없고,
없애고 나면 되돌릴 근거도 안 생깁니다.**

**② 검색이 «유일한 길» 이었던 사고가 실제로 있습니다.**
CLAUDE.md 에 기록된 「원격수리 어디서 해요?」 건 — 그리드 메뉴·카테고리 모달·전체메뉴가
전부 죽어 있어 살아 있던 길은 **「검색창에 '원격' 을 정확히 치기」 하나**였습니다.
검색은 지금 **메뉴가 빠뜨린 것의 안전망** 노릇을 겸하고 있습니다.

⟹ 답은 「없애기」가 아니라 **「주인공 자리를 CTA 에 넘기기」** 입니다.

### ⛔ CTA 확대는 일부러 안 했습니다

C안 그림에는 CTA 를 폭 68%·글자 +25% 로 키우는 것이 들어 있었지만 **하지 않았습니다.**
`.cta-enter`·`.cta-pay` 의 크기가 `!important` 로 **8곳**(`index.html` 7970·8042·15443·
15605·15610·15710·15726·15747·15878·17160·17169)에 흩어져 있고, 그중에는 특정 폭에서만
도는 `margin-bottom:260px`·`404px` 같은 것도 있어 사고 반경이 큽니다.
그리고 **검색창이 내려간 것만으로 CTA 가 이미 화면의 주인공이 됐습니다**(§6 사진).
키우고 싶으시면 별건으로 하는 편이 안전합니다.

## 4. 어떻게 만들었나

### 🔑 핵심 선택 — `<details>` (JS 없이 열리게)

```html
<details id="hs">
  <summary id="hs-sum">
    <span aria-hidden="true">🔍</span>
    <span data-ko="찾는 게 있나요? 눌러서 검색" data-en="Looking for something? Tap to search">…</span>
  </summary>
  …기존 검색 입력줄 그대로…
</details>
```

**왜 `<details>` 인가** — 펼치기가 **브라우저 기본 동작**이라 JS 가 한 줄도 필요 없습니다.
⟹ `js/idx-hero-search.js` 가 못 와도(캐시·차단·오류) **검색은 그대로 열리고 동작합니다.**

⛔ **여는 동작을 JS 로 옮기지 마세요** — 그 순간 「JS 가 죽으면 검색이 통째로 사라지는」
상태가 됩니다. 검색은 §3-②의 안전망이라 그 방향으로 실패하면 안 됩니다.

### 옮긴 것 / 안 옮긴 것

- **옮긴 것**: `.ai-search-box` + 인라인 초기화 스크립트 + `#ai-home-listening` +
  `#ai-home-suggest` (원래 6140~6174행, **35줄**) → `#next-class-countdown` 다음
- **안 옮긴 것**: `.ai-quick`(빠른 버튼 12개). `display:none` 이지만
  `mgGo()`·사이드바가 `.ai-quick-btn[data-go=…]` 를 찾아 `.click()` 으로 대신 눌러 씁니다.

⚠️ **`.ai-search-wrap` 을 통째로 옮기려 하면 안 됩니다** — 그 div 는 6139~**6827행**
(688줄)짜리 **히어로 컨테이너**이고 CTA·카운트다운·`openAiFriendsOverlay` 가 전부
그 **안**에 있습니다. 이름만 보고 «검색창 상자» 로 읽으면 크게 다칩니다.

### `js/idx-hero-search.js` (defer, 신설)

펼치면 **커서 넣기** + **`scrollIntoView`**(폰에서 키보드가 올라와 밀리는 것 방지) + **Esc 로 닫기**.
그뿐입니다.

### 🪤 이번에 실제로 밟은 함정 (CLAUDE.md 2장에 추가함 — 커밋 `ec1c09d`)

주석에 「하니스는 인라인 **«script»** 본문과 …」라고 **설명을 적었을 뿐인데**
첫 화면 blocking 이 **1575 → 1580KB**(인라인 275 → 280KB)로 뛰어 예산 FAIL 이 났습니다.

`first_paint_budget_harness` 의 «인라인» 정규식이 주석을 안 벗겨서, 주석 속 여는 태그

(「소스 파일이 실제로 있는 것만 센다」) — 인라인 쪽에는 그 방어가 없습니다.
