기준: main `3ffc9f33f6beafc74cb89efa6e4116e735deb463`.

## 요청과 재현
PR #1015–1017 운영 전 점검 후 사용자의 «문제없도록 계속 진행» 요청.
기존 전체 인라인 게임 코드를 가짜 DOM/시계/SpeechRecognition에서 실행했다.
추가한 회귀 사례 중 수정 전 7건이 실패했다: 내레이션 중 그림 클릭 후 듣기,
침묵 후 클릭 안내, 종료 시 마이크 해제, 새 판에 이전 음성 결과 적용,
재시작 후 마이크 재개, 이전 단계 이동 타이머, 한 글자 조각 정답 인정.

## 수정
- 내레이션 중 그림 클릭도 기존 마이크 진입 흐름으로 연결.
- 종료·재시작·단계 진행 시 음성인식 및 예약된 듣기를 정리.
- 이전 게임의 결과·단계 이동·문 열림 효과·성공 안내 콜백은 무시.
- 늦게 도착한 TTS 응답/폴백은 중지 세대 번호로 무효화.
- 침묵·권한 문제 후 클릭 안내 복구, 인식 종료 이벤트가 없어도 침묵 제한 적용.
- 임의 접두어 정답을 제거하고 정확한 단어·명시적 어형·기존 STT 허용 유지.
