# 웜업: 그림 선택, 단계별 도움, 집중 화면

사용자 요청: 웜업을 흥미롭고 자연스럽게 만들고 집중과 학습에 도움이 되도록 개선. 제안 뒤 “아주 좋아 이거 진행해줘”로 구현 승인.

## 바뀐 동작과 이유

- 아바타·현재 질문·입력창을 가까이 두고 이전 대화는 펼쳐 볼 수 있게 했다. 휴대폰·태블릿·PC에서 입력창과 종료 버튼을 유지한다.
- 기존 이미지 3개(가족 요리, 축구, 기차 여행)를 선택해 말문을 연다. 그림 선택은 학생 답변으로 기록하지 않는다. 기존 질문 선택 API가 서버 이력을 저장한 뒤 현재 질문을 갱신한다.
- 단어 → 빈칸이 있는 문장 시작 → 예시를 차례로 연다. 예시를 눌러도 자동 전송하지 않으며 기존 초안을 덮어쓰지 않는다. 예시를 사용한 답변은 요약에 별도로 표시한다.
- 기존 채팅 AI 호출 하나에 선택 그림과 대화 연결 지침을 전달하고 `speaking_help`를 선택적으로 받는다. 도움은 화면 전용이며 TTS에 넣지 않는다. 영어/중국어 언어와 필드 크기를 검증한다. 도움 응답이 없거나 잘못되면 대화는 계속된다.
- 교재·연령·수준의 기존 선택을 보존한다. 새 설정으로 시작하면 그림과 요약 카운터를 초기화한다.
- 종료 요약에는 실제 제출한 답변 수, 마지막 답변, 실제 교정 표현만 넣는다. 독립 화면에서는 복사, 수업 iframe에서는 기존 웜업 전달 채널을 사용한다. 강사 수신 완료로 표시하지 않는다.
- 종료·페이지 이탈·탭 숨김에서 웜업 음성 인식/Whisper/TTS와 요청을 취소한다. 이미 진행 중이던 작업의 늦은 결과도 세대 번호로 무시한다. 부모가 CSS로 iframe을 숨기는 경우도 감시한다. 다시 보일 때 마이크를 자동으로 켜지 않는다.

## 범위와 선택하지 않은 방법

새 데이터베이스·추적 서버·교실 WebRTC 수정은 없다. `src/index.ts`는 웜업 응답에 도움 필드를 연결하는 부분만 수정했다. 안내 모듈은 분리했다. 새 AI 호출을 별도로 추가하지 않았고, 새 클라이언트의 기존 호출 토큰 상한만 320에서 440으로 늘렸다. 실제 지연/비용은 측정하지 않았다.

무작위 질문을 계속 바꾸는 방식과 예시를 즉시 자동 제출하는 방식은 학생이 자신의 생각을 말할 기회를 줄여 채택하지 않았다. 매번 정답 점수나 과장된 칭찬을 주는 보상 기능도 추가하지 않았다.

## 검증

- 실제 Chromium DOM을 사용하는 새 브라우저 검사: 390×844, 768×1024, 1366×768에서 총 71개 통과. AI·STT 제공자는 가짜 응답으로 대체했다. 늦은 채팅/Whisper 응답, 수업 iframe 숨김, 예시 도움과 전송 분리, 요약창에서 다음 활동 메뉴로 전환 포함.
- 기존 교재 선택 브라우저 검사 63개 통과.
- 새 도움 파서/프롬프트 18개, 기존 음성 인식 33개, 연령/수준 162개, 교정 95개 통과.
- 최종 `TZ=Asia/Seoul bash test-harness/ci-gates.sh`: TypeScript·회귀 350개(실패 0, E2E 제외 20)·인라인 JS·정적자산 230개 모두 통과. 최신 main의 방탈출 변경은 별도 하니스 71개 통과. 기존 `class_time_harness`는 로컬 시간대에 의존하여 UTC에서 실패, `TZ=Asia/Seoul`에서 14개 통과. 해당 테스트를 끄거나 수정하지 않았다.
- 브라우저 워크플로에 새 검사를 추가했다. 자산 `?v=`와 원장도 함께 갱신한다.

실제 학생 마이크/스피커, 실제 모델 답변의 품질·지연과 운영 화면은 이 로컬 검사로 검증한 것이 아니다. 병합 및 배포 상태는 PR/Actions를 확인해야 한다.

## 추가 승인: Higgsfield 영상 3종

사용자가 GitHub 업로드·검사 후 병합·배포를 승인한 뒤 “힉스필드도 연결해서 이미지나 동영상 추가해줘”라고 요청했다. 기존 그림을 첫 프레임으로 Higgsfield Seedance 2.5에서 5초 무음 영상을 생성했다(사전 견적 각 35크레딧). 실제 생성 완료 결과를 내려받아 H.264 960×540, 24fps, 정확히 5초로 변환했고 오디오 스트림이 없음을 ffprobe로 확인했다. 원본을 1초 간격으로 확인해 요리 동작·축구 패스/받기·창밖 풍경 이동을 검토했다.

| 장면 | 생성 job ID | 배포 파일 크기 |
|---|---|---:|
| 가족과 팬케이크 만들기 | `b07a8d65-c2a4-4600-ad7f-b51b56200177` | 337,043바이트 |
| 축구공 차고 받기 | `ba3ecc16-52b3-4806-9e8b-e8bfffc05adb` | 173,156바이트 |
| 기차 창밖 풍경 | `70ad614f-802c-4f22-9445-21814485e1cc` | 201,234바이트 |

`public/video/warmup-scenes/`에 포함하여 운영 시 외부 생성 서비스에 연결하지 않는다. 그림을 골라도 영상을 받지 않으며 “5초 영상 보기”를 누를 때만 같은 오리진 파일을 요청한다. 자동 재생·반복·소리 켜기는 제공하지 않는다. 마이크 시작, AI 발화, 답변 제출, 장면 변경, 종료, iframe 숨김에서 정지하며 재진입으로 자동 재생하지 않는다. 영상 오류 시 원래 그림과 대화 입력을 유지한다.

실제 MP4 재생을 포함하는 브라우저 검사 84/84 통과. 영상 지연 로딩, 무음, 마이크와 재생의 배타 동작, 장면 변경 시 이전 파일 해제, 종료·재진입, 오류 후 대화 지속을 추가 검증했다. AI/STT 제공자는 여전히 가짜 응답이며 실제 장치·실제 AI 품질 검증과는 구분한다.
