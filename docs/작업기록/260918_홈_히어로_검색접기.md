## 요청과 범위
사용자가 전달한 이전 진행 내용에 따라 슬로건과 학습 안내를 추가하고 검색창·빠른 버튼만 접었다. 이전의 미커밋 수정본은 현재 작업 폴더와 원격 PR에서 확인할 수 없어 main 22873cd를 기준으로 다시 적용했다. 기존 비회원/회원 분기, 수업 입장 CTA, 4단계 안내, 수업·서버 코드는 유지했다.

## 선택한 방법
- 기존 안내 자료의 문구인 ‘재미가 의지를 이깁니다!’와 한영 번역을 사용했다.
- 출처 없는 학생 수·만족도 대신 기존 서비스 기능인 1:1·1:2 수업, AI 예복습, 4단계를 표시했다.
- 브라우저 기본 details/summary를 사용해 클릭·키보드·접힘 의미를 제공한다. ai-search-wrap 전체를 감싸지 않는다.
- ai-quick은 기존 드로어 스타일에서 display:none!important였다. 펼친 home-search-fold 안에서만 grid로 표시한다.
- 밝은 사진에서 그림자만으로 대비를 확보하기 어려워 안내 줄과 summary에 흰 글자 및 반투명 남색 배경을 썼다. 새 이미지·폰트·라이브러리·타이머는 없다.

## 0바이트의 정확한 의미
인라인 JavaScript 본문과 외부 script 태그는 변경 전후 동일하다. 실행을 막는 JavaScript 증가량은 0바이트지만 HTML 전체가 0바이트 증가인 것은 아니다.

| 측정 | 결과 |
|---|---:|
| index.html 전 | 1,060,234 B |
| index.html 후 | 1,062,981 B |
| HTML·CSS 증가 | 2,747 B |
| gzip 압축 증가 | 903 B |
| Brotli 압축 증가 | 698 B |
| 추가 JavaScript | 0 B |

압축값은 Node 기본 옵션으로 동일 파일을 전후 비교한 값이며 실제 CDN 전송량 측정은 아니다. first-paint-budget 기준선은 변경하지 않았다.

## 검증
- TypeScript tsc --noEmit 통과.
- 첫 화면 예산 검사 통과(홈 blocking 1,576 KB). 정적자산 버전 검사 227건 통과. HTML 변경뿐이므로 기존 JS/CSS 버전은 유지했다.
- 로컬 Chromium 153에서 360·768·1440px, 밝은·어두운 배경 확인. 접기/펼치기 및 Enter로 닫기, 비회원/회원 CTA 분기, CTA와 home-flow가 details 밖에 있는지 확인. 전체메뉴 바로가기와 영어 전환도 확인했다.
- 브라우저의 API는 빈 응답으로 대체하고 외부 요청을 차단했다. 실제 로그인·수업 연결 E2E를 대신하지 않는다. 배포 전 시각 검증용 로컬 한글 폰트를 사용했으며 제품에는 폰트를 추가하지 않았다.
- 로컬 전체 회귀는 실행했지만 sparse checkout의 미디어·보조 폴더 누락으로 실패했고 session_guard까지 진행한 뒤 종료됐다. 전체 회귀 통과로 보고하지 않는다. 병합 조건은 전체 체크아웃을 사용하는 GitHub CI의 게이트 통과다.
