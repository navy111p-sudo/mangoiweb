# 웜업 그림·영상 7개 추가 — 2026-09-19

## 요청과 변경

사용자가 기존 요리·축구·여행 그림 선택 화면에 «7개 더 추가해줘»라고 요청했다. 앞서 승인한 Higgsfield 영상 방식으로 자전거 타기, 반려동물 돌보기, 그림 그리기, 음악 연주, 정원 가꾸기, 장보기, 해변 놀이를 추가해 총 10개가 됐다.

- 각 장면은 자체 썸네일과 5초 무음 MP4를 사용한다. 960×540, H.264, 24fps, faststart. 새 MP4 7개 합계 2,037,606바이트.
- 영어·중국어 쉬운 질문과 서버의 장면 사실 allowlist를 함께 연결했다. 목표/꿈 수업의 예시도 선택한 활동에 맞춘다. 예: 음악 → I want to learn to play the piano. / 我想学弹钢琴。
- 10개를 세로로 전부 펼치면 질문이 밀리므로 그림 목록에 높이 제한과 스크롤 안내를 넣었다. 모바일은 2열, 데스크톱은 기존 가로형 카드 목록. 키보드/터치로 끝 항목까지 접근 가능하며 입력창은 별도 영역에 유지된다.
- 기존 재생 정책 유지: 클릭 전 영상 요청 없음, 자동재생·반복·음성 없음, 마이크/답변/종료/숨김 시 멈춤, 영상 실패 시 그림으로 대화 지속.

## 검토한 대안

- 기존 다른 학습 도구의 그림을 재사용하면 영상과 내용이 달라질 수 있어 새 영상에서 썸네일을 추출했다. 기존 공유 이미지 파일은 덮어쓰지 않았다.
- 자동재생 또는 10개 영상 미리 불러오기는 집중력과 데이터 사용에 불리하여 추가하지 않았다.
- 새 항목마다 AI 도움 API를 따로 호출하지 않았다. 기존 질문 선택 및 단일 추론 흐름을 사용한다.

- warmup_guidance_harness: 36 PASS / 0 FAIL. 10개 scene allowlist와 비활성/알 수 없는 scene 거부.
- warmup-guided-browser: 175 PASS / 0 FAIL. 영어·중국어 10개 선택, 질문/scene_id 전달, 실제 이미지 로드, 실제 MP4 10개 클릭 재생, 지연 로드, 마이크/종료/숨김 안전 동작, 영상 실패 후 답변을 확인.
- 390×844, 768×1024, 1366×768 화면을 캡처해 확인. 한국어 폰트를 포함한 추가 시각 검토로 카드 스크롤과 입력창 배치를 확인.
- ffprobe: 새 영상 7개 모두 정확히 5초이며 오디오 스트림 없음. 파일별 239–339KB.
- JS/CSS 캐시 버전 증가 및 자산 원장 게이트 통과. 전체 배포 게이트·브라우저 회귀·운영 배포 결과의 정본은 이 변경 PR과 연결된 Actions 실행 기록.
- 브라우저 테스트의 AI/STT 응답은 대역이며 운영 AI 품질 확인을 의미하지 않는다. 배포 후 정적 파일은 HTTP 상태와 내용 해시로 검증한다.
