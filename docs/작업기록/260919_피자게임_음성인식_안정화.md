# 문법 피자 마스터 음성인식 안정화 — 2026-09-19

사용자 제보: 피자 완성 후 듣기·말하기의 음성인식과 작동이 원활하지 않다.

## 코드에서 확인한 문제와 수정

- 듣기와 인식의 동시 실행 가능 → 듣는 동안 말하기 차단, 인식 중 듣기 차단. 오답 직후 강제 정답 재생을 없애 학생이 듣기 또는 즉시 재시도를 선택한다. 듣기는 3회 뒤에도 다시 이용할 수 있다.
- 실제 마이크 준비 전에 '듣는 중' 표시, 시작 예외·종료 이벤트 유실 시 복구 부족 → 준비 안내와 실제 시작 안내 분리, 버튼 재클릭으로 종료, 첫 말 12초 대기, 무음 종료와 전체 30초 상한, 종료 이벤트 1.5초 복구. 브라우저의 비자발적 종료는 최대 2회 재시작하며 앞 문장을 보존한다.
- 권한·기기·네트워크 오류가 onend의 일반 무음 안내에 덮임 → 오류별 안내 유지, 버튼 즉시 복구.
- 미지원 브라우저에서 말하기 클릭만으로 성공 처리 → 기존 MangoiVoice 녹음/전사 연결. 네트워크·인식서비스 실패 후 다음 클릭은 녹음 모드. 두 마이크 엔진을 동시에 실행하지 않는다. 전사 45초 상한. 인식 불가 시 '점수 없이 다음 문장'으로 이동 가능하며 토큰·성공 기록은 주지 않는다.
- 임시 결과의 최고점으로 잘못 통과할 수 있음 → 확정된 완전 일치만 즉시 통과하고, 그 외에는 마지막 문장으로 종료 시 판정한다. 기존 70%/98% 기준 및 첫 시도 보너스는 유지한다.
- 문장 전환 뒤 이전 비동기 응답이 살아 있음 → 시도별 새 인식기, 취소/세대 가드, 탭 숨김·페이지 이탈 시 마이크 정리. 탭 숨김은 굽기/다음 문장 타이머를 막지 않는다.
- 늦은 TTS 응답이 말하기 시작 뒤 재생될 수 있음 → TTS 종료 시 세대 무효화·재생 중단. 서버 TTS 2.5초 대기 후 기기 음성으로 전환.

## 범위와 선택

피자 게임 HTML만 운영 코드 변경. 공용 인식기·화상수업·서버·DB는 변경하지 않는다. 인식 실패를 정답 처리하거나 자동으로 계속 마이크를 재시작하는 방식은 배제했다. 기존 녹음 API를 사용하며 새 외부 음성 서비스는 도입하지 않았다.
