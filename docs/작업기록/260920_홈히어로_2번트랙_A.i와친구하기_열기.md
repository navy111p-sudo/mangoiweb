# 홈 히어로 «2번 트랙» 을 눌러 「A.i와 친구하기」가 열리게 (2026-09-20)

> 사장님 지시 — **「2번은 A.i와 친구하기가 모두 나오게 해줘 . 이페이지가 나오게 해줘」**
> (스크린샷: `mangoi.ai` 의 「AI와 친구하기 / AI로 스스로 공부해요 · 자기주도 학습」 오버레이)

---

## 1. 왜 했나

2026-09-20 에 홈 히어로를 «슬로건 + 두 트랙 한 줄»(배치 D1 · 트랙 줄 2안)로 바꿨습니다.

| | 1번 트랙 | 2번 트랙 |
|---|---|---|
| 언제 | 사람과 · 예약한 시간에 | 혼자서 · 아무 때나 |
| 무엇 | **1:1** 원어민 화상수업 | **8**종 A.i 학습 |

그런데 **둘 다 «보기만 하는 글자»** 였습니다. 사장님이 2번을 누르면 그 도구 목록이
나와야 한다고 보셨고, 그 목록이 곧 스크린샷의 「AI와 친구하기」 오버레이입니다.

⚠️ 그 오버레이는 이미 있었고 코드도 멀쩡했습니다 — **닿는 길만 없었습니다.**
(입구는 전체메뉴 타일 · AI 검색 · `?menu=aitools` 주소 셋뿐이었고, 첫 화면에는 없었습니다.)

## 2. 무엇을 했나

`cloudflare-deploy/public/index.html` 한 곳 — 2번 트랙을 `<div>` → `<a>` 로:

```html
<a class="ht-track ht-ai" href="/?menu=aitools"
   aria-label="AI와 친구하기 목록 열기" data-ko-aria="…" data-en-aria="…"
   onclick="if(window.openAiFriendsOverlay){event.preventDefault();window.openAiFriendsOverlay();return false;}">
  <span class="ht-when" data-ko="혼자서 · 아무 때나" …>…</span>
  <span class="ht-what"><b>8</b><span data-ko="종 A.i 학습" …>…</span><i class="ht-go">›</i></span>
</a>
```

CSS 는 `.home-tracks a.ht-track`(cursor·밑줄 제거·hover·focus-visible)과 `.ht-go`(› 색) 넷 줄.

## 3. 검토했다가 버린 방법

| 버린 것 | 왜 |
|---|---|
| **`<a href="/?menu=aitools">` «만» 두고 onclick 없이** | 누를 때마다 홈 1.6MB 가 통째로 다시 뜹니다. 같은 화면에서 열리는 편이 훨씬 낫습니다 — 그래서 onclick 이 «먼저», href 는 **폴백**입니다. |
| **`href="#"` + onclick** | ⛔ CLAUDE.md 2장 — JS 가 아직 없으면 **무반응 = 「버튼이 고장났다」**. `/?menu=aitools` 는 실제로 열리는 주소라 폴백으로 씁니다(브라우저 하니스 ⑤절이 그것을 실제로 따라가 확인). |
| **`index.html` 인라인 `<script>` 에 리스너 추가** | 첫 화면 예산(blocking)에 그대로 셉니다. 속성 `onclick` 은 마크업이라 **0바이트**입니다. |
| **defer 파일에서 밖에서 배선하기** | 그 편이 예산에는 같지만, «그 파일 이름이 바뀌면 조용히 헛돈다» 는 약점이 생깁니다. 여기는 여는 함수(`window.openAiFriendsOverlay`)가 **같은 파일**에 있어 굳이 나눌 이유가 없습니다. |
| **1번 트랙(화상수업)도 함께 누를 수 있게** | 지시가 「2번은」 이었습니다. 화상수업 쪽은 바로 밑에 큰 CTA 버튼 둘이 이미 있어, 같은 일을 하는 입구를 하나 더 만드는 것이 됩니다(사람이 정할 일). |
| **「중국어 복습퀴즈」 칸을 보이게** | 👉 아래 §4 |

## 4. 「모두 나오게」 — 8칸입니다. 9번째는 «일부러» 감춰져 있습니다

오버레이 `ITEMS` 는 **9개**인데 화면에는 **8개**만 나옵니다. 사장님 스크린샷도 8개였습니다.

[잰 것 — 2026-09-20, 브라우저에서 각 칸의 `getBoundingClientRect()`]

```
0 AI 웜업 360x100   1 AI 음성코치 360x100   2 AI 친구 360x100   3 AI 영작 360x100
4 AI 단어퀴즈 360x100   5 복습 퀴즈 360x100
6 중국어 복습퀴즈  0x0  ← display:none (인라인, JS 가 넣음)
7 판단력 훈련 360x100   8 학생게임 360x100
```

감추는 것은 **`js/idx-allmenu.js` 의 `hideZhStaticEntries()`** 이고,
그 파일 주석이 이유를 적어 두고 있습니다 — **2026-08-24 학원장 검수
「영어 앱인데 중국어 퀴즈가 왜 있나」**. 기능을 없앤 것이 아니라 **볼 사람에게만**
보여 주는 것이고, 페이지(`/review-quiz-cn.html`)와 AI 명령 검색은 그대로 열립니다.
중국어 수강생(`mangoi_lang='zh'` 또는 `mangoi_zh_learner=1`)에게는 **9칸이 나옵니다**
(브라우저 하니스 ③절이 그것을 실제로 재서 확인합니다).

⛔ **그래서 「모두 나오게」를 이유로 그 게이트를 지우지 않았습니다** —
CLAUDE.md 2장 「두 화면이 달라서 «통일» 하려 할 때 — 그 차이가 «사고» 가 아니라
«사람이 승인한 결정» 일 수 있습니다」. 되돌리려면 **지시가 한 번 더** 있어야 합니다.

## 6. 하니스가 «헛돌지 않는가» — 변이시험

### 자동 (`home_hero_track_harness.mjs` — PASS 21, 변이 **13종 전부 실제 FAIL**)

Ⓐ `<a>`→`<div>` 되돌리기 · Ⓑ `href="#"` · Ⓒ `<a>` 에 `data-ko` 달기 ·
Ⓓ **조건 뒤집기** `if(!window…)` · Ⓔ **조건 항상참** `if(true)` · Ⓕ `preventDefault` 제거 ·
Ⓖ `›` 를 `data-ko` span 의 «자식» 으로 · Ⓗ `cursor:pointer` 제거 ·
Ⓘ `?menu=aitools` «받는» 절 삭제 · Ⓙ 부르는 이름 오타 · Ⓚ `›` 색을 CTA 금색으로 ·
**Ⓕ2 `.ht-what`(부모)에 `data-ko` 덧붙이기** · **Ⓔ2 `›` 를 `.ht-when` 의 data-ko span 안으로**

✅ 이 하니스는 **onclick 속성을 오려 내 `new Function` 으로 실제로 돌립니다.**
「여는 함수가 있으면 부르고 막는다」 옆에 **「없으면 «막지 않는다»(폴백이 산다)」를 짝으로**
두었습니다 — 짝이 없으면 «언제나 막기»(= 폴백이 죽은 버튼)도 통과합니다.

✅ `HERO_SRC=<사본>` 으로 소스를 가리킬 수 있습니다 — 변이시험 때 **공동 금지구역 파일을
직접 고쳤다 되돌리지 않아도** 됩니다.

### 브라우저 (`manual/home-hero-track-browser.mjs`)

| 변이 | 잡았나 |
|---|---|
| Ⓐ 옛 코드로 되돌리기(`<div>` + onclick 제거) | ✅ ❌5 |
| Ⓑ onclick 만 제거 (보이는데 안 열림) | ✅ ❌2 |
| Ⓒ `cursor:pointer` 제거 | 🚨 **못 잡음(❌0)** |

다음 사람이 그것을 «지키고 있는 것» 으로 읽지 않도록. CSS 계약 자체는 자동 하니스 ④절이 봅니다.

## 6-2. 함정 대조(trap-check)가 잡은 것 — 커밋 «뒤» 에 고쳤습니다

두 건 다 **제가 추가한 문서·주석** 에서 나왔고, 둘 다 **직접 다시 재서** 확인한 뒤 고쳤습니다.

### 🔴 ① `CLAUDE.md` 새 항목이 «표 셀 3개» 가 되어 렌더링에서 사라짐

📌 덧붙임을 기존 행의 **닫는 `|` 「뒤」** 에 붙였습니다. [잰 것] 그 줄은 파이프 3개인데
**`|` 로 끝나지 않았습니다**(앞뒤 줄은 3개 + `|` 로 끝남). 2열 표에 3번째 셀이 생기면
GFM 은 그 셀을 **버립니다** ⟹ 새로 적은 함정이 **사람이 읽는 화면에서 통째로 안 보입니다.**
(Claude 는 raw 로 읽어 학습은 되므로 «조용한» 사고입니다.)
→ 앞의 `|` 를 지우고 **행 끝에 `|`**. 바뀐 줄은 여전히 **하나뿐**입니다.

### 🔴 ② CSS 주석의 대비 주장이 **방향이 반대**

「가림막 위에 얹는 밝힘이라 대비는 **오히려 올라간다**」라고 적었는데,
글자가 «밝은 색 / 배경이 어두운» 구조라 **배경을 밝히면 대비는 내려갑니다.**

[잰 것 — 2026-09-20, 390×844, 글자를 `color:transparent` 로 지우고 픽셀 합성]

| | 평소 | hover·focus |
|---|---|---|
| 「종 A.i 학습」 | 17.60 | **13.87** ↓ |
| 「8」 | 9.45 | **7.45** ↓ |
| 「›」 | 9.44 | **7.43** ↓ |
| 「혼자서 · 아무 때나」 | 13.77 | **10.84** ↓ |

**전부 4.5 위라 오늘 피해는 없습니다.** 문제는 다음 사람입니다 — 그 문장을 믿고 글자를
낮추거나 hover 를 더 밝히면 그 자리에서 깨지는데 **아무도 다시 안 잽니다.**
→ 주석을 **실측값과 함께** 정정하고 「⛔ 더 손대려거든 픽셀로 다시 재라」를 붙였습니다.
⚠️ 제가 **평소만 재고 hover 는 안 쟀던 것**이 뿌리입니다.

### 🟡 ③ 자동 하니스가 «가장 있음직한 회귀» 를 못 잡고 있었음

「⛔ `<a>` 에 `data-ko` 가 없다」가 **`<a>` 여는 태그만** 봐서,
`.ht-what`(**중간 조상**)에 `data-ko` 를 덧붙이는 변이가 **20/0 으로 통과**했습니다(제가 재현).
그 변이의 실제 피해는 **`<b>8</b>` 과 `<i>›</i>` 가 DOM 에서 즉시 사라지는 것** —
CLAUDE.md 가 경고하는 결재함 배지 건 그 자체입니다.
→ 「트랙 안에서 `<b>`·`<i class="ht-go">` 를 **품은** `data-ko` 요소가 하나도 없다」로
**태그 짝을 세어** 넓혔습니다. Ⓕ2·Ⓔ2 가 이제 실제로 FAIL 나고,
**이름만 바꾸는 무해한 리팩터는 그대로 통과**합니다.

### 🟡 ④ 브라우저 하니스가 개수(8·9)를 글자로 못 박고 있었음

→ 「**감춰진 것 말고 전부** 나오는가」·「감춰진 것은 중국어 **한 칸뿐**인가」·
「중국어 학생에게는 **하나도 안 감춰지는가**」로 바꿨습니다.
변이로 확인: 게이트 삭제·칸 삭제는 **여전히 잡고**, **열 번째 도구를 정당하게 더하면 통과**합니다
(옛 `=== 8` 이었으면 멀쩡한 수리가 빨간불이었습니다).

### 🪤 ⑤ 그 브라우저 하니스가 **앞 회차의 `localStorage` 때문에 한 번 헛돌았습니다**

`mangoi_zh_learner` 가 프로필에 남아 「감춰진 칸이 한 칸」이 **`[]`** 로 나왔습니다.
→ `goto()` 가 회차마다 그 키를 **지우고**, ③이 «그 자리에서» 켜도록 고쳤습니다
(켜고 나서 다시 `goto()` 하면 지워집니다).

## 6-3. 손가락 표적만 넓혔습니다 — 보이는 것은 «한 픽셀도» 안 바뀝니다

[잰 것 — 2026-09-20] 2번 트랙의 실제 크기는 **360×640 / 390×844 에서 높이 34px,
430px 이상 36px**(폭 100px 안팎)입니다. WCAG 2.2 AA 의 «최소 표적 크기»(24×24)는
넉넉히 통과하지만 **Apple 44pt · Android 48dp 권장치보다 작습니다.**
학생 29,000명 대부분이 폰입니다.

⛔ **그렇다고 padding·높이를 키우면 안 됩니다** — 히어로 줄 높이가 함께 바뀌는데
그 배치는 **바로 전날 사장님이 시안을 보고 고르신 것**입니다.

✅ 그래서 **절대배치 가상요소**로 표적만 넓혔습니다 — 흐름 «밖» 이라 레이아웃에
0픽셀입니다.

```css
.home-tracks a.ht-track{ …; position: relative; }
.home-tracks a.ht-track::after{
  content:''; position:absolute; left:0; right:0; top:-5px; bottom:-5px;
}
```

⛔ **좌우는 0 입니다** — 넓히면 옆 트랙(1번)을 침범합니다.
⚠️ 늘어난 5px 은 `.home-tracks` 의 위아래 padding(8px) **안**이라 알약 밖으로 안 나갑니다.

[잰 것 — 세 폭에서 실제로 좌표를 1px 씩 훑어]

| 폭 | 보이는 상자 | 손가락 표적 | 레이아웃 |
|---|---|---|---|
| 360×640 | 34px | **44px** | 가상요소 on/off 비교 — **완전 동일** |
| 390×844 | 34px | **44px** | 완전 동일 |
| 1280×900 | 36px | **46px** | 완전 동일 |

⚠️ **투명이라 «보이는가» 로는 원리상 확인할 수 없습니다** — `elementFromPoint` 로
「트랙 위 3px 을 찍어도 이 `<a>` 인가」를 재야 합니다.
⛔ 그래서 이것을 「44px 로 키웠다」로 읽지 마세요 — **상자는 34px 그대로**입니다.

좌우로 6px 여는 변이는 안 걸립니다(실측 ❌0). **자동 하니스 ④절의 «좌우가 0인가»**
가 그것을 봅니다 — **둘이 짝**이고, 그 사실을 검사 주석에 적어 두었습니다.

## 6-4. 1번 트랙도 이었습니다 (2026-09-21)

> 사장님 — **「이거 두개 카드 연결된거야??」** → **「왼쪽은 1번, 오른쪽은 2번」**
> (1번 = 「망고아이란? ▸ 원어민 선생님과 1:1 / 1:2 수업」 카드)

### 왜

어제까지는 **오른쪽만** 눌렸습니다. 그런데 둘이 **같은 알약 안에, 같은 줄에, 같은 모양**으로
나란히 있어서 — 사장님도 「연결된 거야?」라고 물으셨듯 — **학생도 왼쪽을 누르고,
아무 일도 안 일어났습니다.** 차이는 `›` 한 글자뿐이었고 PC 의 hover 는 **폰에 없습니다.**
⟹ CLAUDE.md 의 「보이는데 안 눌리는 버튼」의 **뒷면**입니다.

### 무엇을

| | 왼쪽 1번 | 오른쪽 2번 |
|---|---|---|
| 누르면 | **원어민 1:1 / 1:2 수업 카드**(목록이 아니라 «자세히») | AI와 친구하기 목록 |
| 폴백 주소 | `/?menu=about-tutor` | `/?menu=aitools` |
| 표시 | **`›`** | `›` |

- `js/idx-about.js` — 그 항목에 **`key:'tutor'`**, `openAboutMangoi(key?)` 가 열쇠를 받게,
  파일 끝에 **`?menu=about-tutor` 받는 절**(선례: `idx-allmenu.js` 의 `?menu=all-menu`).
- `index.html` — 1번 트랙 `<div>` → `<a>` + `›`, `idx-about.js?v=8` → **`?v=9`**.

### 검토했다가 버린 방법

| 버린 것 | 왜 |
|---|---|
| **카드를 «번호»(`data-i`)로 열기** | 그 배열은 **실제로 순서가 바뀌었습니다** — 2026-09-09 에 «홍보영상» 이 맨 앞에 들어와 전부 한 칸씩 밀렸습니다. 번호로 가리키면 그날 조용히 남의 카드가 열립니다. |
| **제목 글자로 찾기** | 문구를 다듬는 순간 조용히 안 걸립니다. |
| **onclick 안에서 `.abm-item` 을 찾아 `.click()`** | `index.html`(공동 금지구역)에 논리가 들어가고, 위 둘의 약점을 그대로 가집니다. |
| **`?v=` 를 안 올리기** | 규칙이 **강제**합니다 — 안 올리면 immutable 캐시에 **옛 파일이 최대 1년** 남습니다(변이 Ⓧ 로 실측: 버전 가드가 `exit=1` 로 잡습니다). |

### ⚠️ `?v=` 한 글자는 공동 금지구역입니다

`idx-about.js` 를 고쳤으니 `index.html` 의 `?v=8 → 9` 가 **따라옵니다**(선례 2026-09-16).
글자 수가 같아 **첫 화면 예산은 0바이트**이고, 버전 원장(`test-harness/asset-versions.json`)도
**함께 커밋**해야 합니다(안 담으면 로컬만 초록이고 CI 가 빨간불 — CLAUDE.md 2장).

### 🔴 자동 하니스가 «진짜 구멍» 을 하나 잡았습니다

열쇠 판정을 **오려 내 실제로 돌리는** 검사를 넣자 그 자리에서 FAIL 이 났습니다 —

```
❌ 짝: 열쇠가 없는 항목에 빈 값으로 걸리지 않는다 — [2]
```

`BENEFITS` 에는 **`key` 를 안 단 카드가 대부분**이라, `__abmShowKey(undefined)` 가
`undefined === undefined` 로 맞아 **아무 카드나 열립니다.** 부르는 쪽의 `if (key)` 가
가려 주고 있었지만, **그 함수를 직접 부르는 자리가 생기는 날 조용히 뚫립니다.**
→ 막는 자리를 **그 함수 안**(`if (!k) return false;`)으로 옮겼습니다.

⚠️ 「그 함수가 있는가」로 물었으면 **영영 못 봤을** 종류입니다.

## 6-5. 곁가지 — 규칙서·목차의 표가 **뒷부분을 통째로 감추고 있었습니다** (2026-09-21)

§6-4 를 `docs/INDEX.md` 에 적다가, 제 행이 **칸이 3개**로 세어지는 것을 발견했습니다.

원인은 **표 칸 «안» 의 날것 파이프**입니다 — GFM 은 **코드스팬(백틱) 안이라도** 파이프를
칸 구분자로 셉니다. 머리글이 2칸이니 **세 번째 칸부터는 통째로 버려집니다.**

하필 제가 그 자리에 적고 있던 것이 「**닫는 `|` 「뒤」**에 붙여 셀이 3개가 됐다」는
바로 그 함정 설명이었고, **설명하려다 같은 함정을 다시 밟았습니다.**

### 전수로 세어 보니 제 실수 하나가 아니었습니다

| 파일 | 머리글보다 칸이 많은 행 |
|---|---|
| `CLAUDE.md` | **31** |
| `docs/INDEX.md` | **15** |

바로 그 함정을 적어 둔 **`CLAUDE.md` 219행 자신**도 그중 하나라, 2026-09-15 덧붙임의
**뒤쪽 202자가 닷새(그 줄이 들어온 #994 병합 2026-09-16 ~ 09-21) 동안 안 보이고 있었습니다.**

🔴 **처음에 이 자리에 「900자 · 몇 달째 · 43행」, INDEX 에 「3,500자」라고 적었는데 전부 틀렸습니다**
(함정 대조가 커밋 뒤에 잡아 다시 쟀습니다). 두 글자 수는 «버려진 부분» 이 아니라 **행 전체 길이**
(CLAUDE.md 219행 744자 · INDEX 87행 3,177자)를 잘못 옮긴 것이고, 실제로 버려진 것은 **202자 · 1,821자** 입니다.
「43행」은 **«백슬래시만 바뀐 행» 수**였고 «깨진 행» 수는 **46** 입니다.

⚠️ **「오래 앓던 병」도 아닙니다** — 46행을 `git blame` 으로 재니 마지막으로 손댄 날이
**2026-09-14 ~ 09-20** 에 몰려 있습니다(가장 오래된 것이 이레). INDEX 쪽 그 행은 **전날 제가 넣은 것**입니다.
⛔ 심각도를 부풀려 적으면 다음 사람이 엉뚱한 것을 고치러 갑니다.

⚠️ **원문에는 멀쩡히 있습니다** — `grep`·`git diff` 로는 영영 안 보이고,
**사람이 렌더링된 화면을 읽어야만** 드러납니다.

### 어떻게 고쳤나

«2번째 파이프와 마지막 파이프 사이» 의 **날것 파이프만** 기계로 `\|` 로 이스케이프했습니다
(2칸 표에서 첫 내부 파이프만 진짜 구분자이므로 결정론적입니다).

⛔ **남의 행을 만지는 변경**이라, 뜻을 바꾸는 편집이 섞이지 않았다는 근거를 따로 만들었습니다 —

```
백슬래시를 도로 떼면 글자 하나도 안 바뀐다  → 43행(내용을 안 건드린 행)에 대해 ✅
머리글보다 칸이 많은 행                      → 46 → 0
```

⚠️ 그 대조는 **내용까지 함께 고친 두 행**(`CLAUDE.md` 219 · `docs/INDEX.md` 87)에는 **성립하지 않습니다** —
그 둘을 포함해 돌리면 `false` 가 나옵니다(같은 커밋이 그 두 행에 설명도 함께 넣었기 때문). 처음에 「둘 다 ✅」라고
적은 것을 범위를 좁혀 고쳤습니다.

⚠️ **첫 판은 46행 중 한 행**(`CLAUDE.md` 「비용이 나가는 API」 행 — 코드스팬 안의 `\|\|`)**을 빠뜨려 1건이 남았고**,
같은 날 마저 고쳐 0건이 됐습니다. ⛔ **「0건으로 만들었다」는 다시 세어 본 뒤에** 적으세요.

⛔ 「몇 줄 바뀌었나」(30/30 · 15/15)로는 확인이 안 됩니다 — 한 항목이 한 줄이라
**뜻을 통째로 갈아도 같은 숫자**가 나옵니다(CLAUDE.md 가 이미 못 박아 둔 함정).

⚠️ **커밋 `5de52a0` 의 메시지에는 틀린 숫자(3,500 · 900 · 몇 달째 · 43→0)가 그대로 남아 있습니다** —
이미 push 된 커밋이라 고치려면 역사를 다시 쓰게 되어 두었습니다. **정본은 이 문서와 `CLAUDE.md` 219행**입니다.

### 한 줄 검사

```bash
python3 -c "
import io,re
for fn in ['CLAUDE.md','docs/INDEX.md']:
    h=None
    for n,r in enumerate(io.open(fn,encoding='utf-8').read().split(chr(10)),1):
        rs=r.rstrip()
        if not (rs.startswith('| ') and rs.endswith('|')): h=None; continue
        if re.match(r'^\|[\s:\-|]+\|\$', rs): continue
        c=len(re.split(r'(?<!\\\\)\|', rs))-2
        if h is None: h=c; continue
        if c!=h: print(fn,n,h,'->',c)
"
```
