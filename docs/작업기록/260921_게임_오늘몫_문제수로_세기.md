그런데 `/api/student/today` 의 게임 칸이

```sql
SELECT COUNT(*) FROM game_sessions WHERE uid = ? AND created_at >= ?
```

였습니다. ⟹ **웜업만 한 학생도 「게임 했음」** 이 되고, 「오늘의 A.i 학습」 카드는
웜업 칸을 **따로** 갖고 있으므로 **한 사람을 두 번** 세고 있었습니다.

⚠️ 에러가 안 납니다. 숫자가 조용히 부풀 뿐입니다.

## 3. 한 것

### 3-1. 두 축을 갈랐다 — «했나»(판 수) 와 «얼마나»(문제 수)

| | 쓰는 곳 | 왜 |
|---|---|---|
| `done.games` — **판 수** | 「했나」 판정 | `items` 를 아직 안 보내는 게임(escape-zombie·language-ace)이 «안 한 것» 으로 뒤집히지 않게 |
| `gameItems` — **문제 수**(`SUM(items)`) | 「오늘 몫」 막대 | 들락날락한 판은 0이라 저절로 안 세어진다 |

⛔ 한 칸에 담으면 둘 중 하나가 반드시 틀립니다.

### 3-2. 게임/학습도구 가르기는 **금지목록**

정본 `src/today-plan.ts`:
`NON_GAME_KINDS` · `isGameKind()` · `NON_GAME_SQL`.

⛔ **허용목록으로 뒤집지 않았습니다** — 새 게임이 하나 생기면 그날부터 조용히 빠져
그 학생 막대가 **영영 0**이 됩니다(빠지는 쪽이 훨씬 나쁩니다). 학습도구는 8종 고정이고
게임만 늘어나므로 «빼기» 가 저절로 맞습니다.

⛔ SQL 조건을 호출부에 베끼지 않았습니다 — 목록이 늘 때 한 곳만 고쳐지는 사고를 막습니다.

### 3-3. 목표는 **5문제**

`TOOLS.games.goal = 5` **한 줄**입니다(바꾸기 쉽게).

근거: 실제로 푼 40일의 **중앙값 6** 보다 조금 아래. 「평소 하던 만큼」이면 채워집니다.
전 기간으로 치면 65일 중 26일(40%)·푼 날 40일 중 26일(65%)이 달성입니다.

⛔ **「판 수」로 두지 않았습니다** — 아무것도 안 하고 세 번 들락날락해도 달성이 됩니다.
(그것이 이 칸이 여태 비어 있던 이유이기도 합니다. 그 반론은 「문제」로 세면 사라집니다.)

### 3-4. 화면

- **게임 허브** 맨 위(`js/games-daily-goal.js`, defer): 「2 / 5문제 · 3문제 더!」 + 막대
- **「오늘의 A.i 학습」** 게임 칸: 같은 숫자

⛔ 화면이 숫자를 **다시 계산하지 않습니다** — 서버가 준 `goal`·`progress` 를 그리기만 합니다.
두 화면이 따로 세면 답이 갈립니다.

✅ **0도 「0 / 5문제」라고 글자로 말합니다** — 빈 막대는 «측정 안 됨» 으로 읽힙니다.

### 6-1. 🪤 변이시험이 내 검사 셋을 «무방비» 로 잡았다

만들자마자 51종이 전부 초록이었는데, 되돌려 보니 **셋이 아무것도 안 재고 있었습니다.**

1. **`require` 를 빈 스텁으로 둬서 정본이 다른 갈래로 빠졌다**
   `today-plan.ts` 가 `judgment-level` 에서 `BAND_COUNT` 를 가져오는데 그것이 `undefined` 라
   `band <= undefined` 가 false → 계획이 **언제나 «레벨 미배정»** → `games` 칸이 **한 번도 안 생김**.
   그 칸을 보는 검사가 `if (gs)` 안에 있어 **FAIL 이 아니라 조용히 사라졌습니다.**
   → `esbuild.buildSync({bundle:true})` 로 의존성까지 번들. 못 찾으면 **건너뛰지 말고 FAIL.**

2. **「`goalBar(s)` 를 부르는가」가 «선언» 에 걸렸다**
   `function goalBar(s)` 가 그 정규식에 맞아, **호출을 통째로 지워도 통과**했습니다.
   CLAUDE.md 가 이미 적어 둔 함정을 그대로 밟았습니다 → 선언을 지운 사본에서 «호출» 로 물음.

3. **`data-ko` 를 HTML 문자열로만 봤다**
   `el.setAttribute('data-ko', …)` 로 상자에 다는 변이를 못 봤습니다 → «모양» 으로 금지.

### 6-2. 🪤 브라우저 검사에서 밟은 둘

- **`addScriptToEvaluateOnNewDocument` 가 쌓였습니다** — 1회차 스텁이 끝까지 살아
  «비로그인» 회차에도 로그인을 심고 fetch 를 가로챘습니다. 회차마다 `remove` 합니다.
- **`about:blank` 에서 `localStorage.clear()`** 를 불렀는데 그건 **그 오리진**을 지울 뿐,
  검사 대상 오리진은 그대로였습니다 → CDP `Storage.clearDataForOrigin`.

### 6-3. 🪤 CSS 주석의 홑낫표

`admin_lazyload_harness` 가 `<style>` 안 CSS 주석까지 세어 **「」 두 자**로 「한자 폰트를
부른다」고 빨간불이 났습니다. 화면에는 한 글자도 안 보이는 설명 주석입니다 → « » 로.
