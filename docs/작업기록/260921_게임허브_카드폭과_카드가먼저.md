# 게임 허브 — 카드가 화면 폭을 쓰게 + 카드를 맨 앞으로 (2026-09-21)

> 사장님 제보(스크린샷 첨부): 「카드가 보이지 않아. 카드가 보이게 해줘. **가장 처음에 보이게 해줘**」
> 이어서 「사진가 동영상 단어 맞추기 카드 얘기하는거야」 — 게임 카드 21장 전부가 사진 썸네일을 답니다.

## 1. 왜 했나 · 무엇이 원인이었나

스크린샷은 1920px 화면인데 카드가 가운데 아주 좁은 띠에만 몰려 있었습니다.
**원인이 둘이고 하나는 사장님 쪽, 하나는 코드 쪽입니다 — 갈라서 봐야 합니다.**

### ① 「작다」 = 브라우저 확대 25% (사장님 쪽)

스크린샷의 카드 한 장이 **88px** 인데 코드가 그리는 값은 **352px** 입니다. 정확히 **1/4**.
브라우저 메뉴 글자 크기는 그대로인 것이 그 증거입니다(페이지 확대만 내려간 상태).
`Ctrl` + `0` 으로 돌아옵니다.

### ② 「가운데 좁은 띠」 = 코드 (진짜 결함)

`.game-grid` 의 폭이 **`width:min(1100px,100%)`** 로 못 박혀 있었습니다.
로컬 서버 + 크로미움 실측(SW 우회 · 캐시 끔 · `?_nc=` 캐시버스터):

| 화면 폭 | 그리드 폭 | 열 | 카드 시작 y |
|---|---|---|---|
| 1920×1080 | **1100px** | 3 | 477 |
| 3840×2160 | **1100px** | 3 | 477 |
| 7680×2160 | **1100px** | 3 | 477 |

즉 **화면이 아무리 넓어도 1100px 3열** 이고, 7680px(=확대 25% 일 때의 실효 폭)에서는
화면의 **14%** 만 씁니다. 사장님이 보신 그 띠입니다.

### ③ 「가장 처음에」 = 카드 위에 463px (폰은 688px)

| 블록 | 1920px | 390px(폰) |
|---|---|---|
| `.hub-topnav`(←/🏠/🔊) | 38 | 38 |
| `.hub-head`(브랜드·제목·설명·컨트롤 패널) | 298 | 421 |
| `.quest-bar`(🎯 퀘스트 안내) | 95 | **228** |
| `.order-bar`(🖐 순서 바꾸기) | 34 | 34 |
| **카드 시작** | **477** | **688** |

폰은 화면 높이가 640~844px 이라 **카드가 첫 화면 밖**이었습니다.

## 2. 바꾼 것

1. **폭 정본을 한 곳으로** — `#app{--hub-w:min(2200px,100%)}` 를 두고
   `.game-grid` 와 `.hub-panel` 이 **같은 변수**를 씁니다.
   그 패널 주석이 원래 「아래 카드 그리드와 **같은 가로폭**」이라고 약속하는데
   숫자가 두 곳에 따로 적혀 있었습니다. 이제 한 곳입니다.
   `minmax(280px,1fr)` → `300px` 로 함께 올려 **카드 크기는 그대로 두고 열 수만** 늘립니다.
2. **머리글의 좌우 여백을 글자 쪽으로** — `.hub-head` 에 좌우 padding 이 있으면
   그 자식인 패널의 `100%` 가 «머리글 내용폭» 이라 패널만 32px 좁아집니다(실측 1841 대 1873).
   여백을 `.brand`·`h1`·`.sub` 로 옮기고 `.hub-head{width:100%}`.
3. **🖐 순서 바꾸기 줄은 카드 아래로** — 카드보다 먼저 읽을 줄이 아닙니다.
4. **🎯 퀘스트 안내 바는 «폰에서만» 카드 아래로**(`order`) — 아래 3장 참고.
5. **폰에서 제목이 가려지던 것** — `.hub-topnav` 가 `position:absolute` 라
   「MANGOI · LEARNING GAMES」 글자 위에 떠 있었습니다(안내음성 말풍선이 뜨면 더 심합니다).
   좁은 화면에서만 흐름 안으로 되돌리되 **`width:100%` 를 함께** 줬습니다(4장 참고).

|---|---|---|---|---|
| 1920×1080 | **1873px** | **5** | 357 | 357×482 |
| 1280×800 | 1233px | 3 | 478 | 396×486 |
| 3840×2160 | **2200px** | **6** | 357 | 348×475 |

## 3. 검토했다가 버린 것

- **퀘스트 안내 바를 모든 폭에서 카드 아래로 내리기** — 처음에 그렇게 했다가 되돌렸습니다.
  그 바에는 「🎫 레벨테스트로 한 번에 열기」·「🔓 전체 열기」 **버튼**이 있고,
  그 자리 코드 주석이 「잠긴 카드를 눌러야만 보이면 **존재를 모르는 학생이 생긴다**」고
  적어 둔 것이 그 바가 있는 이유입니다. 카드가 **21장**이라 폰에서는 11행을 지나야 나옵니다.
  ⟹ 넓은 화면(62px 이라 첫 화면을 안 밀어냄)은 카드 위 그대로, **폰에서만** `order` 로 내립니다.
  «설명은 내려도 되지만 버튼은 다르다» 가 갈림길이었습니다.
- **컨트롤 패널(코인·룰렛·상점·랭킹 / 언어 / 속도)을 통째로 카드 아래로** — 폰에서 262px 를
  먹는 가장 큰 덩어리지만, **언어(영어/중국어)는 게임 출제 언어**라 카드 위에 있어야 합니다.
  쪼개서 언어만 남기는 것은 이 화면의 구성을 바꾸는 일이라 **사장님이 정하실 일**로 남겼습니다.
- **`.sci-banner`(학부모·선생님용 안내)도 `--hub-w` 로 넓히기** — 안 넓혔습니다.
  2026-08-03 에 「학생 카드보다 눈에 덜 띄게, 카드를 다 지나온 자리에」로 정한 줄이라
  1100px 로 좁게 두는 것이 그 결정을 지키는 쪽입니다. 대신 **주석을 고쳤습니다** —
  「게임 그리드와 같은 식을 쓴다」가 이번 변경으로 거짓이 되었기 때문입니다.
- **상한을 더 크게(2600px 이상)** — 2200px 에서 멈췄습니다. 그보다 넓으면 한 줄에 7열이 넘어
  카드가 작아지고, 컨트롤 패널이 같은 폭이라 텅 빈 유리 막대가 됩니다.
- **`?v=` 올리기** — js·css 파일을 한 개도 안 고쳤습니다(HTML 안 인라인 CSS·마크업만).
  `asset_version_harness` 의 의무는 «파일 내용이 바뀐 js/css» 에만 걸립니다.

## 4. 밟은 함정

- **`position:absolute` 를 흐름 안으로 되돌리면 «가운데로 이사합니다».**
  `#hub-menu` 가 `align-items:center` 라 `left:12px; right:12px` 가 무시되면서
  뒤로가기 ← 가 좌상단 → 상단 중앙으로 말없이 옮겨졌습니다(폰 스크린샷으로 발견).
  `width:100%` 를 함께 줘서 제자리로 돌렸습니다.
- **`order` 를 쓰면 뒤따르는 형제의 차례도 함께 적어야 합니다.** 기본값이 0 이라
  안 적은 형제가 앞으로 옵니다 — `.order-bar`·`.sci-banner`·`.hub-tail` 까지 함께 적었습니다
  (마지막 블록에는 클래스가 없어서 `hub-tail` 을 새로 달았습니다).
- **`<style>` 안 CSS 주석의 「」** — `admin_lazyload_harness` 가 한자 폰트 장식문자로 보고
  FAIL 냅니다. 이 작업에서 한 번 밟아 전부 `« »` 로 바꿨습니다.

## 5. 확인한 방법

- 로컬 서버(`python3 -m http.server`) + 컨테이너 크로미움 CDP.
  **`Network.setBypassServiceWorker` + `setCacheDisabled` + `?_nc=<시각>` 셋 다** 켰습니다
  (안 켜면 서비스워커가 옛 사본을 줘서 «고쳤다» 가 조용히 통과합니다).
- 다섯 폭(1920·1280·3840·390·360)에서 `getBoundingClientRect()` 로
  그리드 폭·열 수·카드 시작 y·패널 폭·가로 넘침을 재고, 1920·390 은 스크린샷으로 눈 확인.
- 회귀 하니스 `--fast` **PASS 286 / SKIP 20**(기준선 유지) · 콘솔 오류 0 ·
  `<style>` 안 CJK 장식문자 0.
- 함정 대조(`trap-check`) 1회 — 위 3·4장이 그 지적을 반영한 것입니다.
