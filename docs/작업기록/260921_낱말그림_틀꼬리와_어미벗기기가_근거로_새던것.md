# 낱말 그림 근거 — 「틀 꼬리」와 「없는 어미 벗기기」가 근거로 새던 것

**날짜** 2026-09-21 (저녁)
**브랜치** `claude/nice-wozniak-9q1qvm`
**앞선 작업** `260921_낱말그림_뜻과_안맞는_연결_기준교체.md` · `260921_모든낱말에_그림_낱말그림카드.md`

## 1. 왜 했나

사장님 지시(그림문자 카드를 실사 사진으로 · 문장에는 동영상도)에 따라 **영상 505편**을
만들어 붙이려던 중, 새 클립을 근거 판정에 넣어 보다가 **판정이 이미 새고 있는 것**을 찾았습니다.

「nice 카드에 가방 사진」 사고를 고치며 세운 규칙은 「그 그림을 만들 때 쓴 **설명**이
그 낱말을 가리킬 때만 «낱말 그림»」이고, 껍데기 낱말(설명의 80% 이상에 나오는 것)은
근거에서 뺀다는 것이었습니다. 그 게이트를 **두 갈래가 비켜 가고 있었습니다.**

---

## 2. 잰 것

### ⓐ 틀 꼬리가 `prompt` 를 타고 들어옴

모든 영상 프롬프트에 붙는 고정 꼬리가 이것입니다.

```
Natural light, realistic setting. No writing, logos, subtitles, labels or overlays.
```

`light` · `setting` · `writing` · `subtitles` 네 낱말은 **교재에 실제로 있는 낱말**인데,
껍데기 게이트(80%)에는 **못 미쳐** 안 걸립니다(클립만 세면 100% 지만 낱말 사진 1,511개와
함께 세므로 비율이 내려갑니다).

| 낱말 | prompt 를 근거에 넣었을 때 | 설명(visual·action)만 볼 때 |
|---|---|---|
| light | 클립 549편 **전부** | 34편 |
| setting | **전부** | 2편 |
| writing | **전부** | 2편 |
| subtitles | **전부** | 0편 |

### ⓑ `variants()` 가 «있지도 않은 어미» 를 잘라 기능어를 만들어 냄

```
variants('thing') → thing, things, …, th, the     ← 관사 "the"
variants('ones')  → ones, …, on, one              ← 전치사 "on"
variants('toes')  → toes, …, to, toe              ← 전치사 "to"
variants('used')  → used, …, us, use              ← 대명사 "us"
```

그 기능어는 설명마다 들어 있으니 —

⚠️ 아래는 **클립 549편(기존 44 + 새로 받은 505) 기준**입니다.
처음 잴 때는 저장소에 44편뿐이라 95.5%·45.5%·18.2% 로 적었는데,
클립이 늘자 그 숫자가 그대로 거짓이 됐습니다 — **인용하기 전에 다시 재세요.**

| 낱말 | 클립 그림 549개 중 | 비율 | 고친 뒤 |
|---|---|---|---|
| thing | 426 | **77.6%** | 0 |
| ones | 312 | 56.8% | 3 (0.5%) |
| toes | 74 | 13.5% | 3 (0.5%) |

즉 「clear·natural·subjects 가 모든 그림에 붙는다」와 **같은 사고**가 낱말 쪽에서
한 번 더 일어나고 있었습니다.

### ⚠️ 에러가 안 납니다

그림도 설명도 «있고» 틀린 것은 «그 낱말을 보여 주는가» 뿐이라, 수리 전에도
`scene_curriculum_harness` 가 전부 초록이었습니다.

## 3. 고친 것

**정본은 `scripts/scene-picture-evidence.mjs` 한 곳**(빌드와 하니스가 같은 모듈을 돌립니다).

### ⓐ 설명이 있으면 prompt 는 보지 않는다

```js
const clipRaw=c=>((c.visual||c.action)?[c.visual,c.action]:[c.prompt]).filter(Boolean).join(' ');
```

`prompt` 안에 든 것은 **같은 설명 + 틀**뿐이라 잃는 것이 없습니다.
⛔ 틀 낱말 목록을 손으로 적어 빼지 않았습니다 — 틀이 바뀌면 조용히 낡습니다.
설명이 «없을 때만» prompt 로 떨어집니다.

**실측: 「낱말 사진」 근거 판정(word-image 1,401건 중 1,398건 통과)과 껍데기 15개는 그대로.**

⚠️ 「판정이 한 건도 안 바뀐다」로 적으면 거짓입니다 — 클립 그림을 근거로 삼던 **🖼 줄은
`wordPictureRows` 7,240 → 7,210 으로 30줄 줄어듭니다**(빌드 A/B). 그 30줄이 바로
「이 그림이 light·setting 을 보여 준다」던 거짓 근거라, 줄어드는 것이 이 수리의 목적입니다.

### ⓑ 기능어도 근거에서 뺀다

```js
tokens(describe.get(key)).filter(t=>!shell.has(t)&&!stopWords.has(t))
```

근거는 **교재가 스스로 «뜻이 없다» 고 정해 둔 낱말**(`stopwords.json` 226개)이
설명에 있다고 무엇이 그려졌는지 한 글자도 알려 주지 않는다는 것입니다.

⛔ `variants()` 에서 그 넷을 손으로 빼지 않았습니다 — 어미 규칙이 바뀌면 조용히 낡습니다.

**A/B 실측**

| | 교재 낱말 최대 비율 | 낱말 사진 통과 | 🖼 줄 |
|---|---|---|---|
| 고치기 전 | `thing` **77.6%**(426/549) | 1,398 | 7,211 |
| 고친 뒤 | `hand` 26.0%(143/549) | **1,398 (동일)** | 7,210 |

`go`·`toe`·`use` 는 기능어가 아니라 그대로 살아 있으므로 **멀쩡한 매칭은 하나도 안 잃습니다.**

### ⓒ 배포된 payload 재빌드

근거 판정이 바뀌면 이미 빌드된 payload 가 낡습니다.
실제로 `subtitles` 한 낱말이 빠져 **`bts-31` 한 권**만 바뀌었습니다.

## 4. 감시 — «결과» 로 묻는 새 검사

「껍데기 80%」 게이트는 위 둘을 **원리상 못 봅니다**(꼬리는 80%에 못 미치고,
기능어는 «낱말 쪽» 에서 생깁니다). 그래서 결과로 묻습니다.

> **어느 교재 낱말도 클립 그림의 절반을 넘게 가리키지 않는다**

실측 최대가 **26.0%**(549편 · `hand` 143개)라 **절반은 «정상» 과 «샘» 사이에 넉넉히**
떨어져 있습니다. 짝으로 **「그래도 가리키는 낱말이 있다」**를 둡니다 —
없으면 «근거를 통째로 죽이기» 도 통과합니다.

### 🪤 그 검사가 처음엔 원리상 헛돌았습니다

하니스가 정본에 «안 묻고» 자기가 토큰을 다시 걸러 셌습니다.
그러니 **모듈에서 기능어 거르기를 통째로 지워도 486,407건이 전부 초록**이었습니다(실측).
→ 반드시 **정본 `depicts()` 에 물어서** 세도록 고쳤습니다.

### 변이시험 — 3종 전부 실제 FAIL

| 변이 | 결과 |
|---|---|
| Ⓐ 기능어 거르기 제거 | ❌ `최대 thing 426/549 = 77.6%` |
| Ⓑ `clipRaw` 되돌리기(prompt 를 근거에) | ❌ `최대 light 549/549 = 100.0%` |
| Ⓒ 껍데기 게이트 끄기 | ❌ `껍데기 낱말은 사진이 있어도 «낱말 그림» 이 되지 않는다` |

## 5. 검토했다가 버린 것

| 버린 방법 | 왜 |
|---|---|
| `variants()` 에서 `the`·`on`·`to`·`us` 를 손으로 뺀다 | 어미 규칙이 바뀌면 조용히 낡습니다. «교재가 기능어라고 정한 것» 이 훨씬 오래 갑니다 |
| 어미 벗기기 스템을 3글자 이상으로 제한 | `goes→go`·`does→do` 같은 **멀쩡한 스템을 함께 잃습니다** |
| 껍데기 문턱을 80% → 50% 로 내린다 | `child`·`smile` 같은 진짜 사물 낱말까지 근거에서 빠집니다 |
| 클립 프롬프트의 꼬리를 빼고 다시 생성 | 505편을 다시 만들어야 하고(비용) 이미 만든 44편은 못 고칩니다 |
| 새 검사를 「토큰 빈도 80%」로 | `a`·`the` 가 언제나 100% 라 뜻을 잃습니다. **교재 낱말**로 물어야 합니다 |
