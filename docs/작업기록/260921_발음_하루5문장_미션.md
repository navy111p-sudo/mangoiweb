## 4. 검토했다가 버린 것

| 버린 것 | 왜 |
|---|---|
| **100문장 세트를 5문장짜리로 쪼개기** | 유닛 구조(`STEPS`)를 건드리면 「이어서 하기」·완주 보상(`speech_master`)·진도 표시가 전부 걸립니다. 세트는 그대로 두고 «오늘 몫» 만 얹는 쪽이 반경이 훨씬 작습니다 |
| **`speech_master`(20점) 재사용** | 그것도 `GAME_QUIZ_RULES` 라 20+20 = **40 > 30**(게임 하루 통). 같은 날 유닛을 완주하면 둘 중 하나가 막힙니다. 10점으로 두면 10+20 = **정확히 30** |
| **화면이 localStorage 로 세기** | 기기를 바꾸면 0 이 되고, 같은 문장 재녹음을 «문장» 으로 셉니다. 서버가 DISTINCT 로 셉니다 |
| **새 적립 경로 만들기** | `/api/points/earn-by-rule` 이 이미 본인확인·쿨다운·하루 상한(총량 100 · 게임 30)·원장 기록을 전부 지납니다. 새로 만들면 그 상한을 다시 배선해야 합니다 |
| **중국어 화면(`speech-coach-cn.html`)에도 달기** | 그 화면은 **서버 채점을 안 부릅니다**(브라우저 인식만) → `voice_coaching` 에 행이 안 쌓입니다. 미션 줄을 달면 **언제나 0** 이라 거짓말이 됩니다 |
| **5문장을 채우면 녹음 버튼 잠그기** | 반대 방향 사고입니다. 더 하려는 학생을 막습니다 |

### ⚠️ 보고서와 다르게 한 것 — 「깎기」가 아니라 「막기」

보고서에는 「보상은 «막기» 가 아니라 «남은 만큼 깎기»」라고 적었는데,
실제로는 기존 `earn-by-rule` 경로(= `checkEarnAllowed` → **막기**)를 썼습니다.

- `dailyAllowance`(깎기)는 **한 판에 수백 점이 걸리는 경로**(단어장 400·복습퀴즈 500)를
  위한 것입니다. 10점은 「0 아니면 전부」의 대가가 작습니다
- 대신 **막혔을 때 화면이 서버 문구를 그대로 말합니다**(`message_ko`/`message_en`) —
  「고장」으로 읽히지 않게

⟹ 깎기로 바꾸려면 `earn-by-rule` 경로 전체가 걸리는 별건입니다.

## 5. 🪤 밟은 함정

### ㉠ grid 자식의 좌우 `auto` 마진 — 칸이 «글자 폭» 으로 쪼그라듦

`.wrap` 은 ≥1024px 에서 `display:grid` + `.wrap > * { grid-column: 2 }` 입니다.
그리드 자식에 `margin: 14px auto 2px` 를 주면 **stretch 가 꺼져** 글자 폭만큼 줄어듭니다.

- **1280px 실측: 칸 654px 이 될 자리가 129px**
- 코드에는 `max-width:760px` 이 멀쩡히 있어 **파일만 봐서는 안 보입니다**
- 고침: `margin: 14px 0 2px`

### ㉡ CSS·JS 주석의 CJK 홑낫표 「」 — 규칙서에 이미 있는데 또 밟음

`subtitle_meaning_harness`·`admin_lazyload_harness` 가 `<style>` 을 **느슨하게** 잡아
JS 주석까지 셉니다. 「」 8곳을 `« »` 로 바꿨습니다. **두 번 밟았습니다**(수리 중 한 번 더).

### ㉢ `_scIsEn()` — `window.getLang` 이 «아직 없을» 때

브라우저 실측에서 **영어로 들어왔는데 한국어 줄**이 나왔습니다.
`mango-i18n.js` 가 실리기 전에 서버 응답이 먼저 도착한 것입니다(스텁·캐시·빠른 회선).

- 고침: `getLang` 이 있으면 그것을, 없으면 **`localStorage['mangoi_lang']`** 을 봅니다
- ⚠️ **자동 하니스는 이것을 원리상 못 봅니다**(가짜 상자가 `getLang` 을 늘 정의해 줌)
  → 브라우저 검사 ④절이 맡습니다(그 폴백을 지우면 **2건 FAIL**)

### ㉣ `scLoadMission` 이 «적립을 안 했음»

주석에는 「적립 요청은 그때도 한 번 한다」고 적어 놓고 `scRenderMission` 만 부르고
있었습니다. **적어 둔 것 ≠ 하는 것.** `scApplyMission` 으로 고쳤습니다.

### ㉤ 통신 실패에 표시를 남겨 그날 10점이 조용히 사라짐

`localStorage` 표시를 fetch 「전」에 쓰고 실패에 안 지웠습니다.
「서버가 답을 안 줌」과 「이미 받았음」은 다른 사실입니다 → `.catch` 에서 지웁니다.

### ㉥ 하니스가 «크래시» 로 결과줄을 안 냄

`scRenderMission` 이 `_scIsEn()` 을 부르는데 그 함수를 함께 오려 내지 않아
`ReferenceError` → 하니스가 죽어 **무엇이 깨졌는지 안 보였습니다**.
`_scIsEn` 도 소스에서 오려 내 주입하고, 던져도 **깔끔한 FAIL** 이 되게 고쳤습니다.

### ㉦ 🔴 함정 대조가 잡은 것 — 하니스가 «배선» 을 한 줄도 안 쟀습니다

커밋 전 `trap-check` 가 `/tmp` 사본에 변이를 **실제로 넣어 돌려** 알려 줬습니다.
**PASS 77 / FAIL 0 인 채로 네 변이가 전부 통과**했습니다:

| 변이 | 뜻 | 그때 결과 |
|---|---|---|
| `scApplyMission` 의 `scClaimMission(m)` 삭제 | **보상이 아예 안 나감** | 통과 |
| `try { scLoadMission(); }` 삭제 | 들어올 때 줄이 **안 뜸** | 통과 |
| 들어올 때 `scApplyMission`→`scRenderMission` | **㉣ 버그 되돌리기** | 통과 |
| `.catch` 의 `removeItem` 삭제 | **㉤ 버그 되돌리기** | 통과 |

㉣·㉤ 는 **이 작업에서 방금 고친 버그**인데 **되돌림을 막는 검사를 안 둔** 것이었습니다.

그리고 「호출이 있는가」를 `scLoadMission\s*\(\s*\)` 로 물어서 **함수 «선언» 이 잡혔습니다**
— 호출을 통째로 지워도 통과합니다. CLAUDE.md 에 **이미 두 번** 적힌 함정의 세 번째입니다.

✅ **⑧-2 절**을 새로 만들어 세 함수를 오려 내 **가짜 fetch·가짜 localStorage 로 실제로 돌립니다.**

### ㉧ 🔴 `fetch` 가 401·404 에 reject 하지 않습니다 — ㉤의 나머지 절반

`earn-by-rule` 은 실패를 **JSON 본문으로** 돌려줍니다(`auth_required` **401** ·
`rule_not_found_or_disabled` **404**). 둘 다 `r.json()` 이 **성공**하므로 `.catch` 로 안 옵니다
⟹ 네 갈래 어디에도 안 걸려 **화면은 아무 말도 안 하고 표시는 남아** 그날 10점이 사라집니다.

✅ `r.ok` 를 따로 봅니다. 상한 오류(`daily_total_cap_reached` 등)는 **200** 이라 표시를 남깁니다
(= 「서버가 제대로 답했다」).

### ㉨ 게스트 판정이 실계정을 삼킬 뻔했습니다

`/^guest/i` 는 **`guestavo`·`guesthouse` 같은 실계정**을 게스트로 오판합니다.
그러면 그 학생은 줄도 보상도 영영 못 받는데 **에러가 안 납니다**.
⟹ `/^guest(_|$)/i`(저장소가 실제로 만드는 모양: `guest`·`guest_xxxx`·`guest_zh_xx`·`guest_fb`).
⚠️ 하니스가 그 오판을 **«정답» 으로 못 박고 있었고**, 그 짝 검사는 `A && B || C` 우선순위라
**언제나 통과**하는 죽은 검사였습니다 — 둘 다 고쳤습니다.

### ㉩ CSS 규칙을 **행 번호**로 가리켰습니다 — 이미 4줄 어긋나 있었습니다

주석에 「(166행 `display:grid`)」라고 적었는데 실제는 **170행**이었습니다.
CLAUDE.md 가 「⛔ 행 번호로 가리키지 마세요 — 선택자 문자열로」라고 못 박은 자리입니다.

### ㉪ 대비(글자가 읽히는가)를 **한 번도 안 쟀습니다**

색을 줘 놓고 재지 않았습니다. 🔴 이 화면 `body` 는 **사진 배경**이라
CSS 합성으로는 **원리상 못 잽니다** — 글자를 잠깐 `color:transparent` 로 만들고
그 자리를 찍어 픽셀로 재야 합니다.

**[잰 것]** 진행 중(앰버) **10.6** · 다 채움(초록) **9.21** — 필요 4.5, 둘 다 통과.

⚠️ 그 변이를 넣을 때 `color: #fbbf24; line-height` 로 치환했더니 **파일에 2곳**이라
