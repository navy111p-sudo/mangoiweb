## 3. 고친 것

### ① 학생 명부 「예약」 칸 — 도입(9/15) 이래 100% «—» 였다

정본 `src/student-schedule-summary.ts` 를 **실제로 돌려 보니** jeong 에게 「주 4회」를
정확히 만들고 있었다. 값이 화면에 못 온 이유가 **두 겹**:

- 그 값을 싣는 곳은 `erp-list` 인데 **명부 표가 부르는 것은 `/api/admin/students/unified`**
- 화면이 응답을 `apiItems` 로 **다시 매핑하며 칸을 골라 담는데** 거기에 `sched` 가 없었다

전용 하니스 32종이 전부 초록이었던 이유 — **정본 함수만 돌려 보고 배선을 한 줄도 안 봤다.**

고침: `api-admin.ts` 의 unified 응답에 `loadSchedSummaryMap` 을 싣고(erp-list 와 «같은» 정본),
`adm-core.js` 매핑에 `sched: s.sched || null` 한 줄.

⛔ 왼쪽 네 칸을 이 값으로 «채우지» 않았다 — 뜻이 다르다(수강 종료일에 마지막 예약일을
넣으면 수업을 더 잡을 때마다 늘어나 거짓이 된다).

### ② 끝난 «날짜 지정» 수업이 홈·주간 표에 남던 것

서버 `/api/class/schedule/mine` 이 `status != 'cancelled'` 만 보고 지난 날짜를 안 걸렀다.
**실측: 지난 날짜인데 「활성」인 행 1,808건 · 학생 495명** — jeong 만의 일이 아니었다.

소비자가 **둘**(홈 카드 `js/idx-my-schedule.js` · 주간 표 `my-schedule.html`)이고 **둘 다
같은 사고**여서 화면이 아니라 **서버에서** 걸렀다(판정을 두 곳에 복제하면 어긋난다).

판정은 **이미 계산하던 `next_start_ts` 하나를 재사용**한다(= 시작+길이+15분 유예가 지났는가).
⛔ filter 에서 날짜를 다시 재지 않는다. 내부 표시 `_past` 는 응답에서 떼고 준다.

### ③ 「이 날 하루만」·「지난 수업」을 화면이 말하게

「정규수업」 배지는 `class_type`(수업 **종류**)이고 반복 여부는 `schedule_kind` 인데,
화면 차이가 🔁/📅 아이콘뿐이라 하루짜리를 매주로 읽게 되어 있었다.

`admin/student.html` 에 최상위 함수 `mgsOnceInfo()` 를 두고 스케줄 줄에 칩 둘을 붙였다
(한/영 병기). 색은 흰 카드에서 읽히는 `#b45309`(대비 5.02) — `#fbbf24` 는 1.67 이라 안 읽힌다.

## 4. 검토했다가 버린 것

| 안 한 것 | 왜 |
|---|---|
| **화면(`idx-my-schedule.js`)에서 지난 수업 거르기** | 소비자가 둘인데 `my-schedule.html` 도 같은 사고였다. 화면에서 거르면 그쪽은 그대로 남고, 나중에 소비자가 늘면 또 밟는다. |
| **9/14 수업(id 2479)을 D1 에서 취소 처리** | 개발·운영이 같은 DB 이고, 지우면 그 기록이 사라진다. **사장님이 정할 일**(CLAUDE.md 1-1). |
| **왼쪽 네 칸을 예약값으로 채우기** | 뜻이 다르다(위 ①). |
| **배지 라벨 자체를 「1회 수업」으로 바꾸기** | `class_type` 은 수업 종류이고 급여·리포트가 그 값을 쓴다. 라벨을 바꾸면 그쪽이 흔들린다 — **칩을 옆에 더하는** 쪽이 반경이 작다. |
| **캘린더의 수강신청 레이어 손대기** | 곁가지로 찾은 별건(아래 5장). 사장님 판단이 필요하다. |

## 5. 곁가지로 찾았지만 안 고친 것

**캘린더 금요일의 「체험수업」은 실제로는 없는 수업이다.** 수강신청(9/11, ~10/11)은
`confirmed` 로 살아 있는데 그 신청으로 만든 수업 4회가 전부 취소됐고, 캘린더의
수강신청 레이어(`admin/student.html`)에는 **`status` 검사가 한 줄도 없다**
(바로 아래 AI 스케줄 레이어에는 `if (sch.status === 'cancelled') continue;` 가 있다).

⚠️ `enrollments` 14건이 지금 **전부 `confirmed`** 라 그 누락 자체의 실피해는 **0건**이다.
jeong 의 금요일 칸은 「취소된 신청을 그린다」가 아니라 「신청은 살아 있는데 수업은 다
취소됐다」는 **두 표의 어긋남**이다. 어떻게 그릴지는 사람이 정할 일.
