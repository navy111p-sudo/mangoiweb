# 장면 탐험 — 못 맞히면 그 장면에 갇히던 것을 「넘어가기」로 풀었습니다

**날짜** 2026-09-21 · **브랜치** `scene-quest-skip-button`
**고친 것** `cloudflare-deploy/public/student-game-scene-quest.html` · `cloudflare-deploy/public/js/scene-quest.js`

---

## 1. 왜 했나

사장님 화면(SCENE 2/5 「꼬마 요리사」)에서 답을 못 쓰는 상태로 **「못 맞추면 다음으로 넘어가는 버튼 만들어서 적당한 위치에 놓아줘」**.

재 보니 «버튼이 없는» 정도가 아니라 **나갈 길이 아예 없었습니다.**

- 「다음 장면 →」(`#next`)은 `hidden` 으로 시작하고, **`award()` 가 도는 순간에만** 열립니다.
- `award()` 는 `D.check()` 가 `'correct'` 를 줄 때만 불립니다 = **정답을 직접 입력해야만** 합니다.
- 「정답 배우기」(`#reveal`)는 답을 힌트 상자에 보여 줄 뿐이고 그 자리 문구가
  「직접 입력해 문을 열어 보세요」입니다 — **문을 열지 않습니다.**

⟹ 철자를 못 쓰는 학생은 그 장면에서 **영영 못 나갑니다.** 새로고침 말고는 길이 없었습니다.

---

## 2. 고친 것

`.hint-row`(힌트 보기 · 정답 배우기)에 **「모르겠어요 · 넘어가기 →」**(`#skip`, `.ghost`)를 나란히 두고
`skip()` 을 새로 만들었습니다.

누르면:

| | |
|---|---|
| 점수 | **0** · 콤보 0 (공짜 통과가 아닙니다) |
| 복습 | `remember()` 로 **마지막 복습 대상**에 들어갑니다 |
| 배움 | 정답을 힌트 상자에 보여 주고 **「♪ 정답 듣기」를 엽니다** |
| 보물문 | **열지 않습니다** — `unlocked` 클래스도 🔓 아이콘도 안 붙습니다 |
| 화면 문구 | 「**넘어갔어요.** 정답을 한 번 읽거나 들어 보세요.」 (「정답!」이라고 하지 않습니다) |
| 결과·요약 | 「**· 넘어감**」 / `[넘어감]` — 「다시 연습」과 **갈라서** 적습니다 |

**상태를 셋으로 갈랐습니다** — `passed`(이 라운드는 끝났다, 기존 코드 전체가 쓰는 뜻 그대로)와
`skipped`(맞혀서가 아니라 넘어가서 끝났다). 한 칸으로 뭉치면 언어를 바꿀 때 「넘어감」이 「통과」로
되살아납니다(`renderText()` 가 `skipped` 를 봅니다).

### 곁가지로 드러난 것 — 결과 화면이 거짓말을 하고 있었습니다

전부 건너뛰고 끝내 보니 제목이 **「보물문이 열렸어요!」**, 부제가 「보고, **쓰고**, 끝까지
탐험했어요」였습니다. 한 글자도 안 썼는데 그렇게 말합니다.

**건너뛰기를 만들기 «전» 에는 닿을 수 없던 경로**입니다(전부 건너뛰는 일이 불가능했으니) —
이 변경이 그 경로를 처음으로 «닿게» 만들었습니다. 그래서 함께 고쳤습니다.

- 하나도 스스로 못 쓴 채 끝나면 → 「**끝까지 왔어요!**」 ·
  「이번엔 모두 넘어갔어요. 아래 표현을 한 번씩 따라 써 보면 다음엔 문이 열려요.」
- **한 장면이라도 스스로 풀었으면 예전 축하 문구 그대로**(짝으로 검사).
- ⛔ 「안 열렸어요」처럼 벌주는 말은 쓰지 않았습니다 — 끝까지 온 것은 사실입니다.
- ⚠️ 그 제목에는 `data-ko`/`data-en` 이 달려 있어 **속성까지 함께 갱신**해야 합니다
  (`label()` 헬퍼). 안 하면 🌐 를 누르는 순간 `language()` 가 옛 글자로 되살립니다.

## 3. 검토했다가 버린 방법

| 버린 방법 | 왜 |
|---|---|
| **「정답 배우기」가 곧바로 문을 열게** | 그 버튼의 뜻은 「답을 보고 **내가 써 본다**」입니다. 바꾸면 쓰기 연습이 통째로 사라집니다(그 자리 문구가 그렇게 약속합니다). |
| **`award()` 를 재사용** | 「정답!」·문 열림·🔓 가 딸려 옵니다 — 건너뛴 학생에게 **거짓 축하**입니다. |
| **「N번 틀려야 버튼이 나온다」** | 틀린 답을 못 쓰는 학생(철자를 아예 모름)이 다시 갇힙니다. 고치려던 그 문제가 절반 남습니다. |
| **확인창(「정말 넘어갈까요?」)** | 아이 화면이고 점수가 0이라 남용해도 이득이 없습니다. 마찰만 늘어 다시 갇히는 쪽으로 기웁니다. |
| **결과에서 「다시 연습」으로 뭉치기** | 「힌트 쓰고 맞힘」과 「아예 못 씀」이 한 글자가 됩니다 — 선생님이 볼 정보가 사라집니다. |

## 4. 확인한 방법

- **자동 하니스** `test-harness/scene_quest_harness.mjs` — 354 → **379 assertions**(25건 추가).
  실제 이벤트 핸들러를 가짜 DOM 으로 돌립니다. 가짜 DOM 의 `classList` 가 클래스를 **기록**하도록
  고쳐 「문이 열렸는가」를 잽니다.
  **변이 16종 전부 실제 FAIL** — 배선 제거 · 조건 뒤집기(`if(true)return`) · 공짜 점수 ·
  복습에서 빼기 · 거짓으로 문 열기 · 다음 버튼 안 열기 · 정답 안 가르치기 ·
  결과에서 「넘어감」 뭉개기 · 요약에서 지우기 · 버튼 영영 감추기 · HTML 에서 id 제거 ·
  **「맞히면 점수」 깨기(짝)** · 전부 건너뛰어도 「열렸다」고 말하기 ·
  언제나 「끝까지 왔어요」(짝 깨기) · `data-ko` 갱신 빼기 · 끝맺음 문구 고정.
- **브라우저** `test-harness/manual/scene-quest-skip-browser.mjs` — PC 1280×800 · 폰 390×844 에서
  **PASS 38 / FAIL 0**. ⚠️ 자동으로 안 돕니다, 사람이 부릅니다.
  「그려졌나」가 아니라 `getComputedStyle` + `elementFromPoint` 로 **「보이나·맨 위가 나인가」**,
  실제 좌표 클릭으로 **「눌리나」**, 장면 이름 변화로 **「진짜 넘어가나」** 를 잽니다.
  **변이 6종 전부 실제 FAIL.**
- **눈으로** — PC·폰 스크린샷으로 버튼 자리와 누른 뒤 화면을 확인했습니다.
- **회귀** — `--fast` PASS 330(origin/main) → **350**. FAIL 목록을 이름으로 `comm` 대조해
  **새로 깨진 것 0건**(`schedule_once_and_sched_col_harness` 는 `origin/main` 에서도 똑같이 빨간불 —
  `node_modules` 가 없어 esbuild 를 못 찾는 **환경 사유**, 3회씩 돌려 확인).
- `?v=` — `/js/scene-quest.js?v=1` → `?v=3`, `test-harness/asset-versions.json` 에 기록(함께 커밋).
  ⚠️ 중간에 `?v=2` 로 기록된 뒤 파일을 또 고쳐 `asset_version_harness` 가 빨간불이 났습니다 —
  **배포된 적 없는 `?v=2` 줄은 원장에서 뺐습니다**(남겨 두면 «나갔던 버전» 으로 읽힙니다).

### 검사를 만들며 밟은 함정 셋

1. **`display:none` 인 요소를 「보인다」로 셌습니다** — `querySelector` 로는 `hidden` 요소도 잡힙니다.
   `seen()` 이 `display`·`visibility`·`opacity`·크기를 함께 보게 고쳤습니다.
2. **정답을 검사에 손으로 적었습니다**(`'wand'`) — 장면은 `Math.random` 으로 뽑혀 회차마다 다릅니다.
   화면의 장면 이름으로 `window.MangoiSceneQuest` 에서 **찾아 쓰도록** 고쳤습니다.
3. **파이썬으로 고치고 «들어갔겠거니» 했습니다** — 편집 스크립트가 `ok` 를 찍었는데
   파일에는 안 들어가 있었습니다(파일 핸들을 안 닫고 `os.replace`). 하니스가
   「제목이 빈 문자열」로 잡아 줬습니다. **고친 뒤 즉시 `grep` 으로 확인**합니다.
4. **폰 폭에서 스크롤 없이 쟀습니다** — 질문 패널이 아래로 내려가 좌표가 화면 밖이라
   「가려졌다」·「안 눌린다」는 **거짓 실패**가 났습니다. `scrollIntoView` 뒤에 재고 누릅니다.

## 5. 남은 것 · 안 한 것

- 폰 세로에서 이 버튼은 **첫 화면 밖**입니다(스크롤해야 보입니다). 「힌트 보기」·「정답 배우기」와
  **같은 줄**이라 그 둘과 접근성이 같습니다 — 이 버튼만의 문제가 아니라 그대로 두었습니다.
  질문 패널을 위로 올리는 것은 배치 전체가 걸린 별건입니다.
- 「N분 동안 못 맞히면 버튼을 더 눈에 띄게」 같은 자동 안내는 **안 넣었습니다**(지시 범위 밖).
