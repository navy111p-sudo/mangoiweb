⛔ **곁가지로 찾은 것의 심각도를 낮춰 적지 마세요.** 이 저장소가 이미 「지금 터진 사고가 아니다」로

## 5. 고친 것 — `cloudflare-deploy/public/admin/student.html`

### 5-1. 판정 정본 한 곳

```js
function mgsEnrHasLiveClass(enr) {
  if (!_dSchedState.aiOk) return true;          // 못 읽었으면 예전대로(fail-open)
  var id = enr && enr.id;
  if (id === undefined || id === null || id === '') return true;
  var key = 'adm-enroll:' + String(id);
  var list = _dSchedState.aiSchedules || [];
  for (var i = 0; i < list.length; i++) {
    if (String((list[i] && list[i].source) || '') === key) return true;
  }
  return false;
}
```

근거: `GET /api/admin/class-schedules` 의 WHERE 에 `cs.status != 'cancelled'` 가 있어
**살아 있는 수업만** 옵니다 ⟹ 그 목록에 이 신청의 수업이 0건이면 «수업 없음».

### 5-2. 「제대로 읽었나」를 따로 기록

```js
_dSchedState.aiOk = !!(aiR && aiR.ok === true && !aiR.warning && Array.isArray(aiR.items));
```

🔴 그 API 는 조회가 실패해도 **`{ok:true, count:0, items:[], warning:…}`** 를 돌려줍니다.
`ok` 만 보면 「수업이 없다」와 「못 물어봤다」가 같은 값이 되어 **멀쩡한 수강신청이 통째로 회색**이
됩니다 — 그쪽이 훨씬 나쁘므로 `warning` 까지 봅니다.

### 5-3. 주간·월간 **둘 다** 그 정본을 부름

월간 뷰에는 `aiSchedules` 레이어가 아예 없어서 한쪽만 고치기 쉬운 자리입니다.
⛔ 판정을 복제하지 않고 같은 함수를 부릅니다.

### 5-4. 색

`MGS_ENR_DEAD = { bg:'#e2e8f0', border:'#94a3b8', text:'#475467' }` — 대비 **6.23**.

- ⚠️ 이 화면은 `adm-light-surfaces.js` 페인터가 돌아 **대비 4.5 미만이면 인라인 `!important` 로
  «구제»** 해 놓습니다. 연한 회색을 주면 오히려 진해져 「낮췄다」는 뜻이 사라집니다.
- ⚠️ 처음에 `#f1f5f9` 를 골랐다가 **슬롯 격자선과 같은 색**이라 카드가 묻혔습니다(검사가 잡음).

## 8. 이 작업에서 내 «검사» 가 헛돌던 것

만드는 도중 세 번 헛돌았고 전부 실측으로 잡았습니다.

1. 🔴 **`aiOk` 정규식이 초기화 줄을 먼저 물었습니다.** `/aiOk = ([^;]+);/` 가
   `_dSchedState.aiOk = false;` 에 먼저 걸려 **늘 `false`** 를 평가했고, 그 바람에
   「warning 이면 못 읽음」·「ok:false 면 못 읽음」·「빈 응답이면 못 읽음」 **세 검사가
   우연히 통과**했습니다. `aiR` 를 참조하는 식만 고르게 고쳤습니다.
2. 🔴 **색을 하니스에 손으로 적었습니다** — 소스에서 `#f1f5f9` → `#e2e8f0` 로 바꾸자
   전제 검사가 어긋났습니다. **상수를 평가해** 가져오도록 고쳤습니다.
3. 🔴 **「격자선과 다른 색인가」를 파일 전체로 물었습니다** — 카드가 놓이지도 않는
   **요일 머리글 구분선**(`#e2e8f0`)에 걸려 거짓 FAIL. 카드가 «놓이는» 슬롯 격자선만
   콕 집도록 고쳤습니다.

그리고 반례를 «남의 번호» 하나(`adm-enroll:104`)로만 두면 `===` → `includes` 변이가 안 잡혀서,
**접두사를 품는 번호**(`adm-enroll:1030`)를 반드시 섞었습니다.

- **「신청은 확정했는데 수업이 아직 안 만들어진」 경우도 회색**입니다. 화면이 하는 말이
  「신청만 있고 수업이 없다」라서 그 경우에도 **사실**이라 그대로 뒀습니다(실측 13건은 전부
  수업을 갖고 있어 지금 반경은 0).
- ⛔ **D1 은 한 줄도 안 건드렸습니다.** 신청서 103 은 그대로 `confirmed` 입니다. 그 행을
  정리할지는 사장님이 정할 일입니다.
- **왜 수업 4건이 전부 취소됐는지**는 이번에 캐지 않았습니다. `notes` 에 「[2026-09-11] 담당 강사
  변경」이 남아 있어 그날의 «드래그 이동이 저장되지 않던» 건과 얽혀 보이지만 **추론이고
  측정이 아닙니다.**
- **화면은 사람이 한 번 봐야 끝납니다** — 프록시가 `mangoi.ai` 를 막아 배포된 화면을 못 봅니다.
