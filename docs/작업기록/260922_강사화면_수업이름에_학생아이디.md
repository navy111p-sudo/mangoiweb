**날짜** 2026-09-22 · **브랜치** `claude/mango-ai-student-id-naming-lsbnx7`

> At mangoi LMS teacher's page, always name mango ai with student ID,
> so teachers will know that they need to enter mangoai for test class.
>
> (망고아이 LMS 교사 페이지에서 망고아이 이름을 항상 학생 ID와 함께 표시해 주세요.
>  그래야 선생님들이 테스트 수업을 위해 망고아이에 입장해야 한다는 것을 알 수 있습니다.)

⟹ **강사는 같은 수업을 «옛 LMS» 에서도 봅니다**(2,096/2,173). 두 화면을 잇는 열쇠는
«이름» 이 아니라 **아이디** 인데(이 저장소에는 동명이인이 실재합니다 — 김민서 71명·김민준 56명),
강사 화면은 이름만 그리고 있었습니다. 그리고 **서버는 이미 아이디를 보내고 있었고
화면이 안 쓰고 있었을 뿐**입니다.

## 2. 한 것

### 2-1. 서버 — `cloudflare-deploy/src/api-teacher.ts`
- `studentUidOf(s)` 신설. 주간 시간표(`weekDays[wi].items`)·앞으로 7일(`upcoming`)
  payload 에도 `student_uid` 를 싣습니다(SELECT 에는 `cs.user_id` 가 이미 있어 SQL 은 안 바꿨습니다).
- ⛔ **자리표시 행은 비웁니다.** `user_id` 가 `lms`·`type_seed` 인 행은 학생이 아닙니다 —
  그 값을 아이디로 내려주면 강사 화면에 「lms 라는 학생」 이 생깁니다.

### 2-2. 화면 — `cloudflare-deploy/public/teacher.html`
- **판정 정본은 `stuParts` 한 곳**이고 `stuLabelText`·`stuLabelHtml` 은 «글자를 만들기만» 합니다.
  두 곳에 복제하면 텍스트 자리와 HTML 자리가 조용히 다른 말을 합니다.
- 이름을 그리던 **9자리**(오늘 목록·취소된 수업·다가오는 수업·주간표·다음 수업 스트립·
  연기 요청 목록·일지 모달·AI 리포트 모달·복사용 요약)가 전부 그 정본을 부릅니다.
- ⛔ 아이디가 없으면 «()» 같은 빈 껍데기를 만들지 않습니다.
- ⛔ 이름 칸에 아이디가 든 행은 같은 글자를 두 번 적지 않습니다
  (옛 LMS 행은 서버가 `student_name = user_id` 로 내려줍니다).
- 아이디 색은 `.cls-meta` 와 **같은 `#5d6b7a`** — 흰 카드에서 대비가 이미 확인된 값입니다.
  ⛔ `opacity` 로 흐리게 만들지 않았습니다(읽히지만 못 읽는 글자가 됩니다).

### 2-3. 🥭 「망고아이에서 입장하세요 — 옛 LMS 아님」
- **레벨테스트·체험수업 줄에만** 붙입니다. 배지(레벨테스트)는 «무슨 수업인지» 만 말하고
  «어디로 들어가는지» 는 말해 주지 않아서입니다 — 제안이 말한 이유가 바로 그것입니다.
- ⛔ 정규수업에는 안 붙입니다. 모든 줄에 붙으면 특별한 표시가 묻힙니다.
