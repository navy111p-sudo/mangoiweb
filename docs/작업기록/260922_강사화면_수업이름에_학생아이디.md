# 강사 화면 수업 이름에 «학생 아이디» 를 항상 함께 — 그리고 테스트 수업은 망고아이로

**날짜** 2026-09-22 · **브랜치** `claude/mango-ai-student-id-naming-lsbnx7`

## 0. 무엇에서 출발했나

> At mangoi LMS teacher's page, always name mango ai with student ID,
> so teachers will know that they need to enter mangoai for test class.
>
> (망고아이 LMS 교사 페이지에서 망고아이 이름을 항상 학생 ID와 함께 표시해 주세요.
>  그래야 선생님들이 테스트 수업을 위해 망고아이에 입장해야 한다는 것을 알 수 있습니다.)

## 1. 먼저 잰 것

| 잰 것 | 값 | 어떻게 |
|---|---|---|
| 활성 수업 | **2,173건** (전부 `class_type='regular'`) | D1 SELECT |
| 그중 카페24 미러 | **2,096건** (`source='c24-mirror'`) | D1 SELECT |
| 지금 잡힌 레벨테스트·체험 | **0건** | D1 SELECT |
| 자리표시(`lms`·`type_seed`) 활성 행 | **0건** (전부 취소 정리됨) | D1 SELECT |
| 강사 화면이 그리는 학생 «아이디» | **한 글자도 없음** | 소스 |
| 서버가 내려주는 `student_uid` | 오늘 목록엔 **있음**, 주간표·앞으로 7일엔 **없음** | 소스 |

⟹ **강사는 같은 수업을 «옛 LMS» 에서도 봅니다**(2,096/2,173). 두 화면을 잇는 열쇠는
«이름» 이 아니라 **아이디** 인데(이 저장소에는 동명이인이 실재합니다 — 김민서 71명·김민준 56명),
강사 화면은 이름만 그리고 있었습니다. 그리고 **서버는 이미 아이디를 보내고 있었고
화면이 안 쓰고 있었을 뿐**입니다.

## 2. 한 것

### 2-1. 서버 — `cloudflare-deploy/src/api-teacher.ts`
- `studentUidOf(s)` 신설. 주간 시간표(`weekDays[wi].items`)·앞으로 7일(`upcoming`)
  payload 에도 `student_uid` 를 싣습니다(SELECT 에는 `cs.user_id` 가 이미 있어 SQL 은 안 바꿨습니다).
- ⛔ **자리표시 행은 비웁니다.** `user_id` 가 `lms`·`type_seed` 인 행은 학생이 아닙니다 —
  그 값을 아이디로 내려주면 강사 화면에 「lms 라는 학생」 이 생깁니다.

### 2-2. 화면 — `cloudflare-deploy/public/teacher.html`
- **판정 정본은 `stuParts` 한 곳**이고 `stuLabelText`·`stuLabelHtml` 은 «글자를 만들기만» 합니다.
  두 곳에 복제하면 텍스트 자리와 HTML 자리가 조용히 다른 말을 합니다.
- 이름을 그리던 **9자리**(오늘 목록·취소된 수업·다가오는 수업·주간표·다음 수업 스트립·
  연기 요청 목록·일지 모달·AI 리포트 모달·복사용 요약)가 전부 그 정본을 부릅니다.
- ⛔ 아이디가 없으면 «()» 같은 빈 껍데기를 만들지 않습니다.
- ⛔ 이름 칸에 아이디가 든 행은 같은 글자를 두 번 적지 않습니다
  (옛 LMS 행은 서버가 `student_name = user_id` 로 내려줍니다).
- 아이디 색은 `.cls-meta` 와 **같은 `#5d6b7a`** — 흰 카드에서 대비가 이미 확인된 값입니다.
  ⛔ `opacity` 로 흐리게 만들지 않았습니다(읽히지만 못 읽는 글자가 됩니다).

### 2-3. 🥭 「망고아이에서 입장하세요 — 옛 LMS 아님」
- **레벨테스트·체험수업 줄에만** 붙입니다. 배지(레벨테스트)는 «무슨 수업인지» 만 말하고
  «어디로 들어가는지» 는 말해 주지 않아서입니다 — 제안이 말한 이유가 바로 그것입니다.
- ⛔ 정규수업에는 안 붙입니다. 모든 줄에 붙으면 특별한 표시가 묻힙니다.

### 2-4. 함정 대조(trap-check)가 잡아 고친 것 — 전부 «에러가 안 나는» 종류

| 무엇 | 왜 그대로 두면 안 되나 | 고침 |
|---|---|---|
| 🔴 「수업 연기·변경」 목록·모달에 아이디가 **원리상 안 나옴** | `renderPostponeList` 가 rows 를 **손으로 고른 필드 목록**으로 다시 만드는데 `student_uid` 가 빠져 있었습니다. 9자리 중 2자리가 죽은 배선이었고 **화면은 멀쩡히 그려집니다.** | 두 `rows.push` 에 칸 추가 + 하니스 ⑦이 그 함수를 **실제로 돌려** 나온 HTML 을 봅니다 |
| 🔴 다크 모드 대비 **3.08** (4.5 미달) | `.cls-meta` 에는 다크 override 가 있는데 `.stu-id` 에만 없었습니다. 이 화면의 다크는 사람이 켜는 실제 모드입니다(`mangoi_teacher_theme`). | 다크 목록에 `.stu-id` 를 **짝으로** 추가 → **7.17** · 하니스 ⑥-3~⑥-5 와 브라우저 (9)절이 잽니다 |
| ⚡ 장애 신고 본문에 아이디가 섞임 | `outageAffected()` 의 글자는 화면이 아니라 **D1 `teacher_outages.affected_text` 와 사무실 알림**으로 나가 그대로 쌓입니다. «화면에 보이게» 와는 다른 일이라 지시 범위 밖입니다. | 그 한 자리만 이름으로 되돌림 · 하니스 ⑧이 **실제로 돌려** 아이디가 안 들어가는지 봅니다 |
| 🥭 안내가 🔄 대체강사보다 **앞**에 끼어듦 | 그 자리 주석이 「🔄 를 맨 앞에 둔다」고 못 박아 두었습니다(「이거 내 수업 아닌데?」를 먼저 답하려고). | 🔄 뒤로 옮김 · 하니스 ⑨가 순서를 봅니다 |
| 다시 그릴지 판정하는 지문(sig)에 아이디가 없음 | 아이디만 바뀐 응답에서 화면이 **옛 글자를 그대로 둡니다.** | `stuUid(sc)` 추가 · 하니스 ⑩ |
| 서버 `student_uid` 5자리 중 **3자리가 정본을 안 지남** | 주석은 「같은 판정이 아래에도 있다 — 한쪽만 고치지 말 것」이라 적어 두고 실제로는 오늘 목록·대타·옛LMS 미러가 날것 `user_id` 였습니다(**적어 둔 것 ≠ 사실**). | 셋 다 `studentUidOf()` 로 · 하니스 ⑤-12·⑤-13 이 **전수**로 봅니다 |

## 3. 검토했다가 버린 것

| 버린 방법 | 왜 |
|---|---|
| 카페24(옛 LMS) 수업 제목을 「Mango AI · <아이디>」로 바꾸기 | **이 저장소에서 못 합니다.** 카페24가 정본이고 우리는 읽기만 합니다(`c24-mirror`). 쓰는 경로가 0곳입니다. |
| 아이디를 «이름이 없을 때만» 보여주기 | 제안이 「**always**」입니다. 그리고 이름이 있는 행이야말로 동명이인 때문에 아이디가 필요합니다. |
| 모든 줄에 「망고아이에서 입장」 붙이기 | 그 화면의 모든 줄이 이미 망고아이 수업이라 특별한 표시가 묻힙니다. |
| `stuName` 을 고쳐 아이디를 섞기 | 그 함수는 «사람 이름» 정본이고 로그·payload 등 다른 뜻으로 쓰는 자리가 있습니다. 새 표시 함수를 따로 뒀습니다. |
| 화면에서 자리표시를 거르기 | 화면은 그 행이 자리표시인지 «아이디만 보고는» 모릅니다. 서버가 비워 보내는 쪽이 정본입니다. |
