## 2. 무엇이 틀렸나

### ① `hidden` 이 안 먹었습니다 — 「있다」와 「보인다」는 다른 값

목표가 0인 게임은 `box.hidden = true` 로 감췄는데, `.game-progress` 에
`display:flex` 가 있어 **작성자 CSS 가 브라우저 기본 `[hidden]{display:none}` 을
«작성자 > UA» 순위로 이겼습니다.** 게다가 채움(`.gp-fill`)은 폭이 미설정이라
block 자식이 부모 폭을 100% 먹었습니다.

```
[잰 것 — 크로미움 390×844]
  hidden 속성  : true
  computed     : display:flex · 높이 20px
  채움         : 358 / 358 = ratio 1.000  (초록 가득)
  글자         : "" (빈 문자열)
```

🔴 **제 브라우저 검사가 `hidden` «속성» 만 재고 통과시켰습니다.**
CLAUDE.md 에 「`el.hidden = true` 인데 그대로 보임」이 이미 있는데 **읽고도 밟았습니다.**

✅ 고침은 **두 겹** — `.game-progress[hidden]{display:none !important}` +
숨길 때 채움 폭을 `0%` 로 되돌리기.

### ② 진행을 «알려 올 통로» 가 없는 3종에 띠를 그렸습니다

낚시(`english-mastery-suite`) · 말하기 퀴즈(`speaking-quiz`) ·
장면 탐험대(`scene-quest`) 셋은 **`js/game-track.js` 를 안 싣습니다**(전수 grep 0건).
⟹ 진행 메시지가 **원리상 0건**이라 띠가 게임 내내 0 에 멎어 있다가 끝에 갑자기
가득 찹니다. 화면이 «측정한 척» 하는 것입니다.

🔴 **그런데 #1074 커밋 메시지는 「그 셋은 이번엔 안 붙였습니다」라고 정반대를
적었습니다.** 표에는 `scenequest:12`·`fish:5` 가 있었고 `speaking` 은 기본값 10 으로
떨어져 붙고 있었습니다 — 이 저장소가 네 번 사고를 낸 **「적어 둔 것 ≠ 사실」** 그 형태라
CLAUDE.md 에 그대로 적었습니다.

✅ 셋을 `n:0` 으로. 그리고 **손으로 적은 목록을 믿지 않게** 하니스가 registry 에서
그 게임의 파일 이름을 읽어 **그 파일을 실제로 열어** `game-track.js` 를 싣는지
기계로 대조합니다(⑧절). 통로가 생기면 그때 숫자를 넣으면 됩니다.

### ③④ 분자와 분모의 «단위» 가 서로 달랐습니다

표에 `spacemonster:{ n:6, by:'seen' } // 화면 표시 1/6` 이라 적었는데 —

- 그 **「1/6」은 문제 수가 아니라 게임 HUD 의 `LEVEL`** 이었습니다
  (`student-game-space-monster.html` 의 `<div class="label">LEVEL</div>`).
- `by:'seen'` 의 seen 은 `game-track.js` 에서 **«감싼 fetch 가 몇 번 불렸나»** 입니다.
  우주 괴물은 문장 하나에 `hit` + `shadow` 두 번을 부르므로 문장당 2씩 늡니다
  ⟹ **문장 3개에서 6/6 「다 했어요!」**.
- 덤으로 중복 방지 게이트가 `correct` 만 봐서, **오답만 나오는 동안은 메시지가 아예
  안 나갔습니다**(띠가 0에 멎음).

✅ `by:'seen'` 축을 **없애고** 단위를 **«맞힌 개수» 하나**로 통일했습니다.
학생이 게임을 옮겨도 숫자의 뜻이 안 바뀌는 것이 이 띠를 만든 이유입니다.
글자도 「✅ 2 / 10 · 8개만 더!」로 **«맞힌 개수» 임을 드러냅니다.**
ℹ️ 목표를 못 채운 채 게임이 먼저 끝나면 완료 신호가 띠를 채우므로 중간에서 안 멎습니다.

### 곁가지

- 🌐 를 눌러도 띠 글자가 **«다음 정답이 올 때까지» 옛 언어**였습니다 → 토글에서 다시 그립니다.
  ⛔ `data-ko`/`data-en` 은 **안 씁니다** — 두 i18n 엔진이 `textContent` 를 갈아끼워
  안쪽 `<b>` 가 DOM 에서 사라집니다.
- `.game-progress` 에 `flex-shrink:0`(형제 둘에는 있었습니다).
- 하니스 ⑤절이 리스너를 `slice(1400)` 으로 잘라 **462자가 새어 나갔습니다** → 중괄호 짝으로.
- `bodyAt` 주석이 「괄호 깊이 0인 것만 본다」고 적었는데 코드는 첫 `{` 를 씁니다 →
  **주석을 사실에 맞췄습니다**(코드가 아니라 주석이 틀린 경우).

## 3. 검토했다가 버린 방법

| 버린 방법 | 왜 |
|---|---|
| **통로 없는 3종에 `game-track.js` 를 싣기** | 화면 셋을 각각 고치는 별건입니다. 그전까지 띠가 «측정한 척» 하는 것이 더 나쁘므로 **0 으로 두어 아예 안 그립니다**(모르는 것을 지어내지 않습니다) |
| **`by:'seen'` 을 남기고 게임마다 «몇 번 부르는지» 를 표에 적기** | 게임이 fetch 를 한 번 더 부르는 날 조용히 어긋납니다. 그리고 학생에게는 그 숫자의 뜻이 게임마다 달라집니다 |
| **분모를 «그 게임의 진짜 끝» 으로** | 게임마다 끝이 없거나(무한) 뜻이 다릅니다. 이 숫자는 «오늘 이만큼 하면 된다» 는 **우리 목표**이고 값은 사장님이 정하실 일입니다(제안서 2층) |
| **띠를 통째로 빼기(되돌리기)** | 「끝이 안 보인다」가 원래 문제였습니다. 되돌리면 그 문제가 그대로입니다 |
| **`hidden` 대신 `style.display='none'` 으로 감추기** | 같은 «작성자 CSS 가 이기는» 함정을 다른 형태로 밟습니다. `[hidden]{display:none !important}` 가 정본입니다 |
