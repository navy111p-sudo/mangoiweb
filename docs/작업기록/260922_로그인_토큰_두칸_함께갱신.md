# 로그인 토큰 칸 «두 벌» 을 함께 갱신 — 같은 기기에서 자기가 자기를 밀어내던 것 (2026-09-22)

> 사장님 「너가 추천한대로 수정 보완 해줘」 — 진단([260922_…_자가퇴출_진단.md](260922_로그인_다른기기에서_로그인됨_한기기_자가퇴출_진단.md))의 **A 안**을 시행했습니다.

## 1. 무엇이 문제였나 (한 줄)

운영은 `SINGLE_SESSION='on'` 이라 **로그인에 성공할 때마다** 새 세션번호(`sid`)가 발급되고
이전 토큰은 그 자리에서 401 이 됩니다. 그런데 화면의 토큰 칸이 **두 벌**인데 서로를 몰랐습니다 —

| 칸 | 쓰는 곳 |
|---|---|
| `mango_token` | 홈 로그인 · 학습 화면 **전부**(발음코칭·단어·게임·포인트) |
| `mangoi_parent_token` | **마이 페이지(`parent.html`) 하나뿐** |

⟹ 홈 ↔ 마이 페이지를 오가면 직전 토큰이 죽어, 발음코칭 채점(`/api/voice/coach`)이 401 →
`session-guard` 가 「**다른 기기에서 로그인되었습니다**」를 띄웠습니다. **서버 판정 자체는 맞습니다** —
그 「다른 로그인」이 **같은 기기의 다른 화면**이었을 뿐입니다.

## 2. 고친 규칙 — 정책을 한 글자도 안 깨는 경계

> **«이미 있던 같은 계정의» 반대쪽 토큰만 갱신한다. 없으면 «만들지» 않는다.**

세 가지를 **짝으로** 지킵니다.

| 규칙 | 왜 |
|---|---|
| ① 같은 계정이면 **갱신한다** | 이것이 사고를 닫는 부분 — 살아 있던 토큰이 안 죽습니다 |
| ② **없으면 만들지 않는다** | 만들면 홈에 로그인한 적 없는 기기가 로그인 상태가 되고, 마이 페이지 자동 조회가 열려 **2026-07-30 제보 #3**(자녀가 비번 없이 학부모 페이지 열람)이 되살아납니다. 목적은 «새로 열어 주기» 가 아니라 **«되던 것을 안 죽이기»** 입니다 |
| ③ 다른 계정이면 **손대지 않는다** | 대소문자까지 **정확일치** — `Kim`/`kim` 처럼 대소문자만 다른 계정이 실재합니다 |

⛔ `SINGLE_SESSION` 을 끄는 길(D 안)은 **택하지 않았습니다** — 아이디 돌려쓰기를 막는 상품 정책이 통째로 풀립니다.

## 3. 고친 자리

### 3-1. 마이 페이지 → 홈 (`public/parent.html`)

- `pdTokenUid()` · `pdSyncHomeToken()` 신설(스크립트 최상위)
- **부르는 곳 둘**
  - `pdLogin()` — 비밀번호로 로그인에 성공한 자리
  - `pdGo()` — 「계정 상태 확인」 호출. 🔴 **비밀번호가 «없는» 계정에서는 그 호출이 실제로 로그인에 성공해
    sid 가 갱신됩니다**(주석은 「토큰은 여기서 쓰지 않음」이지만 서버는 세션을 이미 새로 열었습니다).
    토큰을 버리면 홈 토큰만 죽으므로 같은 규칙으로 갱신합니다 — 진단서 §7-2 가 그대로 닫혔습니다.

### 3-2. 홈 → 마이 페이지 (`public/js/idx-user-session.js`)

- `lmTokenUid()` · `lmSyncParentToken()` 신설(IIFE 최상위)
- **부르는 곳 셋** — `doStudentLogin`(아이디·비밀번호) · `pkStoreLogin`(패스키) · `doLogin`(데모 빠른 로그인)
- `index.html` 은 **`?v=8` → `?v=9` 한 글자만** 바꿨습니다(공동 금지구역 · 글자 수가 같아 **첫 화면 예산 0바이트** — 실측 1,068,188 → 1,068,188)

> ⚠️ 규칙이 **두 벌로 복제**돼 있습니다(마이 페이지는 이 JS 를 싣지 않습니다).
> 이 저장소 관례대로 **하니스가 둘을 오려 내 «같은 답» 인지 대조**합니다(⑥절).
> 한쪽만 고치면 그 자리에서 빨간불이 납니다.

2. **블록을 「시작 ~ 다음 함수 이름」으로 잘랐습니다** → `doStudentLogin` 과 `doPasskeyLogin` 사이에
   **`pkStoreLogin` 이 끼어 있어**, `doStudentLogin` 의 호출을 지워도 옆 함수의 것이 잡혀 **통과**했습니다

   ⚠️ **못 잡았다고 다 구멍이 아닙니다** — «관측 차이가 없다» 와 «검사가 헛돈다» 는 다릅니다.
