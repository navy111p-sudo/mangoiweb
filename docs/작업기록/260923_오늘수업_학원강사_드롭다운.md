# 「오늘 수업」 학원·강사 드롭다운 (2026-09-23)

## 왜
매니저 Karl 제안 — «At manager's page, at today's classes, can we add options at the top with list of
academies and list of teachers, instead of typing them. Cases like we need to postpone 1 specific academy
on that day better to show them all together.» (옛 카페24 LMS 화면의 학원·강사 드롭다운 사진 첨부)

그전에는 학원·강사로 거르려면 검색창에 글자를 쳐야 했습니다(admin.html). manager.html 「오늘 전체 수업」은
날짜 칸뿐이었습니다. 사장님이 두 단계 안 중 **1단계(고르기)** 를 먼저 하라고 정하셨습니다.

## 한 일
- **admin.html 「오늘 수업」**(`js/adm-today-classes.js` v=37) · **manager.html 「오늘 전체 수업」** 두 곳에
  「학원」·「강사」 드롭다운.
- 목록은 **그날 불러온 줄에서만** 만들고 건수를 붙입니다(`BNJ어학원 (7)`). 전체 명부로 채우면 고르고 나서
  0건인 항목이 대부분이 되기 때문입니다.
- 두 목록은 **서로를 따라 좁혀집니다** — 학원을 고르면 강사 목록은 그 학원 강사만(반대도 같음).
- 빈 값은 «(학원 미지정)»·«(강사 미배정)» 한 항목으로 모아 맨 끝에 둡니다(조용히 사라지지 않게).
  공백만 다른 이름은 한 항목, 대소문자만 다른 이름은 **합치지 않습니다**(다른 학원일 수 있음).
- 학원을 고르면 요약 한 줄: 「🏫 BNJ어학원 · N건 (망고아이 · 카페24) · 강사 N명」, 카페24 수업이 섞이면
  「여기서 옮길 수 없다 — 카페24에서 직접」.
- 0건이면 «조건에 맞는 수업이 없습니다 (고른 학원·강사 · 전체 N건)» 로 이유를 말합니다.

  「2건 보이는데 카페24 40건」).
- 화면 안에서만 거릅니다 — 서버 요청 0건, 서버 코드 변경 없음.

## 검토했다가 버린 것
- **공용 js 파일 하나로 두 화면이 나눠 쓰기** — manager.html 은 파일 머리 계약 1번이 «외부 리소스 0개»
  (지연 350ms 회선에서 요청 하나가 첫 화면 0.4초). 그래서 판정 네 함수(pickKey·pickMatch·pickOptions·
  fillPick)가 **두 벌**이고, 자동 하니스가 두 벌을 오려 내 같은 답인지 대조합니다.
- **전체 학원 명부(921곳)로 목록 채우기** — 위 이유로 버림.
- **localStorage 로 고른 값 기억** — 처음 안에서는 말씀드렸지만 넣지 않았습니다. 다음 날 이유도 모른 채 목록이
  비어 보이는 위험이 있고, 한 화면 안에서는 선택이 이미 유지됩니다.
- **2단계(학원 수업 한꺼번에 연기)** — 사람 결정 3가지(연기=다른 날로/취소 · 급여 처리 · 권한)가 남아 보류.

# 2단계 — 학원 수업 한꺼번에 연기 (2026-09-23 같은 날)

## 한 일
- 학원을 고르면 요약 줄에 **「⏸ 이 N건 한꺼번에 연기…」** 버튼(admin.html · manager.html 두 곳).
- 누르면 공용 창(`js/class-move-modal.js` v=2 의 `bulkOpen`) — 옮길 줄은 체크 목록, **안 옮기는 줄은 이유와 함께 따로**
  (카페24 · 매주 반복 · 이미 끝남 · 지금 진행 중 · 수업 번호 없음). 판정은 `bulkPlan` 한 곳.
- 실행 = 줄마다 **단건 «완전히 연기» 와 같은 두 요청**(`POST /schedule-requests` postpone → `/decide` approve)을
  **차례로**. 한 줄이 실패해도 계속하고, 줄마다 결과를 적고, 된 줄은 체크를 잠가 다시 안 보냅니다.
- 서버 코드 변경 없음(겹침·스코프·강사 차단·변경이력은 서버가 그대로).

## 사람 결정 3가지 — 이번에 정한 기본값 (바꾸려면 말씀만)
1. **연기의 뜻** = 단건과 같은 «연기»(날짜 미정). 다른 날로 옮기기는 한 건씩(기존 창).
2. **급여** = 기존 규칙 그대로 — 시작 30분보다 이르면 «사전 연기»(지급률 기본 0), 확인창이 **몇 건인지** 말합니다.
3. **권한** = 단건 연기와 같음(서버가 스코프를 다시 봄). ⛔ **일괄 «취소» 는 두지 않았습니다** — 되돌릴 수 없는
   조작을 여러 건 한꺼번에 하지 않습니다.

## 함께 고친 것 — 매니저 화면 머리글 «본사(전체)» 가 한 글자씩 세로로
