# 장면 탐험대 — 「P.E.」가 「e」로 쪼개짐 · 「english」 소문자 · 뜻 안 맞는 사진 6장 (2026-09-23)

## 1. 왜 했나
사장님 캡처 세 장(BTS 1 낱말 카드):
- 「**e**」 카드 — 예문 「We play games in P.E. class.」 → 뜻 없는 한 글자가 낱말로 나옴
- 「**english**」 — 소문자로 나오고, 사진이 야외에서 손을 뻗는 아이들이라 «영어 수업» 으로 안 읽힘
- 「**easy**」 — 예문 「The lessons are easy to understand.」 인데 **계단 사진**

## 2. 원인 (잰 것)
- 낱말 세는 정규식 `/[a-z]+/` 가 **점 약어를 글자별로** 쪼갬 → `P.E.`→p·e, `J.R.R.`→j·r.
  같은 이유로 K-pop 의 k · X-rays 의 x · Vitamin C 의 c 도 낱말이었음(7개).
- 낱말은 소문자로 저장되고 화면이 그대로 그림 → 고유명사도 소문자.
- easy 사진 프롬프트 = 「A gentle easy slope **ramp** beside a steep **staircase**」 — 낱말의 «글자 뜻» 을 그렸고
  모델은 경사로도 안 그리고 계단만 그림. 근거 게이트는 설명에 easy 가 있으니 정직하게 통과(README-낱말사진 「추상어를 글자대로」 형태).
