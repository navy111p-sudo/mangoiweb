# 결재함 자동화 7단계 — 영수증 사진 흐림·어두움 알림 (2026-09-24)

## 왜 했나
사장님 「계속 해 끝까지 … 배포해줘」「1,2,3」의 3번(남은 개선 계속). 제안서의 «사진이 흐리면 다시 찍게» 항목입니다.
흐린 영수증은 AI 판독(가게·금액)이 틀리고, 장 부장님이 결재할 때 금액을 대조할 수 없어 반려 → 다시 올리기가 됩니다.
**올리기 «전», 휴대폰에서 바로** 알려 주는 것이 가장 쌉니다.

## 한 것
1. **휴대폰에서 사진 상태를 잰다**(`work.html` `photoQualityOf` → `photoQ`, AI 없음·결정론)
   - 폭 320px 로 줄인 흑백에서 ① 평균 밝기 < 45 → «어두움» ② 라플라시안 절댓값의 **상위 0.1% 값** < 60 → «흐림».
   - 흐리면 글자 가장자리의 급한 밝기 변화가 사라지므로 «가장 선명한 곳» 이 낮아집니다. 분산(평균)으로 재면 여백이 많은 영수증에서 희석돼 못 가립니다(시험했다가 버림).
2. **화면에 한 줄**(`#photoWarn`, 한/영) — 「📷 사진이 흐립니다. 글자가 또렷하게 다시 찍어 주세요」. 막지 않습니다.
3. **서버에 알림**(`photo_quality`) → `runChecks` 가 🟡 `photo_unclear` 를 붙입니다(`normPhotoQuality` 는 `blurry`·`dark` 만 인정).
   결재자 카드에 «사진이 흐립니다 — 글자를 확인해 주세요» 가 뜹니다. **빨강이 아닙니다** — 반려 사유가 아니라 확인 신호.
4. 늦게 끝난 측정이 새 사진의 결과를 덮지 않게 순번(`PHOTO_SEQ`) 가드, 오프라인 보관함(outbox)에도 값을 함께 넣습니다.

## 검토했다가 버린 것
- **AI 에게 «읽을 수 있나» 묻기** — 느리고 돈이 들고 매번 답이 다릅니다. 픽셀 계산이 0.1초 안에 끝납니다.
- **흐리면 올리기 막기** — 오판이면 필리핀 직원이 결재를 아예 못 올립니다. 경고만.
- **라플라시안 분산** — 합성 영수증 실측에서 크게 흐린 것도 119 로 나와 기준을 못 잡았습니다.

## 한계 (사실대로)
- 기준값(45·60)은 **합성 영수증**(선명 136~410 · 흐림/빈 32~56)으로 맞춘 것입니다. **실제 휴대폰 사진으로는 아직 못 쟀습니다** — 오경보·놓침이 보이면 이 두 숫자를 조정해야 합니다.
- PDF·이미지가 아닌 첨부는 재지 않습니다(판정 없음 = 알림 없음).
- 옛 판 화면(캐시)에서 올린 건은 값이 없어 알림이 없습니다.
