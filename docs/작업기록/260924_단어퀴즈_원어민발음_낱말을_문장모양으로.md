## 1. 왜 했나

사장님 제보: AI 단어 퀴즈 「듣고 맞히기」(문제 4/5, 「잘 듣고 뜻을 고르세요」) 화면에서 **원어민 발음이 이상하다.**
화면 파일은 `cloudflare-deploy/public/micro-quiz.html`.

## 2. 무엇을 바꿨나

- `cloudflare-deploy/public/micro-quiz.html` — `speakWord()` 앞에 `ttsWord()` 를 새로 두었다.
  소리를 만들 때만 낱말을 **첫 글자 대문자 + 마침표**(`study` → `Study.`)로 보낸다. 화면 글자는 그대로.
  - 이미 `. ! ?` 로 끝나면 그대로
  - 영문자·숫자·`'`·`,`·`-`·공백 밖의 글자(한자·한글)가 섞이면 그대로
  - 빈 값은 빈 문자열
- `test-harness/micro_quiz_tts_word_harness.mjs` — 새 하니스 14종(아래 4장).

소리 경로(참고): `speakWord` → `MangoiTTS.speak()`(`js/game-tts.js`) → `POST /api/voice/tts`(`src/api-games.ts`)
→ Deepgram **Aura-2**(`asteria`) → 실패 시 Aura-1 → MeloTTS → 서버 전부 실패 시 기기 목소리(`speechSynthesis`).

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

원인 후보는 셋이었다(코드 읽고 좁힌 **추론** — 이 환경은 소리를 들을 수 없고 `mangoi.ai` 도 프록시에 막혀 응답 헤더도 못 봄).

1. **낱말 하나만 보냄** — 문장용 AI 음성은 낱말 하나를 받으면 첫소리를 자르거나 억양이 어색해지는 경우가 흔하다. 코드에 한 단어용 처리가 없었다. ← 사장님이 이 방법을 골라 적용
2. 폴백 목소리(Aura-1·MeloTTS·기기 음성)로 떨어졌을 가능성
3. 서버 R2 캐시(7일)에 옛 이상한 음성이 남았을 가능성 — 보내는 글자가 바뀌면 캐시 키도 바뀌어 이것도 함께 비켜 간다

버린 방법:
- **공용 `js/game-tts.js` 에서 고치기** — 여러 게임·AI 친구·판단력 훈련이 함께 쓰므로 반경이 크고, 문장을 넘기는 화면까지 모양이 바뀐다. 제보된 화면 하나로 좁혔다.
- **서버(`/api/voice/tts`)에서 짧은 입력을 다듬기** — 이때는 «모든 화면의 캐시 키가 바뀐다» 고 보고 버렸다. ⚠️ **같은 날 6장에서 이 길로 되돌아왔다** — 규칙을 «세 낱말 이하 · 끝맺음 없음» 으로 좁히면 바뀌는 캐시 키는 짧은 낱말뿐이라 그 우려가 성립하지 않았다.

## 6. 후속 — 모든 게임에 같은 방법 (PR #1154)

사장님 「다른 게임들도 같은 방법으로 고쳐줘」.

**찾아본 것 [잰 것]**: `/api/voice/tts` 를 직접 부르는 화면·스크립트가 20곳 남짓이고(`battle-3d`·`escape-*`·`grammar-pizza`·`language-ace`·`p38-3d`·`rescue-voyage`·`shooter`·`space-monster`·`tank-battle`·`tetris`·`wordfighter`·`suspect-mystery`·`vocab`·`speech-coach`·`warmup`·`game-tts.js` 등), 그중 여럿은 공용 `game-tts.js` 를 안 쓰고 **자기 음성 코드**를 따로 갖고 있다. Aura 를 부르는 곳은 서버 `src/api-games.ts` 안의 두 라우트뿐이다.

**무엇을 바꿨나**
- 새 정본 `cloudflare-deploy/src/tts-short-text.ts` — `ttsShortText(text, lang)`
  - 영어(lang 이 `en…`) + 영문자·숫자·`'`·`,`·`-`·공백만 + **세 낱말 이하** + `. ! ?` 로 안 끝남 → 첫 글자 대문자 + 마침표(끝 쉼표는 뗌)
  - 그 밖(긴 문장·중국어·한글 섞임·숫자로 시작·이미 끝맺음)은 한 글자도 안 바꿈
- `src/api-games.ts`
  - `POST /api/voice/tts` — `text` 를 정본으로 만듦. **캐시 키(`TextEncoder().encode`)보다 먼저**라 옛 «낱말 그대로» 캐시본을 비켜 간다
  - `POST /api/review-quiz/tts`(복습퀴즈 듣기) — 같은 정본. 중국어 퀴즈는 `zh` 로 넘겨 병음이 안 바뀐다
- 화면 글자·채점은 그대로. `micro-quiz.html` 의 `ttsWord`(#1149)는 남겨 두었다 — 서버에서 `Study.` 는 그대로 통과하므로 무해하다.

**왜 서버 한 곳에서** — 화면마다 고치면 20곳을 따로 만지고, 자기 음성 코드를 가진 게임은 각각 다른 모양이라 빠뜨리기 쉽다. 앞으로 새 게임도 자동으로 적용된다.

**안 한 것**
- 기기 목소리(`speechSynthesis`)로 곧장 읽는 경로 — Aura 문제가 아니다.
- ~~`GET /api/exam/tts`(시험 듣기, MeloTTS)~~ — 처음엔 뺐다가 같은 날 사장님 지시로 추가(아래 7장).
- 세 낱말을 넘는 «마침표 없는 문장» — 캐시를 전부 다시 만들게 되어 뺐다.

**확인**
