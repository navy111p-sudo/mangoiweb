# 수강신청 일괄 등록 엑셀에 «강사» 칸 추가 (2026-09-24)

## 왜
사장님 제보 — 일괄 등록 뒤 자동으로 내려받는 엑셀(학생 이름·UID·…·인원 방식·시작일)에 강사 이름이 없어
누가 배정됐는지 따로 찾아봐야 했다.

## 무엇을 (PR #1144)
- `src/enroll-activate.ts` — 확정(activate) 응답에 실제 배정된 강사 이름 `teacher_name` 을 싣는다
  (배정 단계가 없거나 강사를 못 정했으면 null).
- `js/adm-core.js` v=241 — 다건·단건 내보내기(CSV·Word·카톡 요약)에 «강사» 칸.
  우선순위: 서버가 배정한 강사 → 폼에 적은 이름 → 빈칸.
  단건 경로는 강사 이름을 알 수 있게 내보내기를 확정 «뒤» 로 옮겼다.

## 버린 방법
- `steps[].detail` 문장(「FAR 배정」)에서 이름을 잘라내기 — 문구가 바뀌면 조용히 깨진다. 응답 칸으로 받는다.
- 폼의 `teacher_name` 만 쓰기 — 대부분 비워 두고 자동 배정하므로 늘 빈칸이 된다.

## 확인
- CSV 생성 함수를 오려 내 실제로 돌려 머리글·값 확인.
- `run.mjs --fast` — origin/main 기준선과 실패 목록 동일(17건, 환경 사유). 배포 게이트 CI 통과.
- 사장님 요청으로 수업 보호 창(목 12~16시) 중 `[deploy-now]` 로 즉시 배포.
- ❌ 배포된 화면은 못 봄 — 다음 일괄 등록 때 엑셀의 강사 칸을 사람이 확인해야 끝.

## 후속 — 신청 목록에서 골라서 엑셀·PDF 받기 (PR #1150)
- 사장님: 「엑셀로 다운 버튼이 없어?」 → A안(등록 순간 자동 다운로드는 유지 + 목록에 버튼) + PDF + «이 중에 선택».
- 「📋 신청 목록」 줄마다 체크박스 + 전체선택. 「📥 엑셀로 받기」·「📄 PDF로 받기」는 체크한 줄만,
  없으면 지금 보이는 목록(`__enShown` — 검색·상태·중복 필터 반영) 전체. 필터로 사라진 줄은 선택에서도 뺀다.
- PDF: 숨긴 iframe 에 표를 그려 인쇄 창 → «PDF로 저장». ⛔ 한글 PDF 라이브러리를 싣지 않음(글꼴 수 MB).
- 병합 때 main 과 `adm-core.js?v=242` 가 겹쳐 v=243 으로 비킴.
- 확인: 진짜 Chromium(API 스텁) — 1건 체크 → CSV 1행 / 해제 → 2행 / PDF iframe 2행·강사 칸.
- 목 12~16시 보호 창이라 보류됐던 것을 사장님 요청으로 `[deploy-now]` 즉시 배포.
