# 수업 화면 경계 드래그로 폭 조절 (2026-09-24)

## 왜
사장님 캡처: 교재 | 얼굴 경계(①)와 얼굴 | 채팅 경계(②)를 끌어서 늘리고 줄이고 싶다.
「수업에 지장은 없게, 가볍게」.

## 한 것
- 새 defer 파일 `cloudflare-deploy/public/js/idx-vc-splitter.js` + `index.html` 에 `<script defer>` 한 줄.
- PC(≥1025px)만. 폰·태블릿은 손잡이를 아예 안 그림(`.vc-split-h{display:none}` 을 미디어쿼리 «밖» 에).
- ① 얼굴 칸 왼쪽 가장자리 7px 손잡이 → `#vc-main-row.vc-split-on` + CSS 변수 `--vc-split-w`.
  교재 최소 320px · 얼굴 최소 180px. 전체영상·자유크기·솔로·PIP·접기에서는 손잡이도 폭도 저절로 비켜섬.
  크기바 버튼을 누르면 드래그 폭이 풀림(`vcSetVideoSize` 감쌈). 얼굴 폭은 기억하지 않음(학생 기본 크기와 싸움).
- ② 채팅 패널 왼쪽 가장자리 손잡이 → `--vc-chat-w`(260~760px, 화면 60% 이하). 이 기기에 기억(`vc_chat_w`).
- 두 손잡이 모두 두 번 누르면 원래대로.

## 가볍게 / 수업 지장 없음
- 상주 타이머·MutationObserver 없음. 누를 때만 포인터 이벤트, rAF 1회/프레임으로 변수 한 칸만 바꿈.
- 칠판·교재 다시 그리기(`wbResize`·`pdfResize`·`pdfRenderCurrent`)는 손을 뗀 뒤 한 번.
- 드래그 중 iframe 포인터 차단·transition 끔(포인터 캡처가 게임/영상 iframe 에 뺏기지 않게).
- 연결·영상·녹화 코드는 건드리지 않음. `idx-main.js`(blocking) 0바이트.

## 버린 방법
- 인라인 `width !important` — 크기바·전체영상 모드 전환마다 지워 줘야 하고 한 곳 빠지면 모드가 깨짐 → 클래스+변수로.
- 얼굴 폭 localStorage 기억 — 입장 때 기본 크기(vcSetVideoSize)가 즉시 풀어 버려 의미 없음.
