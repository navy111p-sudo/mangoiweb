# 수업 화면 «사용법 한 장» 안내 — 입장하면 먼저 + ❓ 버튼 (2026-09-24)

## 왜 했나
사장님 지시: 「수업 입장하면 학생용 한 장은 학생 수업화면에, 선생님용은 선생님 수업화면에 바로 먼저 보여줘.
언제나 궁금할 때 보게, 잘 보이는 곳에 버튼 만들어서 누르면 나오게 해줘.」
그림은 같은 날 만든 «왼쪽 화면 · 오른쪽 설명» 한 장 판(한국인 학생 판)입니다.
