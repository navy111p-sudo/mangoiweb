   - **중국어 학생은 뺍니다**(`classDayHome` — 영어 전용 낱말이라).
   - 「했나」는 `game_sessions` 의 `game='scene-words'` 오늘 기록(`api-students.ts`).

   - 고른 권은 기기에 기억(`mangoi_scene_book`) — URL `book=` 이 이깁니다. 모르는 id 는 무시.
3. **월간 성적표**(`api-reports.ts` `scene_words` · `monthly-report.html`) — 횟수·문제·맞힌 수 + «다시 볼 낱말»(틀린 수 ≥ 맞힌 수, 최대 10).
