# 학생 명부 「수강신청」 카드 (2026-09-24)

## 왜
- 관리자 › 학생 명부의 「수강신청」 칸은 카페24 `enroll_package` 를 그렸는데 전원 비어 «—» 였다.
- 사장님 지시: 가장 적당한 자리에 수강신청 칸을 두고, 학생마다 카드를 눌러 바로 수강신청 메뉴로.

## 한 것 (PR #1140)
- 칸 위치: 포인트 옆 → 「예약」 바로 옆(수업회수·예약·수강신청).
- 카드(`<a>`) → `smGoEnroll(uid)`: 「📚 수강신청 관리 › + 수강신청 등록」 표를 열고 그 학생 아이디를 채운다
  (같은 학생 줄이 있으면 그 줄, 빈 줄이면 채움, 없으면 새 줄 — 이름 자동 조회까지). 등록은 하지 않는다.
- 옛 `enroll_package` 값은 있으면 카드 아래 작게 남김.

## 버린 방법
- 「그 학생의 신청 목록으로」·「양식 등록으로」 — 사장님이 「수강신청 등록 표」로 확정.
- `<button>` — `details.menu-card button` 전역 !important 규칙이 큰 파란 알약으로 만든다(CLAUDE.md 2장). `<a>` 로.

## 확인
- 로컬 서버 + 크로미움: 머리글 순서, 클릭 → 등록 표 열림·아이디 채움·이름 「정예희」 조회·맨 위 요소 = 입력칸.
- 배포 게이트 통과. `--fast` 실패 목록은 main 과 동일(환경 사유 17건).
