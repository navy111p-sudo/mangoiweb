# 결재함 자동화 12단계 — 📒 간단 회계장부 · 📷 카드 영수증 사진 (2026-09-25)

## 1. 왜 했나
- 사장님 「간단한 회계장부도 자동으로 적당한 위치에 바로 나오게 — 이번 달 것과 일년치 것, 결제액수·날짜 오름차순 내림차순으로」.
- 제안서 ② «카드 맨 위에 요약 + 신호등 + **영수증 사진**»이 남아 있었습니다.
  - 휴대폰에서 «첨부 보기»는 내려받기라, 파일을 열었다가 결재함으로 돌아와야 했습니다.

## 2. 무엇을 바꿨나
| 자리 | 내용 |
|---|---|
| `approval-policy.ts` | `ledgerFrom(items)`: 승인된 지출 한 건이 장부 한 줄입니다. 대기·반려·취소 결재·금액 없는 건은 빼고, 대기와 금액 없음은 건수만 따로 셉니다. 합계는 통화별로 냅니다. `fileKind`·`fileDisposition`: 화면 안에 띄우는 것은 «사진이고 inline 을 요청했을 때»뿐입니다. |
| `api-approval.ts` | `?view=ledger`: 기존 «지출 정리»(report)와 같은 읽기·`canView` 거르기를 지나고, 줄 목록만 다르게 내보냅니다. 새 경로가 아니라 쿼리값 하나 추가입니다. 목록 한 줄에 `file_kind` 를 싣습니다. `/file?inline=1` 은 사진만 inline 으로 줍니다. |
| `work.html` | 「지출 정리」 위에 **회계장부** 칸을 두고 처음부터 펼칩니다. 홈을 불러 본 뒤 한 번 자동으로 불러옵니다(문서함과 같은 방식). 탭은 이번 달 / 최근 1년, 날짜·금액 머리글을 누르면 ▼↔▲. 결재할 사진 건 카드에 영수증 미리보기가 보입니다. |

## 3. 검토했다가 버린 것
- **대기 건도 장부에 넣기**: 아직 나가지 않은 돈이라 뺐습니다. 건수만 알려 줍니다.
- **₱와 ₩를 한 줄로 합치거나 금액 순서를 섞어 매기기**: 환율을 모르므로 버렸습니다. 금액 정렬은 같은 통화 안에서만 합니다.
- **장부 날짜를 «사용일»로**: 기간 거르기가 «올린 날» 기준이라, 사용일로 쓰면 이번 달 장부에 지난달 날짜가 섞입니다. 날짜 기준을 하나로 맞췄습니다.
- **PDF 도 화면 안에 띄우기**: 문서 뷰어로 여는 길은 열지 않았습니다. PDF는 예전처럼 내려받기입니다.
- **«일년치»를 올해(1월~)로**: 연초에는 거의 비어서, 최근 12개월로 했습니다.

## 4. 주의
- 장부는 첫 화면이 뜬 **뒤** 한 번 더 부릅니다(요청 1개 추가).
- 결재 권한자는 «전체», 그 밖의 사람은 «내가 올린 것»이 기준입니다. 인사·급여처럼 볼 권한이 없는 건은 서버가 이미 뺍니다.
- 한 번에 300줄까지 보여 줍니다(서버 상한 2,000건). 넘으면 화면이 그렇다고 말합니다.
