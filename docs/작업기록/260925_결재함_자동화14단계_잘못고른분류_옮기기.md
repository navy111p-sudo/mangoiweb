# 결재함 자동화 14단계: 🔀 잘못 고른 분류 알리기 · 옮기기 (2026-09-25)

## 1. 왜 했나
사장님 요청: 「휴가신청에 결제 영수증이나 물품주문을 잘못 올리면 "잘못 올렸다" 고 알려 주고, 자동으로 물품으로 옮겨서 올려 줄 수 있어?」

분류를 잘못 고르면 두 가지가 틀어집니다.
- **결재가 엉뚱한 사람에게 갑니다.** 물품 구입은 장 부장님 결재 → 대표님 확인인데, 휴가 신청이면 다른 흐름을 탑니다.
- **돈이 장부에서 빠집니다.** 휴가 신청으로 올린 돈은 회계장부(12·13단계)에 안 잡힙니다.

## 2. 무엇을 바꿨나

**`approval-policy.ts`**
- `misfileGuess({reqType,title,body,amount,hasFile})`
  - 휴가 신청·일반 문서인데 **주문** 이야기면 → 물품 구입으로 보냅니다.
  - 휴가 신청·일반 문서인데 **이미 낸 돈**(영수증·정산·택시…) 이야기면 → 지출 정산으로 보냅니다.
  - 물품 구입·지출 정산인데 **금액·영수증·돈 낱말이 하나도 없이** 쉬는 날 이야기뿐이면 → 휴가 신청으로 보냅니다.
  - **휴가 낱말과 돈 낱말이 섞이면 모른다(null)** 로 둡니다. 휴가 중 택시비 같은 글입니다.
  - 일반 문서는 원래 돈 이야기가 섞이므로 신호가 둘 이상일 때만 봅니다.
  - 불만·긴급·인사급여는 건드리지 않습니다.
- `amountInText`: 글 속 금액이 **정확히 하나** 일 때만 금액 칸을 채웁니다.
- 판정은 **낱말 목록으로 하는 결정론** 입니다(LLM 을 쓰지 않습니다). 모르면 알리지 않는 쪽으로 실패합니다.

**`api-approval.ts`** (`/api/approval/precheck`)
- 결과에 `misfile` 을 싣습니다.
- 그 사람이 **올릴 수 없는 분류는 권하지 않습니다**(`canSubmit`). 예를 들어 강사에게 물품 구입은 안 권합니다.
- 휴가·문서는 분류 확인만 하고 돌아갑니다. AI 검토를 부르지 않습니다.
- 금액이 없으면 AI 를 부르지 않습니다.
- 화면 목록 `misfile_check` 는 정본 `MISFILE_FROM` 하나에서 만듭니다.

**`work.html`**
- 분류 확인은 **금액·날짜 칸 검사보다 먼저** 합니다. 그렇지 않으면 「금액을 넣어 주세요」 에서 멈춰 잘못 고른 것을 영영 모릅니다.
- 노란 상자에 이유가 뜨고 버튼이 둘 나옵니다: **«물품 구입 으로 옮기기»** / **«휴가 신청 그대로 올리기»**.
- 옮기기를 누르면 제목·내용·휴가 날짜·붙인 파일을 지킨 채 분류를 바꿉니다.
  - 파일은 같은 길(`takeFile`)로 다시 받아 영수증 판독이 돕니다.
  - 글 속 금액이 하나면 금액 칸을 채웁니다.
  - 빠진 칸이 있으면 「금액 · 영수증 사진을 넣고 올려 주세요」 라고 말합니다.
- «그대로» 를 고르면 그 기안에서는 다시 묻지 않습니다. 분류를 새로 고르면 다시 묻습니다.
- 점검이 실패하면(회선) 막지 않고 예전처럼 올립니다(fail-open).

## 3. 검토했다가 버린 것

| 방법 | 버린 이유 |
|---|---|
| **옮긴 뒤 자동으로 올리기** | 물품 구입은 금액과 영수증 사진이 «반드시» 있어야 하고, 휴가 신청에는 그 칸이 없습니다. 자동으로 올리면 서버가 거절하거나 빈 금액으로 올라갑니다. 그래서 옮기고 채울 수 있는 것은 채운 뒤, **올리기는 사람이 한 번 누릅니다.** |
| **LLM 으로 분류 판단** | 비용이 들고 답이 흔들립니다. 틀린 제안은 제안이 없는 것보다 나쁩니다. |
| **서버가 올릴 때 분류를 몰래 바꾸기** | 사람이 고른 것을 말없이 바꾸면 «내가 올린 게 어디 갔지?» 가 됩니다. 사람이 고르게 둡니다. |
