# 결재함 자동화 17단계 — 회계장부 «빠진 것 점검» 탭

> 2026-09-25 · 사장님 「또 추가로 진행해줘」 → 15·16단계 장부 위에 «점검» 하나를 더함.

## 1. 왜
장부는 «올라온 돈» 만 보여 줍니다. 대표님이 실제로 궁금한 것은 반대쪽 — **«와야 하는데 안 온 것»** 입니다.
- 영수증 없이 승인된 지출(나중에 증빙을 못 찾음)
- 지난달엔 매달 나가던 돈(인터넷·전기·월세)이 이번 달엔 아직 안 올라옴(누락·지연)

## 2. 무엇을
회계장부 탭에 **「빠진 것 점검 (N)」** 을 «가게·큰 지출» 뒤·«장부 목록» 앞에 추가.
1. **영수증 없이 승인된 지출** — 정본 `ledgerChecks()`(`approval-policy.ts`).
   - `requiresFile` 분류만(물품 구입·지출 정산). ⚠️ `wantsFile` 이 아님 — 일반 문서는 붙일 수만 있고 없어도 정상(정리 카드 `no_file` 과 같은 기준).
   - 승인된 것만(대기·되돌림 제외) · 통화별 금액 큰 순 · 20건 + «외 N건».
2. **앞 달엔 있었는데 이번에 아직 없는 지출**
   - 같은 사람(아이디) · 같은 분류 · 같은 제목. 제목은 숫자·달 이름을 뺀 열쇠(`repeatTitleKey` — 「9월 인터넷 요금」 == 「10월 인터넷 요금」).
   - 이번 기간 **대기 중**인 것도 «올라온 것» 으로 봄(승인 전일 뿐 빠진 게 아님).
   - 앞 달은 15단계가 이미 읽는 `items2`(같은 조건·같은 canView 거르기)를 그대로 씀 — **추가 조회 없음**.
   - 승인된 지출이 0건인 빈 장부 화면에도 이 목록은 보여 줌(그때가 제일 중요).

## 3. «확인 못 함» 을 «빠진 것 없음» 으로 말하지 않기
`missing_why` 로 이유를 내려 주고 화면은 고르기만 합니다(✓ 는 확인했을 때만).
| why | 뜻 | 왜 확인 안 하나 |
|---|---|---|
| `period` | 올해 보기 | 달 단위 반복만 봄 |
| `truncated` | 이번 기간이 상한에서 잘림 | 잘린 건은 «올라온 것» 을 «없다» 로 오판 |
| `status` | 상태 필터가 걸림 | 대기 건이 빠져 «없다» 로 오판 |
| `prev` | 앞 달 조회 실패 | 모름 |

## 4. 버린 방법
- **금액·가게로 맞추기** — 월세가 조금 올라도, 가게 이름을 달리 써도 다른 건이 됨. 사람+분류+제목이 제일 덜 틀림.
- **자동 알림(문자)** — 한 번만 산 물건도 걸려 오경보가 많음. 화면이 «한 번만 산 물건일 수도 있으니 보고 판단» 이라고 말하는 선에서 멈춤.
- **`wantsFile` 로 영수증 판정** — 일반 문서가 늘 걸림(기존 코드 주석이 이미 경고).
