# 결재함 자동화 9단계 — 🤖 자동 반려 «켤지 말지» 판단 패널 + 알림은 문자로만 (2026-09-25)

## 1. 왜 했나
- 자동 반려는 지금 **연습(shadow)** 입니다. AI 가 🔴 로 본 건은 표시만 하고, 결재는 사람이 합니다.
  켤지 판단할 자료는 주간 요약 문자 한 줄뿐이었고, **켜고 끄는 스위치는 KV 에만 있어 화면에서 바꿀 방법이 없었습니다.**
- 사장님 지시(2026-09-25): 「ARS 음성 메시지는 하지 말고 문자로만 해줘」 → 잊은 결재 알림은 전화 대신 **문자**로 보냅니다.

## 2. 무엇을 바꿨나
| 자리 | 내용 |
|---|---|
| `approval-policy.ts` | `autoRejectReadiness`(not_yet / too_few / ready) · `autoRejectModeInput`(쓰기는 on·off·shadow 만, 모르는 값은 거절) · `nudgeSmsKind`(8시간·12시간에 문자 한 번씩) |
| `api-approval.ts` | `GET /api/approval/autoreject/report` · `POST /api/approval/autoreject/mode` — **경영진만**. 연습 성적은 `loadShadowRows` 한 곳에서 계산하고 주간 요약도 그 함수를 씁니다. 알림 회차는 12시간 «사이렌» 단계에도 문자를 보냅니다. |
| `work.html` | 경영진에게만 «🤖 AI 반려» 버튼. 14일 숫자, 판정, «AI 는 🔴 인데 두 분은 승인한 건» 목록과 이유, 마지막으로 바꾼 사람을 보여 줍니다. 켜기·끄기·연습으로 되돌리기 버튼이 있고, 켜기는 확인을 한 번 받습니다. |

## 3. 검토했다가 버린 것
- **AI 가 스스로 켜기(ready 가 되면 자동 전환)** — 버렸습니다. 켜는 순간 사람 손을 거치지 않고 필리핀 결재가 되돌아가므로 **사람이 누릅니다.**
- **모르는 값을 shadow 로 바꿔 저장** — 버렸습니다. 쓰기에서 조용히 바꾸면 «켰는데 안 켜짐» 이 됩니다. 400 으로 거절합니다(읽기는 예전대로 모르면 shadow).
- **ARS(음성 전화)** — 사장님 지시로 만들지 않습니다. 코드에도 없고, 하니스가 «ARS·음성 발송 코드가 없다» 를 못 박습니다.

## 4. 주의
- 스위치를 못 쓰면(KV 장애) 503 을 돌려주고 화면은 «바꾸지 못했습니다» 라고 말합니다. «바꿨다» 고 거짓말하지 않습니다.
- «며칠치 자료인가» 는 결재 기록의 첫 날부터 셉니다(최대 14일). 기록이 짧으면 짧다고 말합니다.
- 문자는 밤(22~8시 KST)에는 단계를 올리지 않으므로 나가지 않습니다(긴급은 예외 — 원래 규칙 그대로).
- 사이렌 문자가 추가되어 **한 건에 문자가 최대 두 번**(8시간·12시간) 나갑니다. `approval_sms=off` KV 스위치로 전부 끌 수 있습니다(원래 있던 것).
