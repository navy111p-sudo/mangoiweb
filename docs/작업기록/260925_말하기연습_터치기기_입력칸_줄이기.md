# A.i 말하기 연습 — 휴대폰·태블릿에서 입력 묶음 줄이기 (2026-09-25)

## 왜 했나
사장님 캡처(휴대폰 세로, 중국어 메이 선생님, 자동 말하기): 아래 입력 묶음이 커서 선생님이 방금 한 말
(「你觉得看电影最好是在哪里看？」)이 가려졌다. 시안 5종(`docs/말하기연습_휴대폰입력칸_줄이기_샘플4종_2026-09-25.html`)
중 **A+C 중간안**으로 결정. 「휴대폰과 테블릿에서만 적용해줘. 가로 세로 모두」.

## 한 것 (`warmup.html` 끝의 `<style id="touch-compact-2026-09-25">`)
- 판정은 폭이 아니라 **터치 기기** — `@media (hover:none) and (pointer:coarse)`. 마우스 PC 는 좁은 창이어도 그대로.
- 얼굴 56px(눕힌 폰 40px)로 줄이고 이름·진행 문구와 한 줄에.
- 「말하는 방법」 스위치 작게, 폭이 되면 «듣는 중» 과 한 줄에. 400px 이하 폰에서는 「말하는 방법」 글자를 뺌.
- 듣는 동안 같은 말 세 번(자동 알약 · wgState · #listening) → #listening 하나만(`:has()`).
- 사용법 줄(.hint)은 학생이 한 번 말한 뒤 감춤.
- 눕힌 폰: `warmup-guide.css` 의 `min-height:520px` 가 화면(390px)보다 커서 입력칸·⏹ 이 화면 밖에 있었다
  (**고치기 전에도 그랬다**). 터치+세로 520 이하에서 풀고, 주제·콤보 칩 줄을 감춤.

## 잰 값 (중국어 · 자동 · 듣는 중, 헤드리스 크로미움)
| 화면 | 입력 묶음 전→후 | 대화칸 후 |
|---|---|---|
| 폰 세로 390×844 | 272 → 131px | 459px |
| 작은 폰 360×640 | 312 → 131px | 255px |
| 폰 가로 844×390 | 228(⏹ 화면 밖) → 97px | 117px |
| 태블릿 세로 768×1024 | 254 → 97px | 659px |
| 태블릿 가로 1024×768 | 254 → 97px | 403px |
| 마우스 PC 1280·390 | 그대로 254·272px | — |

## 버린 방법
- 폭(max-width)으로 가르기 — 지시가 «휴대폰·태블릿» 이라 좁은 PC 창까지 바뀌면 안 된다.
- «듣는 중» 문구를 JS 에서 하나로 합치기 — 자동 말하기 파일(`warmup-auto-talk.js`)의 단계 표시(말하는 중·확인 중·완료)까지 건드린다. CSS 로 «듣는 동안만» 감췄다.
