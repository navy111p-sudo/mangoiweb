# 수강 운영 관리 — 정리(D) → 공휴일 한 곳 → 오늘 할 일(C) (2026-09-25)

## 왜 했나
사장님 요청: 「수강 운영 관리」 기능이 다른 사이드바 메뉴와 얼마나 겹치는지 보고 개선안 4개를 만들 것 →
제안서(A 제자리로 이사 · B 수강 한살이 허브 · C 오늘 처리할 일 · D 최소 정리) 중
추천 순서 「D로 먼저 정리 → 공휴일 저장 위치를 한 곳으로 → C로 완성」 그대로 진행.

## 한 것
1. **D 정리**
   - 「💸 환불 계산기」 탭 삭제 — 정산·매출 › 환불 처리(`/admin/refunds.html`)가 같은 계산 + 실제 환불까지 한다. 옛 `#refund` 주소는 그 화면으로 보낸다.
   - 탭 이름을 쉬운 말로: 강사 배율 → 💲 수업료 배율, 자동 작업 점검 → 🔔 자동 문자.
   - 사이드바에서 「수강 운영」을 강사 그룹 → 학생 그룹(수강신청 바로 아래)으로 이사.
     ⭐고정·최근 메뉴가 옛 자리를 가리켜도 이어지게 `RENAMED` 에 두 줄(`teacher:수강 운영(배율·정원)`·`teacher:수강 운영` → `student:수강 운영`).
   - 각 탭에 「같은 일을 하는 다른 곳」 한 줄 · 폰에서 탭 한 줄 가로 스크롤 · 표를 카드로 · 버튼 44px · 🌐 EN/KO.
2. **공휴일 한 곳** — 수업을 «미는» 표는 `enroll_holidays` 하나뿐(6시 cron `runHolidayShiftSweep` 이 이것만 읽음).
   - `calendarHolidaysMissing()` 이 캘린더(`calendar_events.holiday`, KR·나라 빈칸)에만 있고 수강 운영에 없는 **앞으로의** 날을 찾아 공휴일 탭에 «옮기기 / 모두 옮기기» 로 보여 준다(기존 POST 경로 재사용).
   - 캘린더 「공휴일 등록」 옆에 «여기 넣은 공휴일은 수업을 미루지 않습니다 → 수강 운영에서» 안내.
3. **C 오늘 할 일** — 첫 탭. `GET /api/pay/enroll/admin/todo` 한 번으로 종료 후보·만료 문자 예정·다가오는 공휴일(걸린 수업 수)·캘린더에서 빠진 공휴일·다가오는 강사 휴가를 급한 순서로.

## 검토했다가 버린 것
- **cron 이 캘린더 공휴일도 읽게 하기** — 필리핀 공휴일·오타가 섞인 표라 자동으로 수업이 밀리면 되돌리기 어렵다. «사람이 한 번 눌러 옮기기» 로 둠.
- **«비는 수업 N건» 계산** — 휴가 강사 이름으로 수업표를 이어야 하는데 강사 이름이 세 벌이라 남의 수업이 붙을 수 있다(CLAUDE.md 「남의 이름이 뜸」). 휴가 «건수» 까지만 말한다.
- **오늘 할 일에서 공휴일 이동 미리보기(sweep dry)** — 공휴일마다 수업×충돌검사라 첫 화면에 무겁다. 걸린 수업 «수» 만 센다.
- **운영 인프라 모듈 ③ `holidays` 표 정리** — 이번 범위 밖(레거시 모듈). 그대로 둠.
