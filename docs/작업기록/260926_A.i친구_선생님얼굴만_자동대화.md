# 2026-09-26 A.i 영어친구 — 선생님 얼굴과만 자동 대화 (1안)

## 왜
사장님: 「선생님 얼굴 버튼을 누르면 다른 것 없이 선생님과 대화만 자동으로. 선생님 얼굴만 보이게.」
→ 시안 4종(A 얼굴 가득 · B 동그란 빛 · C 끌어올리는 자막 · D 큰 버튼) → 「A와 C 혼합으로 4가지」
→ **1안(얼굴 가득 + 유리판 자막)** 선택. 추가 지시 「끌어올리는 동작을 몰라도 자동으로 해줄 수 있어?」.
시안: https://claude.ai/artifact/8KLLbxfZ8MguLvK9LtnSKd

## 무엇을 했나
- 새 파일 `cloudflare-deploy/public/js/aifriend-facetalk.js`(defer), `ai-friend.html` 에 `<script>` 한 줄(`?v=1`).
- 선생님 얼굴 카드(`#tavatar-ring`)에 초록 ▶ 표시 → 누르면 얼굴이 화면 가득, 채팅·버튼·설정은 가려짐.
- 순서: 선생님 인사 → 학생 말 듣기(`MangoiVoice.record`, 조용함 2.5초면 끝) → `sendMsg()` → 선생님 대답 → 다시 듣기.
- 화면 가장자리 색: 초록=들음 · 노랑=생각 · 주황=말함 · 회색=쉼. 아래 막대도 같은 색.
- 유리판(자막): **끌어올리기를 몰라도 되게**
  1. 막히면 저절로 열림(9초 무음·소리 안 들림·받아적기 실패) + 대답 보기 칩(빈칸 칩 제외)
  2. 손잡이 한 번 탭으로 열고 닫음(끌어올리기·내리기도 됨)
  3. 이 기기에서 처음이면 한 번 저절로 올라왔다 내려감
- 두 번 연속 조용하면 쉬기(마이크 끔) → 얼굴을 누르면 다시 시작. 선생님이 말하는 중에 얼굴을 누르면 끊고 바로 듣기.
- ✕·Esc → 얼굴 카드를 원래 자리로 되돌리고, 대화는 채팅창에 그대로 남음.

## 지킨 것 (CLAUDE.md 함정)
- **선생님이 말하는 동안 녹음 안 함**(2026-07-23 사고) — `speakText` 를 감싸 «남은 낭독» 을 세고 0 이 된 뒤 0.7초 더 조용해야 듣는다.
- **무음에서 Whisper 가 지어낸 말은 버림** — `speaking` 상태를 한 번도 못 본 녹음의 전사 결과는 안 보냄.
- 새 판정·새 API 없음 — `sendMsg`·`stopSpeakingNow`·`helpChipsFor` 등 화면의 정본을 그대로 부름(교정 카드·포인트·스트리밍 낭독이 예전대로 돈다).
- 얼굴은 새로 그리지 않고 카드를 «옮겨» 옴 → 립싱크 그대로.
- 상주 타이머·body class 감시 없음(모드가 켜진 동안만).
- 입력칸은 이 모드 동안 읽기 전용 — `sendMsg` 끝의 `input.focus()` 로 폰 키보드가 튀어나오는 것 방지.

## 버린 방법
- **`mango-avatar.js` 의 캔버스 해상도(320) 올리기** — 5개 화면 공용이고 초록 제거 계산이 4배가 되어 저사양 폰이 버거움. 대신 폰 세로는 `cover`, PC·가로는 `contain`(잘림 없음).
- **`micViaWhisper()` 재사용** — 그 함수는 안내 토스트(얼굴 화면 밑에 깔림)를 띄우고 «말이 한 번도 안 들린» 녹음을 구분하지 않음.
