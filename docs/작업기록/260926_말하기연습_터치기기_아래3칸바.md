# A.i 말하기 연습 — 휴대폰·태블릿 «아래 3칸 바» (2026-09-26 · 시안 4)

## 왜 했나
#1228(A+C 중간안) 뒤에도 사장님 「1,2번이 아직도 너무 복잡하고 혼란 스러워」. 시안 4종
(`docs/말하기연습_단순화_세로가로_샘플4종_2026-09-26.html`) 중 4번(아래 3칸 바)을 추천했고
「추천한대로 진행하는대신 자동,버튼은 잘 좀 보이게 해줘」.

## 한 것 — `js/warmup-touch-bar.js?v=1` (터치 기기에서만)
- 화면 아래는 두 줄뿐: ① 「말하는 방법」 🎤 버튼으로 | ✨ 자동으로 (꽉 찬 폭, 42px, 고른 쪽 하늘색 + ✓)
  ② 💡 도움 · 🎤 말하기(가운데 크게, 듣는 중이면 빨간 ⏹) · ⌨ 글쓰기.
- 이전 대화·대답 도움·새 질문·그림·끝내기는 «💡 도움» 시트 하나에 — 전부 **원래 버튼을 대신 누른다**(새 판정 없음).
- 입력칸은 ⌨ 를 눌렀을 때만. 평소 안내 줄은 감추고 «멈춤·오류·답 준비 중» 같은 문구만 한 줄로 옮긴다.
- 스위치는 `warmup-auto-talk.js` 가 만든 `#talkSwitch` 를 그대로 옮겼다(그 파일은 id 로 다시 그리고 요소에 click 을 묶는다).
- 눕힌 폰: 스위치와 3칸을 한 줄(48px).
- 관찰자는 `.wg-composer` 하나만 본다(⛔ body 관찰 금지), 바뀐 값만 쓴다.

## 버린 방법
- 스위치를 3칸 안에 넣기 — 「잘 보이게」 지시와 반대라 한 줄을 통째로 줬다.
- 「베타」 표를 바에도 두기 — 360px 폰에서 「자동으로」 글자가 잘렸다(바에서만 뺌. ⋮ 메뉴·설정 화면엔 그대로).
