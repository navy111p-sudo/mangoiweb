# 260926 A.i 말하기 연습(웜업) — 선생님 얼굴과만 자동 대화

## 왜 했나
- 사장님이 «선생님 얼굴만 보고 자동으로 대화» 1안을 고르셨다. 먼저 **A.i 영어친구**에 넣어 배포했다(#1231).
- 그런데 사장님이 실제로 쓰시는 화면은 **A.i 말하기 연습(웜업, `warmup.html`)** 이었다. 스크린샷을 보내시며 「보이지 않아」.
  ⟹ 같은 얼굴 대화를 웜업에도 넣었다.

## 무엇을 바꿨나
- 새 `js/warmup-facetalk.js` — 얼굴 카드 ▶ 를 누르면 얼굴이 화면 가득, 글·버튼은 가려진다. 모양(#ftk)은 A.i 친구하기와 같다.
- **듣기·보내기를 새로 만들지 않았다.** 웜업에는 이미 «✨ 자동으로 말하기(베타)» 엔진(`warmup-auto-talk.js`)이 있다.
  얼굴 화면은 그 엔진을 «켜고» 모양만 바꾼다 → 에코 방지(AI 말하는 동안 안 열기)·말 끝 판단·Whisper 폴백·두 번 못 들으면 쉬기가 정본 그대로.
- 엔진은 «못 들음» 뒤 다음 AI 말까지 기다린다. 얼굴 화면에는 🎤 버튼이 없으니 **대답 보기를 펼치고 한 번 더 듣는다**
  → 엔진에 `arm` 한 줄을 내보냈다(`warmup-auto-talk.js?v=5`). 못 들은 횟수는 엔진이 세어 두 번이면 쉰다.
- 유리판: 막히면 저절로 열림(서버가 준 «대답 보기» 목록 그대로 — 8초 기다리지 않음) · 한 번 탭 · 처음 한 번 보여 주기.
- 나갈 때 **말하는 방법 저장값을 들어오기 전으로** 되돌린다(학생이 고른 버튼 모드를 바꿔 두지 않음). 소리를 꺼 두었으면 이 동안만 켠다.
- 화상수업 안(iframe)에서는 입구가 없다(자동 말하기가 거기서 꺼져 있는 것과 같은 이유 — 선생님 목소리 에코).
- `warmup.html` `micViaWhisper`: **말소리가 한 번도 안 들린 녹음의 전사를 버린다**(Whisper 가 무음에서 "Thank you." 를 지어냄).
  자동 말하기·얼굴 대화는 조용한 순간에도 마이크를 열어서 잦다. A.i 친구하기 얼굴 대화와 같은 규칙.

## 검토했다가 버린 것
- 얼굴 화면용 녹음·전송 로직을 따로 만들기 — 판정이 두 벌이 된다(CLAUDE.md «같은 판정이 두 곳이면 한쪽만 고쳐진다»).
- A.i 친구하기 파일과 공용 모듈로 합치기 — 이미 배포·검증된 파일을 다시 흔든다. 지금은 CSS 를 같은 값으로 두고, 다음에 손댈 때 합친다.
- `setMode('auto')` 로 다시 열기 — `wake()` 가 못 들은 횟수를 0 으로 되돌려 **영영 쉬지 않는다**. 그래서 `arm` 을 내보냈다.
