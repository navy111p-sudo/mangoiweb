# 학생 목록 학습 유형 표시

## 요청과 변경
학생 목록에서 화상수업 학생과 AI 전용 학생을 구분한다. 화상수업에는 AI 학습이 무료로 포함되므로 별도의 ‘화상+AI’ 그룹은 만들지 않는다.

- 이름 아래 파란 화상수업 / 보라 AI 전용 / 회색 미수강 배지.
- 기존 unified API에 track=1을 요청하고 서버의 청구 기준 분류를 그대로 사용한다. live_ai → 화상수업, ai_only → AI 전용, idle/none → 미수강. 알 수 없는 값은 확인 필요로 표시한다.
- 서버 분류는 수업·신청 기록에 따른 기존 운영 기준이며, 이 변경이 현재 수강권 만료 검증을 새로 구현하는 것은 아니다. 청구·이용 권한·DB는 변경하지 않는다.
- 화상수업 배지 툴팁과 필터 안내에 AI 학습 무료 포함을 표시한다.
- 상단 인원 필터는 불러온 명부(기존 최대 1000명) 안에서 이름/학원 검색 및 대리점 필터와 함께 적용한다. 전체 재원 통계로 오해하지 않도록 ‘불러온 목록 기준’을 표시한다.
- CSV에도 동일한 필터와 학습 유형/AI 무료 포함 열을 적용한다. 필터 결과 0명일 때 이전 청크가 스크롤로 다시 나타나지 않게 한다.
- 기존 검증 두 개는 필터를 공통 함수로 추출한 구조를 검사하도록 수정했다. 검사 제거 없음.

## 선택하지 않은 방법
AI 사용 이력이 없다는 이유로 AI 전용으로 분류하지 않는다. 새로운 DB 필드나 수강권 판정 규칙을 만들면 기존 청구와 달라지고 카페24 동기화와 충돌할 수 있어 기존 서버 track을 사용한다.

## 검증
- TypeScript noEmit: 성공.
- 빠른 회귀 검사: 최초 408 PASS / 20 SKIP / 5 FAIL. 이 중 2개는 검사 시작 시 의존성 연결 전이라 실행 불가, 3개는 공통 필터/배선 변경에 따른 소스 계약 불일치였다. 수정/준비 후 실패한 5개 모두 개별 재검사 통과(admin API 40, AI report 20, student list 35, hidden 45, teacher feedback 63).
- 자산 버전 검사: 253 통과. adm-core 캐시 버전 변경.
- 실제 목록 코드와 HTML을 jsdom에서 실행: API track 요청, 서버 5개 상태, 학원/검색/유형 복합 필터, 0명 스크롤 상태, 한영, 키보드, CSV 통과.
- 실제 Chromium 시각 검증은 미실시: 실행 파일이 없고 브라우저 다운로드도 실패. 실제 운영 데이터 화면 및 모바일 시각 확인은 남아 있다.
