# 홈 밝은 배경 구름 윤곽

사용자 요청: 밝은 배경을 흐리게 하지 않고 구름 모양이 적당히 보이게 조정.

확인: 정상 모드는 배경에 blur(3px), scale(1.06), 전면 비네트가 적용된다. 저속 모드는 원본 배경을 받지 않고 40×22 축소 사진을 확대한다. 제공된 캡처만으로 저속 모드 여부는 확정하지 않았다.

변경: 기존 defer 테마 파일 idx-theme-mobile.js에 홈 밝은 테마 전용 CSS를 추가했다. blur와 확대를 제거하고 중앙의 글자 대비용 음영만 남겼다. 저속 모드는 인라인 SVG 구름을 사용해 추가 이미지 요청 없이 윤곽을 유지한다. 정상 모드의 32KB 원본 이미지, 어두운 테마 및 수업 테마와 시간대 전환은 그대로다.

대안: 저속 모드에서 원본 이미지 다운로드를 강제하는 방식은 공유 회선 보호를 유지하기 위해 사용하지 않았다. 첫 화면 HTML 변경 없이 기존 defer 파일에 약 2.1KB만 추가했다.

검증: node --check 통과. 기존 원본 배경 이미지 육안 확인. 로컬 브라우저 설치는 다운로드된 ZIP 오류로 실패하여 브라우저 렌더링 검증은 하지 못했다. PR CI에서 타입 검사, 회귀 하니스, 인라인 JS, 버전 검사를 수행한다. 최종 CI 및 배포 상태는 PR/Actions 결과를 확인할 것.
