# 홈 구름 실사풍 통일

사용자 후속 요청: 구름을 실사에 가깝게 표시.

앞선 PR #1240은 저속 모드에서 인라인 SVG를 사용해 추가 이미지 요청 없이 윤곽을 유지했으나, 단순 도형이라 사진 같은 질감이 없다. 이번 요청에 따라 이 SVG를 기존 32,458바이트 WebP 구름 이미지로 교체한다. 저속 모드의 밝은 홈에 한해서 이 이미지 한 장을 허용하며, 다크 모드와 영상 등 다른 저속 회선 보호는 유지한다.

구름 원본은 기존 Higgsfield 실사풍 이미지이며 실제 촬영 사진이라고 주장하지 않는다. 흐림/확대 제거 및 중앙의 절제된 음영은 그대로 유지한다. 새 이미지나 라이브러리 추가 없이 기존 자산을 재사용한다. 캐시 버전은 v4로 갱신한다.

검증: node --check 통과. PR 정식 CI 통과 후 병합하며 배포 뒤 일반/저속 밝은 모드를 확인한다. 실제 결과는 PR 및 배포 실행 기록을 참조한다.
