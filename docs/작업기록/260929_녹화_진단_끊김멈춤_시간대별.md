# 녹화 진단 — «이 수업이 잘 진행됐는가, 안 됐으면 언제 무엇이» (2026-09-29)

## 왜 했나
사장님 요청: 「녹화된 것을 AI가 스스로 확인해 잘 진행됐는지, 안 됐으면 문제점을 간단히」 + 예시로 「08:11에 잠시 끊김, 화면 멈춤」.

## 무엇을 했나
- 관리자 › 녹화 목록 한 줄마다 **🩺 진단** 버튼이 생겼습니다. 누르면 그 줄 밑에 판정(✅ 정상 / ⚠️ 주의 / ❌ 문제 / ❔ 확인 불가)과 «녹화 몇 분째에 무엇이» 목록이 펼쳐집니다.
- 판정 정본: `cloudflare-deploy/src/recording-diagnosis.ts` (순수 함수 — **AI 아님, 규칙 판정, 비용 0원**).
- 서버: 기존 `GET /api/recordings` 에 `?diagnose=<녹화 id>` 갈래를 더했습니다. 이미 로그인·본사 전용 게이트를 지나는 경로라 `src/index.ts`(공동 금지구역)는 한 줄도 안 건드렸습니다.
- 화면: `public/js/adm-core.js` 의 `recDiagnose()` — 서버가 만든 문장을 «그리기만» 합니다.

## 근거로 읽는 기록
| 사건 | 근거 | 정밀도 |
|---|---|---|
| 🔌 끊겼다가 재입장·🕒 늦은 입장 | `attendance` (입장할 때마다 한 행, 서버 시각) | **초** («08:31») |
| 🧊 화면 멈춤·🔇 소리 끊김·📵 음성만·🐢 지연 | `vc_quality` 1분 요약 (`rx_freeze`·`rx_conceal`·`aao`·`avg_rtt`) | **1분** («08~09분대») |

문턱: 소리 끊김 5% 이상(15% 이상이면 ❌), 멈춤 1회 이상, 지연 800ms 이상, 발화 40% 미만, 녹화 5분 미만, 3분 넘게 늦은 입장. 정본 `DIAG` 상수.

## 검토했다가 버린 것
- **AI(LLM)가 판정** — 같은 녹화에 날마다 다른 답이 나올 수 있고 비용이 듭니다. 규칙 판정으로 두고, 필요하면 나중에 «문장만» AI로 다듬을 수 있습니다.
- **AI가 영상을 직접 봄/들음** — 녹화는 webm 60~70MB이고, 워커에서는 소리를 뽑을 수 없습니다. 미성년자 음성을 외부로 보내는 동의 문제도 있습니다. 별건입니다.
- **목록에 «진단» 칸을 새로 추가** — 표 칸 수(th·td·colspan)를 못 박아 둔 하니스가 여럿이라, 버튼(재생 칸 안)으로 두었습니다.

## 한계 (그대로 말합니다)
- 멈춤·소리는 1분 단위입니다. 회선 기록은 **30일만** 보관되어 옛 녹화는 「회선 기록 없음」으로 나옵니다.
- **기록이 없으면 «정상» 이라 하지 않습니다**(❔ 확인 불가). 조회가 실패해도 마찬가지입니다.
- 원인(회선·탭 닫기·배포)까지는 가리지 못합니다.
- 입장 기록이 재접속마다 새 행을 남기는지는 `/api/attendance/join` 호출 시점에 달려 있습니다 — 페이지를 다시 열지 않고 소켓만 다시 붙은 끊김은 «재입장» 으로 안 잡힐 수 있습니다(1분 기록의 멈춤·음성만으로는 보입니다).
