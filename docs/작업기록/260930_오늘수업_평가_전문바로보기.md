# 「오늘 수업」 지난/오늘 평가 — 눌러서 전문 바로 보기 (2026-09-30)

## 왜
매니저 제보: 「오늘 수업」의 **Last class feedback / Today's feedback** 칸이 90자로 잘린 한 줄이라,
대체강사(커버 수업)가 «지난 수업에서 무엇을 했나» 를 읽으려면 다른 화면을 찾아가야 했다.

## 한 것 (추천 순서 ①·②)
- ① **세 화면에서 눌러 전문 보기** — 관리자 「오늘 수업」(`js/adm-today-classes.js`)·매니저(`manager.html`)·강사(`teacher.html`).
  공용 창 `js/eval-quick-view.js`(`window.mgEvalQuick(id,{en})`)가 `GET /api/eval/:id` 로 전문을 그린다
  (수업·태그·강사 영어 메모·학부모 안내(한국어)·잘한 점·보완점·다음 목표·코멘트).
- ② **오늘 일지 쓰기** — 강사 화면에는 이미 있다(수업이 끝나면 「일지 쓰기」/「일지 ✓ 보기」). 이번에 새로 만든 것 없음.

## 검토했다가 버린 방법
- **eval.html(학부모 화면)로 보내기** — 그 화면은 강사가 영어로 쓴 본문(`note_en`)을 한 줄도 안 그린다. 필리핀 강사·매니저에게 쓸모가 적다(창 아래에 링크로만 남김).
- **창 코드를 세 화면에 복제** — manager·teacher 는 «첫 화면 외부 리소스 0개» 계약이라 정적 `<script src>` 를 못 넣는다.
  대신 **처음 누를 때만** 공용 파일을 불러온다(첫 화면 비용 0, 판정 한 벌).
- **관리자 칸에 `<button>`·인라인 색** — `details.menu-card button` 전역 알약 규칙, `details.menu-card a{#60A5FA!important}` 가 덮는다.
  → `<a class="tc-evq-link">` + `css/admin-inline-c.css` 맨 끝 `#sm-today-classes a.tc-evq-link`(v=83).

## 남은 것 (사람이 정할 일)
- ③ **수정 API(`PATCH /api/eval/:id`) 없음** — 창은 «보기 전용» 이라고 말한다. 누가 남의 평가를 고칠 수 있나 / 이미 학부모에게 나간 평가를 고치면 재발송하나 — 결정 대기.
- (기존 구멍) `GET /api/eval/:id` 는 관리자 세션이면 지사·대리점도 통과한다(`resolveOwnerScope`). 화면은 `eval_hidden` 이라 id 를 안 주지만 id 열거로는 읽힌다.
- `eval-quick-view.js` 를 고치면 **세 곳의 `?v=`** 를 함께 올릴 것(JS 가 주소를 만들어 asset_version 가드가 못 본다 — 하니스 D-9 가 셋이 같은지 본다).
