# 학생 상세 › 출결 현황 — 출석 캘린더를 PC «월별 달력» / 휴대폰 «5주 ✓ + 집중도 그래프» 로

- 날짜: 2026-09-30
- 파일: `cloudflare-deploy/public/admin/student.html` (`renderAttendance` · CSS `.ac-*` · 제목 h3)

## 1. 왜 했나
사장님 제보(jeong 학생 화면 캡처): 「이게 이해가 가지 않아」. 색칸만 늘어서 있고 무슨 날인지 알 수 없었습니다.

## 2. 잰 것 (코드에서 확인)
- **위쪽 큰 빈 공간은 버그** — 제목·그리기는 «최근 90일» 인데 데이터는 `?days=` (기본 30)만 받아 옴 → 앞 60칸이 늘 «기록 없음».
- 한 줄 15칸이라 주(7일)와 안 맞고 날짜·요일 표시가 없음.
- 색은 «출석» 이 아니라 그날 «집중도(시선 점수)» 인데 범례에 «출석» 파랑이 따로 있어 빨강이 «결석» 으로 읽힘.
- 날짜를 `toISOString()`(UTC)로 만들어 KST 오전 9시 전에는 하루 밀림(attendance.date 는 KST).

## 3. 한 일 (사장님 결정: 시안 4종 → PC A · 휴대폰 C)
- 그리는 날 수 = 받아 온 기간(`_state.days`). 제목은 「📅 출석 캘린더」 + 아래 줄에 「최근 N일 (시작 ~ 오늘)」.
- **PC(>720px)**: 월별 달력. 요일 머리글(월~일), 칸 안 날짜 숫자, 오른쪽 아래 「N회」(그날 수업 수), 칸 색 = 집중도, 오늘 테두리, 기간 밖 날짜는 흐리게.
- **휴대폰(≤720px)**: 최근 5주(기간이 짧으면 기간만큼) 주별 줄 — 수업한 날 ✓, 없는 날은 점선 칸에 날짜. 아래에 집중도 선 그래프(40·70 점선, 점 색 = 구간).
- 두 모양을 다 그리고 CSS `@media (max-width:720px)` 로 하나만 보임(리스너·타이머 없음).
- 날짜를 KST 기준으로 통일(「수업 기록이 없는 평일」 목록도 같은 기준).
- 밝은 테마라 처음부터 밝은 색 값 사용(CLAUDE.md 2장 「다크 화면을 새로 만들었더니」).

## 4. 검토했다가 버린 것
- 한 모양으로 둘 다: 월별 달력은 폰에서 세로로 길고 칸이 작음, 5주 줄은 PC에서 긴 기간을 못 보여 줌.
- 시안 B(요일 줄무늬)·D(주간 표): 폰에서 가로 스크롤이 필요하고 날짜가 안 보임.

## 5. 확인한 방법
- 로컬 서버 + 헤드리스 크로미움(API 스텁)으로 1280px·390px 렌더, 30일(1개월)·365일(12개월)·EN 전환에서 오류 없음.
- 390px 에서 캘린더 요소 중 화면 밖으로 나가는 것 0개(페이지 가로 넘침 597px 은 기존 상단바 버튼 탓 — 이번 변경과 무관).
- `node test-harness/run.mjs --fast` 를 main 기준선과 FAIL 목록으로 대조.

## 6. 남은 것
- «결석» 판정은 여전히 불가 — 예약 요일(class_schedules)이 이 응답에 없음. 캘린더는 «수업 기록이 있다/없다» 만 말합니다.
- 상단바가 390px 에서 가로로 넘치는 문제(기존)는 별건.
