# AI 친구 — 폰에서 AI 답이 끝날 때마다 키보드가 올라와 화면을 덮음 (2026-10-01)

## 왜 했나
사장님 캡처(폰 세로): AI 친구에서 AI 말이 끝나면 곧바로 키보드가 올라와 화면 절반을 가림 → 매번 뒤로가기.
「AI 말하기 연습(웜업)에서는 안 그런다.」

## 원인
`ai-friend.html` 의 전송 처리 `finally` 에 `input.focus()` 가 있어, 답이 끝날 때마다 입력칸에 포커스를 줌.
폰에서는 포커스 = 키보드 표시. PC 에서 바로 이어 치게 하려던 코드가 폰에서는 화면을 덮음.
웜업(`warmup.html`)에는 이 자동 포커스가 없어 문제가 없었음.

## 고친 것 (PR #1321)
`matchMedia('(pointer: coarse)')`(터치 기기)면 자동 포커스를 하지 않음. PC 는 그대로.
빈칸 칩(`helpPick`)을 눌렀을 때의 포커스는 학생이 직접 누른 것이라 그대로 둠.

## 버린 방법
- 포커스를 지운 뒤 `blur()` — 포커스를 주지 않는 것보다 키보드가 한 번 깜빡여 더 나쁨.
- 화면 폭(px)으로 판정 — 태블릿·가로 폰을 놓침. 입력 방식(pointer)이 정확한 축.
