## 검토했다가 버린 것
- **30분 경계를 «30분 이상» 으로**: 급여(`api-admin.ts` 연기 요청 저장부)가 `minutes_before > 30` 이라
  학생만 `>=` 로 하면 «학생은 차감 안 됐는데 강사는 전액» 이 된다. 같은 기준으로 맞췄다.
  ⟹ **정확히 30분 전 요청은 «늦은 연기(결석 처리)»**. 바꾸려면 두 곳을 함께.
- **요청 기록 없는 연기를 결석으로**: 관리자가 상태만 바꾼 연기는 «언제» 를 모른다 → 연기로 둔다(급여와 같은 판단).
- **기록이 없으면 결석으로**: 지어내지 않는다 → «미정», 차감 안 함, 사람이 확인.
- **class_schedules 에 상태를 써 넣기**: 기존 표를 고치면 급여·노쇼 리포트와 어긋난다. 읽어서 판정만 한다.
