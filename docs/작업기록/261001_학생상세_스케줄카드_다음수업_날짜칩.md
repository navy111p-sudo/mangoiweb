# 학생 상세 «등록된 수업 스케줄» — 다음 수업·날짜 칩·연기/변경 (2026-10-01)

## 왜 했나
사장님 판단: 「시작 날짜보다 **앞으로 수업할 일시**가 더 중요하다」. 옛 카드는 요일별 줄만 있었고,
그 줄에는 시작일만 적혀 있어서 다음 수업이 언제인지 알려면 머릿속으로 계산해야 했습니다.
시안 4종, 그다음 PC·휴대폰 시안을 거쳐 **B안**으로 정했습니다.

추가 지시:
- 버튼은 «수업 연기» 와 «변경» 두 개만 둡니다(취소는 뺍니다).
- 「내일 수업이 정규인지 보충인지 체험인지 어떻게 알지?」 → 종류를 글자와 색으로 함께 보여 줍니다.

## 무엇을 했나 (`admin/student.html`)
- **다음 수업 상자**: 날짜·요일·시각·길이·강사·종류 알약(정규/보충/체험/레벨테스트). 연기된 회차와 이미 끝난 회차는 건너뜁니다.
- **주 N회 묶음**: 반복 줄 가운데 종류·강사·시각·길이·시작일이 같은 것만 묶습니다(시작일이 다르면 따로 묶음).
- **앞으로 14일 날짜 칩**: 정규가 아니면 종류 글자를 붙입니다. 연기됨·공휴일(KR)·지남(흐림+취소선)을 표시합니다.
- 칩을 누르면:
  - **날짜 지정 수업** → 공용 연기·변경 창(`js/class-move-modal.js?v=3`)을 엽니다. `canCancel:false` 라 취소는 숨겨지고, 「오늘 수업」 화면과 같은 창입니다.
  - **매주 반복 수업** → 「이 날 하나만은 지금 안 됩니다(바꾸면 매주 전부)」라고 사실대로 말하고 «매주 변경» 만 줍니다.
  - **이미 끝난 수업** → 「이미 끝난 수업입니다」.
- 옛 요일별 줄은 `<details id="mgsuFold">`「요일별 보기 · 연기/변경」 안에 접었습니다. 접힘 상태는 다시 그려도 유지됩니다.
- 카드의 🗑 취소 버튼은 없앴습니다. `cancelAiSchedule()` 함수는 남겨 두었습니다.
- 날짜 계산은 새로 만들지 않고 정본 함수 `mgsSchedHitsDate`(날짜가 요일을 이김, 시작일 전에는 안 엶)를 그대로 씁니다.

## 버린 방법과 이유
- **반복 수업도 칩에서 «이 날 하나만» 연기·변경** → 서버가 반복 줄에는 `applied='recorded'`(기록만)로 끝나서, 화면은 «됐다» 고 하는데 실제로는 안 옮겨집니다. 그래서 사실대로 말하는 쪽을 택했습니다.
  근본 해결(반복 줄을 날짜별로 펼치기, 또는 예외 표)은 D1 변경이라 **사람이 정할 일**입니다(미결).
- **종류 알약을 진한 바탕 + 흰 글자로** → `adm-light-surfaces` 페인터가 바탕을 밝혀 정규·보충 색이 같아졌습니다. 옅은 바탕 + 진한 글자로 바꿨습니다.
- **휴대폰 칩 줄을 그냥 nowrap 으로** → 안쪽 내용 폭이 조상 그리드를 밀어 페이지가 1245px 이 됐습니다. `width:0;min-width:100%` 로 막았습니다(원본은 375px).

## 함정 대조(trap-check)로 고친 것
- **안내 문구가 거짓이었음**: 「다른 날 수업은 그대로입니다」라고 했지만, 공용 창의 «🔄 변경(앞으로 계속)» 은 같은 요일·시각의 뒤 회차를 **전부** 옮깁니다.
  → 문구를 창의 실제 동작대로 고쳤습니다.
  → 창이 모드를 미리 받지 않아 두 버튼이 같은 일을 했으므로, 버튼을 하나(「⏸ 연기 · ✏️ 변경」)로 합쳤습니다.
- **연기된 회차 처리가 두 곳에서 달랐음**: 요일별 줄은 연기된 줄에 ⏸ 를 안 주는데, 칩은 버튼을 줬습니다.
  → 칩도 「이미 연기된 수업입니다」로 맞췄습니다.
- **14일 창의 첫날이 브라우저 로컬 날짜였음**: 필리핀 매니저가 KST 0~1시에 보면 하루 어긋납니다.
  → `_mgsKstToday()` 기준으로 바꿨습니다.
- **`?v=` 짝 검사 없음**: manager·branch·student 는 그 창을 `sc.src = '…?v=3'` 로 동적으로 싣는데, 이 모양은 `asset_version_harness` 가 못 봅니다.
  → 새 자동 하니스 `class_move_modal_version_harness.mjs` 를 추가했습니다. 싣는 화면 전부가 같은 번호인지 봅니다(일부러 하나를 v=2 로 바꾸면 실제로 FAIL).
- **확인 필요(사람)**: 카드의 취소 버튼을 없애서 **이 화면에서 수업을 취소할 길은 없습니다.** 취소는 관리자 「오늘 수업」·주간 스케줄에서 합니다.
