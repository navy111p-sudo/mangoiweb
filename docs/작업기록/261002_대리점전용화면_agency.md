# 대리점 전용 화면 /agency — 지사 화면과 같은 레이아웃 (2026-10-02)

## 1. 요청
사장님: 「testagency 계정을 만들었어. 대리점은 /agency URL을 사용하게 해줘. 레이아웃은 지사(/branch)와 비슷하게.
권한은 본인 학생들과 본인 대리점 정보만 보이면 충분해.」

## 2. 잰 것
- `branch.html` 은 이미 범위(scope)를 보고 그리는 화면이었습니다 — 조직 계정에는 강사 가동률·전체 경영 대시보드를 감추고,
  AI 사용료 청구서는 `scope.type==='agency'` 일 때만 켭니다.
- 그 화면이 부르는 API 는 지사·대리점이 같은 허용목록(`isAgencyAllowedApi`)을 쓰고, 핸들러가 대리점을 «자기 한 칸·자기 학생» 으로 자릅니다
  (`scopeStudentCond`: `shop_name = ?` · `scopeCenterCond`: `name = ?` · `scopeFranchiseCond`: 자기 대리점이 속한 지사 한 줄).
- 대리점은 지금까지 `/manager` 로 갔습니다(로그인 정본 `auth-admin.ts` home_path).

## 3. 고친 것
- **같은 파일을 두 주소로**: `/agency` → `branch.html`(240KB 를 복사하지 않음 — 두 벌이면 한쪽만 고쳐집니다).
- 화면: 대리점이면 메뉴·탭·카드 제목 7곳을 대리점 말로(「가맹점 · 대리점 명부」→「내 대리점 정보」, 「지사 · 대리점별 정산」→「우리 대리점 정산」 등).
  바꿀 글자는 각 요소의 `data-agency-ko/en` 에 있고, `data-ko/en` 도 함께 바꿔 🌐 를 눌러도 안 되돌아갑니다. 지사 화면은 한 글자도 안 바뀝니다.
- 라우팅(`src/index.ts`): 로그인 게이트(`isAdminPath` + 미인증 리다이렉트 목록) · `/agency` 서빙 · 역할 분기
  — 대리점이 `/admin`·`/manager`·`/branch` → `/agency` · 지사장이 `/agency` → `/branch` · 지사본사가 `/agency` → `/manager` · 강사 → `/teacher` · 본사는 통과. `?full=1` 탈출구 그대로.
- 로그인 뒤 첫 화면: `auth-admin.ts` home_path 와 `admin/login.html` 폴백을 `/agency` 로.
- ⛔ **권한은 넓히지 않았습니다** — 서버 허용목록·스코프는 한 줄도 안 바꿨습니다. 착지 화면만 갈립니다.

## 4. 확인
- `test-harness/agency_portal_route_harness.mjs` 26종 — `managerPortalRedirect`·`isAdminPath` 를 오려 내 역할별로 실제로 돌리고, 화면 블록은 가짜 DOM 으로 실행.
  변이 5종 실제 FAIL(리다이렉트 끄기 · 조건 뒤집기 · 지사 분기 빼기 · 로그인 게이트 빼기 · 화면 조건 뒤집기).
- 브라우저(크로미움, 로컬 서버 + API 스텁): 대리점 → 제목 「대리점 · Mangoi」, 메뉴 대리점 말, 강사 가동률 숨김, AI 청구서 보임, JS 오류 0. 지사 → 예전 그대로.
- tsc: 기준선과 오류 목록 동일(127=127, 전부 workers-types 미설치). `--fast`: 실패 19개가 `origin/main` 과 같은 목록(새 실패 0).

## 5. 남은 것
- ❌ 실제 `testagency` 로 로그인해 본 확인은 사람이 해야 합니다(이 환경은 mangoi.ai 에 못 닿습니다).
  그 계정의 `admin_scope` 가 `agency` + 대리점 이름(centers.name 과 같은 글자)이어야 자기 학생이 보입니다.
- `js/idx-user-session.js` 의 옛 폴백 두 곳은 여전히 `/manager` 입니다 — 서버가 home_path 를 주므로 평소엔 안 닿고, 닿아도 서버가 `/agency` 로 돌립니다.
  그 파일은 홈 첫 화면 blocking 이라 손대지 않았습니다.
- ⚠️ 대리점 이름(centers.name)은 유일하지 않습니다 — 같은 이름이 둘이면 «내 대리점 정보» 에 두 줄이 보일 수 있습니다(예전 /manager 와 같은 동작).
