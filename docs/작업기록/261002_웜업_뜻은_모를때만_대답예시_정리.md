# 웜업 «뜻» 도움 정리 — 뜻은 모를 때만 · 대답 예시 정리 · 답 대기 단축 (2026-10-02)

## 1. 왜 했나
사장님 mangoi.ai 화면 제보 6건(웜업 «뜻» 도움):
1. 버튼이 너무 많다
2. 뜻에 「ㅋㅋㅋㅋ」가 나온다
3. 대답 예시가 늘 「Yes, I do / No, I don't / One more time, please」
4. 「입력칸에 넣고 고치기」가 3개씩
5. 흐름이 부드럽지 않다
6. 휴대폰에서 더 어렵다

샘플(PC·폰 5종씩, 아티팩트) 뒤 추가 지시: 「뜻을 처음부터 보여주면 교육 효과가 떨어지니 모를 때만」 → 「추천대로 진행」.
작업 중 추가 지시 두 가지:
- 「자동 마이크는 계속 잘 되게 유지」
- 「학생이 답하면 빠르게 다시 질문」

같은 화면에서 AI가 「Do you like blue balls?」를 묻는 것도 함께 확인했습니다. 영어권에서는 성적인 속어로 들리는 표현입니다.

## 3. 검토했다가 버린 것
- **뜻을 LLM 으로 다시 검증** — 요청이 늘고 결국 확률입니다. 결정론 검사로 충분합니다.
- **`trl2:`→`trl3:` 로 캐시 통째로 버리기** — 멀쩡한 뜻 수만 건을 다시 만듭니다. 대신 읽을 때 거릅니다.
- **바꿀 낱말 목록을 화면에도 두기** — 정본이 둘이 됩니다. 화면은 두 대답의 «다른 낱말 자리» 만 계산합니다.
- **도움을 내는 LLM 필드(speaking_help) 빼기로 답을 더 빠르게** — 높은 단계에서는 그것이 유일한 예시이고, 대화 규칙(guided)도 함께 꺼져 질이 떨어집니다. 이번에는 대기 시간만 줄였습니다.
- **25초 무응답 때 뜻을 자동으로 열기** — 「모를 때만」에 어긋납니다. 반짝임만 합니다.

## 4. 자동 마이크
- `js/warmup-auto-talk.js` 와 «말하는 방법» 스위치는 손대지 않았습니다.
- 뜻 열기·반짝임은 마이크를 건드리지 않습니다. 듣는 중에도 반짝임은 보입니다.
- 대답 예시를 누르면 입력칸에 글이 들어가므로, 그동안 자동 마이크는 원래 규칙대로 쉽니다.
