# 웜업(A.i 말하기 연습) 피드백 다섯 가지 — 2026-10-02

## 1. 왜 했나
직원 시험 사용 피드백(사진) 다섯 가지와 사장님 지시 「제이크와 노아 목소리를 좀 더 개선, 2번을 없애지는 말고」.
제안서(아티팩트)를 먼저 보고드리고 「진행해」를 받아 5 → 3 → 4 → 2 → 1 순서로 고쳤다.

| # | 피드백 | 한 일 |
|---|---|---|
| 5 | 수동 버튼인데 말이 안 끝났는데 시간이 지나면 올라감 | **버튼 모드에서는 침묵으로 보내지 않는다.** ⏹ 를 눌러야 보낸다. 30초 동안 아무 말이 없으면 마이크만 끄고 들은 말은 입력칸에 남긴다(고치거나 ➤). 녹음(Whisper) 경로도 같다. 자동 말하기는 그대로. |
| 3 | 「대화 처음부터」 버튼이 설정 밑에 있음 | 위쪽 바에 🔄 버튼(`#newChatTop`). ⋮ 안의 버튼도 그대로. 수업방(`?room=`·`?session=`)에서는 감춤. 학생이 한 번이라도 말했으면 한 번 묻는다. |
| 4 | 성인인데 BTS4 대화에 «yummy» | 성인 프롬프트 줄에 «아이 말 금지(yummy·tummy·doggy…) + 어른 낱말» 을 더함. 성인이면 교재 목록을 SIU 쪽부터(`_bookSortBase`). 성인이 1~2단계를 고르면 한 번 안내. |
| 2 | Jake·Noah 목소리가 어색함 (없애지 말 것) | 영어 남자 목소리는 **0.9배보다 늘이지 않고** 그만큼 문장 사이를 쉰다(늘여 재생할 때 낮은 목소리가 갈라지는 것이 원인으로 보임 — 귀로 확정 필요). 목소리 자체를 바꿀 후보를 고르는 화면 `/admin/voice-compare.html` 신설. |
| 1 | 번역(뜻)이 틀린 곳이 있음 | 뜻 카드 밑에 「🚩 뜻이 이상해요 / Wrong meaning?」. 누르면 `/api/translate` `mode:'learn_report'` 로 문장·뜻을 D1 `learn_meaning_reports` 에 적는다(사람이 모아 보고 고친다). |

## 2. 검토했다가 버린 것
- **5번 — 침묵 대기만 늘리기(예: 5초)**: 길게 쉬는 아이는 여전히 잘린다. 버튼 모드의 뜻이 «내가 끝을 정한다» 이므로 침묵 전송 자체를 끔.
- **5번 — 30초 뒤 그대로 보내기**: 피드백이 정확히 그 증상. 대신 입력칸에 남김.
- **3번 — 확인 없이 바로 새 대화**: 위쪽은 손이 잘 닿는 자리라 잘못 누름이 생긴다. 처음엔 «두 번 이상 말했을 때만 묻기» 로 했다가 기존 브라우저 검사(한 번 말한 뒤 취소하면 그대로)가 잡아 «한 번이라도 말했으면 묻기» 로 되돌림.
- **4번 — 결과를 확인해 아이 말이 나오면 다시 뽑기**: `src/index.ts`(공동 금지구역)를 고쳐야 해서 **하지 않음 — 사장님 승인 대기**. 지금은 프롬프트(확률)뿐이다.
- **2번 — 목소리를 내가 골라 바꾸기**: 이 환경에는 오디오 디코더가 없어 들을 수 없다. 비교 화면을 만들어 사람이 고르게 함.
- **1번 — 신고하면 캐시를 바로 지우기**: 무인증 경로라 누구나 번역 캐시를 지울 수 있게 된다. 적기만 하고 사람이 고친다.

## 3. 반경·주의
- ⚠️ **5번은 모든 학생의 기본 동작이 바뀝니다** — 버튼 모드가 기본값(`mangoi_warmup_talk_mode` 미설정 = button)이라, 이제 학생은 말을 마치면 ⏹ 를 눌러야 보내집니다(안내 문구를 듣는 중 표시에 붙임).
- `learn_report` 는 무인증 공개 쓰기다 — 길이 300자·같은 (문장, 뜻) 한 줄로 모음·하루 500줄 상한. 넘으면 `stored:false` 이고 화면은 «고마워요» 라고 하지 않는다.
- 좁은 폰(≤420px)에서 🔄 가 들어가 제목이 잘려 제목 앞 이모지를 감추고 버튼 34px·간격 6px(≤370px 은 글자 15px). 측정: 390px 제목 126px 잘림 없음, 360px 108px 잘림 없음(원래 360px 은 잘리던 상태).
- 바뀐 js·css 파일이 없어 `?v=` 변경 없음(전부 `warmup.html` 인라인).
