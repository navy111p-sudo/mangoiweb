# 주간 스케줄 «연기·변경» 드래그 스트레스 하니스 (2026-10-05)

## 왜
사장님: 「샌드박스랑 하니스를 이용해서 수업연기,변경 드래그 테스트를 수백번 해서 문제없을때까지 해줘」
「반드시 학생,교사 수업 스케줄 캘린더에서 잘 이동하고 표시되게 해야해」.
(앞 단계: PR #1374 드래그 확인창에 «연기/변경» 두 갈래, #1375 잠긴 채 끌기)

## 무엇을 만들었나
`test-harness/manual/weekly-drag-stress-browser.mjs` (자동으로 안 돕니다 — 사람이 부릅니다)

    PW_DIR=/tmp/pw node test-harness/manual/weekly-drag-stress-browser.mjs [회차=300] [seed=1]

- 진짜 Worker(`src/index.ts` esbuild 번들) + 메모리 SQLite(D1 모양) + 진짜 Chromium.
  화면은 배포되는 `public/` 그대로, `/api` 만 그 Worker 로. 운영 D1·외부 네트워크 0.
- 씨앗: 강사 3명, 사흘에 수업 12건(일회성·매주반복 섞음) + 그룹 수업 1개(학생 둘).
- 매 회차: 무작위 수업을 **실제 마우스로** 끌어 → 「연기」/「변경」/「아니요」, 잠김/풀림 무작위,
  같은 강사/다른 강사, 가끔 15초 «되돌리기».
- 매 회차 대조(전 수업): ① DB 행 ② 학생 «내 수업»(`/api/class/schedule/mine`)
  ③ 강사 3명의 주간 캘린더(`/api/teacher/portal?week=`) — 제자리 1번·다른 강사엔 유령 0
  ④ 관리자 주간(`/api/admin/schedules`) ⑤ 화면 격자 칸 ⑥ 보낸 요청 내용(연기는 강사를 안 보냄 ·
  그룹은 전부 보냄) ⑦ 겹침이면 서버 거절 ⑧ 찬 칸이면 모달 없이 요청 0 ⑨ 페이지 JS 오류 0.
- 회차가 예외로 끊기면 **FAIL 로 세고** 서버 행으로 모델을 맞춘 뒤 화면을 다시 엽니다
  (크래시가 «검출 0» 으로 위장하지 않게).

빡빡한 판 = 강사 3명·사흘에 수업 12건(일회성+매주반복)+그룹 수업 1개. 마지막 4실행 합계: 변경 532 · 연기 164 · 아니요 251 · 그룹 130 · 되돌리기 122 · 겹침 거절 27 · 찬 칸 28 · 빠른 끌기 179.

- ① «되돌리기 버튼이 안 보임» — 제품 결함 아님. 토스트는 rAF 한 번 뒤에 `show` 가 붙고 무거운
  재그리기 직후엔 수백 ms 늦습니다(토스트는 DOM 에 있었음). 하니스가 3초까지 기다리게 고침.
- ② «화면 칸만 옛 자리»·«확인창 버튼 먹통» — **하니스 결함이었습니다.** 대기에
  `waitForLoadState('networkidle')` 를 썼는데, 그것은 페이지가 한 번 idle 에 닿은 뒤엔 **즉시**
  돌아와 저장 뒤 재읽기 «도중» 에 화면을 재고 있었습니다(DB·학생·강사·관리자는 전부 맞았고 화면 칸만
  어긋났다가 다음 회차엔 맞음). «진행 중 /api 요청 0 + reloadAndRender 완료 + 250ms 조용함» 으로
  바꾼 뒤 실패했던 시드 포함 1,200회 0건.
- 그 의심(재읽기 도중 끌면 확인창이 먹통?)을 따로 재려고 «빠른 연속 드래그» 단계를 넣었습니다 —
  저장 응답 직후 곧바로 다음 수업을 끕니다. 120회 0건. 사람이 연달아 옮겨도 안전합니다.
- **제품 코드는 고치지 않았습니다** — 학생·강사·관리자·화면이 어긋난 회차는 한 번도 없었습니다.

## 하니스가 헛돌지 않는가 — 변이시험
`WDS_MUT=<이름>` 로 화면을 «일부러 고장 낸» 판으로 서빙합니다. 6종 전부 실제 FAIL:
`drop-teacher`(강사 변경을 안 보냄) 57 · `off-by-10`(시각 10분 밀림) 44 · `split-group`(그룹 한 명만) 8 ·
`undo-keeps-teacher`(되돌리기가 강사를 안 돌림) 44 · `postpone-any-teacher`(다른 강사에 연기 허용) 33 ·
`unlock-without-yes`(끌기만으로 잠금 해제) 18.
대기를 고친 뒤에도 3종(drop-teacher 44 · unlock-without-yes 26 · split-group 2)을 다시 돌려 실제 FAIL 확인.
앵커 문자열이 사라지면 `MUTATION ANCHOR MISSING` 로 죽습니다(조용히 통과 안 함).
