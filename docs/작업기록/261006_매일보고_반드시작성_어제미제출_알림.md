# 매일보고 «반드시 작성» 표시 · 지난 근무일 미제출 알림 (2026-10-06)

## 왜 했나
사장님: 「daily report 를 반드시 작성하라는 것을 적합한 곳에 표시하고, 전날 안 했으면 상기시켜 달라」.

## 잰 것 (운영 D1, 2026-10-06)
- 마감 전후 푸시 코드는 있었지만 대상 명단 `daily_handover_schedule` 이 **0명** → 한 번도 안 울림(`daily_handover_notices` 0건).
- 매니저 4명 기기 푸시 구독 **0건**(대표님 admin 만 2건) → 푸시만으로는 아무에게도 안 닿음. 그래서 화면 배너가 필요.
- «전날 미제출» 알림은 아예 없었음. 지난 날짜로 저장은 서버가 받지만 편집기 날짜가 오늘로 고정(readonly)이라 화면에서 쓸 수 없었음.

## 한 것
- **D1(사장님 지시)**: 명단 4명 — 장지웅 18:00(KR) · Maimai 20:00 · Karl 22:00 · Melca 23:00(PH), 월~금, 시각은 **KST**. `holiday_country` 칸 추가(ALTER) 후 외국인 3명 PH.
- `src/daily-handover.ts`: 정본 `handoverDuty()` — 근무일 = 명단 켜짐 · 근무 요일 · 쉬는 날 아님 · **그 사람 나라 공휴일 아님**(`holidays` 표). 직전 근무일 미제출을 계산(월요일은 금요일).
  - 15분 cron 에 얹음: 근무일 **09:00~12:00 KST** 에 본인 푸시 1회 + 대표님(admin) 요약 1회. 공휴일·쉬는 날엔 마감 알림도 안 보냄.
  - `/inbox` 응답에 `writer`(내 오늘/지난 근무일 상태) · `missed_staff`(대표님만) 추가. `/home` 명단에 공휴일 반영 + 미제출 명단.
  - `DUTY_START='2026-10-06'` — 그 전 날짜는 미제출로 세지 않음(명단에 넣기 전으로 소급 안 함).
- 배너(`js/handover-inbox-banner.js` + `work.html` 인라인 복사본): 「📝 오늘 매일보고 반드시 작성 · 마감 HH:MM」·「⚠️ 지난 근무일 미제출 — 지금 작성」·(대표님) 「📋 미제출: 이름」. 제출하기 전까지 닫기 없음.
- `js/daily-handover.js`: `?write=YYYY-MM-DD` 로 지난 날짜 보고를 편집기에 연다 · 명단 줄 연산자 우선순위 수정.

## 버린 방법
- 미제출을 문자로 보내기 — 비용, 사람이 정할 일.
- 공휴일 표를 못 읽으면 막기 — 알림 한 번 더가 «안 써도 되는 줄» 보다 낫다(fail-open).
- 경영진(EXEC) 전원에게 미제출 명단 — 지시는 «대표님».
