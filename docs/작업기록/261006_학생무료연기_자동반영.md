## 한 일

  학생 · 연기 · 무료(시작 30분 전보다 일찍) · 강사 변경 없음 · 연기보강 이름 없음 · **날짜 지정 수업** · 접수 스냅샷과 수업이 같음 · 미러 수업을 같은 날 시각만 옮기는 것이 아님.

- 관리자 알림 제목·본문도 «자동 반영» 으로.

## 검토했다가 버린 것
- 반복 수업 자동 승인 — `/decide` 도 `recorded`(기록만)라 시간표가 안 바뀐다. 자동 승인해도 학생에게 «됐다» 는 거짓말만 된다 → 대기 유지.
- 유료(30분 이내) 자동 — 수업료가 걸려 사람이 보게 둠.
- 강사 변경 자동 — `/decide` 에 본사 전용 게이트가 있다(급여 근거) → 대기 유지.
- `/decide` 몸통을 함수로 빼기 — 그 글자를 오려 내 돌리는 하니스가 7개라 반경이 큼. 부품 재사용으로 대신.
