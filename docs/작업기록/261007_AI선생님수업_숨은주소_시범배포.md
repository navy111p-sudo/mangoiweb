### 데이터는 «이미 있는 것» 을 씁니다 — 새로 올린 교재 데이터는 목록 64KB 뿐
- **문장**: `/data/tb-say/<권>.json` — 수업 화면 «이 쪽 문장 듣기»(2026-09-28)가 이미 쓰는 정본.
  레슨을 고를 때 **그 권 파일 하나만** 받습니다(16~32KB).
- **그림**: `/api/textbook-files?book=…`(번호·이름) → `/api/textbook-files/<id>/raw`(R2) — 학생 수업 화면과 **같은 API**.
  둘 다 원래 로그인 없이 열립니다. 그래서 443레슨 **전부** 실제 교재 그림으로 보입니다(샘플은 211장만).
- **선생님 얼굴**: `/img/lily-*.webp` — 저장소에 이미 있던 파일과 md5 동일.
- ✅ 확인: 샘플이 쓴 슬라이드 번호 211개를 운영 D1 에서 **SELECT** 로 대조 — 211개 모두 `active=1`, 이름 일치.

## 검토했다가 버린 방법
- **레슨 데이터 통째(units.json 1.7MB)를 올리기** — 문장이 이미 tb-say 에 있어 같은 내용이 두 벌이 되고, 첫 화면이 무거워짐.
  → 목록만 따로 뽑고 문장은 tb-say 를 그대로 읽음.
- **슬라이드 번호표(slides-map)를 올리기** — 교재를 다시 올리면 번호가 바뀌어 조용히 낡음. → 화면이 그때그때 API 로 받음.
- **샘플의 슬라이드 이미지(9.4MB)를 올리기** — 저장소가 공개라 원본 교재가 누구에게나 퍼짐. ⛔
- **목록 주소의 `?v=` 를 손으로 올리기** — 잊으면 학생 브라우저에 옛 목록이 1년 남음. → `?v=` 를 **목록 내용 해시**로 정하고 하니스가 대조.

## 실서비스에서 달라진 점(샘플 대비)
- 🎤 = **진짜 마이크**(브라우저 음성인식, 웜업과 같음). 마이크가 있는 브라우저는 «자동 말하기» 가 **처음부터 켬**.
  마이크를 못 쓰면 예전처럼 «대답 고르기·입력» 창.
- 그림을 못 받은 쪽(삭제·네트워크)은 **그 쪽만 문장으로** 다시 그림 — 수업은 계속됨.
- 학생 이름: 로그인 이름(`mangoi_logged_user.name`). 그 칸이 아이디와 같으면 **부르지 않음**(아이디 노출 금지).
