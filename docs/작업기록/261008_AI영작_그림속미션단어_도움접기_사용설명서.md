# 261008 AI 영작 — 그림 속 미션 단어 · 도움 접기 · 사진 설명서

## 왜 했나
2026-10-08 수업 후 선생님 피드백: «화면이 복잡해 학생에게 설명하기 어렵다, 그냥 그림 보고 영작하라고 하겠다» · «그림에 apple 은 없는데 미션 단어는 apple — 다른 건지?».
코드 확인: 미션 단어(`loadMission`)는 학생 단어장 또는 레벨 기본 목록(A1 첫 단어 `apple`)에서 뽑혀 **그림과 아무 연결이 없었다**. 글쓰기 칸 위에 7겹(레벨·미션·그림·문장연습·글감·브레인스토밍·안내).
시안 A/B/C 를 사장님께 보여 드리고 **B(첫 화면은 그림 보고 쓰기만 + A 포함)** 로 결정. 이어서 «초등생도 쉽게 쓰는 사용 설명서 — 캡처 사진에 화살표로».

## 한 일 (`public/ai-write.html`, `src/api-ai.ts`)
1. **`SCENE_WORDS`** — 그림 36장을 눈으로 보고 «실제로 보이는» 낱말 3개씩. `loadMission` 이 그것을 먼저 쓰고, `renderPic` 이 그림을 바꿀 때 다시 그린다. 없으면 예전 동작(단어장 → 레벨 목록).
2. 미션 카드를 그림 **아래**로, 문구 「그림 속 미션 단어 — 그림에서 찾아 3개 모두 쓰면 +15P!」.
3. **«🙋 도움이 필요해요»**(`details#awHelp`, 기본 접힘) 안에 글감 안내·문장 연습·오늘의 글감·브레인스토밍. 4단계 줄(`#flowSteps`)은 `hidden`(+`[hidden]{display:none!important}` — `.flow-steps{display:flex}` 가 이기므로). 안내 줄 ②·`goApplyTheme` 이 접힌 칸으로 갈 때 먼저 편다(닫힌 details 안은 scrollIntoView 가 안 먹는다).
4. **📖 사용 방법** — 본문 맨 위 버튼 + 5단계 설명서 창(한/영, 처음 방문 시 한 번 자동). 사진 `public/img/aiwrite-guide/step1~5.webp` 는 실제 새 화면을 폰 폭(390, DPR2)으로 찍어 빨간 테두리·화살표를 얹은 것(CDP, 캔버스로 webp 변환, 각 28~71KB).
5. 서버 미션 판정이 복수형(`candles`)도 인정 — `\b단어(?:s|es)?\b`.
6. 곁가지 수리: `cooking-action-motion.webp`(움직이는 그림 첫 장면)가 **0바이트**라 요리 그림이 늘 「그림을 불러오지 못했어요」였다 → 깨지면 원래 그림으로 한 번 더 받는다.

## 버린 방법
- 버튼을 머리줄 오른쪽에 두기 — 공용 🏠/EN 칩(고정)에 덮여 **안 눌림**(브라우저 실측) → 본문 맨 위로.
- 도구를 지우기 — 상급 학생이 쓰고 하니스가 배선을 지킨다. 접어 두기만.
- 그림마다 단어를 AI 로 뽑기 — 결정론이어야 하고 «그림에 실제로 보이는가» 는 사람이 봐야 한다.
- C(단계형) — 가장 단순하지만 바꿀 양이 가장 커 이번엔 안 함.
