# 관리자 자료실 — 「학생 등록 → 수업 예약 단계별 안내」 PDF 추가 (2026-10-08)

## 1. 왜 했나
필리핀 매니저 문의(사장님 전달, 관리자 › 자료실 › 1 Admin Library 캡처와 함께):
> "there is no content explaining how to register and schedule a student. Maybe we can add a section here explaining how to schedule the class step by step."

사장님 지시: 「여기에 있는지 확인해 보고 없으면 잘 이해할 수 있게 mangoi.ai 캡처와 함께 포함시켜줘.」

## 2. 있었나 — 확인 결과 (잰 것)
관리자 자료실(`#card-lib-admin`)에 있던 자료는 셋: 🎬 동영상 사용설명서 · 📘 관리자용 사용설명서(PDF/PPT/Excel) · 📊 관리자 페이지 쉬운 사용법.
PPT 슬라이드 글자를 전수로 뽑아 «등록·스케줄·예약» 낱말을 찾아보니 있는 것은
- 「수강신청 화면에서 학생이 결제하면 수업 회차가 자동 생성」(학생 셀프 결제 흐름)
- 「수업 예약 관리 — 수업 형태·강사·날짜·시간을 배정하는 화면」(한 줄 개요)
뿐이었고, **직원이 한 학생을 손으로 등록하고 수업을 잡는 순서**는 어디에도 없었습니다 → 새로 만듦.

## 3. 무엇을 했나
- `public/library/admin/student-schedule-kr.pdf` · `student-schedule-en.pdf` (A4 5쪽, 캡처 8장)
  1 학생 목록 › ➕ 학생 등록 → 2 정보 입력 → 3 임시 비밀번호(한 번만 보임) → 4 행의 📅 스케줄
  → 5 (다른 길) 상세 › 스케줄 탭 → 6 수업 예약 등록(종류·요일·시작일·시각·분·강사·근무지) → 7 결과 확인 → 8 같은 방 자동 입장
  + «시작하기 전에»: 본사·직원 계정만 · 시각은 KST(PH 는 1시간 늦음) · 여러 명은 수강신청 일괄 등록
- `admin.html` 관리자 자료실 맨 위에 항목 추가(열기·저장·카톡 링크, 한/영 `data-ko`/`data-en`)
- 원본: `docs/자료실_원본/학생등록_수업예약/capture.mjs`(캡처) · `build.mjs`(PDF) — 화면이 바뀌면 다시 만들 수 있게

## 4. 캡처를 어떻게 찍었나 — 그리고 한계
- `mangoi.ai` 는 작업 컨테이너 프록시가 막아 직접 못 엽니다(CLAUDE.md 4-1-1). 그래서 **배포되는 것과 같은 `public/` 파일**을 로컬로 띄우고 API 만 시험용 가짜 데이터(Emma Kim · Teacher Anna · Sample Academy)로 대신해 찍었습니다.
- ⛔ 실제 학생 정보를 쓰지 않은 이유: `/library/` 는 로그인 게이트 밖이라 **PDF 를 누구나 받을 수 있습니다**(자료실 비밀번호는 화면에서만 가립니다).
- ⚠️ 화면 일부(시작일·근무지 라벨)는 영어 화면에서도 「시작일 / Start date」처럼 한/영 병기 — 실제 화면 그대로입니다.
- ⚠️ 실제 운영 화면에서 사람이 한 번 열어 보는 확인은 아직입니다(PDF 링크 2개 열림·문구가 화면과 맞는지).

## 5. 검토했다가 버린 것
- **새 HTML 안내 페이지**: 사이트 구성표 등록·한자 글꼴 가드 등 손이 더 가고, 자료실의 다른 자료가 전부 PDF/PPT 라 형식을 맞췄습니다.
- **수강신청 카드의 4단계 안내(`adm-enroll-guide.js`)만 가리키기**: 그건 «양식으로 여러 명 일괄 등록» 흐름이라 한 명 수동 등록·예약 질문의 답이 아닙니다(안내서에 «여러 명이면 그쪽» 으로만 연결).
