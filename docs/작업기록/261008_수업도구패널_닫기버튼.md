# 화상수업 교재도구·필기도구 패널에 «✕ 닫기» 버튼

- 브랜치 / PR: `claude/gifted-hopper-xdhh6s` · [#1426](https://github.com/navy111p-sudo/mangoiweb/pull/1426)(버튼) · [#1433](https://github.com/navy111p-sudo/mangoiweb/pull/1433)(재렌더 틈 수리 + 반복 검사 하니스) · [#1441](https://github.com/navy111p-sudo/mangoiweb/pull/1441)(탭 바꾸면 닫기)

## 1. 왜 했나
사장님 폰 세로 수업 화면 캡처 2장 — 필기도구(포인터·펜·형광펜…)와 교재도구(다운로드·이전/다음·확대…) 패널이 화면 가운데를 덮는데 **닫는 방법이 없었다.** 닫는 길은 «📚 교재도구 / ✍️ 필기도구» 칩을 다시 누르는 것뿐인데, 그 칩은 패널·☰ 기능 메뉴 뒤에 있어 찾을 수 없었다. 요청: 「필기도구, 교재도구 모두에 닫기 표시 추가해줘」 → 이어 「테스트 수백번 해줘. 문제없을때까지」.

## 2. 무엇을 바꿨나
- `cloudflare-deploy/public/js/mango-tools-dock.js`
  - `ensureClose(bar)` — 교재도구(`#tab-pdf .pdf-controls`)·필기도구(`#tab-pdf .pdf-anno-bar`)·칠판 도구바(`#tab-whiteboard .wb-toolbar`) **맨 앞**에 «✕ 닫기 (Close)» 버튼을 하나만 넣는다(`:scope > .mango-dock-close` 로 중복 방지). data-ko/data-en·aria-label 포함.
  - `window.mangoCloseToolDock()` — 세 패널을 모두 닫기만 한다(탭 전환·화면 모드 변경 없음). 클릭은 `preventDefault`+`stopPropagation`(패널 뒤 교재가 클릭을 받지 않게).
  - 호출 자리: `enforce()`(로드·1.2초 틱·언어 전환) **와** 패널을 «열 때»(apply* 3곳 — #1433).
- `cloudflare-deploy/public/css/mango-tools-dock.css` 끝 — 열렸을 때만 보임, `position:sticky; top:0`(패널이 스크롤돼도 맨 위), 빨간 알약. 기존 패널 버튼 규칙(1,4,2)을 id 두 개로 이김. 닫힌 패널용 숨김 규칙은 보이기 규칙보다 특이성이 높다((2,3,2) > (2,1,2)).
- `cloudflare-deploy/public/index.html` — `?v=` 만: js 7→8→9, css 8→9(같은 글자 수, 첫 화면 0바이트). 공동 금지구역이라 사장님 «병합해줘» 뒤 병합. #1433 의 v=9 는 같은 종류라 그대로 병합했다.
- 검사: `test-harness/tool_dock_close_harness.mjs`(자동) · `test-harness/manual/tool-dock-close-browser.mjs`(브라우저, 사람이 부름).

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법
- **닫기를 `mangoToggleToolDock(which)` 재사용으로** → 버림. 그 함수는 교재 탭으로 전환(`vcSwitchTab('pdf')`)하고 `idx-vc-screenmode.js` 가 감싸 화면 모드(facepip→pip)까지 바꾼다. 닫기는 «닫기만» 해야 해서 `mangoCloseToolDock` 을 따로 뒀다.
- **index.html 마크업에 버튼을 직접 넣기** → 버림. 공동 금지구역 + 첫 화면 예산, 그리고 칠판 도구바는 JS 가 그린다. defer 파일 한 곳에서 세 패널을 다 맡는다.
- **재렌더 때 1.2초 공백을 상주 MutationObserver 로 메우기** → 버림. 이 저장소는 관찰자로 홈이 통째로 멎은 사고가 두 번 있다. 대신 «패널을 열 때» 버튼을 확인한다 — 남는 틈은 «열린 채로 다시 그려진 경우» 의 최대 1.2초(다음 틱이 되살림).

- **(#1441) 탭이 바뀌었는지를 `.tab-panel` 의 class 를 지켜보는 MutationObserver 로 알기** → 버림. 같은 이유(관찰자 사고 전력). 대신 탭을 바꾸는 정본 `vcSwitchTab` 을 «감싸» 전환 직후에만 확인하고, 다른 경로는 기존 1.2초 틱이 받는다.
- **(#1441) 탭 «돌아올 때» 닫기** → 버림. 떠날 때 닫는 편이 단순하고, 숨은 탭에 «열린» 상태가 남지 않는다(브라우저 실측 숨은 탭에 열린 창 45회 → 0회).
- **(#1441) vcSwitchTab 이 불릴 때마다 닫기** → 버림. 교재 탭에서 라이브러리로 교재를 고르면 `vcSwitchTab('pdf')` 가 같은 탭으로 다시 불리는데 그때 창이 닫히면 안 된다. 그래서 «창을 연 탭» 을 기억해 «실제로 바뀌었을 때만» 닫는다(변이 «아무 전환이나 닫기» 가 실제 FAIL).

## 5. 남은 것 / 주의할 것
- 칠판 도구바는 브라우저 반복 검사에 포함됐지만 실기기 확인은 없음.
- ✅ **(같은 날 후속, 사장님 「탭 바꿨다 돌아오면 창 닫히게」)** 탭(교재·칠판·동영상·게임…)이 «실제로» 바뀌면 열려 있던 도구 창을 닫는다 — 돌아와도 닫힌 채. `mango-tools-dock.js` 가 창을 연 탭(`openedTab`)을 기억하고 `window.vcSwitchTab` 을 감싸 전환 직후 `closeIfTabChanged()` 를 부른다. 다른 경로로 탭이 바뀌면 1.2초 틱이 대비책. 같은 탭을 다시 골라도 안 닫는다. ?v=10.
  - 검사: 자동 하니스 ⑦절 + 무작위 탭 전환(PASS 11,470 / FAIL 0) — 변이 6종(감싸기 무력화·조건 뒤집기·항상거짓·기록 안 함·아무 전환이나 닫기·틱 대비책 제거) 전부 실제 FAIL. 브라우저 600회 PASS 4,321 / FAIL 0, «숨은 탭에 열린 창» 0회(이전 판 45회 · 이전 판을 물리면 실제 23건 FAIL).
- 브라우저 하니스는 자동으로 안 돈다: `cd cloudflare-deploy/public && python3 -m http.server 8977 &` 후 `ITER=60 node test-harness/manual/tool-dock-close-browser.mjs`. 변이는 `MUTANT_JS=<사본>`(브라우저)·`MUTANT_SRC`/`MUTANT_CSS`(자동).
- 브라우저로 잴 때 폰 세로는 «가로로 돌려주세요» 오버레이가 화면을 덮는다 — `vcNukeRotationOverlays()` 를 먼저 불러야 한다(안 부르면 버튼이 «가려짐» 으로 거짓 실패).
