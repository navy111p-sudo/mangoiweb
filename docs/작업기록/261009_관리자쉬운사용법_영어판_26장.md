# 관리자 쉬운 사용법 — 영어판도 26장으로 (2026-10-09)

## 왜 했나
사장님 «병합되면 영어판도 똑같이 만들어줘». 한국어판은 PR #1468 로 21 → 26장(핵심 업무 6장 + 빨간 번호·화살표)이 됐는데,
영어판(`/guide/admin-easy-en/`)은 옛 21장 그대로였고 **소스도 없었습니다**(손으로 만든 옛 그림).

## 한 일
- `slides-en.mjs` 신설 — `slides.mjs` 와 같은 26장 구조, 글은 영어(쉬운 문장).
- `build.mjs` — `GUIDE_LANG=en` 이면 영어 글·`.shots/en/`·`admin-easy-en/` 로 굽습니다. 슬라이드 틀 글자는 `UI` 표 한 곳.
- `capture.mjs` — 관리자 화면을 실제 영어 모드로 띄워 찍습니다(`mangoi_lang='en'` + `by='user'`). 견본 데이터의 지점·강사는 `enSample()` 로 영어.
  버튼 글자로 표시를 찾는 장은 `marksEn`, 영어 글자가 길어 칸이 잘린 급여 장은 `viewportEn` 2400 폭.
- `adm-s18.js` — 영어 덱 26개 제목·`ver:'26a'`. `admin.html` 영어 PDF 링크 `?v=26a`, `adm-s18.js?v=8`, `adm-welcome.js?v=9`.
- `adm-welcome.js` — 환영 안내의 «몇 번 장» 대응이 **이전부터** 어긋나 있었습니다(21장 시절 번호) → 1·5·7·14·22 로 고침, 그림 주소에 `?v=26a`.

- `adm-welcome.js` 217행의 jpg 되돌림이 `/\.webp$/` 라 그림 주소에 `?v=` 가 붙자 **조용히 안 걸리던** 것을 `admin_lazyload_harness` 가 잡아 고쳤습니다(`/\.webp(\?|$)/` → `'.jpg$1'`). 하니스도 옛 `$` 정규식이면 FAIL 나게 바꿨습니다(변이로 실제 FAIL 확인).

## 검토했다가 버린 것
- **화면 글자를 번역해서 적기** — 실제 영어 화면 버튼은 «Log In»·«Mark Paid»·«Save All» 처럼 정해진 글자라, 안내서가 다른 말을 하면 못 찾습니다. 원본의 `data-en` 값을 찾아 맞췄습니다.
- **급여 장을 1920 폭 그대로** — 영어 글자가 길어 «Detail»·«Mark Paid» 칸이 잘렸습니다. 영어판만 넓게 찍습니다.
