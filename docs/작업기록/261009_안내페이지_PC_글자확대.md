# 안내 페이지 PC 글자 확대 (환불규정·교육과정·소개영상)

- 작업자: 사장님 지시 · Claude Code

## 1. 왜 했나
사장님이 1920 PC 모니터에서 `mangoi.ai/refund.html` 스크린샷을 보내며 「글자가 너무 작아, PC 화면에서 잘 보이게」라고 하셨습니다.
이어서 「다른 안내 페이지들도 PC에서 글자 크게」를 요청하셨습니다.

원인은 글꼴이 아니라 **폭**이었습니다. 본문이 폰 기준(760~1100px · 글자 11~14px)으로 고정돼 있어서, 큰 모니터에서는 가운데에 작은 띠처럼만 보였습니다.

## 2. 무엇을 바꿨나
세 파일 모두 `<style>` 끝에 **PC 전용 미디어쿼리**만 더했습니다. 폰(1024px 미만)용 규칙은 손대지 않았습니다.

| 파일 | 확대 대상 | 배율 |
|---|---|---|
| `cloudflare-deploy/public/refund.html` | `.wrap`, `.top` | 1024px↑ 1.1 · 1440px↑ 1.22 · 1700px↑ 1.35 |
| `cloudflare-deploy/public/curriculum.html` | `.wrap` | 1440px↑ 1.15 · 1700px↑ 1.28 (원래 폭이 1100px이라 1440 미만은 그대로) |
| `cloudflare-deploy/public/promo.html` | `main`, `.top` | 1024px↑ 1.12 · 1440px↑ 1.2 |

손대지 않은 페이지와 이유(1920 화면에서 실제로 찍어 보고 판단):
- `faq.html` — 이미 `@media (min-width:701px)` 확대가 있어 질문이 20px로 나옵니다
- `game-learning-science.html` — 이미 `@media screen` 확대(폭 1180px)가 있습니다
- `level-start.html` — 글자가 원래 충분히 큽니다

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법
- **글자 크기(`font-size`)를 하나씩 키우기** — 클래스마다 크기가 따로 적혀 있어(환불규정만 20곳 이상) 빠뜨리기 쉽고, 폭은 그대로라 줄바꿈이 늘어납니다. `zoom` 은 폭(`max-width`)·여백·글자를 같은 비율로 키워 배치가 그대로 유지되어 이쪽을 택했습니다. 관리자 화면이 이미 `zoom:1.3` 을 쓰는 것과 같은 방식입니다.
- **한 배율로 통일** — 환불규정은 오른쪽 위에 안내 영상(폭 190px, `position:fixed`)이 떠 있어 1366 화면에서 1.35배면 본문과 겹칩니다. 그래서 화면 폭별로 단계를 나눴습니다.
- **소개영상도 1.35배** — 1920×950 첫 화면에서 「무료 레벨테스트 신청」 버튼이 아래로 밀려나 1.2배에서 멈췄습니다(신청 버튼이 첫 화면에 보이는 것이 이 페이지의 목적이라).
- **공용 CSS 한 곳에서 처리** — 페이지마다 컨테이너 이름(`.wrap`·`main`)과 폭이 달라 공용 규칙이 엉뚱한 화면을 키울 수 있습니다. 각 페이지 안에서만 바꿨습니다.

## 5. 남은 것 / 주의할 것
- **배포된 실제 화면은 사람이 아직 안 봤습니다.** 프록시가 `mangoi.ai` 를 막아 Claude 는 볼 수 없습니다. PC에서 `Ctrl+Shift+R` 로 한 번 확인이 필요합니다.
- 폰 폭 스크린샷이 잘려 보이는 것은 헤드리스 크로미움의 최소 뷰포트(500px) 때문이고 이번 변경과 무관합니다(CLAUDE.md 2장에 이미 있는 함정).
- 이 페이지들에 `getBoundingClientRect` 를 쓰는 스크립트가 생기면 `zoom` 때문에 좌표가 어긋날 수 있습니다(지금은 0건).
- 다른 안내 페이지를 새로 만들면 같은 방식(폭별 `zoom` 단계)을 쓰면 됩니다. 오른쪽 위 떠 있는 요소·첫 화면 버튼과 겹치지 않는지 함께 보세요.
