## 검토했다가 버린 것
- **AI 가 목표를 고르게 하기** — 보고서가 못 박은 대로 화면마다 다른 말을 하게 됩니다. 목표는 사람(강사)이 정합니다.
- **자유 입력 목표** — 검토 안 된 글이 학부모 화면에 그대로 나갑니다. 보기 밖 key 는 서버가 거절합니다.
- **«목표 달성률» 숫자** — 잴 방법이 없습니다. 막대는 «시간(N/28일)» 이고, 연습은 «센 횟수» 만 말합니다(못 세면 null → 그 줄을 안 그림).
- **웜업 대화도 목표 쪽으로 기울이기** — 웜업 프롬프트는 `src/index.ts`(공동 금지구역)에 있어 이번엔 못 했습니다. 사람이 정할 일.
