# 강사 스케줄 캘린더 드래그 이동 — 원자 저장으로 교체 (2026-10-10)

## 왜 했나
사장님 「캘린더에서 스케줄 drag로 연기 또는 변경할 때 완벽하게 … 관리자페이지에 있는 모든 스케줄 캘린더에서」.
관리자 스케줄 캘린더는 둘입니다 — ① 관리자 › 강사 스케줄 캘린더(`js/adm-q6.js`, ph54) ② 주간 전체 스케줄(`admin/weekly-schedule.html`).

## 무엇이 틀려 있었나 (① 강사 캘린더)
- 드롭이 옛 단건 `PATCH /api/admin/class-schedules/:id` 에 **`day_of_week` 만** 보냈습니다.
  지금 수업의 대부분(카페24 미러 one_off · 수강신청 dated)은 «날짜 지정» 이라 서버가 요일 칸만 바꾸고
  **날짜는 그대로** → 응답은 ok 인데 수업은 안 옮겨졌습니다(진짜 SQLite 로 재현).
- 저장 «전» 에 화면을 먼저 옮겨, 실패해도 «화면만 이동» 으로 남았습니다.
- 그룹 수업은 한 줄만 옮겨 쪼개졌고, 시각은 드롭 위치의 «포인터» 기준이라 카드 윗변과 어긋났습니다.
- LMS 점유칸·차단도 끌렸습니다(서버가 거절).

## 고친 것
- 이동은 `PATCH /api/admin/class-schedules/move`(원자 이동 — 날짜/요일을 서버가 행마다 고름, 그룹 함께, 겹침·휴가 거절, 미러 도장, move_version 대조).
- 드롭 → 확인 창(지금 → 바꿀 곳 · 그룹 N명 · 🔁 매주 · 지난 날짜 · 강사는 그대로) → 저장 → **서버에서 다시 읽어** 그림.
- 성공하면 15초 「↩ 되돌리기」(서버에 원래 자리로 다시 보냄 · 받은 move_version 으로).
- 실패하면 「❌ 저장하지 못했습니다(옮기지 않음): 사유」.
- 판정 함수: `ph54Movable` · `ph54DropMinute`(카드 윗변·10분) · `ph54MoveGroupIds` · `ph54BuildMovePlan` · `ph54SaveMove`.
- ② 주간 전체 스케줄은 이미 같은 이동 모듈을 쓰고 있어 코드 변경 없음(샌드박스로 확인만).

## 검토했다가 버린 것

## 시험하며 밟은 것
- 강사 캘린더 본문은 560px 안에서 굴러가고 **zoom 1.3** 이라 scrollTop 과 화면 px 이 다름 — 머리글(sticky) 밑으로 굴린 뒤 끌어야 드롭이 일어남.
- 같은 강사·**정확히 같은 시각·길이** 는 서버가 «그룹 합류» 로 받음(설계) — 겹침 시험은 엇갈린 시각으로.
- 주간 스케줄의 「연기」는 비매니저에게 «30분 안·지난 수업» 을 막음(설계) — 시험은 관리자 신원으로, 거절도 따로 검사.
- 두 칸을 따로 `scrollIntoView` 하면 첫 칸 좌표가 낡음.

## 시험으로 «더» 찾은 결함 (함께 고침)
- **같은 강사의 다른 수업이 «정확히 같은 날짜·시각» 에 있는 자리로 놓기** — 서버는 «같은 시각·같은 길이» 를
  그룹 합류로 받아 «성공» 하지만, 그 순간 두 수업이 한 묶음이 되어 ↩ 되돌리기가 «구성원 변경» 으로 거절됐습니다
  (브라우저 300회 왕복 중 3회 실측). 화면이 그 드롭을 미리 막습니다(`reason:'occupied'` — 주간 전체 스케줄과 같은 규칙).
- **되돌리기 버튼 색** — 어두운 파랑(#1d4ed8)은 관리자 밝기 페인터가 희게 덮어 «흰 바탕 흰 글자» 가 될 수 있어
  밝은 값(#dbeafe / #1e40af)으로, 위치는 오른쪽 아래 스피드다이얼을 비켜 bottom:110px.
- 1:1 이 같은 시각에 겹친 것은 «그룹 수업» 이 아니라 «겹친 수업 N건» 이라 말합니다.
