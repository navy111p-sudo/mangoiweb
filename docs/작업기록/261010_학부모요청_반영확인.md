# 261010 학부모 요청 → 선생님 «반영함 ✔» (경쟁사 분석 적용 ⑤)

## 왜 했나
경쟁사 분석 보고서 ⑤ — 학부모가 «말하기를 더 해 주세요» 같은 요청을 남기면 다음 수업 강사 화면에 뜨고,
강사가 반영하면 학부모 화면에 «반영함 ✔» 이 돌아오게. 학부모 문자 번호가 거의 없어(CLAUDE.md 2장) 화면 중심으로 만들었다.

## 무엇을 했나
- 정본 `src/parent-request.ts` — 표 `parent_requests`(지연 CREATE), 보기 6개(한/영), 학생당 «열린» 요청 1개
  (새로 보내면 앞 것 `replaced`, 학부모가 지우면 `cleared` — 지우지 않고 이력으로), 반영된 것은 14일까지 보여 줌.
  쌍둥이 계정(X ↔ mangoai_X)은 함께 읽고 함께 끝낸다.
- 학부모: `parent.html` «👪 선생님께 요청» 카드(보기 고르기·취소), 저장은 **이미 등록된** `/api/parent/dashboard`
  의 `POST ?part=request`(라우팅 허용목록이 메서드를 안 가려 `src/index.ts` 무수정). 인증은 GET 과 같은
  «자녀 토큰 + 비밀번호 설정» 게이트 «뒤» 에서.
- 강사: `teacher.html` 오늘 수업 줄에 «👪 Parent request …» + «반영함 ✔» 버튼, `POST /api/teacher/portal?part=preq`.
  오늘 그 강사 수업(`kind==='class'`)의 학생 uid **정확일치**일 때만(아니면 403), 이미 끝난 요청은 409.

## 검토했다가 버린 것
- **자유 입력** — 필리핀·중국 강사가 못 읽고 검토 안 된 글이 강사 화면에 나감 → 보기 6개만.
- **새 API 경로** — `src/index.ts`(공동 금지구역) 허용목록 수정이 필요 → 기존 경로의 비어 있는 POST 를 씀.
- **학부모 문자 알림** — 번호가 사실상 0건이라 닿지 않음. 웹푸시는 별건(아래).
- **수업일지와 자동 연결** — 반영 여부를 사람이 누르는 쪽이 정직(AI 가 «반영됐다» 고 판단할 근거 없음).
