## 검토했다가 버린 것
- **1권 파일을 «여러 권을 읽는 하나의 화면» 으로 바꾸기** → 1권 하니스·포인트 검사·직원 안내 PDF 가 그 파일 구조에 묶여 있음. 반경이 커서 복제.
- **그림 없이 글만** → «같은 스타일» 지시와 다름.
- **CDN 주소를 그대로 쓰기** → 남의 도메인에 묶이고 만료되면 그림이 사라짐(CLAUDE.md 2장).
