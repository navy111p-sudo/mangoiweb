# 대체 강사 고르기 카드에 «그날 수업 수» + 적은 순 정렬 (2026-10-13)

## 왜 했나
필리핀 매니저(Karl) 제안 — 매니저 화면 「오늘 수업」에서 결석한 강사의 수업을 다른 강사에게 옮길 때,
«이 시간 가능한 강사» 카드 이름 아래에 **그 강사의 그날 총 수업 수**를 보여 달라. 그래야 대체 수업을
한 강사에게 몰지 않고 고르게 나눌 수 있다. 제안서 사진의 「Teacher Chaine — 10 classes」는 매니저가 그려 넣은 예시였고
코드에는 그 정보가 없었다. 사장님이 «정렬까지 같이» 를 지시하셨다.

## 무엇을 바꿨나
- 서버 `src/enroll-ops.ts`
  - `teacherDayCounts(env, date)` 신설 — 그날 강사별 수업 수(원부 번호 → 회수).
    - 날짜 지정 행은 `scheduled_date` 가 그날일 때, 반복 행은 요일이 맞고 `recurStartedOn`(시작일·그 주만 빠짐) 을 지날 때.
    - 취소·LMS/시드 자리표시(`NOT_PLACEHOLDER`)는 안 셈.
    - 그룹 수업(학생마다 한 행)은 (강사, 시작 시각) 으로 묶어 한 번만.
    - 그날 대체(`class_substitutions`)가 걸린 수업은 대체 강사의 수업으로 셈.
    - 조회 실패 = `null`(모름) — 0 으로 지어내지 않음.
  - `moveCandidatesFor(…, { dayCount: true })` 일 때만 세고 후보를 **수업 적은 순(같으면 이름순)** 으로 정렬, 응답에 `day_count`·`day_count_ok`.
  - 켜는 곳은 관리자 `/api/pay/enroll/admin/move-candidates` 하나. 학생 «교사로 연기»(`/api/class/schedule/free-teachers`)는
    안 켬 — 학생이 강사 업무량을 볼 이유가 없고 순서도 예전 이름순 그대로(응답 `pick` 도 `day_count` 를 안 실음).
- 화면 `public/js/class-move-modal.js` — 카드 이름 아래 「그날 N회 / N classes that day」, 목록 위 「그날 수업이 적은 강사부터 보여 드립니다」.
  `null` 이면 아무것도 안 그림. `?v=8 → 9`(admin.html · admin/student.html · manager.html · branch.html 네 곳 모두).

## 검토했다가 버린 것
- **화면에서 세기** — 화면은 그날 전체 시간표를 모른다(오늘 수업 목록은 지사 범위로 잘려 있을 수 있음). 서버 한 곳에서.
- **항상 세기(학생 경로 포함)** — 학생 화면 순서가 바뀌고 조회가 늘어나 이득이 없음. 옵션으로만.
- **공휴일 휴강 반영** — 수 세기에는 안 넣음(휴강일에 수업을 옮길 일이 드묾). 필요하면 별건.
