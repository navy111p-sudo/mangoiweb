# 매니저 화면 «빈 강사 찾기 (날짜·시간)» — 2026-10-13

## 왜 했나
필리핀 매니저 질문: 「학원이 5시에 학생 5명을 등록하려는데, 그 시간에 빈 강사가 있는지 바로 볼 수 있나?」
→ 없었다. 비슷한 것은 셋(주간 스케줄 «빈자리 찾기» · 수강신청 «시간 먼저» · 대기자 명단)인데
모두 «눈으로 세기» 이거나 «요일 반복» 기준이라 «특정 날짜 하루» 에 숫자로 답하지 못했다.
사장님 결정: **특정 날짜 하루 기준.**

## 만든 것
- 화면: `manager.html` 수업 관리 › **👥 Find free teachers / 빈 강사 찾기** (본사 계정만 보임)
  - 입력: 날짜 · 시작 시간(한국 시간, 옆에 필리핀 시간 표시) · 수업 길이(20/30/40) · 학생 수(1:1)
  - 결과: «확실히 빈 강사 N명 → 학생 M명 배정 가능 / K명 부족», 강사 목록(그날 수업 수 포함),
    «카페24 확인» 이 필요한 강사, 안 되는 강사 수, 공휴일 휴강 표시
- 서버: `GET /api/pay/enroll/admin/free-teachers-on-date?date&time&minutes`
  - 게이트: 이 접두사의 기본값 = 본사 전용(`enrollAdminHqOnly`). 강사·지사·대리점 403.
    `src/index.ts`(공동 금지구역)는 안 건드림 — `/api/pay/` 가 접두사로 이미 라우팅됨.
  - 판정 정본: `src/free-teachers-on-date.ts` 의 `freeTeachersOnDate()`

## 판정 (세 겹 모두 통과해야 «가능»)
1. `moveCandidatesFor` — 옮기기 승인이 쓰는 그 겹침 검사 + 대체 수업 + 근무 불가 (복제 안 함)
2. `teacherIntervalsOn`(enroll-ops.ts 신설) — 1이 원리상 못 보는 둘을 막음
   - «같은 시각·같은 길이» 수업: 1은 합반으로 보고 빼서 **1:1 수업 중인 강사가 «빈 강사» 로 나옴**
   - 날짜 없는 «매주 반복» 행: 1의 날짜 조회가 `scheduled_date` 로만 좁힘
3. 공휴일 휴강(`holiday-closure.ts`) — 예외 강사(중국어 강선생님)는 엶

## 검토했다가 버린 것
- **수강신청 «시간 먼저» API(`teachers-free-at`) 재사용** — 요일 반복 기준이라 특정 날짜를 못 넣음.
- **카페24 미러를 안 켠 강사를 «가능» 에 넣기** — [잰 것 2026-10-13] 미러 모드 `whitelist`,
  활성 24명 중 19명만 미러(FAR·JP·KARL·MELCA·MAIMAI 는 아님). 그들의 카페24(LMS) 수업은 우리 시간표에 없으므로
  비어 보여도 «모름». 학원에 «된다» 고 답했다가 겹치면 안 되므로 **«카페24 확인» 으로 따로** 보여 주고
  «가능» 숫자에는 넣지 않음.
- **강사·지사에게도 열기** — 전체 강사 명단·하루 일정이라 본사 전용 유지.

## 리뷰(trap-check) 뒤 고친 것
- 🔴 미러 모드 'off' 인데 «확실히 가능» 으로 나오던 것 → off 면 전원 «카페24 확인».
- 🔴 «오늘+14일» 이후 날짜를 «확실히 가능» 으로 보던 것 → 야간 미러가 그 날짜까지만 만들므로 그 뒤는 전원 «카페24 확인» + 화면 안내.
- 🟡 'all' 모드에서 «켜지 마라»(enabled=0) 강사 → «카페24 확인».
- 🟡 근무 불가 표를 못 읽으면 «없음» 으로 삼켜 휴가 중인 강사가 «가능» 이 되던 것 → 표가 «없는» 것만 정상, 그 밖은 ok:false.
- 🟡 «그날 수업 수» 와 «빈 강사» 가 서로 다른 조회를 쓰던 것 → `teacherIntervalsOn` 하나로 합침.
- 무작위 시험이 찾은 것: 대체가 잡힌 수업의 «원래 강사» 가 (같은 시각·같은 길이일 때) «비었다» 로 나오던 것
  → 빈 강사 화면에서는 원래 강사도 «바쁨»(`keepOriginal`, 그날 수업 수에는 안 씀).
