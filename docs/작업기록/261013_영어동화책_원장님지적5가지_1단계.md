# 영어 동화책 샘플 — 원장님 지적 5가지 1단계 반영 (2026-10-13)

## 왜 했나
원장님들이 A.i 영어 동화책 샘플(4편 — 빨간 우산·생일 케이크·로봇 춤·보물 지도)을 보고 지적한 5가지.
제안서: https://claude.ai/artifact/5dDnJejQ5UgdCLNPLRTBy9 (비공개). 사장님 「추천안대로 1단계부터 · 정할 것은 알아서」.

## 한 것 (4편 공통)
1. **응용문장 자동 고치기** — 「완성하기」를 누르면 `js/story-kit.js` 의 `StoryKit.review()` 가 구조·철자를 봅니다.
   - 문법(동사 원형 자리에 주어·-s·-ing·to, 주어-동사 일치, be 일치, -ing 앞 be 빠짐)이 틀리면 **도장을 막고** 고친 문장·이유(한/영)를 보여 줍니다.
   - 「✏️ 고친 문장으로 바꾸기」 → 「🔊 내 문장 듣기」를 누르면 도장. 직접 고쳐 다시 「완성하기」도 됩니다.
   - 철자만 틀리면 도장은 그대로 주고 «확인해 보세요» 만 말합니다.
   - 규칙 기반(결정론) — LLM 아님. **모르면 안 고칩니다**: 철자는 4글자 이상·글자 바꿈/빠뜨림·후보 하나일 때만, 주어는 대명사·한정사+명사·이름/가족 호칭만.
   - 사전 `js/story-dict.js`(4,805낱말)는 `scripts/build-story-dict.mjs` 가 `word-pictures.json`+`stopwords.json` 에서 만듭니다.
   - StoryKit 이 없으면(로드 실패) 예전 동작.
2. **심화 질문의 한국어 번역 줄 제거** + 학생 화면의 EN/한국어 전환 버튼 제거(언어 고정 ko). 데이터(`q.qko`)는 남김(기존 하니스가 요구).
3. **근거 설명만 한국어**(`q.why[0]`).
4. **뜻 맞히기 정답 노출** — 핵심단어 카드의 뜻을 «👀 뜻 보기» 뒤로 감춤. 게임을 끝내면 열림. 엿본 낱말은 게임에 한 번 더(`wqAgain`). 보기에 다른 편의 뜻 1개를 섞어 «같은 편 6개 중 소거» 를 막음(`poolFor`).
5. **요점정리 영어 글로** — 다 맞히면 요점정리 카드(문장 전부 + 누가/문제/해결 틀 + 문장별 읽기 강조)가 남음.
