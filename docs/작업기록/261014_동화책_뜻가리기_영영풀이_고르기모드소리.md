# 영어 동화책 4편 — 뜻 미리보기 제거 · 영영풀이 · «소리가 안 나요» 수리 (2026-10-14)

## 왜 했나 (원장님 제보 4건)
1. 낱말 게임이 안 끝났는데 한글 뜻이 보인다 → 아이들이 답을 미리 본다.
2. «처음부터 다시» 를 누르니 본문 소리가 안 들린다.
3. 낱말 카드에 예문보다 영영풀이가 있으면 좋겠다(중학교 영영풀이 대비).
4. 본문 문장을 아무거나 눌러도 소리가 안 난다.

## 원인 (잰 것 — 로컬 서버 + 크로미움, speechSynthesis 를 가로채 «읽기 요청» 을 셈)
- 2·4번: ② 핵심 문장의 «✏️ 고르기 시작» 이 켜져 있으면 본문 문장을 눌러도 칠하기만 하고 읽지 않는다.
  ① 칸에는 켜져 있다는 표시가 없었고, «처음부터 다시» 는 도장만 지우고 이 모드를 안 껐다.
  사진 4의 노란색(`#ffe58a`, 밑줄 없음)이 바로 «고르기» 색이다. 재현: 고르기 중 클릭 → 읽기 0건, 처음부터 다시 뒤에도 0건.
- 1번: 10/13 에 넣은 «🙈 눌러서 보기»(엿보기) 버튼. 게다가 게임을 한 번 끝내면 «열림» 을 localStorage 에 저장해
  «한 번 더 하기»·«처음부터 다시» 때도 뜻이 전부 보였다.

## 한 일 (사장님 결정: 1번=가, 3번=나 · 4편 모두)
- 1번(가): 엿보기 버튼 삭제. 뜻은 «이번 게임을 다 풀었을 때만». 열림을 저장하지 않고 예전 판이 남긴 기록도 지움.
  «한 번 더 하기»·«처음부터 다시» 는 다시 가림.
- 3번(나): WORDS 4번째 칸에 영영풀이(손으로 씀, 낱말 자신은 안 씀) — 카드에 «영영풀이» 줄을 예문 위에, 예문은 아래 작게.
  🔊 는 낱말 → 영영풀이 순으로 읽음.
- 2·4번: 고르기 모드가 켜져 있으면 ① 본문 바로 위에 알림 + «고르기 끝내기» 버튼(고른 문장은 유지 — 정답 확인에 쓰임). «처음부터 다시» 는 고르기 모드를 끄고 고른 것도 지우며,
  낱말 게임도 처음으로.

## 버린 방법
- 고르기 중에도 문장을 읽게 하기 — 고르는 동안 매번 소리가 나 «칠하기» 와 섞인다. 알림 + 끄기가 낫다.
- 영영풀이를 AI 로 생성 — 아이가 그대로 외우는 문장이라 결정론(손으로 쓴 값)으로.
