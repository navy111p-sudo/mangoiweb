# AI 영작 — 그림·문장 연습·브레인스토밍이 «지금 주제 하나» 를 따르게 (2026-10-16)

## 왜
세 칸이 서로 다른 주제를 말했습니다.
- 문장 연습(`initSentenceCoach`)이 **언제나 지금 그림**(`PIC_SCENES[_picIdx]`)만 읽어, 글감·내 경험 주제를 골라도 그림 문장 틀이 나왔습니다.
- 그림으로 브레인스토밍을 시작한 뒤 «다른 그림» 을 누르면 화면 그림만 바뀌고 브레인스토밍 주제는 옛 그림에 남았습니다.
- 새로고침하면 브레인스토밍 주제(저장값)는 그림 A 인데 화면은 처음 그림(0번)이었습니다.

## 한 일 (`public/ai-write.html`)
- 정본 `window.awCurTopic()` — 학생이 고른 주제(`_goTheme`)가 있으면 그것, 없으면 지금 보이는 그림.
- 문장 연습이 그 정본을 따름: 글감·내 경험이면 그 시작 문장(`starter`)으로 틀을 만들고, 확장 질문도 그림용(«표정을 보고») 대신 일반 질문, 맨 위에 «지금 주제: …» 표시.
- `window.awOnPicChange()` — **그림 주제로 쓰는 중**에만 그림을 바꾸면 주제도 따라감. 적은 답은 지우지 않고 «앞서 고른 … 대신 바꿨어요» 한 줄. 글감·내 경험 주제는 그대로(학생이 고른 주제가 이김). 스크롤·포커스는 안 옮김.
- 새로고침 때 저장된 주제가 그림이면 그 그림을 다시 띄움.

## 검토했다가 버린 것
- 그림을 바꾸면 «무조건» 브레인스토밍 주제를 새 그림으로 → 글감을 고른 학생의 주제가 그림 버튼 하나에 사라짐.
- 그림 주제가 바뀔 때 답을 지우기 → 학생 입력을 잃음(«바꿨어요» 알림으로 대신).
