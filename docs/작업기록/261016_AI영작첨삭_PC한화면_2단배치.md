# AI 영작 첨삭 — PC 화면을 스크롤 없이 한 장에 (2단 배치)

- 날짜: 2026-10-16
- 파일: `cloudflare-deploy/public/ai-write.html` (CSS 한 블록 추가, DOM 은 손대지 않음)

## 1. 왜 했나
사장님 화면(1920×1080 모니터, 브라우저 안쪽 높이 920px)에서 «AI 영작 첨삭» 첫 화면이 세로로만 쌓여 있었다.
오늘의 그림이 화면 끝에서 반쯤 잘리고, 미션 단어·쓰기 칸·「AI 첨삭 받기」는 스크롤해야 보였다.
요청: 「한방에 모두 보이게 · 글자 크기는 그대로」.

## 2. 무엇을 바꿨나
`@media (min-width:1200px)` 에서만 `.wrap` 을 2단 그리드로 바꿨다.
- 왼쪽(고르기): 사용 방법 버튼 → 난이도 A1~C1 → 장면 선택 → 오늘의 그림
- 오른쪽(쓰기): 3단계 안내 줄 → 소개(캐릭터 116→68px) → 미션 단어 → 🙋 도움 → 내 영작 칸 → AI 첨삭 받기
- 결과·성장 그래프·영작 일기는 그 아래에서 두 칸을 다 쓴다.
- 그림 높이·쓰기 칸 높이는 화면 높이(`100vh`)에 맞춰 늘고 준다.
- 마지막 줄을 `1fr` 로 둬서 그림 카드가 길어져도 오른쪽 칸들 사이가 벌어지지 않게 했다.

## 3. 검토했다가 버린 방법
- 오른쪽에 난이도·장면까지 몰기: 1920×920 에서 첨삭 버튼이 하단 «말로 쓰기» 바 밑으로 75px 들어가서 버렸다.
  → 난이도·장면은 «그림을 고르는» 일이라 그림 위(왼쪽)로 옮겼다.
- 좌우 묶음 `<div>` 를 새로 만들기: DOM 순서가 바뀌어 폰 화면 순서가 달라지고 JS·하니스가 찾는 구조가 흔들린다. CSS 그리드 «자리» 만 정했다.

## 4. 확인한 것 (잰 값)
로컬 서버 + Chromium(사용 방법 창은 «본 것» 으로 둠):
- 1920×920: 첨삭 버튼 782~844px, 하단 말로 쓰기 바 849px — 전부 첫 화면 안. 그림 카드 269~846px.
- 1920×1080: 첨삭 버튼 942~1004px, 바 1009px — 첫 화면 안.
- 글자 크기 그대로: 제목 30px · 난이도 17px · 쓰기 칸 19px (바꾸기 전과 같음).
- 390×844 폰: 모든 요소 위치가 바꾸기 전과 같음(미디어쿼리 밖).
- 가로 넘침 없음(scrollWidth = innerWidth).
- 자동 하니스 6종(ai_write_brainstorm 95 · guide 31 · picture_mission 27 · login_uid_shape 67 · speech_recognition 33 · stt_hardening 73) 전부 FAIL 0, origin/main 과 같음.
- 브라우저 `manual/ai-write-guide-browser.mjs`: main 에서 FAIL 18 → 이 변경 후 16. 새로 생긴 FAIL 0건(comm 대조). 남은 FAIL 은 첫 방문 «사용 방법» 창이 덮어서 나는 것으로 main 에도 똑같이 있다(별건).

## 5. 못 한 것
- 1366×640·1536×730 같은 낮은 노트북 화면은 글자를 안 줄이는 한 한 화면에 다 못 넣는다(그림·쓰기 칸은 보이고 첨삭 버튼만 스크롤 아래).
- 배포된 실제 화면은 이 환경에서 못 본다 — 사람이 한 번 확인해야 끝.
