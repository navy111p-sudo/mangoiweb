## 1. 왜 했나
사장님 요청 「영어교육 개선안」 코드 분석에서 **0순위(버그·보안) 4건**을 뽑았고, 그중 3건을 이번에 고쳤습니다.
1. 단어 퀴즈를 틀려도 그 단어가 복습에 다시 안 나옴 — `/api/vocab/quiz-submit` 이 정답/오답 카운트만 올리고 `next_review_at`·`level` 을 안 건드렸습니다.
2. 웜업 21번째 대화부터 교정이 멈춤 — «몇 번째 턴» 을 `history.length`(조회 `LIMIT 20`)로 세서 21에 붙고, `turnCount - lastShownTurn` 이 0이 되어 교정 게이트가 영영 닫혔습니다.
3. 레벨테스트 정답·해설이 로그인 없이 새어 나감 — 24문항을 전부 0번으로 채워 한 번 부르면 정답키가 100% 복원됐습니다(CLAUDE.md 「시험·퀴즈에서 정답을 보여주는 기능」 항목에 적혀 있던 남은 위험).

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법
- **퀴즈 완료를 먼저 따로 UPDATE 하고 SRS 는 try/catch** (첫 판) → Codex 리뷰가 잡음: SRS 가 한 번 실패하면 완료만 남고, 재제출은 `changes === 0` 으로 걸러져 **그 답이 복습 일정에 영영 안 들어감**. ⟹ batch 하나로 묶음.
- 웜업 턴을 `COUNT(*)` 로 세기 → 웜업 대화가 D1 에 매 턴 저장되지 않아 근거가 없음. 세션 KV 카운터를 택함.
- 레벨테스트 해설을 아예 없애기 → 로그인 학생에게는 학습 가치가 큼. 익명만 잠금.
- 0순위 4번째 «레벨 판정이 너무 후함(4문항 중 2개)» 은 **안 고쳤습니다** — 문턱을 3/4 로 올리면 과대 22%→3% 지만 과소 3.6%→31% 로 나빠지고, 판정할 «정답»(`teacher_score`)이 0건이라 사람이 정할 일입니다(`docs/작업기록/260922_레벨계산규칙_잰것과_결론.md`).
