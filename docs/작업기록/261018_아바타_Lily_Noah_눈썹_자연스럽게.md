# 아바타 Lily·Noah 눈썹을 말할 때 자연스럽게 (2026-10-18)

## 왜 했나
사장님: 「lily랑 noah가 눈썹다 말할때 자연스럽게 움직이게 해줘」. 그전에는 말소리가 커질 때 «눈썹 올린 칸» 으로
**한 번에 바꿔 끼우고**(eyeState 3) 끝나면 한 번에 되돌려, 눈썹이 «툭» 튀었다 «툭» 떨어졌습니다.

## 한 것 (mango-avatar.js v15 · `?v=36`, 화면 6곳)
- Lily·Noah 만(`BROW_SMOOTH` 표에 눈썹 띠 좌표가 있는 캐릭터) 눈썹을 **원본 사진의 띠를 세로로 늘이고 줄여** 그립니다(`browWarp`).
  이마 쪽은 눌리고, 눈썹은 최대 7px(Lily)·8px(Noah) 올라가고, 눈꺼풀 살은 늘어납니다. 좌우 끝은 가로 그러데이션으로 섞습니다.
- 올리는 양 `browLv` 은 지수 이징(올릴 때 τ 70ms · 내릴 때 170ms).
- 말이 «시작될 때»(소리가 커지는 순간 = onset)만 80% 확률로 올리고, 30% 는 크게(0.85~1), 나머지는 작게(0.45~0.75). 1.4~4초 간격.
- 말이 멈추면 rAF 로 0.6초 안에 내려앉습니다(`browSettle`). 캐릭터를 바꾸면 그 rAF 를 끊습니다.
- 다른 캐릭터(Emma·Jake·Mei·Long)는 옛 동작 그대로.

## 버린 방법
1. **눈썹 올린 칸을 반투명(globalAlpha)으로 겹치기** — 중간 단계에서 내린 눈썹·올린 눈썹이 함께 비쳐 «눈썹 두 줄». 크로미움 픽셀로 확인 후 버림.
2. **띠 전체를 크게 늘이기(D 12px 이상)** — 눈꺼풀 주름이 두 겹. 7~8px 로 낮추고 띠를 넓힘.
