# A.i 선생님 수업 — 선생님 화면 크게·작게 (2026-10-19)

## 1. 왜 했나
사장님 「이거 크게 작게 하는 기능 추가해줘. 교사화면 크기」 — `/ai-class.html` 스크린샷에 교재 칸과 선생님(Emma) 칸 사이 경계에 세로선과 ←← 를 그려 보내셨습니다. 경계를 끌거나 버튼으로 선생님 화면을 키우고 줄이는 기능입니다.

## 2. 무엇을 했나 (파일 1개 — `cloudflare-deploy/public/ai-class.html`)
- **경계 손잡이** `#tSplit` — 교재·선생님 칸 사이를 끌면 폭이 바뀝니다. 가운데 작은 손잡이에 **◀(크게)·▶(작게)** 버튼(5%씩), **두 번 누르면 원래대로**(31%).
- **키보드**: 경계에 포커스(Tab) 뒤 ← 크게 · → 작게 · Home 최대 · End 최소 · Enter 원래대로. 그 키는 수업 단축키(스페이스·화살표)로 새지 않습니다.
- **기억**: 고른 비율을 `localStorage` `aiClassTeacherW`(0.20~0.60)에 저장 — 다음 수업에도 같은 크기. 비율로 기억하므로 창 크기가 바뀌어도 같은 비율.
- **폰(≤760px)**: 손잡이가 숨고 폭 규칙도 안 걸립니다(저장값이 있어도 폰 배치는 그대로).
- **범위**: 교재 최소 320px · 선생님 최소 220px(옛 기본값의 바닥과 같음) · 최대 60%.
- **작게 했을 때** 「Emma · A.i Teacher」 이름표가 오른쪽 아래 학생 창과 겹치지 않게 말줄임(…).
- 이름표·툴팁·화면낭독기 이름 전부 한/영 병기.

## 3. 얼굴 보호 상한 — 그리고 그 기준을 바꾼 이유
선생님 그림은 칸을 «덮어» 채웁니다(`object-fit:cover`). PC 큰 화면은 칸 높이가 화면에 묶여 폭만 늘기 때문에, 넓히면 얼굴이 확대돼 «눈만» 남습니다(1383×786 에서 60% → 그림 695×239 = 가로÷세로 2.9 실측).
- **1차**: «그림 칸 가로÷세로 ≤ 2.2» 로 막았습니다.
- **문제(실측으로 발견)**: 수업이 흐르면 «대답 고르기» 보기가 떠서 그림 칸이 **239 → 110px** 로 눌립니다. 그 높이로 상한을 다시 재면 선생님 칸이 **40% → 21%** 로 줄었다가, 보기가 사라지면 다시 넓어져 **수업 중에 칸이 출렁였습니다.** 게다가 처음 불러올 때(수업 시작 전 — 대답 칸이 아직 없음)는 그림 칸이 높아 상한이 아예 안 걸렸습니다.
- **고침**: 상한을 «오른쪽 칸 전체(선생님·자막·대답) 가로÷세로 ≤ 1.25» 로 잽니다(`TW_SIDE_MAX`). 칸 전체 높이는 화면이 정하므로 수업 내내 같습니다 → 출렁임 0. 평소 그림 가로÷세로는 1383 에서 2.20 · 1920(확대 1.2) 2.08 · 1200×540 2.39(눈썹~턱).
- 다시 재는 시점: 창 크기 변경 + 교실 칸 크기 변경(ResizeObserver — ⛔ 그림 칸이 아니라 교실 칸을 봅니다).

## 4. 검토했다가 버린 방법
- **그림만 좁혀 가운데 두기**(캔버스 폭을 `205cqh` 로 제한) — Emma 그림에 자체 배경이 있어 양옆에 이음매가 보였습니다(실측). 되돌렸습니다.
- **그림 칸 높이로 상한 재기** — 위 3절의 출렁임.
- **손잡이를 «대답 고르기» 상자보다 위로** — 그 상자(.sim)가 교실 가운데에 떠서 경계 아래쪽을 덮는데, 손잡이를 위로 올리면 16px 띠가 **보기 버튼 클릭을 가로챕니다.** 그래서 상자가 이기게 두었습니다(손잡이 위쪽·◀▶ 는 그대로 닿음).
