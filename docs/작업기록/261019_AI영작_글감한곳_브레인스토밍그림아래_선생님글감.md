# AI 영작 — 글감 고르는 곳 «하나» · 브레인스토밍을 그림 바로 아래로 · 선생님 글감 만들기 (2026-10-19)

## 왜 했나
사장님 의견(선생님 제보 화면과 함께) 세 가지:
1. 「글감이 두세 군데 있는 것보다 **한 군데에서 «오늘의 글감»** 을 고르는 게 좋다」
2. 「움직이는 그림의 글감과 브레인스토밍의 글감을 합쳐 그림 위 **«장면 선택» 에 합쳐서** 창구를 한 군데로」
3. 「움직이는 그림 **밑에** 브레인스토밍의 6하원칙(글의 뼈대) — 그 글감으로 STEP 3 «내 영작» 에서 쓰고 AI 첨삭」

이어서 원장님 의견: 「원장(관리자)이 **글감 제목을 쓰는 빈칸**을 그림 위나 아래에 — 제목을 쓰면 바로 아래 브레인스토밍이 나와 그것으로 쓰게」.
물어본 결정 3개: **① 원장·선생님 둘 다** 만든다 · **② 학원 전체**에 보인다 · **③ AI 그림 생성 필요**.

## 한 것
### 화면 (`public/ai-write.html`)
- **«🎬 장면·글감 선택» 목록 하나**(`#picChoice`)에 네 묶음 — 📌 선생님 글감 · 🎬 그림 장면 · 🧠 내 경험 이야기 · 🎲 오늘의 글감(`AW_GROUPS`·`awPickerEntries`·`awBuildPicker`).
  옛 고르는 곳 셋(🎲 글감 칩 줄 `#topicRow` · 🧠 경험 칩 · «셋 중 하나만» 안내 `#pickNote`)은 지웠습니다.
- **브레인스토밍(`#goCard`)을 «🙋 도움이 필요해요» 밖, 그림 바로 아래로.** 그림·선생님 칸·브레인스토밍을 `.aw-plan` 한 묶음으로 두어 PC 2단(≥1200px)에서는 왼쪽 칸에 함께 놓입니다. «도움» 안에는 문장 연습만 남았습니다.
- **그림이 없는 글감은 그림 칸에 «제목 카드»**(`#picTopic`) — 그때 «이 장면으로 쓰기»·움직임 버튼·배지는 감춥니다. «🔀 다른 그림» 을 누르면 그림이 다시 주제가 됩니다.
- **📌 선생님 글감 만들기 칸**(`#wtPanel`) — 서버가 `can_create` 를 줄 때만 보입니다(학생 화면에서는 `hidden` 그대로). 제목 → «🧠 브레인스토밍 만들기»(AI 초안이 **바로 아래 브레인스토밍에 그대로** 보임) → 고쳐 «💾 저장» → «🎨 그림 만들기(AI)» → «📢 학원 전체에 올리기». 아직 안 올린 초안은 목록에 «(아직 안 올림)».
- 선생님 글감을 고르면 **그 글감의 질문(6하원칙)·첫 문장·미션 단어**가 그대로 쓰입니다(영어가 아닌 단어는 버림). 새로고침해도 그 글감이 되살아납니다.

### 서버 (`src/write-topics.ts` 신설 · `src/api-mango.ts` 위임 6줄)
- `/api/class/write-topics` — GET(학생: 올린 글감 목록 · 직원 쿠키가 있으면 `can_create`·내 글감·남은 횟수), POST `draft|image|save|publish|hide`, 그림 `GET …/img/<id>/<판>`(R2 `write-topics/`, 1년 캐시 · 판이 안 맞으면 404 · 새 판을 만들면 옛 R2 파일 삭제).
- **권한은 «모르면 막기»** — `getAdminActor` + `admin_scope` 재조회 → `writeTopicEditVerdict`(hq 만 통과 · 지사·대리점 403 `forbidden_scope` · 못 읽으면 403 `scope_unknown`). **선생님은 자기 글감만** 고칩니다(아이디 완전일치), 본사는 전부.
- **하루 상한** 한 사람 30회 · 전체 300회(`write_topic_gen_log` 로 셈. 못 세면 막지 않음 — 부르는 사람이 이미 로그인 직원).
- **학생 목록에는 직원 칸(`status`·`created_by`·`image_prompt`)을 싣지 않습니다.**
- 초안 AI: llama-3.3-70b → 실패하면 llama-3.1-8b → 그래도 실패하면 **기본 6하원칙 6칸**(`ai_used:false`). 그림 AI: flux-2-klein-4b → flux-1-schnell.
- 표 `write_topics`·`write_topic_gen_log` 는 첫 호출 때 `CREATE TABLE IF NOT EXISTS`(기존 데이터는 안 건드림).

### 함께 고친 결함 (새 검사가 찾음)
1. **`Number('')` 는 0** — 목록 값 `pic:`·`topic:` 처럼 번호가 빈 값이 **0번 장면·0번 글감을 골랐습니다.** 숫자만 받게(`/^\d+$/`).
2. **미션 단어를 «거르기 전에» 3개로 잘라** 선생님이 한글 단어를 하나 섞으면 영어 단어가 2개만 남았습니다 → 거른 뒤 자름.
3. **영어로 저장된 학생이 «처음» 열면 목록 묶음 이름·«지금 주제» 줄이 한국어**였습니다(🌐 를 눌러야 고쳐짐) — 이 화면 스크립트가 공용 i18n 엔진(defer)보다 먼저 돌아 `getLang` 이 없었기 때문. 엔진이 실린 뒤(`DOMContentLoaded`) 한 번 다시 그립니다.

## 검토했다가 버린 방법
- **목록을 둘로(그림 / 글감) 남기기** — 사장님 지시가 «한 군데» 였고, 셋이던 때 «무엇이 다른지» 를 아무도 몰랐습니다(2026-10-05·10-16 제보).
- **선생님 글감을 화면(localStorage)에만 저장** — ②«학원 전체» 를 못 지킵니다.
- **지사·대리점도 만들게** — 학원 전체에 보이는 글감이라 남의 지사 학생 화면에 실립니다. 본사·선생님만.
- **권한을 화면에서 판정** — 화면은 서버가 준 `can_create`·문구를 그리기만 합니다.
- **AI 초안 실패 시 오류로 끝내기** — 기본 6하원칙 6칸으로 떨어뜨려 제목만으로도 쓸 수 있게 했습니다.
- **«🔀 다른 그림» 을 눌러도 고른 글감 유지(10-16 규칙)** — 그림 칸이 이제 «지금 글감» 을 보여 주는 자리라, 다른 그림을 누르는 것은 «그림을 고르는 것» 입니다(바뀜 알림이 함께 뜹니다).
