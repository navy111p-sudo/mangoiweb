# 수업 관찰 — «예약 기준 지금 수업» 줄에 «🚪 직접 입장(보임)» 버튼 (2026-10-19)

## 왜 했나
필리핀 매니저 질문: 「Observe class 에서 매니저가 보이게 참관할 수 있나요?」

- 「👁 바로 참관」(`ghQuickObserve`)은 **투명 유령** 설계라 학생·강사에게 안 보입니다(카메라·마이크도 안 보냄).
- 보이게 들어가는 길(`ghEnterRoom` — 실제 참가자 · 카메라 꺼진 채 입장)은 같은 카드의 **위쪽 «화상방» 표에만** 있었습니다.
- 그런데 그 표는 **누군가 화상방에 접속해야** 뜹니다. 제보 화면처럼 「지금 망고아이 화상방에 접속해 있는 사람이 없습니다」일 때(수업 시작 직전)는 아래 «예약 기준 지금 수업» 줄만 보이고, 거기에는 «바로 참관» 뿐이라 **보이며 들어갈 길이 이 카드에 없었습니다.**

사장님 지시: 「Booked classes 목록에도 Join (visible) 버튼 추가해줘」.

## 검토했다가 버린 것
- **이름을 «Join (visible)» 로**: 같은 카드 위쪽 표가 이미 «Enter (visible) / 직접 입장(보임)» 이라, 한 카드에 같은 동작이 두 이름이면 헷갈립니다. 같은 이름으로 맞췄습니다(「오늘 수업」 카드의 «Join (visible) / 입장(보임)» 은 다른 화면이라 그대로).
- **🔴 실시간 수업 현황(adm-core.js)·수업 고르기(ghost-view.html) 표에도 추가**: 그 두 화면의 «화상방» 줄 자체에 직접 입장 버튼이 없어, 예약 줄에만 넣으면 그 화면 안에서 어긋납니다. 이번 지시 범위(수업 관찰 카드)만 했습니다.
- **입장 시간 창(시작 10분 전~종료 15분 후)으로 가르기**: 이 목록은 서버가 이미 «지금 수업(곧 시작·진행 중·방금 끝남 5분)» 만 주고, 방에는 시간 잠금이 없습니다. 확인창이 있으므로 같은 조건(방이 있는가)만 봤습니다.
