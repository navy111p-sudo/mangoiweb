# 아바타 Lily·Noah 눈썹이 자연스럽게 내려오게 (2026-10-19)

## 왜 했나
같은 날 눈썹을 더 자주(v16)·더 높이(v17) 올린 뒤 사장님이 **「눈썹 조금 더 자연스럽게 내려오게 해줘」** 라고 하셨습니다.
코드를 보니 내려오기가 지수 감쇠(τ 170ms)였습니다 — 지키던 높이에서 내려오기 **«시작하는 순간이 가장 빠르고»**
(첫 프레임에 가장 많이 떨어짐 = 툭), 끝은 꼬리처럼 오래 끌린 뒤 0.6초에 0 으로 잘렸습니다.

## 한 것 (mango-avatar.js v18 · `?v=39`, 화면 6곳)
- `browStep` 의 «내려오기» 를 **smoothstep 곡선**으로: 천천히 떨어지기 시작해 · 가운데서 가장 빠르고 · 살며시 내려앉습니다.
- 걸리는 시간은 올렸던 높이에 비례: `browDownMs = 0.38 + 0.3×높이` 초(보통 높이 0.6 → 0.56초, 최대 → 0.68초 — 그래서 «약 0.5~0.68초»).
- 내려오기 시작 시각은 «지키기가 끝난 그 시각»(`browHold`)부터 잽니다(프레임 사이에 끝나도 어긋나지 않게).
- 시계가 뒤로 가면(시간 동기화 등) 그 자리에서 다시 잽니다 — 안 그러면 진행률이 음수로 묶여 눈썹이 올라간 채 멈춥니다.
- 깜빡임 미루기(`browUntil`)를 «지키기 끝 + 내려오기 + 0.04초» 로 — 다 내려오기 전에 눈 그림이 덮어 눈썹이 «뚝» 내려가지 않게.
- 말이 끝난 뒤 내려앉기(`browSettle`) 상한 0.6 → 0.75초.
- **올라가기는 그대로**(지수 τ 70ms) — 눈썹은 «빠르게 올라가고 천천히 내려오는» 것이 자연스럽습니다.

옛 v15(5.0초·18초)보다는 여전히 고릅니다.

## 버린 방법
- **τ 를 늘리기만(지수 그대로)** — 더 느려질 뿐 «시작이 가장 빠른» 모양은 그대로라 툭 떨어지는 느낌이 남습니다.
- **직선(일정한 속도)** — 시작과 끝에서 속도가 꺾여 기계처럼 보입니다.
- **올라가기까지 smoothstep** — 강세에 늦게 반응해 말과 어긋나 보입니다.
