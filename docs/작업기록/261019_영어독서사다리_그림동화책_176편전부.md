# 영어 독서 사다리 새 글 128편에도 그림 동화책 (48권 → 176권, 2026-10-19)

## 왜 했나
사장님이 `mangoi.ai/stories.html` 화면을 보내시며 「왜 그림이나 실사 이미지가 없는 도서책들이 있어?」라고 물으셨습니다.
원인은 같은 날 사다리 글을 48편에서 176편으로 늘리면서, 새 글 128편에 `book:false` 를 달아 그림책 표시를 꺼 두었기 때문입니다(그림책이 없는 페이지로 보내지 않으려는 조치).
사장님이 「2번」(새 글 전부를 그림 동화책으로 만들기)을 고르셨고 「재밌고 유익하고 독서에 도움이 되는 아주아주 흥미로운 이미지들 꼭 넣어줘. 힉스필드에서 받아서」라고 하셨습니다.

## 그림을 만들며 고친 것
- **Higgsfield 안전 필터에 걸린 장면 3장**: 원인 문구를 빼고 다시 만들었습니다. 셋 다 통과했습니다.
  - s2-29 «아홉 살 쌍둥이 소녀» → «쌍둥이처럼 닮은 두 아이»
  - s1-24 «해적들이 겁에 질려 떤다» → «통 뒤에서 놀란 얼굴로 엿본다»
  - s2-45 «어둠 속에서 빛나는 두 눈» → «환풍구에서 삐져나온 고양이 꼬리»
- **표지를 그대로 베낀 장면 12장 (s1-20·23·36·38·46·48 · s2-40)**
  - 문제: 장면이 표지를 참조하다 보니 세 장이 거의 같은 그림인 권이 있었습니다(흑백 축소 비교 차이 2~10).
  - 1차: «레이아웃을 베끼지 말고 다른 구도로» 라는 문장을 붙여 다시 만들었습니다. 9장이 좋아졌습니다(차이 34~54).
  - 2차: 남은 3장(s1-23·s1-46)은 «가까이 당겨 찍은 구도» 로 한 번 더 만들었습니다. 데이터의 그림 설명도 실제로 쓴 문장으로 맞췄습니다.
  - 새 1~2단계 그림의 장면 간 차이 중앙값은 31.8입니다. 처음 48권은 20.8이었습니다.
  - 잰 방법: 그림을 흑백 64×43 으로 줄여 픽셀 차이의 평균(0~255)을 냈습니다. 그 스크립트는 작업용 임시 폴더에만 있었고 저장소에는 남기지 않았습니다(다시 재려면 같은 방법으로).
- **503 «Generation creation is busy»**: 일부 표지가 제출 단계에서 거절됐습니다. 같은 요청을 한 번 더 보내 모두 완료됐습니다.
  - [잰 것] 그 요청에는 작업 번호(job_id)가 돌아오지 않았고, 다시 보낸 뒤 장부에는 그림마다 작업이 하나씩만 남았습니다.
  - [판단] 그래서 중복 작업은 없다고 봅니다. **크레딧이 실제로 빠졌는지는 재지 않았습니다**(Higgsfield 사용 내역을 보지 않음).

## 밟은 함정 — «틀 흔적» 검사가 생일 이야기를 잡음
생성기와 하니스는 «틀(2권 The Missing Birthday Cake)의 글자가 남았나» 를 `/Birthday|…/` 로 보고 있었습니다.
그런데 새 글 중 s1-15(공룡알)와 s3-17(세계의 축제)은 본문에 «Birthday» 가 실제로 나옵니다. 그래서 생성기가 «2권 흔적이 남음» 으로 멈췄습니다.
→ 검사를 틀 제목 전체(`Missing Birthday Cake`)로 좁혔습니다. 생성기와 하니스 두 곳을 함께 고쳤습니다.
⛔ 낱말 하나로 «틀 흔적» 을 판정하지 마세요. 새 글이 늘수록 같은 낱말이 본문에 나옵니다.
