## 3. 검토했다가 버린 방법

- **생성 서비스 주소(`d8j0ntlcm91z4.cloudfront.net/…`)를 화면에 그대로 쓰기** — 영구 보관이 아니고(PR #1653 README 도 같은 말), 남의 도메인에 실서비스가 묶입니다. ⟹ 화면·빌드 모두 `/…` 경로만 받습니다.
- **에피소드 JSON 하나를 손으로 써서 `public/` 에 두기** — 대본(GPT)·검수 상태(사람)·미디어 경로(우리)가 한 파일에 섞여 누가 무엇을 고쳤는지 안 보입니다. ⟹ 정본을 셋으로 나누고 빌드로 합칩니다. 하니스가 «공개 자료 = 다시 빌드한 것» 을 바이트로 대조합니다.
- **클립 16개를 이어 붙여 장면 6개를 «일단» 만들기** — 대본 사건과 영상이 안 맞고(재채기·작별·로보 없음), 소리에 대본에 없는 대사가 있어 그대로 내면 학생이 엉뚱한 문장을 따라 합니다. 대응은 사람이 정할 일이라 `assignedScene` 을 `null` 로 남겼습니다.
- **녹음·발음 평가 버튼을 함께 열기** — 별도 검증 대상이라고 지시받았습니다. 잠긴 버튼이 «검증 뒤 열려요» 라고 말하게만 했습니다.
- **ChatGPT 의 영상 생성 이어서 하기** — 중복 제작 금지 지시. 생성 서비스는 상태 조회만 했습니다.
