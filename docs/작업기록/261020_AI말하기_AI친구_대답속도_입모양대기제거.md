# A.i 말하기·A.i 친구 대답 속도 — 입모양 분석 대기 제거 (2026-10-20)

## 1. 왜 했나

- 세미나 피드백(부산지사 정사장): 「AI 아바타 입모양과 반응 속도가 약간 느리다」.
- 사장님 지시: 「A.i 말하기와 A.i 친구들 대답 속도, 반응과 대답을 더 빠르게」.
- 대상 화면: `warmup.html`(A.i 말하기 연습) · `ai-friend.html`(A.i 친구).

### 2-2. 브라우저 쪽 (Chromium, 같은 음성 파일)

- 입모양 분석(Rhubarb WASM, Web Worker)은 **소리 길이의 약 0.8배**: 3초 음성 2.3초 · 6초 음성 5.1초.
- 첫 문장은 엔진 부팅 5~6초 + 데이터 다운로드(37.8MB, gzip 28.7MB)까지.
- 부팅 제한이 30초라, 느린 회선은 방문할 때마다 다운로드를 처음부터 다시 했습니다.

⟹ **소리가 이미 도착했는데** `MangoAvatar.prepare()` 가 분석이 끝날 때까지 `play()` 를 막고 있었습니다.

## 5. 검토했다가 버린 것

- **입모양 분석을 아예 끄기** — 2026-08 에 «입이 안 맞는다» 를 고치려고 넣은 기능이라 되돌리면 그 문제가 돌아옵니다. 기다리지만 않게 했습니다.
- **분석 Worker 를 여러 개 띄우기** — 37.8MB 엔진을 여러 번 올려 폰 메모리가 부족합니다.
- **서버 쪽 병렬화**(웜업 문맥 4블록 · TTS R2 저장을 `waitUntil` 로) — `src/index.ts`(공동 금지구역)·`api-games.ts`(B 영역)라 사람 결정이 필요합니다.
- **침묵 판정 줄이기**(웜업 5초 · AI 친구 Whisper 2.5초) — 코드에 「줄이지 말 것」 정책이 적혀 있어 손대지 않았습니다.
