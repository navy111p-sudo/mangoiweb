## 3. 검토했다가 버린 것

- **플레이어에 «장면 하나 = 클립 여러 개» 재생목록을 넣기** → 매니페스트 계약(장면당 영상 1개)이 바뀌고 동기 모드 시각 계산이 복잡해짐. 클립을 장면 영상으로 **이어 붙이는 쪽**이 화면 코드 0줄 변경으로 끝남.
- **1편 아이 얼굴을 다시 만들기** → 사장님이 «똑같이 생길 필요 없다» 로 정함. 크레딧도 안 씀.
- **힉스필드 CDN 주소를 그대로 두기** → 그쪽이 지우면 영상이 사라지고, 다른 오리진이라 완성 영상(캔버스)에 그림이 막힐 수 있음. 우리 서버로 옮김(공개 저장소라 누구나 받을 수 있다는 점은 #1661 선례대로 감수).
- **듣기용 원어민 목소리도 완성 영상에 담기** → 완성 영상에 같은 줄이 «원어민 + 학생» 두 번 들어감. 녹화를 멈춰 빼는 쪽으로.
- **«건너뛰기» 가 그 줄을 통째로 넘기기** → 연습하던 학생이 듣기만 건너뛰려다 자기 차례까지 잃음. 듣기만 건너뛰게.

### 4-1. 함정 대조(trap-check)가 잡은 것 → 고침
- TTS 를 못 받아 기기 목소리로 «먼저 들려주면» 완성 영상 카드에 «일부 대사가 안 담겼어요» 가 **거짓으로** 떴음 → 듣기용이면 표시 안 함.
- 학생 대사는 미리 받지 않아 차례마다 멈칫했고, **받는 사이 «넘어가기» 를 누르면 아무 일도 안 일어났다가** 받은 뒤 끝까지 재생됨 → 미리 받기 + 받는 중 취소.
- 하니스 ⑦-17 이 «녹화 멈춤» 만 보고 «다시 켜기» 를 안 봐서, 그 줄을 지우면(= 첫 학생 줄 뒤로 완성 영상이 빔) 통과했음 → ⑨절이 실제로 돌려 짝으로 봄.
- 준비 중인 편을 `?ep=dub-002` 로 직접 열면 그 칸에 «지금 이 이야기» 가 붙음 → «준비 중» 으로.
- 설명서 «✅ 화면에서 재생» 은 배포·재생 확인 전 완료형이라 «연결됨 · 재생은 사람 확인» 으로.
