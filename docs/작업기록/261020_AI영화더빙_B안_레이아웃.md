## 1. 왜 했나
사장님 제보 — 「A.i 더빙 페이지 레이아웃 디자인이 이상해. 두 장르(모험 3D 애니 6편 · 키키와 토토 10편)가 모두 잘 보이게 한 화면에서」.
실제 화면은 ① 큰 소개 배너·기능 카드가 첫 화면을 차지하고 ② 키키와 토토는 작은 배너 한 줄에 묻혀 있었으며
③ «누가 연기할까요» 가 «무엇을 더빙할까» 보다 먼저 나왔고 ④ «6편 × 에피소드 6» 구조가 화면 어디에도 없었다.
시안 4종을 캔버스로 보여 드렸고(정정: 3D 애니는 6편 각각 에피소드 6개) 사장님이 **B안**을 고르셨다.

## 2. 무엇을 했나
- 첫 화면 위쪽에 **장르 카드 2개**(🦖 모험 3D 애니 6편×6 · 🐱 키키와 토토 10편) — 언제나 둘 다 보이고, 누르면 아래 칸이 바뀐다(고른 장르는 기억).
- 모험 애니: **1. 작품 고르기**(6편 — 준비된 편만 열림) → **2. 에피소드 고르기**(그 편의 6개, 카드를 눌러 고르거나 «▶ 바로 더빙») → 오른쪽 sticky **3. 누가 연기할까요**(고른 에피소드 요약 + 시작 버튼).
- 매니페스트의 «장면» 6개를 화면에서는 «에피소드» 로 부른다(편 = `index.json` 의 dub-00N). 진행 문구 «장면 N» → «에피소드 N».
- 키키와 토토: 10편을 고르면 오른쪽에 큰 그림·레벨·출연, **«▶ 이 에피소드 더빙 시작» = `/ai-dubbing-studio.html?ep=<id>`** — 재생 로직을 복제하지 않고 기존 스튜디오로 보낸다. 스튜디오는 `?ep=` 를 읽어 그 편으로 시작(모르는 값은 무시).
- 폰(≤860px): 출연 설정은 **아래 고정 바 + 바텀시트**, 시트를 여는 동안 공용 «메뉴» 손잡이를 숨김(시트 글자를 덮었음).
- URL `?g=kt|adv` 로 장르를 열 수 있음(`?ep=` 는 모험 쪽 딥링크라 모험이 이김).

## 3. 검토했다가 버린 것
- **키키와 토토를 이 화면 안에서 재생**: 스튜디오가 이미 역할 고르기·연습/실전·녹화를 갖고 있어 복제하면 정본이 두 벌이 된다 → 고르기만 하고 딥링크.
- **장르를 탭으로 숨기기**(시안 D): 「두 장르가 모두 잘 보이게」라는 지시와 반대.
- 목록 데이터(KT 10편)를 스튜디오 HTML 에서 런타임으로 읽기: 다른 문서를 가져와 파싱해야 해 무겁다 → 사본을 두고 **하니스 ⑩ 이 두 곳을 대조**(한쪽만 고치면 FAIL).

## 4. 밟은 함정
