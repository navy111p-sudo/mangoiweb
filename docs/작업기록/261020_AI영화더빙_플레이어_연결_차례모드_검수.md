## 두 가지 재생 방식 (장면마다 정본이 정함)
- **차례 모드** — 대사 시각을 아직 믿을 수 없을 때(지금). 영상은 소리 없이 배경, 원어민 = 임시 AI 목소리(TTS), 학생 차례 = 마이크.
- **동기 모드** — `timing:"synced"` + 시각이 전부 맞고 + 캐릭터별 음성 파일이 전원 있을 때. 학생 캐릭터 음성만 0.

## 버린 방법
- **`episode.json` 시각을 그대로 믿기** — 40초 장면 기준(6초 간격 균일)인데 영상은 15초라, 쓰면 15초 뒤 대사 4줄이 영상 밖. 지어내 맞추지 않고 차례 모드로.
- **영상 원본 소리 켜기** — 받아쓰기로 확인하니 생성기가 대본에 없는 목소리를 넣어 둠(장면 1·3·6, 추가 7·8·10·11·12·13(한국어)·16). 기본 끔, `videoAudio:"clean"` 만 켬.
- **영상을 저장소에 커밋** — 공개 저장소라 승인 필요. CloudFront 주소를 그대로 참조(CORS `*` 확인 — 완성 영상에 그려짐).
- **완성 영상을 서버에 저장** — 새 API 는 `src/index.ts`(공동 금지구역) 승인이 필요. 이번엔 기기 저장(«저장» 내려받기)까지.
- **추가 영상 10개(7~16)를 장면에 붙이기** — 어느 장면 몇 번째인지 순서표가 없음. 추측으로 붙이지 않음(설명서 6-2 에 부탁).
