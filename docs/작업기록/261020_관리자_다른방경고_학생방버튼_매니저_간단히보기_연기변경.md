# 관리자 «서로 다른 방» 경고 띠에 학생 방 참관·입장 버튼 + 매니저 «간단히 보기»에도 연기·변경 버튼

- 날짜: 2026-10-20
- 작업자: Claude Code (요청: 사장님)
- 브랜치 / PR: `claude/student-room-observe-move-pill` / navy111p-sudo/mangoiweb#1689

## 1. 왜 했나

사장님이 직원 문의·제안 세 가지를 전달하셨습니다.

1. **문의:** 관리자 수업 관찰에 «관리자가 관찰 중에 보이는» 옵션이 있나?
   - 답변만 했고 코드는 바꾸지 않았습니다.
   - 이미 두 입구가 있습니다. 「👁 바로 참관」(보라색, 학생·강사에게 안 보임)과 「🚪 직접 입장(보임)」(주황색, 카메라 꺼짐으로 입장)입니다.
   - 관찰 화면 안에서 둘을 바꾸는 스위치는 없습니다. 실수로 마이크가 켜지는 사고를 막으려고 일부러 입구를 나눠 두었습니다(`js/vc-observe-guard.js`).
2. **제안:** 버그로 학생과 교사가 다른 방에 있을 때, 관찰자(교사)가 학생 방에 들어갈 곳이 있나?
   - 그동안 관리자 화면의 빨간 경고 띠(`_renderRoomMismatch`, 판정은 `src/room-mismatch.ts`)는 «학생은 X, 선생님은 Y» 라고 **말만** 했습니다. 버튼은 0개였습니다.
3. **문의:** 매니저 페이지 «오늘 수업» 에 모든 시간표에 이동 버튼이 없다.
   - 「📅 연기·변경 / Move」 버튼은 «자세히 보기» 에만 있었습니다.
   - 기본값인 «간단히 보기»(2026-10-07 사장님 지시)에서는 **모든 줄**에서 버튼이 빠져 있었습니다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **관제탑(monitor-wall)에도 버튼을 넣으려 했으나 #1687 이 먼저 같은 기능을 병합했습니다.**
  - rebase 충돌이 났고, 관제탑 파일은 main 쪽을 그대로 채택했습니다.
  - 참고로 첫 시도에서는 두 버튼을 넣자 관제탑 «HTML+JS 52KB 상한»(2026-09-14 사장님 확정)을 439바이트 넘었습니다.
- **«간단히 보기» 기본값을 «자세히» 로 바꾸는 방법은 버렸습니다.** «간단히» 가 기본인 것은 2026-10-07 사장님 지시입니다. 칸 하나만 더했습니다.
- **카페24 줄·매주 반복 줄에 버튼을 «억지로» 주는 방법도 버렸습니다.**
  - 카페24 줄은 `schedule_id` 가 없어 옮길 대상이 없습니다.
  - 매주 반복 행 하나는 «매주 전부» 를 뜻하므로, 옮기거나 취소하면 모든 주가 바뀝니다.
  - 지사·대리점 계정은 나누기 API 가 403 입니다.
  - 판정은 서버가 주는 `can_move` · `can_split` 그대로입니다.
- **onclick 문자열은 쓰지 않았습니다.** 방 번호에 따옴표가 섞이면 깨집니다(261019 작은따옴표 수리와 같은 함정). 그래서 `data-*` + 위임으로 했습니다.
- **보조 함수 `_mismatchBtns` 를 `_renderRoomMismatch` 안쪽에 둔 이유:** `room_mismatch_harness` 가 그 함수 본문만 오려 내 실행합니다. 바깥에 두면 ReferenceError 가 try/catch 에 삼켜져 띠가 통째로 안 그려집니다(실제로 FAIL 2건이 났습니다).

## 5. 남은 것 / 주의할 것

- 경고 띠는 «학생이 예약 아닌 방에 있고, 예약방에는 누군가 있을 때» 만 뜹니다(`room-mismatch.ts`). 학생 혼자 다른 방에 있고 예약방이 비어 있으면 띠도 버튼도 없습니다.
- 학생을 예약방으로 **옮기는** 기능은 여전히 없습니다. 관찰자가 학생 방으로 «들어가는» 것뿐입니다.
- «간단히 보기» 의 매주 반복 줄에는 칩이 없습니다(빈 칸). 캘린더로 가는 «📅 매주 반복 — 캘린더에서» 는 «자세히 보기» 에만 있습니다.
