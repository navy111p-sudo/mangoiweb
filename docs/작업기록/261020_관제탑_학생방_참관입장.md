# 261020 수업 관제탑 — «서로 다른 방» 경고에 학생 방 참관·입장 버튼

## 문제 / Problem
- KO: 「🚨 지금 손봐야 할 방」의 «🔀 서로 다른 방» 경고 줄에는 **선생님 예약방** 참관 버튼만 있었다. 학생이 실제로 앉아 있는 방(`student_room`)으로 들어갈 길이 없었다.
- EN: The "different rooms" warning line only offered Observe for the teacher's booked room. There was no way to reach the room the student was actually in.

## 해결 / Fix (`cloudflare-deploy/public/js/monitor-wall.js` — `renderUrgent`)
- 경고 줄 = `선생님 방 [👁 참관]` + `학생 방 [👁 참관] [🚪 입장(보임)]`.
  - 참관 정원 규칙(차면 disabled · 2명 이상이면 🎧 소리만)은 학생 방 버튼에도 그대로(`ob()` 공용).
  - 입장은 기존 `enterRoom()`(확인창 · 카메라 꺼짐 · 학생에게 보임) 그대로.
  - `student_room` 이 비면 학생 방 버튼을 그리지 않는다.
- `ob()` 는 이제 `</div>` 를 닫지 않는다 — 호출하는 쪽이 줄을 닫는다(학생 방 버튼을 같은 줄에 붙이기 위해).
- 서버(`src/room-mismatch.ts`)는 바꾸지 않았다 — 여전히 «알리기만» 한다.
- 학생을 선생님 방으로 «모으는» 정식 길은 그대로 강사 포털 「🚪 오늘은 다른 방으로」.

  > ⛔ 'adminLang' 키를 읽거나 쓰지 말 것 — 그 키는 아무도 저장하지 않는 죽은 키인데 읽는 코드가 10곳 잠들어 있어,
