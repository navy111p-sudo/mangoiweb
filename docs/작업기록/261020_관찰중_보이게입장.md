# 수업 관찰 중 «🚪 보이게 입장» — 매니저가 학생·강사에게 보이면서 들어가는 길

- 날짜: 2026-10-20 (KST)
- 브랜치: `manager-join-visible`
- 제보: Google Doc «NEW TEACHER'S PAGE PROBLEM» 2026-10-19 1번 —
  “At manager's page, observe class option, is there an option where the manager can be seen during the observation?”
  + 제안: 버그로 학생과 강사가 서로 다른 방에 있을 때, 강사가 학생 방으로 들어갈 수 있는 길.

## 1. 왜 했나

- 수업 관찰(👁)은 **«투명 유령»** 설계입니다 — 인원수·입퇴장·로스터 어디에도 안 나오고
  카메라·마이크 버튼도 감춰집니다(`js/vc-observe-guard.js`). 그래서 관찰하다가
  «지금 들어가서 말을 걸어야겠다» 싶을 때 갈 길이 화면에 없었습니다.
- 실제 참가자로 들어가는 길(«직접 입장» `tcEnterClass`·`ghEnterRoom`)은 **관리자 큰 화면(`admin.html`)**
  에만 있었고, 매니저가 온종일 쓰는 `manager.html` 의 «지금 진행 중인 수업» 줄과
  관찰 화면(`admin/ghost-view.html`)에는 없었습니다.
  ⚠️ 처음에 「manager.html 에는 Observe 만 있다」고 보고했는데 **틀렸습니다** — 「오늘 수업」 표에는
  이미 `taJoin`(Join) 버튼이 있었습니다. «Join (visible)» 글자로만 찾다 놓쳤고, 같은 대화에서 정정했습니다.
- 제안(«다른 방에 있을 때 학생 방으로»)도 같은 버튼으로 풀립니다 — 학생이 있는 방 줄에서
  «보이게 입장» 을 누르면 그 방에 실제 참가자로 들어갑니다.

## 2. 무엇을 했나

| 자리 | 바뀐 것 |
|---|---|
| `admin/ghost-view.html` 머리줄 | 🚪 **보이게 입장** 버튼(주황 `#c2410c→#9a3412`, 흰 글자 대비 5.18) — 참관(보라)과 색을 가름 |
| `admin/ghost-view.html` 영상칸 | 🎥 라이브 화면 열기 아래 «🚪 학생에게 보이게 입장 (새 창)» |
| `admin/ghost-view.html` 수업 고르기 목록 | 줄마다 세 번째 버튼 «보이게 입장» (`ghdPickBtns`) — 고르기 화면에서는 머리줄 버튼을 감춤 |
| `manager.html` «지금 진행 중인 수업» | Observe 링크를 «👁 관찰(안 보임)», 옆에 «🚪 입장(보임)» — 두 버튼이 **보임/안 보임을 글자로** 말함 |
| `manager.html` 「오늘 수업」 | 기존 Join 라벨을 «🚪 입장(보임)» 으로 통일, 확인창에 «라이브 관찰 창을 먼저 닫으세요(소리가 울립니다)» 한 줄 |

- 입장 주소는 기존 «직접 입장» 과 같은 `/?vc_autojoin=1&vc_cam=off&vc_role=teacher&vc_room=<방>` —
  **카메라는 꺼진 채** 시작하고(트랙은 살려 둠 — 이 앱은 자동 재협상이 없어 나중에 켤 수 있어야 함),
  확인창이 «참관이 아니라 실제 참가자 · 학생·강사가 보고 듣습니다» 를 KO/EN 으로 먼저 말합니다.
- 새 창은 기존 `ghdOpenTab`(반환값을 쓰므로 `noopener` 를 기능 문자열에 안 넣는 정본)을 그대로 씁니다.

## 3. 검토했다가 버린 방법

- **관찰 상태에서 «보이기» 로 전환하는 스위치** — 관찰은 `handleJoinObserve`(`joined:false`, recvonly)라
  보이려면 방에 «다시» 들어가야 합니다. 같은 창에서 바꾸려면 `video-call-room.ts`(공동 금지구역)를
  고쳐야 하고, 새 창으로 실제 입장하는 길은 이미 검증된 경로라 그쪽을 택했습니다.
- **`/?observe=` 영상 화면(index.html)에도 버튼** — `index.html` 은 공동 금지구역이고
  `vc-observe-guard.js?v=12` 를 올려야 합니다. 이번에는 넣지 않았습니다(사람 승인 대기 — 아래 5).
- **아이콘 버튼에 `data-ko`/`data-en`** — 두 i18n 엔진이 `textContent` 를 갈아끼워 아이콘이 사라집니다.
  머리줄 버튼은 `data-ko-title`/`data-en-title` 만 달고 글자는 안쪽 `<span>` 에.
