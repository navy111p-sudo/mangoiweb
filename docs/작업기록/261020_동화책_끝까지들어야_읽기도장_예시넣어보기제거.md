# 영어 독서 동화책 — 끝까지 들어야 «읽고 듣기» 도장 · «예시 넣어 보기» 버튼 제거 (2026-10-20)

## 1. 왜 했나

사장님 제보 두 가지(`story-s1-01.html` 화면 사진과 함께).

1. «중간까지만 들어도 읽기 완료가 됩니다. 끝까지 읽으면 되게 해도 좋을 것 같습니다.»
2. «틀을 보고 학생들이 틀리면 AI 가 교정해 주니 예시 넣어 보기는 없어도 좋을 것 같습니다.
   예시를 넣고 그냥 완성하기를 누를 수가 있어 스스로 생각해서 쓰지 않을 수도 있을 것 같아요.»

### 잰 것

- ① 읽고 듣기 도장 규칙이 **«문장 5개를 눌러 들으면 도장»** 이었습니다(`if (Object.keys(heard).length >= 5) storyDone('read')`).
  게다가 «누른 순간» 셌기 때문에 소리를 끝까지 안 들어도 셌습니다.
- 1단계 글은 짧아서(가장 짧은 글 7문장) **5문장이면 절반이 조금 넘습니다** → «중간까지만 들어도 완료».
- ⑥ «예시 넣어 보기» 칩 3개(rain·cat·Mom 등)를 누르면 두 칸이 통째로 채워지고, 그대로 «완성하기» 가 됐습니다.

## 2. 무엇을 바꿨나

### ① 읽고 듣기 — «모든 문장을 끝까지» 들어야 도장

- 판정 정본은 페이지 안 `/* STORY-READ-START */ … /* STORY-READ-END */` 블록의 `makeReadTracker()` 하나입니다.
  - 문장마다 «끝까지 들었나» 를 기록하고, **모든 문장**을 들으면 도장.
  - «처음부터 듣기» 와 «문장 누르기» 를 **합쳐** 셉니다(앞 절반을 듣다 멈추고 나머지를 눌러 들어도 됨).
  - 소리를 시작할 때 번호(gen)를 받고, **멈추거나 다른 문장을 누르면 번호가 바뀌어** 그 전 소리는 «끝까지 들음» 으로 안 셉니다.
    크롬은 `cancel()` 할 때도 `onend` 를 보내므로 이 번호가 없으면 «멈춘 문장» 이 셈에 들어갑니다.
  - `SpeechSynthesisUtterance` 참조를 붙잡아 둡니다(`curUtter`) — 크롬은 참조 없는 소리 객체를 치워 `onend` 가 안 오는 일이 있습니다.
  - `stop()` 이 `playing=false` 를 **먼저** 내리고 멈춥니다(멈출 때 `onend` 가 곧바로 와도 다음 문장으로 안 넘어가게).
- 화면: ① 안내 문구를 «모든 문장을 끝까지 들으면 «읽고 듣기» 도장을 받아요» 로 바꾸고, 본문 위에 **«들은 문장 N / M»** 줄(`#readProg`)을 둡니다.
  다 들으면 «✅ 모든 문장을 끝까지 들었어요!», 이미 도장이 있으면 «✅ 도장은 이미 받았어요».
- 도장판 «처음부터 다시» 가 들은 문장 수도 0 으로 되돌립니다(`window.__storyReadReset`).
- 소리를 못 내는 브라우저는 예전처럼 «처음부터 듣기» 를 누르면 도장(그 경우 `say()` 가 곧바로 `onend` 를 부릅니다).

### ⑥ 바꿔 쓰기 — «예시 넣어 보기» 버튼 줄 제거

- 칩 버튼 줄(`.ex-row`)과 클릭 처리, 칩 CSS 를 지웠습니다.
- 예시 문장은 **화면에 안 그리고** `var WRITE_EX = [...]` 목록에만 남겨, 철자 점검의 «아는 낱말»(`KIT_WORDS`)에만 씁니다
  (예시 낱말을 학생이 직접 쳐도 «철자 틀림» 으로 잡히지 않게).
- 한글 입력 안내 문구 «…예시를 눌러 보세요» → «…위의 틀을 참고해 보세요».
- **그대로 둔 것**: 두 칸의 회색 안내(placeholder, 예: `it will rain` / `the sky is dark`). 칸에 무엇을 쓰는지 알려 주는 «모양 안내» 라 남겼습니다.
  눌러서 채워지지는 않으므로 «그냥 완성하기» 는 안 됩니다. 이것도 빼거나 «내 생각(영어로)» 같은 말로 바꿀지는 사람이 정할 일입니다.

### 적용 범위

- 손으로 만든 4권(`story-birthday-cake`=틀 · `red-umbrella` · `robot-dance` · `treasure-map`)을 같은 스크립트로 고치고,
- 생성기 `scripts/ladder-storybooks/build.mjs` 를 맞춰 **176권을 다시 만들었습니다**(`node scripts/ladder-storybooks/build.mjs` → 만든 페이지 176개).
  다시 돌려도 변경 0건(재현됨)을 확인했습니다.
- `SCHEMA.md` 의 `chips` 설명에 «2026-10-20 부터 버튼으로 안 그림(철자 점검·첫 칸 placeholder 에만 씀)» 을 적었습니다.

## 3. 검토했다가 버린 것

- **«처음부터 듣기» 를 끝까지 한 번 들어야만 도장**: 문장을 하나씩 눌러 끝까지 다 들은 학생은 못 받게 됩니다. 합쳐 세는 쪽이 공정합니다.
- **«문장 수의 80%」 같은 비율**: 다시 «중간까지만» 이 됩니다. 사장님 말씀이 «끝까지» 라 전부로 했습니다.
- **문장을 «누른 순간» 세기(예전 방식)**: 누르고 곧바로 다음 문장을 누르면 소리를 안 들어도 셉니다 → `onend`(끝까지) 로만 셉니다.
- **예시 칩을 남기고 «완성하기» 에서 예시와 같으면 거절**: 학생이 예시 낱말 하나만 바꿔도 통과하고, 거절 이유를 설명하기 어렵습니다. 버튼을 빼는 쪽이 지시에 맞습니다.
