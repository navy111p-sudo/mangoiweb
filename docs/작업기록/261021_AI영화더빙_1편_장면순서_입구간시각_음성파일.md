## 3. 검토했다가 버린 것

- **대본을 그대로 두고 시각만 붙이기** → 옛 대사 일부가 «다른 장면의 행동» 을 말하고 있었습니다(옛 대본 대조: 4장면의 «Hop, hop! Follow me!» 는 5장면 클립(5)의 행동이고, 3장면 끝 «Shh! A big friend is coming.» 뒤에 긴목 공룡(클립 4)이 바로 나왔습니다). 시각만 맞추면 «입은 맞는데 말이 딴소리» 가 됩니다.
- **6장면 마지막 줄을 아이 셋 중 하나에게** → 영상 속에서 입을 움직이는 것은 남자 선생님이라 그 아이 목소리가 선생님 입에서 나옵니다(5편 사고와 같은 모양). 손님으로 둠.
- **클립을 다시 생성하기(유료)** → 순서만 바꿔도 이야기가 이어져서 크레딧을 안 썼습니다. 아이 얼굴이 클립마다 조금씩 다른 것은 2026-10-19 결정대로 그대로.
- **TTS 캐시(`r2-cache`)로 나온 음성 그대로 쓰기** → 캐시 적중은 «어느 엔진이 만들었는지» 를 안 알려 줘 목소리가 바뀌었을 수 있습니다. 네 줄(2장면 3·6줄, 5장면 3·6줄)은 문장을 살짝 바꿔 새로 받아 Aura-2 를 확인했습니다. 교장 선생님 줄만 `r2-cache` 인데, 같은 세션의 앞선 시험 호출이 `aura-2 / zeus` 로 만든 것입니다.

## 4. 확인한 방법

- 자동: `node test-harness/ai_dubbing_harness.mjs` → **PASS 499 / FAIL 0**(main 병합 뒤). 매니페스트를 정본(`js/ai-dubbing-core.js`)으로 읽으면 6장면 전부 `synced/stems`, 문제 0.
- 새 검사 변이 6종 전부 **실제 FAIL**: 시각 provisional(⑥-9·⑥-e1) · 4장면 화자 맞바꿈(⑥-e3) · 5장면 `?v=2` 빼기(⑥-e6) · 교장 선생님 음성 파일 빼기(⑥-19b·⑥-e1·⑥-e4) · 안내에 «임시»(⑥-e5) · 장면 길이 늘리기(⑥-e7). 매니페스트는 원본으로 되돌려 대조함(`cmp` 동일).
- 음성 파일 19개를 디코딩해 «다른 캐릭터 구간에 말소리가 새지 않는가(−0.08/+0.12초)» · «말소리가 시작 시각 ±0.06초에 붙는가» · «최고 −1.4dBFS 이하» 를 전부 재서 **문제 0건**(시작 차이 ±0.02초 안).
- 회귀: `node test-harness/run.mjs --fast` 를 이 브랜치와 `origin/main` 사본(`git worktree`)에서 같은 방식으로 돌려 FAIL 목록을 이름으로 대조(PR 본문에 결과).
