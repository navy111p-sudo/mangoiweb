# A.i영화더빙 «먼저 보기» — 아이폰 무음 · 멈춰도 울리던 효과음 (Codex 리뷰 수리)

- 날짜: 2026-10-21
- 브랜치: `ai-dubbing-watch-ios-pause`
- 앞 작업: [261021_AI영화더빙_먼저보기_배경음악_효과음.md](261021_AI영화더빙_먼저보기_배경음악_효과음.md) (PR #1695·#1696, 배포됨)

## 1. 왜 했나

#1695 병합 뒤 Codex 자동 리뷰가 두 가지를 지적했고, 코드를 읽어 둘 다 사실로 확인했습니다.

| | 지적 | 확인한 것 |
|---|---|---|
| P1 | 아이폰에서 «먼저 보기» 원어민 목소리가 안 날 수 있다 | 감상은 제목 카드(2.2초)·음성 받기가 끝난 **뒤** 에 `new Audio()` 를 만들어 틉니다. 아이폰 사파리는 소리 나는 요소 **마다** «사람이 누른 그 순간» 에 재생 허락을 받아야 해서, 그때 만든 요소는 조용히 막힙니다(에러 없음 · 화면은 자막만 흐름). 데스크톱 크롬은 한 번 누르면 페이지 전체가 풀려 재현되지 않습니다. |
| P2 | 멈춤을 눌러도 효과음이 끝까지 울린다 | `pause()` 는 박자 타이머·음악 버스만 멈추고, 이미 울리기 시작한 효과음(파도·천둥·우르릉은 몇 초짜리)은 붙잡고 있지 않아 끊을 방법이 없었습니다. 「💥 효과음 끄기」·치우기(dispose)도 같았습니다. |

## 2. 무엇을 바꿨나

| 파일 | 바꾼 것 |
|---|---|
| `js/ai-dubbing-sound.js` (`?v=2`) | 울리는 효과음 gain 을 `live` 에 붙잡아 두고 `cutSfx()` 가 0.06초에 걸쳐 0 으로 줄인 뒤 0.12초 뒤 연결을 끊습니다. `pause()`·효과음 끄기(`setEnabled(…, false)`)·`dispose()` 가 부릅니다. 이어 가기(resume)는 되살리지 않습니다(한 번짜리 소리). `state().sfxLive` 로 셀 수 있습니다. |
| `js/ai-dubbing.js` (`?v=6`) | 🍎 **감상용 소리 요소 묶음**(`W_POOL`, 6개). «보기»·«모든 작품 이어 보기» 를 누른 **그 순간(클릭 처리 안, 동기)** 에 무음 WAV 로 한 번 틀어 허락받아 두고(`primeWatchAudio`), 진행기는 `kit.Audio` 로 그것을 빌려 쓰고(`takeWatchAudio`) 다 쓰면 돌려줍니다(`releaseWatchAudio`). 다 쓰고 있으면 새로 만듭니다(= 예전과 같음). 기기 목소리 폴백(`speechSynthesis`)도 같은 순간 볼륨 0 으로 한 번 말해 둡니다. `routeEl` 은 요소마다 `MediaElementSource` 를 **한 번만** 만들고 `el.__dubSrc` 에 붙여 다시 잇습니다(같은 요소에 두 번 만들면 브라우저가 던집니다). |
| `js/ai-dubbing-watch.js` (`?v=2`) | 다 쓴 소리 요소를 `kit.release(el)` 로 돌려줍니다 — **멈추고(`stopEl`) 섞개에서 끊은(`route.cut`) 뒤에만**. 차례 장면(`playClip`)·동기 장면(`dropTracks`, 두 번 돌려주지 않게 `tracks = []`) 둘 다. |
| `ai-dubbing.html` | 위 세 파일 `?v=` 올림 · `test-harness/asset-versions.json` 기록. |

## 3. 검토했다가 버린 것

- **`playbackRate`·`muted` 로 미리 틀어 두기** → 아이폰은 «음소거로 튼 것» 을 «소리 허락» 으로 치지 않습니다. 실제로 소리를 내야 하므로 **무음 WAV 를 소리 켠 채** 틉니다.
- **감상 전에 요소를 «필요한 만큼» 만들어 두기** → 장면마다 필요한 수가 다르고(동기 장면 = 배경음악 + 캐릭터 수), 36장면을 미리 만들면 메모리만 씁니다. 동시에 필요한 최대(배경음악 1 + 캐릭터 4~5)만큼인 **6개를 돌려 씁니다.**
- **`primeWatchAudio` 를 `startWatch` 하나에만 두기** → «모든 작품 이어 보기» 는 편을 다 받은(`Promise.all`) **뒤** 에 `startWatch` 를 부르므로 그때는 이미 클릭 밖입니다. `watchAll` 이 받기 **전** 에 따로 부릅니다.
- **허락 거절(AbortError)도 «다시 시도» 로 되돌리기** → 빌려 간 뒤 새 `src` 를 넣으면 앞선 무음 재생이 `AbortError` 로 끝나는데, 그건 허락과 무관합니다. **`NotAllowedError` 만** 다음 클릭에 다시 시도합니다.
- **효과음을 뚝 끊기** → «딱» 소리가 납니다. 0.06초 램프 후 끊습니다.

## 5. ⚠️ 사람이 봐야 할 것 · 남은 것

- **진짜 아이폰에서 한 번** — 이 환경에는 WebKit 이 없어(크로미움뿐) 아이폰의 «요소마다 허락» 정책을 재현할 수 없습니다. 위 검사는 «누른 순간 허락받고 그 요소를 빌려 쓴다» 는 **배선** 까지입니다. 아이폰 사파리로 `/ai-dubbing.html` → 장면의 «👀 보기» 를 눌러 원어민 목소리가 나는지 봐 주세요.
- **더빙(따라 말하기) 모드에도 같은 위험이 남아 있습니다** — `playUrl`·동기 장면 `addTrack` 도 비동기 뒤에 `new Audio()` 를 만듭니다. 이번 수리는 Codex 가 짚은 «먼저 보기» 만 고쳤고, 같은 방식으로 더빙 모드도 고칠 수 있습니다(사람이 정할 일).
- 소리 크기·효과음이 끊기는 느낌은 사람이 들어야 확정입니다(오디오 디코더 없음).
