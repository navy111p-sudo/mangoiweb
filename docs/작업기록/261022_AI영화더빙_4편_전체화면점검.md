# A.i영화더빙 4편 전체 화면 재점검

## 범위와 판단

6장면, 60개 대사를 화자 표시와 대조했다. 각 대사 안의 3개 시점과 전체 타임라인의 0.5초 간격 표본을 확인한 뒤, 문제 구간은 추가 프레임으로 다시 확인했다. 프레임 표본 검사이므로 모든 프레임의 무결성을 보증하는 자동 판정은 아니다.

이전 #1706의 카이·마야 화자 화면과 사다리 두 팔 수정은 유지한다. 이번에는 다른 인물이 말하는 것으로 보이거나 지정 화자의 입 움직임이 약한 13개 대사를 명확한 화자 클로즈업으로 보완했다. 배·등대·지도·나침반만 보여주는 의도된 화면 밖 대사는 유지한다.

첫 장면 3.500–8.125초에서 엠마가 단발머리와 다른 옷의 인물로 바뀌는 연속성 오류를 같은 긴 금발·분홍 스웨터의 엠마가 듣는 컷으로 고쳤다. 이후 엠마의 첫 대사는 원래 배 화면을 유지한다. 긴 무음 입력으로 제작한 첫 말하기 컷이 실제로는 입을 움직이지 않아, 그 말하기 결과는 채택하지 않았다.

## 배포 및 검증

- 30개 MP3, 60개 대사 문자열·화자·시각, 장면 길이를 그대로 둔다. 생성기 오디오는 배포 영상에서 제거한다.
- 6개 MP4 모두 1280×720, 24fps, 960프레임, 정확히 40초, 오디오 스트림 없음, 파일당 25MiB 미만을 ffprobe로 확인했다.
- 교체 구간 밖의 원본 대비 SSIM은 0.99206–0.99545다(재인코딩 차이).
- 영상 URL: 1–3장면은 ?v=2, 4–6장면은 ?v=3으로 갱신해 이전 캐시를 분리한다.
- Windows 더빙 하니스는 기존 기준과 같은 PASS 487 / FAIL 12다. 기존 줄바꿈·가짜 시계 환경 차이가 있어 Linux PR CI의 배포 게이트를 병합 조건으로 확인한다.
- 음성 분석 자료는 로컬에 보관하고 공개 저장소에 올리지 않는다. 실제 청감의 자연스러움은 사람이 최종 확인해야 한다.
