# A.i영화더빙 4편: 실제 화자가 말하는 화면과 사다리 팔 수정

- 요청: 모모가 어른 목소리에서 아이 목소리로 바뀌어 보이는 세 구간, 카이의 팔 세 개.
- 이전 PR #1702의 음높이 보정과 별개의 문제다. 음높이만으로 이번 제보를 해결했다고 판단하면 안 된다.

## 확인한 원인

| 제보 구간 | 대본과 실제 음원 | 모모 트랙 RMS |
|---|---|---|
| s4-l4, 12.887–14.842초 | 카이: You were rescuing the lost sailors! | 디지털 무음 |
| s4-l9, 32.442–34.032초 | 카이: Let us bring everyone home. | 디지털 무음 |
| s6-l3, 6.299–8.369초 | 마야: We should always listen first. | 디지털 무음 |

각 대사 창에서 다섯 캐릭터 MP3를 16kHz float PCM으로 풀어 RMS를 측정했다. 지정 화자만 -18.0 / -18.6 / -17.4dBFS, 나머지는 정확히 0인 PCM이다. 원본 MP4에는 오디오 스트림 자체가 없다. 따라서 이번 세 구간의 아이 목소리는 모모 음원으로 바뀐 것이 아니라 다른 인물의 정상 대사이며, 잘못된 인물의 입 움직임과 화면 구성이 혼동을 만든다. 화면 자막만 보고 원인을 단정하지 않고 음원과 영상 둘 다 확인했다.

## 수정 범위

- 4장면 12.5–15.5초, 32–35초: 카이가 혼자 말하는 클로즈업.
- 6장면 6–9초: 마야가 말하는 클로즈업. 모모의 입이 보이지 않는다.
- 각 클로즈업은 원본 화자 MP3의 같은 3초 구간을 입력한 Wan 2.7 영상이다. 배포 MP4에서는 생성기 오디오를 모두 버리고 기존 캐릭터 MP3를 그대로 재생한다.
- 5장면 4.5–9초: ImageGen으로 추가 팔을 제거한 정확한 기준 프레임을 만든 뒤 Wan 2.7로 작은 호흡 움직임만 있는 컷을 제작했다. 화면 왼쪽 아래 손과 오른쪽 위 손만 남긴다. 원본 정상 두 팔 프레임을 참조한 Genjutsu 첫 시도는 추가 팔이 남아 폐기했다.
- 모모 및 다른 캐릭터의 MP3, 대본, 화자, 대사 시각을 변경하지 않는다.
- 수정 MP4는 1280×720, 24fps, 960프레임, 오디오 스트림 없이 정확히 40초다.
- 영상 URL은 scene-4/5/6.mp4?v=2로 갱신한다.

## 검증

- 실제 결과 프레임 확인: 세 대사 컷의 화자와 움직이는 입을 확인했다. 팔 재제작본은 0–4.9초 12개 시점에서 손 두 개와 연속된 두 팔을 확인했다. 첫 Genjutsu 결과는 손이 세 개라 배포하지 않는다.
- 4·6장면 수정 구간 외 SSIM은 각각 0.99380·0.99345(재인코딩 차이).
- Windows 회귀 검사는 줄바꿈을 LF로 읽은 뒤 PASS 497 / FAIL 2. 두 실패는 수정하지 않은 가짜 시계의 재개 시각 검사와 그 전제 검사다. PR의 Linux CI를 최종 배포 게이트로 확인한다.
- 실제 청감의 자연스러움은 사람이 최종 확인해야 한다.
