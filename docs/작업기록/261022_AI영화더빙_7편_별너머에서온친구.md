# A.i영화더빙 7편 — 별 너머에서 온 친구

소녀 우주비행사 루나가 고장 난 우주선을 밖에서 수리하다 지오의 UFO를 만나고, 함께 엔진을 고쳐 지구로 귀환하는 작품을 추가했습니다. 가족사진을 보고 버티는 루나와 마지막 엄마 노라와의 재회를 연결해 감정선을 만들었습니다.

- 6개 약 1분 에피소드, 총 약 6분. 움직이는 3D 장면에 가족사진·손·재회의 이미지 삽입 숏과 카메라 움직임을 더했습니다.
- 영어 연습 36문장, 문장당 3~8단어. 학생 역할은 루나·노바·지오이고, 엄마 노라는 마지막 인사를 하는 손님 역입니다.
- 생성된 원본 영어 목소리를 유지하고 영상과 함께 편집했습니다. 원본에 있던 불필요한 말과 과도한 멈춤을 편집하고, 실제로 마지막 인사를 하는 화면 속 여성을 노라로 배정했습니다.
- 역할별 음성 19개와 대사 없는 원작 우주 분위기 음악 6개를 따로 제공합니다. 영상 자체는 무음으로 재생하므로 학생 역할 음소거가 원본 음성으로 새지 않습니다. 효과음은 기존 더빙 엔진의 신호를 사용합니다.
- 기존 먼저 보기, 6개 이어 보기, 역할 선택, 따라 말하기, 역할 더빙, 평가·녹음·완성 영상 흐름은 기존 엔진을 그대로 사용합니다. 작품 수 표시와 목록을 7로 업데이트했습니다.

## 파일과 연동

- `public/data/dubbing/dub-007.json`: final / synced. 6개 장면은 후속 검수에서 각각 61초이고 실제 편집에 맞춘 대사 시각과 모든 발화자의 음성 파일을 포함합니다.
- `public/media/dubbing/dub-007/`: 6개 MP4, 장면 포스터, 인물별 MP3, 배경음악 MP3. 모든 파일은 25MiB 미만입니다.
- 주소: `/ai-dubbing.html?ep=dub-007`.
- 노라가 있는 마지막 장면은 기존 손님 배역 규칙을 적용합니다. 노라는 선택하지 않고 원래 목소리로 들려줍니다.

## 검증

- `node test-harness/ai_dubbing_harness.mjs`: PASS 525 / FAIL 0. 기존 6편 기준선은 PASS 499 / FAIL 0입니다.
- 원어민 음성 36문장을 분리한 최종 역할 파일에서 다시 ASR 대조했습니다. 36/36 문장이 단어열 유사도 0.8 이상이며, 역할별 발화 구간 밖의 PCM 최대값은 0입니다. ASR만으로 입모양의 모든 음소가 완벽하다고 주장하지 않습니다.
- 브라우저에서 7편 선택, 이어 보기 진행, 3인 역할 선택 시 루나·노바·지오만 음소거되고 손님 노라가 유지되는 표시를 확인했습니다. 실제 학생의 마이크 음성과 유료 평가 API는 시험 호출하지 않았습니다.
- Windows 체크아웃의 JS/HTML 줄바꿈을 검사 실행 중 LF로 정규화해 문자열 변이 앵커를 확인했습니다. 더빙 엔진 JS의 내용 변경은 포함하지 않습니다.
- 전체 fast 회귀와 배포 상태는 PR/배포 실행 결과를 확인합니다.
