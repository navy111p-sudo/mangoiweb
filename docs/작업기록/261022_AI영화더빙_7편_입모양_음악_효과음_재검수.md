# 7편 전편 재검수 — 화자 화면·음악·효과음

원어민 음성이 나오는 동안 다른 인물이 입을 움직이거나, 정작 화자의 얼굴이 보이지 않는 부분을 보정했습니다. 장면 끝 효과음이 잘리고 마지막 말 직후 전환되는 부분도 함께 수정했습니다. 기존 더빙 엔진의 동작과 다른 작품은 변경하지 않습니다.

- 대사 장면 6개를 원래 분리 음성을 참조한 Wan 2.7 영상으로 재생성했습니다. `s1-l1`, `s4-l1`, `s4-l5`, `s5-l3`, `s6-l1`, `s6-l5`이며, 마지막 지오 인사는 기존 착륙장과 캐릭터를 참조한 Nano Banana 2.1 기준 이미지를 사용합니다.
- 새 영상의 원어민 음성과 기존 음성의 파형 상관계수는 0.999006~0.999911, 교차상관 시간 차이는 6개 모두 0초입니다. 앱에는 기존 분리 음성을 유지하고 영상만 동일 시계에 합성했습니다. 영상 컷은 24fps의 한 프레임 범위에서 원래 시각에 배치합니다.
- 노바의 대사에서는 홀로그램·계기·우주선 구도를 사용하고, 인물 대사는 화자 중심으로 재구성해 듣는 인물의 과도한 입 움직임을 줄였습니다. 이는 원본 전체의 모든 음소를 새로 합성했다는 의미는 아닙니다. 전편 타임라인과 36문장의 시작·중간·끝을 프레임으로 대조했습니다.
- 외부 BGM 파일은 합성 음악용 duck 버스를 지나지 않습니다. 7편 BGM 파일 자체에 대사 전 0.18초 하강·대사 후 0.75초 회복의 부드러운 음량 감소를 넣었습니다. 학생 차례에도 같은 자리를 비웁니다. 다른 작품의 소리 엔진은 변경하지 않습니다.
- 효과음은 장면 동작 시각으로 지정했습니다. 우주선 접근·문 열림·불꽃·전력 복구·포옹에 맞추고, 마지막 0.6초에 효과음을 걸던 신호는 제거했습니다. 감상용 MP4도 앱의 동일한 효과음 레시피를 오프라인 렌더링해 사용합니다.
- 각 장면 끝에 1초의 여유를 추가해 에피소드당 61초, 총 약 6분 6초입니다. 자막 파일도 누적 길이에 맞게 갱신했습니다. 미디어 URL의 `?v=2`로 이전 캐시를 구분합니다.

## 검증

- 더빙 회귀 하니스: PASS 525 / FAIL 0. Windows 변이 문자열 검사를 위해 실행 중 JS/HTML을 LF로 정규화했으며, 엔진 파일의 변경은 커밋하지 않습니다.
- 최종 역할 음성 ASR 대조: 36/36 문장 유사도 0.8 이상, 역할별 발화 구간 밖 PCM 최대값 0. 재인코딩 후 기존 음성과의 지연은 1ms 이내입니다.
- 디코딩한 음성의 활동 샘플에서 대사/음악 RMS 차이는 최소 11.97dB입니다. 효과음도 대사를 덮는 수준으로 추가되지 않았으며 믹스 피크를 제한했습니다.
- MP4 6개는 각각 1,464프레임/61초이고 모든 업로드 파일은 25MiB 미만입니다.
- 실제 학생 마이크 및 유료 발음 평가 API는 검증용으로 호출하지 않았습니다. CI·배포·운영 브라우저 검증 결과는 해당 PR 및 최종 보고에서 확인합니다.

## 제작 비용

승인된 Higgsfield 크레딧으로 Wan 2.7 5초 영상 6개(45크레딧), Nano Banana 2.1 기준 이미지 1개(1.5크레딧)를 사용했습니다. 합계 46.5크레딧입니다. 생성 결과는 중복 제출하지 않았습니다.
