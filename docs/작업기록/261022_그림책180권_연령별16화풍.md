# 그림책 180권: 연령별 16가지 화풍

180권의 표지 180장과 본문 장면 360장을 교체했다. 원래 Claude 작업에서 생성한 표지는 복구하고, 본문 장면은 각 권의 표지를 인물 참고 그림으로 사용했다. 참고 그림의 구도를 복제하지 않도록 카메라 각도·거리·배경 배치를 새롭게 지정했다.

화풍 정본은 `scripts/ladder-storybooks/styles.mjs`다. 3D 애니메이션, 일본 애니메이션, 고전 동화 애니메이션(사용자가 요청한 디즈니풍), 클레이, 펠트, 크레용, 만화책, 빈티지, 민화, 픽셀, 웹툰, 굵은 선 카툰, 종이 공예, 실사, 잡지 일러스트, 브릭 블록의 16종을 사용한다. 특정 기존 캐릭터를 쓰지 않는다.

- 1단계: 6~9세, 둥글고 귀여운 비율과 밝은 색.
- 2단계: 10~12세, 역동적인 장면과 더 풍부한 디테일.
- 3~4단계: 실제에 가까운 비율과 성숙한 표현. 클레이·펠트·크레용·고전 동화 애니메이션은 배정하지 않는다.
- 브릭 블록은 s1-31, s2-05, s2-13에 적용했다.

권별 `img.style`이 생성 프롬프트, 그림책의 한/영 화풍 표시, 독서 목록 상세 화면의 화풍 표시를 함께 결정한다. 예전의 단계별 실사 여부로 설명문을 정하던 동작을 제거했다. 표지와 장면 URL의 버전을 올려 이전 이미지 캐시를 피한다. 생성기는 Windows CRLF 템플릿도 읽을 수 있다.

`scripts/ladder-storybooks/image-manifest.json`에는 최종 540장의 생성 작업 ID, 이미지 버전, WebP SHA-256을 보관했다. 원본 생성 결과가 다시 필요할 때 해당 작업 ID로 조회한다. 모델은 Nano Banana 2.1, 배포 파일은 1024×688 WebP다.

검수에서 초기 장면 6장이 다른 책 결과에 연결된 문제를 발견해 해당 6장을 새로 생성했다. 강아지를 안는 장면도 동작이 분명하도록 보완했다. 장면 360장을 묶음 시트로 확인했고, 새 브릭 표지 3장을 별도로 확인했다.

검사: 데이터 180/180, 독서 사다리 139/0, 그림책 6769/0(249266 조합), 정적 자산 버전 277/0. 화풍 목록과 각 권의 일치, 한/영 화풍명, 청소년 단계 유아 화풍 거부, 그림 URL 버전 일치 검사도 포함한다. 전체 배포 게이트는 PR CI에서 확인한다.
