# 그림책 표지를 화풍별로 둘러보기

`/story-cover-gallery.html`에서 영어 그림책 180권의 표지를 16가지 화풍별로 볼 수 있다. 처음에는 모든 화풍을 펼치고, 선택 상자에서 한 화풍만 골라 볼 수 있다. 각 표지에는 책 번호·단계·한글/영어 제목을 표시하고 그림책 페이지로 연결한다. 영어 독서 화면 상단에 «표지 갤러리» 입구를 추가했다.

갤러리는 `scripts/ladder-storybooks/gallery.mjs`가 기존 책 데이터·화풍 정본·표지 버전을 읽어 생성한다. `node scripts/ladder-storybooks/build.mjs`를 실행하면 그림책과 함께 갱신된다. 기존 표지를 지연 로딩하며, JavaScript가 없어도 180권 표지와 링크는 HTML에 남는다. 언어 설정은 기존 그림책과 같은 `story_lang`을 사용한다.

검증: 180권의 중복·누락, 16가지 화풍 선택, 이미지 버전과 책 링크, 언어 전환 후 선택 유지, 저장소 접근 불가 상황을 자동 검사했다. 기존 독서·그림책 검사도 통과했다. 로컬 브라우저에서 전체 배치, 고전 동화 애니메이션 8권 선택 및 영어 전환을 확인했다.
