# 연습 더빙 — 말하기 완료를 눌러 다음 차례 진행

문제: 동기 영상의 정해진 대사 시간이 끝나면 학생이 아직 말하는 중이어도 상대 목소리가 시작됐습니다.

연습 모드에서는 학생 차례에 영상과 모든 원본 음성·BGM 파일 시계를 함께 정지하고 마이크와 완성 영상 녹화는 계속합니다. ‘말하기 완료’만 다음 차례로 이어집니다. 안내 시간은 10초부터 줄어들고 ‘시간 더 주기 +5초’로 늘립니다. 0초·침묵으로 자동 종료하지 않습니다. 학생 차례의 넘어가기 버튼은 비활성화합니다. 발표 모드는 원래 동기 시계를 유지합니다. 비동기 차례형 영상도 연습일 때 수동 완료를 기다립니다.

완성 영상은 녹화의 실제 시간축에 학생 목소리와 그 화자의 정지 장면·자막을 함께 담습니다. 완료 후 사용하지 않은 원래 학생 대사 구간을 건너뛰어 상대 목소리가 그 뒤 장면부터 이어집니다. 학생 발화가 길어지면 완성 영상도 길어집니다. 새 목소리에 맞춰 입모양을 재합성하는 기능은 아닙니다.

검증:
- 실제 플레이어 함수 회귀: 0초가 돼도 대기, +5초, 완료·중단 정리, 발표 모드 원래 동작 통과.
- 더빙 전체 하니스 PASS 510 / FAIL 0 (Windows CRLF 변이 앵커는 검사 중 LF로 정규화 후 원상복원).
- 격리 Chrome + 운영 EP1 원본 영상·음성 + 시험 마이크로 실제 녹화: 14개 검사 통과. 루나 두 차례를 각각 12초 유지해도 영상·원어민 트랙 정지 및 마이크/MediaRecorder recording 유지. 완료 후 소스 음성·영상 시각 차이 0.3초 미만.
- 생성된 78.42초 VP8/Opus 영상 재생·다운로드 성공. 파일 디코딩으로 두 학생 대사 구간의 997Hz 시험 입력 검출. 대기 중 장면 픽셀 차이 평균 0.22, 다음 상대 장면 차이 63.83으로 대기 장면 유지와 완료 후 전환 확인.
- 추가 브라우저 검사 3개 통과: 발표 모드 자동 진행, 대기 중 중단 시 컨트롤 정리·재출발 없음, 페이지 오류 0.
- 시험 마이크와 로컬 전사/평가 대역 사용. 사용자 목소리나 운영 유료 평가 API를 호출한 시험이 아닙니다.
