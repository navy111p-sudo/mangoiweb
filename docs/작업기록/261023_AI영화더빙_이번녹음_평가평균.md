# 더빙 평가 평균을 이번 녹음으로 제한

다시 녹음하면 이전 시도의 대사가 `S.results`에 남아 평균과 결과 목록에 섞였습니다. 새 녹음 실행이 확정되는 `startRun`에서 결과 목록과 이전 채점 대기열을 초기화합니다. 이미 실행 중인 이전 채점은 끝나더라도 분리된 결과 객체만 갱신하므로 이번 목록에 들어오지 않습니다.

초기화는 에피소드 시작마다가 아니라 녹음 실행 시작에 한 번입니다. 따라서 처음부터 끝까지 이어서 더빙하면 그 실행의 모든 에피소드가 함께 집계됩니다. 실행 중 중복 시작 요청은 기존 가드가 막아 진행 중인 결과를 보존합니다. 완성 영상 목록은 유지합니다.

검증: 실제 startRun 함수를 실행하는 presentation harness에 이전 점수 제외, 늦은 이전 객체 갱신 격리, 중복 시작 시 현재 결과 보존, 이번 점수만 평균, 발표 모드 초기화 검사를 추가했습니다. JS 캐시 버전은 12로 갱신했습니다.

## 배포 도구 충돌 해결

Cloudflare 자동 빌드의 npm clean-install은 Wrangler 3.114.17의 선택적 peer 타입 ^4와 프로젝트 타입 ^5의 충돌(ERESOLVE)로 멈췄습니다. npm 11로 맞추는 시험도 실패해 임시 NPM_VERSION 변수는 삭제했습니다.

기존 GitHub 운영 배포는 이미 wranglerVersion 4를 사용합니다. 프로젝트 CLI도 4.152.0으로 맞추고 공식 peer 범위 ^5.20261019.1을 만족하는 Workers 타입 5.20261019.1을 정확한 버전으로 고정했습니다. lockfile도 함께 갱신했으며 force나 legacy-peer-deps는 사용하지 않았습니다.

검증: npm ci 정상 설치(취약점 0), npm run build(tsc) 통과, Wrangler 4.152.0의 기본·production deploy --dry-run 모두 성공. 기존 wrangler.toml의 도메인·바인딩·마이그레이션·compatibility_date는 수정하지 않았습니다. 더빙 startRun 회귀 검사 재통과.
