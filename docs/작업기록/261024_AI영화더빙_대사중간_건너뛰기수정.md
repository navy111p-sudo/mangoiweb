# AI 영화더빙: 대사 중간의 강제 위치 이동 방지

대상: `/ai-dubbing.html?ep=dub-007` (별 너머에서 온 친구), 2026-10-24.

## 재현과 수정

기존 clockFollower는 영상과 음성의 차이가 0.2초를 넘으면 음성 currentTime을 즉시 영상 시각으로 옮겼습니다. 실제 scene-1-luna.mp3의 첫 문장(10.24~13.68초)을 재생하면서 0.4초 지연을 주자, 11.000006초에서 11.400006초로 이동하는 seeking 이벤트가 발생했습니다. 말소리가 있는 구간의 샘플이 생략되는 경로입니다. 자연 재생에서는 항상 발생하는 현상이라고 단정하지 않습니다.

이제 감상·더빙·연습 재개 경로가 장면의 대사 시각을 공통 진행기에 전달합니다. 이동 경로가 대사 또는 앞뒤 0.12초와 겹치면 강제 이동 대신 최대 ±3%의 속도 보정을 사용합니다. 오차가 0.04초 이내가 되면 원래 속도로 복귀하고, 전체 이동 구간이 무음일 때 위치를 맞춥니다. 영상 버퍼링 때 음성을 함께 세우는 기존 처리는 유지합니다. HTML의 관련 JS 캐시 버전도 올렸습니다.

수정본의 실제 MP3 재현: 11.258098초에 0.4초 지연을 주었을 때 seeking 0회, playbackRate 1.03, 이후 11.440774초로 연속 진행했습니다.

## 범위와 한계

원본 영상·음성을 재생성하거나 재인코딩하지 않았습니다. 동시 검사 음성은 음소거 상태이며 디코딩·시간 연속성·프레임 진행 검사입니다. 원본 성우 발음이나 생성 영상의 입모양에 대한 청취·지각 품질 보증은 아닙니다.

전체 fast 러너는 esbuild 미설치와 다른 기능의 검사 실패가 있어 중단했습니다. 전체 저장소 게이트 통과를 주장하지 않습니다. 전수 문법 스캔도 완료하지 못했으며 변경 JS는 개별 검사했습니다.

수정본은 로컬 패치로 전달합니다. GitHub 업로드는 자동 승인 검토에서 원격 전송의 명시적 승인이 없다는 이유로 거절되어 수행하지 못했습니다. main 병합과 운영 배포도 하지 않았습니다.
