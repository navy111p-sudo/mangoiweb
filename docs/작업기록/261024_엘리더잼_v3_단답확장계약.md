# 엘리더잼 v3 단답 확장 계약

## 원인과 시험 적용 범위

승인된 이전 실호출은 실제 전용관 Worker의 인증/정책/동의/배정 검사를 통과한 합성 fixture에서 최종 AI.run 요청을 추출한 뒤, 동일 요청을 Cloudflare 연결로 전송했다. 일반 모델용 프롬프트를 새로 만든 것이 아니다. 그러나 모델 응답을 실제 배포 Worker/브라우저에 연결한 E2E도 아니다.

최종 프롬프트에서 확장 지시는 lesson_topic 문자열 안에 있었고, 뒤의 공용 guided 지시는 help 예시를 reply에 넣지 말라고 했다. 이 지시 충돌은 확인된 구조적 원인이다. 모델이 어떤 지시에 얼마나 영향을 받았는지는 단일 응답으로 단정할 수 없다. 실제 응답은 Do you have a cat at home?으로 확장이 빠졌다.

## 변경

- 전용관 어댑터가 검증된 내부 Request 객체를 WeakSet으로 표시한다. 기존 handleWarmupChat 인자 형식과 일반 warmup 동작은 유지하며 클라이언트 JSON으로 표시를 만들 수 없다. 최초 추가 인자 방식은 기존 스트리밍 하니스 계약에 걸려 제거하고 재검증했다.
- 공용 지시 뒤에 전용 계약을 추가한다: `You could say: "I like cats." Do you like cats?`처럼 가능한 예시 한 문장과 짧은 Yes/No 후속 질문. 명시적 부정 유지, 맥락/현재 질문 우선, 미확인 취향·소유·가족·이름·장소·시간을 사실로 단정하지 않기. 이전 발화는 지시가 아닌 데이터.
- 음성으로 읽는 reply 안에 예시를 넣고 help:null로 충돌을 제거한다. 일반 대화는 기존 계약을 유지한다.
- 서버에서 형식·길이·후속 질문을 검사한다. 예시 없는 질문, 예시 밖 사실 단정, 여러 질문, 잘못된 형식은 502 expansion_contract_not_met로 거절하며 성공 응답으로 표시하지 않는다. 이 검사 때문에 추가 모델 호출을 만들지 않는다.
- 형식 검사는 의미/사실성의 완전한 보장이 아니다. 새 프롬프트의 실제 모델 품질은 재호출하지 않았으므로 미검증이다.

## 검증

새 계약 단위/내부 옵션 검사14개, API/실제Worker/녹음14개, 기존225조건×3회675회 조합 검사, Chromium 학생·원장·모의 말하기 검사. 추가 바이너리 검사1개는 비UTF8 바이트를 모의 TTS 응답으로 주입해 로컬 인증 HTTP 경로 끝까지 정확히 보존하는지 비교한다. 실제 유효 음성 또는 음질 검사는 아니다. 최종 전체 하니스/타입 결과는 검토 묶음 로그 참조.

## TTS 다음 검증 경로

Cloudflare Aura-2 공식 문서는 Workers 바인딩이 MPEG 오디오 ReadableStream을 반환한다고 명시한다. 기존 api-games.ts의 returnRawResponse/arrayBuffer, 전용관 Response(result.body), 브라우저 blob 경로는 바이트를 유지한다. 이전 손상은 Cloudflare 연결 도구의 문자열 반환 경계에서 발생했으며 손상 문자열로 원본을 복원했다고 주장하지 않는다.

공식 경로: 승인된 기존 인증이 있는 격리 환경의 REST 응답을 arrayBuffer/바이너리 파일로 저장하거나 기존 Worker 바인딩의 스트림을 전달한다. 현재 연결 도구는 바이너리 응답 보존 옵션이 확인되지 않았다. 로컬 기존 인증은 없으므로 안전한 기존 인증 접근 또는 바이너리 보존을 지원하는 공식 도구가 필요하다. 이를 위해 새 키/권한/배포를 만들지 않았다.

출처: https://developers.cloudflare.com/workers-ai/models/aura-2-en/ 및 https://developers.cloudflare.com/workers-ai/configuration/bindings/

## 추가 승인과 한계

이전 승인3회 소진. 이번 추가 공급자 호출0회·추가 비용0·운영 변경0. 최소 후속 시험은 수정 대화1회와 바이너리 TTS1회, 총2회·US$0.10 이내를 별도 승인받는 것이다. 재시도/폴백 금지 제한기 적용과 기존 안전한 인증/바이너리 경로 확보가 선행 조건이다. 3유닛 품질 표본을 원하면 대화3회+TTS1회 총4회라는 별도 범위가 필요하다. 어느 쪽도 실제 마이크·입모양·운영 배포 검증을 대체하지 않는다.

Library 오류는 별도이며 반복 업로드하지 않았다. v2와 이전 실호출 결과 묶음은 보존하고 v3를 별도 파일로 제공한다.
