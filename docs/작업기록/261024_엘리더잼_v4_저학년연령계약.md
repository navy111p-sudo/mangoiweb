# 엘리더잼 v4 초등 저학년 연령 계약

v3 최종 요청을 PC 시험용으로 전달하면서 공용 child 분류가 10~15세라는 충돌을 확인했다. 원래 목표는 초등 저학년이므로 전용관 내부 payload만 age_group:'kid', difficulty:1로 고정했다. 기존 warmup-audience의 kid(6~9세) 분류를 재사용하며 공용 기본 child 및 다른 서비스 연령 설정은 수정하지 않는다.

전용관 계약에는 lower-primary children aged 6-9, beginner pre-A1/A1, 익숙한 반려동물/일상/음식, 쉬운 현재시제와 Yes/No 질문을 명시했다. 실제 Worker 함수로 최종 모델 요청을 다시 추출해 10~15/16~19/초등 고학년~중학생 지시가 없고, 6~9세·레벨1·새 전용 지시가 있는지 검증했다. 클라이언트에서 age_group:adult,difficulty:8을 보내도 서버 고정값이 적용되는 회귀도 포함했다.

새 계약 검사15개, API/Worker/녹음14개, 225조합×3회675회 검사 및 브라우저/타입/전체 하니스를 재실행했다. 최종 결과는 v4 검토 묶음 참조. 모델 응답 품질·마이크·입모양 실검증은 아니다.

v3 ZIP/전체패치/PC 전달 자료를 그대로 보존하고 v4 별도 디렉터리에 새 requests.json/run-once.mjs를 준비했다. JSON.stringify(parsedRequests)의 SHA-256:
83e1b4599f1e5e9612fb40bf6c76244a01e19de7c7fe7e9084a087350ef486b3

구 v3 해시:
0fd09b511ff2717d7b191dea385f5d16d41dfe4f710efe4122143bd5ca5cfb86

PC 실행 제한기는 요청 해시만 새 값으로 변경하고, 같은 추가 승인 원장 파일명(eleader-v3-approved-followup.ledger.json)을 계속 사용한다. 버전 변경이 호출 한도 초기화가 아니다. 기존 원장 파일을 삭제하거나 새 폴더에서 중복 실행하지 않는다. 새 PC 자료의 --check는 네트워크 없이 확인했다.

현재 PC의 기존 Wrangler 인증 갱신은 부모 보고상 HTTP400으로 실패했고 사용자의 직접 재로그인을 기다린다. 이 작업에서는 인증 갱신/새 키/권한/공급자 호출/배포/push를 하지 않았다. 추가 승인 잔여 대화1회+TTS1회 총2회·US$0.10 그대로다. Library 업로드 복구도 미확인이며 재시도하지 않았다.
