# 엘리더잼 v5 비활성 단계 배포

대상: navy111p-sudo/mangoiweb main → 기존 mangoi.ai 배포 workflow. 기준 main 8dccc88069308c48a3d299bc7ba6b57a067c859e 위 별도 worktree에 v5 패치를3way 적용했고, 원래 작업폴더와 upstream 더빙 변경은 보존했다. .agents/skills 및 AGENTS.md는 이 checkout에서 발견되지 않았다. CLAUDE/MAINTENANCE와 기존 ci-gates 지침을 따른다.

미검증 실제 음성 기능을 켜는 배포는 하지 않는다. eleader-release.ts의 정적 Worker 입구 차단은 모든 전용관 API에404 pilot_disabled,release:staged-v5,voice_enabled:false를 돌려준다. 환경변수·로그인·동의로 해제할 수 없고, DB wrapping 전 분기하므로 요청 본문과 DB/AI 바인딩에 접근하지 않는다. 운영 스키마 적용·학생등록·동의 생성·권한 변경·추가 유료 호출 없음. 활성화에는 별도 코드 리뷰와 배포가 필요하다.

기존 내부 모의 Worker 테스트는 esbuild plugin으로 이 차단 모듈만 대체해 미활성 내부 기능을 계속 검증한다. 실제 출하 Worker를 그대로 빌드한 staged.test.mjs에서는 GET/POST/PUT/DELETE/OPTIONS×7경로35사례가 바인딩/본문접근0으로 차단되는지 별도로 검증한다. 해당검사는 기존 eleader_pilot_harness를 통해 PR CI에도 포함된다. 집중검사98통과와 SQLite225조합×3=675통과. 정확한 CI 커밋과 원격배포 결과는 PR/최종보고로 별도 확인하며 이 문서는 배포 성공을 주장하지 않는다.

학생 안내 화면은 '비활성 코드 배포 단계'를 명시하고 학습/기록/마이크 버튼을 노출하지 않는다. 실제 출하 Worker와 정적화면을 연결한 로컬 Chromium에서도 차단응답,음성버튼 비노출,DB바인딩0,외부요청0을 확인했다. 내부 시범판3유닛60문항을440문항 완성이라고 표시하지 않는다.

실제 마이크·청취·전체 대화 TTS·입모양·유료 전체E2E는 미검증. 이전 승인5회는 모두 소진됐으며 원장을 초기화하지 않는다. 외부 음성 활성화 및 운영 동의/보관/삭제 정책 결정은 이 배포 승인과 별개다. SQL 파일은 검토용이며 배포 workflow에서 실행하지 않는다. Library 전달 오류도 별개로 남아 있다.
