# 엘리더잼 v5 실제 응답 재현과 정규화

PC v4 실호출 결과(부모 보고): `You could say: 'I like cats.' Do you have cats?`, fix:null, help는 객체였다. 내용은 과제에 맞지만 v4 큰따옴표 전용 정규식에서 거절됐다. 원본 공급자 envelope와 help 내용은 이 환경에 전달되지 않았으므로 fixture에는 전달받은 reply/fix와 help 타입만 보존한다. Worker replay의 help 객체는 별도로 표시한 합성 값이다.

v5는 전용관 경계에서 짝이 맞는 큰/작은/곡선 따옴표와 단어 내부 곡선 apostrophe만 표준화한다. 없는 문장·구두점·후속 질문을 생성하거나 덧붙이지 않는다. 예시 1개와 Yes/No 질문 1개, 각각 최대6단어, 제어문자/마크업/숫자/이메일 차단을 유지한다. 전용관 응답에는 text만 검증해 전달하고 fix:null, help:null을 명시한다. 모델의 help/speaking_help 및 다른 필드를 전달하지 않는다. 공용 warmup과 연령 설정은 수정하지 않았다.

기존 구조 검사만으로 의미를 보장할 수 없으므로 제한된 3유닛의 검수 어휘와 문법어 목록으로 허용 범위를 좁혔다. 현재 질문/답변의 주제 단어가 예시와 후속 질문에 모두 있어야 하고, 주요 동사(like/eat/drink/want/have) 및 명시적인 부정/긍정을 보존한다. 모호한 부정 질문은 거절한다. 이것은 범용 의미·유해성 분류기가 아니다. 적합하지만 목록에 없는 표현도 502 expansion_contract_not_met로 거절할 수 있으며, 운영 전 교사의 단원별 수용성 검토가 필요하다. 검사 실패를 예시 생성이나 공급자 재호출로 덮지 않는다.

로컬 검증: 계약/API/전체 Worker/녹음/바이너리 63개 통과. 새 실제응답 replay, 따옴표4종, 곡선 축약형, 잘림·중복질문·주제이탈·유해어·프롬프트주입·개인정보 형태·부정반전 사례 포함. SQLite225고유조합×3회=675회 통과. 타입검사 통과. 브라우저 및 전체 회귀 결과는 v5 검토 묶음의 최종 결과에 기록한다. 이 숫자는 공급자 실호출 횟수가 아니다.

PC TTS는 부모 보고상 HTTP200 audio/mpeg,7056bytes,24kHz mono,1.176초,FFmpeg decode exit0. 이 환경에서 원본 음성을 직접 검사하거나 청취하지 않았다. 실제 마이크·전체 대화 TTS·입모양·학생 대상 E2E는 미검증이다. 기존 추가 승인2회는 PC에서 소진됐으며 이 작업의 추가 호출은0회다. 배포/병합은 안전 검토에서 보류된 그대로이고, push/DB변경/인증변경/Library 재시도도 하지 않았다. 이전 v4 자료와 호출원장은 그대로 보존한다.
