## 기존 구조 조사와 선택

- 실행 서비스는 `cloudflare-deploy/`이며 루트 Express 서버 등 레거시는 수정하지 않았다. AGENTS.md는 발견되지 않았다. CLAUDE.md의 실행·공동작업·검증 지침과 MAINTENANCE.md를 확인했다.
- 학생 로그인은 기존 `mango_token`과 `verifyUidToken`, 원장은 기존 `mango_admin_session`과 `getAdminActor`를 재사용한다. 새 가입·비밀번호·인증 서비스는 없다.
- 기존 `scope.ts`는 agency/branch/franchise와 `students_erp.shop_name` 기반이다. 학원 명칭이나 클라이언트 tenant 파라미터로 권한을 추정하지 않고, 시범판 전용 소속 테이블이 **기존 신원에 대한 추가 권한 제한**으로 작동한다. 실제 계정 연결은 이번 작업에서 하지 않았다.
- `warmup.html`, `/api/warmup/chat`, `/api/warmup/questions`, `/api/voice/tts`, `/api/ai/class-ask`, 기존 lessons 조회 구조를 조사했다. 기존 엔진은 외부 AI·음성 호출 경로가 포함되어 있어 이번 시범판에서 실행하지 않는다. 기존 공용 `mango-avatar.js`의 Emma 표시를 재사용한다.
- 새 API는 기존 `index.ts → api-mango.ts → api-ai.ts` 경로로 진입한다. index.ts 변경은 새 prefix 허용 조건 **한 줄**이며 인증 게이트·기존 엔진·운영 설정을 변경하지 않았다.
- 기존 `seed-shares.ts`는 공개 불변 학습 스냅샷(단어 3~12개, 문장 1~5개, 질문 1개)을 KV에 저장하고 warmup 링크를 만든다. 답변·신원·AI 이력 저장을 명시적으로 금지하는 공개 공유 구조라 비공개 학원 배정/진도 저장소로 전용하지 않았다.
- 질문팩은 서버의 `eleader-pack.ts` 하나를 정본으로 쓴다. 기존 교재 질문을 복제하지 않고 반려동물·하루·음식 주제로 20개씩 새로 작성했다.
- 서버는 `ELEADER_PILOT=on`이 명시되어야 동작한다. wrangler.toml에는 이 값을 넣지 않았다. 기본 404. SQL은 명시적 migration 파일로만 제공하며 자동 스키마/소속 생성은 없다.

## 경로와 사용 흐름

- 학생: `/eleader-pilot.html?academy=eleaderjam`
- 원장: `/eleader-pilot.html?academy=eleaderjam&view=director`
- API: `/api/ai/eleader/state`, `/settings`, `/assign`, `/complete` (모두 academy query 필요)
- 기존 관리자 사이트 구성표 `admin/site-structure-more.html`에 시범판 경로를 추가했다. 운영 메뉴 전체를 개편하지 않았다.

학생은 기존 계정으로 로그인 → 배정된 유닛 선택 → 질문/한글 힌트 → 짧은 답 입력 → 준비된 문장 예시 → 연습 완료 순서로 사용한다. 다른 답을 입력하면 그것을 정답처럼 교정하지 않고 **일반 예시**임을 표시한다. 다음 질문과 다시 연습이 가능하다. 새로고침 후 완료 건수는 서버 기록으로 복구된다.

원장은 기존 관리자 로그인 → 원장 경로 → 학원 표시 이름/연습 허용 저장 → 등록되어 있는 테스트 학생에게 유닛 배정/해제 → 학생·유닛별 완료 문항 수 확인 순서다. 학생 가입/실제 학생 등록은 제공하지 않는다.

## 권한·저장·동작 한계

- 모든 요청에서 기존 로그인과 학원 소속을 확인한다. 학생은 자기 기록만, 원장은 명시적으로 연결된 학원만 본다. 교사는 원장 경로를 사용할 수 없다. 다른 학원 학생에게 배정할 수 없다.
- 학생 Bearer가 있으면 관리자 쿠키로 fallback하지 않는다. 게스트·위조·만료·교체된 세션은 거절한다. POST는 동일 Origin과 JSON을 요구하고 4 KiB로 본문을 제한한다.
- `X-Eleader-Subject`로 화면이 확인한 신원과 현재 요청 신원이 다른 쓰기를 거절한다. 탭 숨김·로그인 변경에는 기존 화면/입력/재생을 제거하고 다시 확인한다.
- 완료 기록은 `(academy_id, student_uid, unit_id, question_id)` 유일 키와 원자 INSERT 조건으로 중복을 막는다. 반복 클릭과 네트워크 재시도로 건수가 부풀지 않는다. 완료는 자기 보고이며 실력 점수가 아니다.
- 저장 항목은 소속, 배정, 완료 문항 및 시간뿐이다. 답변 원문·음성·녹음은 저장하거나 외부로 보내지 않는다. 학원 식별자는 접근 제어에 쓰는 ID이며 암호화가 아니다.
- 기기 내장 영어 음성(`localService=true`)만 선택적으로 사용한다. 없거나 실패하면 텍스트 안내를 제공한다. 실제 Emma 목소리, STT, AI 대화, 발음 점수는 미연결. 브라우저 음성과 아바타 움직임의 조합은 실제 AI 립싱크 검증이 아니다.
- 서버 재시작을 넘는 D1 영속성은 기존 D1를 사용할 구조이나 이번 검증은 로컬 SQLite 어댑터 및 번들된 Worker 실행이다. 실제 Cloudflare 배포/원격 D1 실행은 하지 않았다.

## 재현 방법 (로컬 합성 데이터 전용)

Node 24 이상, 기존 cloudflare-deploy/package-lock.json의 개발 의존성을 사용한다.

```sh
cd cloudflare-deploy
npm ci --ignore-scripts --cache /tmp/mangoi-npm-cache
node node_modules/typescript/bin/tsc --noEmit
cd ..
node test-harness/eleader_pilot_harness.mjs
node test-harness/eleader/browser.test.mjs
```

브라우저 검사는 Playwright와 Chromium이 필요하다. 설치 위치가 다르면 `PLAYWRIGHT_MODULE` 및 `CHROMIUM_PATH`를 지정한다. 캡처 경로는 `ELEADER_ARTIFACTS` (기본 `/tmp/eleader-artifacts`). 테스트 서버는 `127.0.0.1:8798`에만 바인딩하며 기존 인증 포맷의 **로컬 테스트용** 신원을 주입한다. 운영에 유효한 계정/자격증명을 만들지 않는다. 테스트 중 외부 브라우저 요청을 차단하며 요청 0건을 단언한다.

전체 CI는 개발 의존성을 루트에서도 찾도록 임시 node_modules 심볼릭 링크를 사용하고, 외부 네트워크를 차단하는 테스트 preload와 npm offline 옵션으로 실행했다. 링크는 최종 패치에 포함하지 않는다. 이 preload는 배포용 파일이 아니며 결과물의 `offline.cjs`로 보관한다.

최종 검증 집계와 로그는 결과물 `검증결과.md` 참조. 기존 통합 검사 실패가 나오면 완료형으로 바꾸지 않고 원인과 재검증을 기록한다.
