# 8편 무지개 등불: 검토한 국소 얼굴 보정만 반영

## 변경

- 전체 이야기의 214~217초(2장 안에서 95.25~98.25초), 블루의 주둥이 돌출을 최대 10픽셀 줄인 국소 보정만 반영했다.
- 기존 프레임을 추적해 변형했다. 새 캐릭터/프레임 생성, 속도 변경, 장면 재배열은 없다. 시작과 끝 12프레임에서 변형 강도를 부드럽게 연결한다.
- 2장 영상만 `scene-2-v4.mp4`로 연결한다. 이전 영상도 보관해 기존 URL과 되돌리기를 유지한다. 나머지 매니페스트 값은 동일하다.
- 무늬는 644~647초에서 명암·형태를 유지한 채 여분의 색만 줄이는 별도 실험을 했다. 반점의 옅은 흔적이 남아 개선이 불충분하므로 **반영하지 않았다**.
- Higgsfield 등 새 생성 요청/크레딧 사용: 0. 플레이어 코드나 녹음 기능은 변경하지 않았다.

## 검증

- 2장: 4,220프레임 / 24fps / 175.833333초 / 22,802,901바이트. 전체 이야기 6장 / 182대사 / 약 668.333333초 유지.
- 전체 2장 디코딩 성공. `freezedetect -50dB, 0.7초` 검출 0, `blackdetect 0.1초` 검출 0. 이는 미세한 모든 시각적 어색함이 없다는 보장은 아니다.
- 보정 영역 밖 입력 픽셀 불변(배포 인코딩 전), 변형 좌표의 접힘 없음. 구간 앞뒤 및 내부 9시점 비교 검토.
- 기존 48개 미디어 파일 모두 SHA-256 불변. 이 중 36개 음성·배경 트랙이 포함된다. 화자, 대사, 시간표, 역할 선택 모두 기존값 유지.
- 배포 영상 SHA-256: `efe6ea123cf7fb8bab63a62be91b3e3cda893c6e6dd9f705bbc872e3f3e6ac45`.
- 기존 더빙/무지개 등불 회귀 하니스와 PR CI 결과를 확인한 후 병합하며, 운영 영상 URL·해시·재생을 별도로 확인한다.

## 남은 한계

이번 수정은 검토한 짧은 구간의 작은 개선이다. 원본 이미지와 모든 장면의 얼굴 비율·반점 배치가 완전히 일치하는 것은 아니다. 검증되지 않은 무늬 수정이나 다른 장면으로의 자동 확대는 하지 않았다.
