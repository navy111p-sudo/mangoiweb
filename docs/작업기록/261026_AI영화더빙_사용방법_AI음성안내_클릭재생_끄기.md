# A.i영화더빙 사용방법 안내창에 AI 음성 안내(클릭하면 바로 재생 · 끄기 버튼) 추가

- 날짜: 2026-10-26
- 작업자: 사장님 요청 → Claude(클로드 코드 원격 세션)
- 브랜치 / PR: `ai-dubbing-guide-voice`

## 1. 왜 했나

사장님 요청이 세 단계로 왔습니다.

1. 「성우대본 만들어줘」 — `/ai-dubbing.html` 실제 화면 문구(‘짧은 더빙 시작’·‘내 역할 고르기’·‘자막 보며 연습 (추천)’ …)로 11장면 존댓말 대본을 만들었습니다.
2. 「이 대본으로 AI 성우 음성 만들어줘」 — Higgsfield 에 회사가 등록해 둔 목소리 **«망고아이 안내 목소리»** 로 장면마다 음성을 만들었습니다(한국어 11개, 크레딧 약 5.5).
3. 「다 완성되면 병합해서 배포해줘. **더빙 안내페이지에 클릭하면 바로 들리게** 해줘. **끄기 버튼** 추가하고」

같은 날 먼저 병합된 PR #1819(«사용방법» 안내창 — 저절로 표시 · ❓ 사용방법 다시 열기)는 «이 창은 소리를 건드리지 않는다(play() 0)» 를 규칙으로 두고 하니스로 지키고 있었습니다. 이번 요청은 그 규칙을 **사장님 지시로 바꾸는** 것이라, «어디까지 바꾸는가» 를 아래처럼 좁혔습니다.

### 동작(사람이 보는 것)

- 페이지에 들어와 안내창이 **저절로** 뜨면 → 소리 없음. 창 아래 줄에 **‘🔊 소리로 듣기’** 버튼.
- **‘❓ 사용방법’ 을 눌러 열면 → 바로 소리**. 창 안 버튼이 **‘■ 소리 끄기’** 로 바뀜.
- ✕ · Esc · ‘오늘은 다시 보지 않기’ 로 닫으면 → 소리도 꺼짐.
- **‘시작하기’ 로 닫으면 → 안내가 이어지고** 화면 아래 «🔊 음성 안내 중 · 3/11 **■ 끄기**» 막대.
- 녹음·감상을 시작하면(‘내 목소리로 녹음 시작’·‘모든 장면 이어서 더빙하기’·‘👀 보기’·이어 보기 둘) 또는 화면의 영상이 재생되면 → 바로 꺼짐(녹음에 안내 목소리가 섞이지 않게). 페이지를 떠나도 꺼짐.
- 🌐 로 언어를 바꾸면 → **그 장면 처음부터** 다른 언어 음원으로 이어짐.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

| 버린 방법 | 이유 |
|---|---|
| 안내창이 저절로 뜰 때 바로 재생 | 브라우저가 «사람이 누르지 않은» 재생을 막습니다(자동재생 정책). 막히지 않는 기기라도 **수업 중 페이지를 열자마자 소리가 나는 것**은 #1819 가 막으려던 바로 그 일입니다. 그래서 «클릭하면 바로» 를 ‘❓ 사용방법’ 클릭과 ‘🔊 소리로 듣기’ 클릭으로 해석했습니다 |
| 안내창 파일(`ai-dubbing-guide.js`) 안에 소리 코드를 넣기 | #1819 의 «이 파일 play() 0» 하니스와 정면으로 부딪히고, 열림·단계·포커스 코드와 소리 상태가 한 파일에 섞입니다. 소리 판단을 **새 파일 한 곳**에 두고 안내창은 알리기만 — 음성 파일이 못 실려도 안내창은 그대로 돕니다(`voice()` 가 null) |
| 장면 11개를 파일 11개로 두고 차례로 틀기 | 요청 11번·요소 교체·끊김 관리가 늘어납니다. **언어별 한 파일 + 장면 시작 시각 표(`OFFSETS`)** 로 하면 요청 1번이고, 언어를 바꿀 때 «그 장면 처음» 으로 바로 갈 수 있습니다 |
| 음성 진행에 맞춰 안내창 단계(①②③)를 저절로 넘기기 | 이 대본은 «페이지 전체 둘러보기»(11장면)라 안내창 3단계와 1:1 이 아니고, 사람이 단계를 누르는 것과 다툽니다. 안내창 그림 순서대로 읽는 **사람 성우용 3단계 대본은 이미 따로 있습니다**(`docs/A.i영화더빙_사용방법_성우대본.md`) |
| AI 음성을 받은 그대로 쓰기 | 무음 검출 실측으로 **문장 사이 3~7초 쉼**이 여러 곳(한국어 2번·6번·7번 장면, 영어 1·3·5·7·9·10번 등) 있었습니다. 그대로면 «안내가 멈췄다» 로 들립니다 → 0.55초 넘는 쉼을 0.45초로 줄임(`docs/…AI성우대본.md` «만든 방법») |
| 다른 소리 감시를 `HTMLMediaElement.prototype.play` 가로채기로 | 전역 원형을 덮는 것은 화면 전체(녹음 섞개 포함)에 손을 대는 일입니다. **문서의 `play` 잡기 리스너 + 시작 버튼 클릭**으로 했습니다 |
| 그 감시를 «영상 `play` 이벤트» 하나로만 | 브라우저 실측에서 걸렸습니다 — ‘👀 보기’ 는 **문서 밖 `new Audio()` 8개를 먼저 깨우고**(이 `play` 는 문서 리스너에 안 옵니다) 영상은 받은 «뒤» 에 틉니다. 그 사이 안내 목소리가 겹칩니다 → 감상 시작 버튼(`button[data-watch]`·`#dub-w-film`·`#dub-w-all`)도 `STOP_ON` 에 넣음 |
| 끄기 막대를 화면 아래 가운데 | PC 에서 역할 고르기가 오른쪽 패널(폭 440px)로 열리면 1024px 창에서 겹칩니다 → PC 는 왼쪽 아래. 폰은 아래 고정 바(`.mbar`) 위. 폰에서 시트가 열리면(화면 88%) **«■ 끄기» 만 남겨 맨 위 머리줄 빈자리(← 와 🏠·🌐 칩 사이)** 로 — 320~430px 실측 후 정함 |
| 끄기를 기억하기(localStorage) | 다음에 ‘❓ 사용방법’ 을 눌러도 소리가 안 나면 «클릭하면 바로 들리게» 와 어긋나고, 확인하시는 분이 «왜 안 들리지» 가 됩니다. 끄기는 **이번 한 번**만 |
| ✕ 로 닫아도 이어 듣기 | ✕ 는 «안내를 치운다» 는 뜻으로 보고 소리도 끔. «안내를 따라 해 보겠다» 인 ‘시작하기’ 만 이어 듣기 |
| 128kbps 스테레오 | 두 언어 합쳐 약 5.7MB. 목소리만이라 **모노 64kbps**(합 2.6MB)로. 처음 누를 때만 받습니다(`preload=none`) |

## 5. 남은 것 / 주의할 것

- **화면 버튼 이름이 바뀌면 음성도 다시 만들어야 합니다** — 대본의 ‘…’ 말이 화면과 달라집니다. 다시 만들면 `AUDIO_V` 를 올리고 `OFFSETS` 를 새 파일에 맞추세요(하니스가 길이를 대조합니다).
- 이 저장소는 지금 **공개(public)** 입니다 — 음원 2개(회사 등록 AI 목소리)는 사장님이 «배포해줘» 로 올리신 것입니다.
- 감시는 «문서 안 영상·소리» + «시작 버튼 클릭» 입니다. 새로 «소리를 내는 시작 버튼» 을 만들면 `STOP_ON` 에도 넣으세요(하니스가 «감시하는 id 가 화면에 실재하는가» 를 봅니다).
- 사람 성우용 3단계 대본(`docs/A.i영화더빙_사용방법_성우대본.md`)과 이 AI 대본은 **두 벌**입니다 — 사람 녹음본으로 바꿀 때는 `guide-<ko|en>.mp3` 와 `OFFSETS` 만 바꾸면 됩니다(장면 수가 달라지면 하니스의 «11장면» 도).
