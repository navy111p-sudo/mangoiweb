## 1. 왜 했나

ChatGPT 쪽에서 받은 인수인계 9항목(사장님 요청)을 Claude 가 이어받았습니다. ChatGPT 쪽 작업 환경은 시작되지 않아 **실제 수정·테스트·배포는 0건**인 상태로 넘어왔습니다(인수인계문에 명시).

요청 요지: 페이지에 들어오면 사용 안내가 저절로 뜨고(✕ · 시작하기 · 오늘은 다시 보지 않기), 위쪽에서 다시 열 수 있게. 초등학생·학부모도 알 수 있게 큰 글씨·짧은 존댓말·한/영·폰/PC. ① 영상 골라요 ② 듣고 따라 해요 ③ 내 목소리로 말해요 — 실제 버튼 흐름(보기 · 더빙 · 자막 보며 연습 · 내 목소리로 녹음 시작 · 말하기 완료)으로. 실제 화면 캡처 + 화살표·번호. 기존 더빙·녹음·영상·계정·결제 동작은 그대로, 안내창이 마이크·영상을 켜지 않게.

**저절로 열기 규칙** (`decide`)
- 오늘(**기기 시간대 날짜**, `dayKey`) ‘오늘은 다시 보지 않기’를 눌렀으면 안 연다 → 자정 지나면 다시
- **이 탭에서 이미 봤으면 안 연다**(sessionStorage) — 작품을 바꾸면 `?ep=` 로 새로 고침되는데, 그때마다 뜨면 수업 중에 방해
- `?resume=` · `?library=` 로 «하던 일» 을 이어 들어왔으면 안 연다(보관함·이어 하기를 가리지 않게)
- 저장소가 막힌 기기에서는 **보여 주는 쪽으로** 실패 — ‘오늘은 다시 보지 않기’는 그 화면에서만 기억
- ⛔ 위쪽 **❓ 사용방법** 은 위 규칙과 상관없이 언제나 연다

**하지 않는 것**: 마이크·영상·소리 API 0(`getUserMedia`·`play()`·`AudioContext`), `innerHTML` 0, 바깥 클릭으로 닫기 0(✕ 로만 — `mg-modal-policy.js` 정책). ‘시작하기’는 **‘짧은 더빙 시작’ 으로 포커스만 옮기고 누르지 않습니다**.

## 3. 검토했다가 버린 방법

| 버린 것 | 이유 |
|---|---|
| 상단바(고정 헤더)에 ❓ 버튼 | 오른쪽 120px 은 공용 홈/EN 칩 자리 — 390px 에서 제목과 겹침(`today-guide` 때 같은 결론). 소개 카드 첫 줄 메뉴 버튼 옆으로 |
| 매 접속마다 표시 | 작품 바꾸기가 `?ep=` 새로 고침이라 수업 중 계속 뜸 → 탭당 한 번 + 오늘 숨김 |
| «처음 한 번만»(`today-guide` 방식) | 요청이 «들어오면 저절로 + 오늘은 다시 보지 않기» — 날짜 기준이 필요 |
| 네이티브 `<dialog>.showModal()` | iOS 15.4 미만·옛 WebView 미지원. `div[role=dialog][aria-modal]` + Tab 가두기 + Esc 직접 처리 |
| 뒤 화면에 `inert` | 다른 스크립트가 붙인 공용 칩·드로어까지 건드림. z-index 로 덮고 Tab·포커스를 창 안에 가둠 |
| Esc 를 `document` 에서 받기 | 화면의 «역할 고르기 시트 닫기» Esc 와 같이 돌아 두 개가 한 번에 닫힘 → `window` capture 에서 받고 멈춤(변이로 실제 FAIL 확인) |
| 그림 먼저, 글 아래 | 폰에서 할 일(글)이 화면 밖으로 밀림 → 글 먼저 + 그림 높이 제한 |
| ‘시작하기’ = ‘짧은 더빙 시작’ 누르기 | 역할 시트가 열리고 다음 탭 한 번이면 마이크 → 포커스만 |
| `HOME.ready()` 의 resume/library 판정을 그대로 복사 | «같은 판정 두 곳» 함정 → «그 이름의 주소값이 있으면 건너뜀» 거친 규칙(틀려도 손해는 «안 뜸» 뿐, 버튼으로 열림) |
| 화살표를 HTML 위 % 좌표로 | 폭마다 어긋남 → 캡처할 때 실제 요소 좌표로 그려 넣음 |
