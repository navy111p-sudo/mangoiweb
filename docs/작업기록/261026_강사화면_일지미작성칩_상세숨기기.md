## 1. 왜 했나
필리핀 매니저 Maimai 제안(「강사 페이지를 매니저 화면처럼 한 줄 표로」)을 두 방식 비교 보고서(KO/EN PDF)로 정리했고,
결론은 **하이브리드**(표 + 기존 칩·필터 유지 + 상세 접기 + «일지 미작성» 요약)였다. 사장님 「그럼 이렇게 만들어줘」.

## 2. 같은 날 표 보기가 먼저 병합됨 — #1811 을 정본으로 두고 부족한 것만 붙였다
작업 중 같은 기능(표 보기 «매니저 화면처럼», `#class-view`·`classTableHtml`·`bindClassRows`)이 **#1811 로 먼저 병합**됐다.
처음 만든 «CSS 로 카드를 3열 그리드로 바꾸는 PC 표» 와 겹쳐 두 개의 표가 되므로, 사장님 결정으로
**#1811 표는 그대로 두고** 거기에 없던 두 가지만 옮겼다(내 표 보기·머리줄·관찰자는 전부 버림).

## 3. 무엇을 바꿨나 — `cloudflare-deploy/public/teacher.html`
- `clsChipsHtml`: **✍ 일지 미작성 N** 칩. 줄에 [일지 쓰기](`.btn-eval`, `classActHtml`)가 그려지는 조건과 똑같이 센다
  — 취소·연기·보류 제외, `t > close_at_ts`, `!eval_written`, LMS·샘플 줄 제외. 0 이면 안 그린다.
- `bindClassRows` 칩 클릭: `nolog → '.btn-eval'` → 그 줄(`.cls` 카드 / `.cls-tr` 표)로 스크롤. 카드·표 공통.
- **상세 숨기기** 체크박스(`#cls-lite`, 보기 선택 아래) — `#classes`·`#cls-day-view` 에 `cls-lite` 클래스만 붙이고,
  CSS 가 `.cls-goal/.cls-hand/.cls-prev`(4주 목표·인수인계·지난 수업) 3종만 숨긴다. localStorage `mangoi_teacher_cls_lite`(try/catch).
  **표 보기에서는 체크박스 줄을 숨긴다** — #1811 표는 그 셋을 이미 «📝 메모» 접이칸에 넣어 두었다.
- 칩 색(밝게·어둡게) CSS.

## 4. 왜 그렇게 — 버린 방법
- **두 번째 표(내 CSS 그리드 표)를 남기기** — 버림. 표가 두 벌이면 칸·버튼이 화면마다 달라진다(「같은 판정이 두 곳」).
- **상세 숨기기를 표의 «📝 메모» 에도 걸기** — 버림. 그 칸에는 학부모 요청(`preqHtml`)도 들어 있다. 숨기면 «지금 할 일» 이 사라진다.
- **renderClasses 안에서 숨김을 처리** — 버림. 지문(sig)이 같으면 다시 안 그리므로 체크해도 안 바뀐다. 상자 클래스만 바꾸면 즉시 반영되고 60초 재그리기에도 유지된다.
- 다른 방 경고·학부모 요청·입장/일지 버튼은 숨기지 않는다(검사로 못 박음).
