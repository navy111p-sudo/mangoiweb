## 2. 원인 — 재생 코드가 아니라 «음원 파일 자체» 가 잘려 있었다

[잰 것]

| | 목소리 길이(빌드 때) | 배포된 파일 길이 | 마지막 장면(11) 중 파일에 든 길이 |
|---|---|---|---|
| 한국어 v2 | 151.4초(문서 «2분 31초») | **148.4초** | 10.17초 중 **7.27초** |
| 영어 v2 | 146.1초(문서 «2분 26초») | **143.3초** | 10.69초 중 **7.79초** |

- 배포된 mp3 의 마지막 0.1초까지 말소리 크기(-13~-17dB) 그대로 — 끝 무음·페이드가 없음 = 말하는 도중에 끝남.
- 사라진 약 2.9초 = 한국어 «영화를 만들어 보세요. 감사합니다.» · 영어 «…English movie with A.I. Dubbing. Thank you.»
- 재생 코드(`ai-dubbing-guide-voice.js`)는 `ended` 에서 멈출 뿐이라 원인이 아님 — 파일이 거기서 끝났기 때문.

[재현 — ffmpeg 6.1.1, 151초 합성 음으로]

| 필터 조합 | 결과 |
|---|---|
| `loudnorm` 만 | 151.0초 ✅ |
| `sidechaincompress` + `amix` (loudnorm 없이) | 151.0초 ✅ |
| **`loudnorm` → `amix(duration=first)`** | **148.1초 ❌** |
| `loudnorm` → `aresample=44100` → `amix` | 151.0초 ✅ |

`loudnorm` 은 192kHz 로 내보내며 끝 3초를 들고 있다가 마지막에 내놓는데, 그 출력을 `amix(duration=first)` 에 바로 물리면
그 3초를 받기 전에 섞기가 끝납니다(배경음악이 목소리보다 길거나 같을 때. 짧으면 안 잘림 — 그래서 v1 때는 안 드러났을 수 있음 [추정]).
저장소의 원래 `build_guide.py` 로 같은 장면 음성을 다시 합쳐도 **똑같이 잘렸습니다**(한국어 149.9 → 147.0초).

[왜 아무도 못 봤나] 하니스는 «마지막 장면이 5~25초인가» 만 봤습니다 — 잘린 7.3초도 통과합니다.
