# 강사 화면 수업표 7칸으로 정리 — PC 는 표(B안) · 폰은 수업당 격자 상자(D안)

- 날짜: 2026-10-27
- 작업자: Claude (사장님 지시)
- 앞 작업: `261026_강사화면_수업목록_표보기_매니저처럼.md` (#1811 · #1815)

## 1. 왜 했나

사장님이 강사 계정(`hq_t_len`)으로 «표 보기» 를 열어 보시고 「보기가 너무 복잡해. 가로·세로 실선이 있으면 좋겠어」.
시안 4종(A 기본 격자 · B 압축 격자 · C 고정 열 · D 수업당 한 칸)을 보여 드렸고, 사장님 결정: **PC 는 B, 폰은 D**.

복잡해 보인 가장 큰 이유는 «칸 수» 였습니다 — 매니저 화면을 따라 15칸이라 PC 에서도 옆으로 밀어야 했습니다.

## 2. 무엇을 바꿨나 — `cloudflare-deploy/public/teacher.html` 한 파일

### 칸 묶기 (15 → 7)

| 새 칸 | 담긴 값 (옛 칸) |
|---|---|
| Time · 시간 | 시간 + 날짜 |
| Status · 상태 | 상태 (보류 배지 포함) |
| Student · Contact · Academy | 학생 이름·ID + ☎ 연락처 + 학원 |
| Class calendar · 수업 캘린더 | 이번 주 7칸 + 일정 + «요약 / 캘린더» 버튼 |
| Teacher connection · Attendance | 강사 입장 + 학생 출결 |
| Previous teacher · Feedback | 이전 강사 + 지난 피드백 + 오늘 피드백(✍ 작성) + 레벨·교재 |
| Action · 할 일 | 입장 버튼 + 📝 메모 + 방 번호 |

값은 하나도 빼지 않았습니다. 판정은 예전처럼 `extrasHtml`·`portalContact` 의 «조각» 을 받아 그리기만 합니다.

### PC / 폰 전환 — 같은 DOM, CSS 만

- 표는 **한 벌만** 그립니다. 폰(<900px)에서는 `@media (max-width:899.98px)` 가 같은 `<tr>` 을 `display:grid` 상자로 바꿉니다
  (윗줄 시간·상태 → 학생 → 할 일 → 캘린더 → 입장 | 이전 강사). 칸 이름은 `td[data-k]` 를 `::before` 로 그립니다.
- 그래서 버튼 배선(`bindClassRows`)·화면 지문(`sig`)은 그대로입니다 — 두 벌을 그렸다면 한쪽만 고쳐지는 사고가 났을 자리입니다.
- 900px 경계는 페이지가 이미 쓰는 데스크톱 경계(`@media(min-width:900px)` 의 `.wrap`)와 같습니다.
- 실선: PC 는 모든 칸에 `border:1px solid`(가로·세로), 바깥 테두리는 상자가 그립니다. 줄무늬(짝수 줄)를 넣었습니다.

### 함께 고친 것

- 연기된 줄 배경(`cls-postponed`)이 새 줄무늬에 덮이지 않게 선택자를 올렸습니다(특정성).
- 다크 모드 실선·줄무늬·부제 색.

## 3. 검토했다가 버린 것

- **PC 표와 폰 상자를 두 벌 그리고 CSS 로 하나 숨기기** — 버렸음. 버튼·`id` 가 두 벌이 되어 배선이 꼬입니다.
- **창 크기를 JS 로 재서 다시 그리기** — 버렸음. 회전·창 크기 바꿀 때마다 다시 그려야 하고, 지문 검사와 엇갈립니다.
- **A안(15칸 그대로 + 실선)** — 사장님이 B·D 를 고르셨음. 칸 수가 복잡함의 원인이라 선만으로는 부족.

- `--fast` FAIL 목록을 바꾸기 전과 `comm` 대조 → 새 FAIL 0건(양쪽 30건, 전부 컨테이너에 `node_modules` 없음 사유).
- 크로미움 실측(실제 `<style>` + 실제 `classTableHtml`): 1280·900·390·320px 모두 페이지 가로 넘침 0 · 표 상자 넘침 0 · 칸이 상자 밖으로 안 샘 · JS 오류 0. PC 는 세로선 1px solid, 폰은 grid·머리줄 숨김·칸 이름 표시.
- 함정 대조(trap-check)가 CSS 버그 2건을 찾아 고쳤습니다:
  - PC 의 «마지막 줄 아래선 없음»(`tr:last-child>td{border-bottom:0}`, 특정성 0,2,3)이 폰 규칙을 이겨 **폰의 마지막 상자 안쪽 선이 전부 사라졌습니다** → `@media (min-width:900px)` 안으로.
  - 폰 블록의 `.cls-tbl-act{margin-top:0}` 이 문서상 뒤의 기본 규칙에 져 한 번도 안 먹었습니다 → `td.c-act .cls-tbl-act` 로 특정성을 올림.
  - ⚠️ 둘 다 문자열 하니스로는 원리상 못 잡습니다(규칙 «글자» 는 다 있음). 그래서 새 브라우저 검사를 두었습니다.
- 새 브라우저 검사 `test-harness/manual/teacher-class-table-grid-browser.mjs`(자동으로 안 돕니다, 사람이 부릅니다): 실제 `<style>` + 실제 함수를 폭 6종 × 테마 2 × 줄 1·2·3·6 × 언어 2 = **96 시나리오, PASS 937 / FAIL 0**. 위 두 버그를 되돌리면 각각 **48건 실제 FAIL**.
- 기존 실페이지 브라우저 검사 `manual/teacher-log-chip-lite-browser.mjs` 300회 PASS 6,555 / FAIL 0(표 위의 칩·상세 숨기기와 충돌 없음).
- 하니스 ⑧에 «옛 15칸 값(날짜·일정·상태·지난 피드백·방 번호)이 출력에 남았는가» 와 «한국어 머리글·칸 이름» 짝 검사를 더했습니다(함정 대조 지적 — 전에는 주석만 «④가 본다» 고 말했음). 방 번호를 빼는 변이가 실제 FAIL.

## 5. 남은 것 / 주의

- 「보기 → 카드」 를 골라 둔 강사는 계속 카드로 보입니다(저장값 우선 — #1815 그대로).
- 표 머리글 문구(「Table (like manager page)」)는 그대로 두었습니다. 이제 매니저 화면과 칸 수가 다르므로, 문구를 바꿀지는 사람이 정할 일입니다.
- 900px 근처(태블릿 가로)는 7칸이 빠듯해 글자가 두세 줄로 접힙니다(넘침은 없음).
- 폰에서 연기된 줄은 상자 윗줄(시간·상태)이 회색 그대로이고 주황은 본문 칸에만 남습니다. 「학생이 다른 방에」 빨간 띠도 시간 칸에만 붙습니다 — 디자인 판단이라 그대로 두었습니다.
- 안내용 줄(옛 LMS·샘플)에는 이전 강사·레벨 칸을 «—» 하나로 그립니다(그 줄은 망고아이 수업이 아님).
