# 엘리더잼 L1 — 책 20문항을 다 끝낸 뒤에도 계속 질문하기

- 날짜: 2026-10-27
- 작업자: 사장님 제보 · Claude
- 브랜치: `fix/eleader-l1-after-book-keeps-asking`

## 1. 왜 했나
- 제보(화면 캡처 2장): 1권(반려 고양이) 20문항을 «다 했어요! 🎉» 까지 끝낸 뒤 학생이 더 말하면, Lily 가
  「No, that's all! So, you did a great job today!」·「You're right, I don't have any other questions! So, you did a great job today!」
  만 되풀이하고 다음 질문을 안 함(내 답변 21~25개).
- 사장님: 「학생이 질문을 더 받고 싶은데 계속 질문이 더 없다고 해 — 계속 질문할 수 있게 해 줘」.

## 2. 원인 (코드로 확인)
- 화면 `public/js/eleader-l1.js` 가 문항 번호를 `Math.min(state.q, state.n - 1)` 로 보냄 →
  20문항을 다 끝낸 뒤(`state.q = 20`)에도 매 턴 `eleader_q = 19`(마지막 문항).
- 서버 `src/eleader-l1.ts` `eleaderL1Topic()` 은 19번이면
  «This was the last question. … say today's book practice is finished. Do not ask a new book question.» +
  «Start your closing words with "So," (e.g. "So, you did a great job today!")» 를 줌.
- ⟹ «마지막 문항에 답한 턴» 과 «책을 끝낸 뒤의 턴» 이 **같은 번호**라 서버가 구별할 수 없었고,
  끝난 뒤 매 턴 마무리 인사 지시가 다시 나갔다. 캡처 속 문장이 지시의 예문 그대로다.
- 덤: 마무리 턴 자체도 질문 없이 끝나서 아이가 이어 할 말이 없었다.

## 3. 무엇을 바꿨나
- 화면(`eleader-l1.js`): 끝난 뒤에는 `eleader_q = n`(«다 했어요») 을 보냄. 진행 막대 「다 했어요! 🎉 · 계속 이야기해요」(EN 「All done! 🎉 · Keep talking」). `warmup.html` `?v=3 → 4`.
- 서버(`eleaderL1Topic`): `qIndex === n`(kickoff 제외)을 받아 «책을 끝낸 뒤» 지시 —
  학생 말 인용 · 먼저 반응 · **매 턴 새 쉬운 질문 하나**(책 주제 또는 학생이 고른 주제) ·
  이미 한 질문 금지 · «질문이 더 없다» 금지 · 마무리 칭찬/작별 반복 금지 · 접속사(학생 말 길이로 회전).
  kickoff 의 `n`, 그리고 `n+1` 이상은 예전처럼 400.
- 마무리 턴(19번)도 «책 질문은 끝» 이라고 말한 뒤 쉬운 질문 하나로 끝나게.
- 접속사 줄을 `l1LinkLine()` 하나로 모음(두 갈래가 같은 줄을 씀 — 복제 방지).

## 4. 검토했다가 버린 방법
- **서버만 고치기**(KV 에 «마무리 했음» 기억) → 버림. 같은 번호로 오는 «재시도»(스트림이 끊겨 같은 본문을 다시 보냄)와
  «끝난 뒤 새 말» 을 서버가 가를 수 없다. 화면이 이미 «다 했어요» 를 알고 있으니 그 값을 보내는 것이 정확하다.
- **끝나면 자동으로 「책 그만하기」(일반 웜업 자유 대화)** → 버림. 책 주제·고른 주제·Level 1 지시·엘리더잼 하루 상한이 다 풀린다.
  학생은 같은 책 이야기를 더 하고 싶어 한다.
- **다음 책으로 자동 넘기기** → 진도는 사람이 정할 일. 안 함.
- **끝난 뒤 접속사를 문항 번호로 돌리기** → 번호가 더 안 바뀌어 매 턴 같은 말(«By the way»)이 된다. 학생 말 길이로 돌림.
