## 1. 왜 했나
- 사장님이 4쪽짜리 한글 PDF 「🤖 A.i 컨텐츠 결제 안내서 — 망고아이 대리점용 · 2026년 10월」을 주시며
  「여기 자료실 적당한 곳에 결제 안내 메뉴얼도 넣어줘. 그리고 사용설명서에도 포함해서 다시 만들어서 넣어줘」(관리자 자료실 화면 캡처와 함께),
  이어서 「대리점 자료실에도 들어가야 할 것 같아 · 적당한 곳에 대리점 자료실」.
- 대리점이 대리점 화면(`manager.html`) 「정산통계관리 › AI 컨텐츠 결제」(2026-10-20 신설)에서 다음 달 이용분 학생을 골라
  카드로 미리 내는 흐름인데, 그 사용법 자료가 자료실에 없었다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법
- **사장님 PDF 를 그대로 올리기 → 버림.** 로그인 화면 사진에 **실제 대리점 로그인 아이디**가 찍혀 있었다
  (저장소 `src/api-admin.ts` 주석에 나오는 실제 학원의 아이디와 같은 값). `/library/` 는 로그인 없이 누구나 받고 저장소도 공개다.
  또 「얼마인가요? … (2쪽 표)」인데 단가표는 4쪽에 있었다. 원본(HTML·캡처)이 없어 고칠 수도 없었다.
  → **같은 구성·같은 문구로 원본을 새로 만들어** 한글판도 다시 찍었다(아이디 `sample01`, 「(끝쪽 표)」, FAQ 화면 문구를 실제 글자
  「본사가 아직 **A.i 컨텐츠** 결제를 열지 않았습니다」로). 사장님 원본 PDF 는 같은 이유로 저장소에 넣지 않았다.
- **영어판을 한글 사진 위에 글만 영어로 → 버림.** 화면이 한글이면 영어 사용자(필리핀 매니저 등)에게 쓸모가 반이다.
  `manager.html` 은 KO/EN 을 다 그리고, **시연 계정(testagency) 모드**가 예시 학생(demo001…)·예시 금액을 그려 주며 결제창은 안 연다(D1 기록 0)
  → 그 모드를 띄워 언어별로 찍었다. 대신 답하는 API 는 `/api/admin/me`·`/api/admin/exec/summary` 두 개뿐.
- **관리자용 사용설명서 1~9장도 다시 찍기 → 버림.** 10-09 이후 화면이 바뀐 곳이 있으면 글(10-09 기준)과 그림이 어긋난다.
  → 배포된 PPTX 에서 그림을 **슬라이드 제목(«장. 장제목 — 단계제목»)으로 대조**해 원래 이름으로 꺼냈다(순서 대조는 단계 하나만 늘어도 밀린다).
  KO/EN 각 38장 전부 대조됨. 표지에 «화면: 1~9장 2026-10-09 · 10장 2026-10-28» 로 적었다.
- **대리점용 사용설명서(agency-kr|en, 2026-07)에도 넣기 → 이번엔 안 함.** 옛 파이프라인(`망고아이_사용설명서/content.py`)·옛 내용(mangoi.co.kr 등)이라
  고치려면 통째로 새로 써야 한다. 대리점은 자료실 맨 위 결제 안내서로 받는다. «사용설명서» 는 사장님 캡처에 보이던 관리자용으로 해석했다.
- **결제 안내서 파일을 두 벌(agency/admin) 두기 → 버림.** 한 파일(`/library/agency/`)을 두 자료실이 같이 연다(어긋날 일이 없다).

## 4. 확인한 방법
- 글 근거를 코드와 대조: 버튼·문구(`manager.html` `paintAiBill`·`aibFailText`), 단가(`src/ai-billing-price.ts` 7,500/6,500/5,500/4,500 · 최소 청구 없음 · 경계 보정),
  메뉴 위치(`#sideAibill` 「정산통계관리」, 대리점 계정만), 본사 쪽(`adm-ia6.js` «정산·매출 › 🏢 AI 사용료», `adm-ai-billing.js` «자동 청구 켜기/끄기»).
- PDF 를 쪽 그림으로 떠서 눈으로 봄: 결제 안내서 KO/EN 각 4쪽(사장님 판과 같은 쪽 나눔), 설명서 표지·차례·10장·FAQ.
- PPTX/XLSX 를 python-pptx·openpyxl 로 열어 10장 슬라이드 제목·그림 수·행 수 확인(위 2절 숫자).
- 실제 브라우저(로컬 `python3 -m http.server` + Playwright)로 `admin.html` 두 자료실을 KO/EN 으로 열어 새 항목·링크 6개 확인, 콘솔 오류 0,
  두 PDF 가 `200 application/pdf` 로 나가는 것 확인.
- `node test-harness/run.mjs --fast`: **PASS 576 / SKIP 20 / FAIL 30** — 같은 명령을 `origin/main` 사본(git worktree)에서 돌려도
  **PASS 576 / FAIL 30, 실패 목록이 줄 단위로 완전히 같음**(`comm` 대조, 이 브랜치에만 있는 실패 0). 실패는 이 컨테이너에
  `cloudflare-deploy/node_modules`(esbuild·typescript)가 없어서다(예: `admin_404_apis_harness` «esbuild ENOENT»). 최종 판정은 CI.
- 타입체크: `src/` 를 안 건드려 해당 없음.
- ❌ 운영(mangoi.ai) 화면은 이 컨테이너 프록시가 막아 못 봤다 — 병합·배포 뒤 사람이 자료실에서 한 번 열어 봐야 끝.

## 5. 남은 것 / 주의할 것
- ⚠️ **관리자 화면 «🏢 A.i 학습 사용료 관리» 카드의 안내 글이 아직 «최소 20명분 청구»** 라고 말한다(`admin.html` `#card-ai-billing` 의 `rf-info`).
  최소 청구는 2026-10-26 에 폐지됐다(`ai-billing-price.ts`). 이번 범위 밖이라 안 고쳤다 — 사람이 정할 일.
- 💡 대리점이 실제로 쓰는 화면(`manager.html`)에는 자료실 연결이 없다. 결제 카드 안에 «📄 결제 안내서» 링크 하나를 두면 대리점이 바로 볼 수 있다(제안 · 안 함).
- 🎬 관리자용 **동영상** 사용설명서(`admin-kr|en.mp4`)는 원본이 없어 그대로(10장 내용 없음).
- 결제 카드·단가·마감 규칙이 바뀌면 `docs/자료실_원본/AI컨텐츠_결제안내/` 로 결제 안내서와 관리자 설명서 10장을 **함께** 다시 만든다(그림이 같다).
