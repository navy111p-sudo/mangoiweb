# 강사 화면에도 «📵 번호 없는 학생» 칸 (2026-10-28)

> 사장님: 「강사 화면에도 똑같이 넣어줘」 — 관리자(#1857)·매니저(#1865)에 이어 세 번째 화면.
> 같은 정본(`src/phone-gaps.ts` · `js/adm-phone-gaps.js`)을 쓰고, **강사에게 맞게 범위만 좁혔습니다.**

## 1. 왜

- 수업 30분 전 안내 문자는 번호가 있어야 나갑니다. 강사는 그 학생을 매주 만나는 사람이라
  «번호를 받아 넣기» 에 가장 가까운 사람입니다.
- 그런데 관리자·매니저 칸을 그대로 열면 **전국 학생 명단과 연락처**가 강사에게 열립니다.
  그래서 «똑같이» 는 **모양·저장 방식** 이고, 보이는 범위와 할 수 있는 일은 줄였습니다.

## 2. 무엇을 했나

| 자리 | 바뀐 것 |
|---|---|
| `src/phone-gaps.ts` | `buildPhoneGaps(env, { teacherKeys })` — 강사 범위면 **그 강사의 수업만**(`class_schedules.teacher_id` 정확일치, 쉼표 든 값은 제외). 키가 비면 수업 조회 없이 0명. 강사 범위는 **이탈위험 표(참고 번호)를 읽지 않음**. `teacherKeyList()` 내보냄 |

### 강사가 할 수 있는 것 / 없는 것

- ✅ **자기 수업 학생 중** 번호가 없는 학생을 보고, 학부모·학생 번호를 **넣기만**.
- ⛔ 지우기·고치기·이름·비밀번호 없음. 숫자 10~15자리 · `[0-9+\-\s().]` · 30자 이내만.
- ⛔ 저장 «그 순간» 다시 잽니다(14일) — 지금 목록에 **없는** 학생이면 403(`not_in_your_list`).
  - 목록을 못 읽으면 503(`phone_check_unavailable`), 번호 조회가 덜 됐으면 503(`phone_check_incomplete`) — **막는 쪽으로 실패**.
- 저장은 **`student_erp_override` 만**(카페24 밤 동기화가 안 덮는 칸). 명부(`students_erp`)는 안 건드림 → 응답 `roster_updated: null`.
- 누가 넣었는지 `updated_by = 'teacher:<아이디>'`.

## 3. 검토했다가 버린 것

- **관리자 contact PATCH 를 강사에게 여는 것** — 그 API 는 이름·소속·지우기까지 받고 «아무 학생» 이나 고칩니다. 범위를 좁힐 자리가 없어 새 경로를 냈습니다.
- **화면이 보낸 학생 목록을 믿는 것** — 저장 순간 서버가 다시 재서 «지금 내 목록에 있는가» 만 봅니다.
- **이탈위험 «참고 번호» 를 강사에게도 보여 주기** — 누구 번호인지(학생/학부모) 모르는 개인정보라 뺐습니다.
- **대체강사에게도 보이기** — 오늘만 맡은 수업까지 넣으려면 대체 배정 판정이 함께 들어와야 해서 이번엔 안 했습니다(원래 강사에게는 보입니다).
