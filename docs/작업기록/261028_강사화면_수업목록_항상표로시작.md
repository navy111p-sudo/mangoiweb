# 강사 화면 «오늘의 수업» — 열 때마다 표(매니저 화면처럼)로 시작

- 날짜: 2026-10-28
- 작업자: Claude (사장님 지시 「teacher page 에서 표로 나오는게 default 로 나오게 해줘」)

- 앞선 작업: [261026_강사화면_수업목록_표보기_매니저처럼.md](261026_강사화면_수업목록_표보기_매니저처럼.md) (#1811 표 신설 · #1815 폰도 표로 시작)

## 1. 왜 했나

사장님 화면 캡처(PC)에서 «보기» 상자가 「표 (매니저 화면처럼)」에 **방금 고른 포커스 테두리**가 있었습니다 —
열었을 때는 카드였고 손으로 표로 바꾼 것입니다.

코드상 기본값은 #1815 부터 이미 `'table'` 이었습니다. 그런데 **고른 값을 기기에 기억**해서
(`localStorage['mangoi_teacher_class_view']`), 한 번이라도 「카드」를 고른 기기는 **기본값을 무시하고 계속 카드로** 열렸습니다.
#1815 작업기록 5장에 「저장값이 «cards» 인 강사는 계속 카드로 보입니다」라고 이미 적혀 있던 바로 그 상태입니다.

## 2. 무엇을 바꿨나

`cloudflare-deploy/public/teacher.html` 보기 블록 한 곳.

| 전 | 후 |
|---|---|
| 저장값(`cards`/`table`)이 있으면 그것으로 시작 | **언제나 표로 시작** |
| 「보기」를 바꾸면 기기에 저장 | 저장하지 않음 — 카드는 **그 화면에서만**, 새로 열면 다시 표 |
| — | 옛 저장값(`mangoi_teacher_class_view`)은 열 때 지움(쓰레기 키 정리) |

- 「카드」로 바꾸기 자체는 그대로 됩니다(그 자리에서 다시 그림).
- 「상세 숨기기」(`mangoi_teacher_cls_lite`)·「시간 정렬」(`mangoi_teacher_time_sort`)의 기억은 **그대로** 둡니다 — 지시 범위 밖.
- 폰(<900px)에서 «표» 는 #1825 의 «수업당 격자 상자» 로 그려지는 것이 원래 설계입니다(바꾸지 않음).

## 3. 검토했다가 버린 방법

- **저장 키 이름만 바꿔(`…_v2`) 한 번만 초기화** — 버렸음. 지금 모든 기기가 표로 돌아오긴 하지만, 누군가 카드를 한 번 고르면
  그 기기는 다시 «카드가 기본» 이 됩니다. 이번 제보가 정확히 그 경로(한 번 고른 카드가 남음)였으므로 같은 일이 되풀이됩니다.
- **카드 보기를 아예 없애기** — 버렸음. 지시는 «기본값» 이지 «카드 삭제» 가 아니고, 카드에만 있는 «상세 숨기기» 를 쓰는 강사가 있을 수 있습니다.
- **기본값이 표라는 사실만 안내하고 코드는 그대로** — 버렸음. 강사마다 기기에서 직접 바꿔야 해 사장님 지시(«기본으로») 를 못 지킵니다.

⚠️ 대가: 카드를 좋아하는 강사는 **열 때마다 한 번씩** 「카드」를 골라야 합니다. 그 선택을 다시 기억하게 하려면 2장 표의 «전» 으로 되돌리면 됩니다(사람이 정할 일).
