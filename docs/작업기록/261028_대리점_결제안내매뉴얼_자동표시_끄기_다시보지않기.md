# 대리점 관리자페이지 — 결제 안내 매뉴얼 (화상영어 수업료 카드를 열면 먼저 표시 · 끄기 / 다시 보지 않기)

- 날짜: 2026-10-28
- 작업자: 사장님 요청 · Claude
- 브랜치: `claude/agency-payment-guide`

## 1. 왜 했나
- 사장님: 「대리점 관리자페이지 로그인하고 들어가면 적당한 자리에 결제 안내메뉴얼 버튼을 만들어서 거기 열면 보이게 해줘」
  → 「결제 페이지 PC와 모바일 열면 바로 먼저 보이게 하고 밑에 끄기와 다시보지 않기 버튼」
  → 「이미 되어있는지 확인하고 안되어 있으면 설치해줘」.

## 2. 이미 있었나 (확인한 것)
- 대리점 계정의 착지 화면은 `/manager`(`public/manager.html`) — `src/index.ts` `managerPortalRedirect()` 가 agency 를 보낸다.
  지사장(branch)은 `/branch` 지만 결제 카드가 대리점 전용이라 대상이 아니다.
- 결제 카드는 둘이다: 「화상영어 수업료 결제」(`c-tuition`) · 「AI 컨텐츠 결제」(`c-aibill`).
- **작업 도중(17:13 KST) 다른 세션이 같은 요청을 «AI 컨텐츠 결제» 카드에만 먼저 병합했다 — #1853.**
  그림 안내서(`#aibGuide`, 사진 6장) + 카드를 열면 먼저 뜸 + 끄기/다시 보지 않기(`mangoi_aibill_guide_off`) + 카드 안 「📖 결제 방법 보기」.
- 그래서 «안 되어 있던 것» 은 ① 화상영어 수업료 카드의 안내 ② 첫 화면·메뉴에서 여는 버튼 — 이 둘이었다.
- 같은 날 #1847 이 자료실에 «A.i 컨텐츠 결제 안내서» PDF(한/영)를 올렸다 — 매뉴얼 AI 칸에서 인쇄용으로 잇는다.

## 3. 무엇을 바꿨나 (`public/manager.html` 한 파일 — #1853 코드는 한 줄도 안 건드림)
- `<dialog id="payGuide">` «📘 결제 안내 매뉴얼» — 💳 화상영어 수업료 5단계 · 🤖 AI 컨텐츠 결제(한 문단 + **#1853 그림 안내서 열기 버튼** + PDF) · «결제가 안 될 때» 3줄.
  문구는 수업료 카드(`paintTuition`)가 실제로 그리는 버튼·안내 이름을 그대로 쓴다. **금액·단가 숫자는 안 적었다**(서버가 정한다).
- 자동 표시: `c-tuition` 의 `ontoggle` 이 `payGuideAuto()` 를 부른다 — 한 화면에 한 번. PC·휴대폰 같다.
  - [끄기] = 이번만 닫음(새로 열면 다시 뜸) · [다시 보지 않기] = `localStorage mangoi_payguide_hide_v1='1'`(이 기기).
  - 토스에서 돌아온 화면(`?tui_paid`·`tui_fail`·`aib_paid`·`aib_fail`)은 자동 표시 안 함 — 카드가 저절로 열려 결과 문구를 보여 주는 순간이라.
    그 주소를 메인 스크립트가 지우기 «전» 에 읽어야 해서 매뉴얼 스크립트를 메인 스크립트 «위» 에 뒀다.
- AI 컨텐츠 카드는 **#1853 그림 안내서만** 자동으로 뜬다 — 이 매뉴얼은 거기서 안 뜬다(한 카드에 창 두 개 금지).
- 다시 여는 버튼: «자주 쓰는 기능» 맨 앞 · ☰ 메뉴 정산통계관리 · 수업료 카드 안 「📖 결제 방법 보기」(#1853 의 `.aib-guide-link` 모양·이름을 그대로 써 두 카드가 같아 보이게).
  앞의 둘은 `paintMonth()` 가 결제 카드와 **같은 판정**(`sc.type === 'agency'`)으로 보이게 한다.
- 설계 계약 유지: 외부 리소스 0 · 서버 호출 0(첫 화면 API 2회 그대로) · 애니메이션 0 · 한/영은 `data-ko`/`data-en`.

## 4. 검토했다가 버린 것
- **AI 카드에도 이 매뉴얼을 자동으로 띄우기**(첫 판) — #1853 이 먼저 병합돼 그대로 두면 한 카드에서 창이 두 개 뜬다. 그림 안내서가 더 자세해 그쪽에 맡겼다.
- **#1853 안내서를 고쳐 하나로 합치기** — 공동 유지보수자의 방금 병합된 작업이라 손대지 않았다. 매뉴얼 AI 칸에서 «여는» 것으로만 잇는다.
- **상단 바(결재함·홈 옆)에 버튼** — 휴대폰에서 상단 바가 이미 세 줄로 접혀 있어 버튼 하나가 또 한 줄을 만든다. «자주 쓰는 기능» 칩으로.
- **로그인하자마자 첫 화면에서 띄우기** — 결제와 상관없는 일(출석·명부)로 들어온 원장님을 매번 막는다. 지시도 «결제 페이지를 열면» 이다.
- **저장소가 막힌 기기용 메모리 표시(neverMem)** — 변이시험에서 지워도 검사가 통과해 따져 보니, «다시 보지 않기» 는 창이 열린 뒤에만
  누를 수 있고 그때 이미 `shown` 이 서 있어 **같은 일을 두 번 하는 코드**였다(등가 변이). 지웠다. 막힌 기기는 다음 화면에서 다시 뜬다(하니스가 그것을 «약속» 으로 못 박음).
