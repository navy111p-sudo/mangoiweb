# 📵 번호 없는 학생 — 목록 + 그 자리에서 번호 넣기 (2026-10-28)

## 1. 왜 했나

같은 날 ① 에서 «수업 30분 전 안내 문자» 가 9/20 부터 멈춰 있던 원인(여러 줄 `DB.exec` 로 표가 안 생김)을 고쳤습니다.
그런데 표가 생겨도 **받을 번호가 없는 학생에게는 원리상 안 나갑니다.** 그래서 «누가 번호가 없는지» 를 보여 주고
그 자리에서 넣게 하는 칸을 만들었습니다(사장님 「2번 진행하고 병합하고 배포까지 해줘」).

### 잰 것 (2026-10-28 운영 D1 — SELECT 만)

| 항목 | 값 |
|---|---|
| 다음 7일 수업이 있는 학생 | **252명**(같은 날 다시 재니 254명) |
| 그중 발송 정본(`phonesForStudent`)으로 번호가 잡히는 학생 | **12명** |
| 못 잡히는 학생 | **240명(95%)** |
| 그 240명 중 카페24 이탈위험 표(`student_retention`)에만 번호가 있는 학생 | **49명** |
| 리마인더의 «login_id 로 한 번 더» 폴백으로 늘어나는 학생 | **0명** |

### 그래서 내린 판단

- 숫자는 **발송 정본**으로 셉니다. 표시 정본(`loadContactPhones`, 이탈위험 표까지 봄)으로 세면 61명이 «받는다» 로 부풀어 보입니다.
- 이탈위험 표 번호는 **누구 번호인지(학생/학부모) 그 표에 없습니다.** 그래서 «참고» 로만 보여 주고 칸에 자동으로 넣지 않습니다.

## 3. 검토했다가 버린 방법

- **표시 정본(`loadContactPhones`)으로 세기** — 61명이 «받는다» 로 나와 실제(12명)보다 부풀어 보입니다. 버림.
- **이탈위험 번호를 칸에 미리 채우기** — 누구 번호인지 몰라 학생 번호를 학부모 칸에 넣는 사고가 납니다. «참고» 글자로만.
- **수업 판정을 새로 짜기** — 리마인더와 한 글자만 어긋나도 «목록엔 없는데 문자는 안 가는» 학생이 생깁니다. 리마인더 블록을 하니스가 오려 내 무작위로 대조합니다.
- **표(table)로 그리기** — 칸 7개가 1,081px 를 요구해 PC(1440 창, 실제 칸 624px)에서 [💾 저장]이 상자 오른쪽 밖으로 밀렸습니다(브라우저 실측 x 1788 > 창 1440). 줄 상자(flex-wrap) 두 덩이로 바꿈.
- **역할 숨김을 인라인 `display:none` 으로** — PC 에서 `#legacy-cards details{display:block!important}` 가 이깁니다(실측: 인라인 none · 계산값 block). `.rbac-hide` 로.
- **`manager.html` 에도 붙이기** — 그 화면은 «외부 스크립트 0개» 계약이라 두 벌을 만들어야 합니다. 이번엔 관리자 화면만(아래 6장).

- 한 줄을 저장하면 목록을 다시 불러 통째로 다시 그리는데, 그때 **아직 저장 안 한 다른 줄의 입력이 지워졌습니다.** 다시 그리기 전에 읽고 그린 뒤 되살립니다(언어 바꾸기·기간 바꾸기도 같음).
