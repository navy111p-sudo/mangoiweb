## 2. 무엇을 바꿨나

- **공용 창** `cloudflare-deploy/public/js/eval-quick-view.js` (세 화면이 «누를 때만» 받는 파일, `?v=2 → 3`)
  - `mgEvalQuick(id, { edit:true })` — 보기를 건너뛰고 **곧장 고치기 화면**. 허락(서버 `evalEditAllowed`)이 없으면 보기 화면 + «보기 전용» 이유.
  - `mgEvalQuick.create(ctx, opts)` — **빈 칸에서 새로 쓰기**. 영어 메모 → 「🇰🇷 한국어로 만들기」(강사 일지와 같은 `/api/translate mode='note'`) → 학부모용 한국어 → `POST /api/eval/manual-create`.
    - 오늘: 그 수업 방 번호·날짜. 「📲 학부모에게 문자도 보내기」 체크(기본 **꺼짐**).
    - 지난: **날짜를 고른다**(기본값 = 이번 주 요일 칸으로 짐작한 바로 전 수업일, 틀리면 바꿈). 방 번호 = 오늘 방의 예약 번호 + 그 날짜(`class-<예약>-<YYYYMMDD>`). 문자 칸 없음.
- **관리자 표** `js/adm-today-classes.js` `xEvalAct` (`?v=54 → 55`) + 색 `css/admin-inline-c.css` 맨 끝(`?v=84 → 85`)
- **매니저** `manager.html` `evAct` + 끝 스크립트(IIFE 안 목록은 `window.taEvalHook` 으로 찾음)
- **강사** `teacher.html` `extrasHtml` 의 «➕ 지난 피드백 추가» (오늘 쓰기·고치기는 기존 버튼 그대로)

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **«지난 추가» 를 방 번호 없이 날짜만으로 저장** → 버림. 서버 `pickEvals` 의 «오늘» 규칙이 «오늘 쓴, 방 없는 글» 을 오늘 평가로 잡아 **지난 피드백이 오늘 칸에 뜬다**.
- **방 번호만 붙이고 서버는 그대로** → 버림. 옛 규칙은 «지난 = 이 날짜 전에 *쓴* 것» 이라, 오늘 쓴 지난 수업 글은 **어느 칸에도 안 보였다**. 그래서 «수업일» 기준으로 고침 — 방 없는 글은 옛 규칙과 수학적으로 같다(`kstYmd(c) < dateStr ⟺ c < dayStartTs`). 덤으로 «수업 다음 날 쓴 강사 일지» 가 안 보이던 것도 풀린다.
- **이전 수업의 정확한 방 번호를 서버가 계산** → 이번엔 안 함. 예약표(요일·날짜 지정·연기·휴강)를 거슬러 «바로 전 회차» 를 정확히 찾는 것은 별개 작업이다. 화면이 짐작하고 사람이 날짜를 고치게 했다.
- **매니저가 쓴 글의 `teacher_uid` 를 수업 강사로 채움** → 버림. «누가 썼나» 가 거짓이 된다. 관리자·매니저 화면에서 쓴 글은 `teacher_uid` 가 비고(→ 본사만 고침), 강사 화면에서 쓴 글은 그 강사 아이디(→ 그 강사도 고침). `teacher_name` 은 수업 강사.
- **매니저 추가 시 학부모 문자 자동 발송** → 버림(기본 꺼짐). `api-lessons.ts` create 주석이 이미 «관리자 화면이 저장할 때마다 문자가 나가면 안 된다» 고 정해 둠. **지난** 에는 아예 문자 칸이 없다 — 문자 본문이 「오늘 수업 일지가 도착했어요」라 거짓 문자가 된다.
- **점수(별점) 입력** → 넣지 않음. 별점은 강사 일지 창의 몫이고 비우면 평균에서 빠진다.
- **강사 화면의 «📄 보기 / 수정» 을 «✏️ 고치기» 로 바꿈** → 안 함. 이미 보기·고치기 둘 다 되는 링크라 버튼을 하나 더 두면 중복이다. 강사 화면에서 빠져 있던 것은 «지난 추가» 하나였다.
- **버튼을 `xEval`(칸 내용) 안에 넣음** → 버림. `xEval` 은 정렬값(`tcSortVal`)에도 쓰여, 버튼 글자가 섞이면 «빈 칸은 맨 뒤» 정렬이 깨진다.
- 버튼 속성을 `data-evq-edit` 로 → 버림. 공용 창 안의 «✏️ 고치기» 가 같은 이름을 써서 문서 위임 클릭이 그것까지 잡는다 → `data-evq-fix` / `data-evq-new`.

## 5. 남은 것 / 주의할 것

- «지난 추가» 의 날짜는 **짐작**이다(이번 주 요일 칸 → 없으면 지난주 마지막 수업 요일 → 칸이 없으면 일주일 전). 요일마다 예약 번호가 다른 학생은 방 번호가 그날 실제 방과 다를 수 있다 — 그래도 «지난 피드백» 칸에는 뜨지만, 그날 강사 화면의 «일지 씀» 표시는 안 바뀐다.
- 관리자·매니저 화면에서 쓴 글은 `teacher_uid` 가 비어 **강사는 못 고친다**(본사 매니저만). 바꾸려면 서버가 «쓴 사람» 칸을 따로 가져야 한다.
- 함정 1건을 `CLAUDE.md` 2장에 추가: teacher.html 함수 사이에 넣은 리스너가 하니스 `fn()` 조각에 딸려 들어가 옛 리스너를 덮음.
