# 화면 쪽 말 빠르기 — «부탁» 일 때만 바꾸기 (2026-10-28)

> 사장님 「화면 쪽 말 빠르기도 고쳐줘」. 같은 날 서버 쪽 «다시 말해 달라» 판정(PR #1871·#1874·#1876·#1880)을 고칠 때
> `docs/작업기록/261028_AI영어친구_같은질문_두번금지.md` 8절 «별건 — 화면 쪽 듣기 속도(이번에 안 고침)» 로 남겨 둔 것입니다.

## 1. 왜 했나

AI 영어친구(`public/ai-friend.html`)와 웜업(`public/warmup.html`)은 학생이 말한 문장을 보고 **읽어 주는 속도를 한 칸씩** 바꿉니다
(`maybeAdjustRate`). 그런데 판정이 **낱말 하나**였습니다.

```js
const slower = /(천천히|느리게|너무\s*빠르|못\s*알아|알아듣기)/.test(t)
            || /\b(slow(ly| down)?|too fast|more slowly|speak slower)\b/i.test(t);
const faster = /(빠르게|더\s*빨리)/.test(t) || /\b(faster|speed up)\b/i.test(t);
```

그래서 «부탁» 이 아니라 **대답** 에도 속도가 움직였습니다.

- 「A snail is slow.」(엘리더잼 모범 답) → 느려짐
- 「빠르게 달려요」·「My dog runs faster.」 → 빨라짐
- 「Talk slowly.」(엘리더잼 «도서관에서는 어떻게 말해요?» 의 답) → 느려짐
- 「말이 너무 빨라요」(동물 말) → 느려짐

[잰 것] 하니스의 «대답» 표본 86개 가운데 **47개**에서 옛 판정이 속도를 바꿨습니다.

## 2. 무엇을 했나

### 2-1. 판정을 한 파일로 — `public/js/speech-rate-request.js`(새 파일, `?v=1`)

- `window.MangoiRateRequest.judge(text)` → `'slower'` · `'faster'` · `''`.
- **느리게** = 두 갈래 중 하나.
  1. 서버 정본(`src/question-memory.ts`)의 «다시 말해 달라» 판정(`QM_REASK_KO`·`QM_REASK_EN`·`QM_REASK_ECHO`)이 «부탁» 이라 하고,
     그 안에 «빠르기» 를 뜻하는 말(천천히·느리게·너무 빨라·못 알아·slow·too fast)이 있을 때.
  2. **화면 전용 보강 줄(`SLOW_EXTRA`)** — 정본은 «다시 말해 달라» 를 재는 것이라 일부러 좁습니다(오판 = 같은 질문 반복).
     화면의 오판은 «한 칸 느려짐 + 버튼으로 되돌림» 이라 대가가 작아서, 정본이 안 받는 «빠르기 부탁» 몇 모양을 여기서만 더 받습니다 —
     「It's too fast」·「Okay, too fast」·「Slow down teacher」·「I don't understand, slow down.」·「Can you read slowly?」·「Say it slowly」·
     「천천히 말하세요」·「천천히 부탁해요」·「선생님 너무 빨라요」·「속도 좀 줄여 주세요」.
     ⛔ 그래도 정본이 «대답» 으로 둔 것(「Talk slowly.」·「Speak slowly」·「말이 너무 빨라요」)은 받지 않습니다 — 맨 앞·부름말·이유·please 가 있을 때만.
- 판정 전에 한 번 다듬습니다 — 「pls/plz」 → please · 「좀만」 → 조금만 · 「살짝」 → 조금.
- **빠르게** = 같은 원칙(부탁 어미·부탁 자리·그 말만)으로 따로 만든 세 줄.
  - 한국어: «빨리/빠르게 + 말·말씀·얘기·읽어 + 부탁 어미»(「빨리 말해 줘」·「빠르게 읽어 주세요」), 「속도 좀 올려 주세요」, 그 말만(「더 빨리요」·「좀 빨리」·「빠르게요」·「너무 느려요」).
  - 영어: «부탁 자리»(you·please·teacher… 뒤의 「speak faster」, 「faster, please」), 「You talk too slow(ly)」, 그 말만(「Faster!」·「Faster faster!」·「Read faster」·「Too slow」).
  - ⛔ 말하는 동사가 없으면 안 받습니다 — 「숙제를 빨리 해 주세요」·「빨리 와 주세요」·「빨리 해 줘」 는 말 빠르기가 아닙니다. 앞말 없는 「빨리」·「빨리요」 도 대답일 수 있어 안 받습니다.
  - ⛔ 「speed up」 은 뒤에 목적어가 오면 안 받습니다 — 「Please speed up the car? No.」(자동차 이야기 속 대답).
  - ⛔ 「You're too slow」 처럼 «말하기» 가 없는 꼴은 안 받습니다 — 「You're too slow at running.」·「You are too slow, I win!」.
- 둘 다 걸리면 **느리게가 이깁니다**(예전과 같은 순서).
- 1,000자 넘는 말은 보지 않습니다(서버 `QM_REASK_MAX_LEN` 과 같음). 글자가 아닌 값(배열·객체)은 «바꾸지 않음».

### 2-2. 서버 정본 세 줄을 «글자 그대로» 복사

화면은 브라우저라 `import` 를 못 씁니다. 그래서 정본 세 줄을 그대로 복사하고, 하니스 ②가 **두 파일의 정규식 원문을 직접 대조**합니다.
정본 쪽(`question-memory.ts`)에도 «화면 사본이 있다 — 여기를 고치면 그 파일도, ?v= 도» 를 적어 두었습니다.

### 2-3. 정본에서 함께 고친 빈틈 — «좀 더 천천히요»

정본 ECHO 줄이 앞말을 **하나만** 받아(`(?:좀|더|조금만?|다시)\s*)?`) 「좀 더 천천히요」·「조금만 더 천천히」 를 놓쳤습니다.
`{0,2}` 로 바꿨습니다 — `src/question-memory.ts` 와 그 사본인 `src/api-ai.ts`(`aiFriendIsMetaAsk`) **두 곳**.
`ai_friend_no_repeat_question_harness` 의 «요청» 목록에 다섯 줄을 더했습니다(128 / 0).

⚠️ **이 변경은 «천천히» 만이 아닙니다** — 같은 자리가 `(?:천천히|느리게|쉽게|짧게|간단히)` 를 받으므로 [잰 것] 「좀 더 짧게요」·「좀 더 쉽게요」 도
이제 서버가 «다시 말해 달라» 로 봅니다(웜업·엘리더잼·AI 영어친구 — 그때 그 질문을 «아직 안 다룬 것» 으로 둠). 뜻으로 맞는 방향이지만
지시 범위 밖에 닿는 것이라 따로 적어 둡니다. 「좀 더 크게요」 는 그 자리에 «크게» 가 없어 그대로입니다.

### 2-4. 두 화면

- `<script src="/js/speech-rate-request.js?v=1">` 를 `speech-preferences` 바로 뒤에.
- `maybeAdjustRate` 는 판정을 «부르기만» 합니다. **판정 파일을 못 읽었으면 속도를 그대로 둡니다**(슬라이더·버튼으로는 계속 바꿀 수 있음).

## 3. 검토했다가 버린 방법

- **옛 정규식에 «답» 예외를 덧붙이기** — 「snail is slow」 류를 하나씩 빼면 끝이 없고, 서버와 화면이 서로 다른 말을 하게 됩니다.
- **화면이 서버 판정을 API 로 묻기** — 말할 때마다 요청이 하나 더 나가고, 속도가 «다음 답» 부터 바뀌어 늦습니다.
- **빠르게 쪽도 정본(«다시 말해 달라»)으로 판정** — 정본은 «다시» 에 관한 것이라 「빨리 말해 줘」 를 받지 않습니다.
- **화면 전용 보강을 정본에 넣기** — 서버에서는 오판이 «같은 질문 반복» 이라 대가가 커서 정본을 넓히지 않았습니다(화면만 넓힘).
- **`\s*해?\s*` 꼴 · `(?:천천히\s*){2,3}…[^\p{L}\p{N}]*$` 꼴** — 둘 다 긴 공백 입력에서 제곱 시간입니다(아래 4절). 같은 글자를 먹는 두 덩어리를 나란히 두지 않게 고쳤습니다.

## 5. 못 잰 것

- **진짜 음성인식이 학생 말을 어떻게 받아 적는지** — 하니스는 «받아 적힌 글자» 를 넣어 봅니다. 띄어쓰기가 달라져도 걸리게 했지만, 오인식된 글자까지는 모릅니다.
- **실제 화면에서 소리가 한 칸 느려지는 것** — 가짜 `applyRate`/`setRate` 가 «한 번 불렸다» 까지만 봅니다. 사람이 말해 봐야 확정입니다.

## 6. 일부러 그대로 둔 것 · 알고 둔 한계

- 「Talk slowly.」·「Slowly.」·「Slow.」·「Speak slowly」 — 엘리더잼 답이라 속도를 안 바꿉니다(서버도 같은 판단).
- 「너무 빨라요」(그 말만) — 부탁으로 봅니다(서버와 같음). 동물 얘기 중이면 한 칸 느려질 수 있지만 해가 적습니다.
- [잰 것] 「엄마가 너무 빨리 말해요」 → 느려집니다 — 정본 KO 줄이 «너무 빨리 말» 을 문장 어디서나 받기 때문입니다(서버도 «다시 말해 달라» 로 봅니다).
- [잰 것] 「다시 말해 줘. 거북이는 느리게 가요」 → 느려집니다 — 앞 문장이 «부탁» 이고 «빠르기 낱말» 을 문장 전체에서 찾기 때문입니다(옛 판정도 같았습니다).
- 「\p{L}」 를 쓰려고 `/u` 가 필요합니다 — 그 문법을 모르는 아주 옛 브라우저(크롬 64·사파리 11.1 이전)는 이 파일만 못 읽고 «속도 그대로» 로 동작합니다.
