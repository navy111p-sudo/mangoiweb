# A.i 말하기 연습 — 정직한 칭찬 · 교정 모드 3가지 (2026-10-29)

## 왜 했나
강남캐피 원장님 제보: 틀린 문장·몇 단어만 말해도 AI 가 «It's great!» 이라고 하고 팡파레가 울린다.
교정 카드는 «틀렸다» 고 하는데 목소리는 «잘했다» 고 해서 서로 어긋나고, 고친 문장을 따라 말하는 흐름도 없다.
사장님이 «AI말하기연습 교정모드 제안서»(PDF)를 주시며 «이거대로 해줘». 같은 날 «3가지 옵션을 처음 페이지에 보이게, 고를 수 있게».

## 원인 (코드에서 확인)
- 팡파레: `warmup.html` 의 `sendMsg` 가 **보낼 때마다** `bumpCombo()` → 3·5·7·10… 콤보면 팡파레. 맞았는지와 무관.
- 칭찬: 웜업 프롬프트 [칭찬] 규칙(`src/index.ts`, 공동 금지구역)이 That's great!/Perfect! 를 예로 든다.
