## 1. 왜 했나

사장님이 관리자 › 학생 › 학생 목록 화면을 캡처해 주셨습니다. 요청은 「학생을 단체로 등록할 수 있는 양식이나 엑셀이 없다. 여러 명을 한 번에 등록하는 기능이 필요하다」였습니다.
그 화면에는 「➕ 학생 등록」(한 명씩)만 있었습니다. 수강신청 쪽에 «일괄 등록»이 있지만 그것은 «수강신청»을 만드는 기능이고, 학생 «계정»을 만들지는 않습니다.

## 2. 무엇을 바꿨나

| 파일 | 내용 |
|---|---|
| `cloudflare-deploy/public/js/adm-student-bulk.js` (새 파일, `?v=1`) | 단체 등록 모달 전부. 양식 CSV 받기 · `.csv`/`.xlsx` 읽기 · 엑셀 표 붙여넣기(TSV) · 미리보기 검사 · 한 줄씩 등록 · 결과 CSV 받기 |
| `cloudflare-deploy/public/admin.html` | 학생 목록 도구 줄의 「✏️ 정보 수정」 **뒤**에 `#sm-bulk-student` 버튼, 그리고 `<script src="/js/adm-student-bulk.js?v=1" defer>` |
| `test-harness/student_bulk_register_harness.mjs` (새 파일) | 파일을 `node:vm` 에서 실제로 실행해 읽기·검사 함수를 돌림(23종) |
| `test-harness/asset-versions.json` | 새 `?v=1` 원장 한 줄 |

화면 흐름:
1. **📄 양식 받기(CSV)**: 머리글은 `아이디(필수),이름(필수),비밀번호,학생전화,학부모전화,소속학원,메모`이고 예시 두 줄이 들어 있습니다. UTF-8 BOM 을 붙여 엑셀에서 한글이 깨지지 않습니다.
2. 파일을 고르거나 표를 붙여넣고 **🔍 미리보기**를 누릅니다.
   - 머리글 이름으로 칸을 찾으므로 순서가 달라도 됩니다(별칭 표 `FIELDS`).
   - 머리글이 없으면 양식 순서로 읽습니다.
3. 줄마다 검사합니다. 아이디 4~20자 · 영문·숫자·`_` · 이름 필수 · 비밀번호 4자 이상 · 파일 안 아이디 중복(대소문자 무시). 걸린 줄은 빨간색으로 표시하고 등록하지 않습니다.
4. **✅ N명 등록**을 누르면 한 줄씩 등록하고 진행 상황을 보여 줍니다.
5. 서버가 `possible_duplicate`(같은 이름+같은 번호)라고 답하면 그 줄은 «확인 필요»로 남깁니다. 그 줄의 「그래도 등록」을 눌러야만 `force:true` 로 다시 보냅니다.
6. **📥 결과 받기**: 아이디·이름·비밀번호를 CSV 로 받습니다. 임시 비밀번호는 서버가 해시만 저장해서 다시 볼 수 없기 때문에 둔 버튼입니다.

그 밖의 처리:
- 엑셀이 숫자로 바꾸며 지운 전화번호 앞자리 0 은 되살립니다(`1012345678` → `01012345678`).
- 한 번에 300명까지만 받습니다.
- 401·403 이 오면 거기서 멈춥니다. 권한이 없는데 나머지 줄을 계속 보내지 않으려는 것입니다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **새 서버 경로(`POST /api/admin/students/bulk-create`)를 만들기** → 버렸습니다.
  - 새 `/api/admin/*` 경로는 `src/index.ts` 라우팅 허용목록에 한 줄을 넣어야 하는데, 그 파일은 공동 금지구역입니다.
  - 더 큰 이유는 판정이 두 벌이 된다는 점입니다. 아이디 규칙·대소문자 중복·`duplicateGate`·비밀번호 해시(학생용 솔트)·본사 전용 권한을 새 경로에 복제하면 언젠가 한쪽만 고쳐집니다.
  - 그래서 «한 명 등록»과 **같은** `POST /api/admin/students/create` 를 한 줄씩 부르게 했습니다. 서버는 한 글자도 고치지 않았습니다.
  - 대가는 속도입니다. 매 요청마다 그 라우트의 `CREATE TABLE IF NOT EXISTS` + 지연 ALTER 가 돕니다. 수십~수백 명이면 수십 초가 걸리고, 그래서 진행 표시를 붙였습니다.
- **SheetJS 같은 엑셀 라이브러리 쓰기** → 버렸습니다. 외부 CDN 의존이 늘어납니다(중국 회선).
  - `.xlsx` 는 zip 이라 브라우저 기본 `DecompressionStream('deflate-raw')` 으로 직접 풉니다. `sharedStrings`·`inlineStr` 를 처리하고, 첫 시트는 `workbook.xml` + rels 로 찾습니다.
  - 옛 `.xls`(바이너리)는 읽지 않고 「CSV UTF-8 로 저장해 올려 달라」고 안내합니다.
- **양식을 진짜 `.xlsx` 로 만들어 주기** → 버렸습니다. zip 쓰기 코드가 더 필요한데, CSV 도 엑셀에서 그대로 열리고 다시 저장할 수 있어 충분하다고 봤습니다.
- **`possible_duplicate` 를 자동으로 `force:true` 로 보내기** → 버렸습니다. 2026-09-14 정예희(yahee·yahee1·yahee2) 사고를 막으려고 넣은 «묻기» 를 단체 등록이 우회하게 됩니다. 한 명 등록과 같이 사람이 줄마다 고르게 했습니다.
- **버튼을 「➕ 학생 등록」 바로 옆에 두기** → 옮겼습니다. `student_contact_edit_harness` 가 「✏️ 정보 수정」이 「학생 등록」 옆(1,600자 안)에 있는지 보는데, 그 사이에 넣으니 그 검사가 FAIL 했습니다. 그 자리는 사장님이 정한 자리라 «정보 수정» 뒤로 옮겼습니다.
