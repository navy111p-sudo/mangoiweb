# Eric 수업 제보: 교재·필기·오디오·가상배경

2026-10-30. 제보: 영상/가상배경 지연, 잡음 제거/사무실 모드 이상, 다른 책을 열면 이전 책 접근 불가, 페이지를 넘기면 필기 소실, 강사 안내 부족.

## 변경

- 이미지 교재는 한 장이 한 파일이다. `pdfLoad`가 URL 변경마다 필기를 비워 이전 이미지로 돌아와도 사라졌다. 방 + 정규화 URL별 메모리 저장으로 분리·복원한다. 새 파일에 이전 필기를 그리지 않는다. 새로고침을 넘는 보존은 추가하지 않았다.
- 교재 도구 줄에 이번 수업에서 연 책 목록을 둔다. 각 책의 마지막 파일, 시퀀스와 PDF 페이지를 복원한다. 배정 교재의 최초 자동 공유도 기억한다. 학생의 교재 제어 권한은 넓히지 않는다.
- 텍스트 입력은 Enter 뒤 blur가 따라와도 한 번만 저장한다. 파일을 바꾸기 전에 입력 중인 글을 확정한다. 늦게 끝난 파일 로드가 최신 문서를 덮지 않게 한다.
- 사무실 모드의 마이크/잡음 변경 wrapper는 실제 입력을 복원한 뒤 기존 설정 함수를 실행한다. 종전에는 WebAudio 출력(실제 deviceId 없음)을 읽어 선택한 마이크가 바뀌거나 끝난 트랙을 다뤘다. 사무실 모드 재연결과 끄기도 사용자가 고른 잡음 제거 값을 유지한다.
- 가상배경의 다음 RAF를 추론 완료 뒤가 아니라 추론 전에 예약한다. sending 가드로 동시 추론은 막고, 이미 처리한 카메라 프레임은 건너뛴다. 최초 프레임 처리를 마친 뒤 루프를 시작해 초기 동시 send도 막는다. 네트워크나 모든 영상 지연을 해결했다고 단정하지 않는다.
- 기존 수업 사용법 그림에 한/영 5단계 확인과 전체 강사 매뉴얼 링크를 덧붙였다. Krisp는 웹사이트만 여는 것이 아니라 실행 중인 가상 마이크를 선택하도록 안내한다.

## 검토한 대안

- 필기를 하나의 페이지 번호 객체로 유지: 이미지 교재는 모두 1페이지라 다른 장의 필기가 섞인다.
- 교재를 localStorage에 영구 보존: 다른 학생·수업에 내용이 남는 범위를 넓힌다. 이번 변경은 방별·탭 메모리만 쓴다.
- 가상배경을 기본으로 끄기: 요청한 기능 자체를 없애므로 적용하지 않았다. 기존 품질·자동 복구 정책을 유지했다.
- 배포 설정/도메인 변경: 필요하지 않다. Cloudflare API로 mangoi.ai와 www가 webrtc-unified-platform-prod에 붙은 것을 읽기 확인했다.

## 검증

- TypeScript `node node_modules/typescript/bin/tsc --noEmit`: 통과.
- `vc_eric_class_harness`: 실제 배포 함수로 파일별 필기 격리·복원·지우기, 상대/절대 URL, 늦은 로드, 추론 중 RAF, 이전 책·PDF 페이지 복원, 학생 권한 검사.
- `vc_office_recovery_harness`: 16개 통과. 실제 잡음 설정 함수와 사무실 모드 IIFE를 함께 실행해 선택한 장치·음소거·잡음 설정 유지 확인.
- 기존 교재 영상/오디오 20개, 교재 따라가기 13개, 교재 권한 64개, 사무실 게이트 13개: 통과.
- 첫 화면 blocking 예산: 통과. 변경 JS 4개 직접 `node --check`: 통과. 캐시 버전 해시 294개 통과, sparse checkout에서 생략한 vendor 4개는 없음 경고.
- 로컬 Chrome에서 실제 배포 스크립트를 실행: A/B 교재 전환 뒤 A의 텍스트 복원, 두 책 목록, Enter+blur 1회 저장, 강사용 영어 도움말 렌더 확인. 테스트용 문서만 사용했다. 실수업/실제 마이크·Krisp·필리핀 장치에서의 체감 지연은 아직 확인하지 않았다.
- 로컬 전체 회귀는 sparse checkout에 없는 자료를 읽는 검사에서 실패했고, 하위 프로세스 기반 전수 검사는 진행이 멈춰 중단했다. GitHub CI로 전체 게이트를 확인해야 한다.
