# Eric 수업 수정 후 반복 검증과 추가 수정

2026-10-31. 요청: 샌드박스와 하니스에서 수백 번 검사하고 발견되는 문제를 고칠 것.
기준 소스: main `811bf9e7831f960465083fff2217c5836c26948a`. 실제 운영 방·DB는 테스트하지 않았다.

## 재현해서 고친 문제

1. 현재 교재를 다시 선택하면 마지막 PDF 쪽수 대신 저장 전의 1쪽으로 이동했다. 선택 처리에서 현재 쪽수를 먼저 기억한 뒤 복원할 쪽수를 읽는다.
2. 방이 바뀐 직후 옛 교재 목록을 조작하면 이전 방의 책을 다시 열었다. change 이벤트에서도 방 경계를 확인하고, 유효하지 않은 목록은 즉시 비운다.
3. 이전 방에서 시작한 교재 로드가 늦게 끝나면 새 방의 문서·목록으로 들어왔다. 파일 로드와 교재 선택이 시작된 방을 기억하고, 완료 시 방이 달라졌으면 반영하지 않는다.
4. 사무실 모드에서 잡음 제거를 빠르게 연속 변경하면 앞 요청이 나중에 끝나 마지막 선택을 덮었다. 오디오 설정 요청을 순서대로 처리한다. 마이크 별칭은 실제 `vcSwitchMic`을 거치므로 그 함수만 한 번 큐에 넣어 중첩 대기를 피한다. 마이크 변경 시에도 선택한 잡음 제거 값을 유지한다.
