# A.i 말하기 — 무음 환각과 불확실한 자동 전송 차단

- 날짜: 2026-11-01
- 작업자: Codex
- 브랜치: codex/voice-silence-guard

## 왜 했나

사용자가 아무 말도 하지 않았는데 `Thank you very much for watching.`이 사용자 말풍선으로 나타났다는 제보.
당시 원음·인식 응답은 없으므로 그 세션의 촉발 소리는 확정하지 않았다.

## 바꾼 것

- `public/ai-friend.html`: 자동·버튼 모드 모두 녹음 파일을 공용 `MangoiVoiceCheck`로 검사한 뒤에만 업로드한다. 순간 peak 감지 여부로 검사를 건너뛰지 않는다. 검사 불가도 자동 전송하지 않고 안내한다. 전송 직전에도 같은 검사 결과와 세션 번호를 확인한다.
- `src/api-games.ts`: turbo가 정상 응답으로 빈 결과를 주면 종료한다. AI 친구가 보내는 `strict=1`에서는 인식기 장애 시 구 모델로 떨어지지 않는다. 무음·낮은 신뢰도 결과는 빈 글자로 돌려준다. 기존 음성코치는 약한 발음도 채점해야 하므로 낮은 신뢰도 차단은 strict 요청에만 적용한다.
- `src/stt-confidence.ts`: 제공된 음향 정보만 판정한다. 메타데이터가 없다고 0으로 간주하지 않는다. 낱말 수·특정 문장을 기준으로 차단하지 않는다.
- `src/api-ai.ts`: 모호한 단편은 의미나 취향을 지어내지 말고 짧게 되묻도록 프롬프트 보완.
- 회귀 하니스: 실제 화면 함수와 서버 라우트를 실행한다. 순수 무음·클릭·일정한 잡음·작은 짧은 답변·취소 뒤 도착·빈 결과·구 모델 폴백을 대조한다.

## 버린 방법과 이유

- 특정 문장 금지: 사용자가 실제로 말할 수 있는 문장이고 다른 환각에는 무력하다.
- 질문/정답을 Whisper prompt에 넣기: 발음을 듣지 않고 기대 문장으로 편향될 수 있다.
- peak 임계값만 높이기: 작은 목소리를 잃고 충격음은 여전히 통과한다.
- 공용 녹음기를 모든 화면에서 바꾸기: 다른 화면의 녹음·채점 동작까지 바뀐다. AI 친구의 기존 transcribe 확장 지점을 사용했다.

## 검증

- 타입체크: 통과(exit 0).
- `ai_friend_silence_harness.mjs`: 30건 통과. 외부 AI·운영 DB 호출 없음.
- 인라인 JS 문법: 1,485조각 검사, 오류 0(부분 체크아웃 기준).
- 전체 fast 하니스와 로컬 브라우저: 실행 중. 최종 결과는 후속 기록으로 갱신한다.

## 한계

에너지 기반 검사는 화자 식별기가 아니다. TV 소리나 다른 사람의 실제 음성, 음향 근거가 있는 자신감 높은 오인식까지 완벽히 차단한다고 보장하지 않는다. 실제 사용자 마이크로 무음·작은 목소리·스피커 재생 환경을 확인해야 한다. 운영 배포 여부는 아직 확인하지 않았다.
