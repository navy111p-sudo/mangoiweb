# AI 말하기 입구 통합 (2026-11-01)

## 요청과 결정
사장님이 AI 말하기와 AI 친구하기를 비교한 뒤 추천안으로 작업하도록 요청했다.
홈과 전체 메뉴·공용 사이드바의 입구를 **AI 말하기**로 모으고, `/ai-speaking.html`에서 **교재로 연습하기**와 **AI 친구와 이야기하기**를 고른다.

## 범위와 이유
- 새 입구는 로그인·AI 호출·마이크 요청 없이 목적을 고르는 정적 화면이다. 한국어/영어, PC/모바일을 지원한다.
- `/warmup.html`과 `/ai-friend.html`은 그대로 열리며, 두 화면에 모드 선택으로 돌아가는 링크를 추가했다.
- 수업방에서 room·교재를 지정해 여는 기존 웜업 경로, API, 음성 인식, 교정 기본값, 학습 기록은 변경하지 않았다.
- 두 대화 엔진을 합치는 방안은 버렸다. 서로 다른 사용 목적과 음성 인식에 관한 기존 결정을 유지하기 위해서다.
- 첫 화면에서 무조건 지난 모드로 이동시키는 방안도 쓰지 않았다. 선택권을 유지하고, 실제 이어할 세션 확인 없이 ‘이어서’라고 표시하지 않기 위해서다.
- 공용 사이드바 소비 HTML의 캐시 버전을 함께 올렸다. 이 파일들의 변화는 스크립트 URL 한 줄이다.
- 사이드바 회귀 검사의 옛 독립 `ai-friend` 항목 기대를 통합 입구 `warmup` 코드로 교체했다. 두 목적지와 직접 링크는 새 하니스에서 함께 검사한다.
