## 대화 화면과 질문

휴대폰/태블릿은 대화와 얼굴을 세로로 배치하고, 실제 컨테이너가 넓을 때는 얼굴과 대사를
나란히 둡니다. 얼굴 캔버스에는 `object-fit:contain`을 적용하여 Jake처럼 비율이 다른
캐릭터도 내부 얼굴 비율을 늘리지 않습니다. 짧은 대사는 대비가 높은 반투명 판에,
긴 문장은 확대 패널에 표시합니다. 터치 바의 기존 도움·마이크·글쓰기를 유지하고
직접 질문 버튼을 추가했습니다. 헤더와 입력 줄은 확대 시 줄바꿈하며 시각 뷰포트 높이를
반영합니다. 공간이 부족하면 대화 영역을 스크롤하며 기능을 제거하지 않습니다.

질문은 기존 `/api/ai/class-ask`를 사용합니다. 기본 영어 `en/ko` 응답은 유지하고 선택적인
중국어 요청에는 `zh/ko` 계약을 추가했습니다. 영어 응답을 중국어로 잘못 붙이지 않습니다.
현재 문장·선택 교재/과의 문장·직전 **확정 교정**을 전달하며 질문에는 본 대화 `session_id`,
`student_input`, 보상 이벤트를 보내지 않습니다. 서버 쓰기는 기존 질문 한도 KV뿐이며
새 대화/교정/보상/개인 복습 저장이나 스키마를 추가하지 않았습니다.

질문 패널만 기존 `pauseWarmup`·취소·음성 중단 경로를 사용합니다.
배경·속도 패널과 확대 패널의 단순 열기/닫기/ESC 및 배경 수동·고정·단색은
음성·세션·재생 순번을 중단하지 않습니다. 속도/자막 표시 변경도 기존 재생을 유지합니다.
교정·언어·교재 등 실제 요청 문맥 변경은 기존 취소 정책을 따릅니다.
질문으로 본 연습을 중단한 동안 공유 fetch는 **기존 질문 API만** 허용합니다. 기존 엘리더 요청 래퍼도
그대로 거칩니다. 요청 순번·세션/문맥/epoch 검사로 취소·닫기·새 문맥의 늦은 응답을 버립니다.
질문 마이크는 기존 입력 모듈을 재사용하며 받아 적은 뒤 사용자가 확인하고 보냅니다.
질문과 본 녹음이 겹치지 않고, 닫기만으로 자동 마이크를 시작하지 않습니다.
네이티브 dialog의 포커스와 Escape 복귀를 사용합니다.

이미 서버가 처리한 요청을 클라이언트 취소로 되돌릴 수는 없습니다. 이 변경은 UI의
중복 전송/재발화·늦은 결과의 표시 및 보상 재적용을 막으며, 서버 전역 exactly-once나
기존 저장의 원자성을 새로 보장하는 변경은 아닙니다.

## 배경 정책과 실제 자산

정적 WebP **14개**를 로컬에서 사용합니다. 파일당 28,710~152,564 bytes이며 전체는
1,144,706 bytes입니다. 한 번에 선택된 배경만 불러옵니다. 움직이는 배경·유료 생성·
외부 hotlink·신규 모델은 없습니다. 대사 판의 보수적 흰 배경 합성 대비는 13.91:1,
기본 질문 버튼의 글자 대비는 5.61:1로 계산했습니다(전체 사이트 접근성 인증은 아님).

자동 선택은 기존 교재/과·주제·그림 선택 및 명시적인 “이제 … 이야기/연습”,
“Let's talk …”, 중국어 주제 변경 요청을 신호로 삼습니다. AI의 매 문장에 반응해
무작위로 바꾸지 않습니다. 같은 세션/상황은 유지하고 **새 연습**에서 적합한 후보가
둘 이상일 때 직전 선택의 반복을 피합니다. 후보가 하나면 주제 적합성을 우선합니다.
일반 자유 대화의 모든 의미 변화를 모델로 분류하는 기능은 추가하지 않았습니다.

직접 선택·현재 보이는 배경 고정·단색이 자동보다 우선합니다. 변경은 대화/교재/수준/
교정/속도를 초기화하지 않습니다. 순번으로 늦은 이미지 로드를 무시하며 실패 시 단색과
명시적인 다시 불러오기 버튼을 제공합니다. 새 설정은 기기 저장소 범위이며 기존 속도의
계정 동기화 경로는 재사용합니다. 새로운 기기간 동기화 권한은 추가하지 않았습니다.

Higgsfield 사용자 소유 경비행기 활주로·무인 뗏목 후보 두 개의 공식 CDN 다운로드는
`Tunnel connection failed: 403 Forbidden`으로 실패했습니다. 로컬 파일도 없으므로
현재 목록에 포함하지 않았고 다른 전송 경로로 우회하지 않았습니다.
Emma/Noah 생성 몸통 입력도 전달 미완료입니다. 생성 얼굴을 사용하거나 얼굴 픽셀을
원본이라고 가정하지 않았습니다. 이 배경·몸통 자산 작업은 별도 후속 범위입니다.

Playwright는 저장소 밖에 설치합니다. 이번 검증은 모든 실제 API와 외부 브라우저 요청을
차단하고 로컬 자산·모의 응답을 사용했습니다. 전체 게이트도 로컬만 허용하는 별도 검증

  1024×768, 1366×900의 영어/중국어, 추가 620px 컨테이너.
- 질문 계약 새 검사 **57개**, 기존 영어 질문 검사 **57개** 통과.
- 얼굴 관련 원본 **37개 파일**, 기존 음성/스트리밍/마이크/문맥 **14개 함수** SHA 동일.
- 타입·빌드·JS 구문 통과. 버전/캐시 **314개** 통과.
- 기준선 전체 fast 게이트: **643 PASS / 20 SKIP / 0 FAIL**.
- 최종 후보 전체 fast 게이트: **644 PASS / 20 SKIP / 0 FAIL**, exit 0. `gate.log` 참조.

검사에는 지연 응답·중복 클릭·취소·새 문맥·실패/재시도·지연 이미지·배경 고정·반복 회피·
다시 말하기 중 도움 열기·질문 녹음의 늦은 전사·기존 음성 재시작·눈 영역의 idle 변화·
iframe의 부모 미디어 트랙 유지·저장소 차단을 포함합니다. 음성 이벤트 확인에는 실제
제공자 TTS 대신 로컬 시험 WAV를 사용했습니다.

초기 검사에서 요청 래퍼의 추가 인수 유실, 확대 시 헤더/터치 그리드 넘침,
기존 추출 함수 검사의 `window` 부재를 발견해 수정했습니다. PC의 빈 그림 열을 없애고
대화 영역에 공간을 돌려주었으며, 이유 펼치기·배경 재시도·패널 close 이벤트 경합도
별도 검토 단계에서 확인했습니다. 친구 변경 직후 전송이 멈추는 문맥 경합과 초기 교재 메타데이터가 인사를 취소하는 문제를 수정하고, 명시적인 사용자 설정 변경만 요청을 중단하도록 구분했습니다. 배경 주제 우선순위와 visualViewport 키보드 위치도 재검증했습니다. 별도 사람/에이전트 리뷰를 수행했다고 주장하지 않습니다.

전체 게이트에서 구문 검사 하니스가 90초를 초과한 시도는 실패한 게이트로 기록했습니다. 단독 구문 검사는 1,563조각 모두 통과했습니다. 코드 실행이 없는 `node --check`에도 적용되던 외부 통신 차단 가드의 초기화만 생략하여, 제품 코드나 게이트의 제한 시간/기준선 변경 없이 전체 검사를 다시 실행했습니다.

실제 기기·브라우저 자체 확대·실제 소프트키보드/주소창·유료 모델/TTS/STT·실수업 WebRTC·
실계정/출석/결제/보상 쓰기는 미실행입니다. CSS 200% 확대와 뷰포트 축소는 해당 실기기
검증을 대신하지 않습니다. fast 게이트의 20개 기존 E2E 제외도 완료로 세지 않습니다.
개인 복습의 영구 저장·교사 요약 추가 전송·새 동기화/권한/스키마는 이번 묶음에 없습니다.

## 별도 검토 후 수정 (첫 결과의 검증 공백)

첫 결과 `94d55bb43`은 완료품이 아닙니다. 별도 검토에서 배경/확대 패널이 TTS를
중단하고도 자동으로 복구하지 않는 문제와, SSE 미리보기 대신 이전 완료 문장을
질문/확대에 사용하는 문제를 확인했습니다. 이 두 문제를 후속 로컬 변경으로 수정했습니다.

배경/확대 패널은 음성 중단 경로를 호출하지 않습니다. 질문만 화면에 보이는 문장을
중단 직전에 캡처하고, SSE 미완성 문장은 미완성으로 표시·전달합니다. 미리보기가
삭제되거나 늦은 정본이 와도 질문 스냅샷은 유지합니다. 새 문장이 아직 하나도 오지
않았다면 이전 문장을 새 답변으로 보내지 않고 상태 안내와 전송 비활성화를 제공합니다.
확대 창은 표시 중인 SSE 문장과 다음 문장/정본을 따라가며, 중단되면 마지막 표시
문장을 중단 전 스냅샷이라고 명시합니다. 과거 문장 다시 듣기는 현재 표시 문장을
바꾸지 않습니다. 눈/입 자산과 기존 음성/스트리밍 함수는 수정하지 않았습니다.

추가 검사는 실제 제품 페이지 + 로컬 WAV 및 지연 SSE를 사용합니다. 테스트 작성 중
숨겨진 이전 대화 버튼 경로와 완료 뒤 비활성 취소 버튼을 잘못 호출한 테스트 오류는
수정했으며, 이 시도들을 제품 기능 통과로 계산하지 않습니다.

보류합니다. 기존 auto-talk에 panelOpen/panelClose 연결과 보류 플래그만 추가하여
선택된 자동 모드에서 닫기·ESC·취소 뒤 한 번만 재개합니다. 버튼 모드는 자동으로 바꾸지 않습니다.

초안을 덮어쓰지 않게 합니다. 얼굴/입 atlas·좌표·음성 동기화 함수·기존 인식 시간
기준은 바꾸지 않았습니다. 교사 트랙을 중지하거나 iframe 자동 녹음 제한을 완화하지 않습니다.
