# 집중교정 — 교정 먼저, 총 3번

사용자 요구: A.i 아바타·A.i 친구 모두 집중교정에서는 다음 질문보다 고친 문장을 먼저 말하고, `You can say...`로 총 3번 반복한다. 문제 해결·충돌 정리·병합·배포까지 사용자에게 위임받았다.

## 확인한 문제와 변경

- 아바타 정본은 교정 문장 선행 1회 + 반복 3회라 총 4회였고 뒤에 모델 답장도 붙였다. 검증된 `fix.now`만 `You can say...`로 총 3번 말한 뒤 따라 말하기를 요청하도록 통일했다. 교정 턴의 다음 주제 질문은 학생이 따라 말한 뒤로 미룬다.
- 아바타 SSE는 교정 판정 전에 모델 질문을 미리 읽을 수 있었다. 집중교정이면 최종 판정을 기다리고, 다른 모드의 미리듣기는 유지한다.
- 친구는 답장·질문을 먼저 읽은 뒤 별도 함수가 교정 3회를 덧붙였다. 아바타와 같은 서버 정본을 사용하고, SSE의 미리듣기를 서버·화면 양쪽에서 막는다. 카드 판정과 최종 음성 확정을 대화 저장 앞으로 옮겨 저장 내용도 일치시킨다.
- 친구의 발음 카드가 문법 교정 음성을 끊을 수 있어, 발음 반복은 주 응답이 끝난 뒤 순서대로 실행한다. 음성 큐가 끝나야 자동 대화의 마이크 대기가 시작된다.
- 자유대화·균형, 교정 없는 응답, 음소거, 새 턴의 큐 취소는 유지한다. 검증되지 않은 교정을 지어내지 않는다.

## 선택하지 않은 방법

- 프롬프트 지시만 바꾸면 이미 스트리밍으로 읽은 다음 질문을 되돌릴 수 없다. 서버 최종 문장 조립과 스트리밍 게이트를 함께 고쳤다.
- 앞에 3번을 붙이고 모델 답장을 유지하면 모델이 그 교정을 또 읽어 4번 이상이 될 수 있다. 집중교정의 검증된 교정 턴은 총 3회와 따라 말하기 요청으로 완결한다.
- 집중교정의 미리듣기는 판정 완료까지 기다리는 만큼 늦어진다. 질문보다 교정을 먼저 듣는 요구를 지키기 위한 선택이며 다른 모드에는 적용하지 않는다.

## 검증

- 타입 검사 통과. 집중교정 실행 검사 20/0: 실제 두 워커 API의 JSON·SSE, 대화 저장, 실제 친구 전송 함수·음성 큐, 모드별 스트리밍·음소거·발음 순서·실패 알림을 실행했다. DB는 메모리 SQLite, 모델은 고정 대역이다.
- 기존 관련 검사: 정직한 칭찬/모드 95/0, 아바타 스트리밍 85/0, 친구 스트리밍 37/0, 교정 107/0, 친구 교정 56/0, 학원 교정 모드 60/0.
- 로컬 Chrome에서 두 실제 HTML을 열고 TTS 호출을 기록했다. 친구에서는 일부러 다음 질문을 먼저 보내는 SSE 대역을 사용해도 질문을 읽지 않고 최종 교정 3회만 읽었다. 아바타도 최종 응답이 실제 낭독 함수에 3회 전달됨을 확인했다. 운영 AI·실제 음성 합성을 호출한 청취 검사는 아니다.
- Windows 부분 체크아웃의 전체 fast 검사는 기존 `/C:/...` 경로·누락 이미지/문서·의존성 차이로 실패한다. 관련 코드를 무관하게 바꾸거나 검사를 제외하지 않으며, 완전한 체크아웃의 PR CI로 최종 전체 게이트를 확인한다.
- 운영 D1 변경·실서비스 실험 없음. 병합·배포 결과는 PR에 추가한다.

## 첫 CI에서 확인한 검사 전제

브라우저·수업 일정·Cloudflare 빌드는 통과했으나 전체 게이트는 PASS 630 / SKIP 20 / FAIL 3이었다. 기존 검사가 정상 음성·발음 반복을 옛 직접 호출 모양으로 찾고, 미리듣기 검사는 모드를 지정하지 않아 새 집중교정 기본값의 «최종 판정까지 보류»와 충돌했다.

- 실패 알림 검사: 새 음성 큐 호출도 확인하되 실패 분기에서 두 재생 경로가 모두 없는지 확인한다. 실제 전송 함수에서도 실패 알림은 무음·카드 없음 확인(41/0).
- 발음 검사: 실제 sayThrice 함수를 실행해 완료 후 총 3회·음소거 0회·취소 후 추가 발화 없음·주 음성 뒤 연결을 확인(37/0).
- 반복 질문 검사: 미리듣기 사례에는 균형 모드를 명시하고, 집중교정에서도 최종 질문을 다시 뽑으며 미리듣기는 0건인 짝을 추가했다. 실제 핸들러의 대화 320개·5360턴 샌드박스 포함 129/0.
- 검사 제외·기준선 완화 없음. 최종 전체 CI를 다시 실행한다.
