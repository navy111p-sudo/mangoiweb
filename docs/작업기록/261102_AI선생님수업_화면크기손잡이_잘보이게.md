# A.i 선생님 수업 — 선생님 화면 크기 손잡이를 더 잘 보이게

- 날짜: 2026-11-02
- 작업자: 정우영(사장님) 요청 · Claude 작업
- 브랜치 / PR: `ai-class-teacher-size-hint` / [navy111p-sudo/mangoiweb#1955](https://github.com/navy111p-sudo/mangoiweb/pull/1955) (squash 병합 `1a67f54`)

## 1. 왜 했나
사장님 화면 사진(선생님 Emma 사진 아래 초록 ▶ 아이콘에 빨간 원 표시)과 함께 「선생님을 크게 해 준다는 설명을 PC·휴대폰에서 쉽게 볼 수 있게」 요청.
선생님 화면 크기 조절 기능(`#tSplit` 경계 손잡이)은 이미 있었지만, 버튼이 20px 로 작고 무엇을 하는 버튼인지 알려 주는 안내가 없어 거의 발견되지 않았습니다.

## 2. 무엇을 바꿨나
`cloudflare-deploy/public/ai-class.html` 한 파일(+9 −2).
- CSS `.tsplit .grip button`: 20×20px → **28×28px**, 글자 11px → **13px**.
- JS: 안내 키 `HINT_KEY = 'aiClassTeacherHint'` 추가. 손잡이가 보이는 상태(`shown()`)에서 처음 들어온 사람에게만 「◀ 크게 · 작게 ▶ — 선생님 화면 크기 / Teacher view size」를 손잡이 말풍선(`tip`)에 **5초** 보여 주고 `localStorage` 에 기록(`lsGet`/`lsSet` — 저장이 막혀도 동작에는 영향 없음).
- 폰(≤760px)에서 손잡이를 숨기는 기존 동작은 그대로.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법
- **「크게 보기」 버튼 + 전체화면 확대 창**(샘플로 먼저 보여 드림): 새 화면을 하나 더 만드는 일이라 기존 손잡이(이미 크기를 저장·복원함)와 기능이 겹칩니다. 있는 기능을 «찾게» 하는 쪽이 범위가 작고 안전해서 버렸습니다.
- **안내를 매번 띄우기**: 수업마다 같은 말이 뜨면 방해가 됩니다 → 처음 한 번만.
- **폰에도 손잡이 표시**: 폰은 화면이 좁아 칸을 나눌 자리가 부족해 원래 숨겨 둔 것이라, 바꾸는 것은 사람이 정할 일로 남겼습니다.

## 4. 확인한 방법
- 관련 하니스(`ai_class_*`) 통과.
- 전체 회귀 `node test-harness/run.mjs --fast`: FAIL 목록이 `origin/main` 기준선과 **같은 35건**(이 컨테이너에 `node_modules` 가 없어 원래 실패하는 것들) — 새 회귀 없음.
- CI 배포 게이트·Workers Builds 성공 → 병합 → 배포 성공(11:28 UTC, `1a67f54`).
- ⚠️ **실제 화면은 확인하지 못했습니다** — 이 환경은 배포된 사이트를 볼 수 없습니다.
