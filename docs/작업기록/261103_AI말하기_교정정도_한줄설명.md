# AI 말하기 공통 설정 «교정 정도» 아래 한 줄 설명 (A안 · ①설명형)

- 날짜: 2026-11-03
- 작업자: Claude (사장님 요청)
- 브랜치 / PR: `claude/ai-speaking-corr-hint`

## 1. 왜 했나

사장님 캡처(공통 설정의 «교정 정도: 자유 · 균형 · 집중») + 요청
「이것의 뜻을 잘 안내설명이 필요해. 어디에 넣을지 샘플 3개」.

Artifact 시안으로 위치 3안(A 선택값 아래 한 줄 · B 라벨 옆 ⓘ 팝오버 · C 버튼 안 부제)을 보여 드렸고,
사장님이 **A안**을 고르셨다. 이어서 「균형은 말 1번, 집중은 말 3번 수정을 넣어서」,
「단계마다 문구 3개씩」을 요청하셨고 **①설명형**으로 확정하셨다.

## 2. 무엇을 바꿨나

| 파일 | 내용 |
|---|---|
| `cloudflare-deploy/public/ai-speaking.html` | 교정 버튼 3개에 `data-hint-ko`/`data-hint-en` 문구, 버튼 묶음에 `aria-describedby="corrState"`, `renderSettings` 가 고른 단계의 문구를 `#corrState` 에 쓴다. `.state` 글자 12→13px, 좌우 6px |
| `test-harness/ai_speaking_entry_harness.mjs` | 문구가 서버 동작과 «짝» 인지 보는 검사 블록 1개 |

화면에 나오는 문구

| 단계 | 한국어 | English |
|---|---|---|
| 자유 `free_talk` | 따라 말하기 없이 대화를 이어가요 | No repeat-after-me. Just keep talking. |
| 균형 `balanced` | 꼭 필요한 것만 고치고 1번 따라 말해요 | Fixes key mistakes, then you repeat once. |
| 집중 `focused` | 모두 고쳐서 3번 들려주고 따라 말해요 | Fixes all, says it 3 times, you repeat. |

- 아직 안 골랐거나(«아직 안 정함») 두 화면 값이 다르면(«화면마다 다름») 예전 문구를 그대로 보여 준다.
- 저장 동작(`js/ai-speaking-settings.js`)은 한 글자도 안 바꿨다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **시안 ① 문구 그대로(「말할 때마다 최대 3번 고쳐줘요」)는 버렸다.** 시안은 화면 캡처만 보고
  «3 = 고치는 개수의 상한» 으로 짐작해 썼는데, 서버(`src/warmup-honest.ts`)는 다르다.
  - 집중: 「한 번에 한 가지만」 규칙을 끄고 **실수를 모두** 고친 문장을 만들고, 아바타가
    `"You can say..."` 뒤에 그 문장을 `FOCUSED_FIX_REPEATS`(=3)번 말한 다음 따라 말하자고 한다(`ensureFocusedFixSpoken`).
    ⟹ 3은 «들려주는 횟수» 이고 고치는 개수에는 상한이 없다.
  - 균형: 뜻이 달라지는 실수는 바로, 작은 실수는 되풀이될 때 고치고, 따라 말하기는 가끔 1번이다(`MODE_LINES.balanced`·`warmupShouldOfferRepeat`).
  - 자유: «교정 없음» 이 아니다 — 지적하지 않고 바른 문장으로 되받아 말하며(recast), 교정 카드도 기존 게이트대로 뜬다. 없는 것은 **따라 말하기**다(`gateFixForMode` → `repeat:false`).
  - 사장님께 두 안(실제 동작에 맞춘 ① / 시안 ① 그대로)을 보여 드리고 **실제 동작에 맞춘 ①** 로 정했다.
- **B안(ⓘ 팝오버)·C안(버튼 안 부제)은 이번에 안 넣었다** — 사장님이 A안만 고르셨다.
- **문구를 `js/ai-speaking-settings.js` 표로 옮기는 방법은 버렸다.** 그 파일을 바꾸면 `?v=` 판올림·자산 원장까지 따라온다.
  문구를 쓰는 곳은 이 화면 하나라, 버튼 옆 `data-hint-*` 에 두는 것이 가장 짧다(글자 바꾸기도 한 곳).
- **EN 버튼 라벨(Free/Balanced/Focused)은 그대로 뒀다.** 시안에서 «Free → Light» 를 권했지만 지시 범위 밖이다.
