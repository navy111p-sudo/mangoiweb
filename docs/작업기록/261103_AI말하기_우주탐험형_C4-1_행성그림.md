# AI 말하기 화면 — 우주 탐험형(C-4-1) 개편 + Higgsfield 행성 그림

- 날짜: 2026-11-03
- 작업자: Claude (사장님 요청)
- 브랜치 / PR: `ai-speaking-space-redesign`

## 1. 왜 했나

사장님이 AI 말하기(`/ai-speaking.html`) 화면 디자인 시안을 여러 번에 걸쳐 고르셨다.

1. PC·휴대폰 시안 A(클린 카드)·B(추천 강조)·C(키즈) → C안을 다시 3종(C-1~C-3)
2. 「우리 학생들 대상이 초등중등」 → 초·중등 공용 C-4~C-6
3. 「C-4 를 초등과 중등 모두 만족할 수 있게 3가지로」 → C-4-1 우주 탐험형 · C-4-2 소프트 다크형 · C-4-3 미션 퀘스트형
4. **「C-4-1 우주 탐험형으로 실제 코드 만들어줘」 + 「힉스필드에서 적당한 이미지를 가져다가 넣어줘」**

시안은 Claude 디자인 캔버스와 PDF(`AI말하기_C4_초중등_발전안.pdf`)로 드렸다 — 저장소에는 넣지 않았다.

## 2. 무엇을 바꿨나

| 파일 | 내용 |
|---|---|
| `cloudflare-deploy/public/ai-speaking.html` | **겉모습만** 바꿨다. 밤하늘 배경(CSS 별) + 말하기 3가지를 행성 그림으로. 휴대폰 = 가로 한 줄 카드 + 동그란 화살표, PC(≥900px) = 세로 카드 3장 + 넓은 버튼. 공통 설정은 이모지 타일 → 선 아이콘 + 알약형 선택 버튼, PC 에 남아 있던 모바일용 드래그 손잡이 제거. 카드 제목 앞 이모지는 그림과 겹쳐 뺐다. 항상 어두운 화면(시안이 다크 전용). |
| `cloudflare-deploy/public/img/ai-speaking/planet-{textbook,situation,friend}.webp` | 새 그림 3장(320×320, 투명, 합계 58KB). |

⛔ **스크립트(설정 읽기·쓰기·상황 목록·한/영 전환)는 한 글자도 안 바꿨다** — `<script src="/js/ai-situations.js` 줄부터 끝까지를 원본과 `diff` 해 같음을 확인했다. `js/ai-speaking-settings.js`·`js/ai-situations.js` 도 그대로라 `?v=` 를 올릴 일이 없다.

지킨 계약(`ai_speaking_entry_harness`·`manual/ai-speaking-browser.mjs`): `<a class="mode…" id="…">` 카드 3장의 id·href·클래스 순서, `id="situations"`·`id="sitBody"`, 공용 스크립트 두 개, `/img/mango-char.png`(Mr.mango), `localStorage.setItem`·`fetch(`·`getUserMedia(` 없음, `data-ko`/`data-en` 은 **글자만 담은 요소에만**(아이콘 옆 라벨은 안쪽 `<span>` 으로 옮김 — CLAUDE.md 2장 「아이콘 버튼에 data-ko 를 달았더니」).

### 그림 출처

- Higgsfield `gpt_image_2_5`(quality high, 1k, `background: transparent`)로 메뉴마다 2장씩 6장을 만들고(1.5크레딧 × 6) 카드 배경색 위에 놓고 비교해 **교재 0번 · 상황 2번 · AI 친구 4번**을 골랐다(작게 줄여도 또렷한 쪽, 교재와 AI 친구의 고리가 겹치지 않는 쪽).
- 이 컨테이너는 생성물 CDN 이 프록시에 막혀(CLAUDE.md 2장 「이미지·파일을 밖에서 받아와야 할 때」) **임시 브랜치 `tmp-fetch-ai-speaking-art` 의 임시 워크플로**가 러너에서 PNG 6장을 받아 그 브랜치에 커밋했고, 그 파일만 가져와 투명 확인 → 여백 자르기 → 320px WebP 로 줄였다. 외부 주소는 코드에 쓰지 않는다.

## 3. 검토했다가 버린 방법

| 방법 | 버린 이유 |
|---|---|
| 새 화면 파일(HTML+JS)을 따로 만들기 | 기존 화면의 설정 로직(«사람이 고를 때만 저장»·저장 막힌 기기 대응·mixed 상태)과 하니스 계약을 다시 짜야 한다. 겉모습만 바꾸는 쪽이 동작 회귀 0 을 보장한다. |
| 시안처럼 Google Fonts(Noto Sans KR) 쓰기 | 브라우저 하니스가 외부 요청을 전부 막고, 사이트 공용 글꼴 규칙(`/css/mangoi-han.css`, MangoiHanSC 맨 앞)이 있다. 공용 규칙을 따랐다. |
| 행성을 CSS 그림으로 남기기 | 사장님이 Higgsfield 그림을 원하셨다. 그림으로 바꾼 뒤 CSS 행성(`.ball`·`.ring`·`.moon`·`.sat*`)과 변수는 지웠다(죽은 코드 방지). |
| Higgsfield CDN 주소를 `<img src>` 에 그대로 | CLAUDE.md 2장 금지 — 남의 도메인에 실서비스가 묶이고(중국 회선) 파일이 지워지면 그림이 사라진다. |
| 라이트 모드 따로 그리기 | 시안 C-4 계열이 다크 전용이다. `prefers-color-scheme` 분기를 없애고 `color-scheme:dark` 로 고정. |

- `node test-harness/ai_speaking_entry_harness.mjs` — PASS(220 — 새 그림 3장 실재 확인 3건 포함)
