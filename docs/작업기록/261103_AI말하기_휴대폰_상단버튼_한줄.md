켜지는 조건
- 세로: `(max-width:640px)` — 기존 `warmup-flow.css`·`phone-fit` 블록과 같은 경계
- 가로: `(orientation:landscape) and (max-height:520px)` — 기존 `touch-compact` 의 «눕힌 폰» 경계와 같음
- 그 밖(PC·태블릿)은 클래스가 안 붙어 한 글자도 안 바뀐다

옮기는 것
- 머리글(`.top`) 한 줄 안으로: 주제·콤보 칩(`.meta`), 도구 줄(`#wfTools` 질문하기·배경/속도·문장 크게), 이전 대화·대답 도움(`.wg-history-bar`). 버튼은 CSS 로 **아이콘만** 보이게 하고 글자는 남긴다(`font-size:0`) — 화면낭독기·툴팁·KO/EN 전환이 그대로 동작
- ⋮ 설정 메뉴 맨 위(`.menu-scroll` 안)로: 진행 문구(`.wg-progress`)
- **세로만**: 모드 선택·🏠·🔄·🔊 를 ⋮ 메뉴 «빠른 줄» 로 (🎚️·⋮ 는 한 줄에 남김 — 시안 B 그대로)
- **가로만**: 머리글을 화면 위에 반투명하게 띄우고(`position:fixed`), ⌃ 로 숨기면 위 가운데 «메뉴» 손잡이만 남는다(이 기기에 기억 — `localStorage mangoi_warmup_topbar_hidden`). 얼굴은 왼쪽·대화는 오른쪽(시안 C), 얼굴은 `sticky` 로 위에 붙어 남는다
- 화면을 돌리면 원래 자리(주석 자리표)로 되돌린 뒤 다시 옮긴다

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **CSS 만으로 겹쳐 올리기(absolute 로 도구 줄을 머리글 자리에 띄우기)** — 버림. 도구 줄·칩·진행 줄이 서로 다른 부모에 있고 글자 길이(KO/EN)가 달라 겹침 계산이 화면마다 깨진다
- **복제(같은 버튼을 머리글에 하나 더 만들기)** — 버림. 상태(비활성·이전 대화 펼침)와 처리기를 두 벌로 맞춰야 한다. 옮기기는 `warmup-touch-bar.js` 가 `#talkSwitch` 에 이미 쓰는 방식이다
- **🔄·🎚️ 를 세로에서 감추기만** — 버림. 🔄 는 2026-10-02 「바로 보이게」 피드백으로 올린 버튼이라, 감추지 않고 ⋮ 빠른 줄로 «옮겼다»(같은 기능이 메뉴 안 «🗑 대화 지우고 새로 시작» 에도 있다)
- **터치 기기에서도 이전 대화·도움을 위 줄에 보이기** — 버림. 터치 기기는 아래 💡 도움 시트에 같은 버튼이 있어 기존 규칙(`html.tb-on .wg-history-bar{display:none!important}`)이 감춘다. 그 규칙을 이기지 않도록 `display` 에 `!important` 를 쓰지 않았다
- **가로에서 도구 버튼에 글자 붙이기(시안 C 그림)** — 보류. 844px 에서 KO 는 들어가지만 EN(「Enlarge current sentence」 등)이 넘친다. 지금은 아이콘 + 툴팁
