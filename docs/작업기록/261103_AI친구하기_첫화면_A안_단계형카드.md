# AI 친구하기 첫 화면 — A안 «단계형 카드»로 다시 짜기 (EN/KO)

- 날짜: 2026-11-03
- 작업자: Claude (사장님 요청)
- 브랜치 / PR: `claude/ai-friend-start-card-a`

## 1. 왜 했나

사장님 화면 사진 — A.i 친구하기 첫 화면(강사 얼굴 아래)이 «가독성이 떨어지고 디자인이 너무 복잡하고 이쁘지 않다».
PC·폰 시안 3종씩(A 단계형 카드 · B 대화형 · C 타일 메뉴형)을 보여 드렸고, **A안으로 실제 코드에 적용**하기로 정하셨다.

잰 것(고치기 전):
- 마스코트·제목·부제·차이 칩·오늘의 단어·드롭다운 2개·버튼 4개가 가운데 정렬로 «같은 무게» 로 쌓임.
  테두리 색이 금색·파랑·회색으로 제각각, 버튼마다 이모지.
- 친구 드롭다운 글자가 잘림 — «Emma · 엠마 (다정하게 …».
- 1366×768 노트북에서 빈 화면이 대화창보다 122px 길어 스크롤(대화창 295px · 빈 화면 369px).
- **덤으로 찾은 기존 버그 둘**(원본 main 에서도 재현):
  1. 첫 화면에서 KO↔EN 을 바꾸면 `renderEmpty()` 의 `innerHTML` 이 `#wodSlot` 안 오늘의 단어 칩을 파괴 →
     칩이 사라지고 `updateHUD` 가 `Cannot set properties of null` 로 던짐.
  2. EN 학생도 첫 화면 라벨이 한국어 — 첫 그림이 `js/mango-i18n.js`(defer)보다 먼저 그려지고,
     `mangoi:lang-changed` 는 «바꿀 때» 만 와서 다시 안 그려짐.

## 2. 무엇을 바꿨나

`cloudflare-deploy/public/ai-friend.html` 한 파일(+ 하니스 한 줄).

- `renderEmpty()` — 왼쪽 정렬 한 장:
  인사(작은 Mr.mango + «Hi! I'm Emma» + 부제·포인트 안내 + 작은 «AI 말하기와 뭐가 달라요?» 링크)
  → 오늘의 단어 띠 → **① 친구**(얼굴 버튼 5개) → **② 주제**(작은 사진 칩 10개 · «그림으로 크게 보기»)
  → **노란 버튼 하나 «Emma에게 말 걸기»** + 보조 «새 단어»·«재미난 사실».
- `efPicksHtml(en, cards)` — 드롭다운 대신 버튼. 하는 일은 예전과 같다(친구 `setFriend(v,true)` · 주제 `topicSend(i)`).
- 새 작은 함수: `EFA_ICON`(선 아이콘) · `efFriendLabel` · `efCtaText` · `efDescHtml` · `efSayHi` · `topicChipHtml` · `efToggleBig`.
- `efSyncFriend(f)` — 친구를 바꾸면 고른 표시(aria-pressed)·제목 이름·노란 버튼 이름·설명 줄을 «그리지 않고» 맞춘다.
- 오늘의 단어 칩 마크업 — `✨ … :` 를 빼고 `.wod-lab` 이름표로. 띠 오른쪽 «듣기» 버튼은 가상요소(`data-tap`) +
  스피커 SVG 배경(이모지 없음). 글자 `👂 눌러서 들어요` → `듣기` / `Listen`.
- 버그 수리: `renderEmpty()` 첫 줄에서 `wodPark()` · 첫 그림에 `data-lang` 을 달고 `load` 때 한 번만 대조해 다시 그림.
- CSS — 옛 `.ef-*` 규칙을 `.efa-*` 로 교체. 세로 800px 이하(노트북)는 단계 라벨을 «짧은 이름» 으로 줄 왼쪽에,
  폰(520px 이하)은 친구 5칸 격자·주제 가로 스크롤·노란 버튼 한 줄 통째로, 세로가 짧은 폰(<=760px)은 라벨을 접고
  보조 버튼을 그림만.
- `test-harness/ai_friend_character_help_harness.mjs` — «첫 화면에서 친구를 먼저 고르게 한다» 검사가 옛 드롭다운
  문구(«모험 주제를 골라볼까요?»)를 글자로 찾고 있어 빨간불. **문구가 아니라 순서**(renderEmpty → efPicksHtml 에서
  `.efa-friends` 가 `.efa-topics` 보다 먼저)를 묻게 고침.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **마스코트를 빼는 안**(시안에서는 뺐다) → 버림. CLAUDE.md 0장: Mr.mango 가 공식 캐릭터이고 «제목 왼쪽 마스코트 자리» 에
  쓴다(2026-08-23 사장님). 크기만 48px 로 줄여 제목 왼쪽에 둠. 하니스(`.hero-mango img`)도 그대로 산다.
- **카드 안에 KO/EN 토글을 새로 두는 안** → 버림. 상단에 이미 🌐 EN 버튼이 있고 두 개면 헷갈린다. 대신 새 글자를 전부
  `isEn()` 두 벌로 쓰고, 언어 전환·첫 로드 때 맞게 다시 그리게 했다.
- **주제를 «먼저 고르고 → 노란 버튼으로 시작»** 안(시안 그대로) → 버림. 지금 주제는 누르는 순간 그 주제로 대화를 시작한다
  (`topicSend`). 동작을 바꾸면 저장·판정이 새로 생긴다(10-18 주석의 «판정·저장을 새로 만들지 않는다»). 그래서 주제 칩은
  «누르면 바로 시작해요», 노란 버튼은 «주제 없이 인사로 시작».
- **주제 10개를 늘 여러 줄로** → 폰·노트북에서 «한 장에 스크롤 없이»(2026-10-18 사장님)를 깸. 좁거나 낮은 화면에서는
  가로로 미는 한 줄.
- **`details` 로 큰 그림 카드 접기** → 버림. 주제 줄이 가로 스크롤(nowrap)일 때 그 안에서 펼치면 깨진다. 단계 라벨 옆
  버튼 + `hidden` 상자로(`.efa-big[hidden]{display:none!important}` — `.topics` 가 grid 라 hidden 만으로는 안 숨는다).
- 카드 마크업 정본 `topicCardHtml` 은 그대로(큰 그림 카드), 칩은 별도 `topicChipHtml` — `topic_icon_harness` ⓓ 의
  «카드 마크업 한 곳» 약속을 지킨다.
