# 관리자 «강사 스케줄 (주간 통합 캘린더)» 에도 취소·연기 수업을 지우지 않고 남기기

- 날짜: 2026-11-03
- 요청: 사장님 「주간 시간표도 똑같이 수정해줘」(같은 날 두 번째) — 첫 번째는 `/admin/weekly-schedule.html` 로 끝냈다(PR #2000, [261103_주간시간표_취소연기_빗금칸.md](261103_주간시간표_취소연기_빗금칸.md)).

- 화면: admin.html › 강사 관리 › 「📅 강사 스케줄 (주간 통합 캘린더)」 — `js/adm-q6.js`(ph54)

## 1. 왜 했나

그 캘린더도 `GET /api/admin/schedules?week=` 를 부르는데 `items` 만 읽고 서버가 함께 주는 `off_items`(취소·연기 날짜 회차, PR #2000)를 버렸다.
그래서 이 화면에서는 취소한 수업이 여전히 «통째로 사라진» 것처럼 보였다 — 매니저 제보(「취소했더니 페이지에서 사라졌다」)가 그대로 남은 자리.

같은 API 를 부르는 화면을 전부 세어 봤다:

| 화면 | 이번에 | 이유 |
|---|---|---|
| `admin/weekly-schedule.html` (주간 전체 스케줄) | 이미 고침(PR #2000) | 빗금 칸 |
| `js/adm-q6.js` (강사 스케줄 주간 통합 캘린더) | **고침** | 이 문서 |
| `js/adm-p6.js` (강사 출근·지각 집계) | 안 고침 | 취소된 수업은 출근 근거가 아니다 — `items` 만 읽는 것이 맞다 |
| `js/adm-perf.js` | 안 고침 | 화면이 아니라 관리자 GET 응답을 60초 캐시하는 층이다(쓰기 요청이 나가면 통째로 비운다) |

> 📌 정정(같은 날 후속) — 처음에 이 표에 `admin/mypage.html` «내 주간 시간표» 를 «같은 API 를 부르는 화면» 으로 적었는데 사실이 아니었다. 그 화면은 이 API 를 부르지 않는다(`grep -rln "/api/admin/schedules"` 로 확인한 실제 호출처는 위 넷뿐).

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **records 에 off 를 섞기** — 버렸다. 드래그(`ph54BuildMovePlan`)·차단 삭제가 전부 `records` 인덱스(`data-idx`)로 돈다. 섞으면 카페24 겹쳐보기 때 적어 둔 그 사고(엉뚱한 수업에 PATCH)가 난다.
  그래서 카드에 `draggable`·`data-idx`·`data-block` 을 아예 안 단다 — 누르거나 끌어도 아무 일도 안 일어난다.
- **취소 칸을 겹침 판정에 넣기** — 버렸다. 취소한 자리에 새 수업을 넣는 일이 실제로 있는데(weekly-schedule 작업 때 확인), 그러면 «⚠ 같은 시각에 수업이 둘» 빨간 테두리가 뜬다.
  대신 **자리(lane)는 함께 나눈다** — 두 카드가 같은 자리에 포개져 하나가 안 보이는 일이 없게.
- **빈 자리(«빈 N분») 계산에서 취소 칸 빼기** — 안 뺐다. 빼면 점선 «빈 칸» 상자가 취소 카드 위에 겹쳐 그려진다. 대신 카드 툴팁이 «이 시간은 비어 있습니다» 라고 말한다.
- **취소 카드 클릭으로 그 시간 차단·새 수업** — 처음엔 안 달았다(카드 위 클릭은 무시). ⚠️ 그런데 함정 대조가 «그 자리는 고치기 전에 빈칸이라 눌러서 차단할 수 있었다 — 카드가 그 길을 막는다» 를 짚었다 → 후속(§6)에서 취소·연기 카드 위 클릭은 «빈 시간» 으로 통과시켰다.
- **색** — 밝은 회색만 썼다. 어두운 반투명 그라데이션이면 `adm-light-surfaces.js` 가 «어두운 면» 으로 보고 덮는다(CLAUDE.md 2장). 인라인은 `background-color:` 로.
