- 날짜: 2026-11-03
- 작업자: Claude Code (사장님이 강사 제안 + 스크린샷 전달)
- 브랜치: `claude/teacher-calendar-month-like-manager`

## 1. 왜 했나

강사 제안(원문): «At teacher's page, please include month option at summary/ calendar for each student easy access
like the manager's page». 스크린샷 위쪽은 강사 화면 학생 줄의 [Summary / Calendar] 버튼, 아래쪽은 매니저 학생 화면의
월 달력(수업 칸에 «Regular class · 5:50pm – 6:10pm · 20 min · KAYE · [Student absent] · Report: not written»,
공휴일 «National Foundation Day»·«Hangeul Day» 빨간 이름표, [Today] 버튼).

### 이미 있던 것 (먼저 확인)

- 2026-10-30 #1888 이 이 창에 **[월 | 목록] 전환(기본 = 월)** 을 이미 넣었다. 그러니 «월 보기가 없다» 는 아니다.
- 그런데 그 월 달력의 칸은 **시작 시각 + 짧은 상태 한 마디**뿐이었고(폰에서는 시각만), 공휴일·수업 종류·강사·
  보고서 여부가 없었다. 매니저 달력과 나란히 보면 «월 보기» 로 안 읽힐 만큼 정보가 적었다 → 이번 제안의 실체로 판단.
- ⚠️ 강사가 #1888 배포 «전» 화면을 보고 쓴 제안일 수도 있다(제안 날짜를 모름). 배포된 화면은 이 세션에서 못 본다.

## 3. 검토했다가 버린 방법

- **주간(Week) 보기까지 매니저와 똑같이** — 제안은 «월» 이고, 이 창은 학생 한 명의 «이력» 이라 시간 격자가 필요 없다. 범위 밖.
- **공휴일을 화면이 `/api/calendar/events` 로 따로 받기** — 그 API 는 공개지만 `holidays` 표(KR·PH 동기화)는 관리자 경로
  (`/api/admin/mod/holidays/list`)라 강사 세션 권한을 새로 따져야 한다. 이미 강사 권한을 확인한 이력 응답에 실으면 요청도 하나.
- **공휴일로 수업 상태를 바꾸기** — 상태는 원장(`buildStudentLedger`) 정본이 정한다. 이름표는 장식이라 표가 없거나 읽기가
  실패하면 «이름표 없음» 으로 조용히 넘어간다(경고를 늘리지 않음 — 이력 창의 경고는 «기록이 빠졌다» 는 뜻이라).
- **보고서 줄을 매니저처럼 모든 칸에** — 매니저는 «결석 보류» 칸에도 «미작성» 을 띄우지만, 강사에게는 «내가 안 쓴 보고서» 로
  읽힌다. 수업이 있어야 했던 날만.
