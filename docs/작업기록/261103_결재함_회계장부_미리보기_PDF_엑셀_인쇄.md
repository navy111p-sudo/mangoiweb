## 1. 왜 했나

사장님 요청(2026-11-02, 화면 캡처와 함께)은 다음과 같았습니다.

- 엑셀로 내려받기 전에 장부를 PDF로 보기 좋게 볼 수 있게 해 달라.
- 엑셀도 총액과 분류가 다 있는 정식 회계장부로 만들어 달라.
- 회계사·세무사에게 바로 제출할 수 있는 수준이어야 한다.
- 인쇄도 되게 해 달라.

원래 결재함(`/work`) › 회계장부에는 「엑셀 내려받기 (이 장부)」 버튼 하나만 있었습니다. 실제로는 서버가 만든 CSV를 그대로 받는 버튼이었습니다.

경위 메모: 처음에는 앱 소스가 이 세션에 없어서(`navy111p-sudo/mangoi` 접근 불가) 별도 모듈(`/home/user/ledger-report`)을 먼저 만들었습니다. 사장님이 캡처로 「왜 아직도 안 됐어?」라고 물으셔서 그 사정을 말씀드렸습니다. 그 뒤 `navy111p-sudo/mangoiweb` 을 클론해 실제 화면에 다시 구현했습니다. 별도 모듈은 쓰지 않습니다.

### 문서(미리보기·PDF·인쇄)

A4 가로 한 문서이고 아래 순서로 구성됩니다.

1. **요약**: 통화별 합계·건수
2. **분류(계정)별 집계**
3. **전표 장부**: 일자순, 통화별 누계
4. **제외·확인 필요**: 대기, 금액 없음, 목록 잘림, 결재선 누락
5. **작성 기준과 서명란**: 작성 / 검토(세무사·회계사) / 승인

인쇄할 때는 표 머리글이 쪽마다 반복되고 쪽 번호가 붙습니다. PDF는 브라우저 인쇄 창의 «PDF로 저장»으로 만듭니다.

### 엑셀

4시트로 된 진짜 `.xlsx` 입니다. 외부 라이브러리 없이 STORE zip과 CRC32로 직접 만듭니다.

| 시트(한국어) | 시트(영어) |
|---|---|
| 요약 | Summary |
| 전표장부 | Ledger |
| 분류별집계 | By category |
| 제외·확인 | Excluded |

- 합계·누계·건수·집계는 전부 **수식**입니다.
  - 누계: `SUMIF($G$6:Gn,Gn,$H$6:Hn)` (통화별)
  - 분류별 집계: `COUNTIF`/`SUMIF`
  - 검증 칸: `IF(ROUND(...)=0,"OK","NG")`
- 틀 고정, 자동 필터, 인쇄 제목 행, 열 때 재계산(`fullCalcOnLoad`)이 켜져 있습니다.

### CSV

서버의 `ledgerCsvResponse` 를 그대로 씁니다. 변경 없습니다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **서버에 PDF·엑셀 생성 API를 새로 만드는 방법은 버렸습니다.**
  - 화면이 이미 받은 `/api/approval/requests?view=ledger` 응답을 그대로 쓰면, 화면과 문서가 **같은 줄·같은 합계**를 보장합니다.
  - 새 API를 만들면 `src/index.ts`(공동 금지구역)의 관문 세 곳을 등록해야 합니다.
- **ExcelJS 같은 라이브러리를 CDN에서 받는 방법은 버렸습니다.**
  - 외부 CDN 의존이 늘어납니다(중국 회선).
  - 1MB 가까운 파일을 받아야 합니다.
  - 4시트·수식 정도는 직접 만들 수 있었습니다.
- **분류 집계를 라벨 글자로 `SUMIF` 하는 방법은 버렸습니다.**
  - 분류 이름에 `*`·`?`·`~` 가 들어 있으면 엑셀이 와일드카드로 읽어 엉뚱한 줄을 셉니다.
  - 그래서 숨긴 **숫자 그룹 열**(전표장부 J열, 분류별집계 F열)로 셉니다.
- **통화를 합쳐 원화 하나로 합계를 내는 방법은 버렸습니다.**
  - 장부 금액은 원래 통화 그대로 둡니다.
  - 원화 환산은 «오늘 환율 기준 참고값»이라고 문서에 적었습니다.
  - 환율이 10~60 범위를 벗어나면 환산을 아예 표시하지 않습니다.
- **스크립트를 첫 화면에 바로 싣는 방법은 버렸습니다.** pdf.js 와 같은 방식으로 «처음 누를 때만» 받으므로 결재함 첫 화면 무게는 그대로입니다.
- **기존 「CSV」 버튼은 지우지 않았습니다.**
  - 기존 수동 하니스가 «첫 `.findcsv` = CSV» 를 전제로 합니다.
  - 원본 그대로가 필요한 사람도 있습니다.

## 5. 남은 것 / 주의할 것

- **`?v=` 는 손으로 올려야 합니다.**
  - `work-ledger-export.js` 를 고치면 `work.html` 안의 `loadScript('/js/work-ledger-export.js?v=1')` 번호를 직접 올려야 합니다.
  - `asset_version_harness` 는 `loadScript` 문자열을 추적하지 않습니다(원장 0건 실측). 그래서 안 올려도 하니스가 잡아 주지 못하고, 학생·직원 브라우저에 옛 파일이 남습니다.
  - `work.html` 그 줄에 주석을 남겨 두었습니다.
- **기존 수동 검사 하나가 원본 main 에서도 실패합니다.**
  - `test-harness/manual/approval-ledger-browser.mjs` 의 「기본은 날짜 최신순」 검사입니다. 이번 변경과는 무관합니다.
  - 장부 기본 보기가 «요약» 으로 바뀐 뒤로 정렬 버튼이 없기 때문입니다. 아직 고치지 않았습니다.
- 별도로 만든 `/home/user/ledger-report` 모듈은 쓰지 않습니다. 저장소에도 없습니다.
