# A.i 친구하기 — 설정 시트를 «위로 · 2단» 으로 (스크롤 없이 전부 보이게)

- 날짜: 2026-11-04
- 작업자: Claude (사장님 요청)
- 브랜치 / PR: `ai-friend-settings-sheet-top`

## 1. 왜 했나

사장님 화면 캡처(PC, 오른쪽 아래 «설정과 오늘의 할 일» 패널)와 함께
«설정을 스크롤 안하고 바로 전체 모두 볼 수 있게 최대한 위로 올려줘».

잰 것(헤드리스 크로미움, 2026-11-04):

| 화면 | 고치기 전 시트 | 내용 높이 |
|---|---|---|
| PC 1920x1080 | 위 404px ~ 아래 1064px (660px 상한) — 스크롤 | 916px |
| PC 1440x760 | 위 151px, 593px — 스크롤 | 916px |
| PC 1366x640 | 위 125px, 499px — 스크롤 | 916px |
| 폰 390x844 | 위 118px (86dvh 상한) — 스크롤 | 865px |

PC 시트가 «오른쪽 아래 · 최대 `min(78dvh,660px)`» 라서, 큰 화면에서도 아래 절반
(속도·친구·자막·대화 초기화)이 스크롤 밖이었고 화면 위쪽은 통째로 비어 있었습니다.

## 2. 무엇을 바꿨나

`cloudflare-deploy/public/ai-friend.html` 의 CSS 만(스크립트·DOM 은 그대로).

- **PC(≥760px)**: 시트를 위에 붙임(`top:12px`), 높이 상한을 화면 높이(`calc(100dvh - 24px)`)로.
  닫힘은 예전처럼 «아래로 내려 보내기» 인데, 위에 붙였으므로 자기 높이가 아니라 **화면 높이만큼** 내림.
- **PC 2단**: 폭 `min(800px, 100vw - 32px)`, `.sheet-body` 를 그리드로 —
  왼쪽 = AI 목소리 · 오늘의 퀘스트 · 레벨 상태 · 대화 초기화 / 오른쪽 = 설정 전부(레벨·스타일·교정·속도·친구·자막).
- **폰(<760px)**: 아래에서 올라오되 상한을 `86dvh` → `calc(100dvh - 12px)` (최대한 위까지).
- 브라우저 검사 `test-harness/manual/ai-friend-header-browser.mjs` 에
  «PC 시트가 위에 붙는다 + 스크롤 없이 전부 본다»(짝)와 «폰 시트가 최대한 위까지» 를 추가.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **위로만 올리기(1단 유지)** — 내용이 916px 라 화면 높이 940px 이상에서만 스크롤이 사라집니다.
  사장님 화면은 캡처 높이(899px, 작업표시줄 포함)로 보아 창 안쪽이 그보다 낮다고 **추정**합니다(직접 재지 못함)
  → 1단으로는 여전히 스크롤이라 2단이 필요하다고 판단했습니다.
- **글자·여백을 줄여 1단에 맞추기** — «PC에서 글자가 너무 작다»(2026-07-13 지시)를 되돌리게 되어 버림.
- **왼쪽 묶음을 감싸는 div 를 새로 만들기** — 폰(1단)에서 «위험한 조작(대화 초기화)은 맨 아래» 순서가
  깨집니다(묶음 안에 들어가 설정보다 위로 올라감). 그래서 DOM 순서는 그대로 두고 그리드 자리만 정했습니다.
- **2단 기준을 900px 로** — 760~899px 창(800x600 실측)이 1단으로 남아 916px 를 스크롤 → 760px 로 맞춤.

## 5. 남은 것 / 주의할 것

- **사람이 화면에서 한 번 봐야 끝**입니다(원격 컨테이너는 mangoi.ai 실제 화면을 못 봄).
- 폰은 내용이 화면보다 길어 스크롤이 남습니다 — 완전히 없애려면 폰 전용 압축 배치가 필요(사람이 정할 일).
- 폰에서 시트 바깥(어두운 띠)이 118px → 12px 로 줄어 «바깥 눌러 닫기» 자리가 작아졌습니다. 닫기 버튼·Esc 는 그대로지만
  시트 머리(닫기)가 sticky 가 아니라 아래로 굴리면 닫기가 화면 밖으로 갑니다(함정 대조 지적 — 사람이 정할 일).
- PC 에서 열린 시트가 헤더 오른쪽(⚙·🏠·🌐 자리)을 덮어, ⚙ 자리를 다시 눌러 닫던 동작이 안 됩니다(닫기 버튼이 바로 그 자리에 있음).
- viewport-fit=cover 인데 시트 top 에 safe-area-inset-top 이 없어 노치 기기 standalone 화면에서 머리가 노치 밑에 들 수 있습니다(확인 못 함 · 헤더 .top 도 같은 처지).
- 새 «위에 붙음 + 스크롤 없음» 검사는 manual(사람이 부름)이라 CI 에서 돌지 않습니다. PC 크기는 1920x1080·1280x800 두 개.
- `ai-friend-header-browser.mjs` 의 기존 실패 11건(대화창이 화면 절반 미만 등)은 별건으로 남아 있습니다.
