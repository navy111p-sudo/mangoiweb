# A.i 친구하기 — 설정 시트를 폰에서도 «스크롤 없이 한 화면» 으로

- 날짜: 2026-11-04
- 작업자: Claude (사장님 요청)
- 브랜치 / PR: `ai-friend-settings-sheet-phone`
- 앞 작업: [261104_AI친구하기_설정시트_위로_2단.md](261104_AI친구하기_설정시트_위로_2단.md) (PR #2063 — PC 를 위로·2단)

## 1. 왜 했나

PR #2063 배포 뒤 사장님 «폰도 스크롤 없이 보이게 해줘».

잰 것(헤드리스 크로미움, 폰 에뮬레이션, 2026-11-04 · 고치기 전 main):

| 화면 | 시트 내용 높이 | 시트 칸 | 결과 |
|---|---|---|---|
| 폰 390x844 | 865px | 831px | 스크롤 |
| 폰 360x640 | 912px | 627px | 스크롤 |
| 폰 320x568 | 985px | 555px | 스크롤 |

가장 큰 몫은 «레벨:·스타일:·교정:·속도:·친구:·자막:» 이름표가 섹션마다 **한 줄씩 통째로**
먹는 것이었습니다(여섯 줄 × 약 30px). 그다음이 퀘스트 칩 세 줄, «AI 목소리 듣기» 와
레벨 상태(Lv 칩)가 각각 한 줄씩이었습니다.

## 2. 무엇을 바꿨나

`cloudflare-deploy/public/ai-friend.html` 하나.

- **JS(시트를 만들 때 한 번)** `groupOptRows()` — 설정을 «이름표 + 그 버튼들» 묶음
  (`.opt-row` = `span` + `.opt-list`, `role="group"` · `aria-labelledby`)으로 감쌉니다.
  버튼을 찾는 코드는 전부 «자손» 선택(`.opt[data-level]`·`.opts .opt…`)이라 동작은 그대로입니다.
- **폰(<760px) CSS**
  - 설정은 «이름표 칸 | 버튼 칸» 두 열(`grid-template-columns:max-content …` + `.opt-row{display:contents}`).
    이름표 칸 폭은 가장 긴 이름표에 저절로 맞습니다(영어 «Correction:» 도 안 겹침).
  - 레벨 여덟 칸은 한 줄에 똑같이 나눔. 아주 좁은 폰(≤340px)만 레벨 줄을 이름표 아래 한 줄 전체로(칸이 23~26px 로 좁아져서 → 약 33px).
  - «🔊 AI 목소리 듣기» 와 Lv 칩을 한 줄에(자리가 모자라면 저절로 다음 줄) — Lv 칩의 경험치 막대만 36px 로.
  - 퀘스트는 이름표 한 줄 + 칩 두 개씩.
  - 손잡이·줄 사이·아래 줄(대화 초기화) 여백을 몇 px 씩.
    ⚠️ 아래 줄 여백 규칙은 처음엔 **안 먹었습니다** — 뒤쪽 기본 `.sheet-danger` 와 특이성이 같아 그쪽이 이겼습니다.
    함정 대조가 실측으로 잡아 `.opts-sheet .sheet-danger` 로 올렸습니다(첫 이름표의 2px 위 여백도 같은 이유로 함께).
  - 폰 경계는 `max-width:759.98px` — PC 블록(`min-width:760px`)과 사이에 빈틈(브라우저 확대 시 759.x px)이 없게.
  - ⛔ 글자 크기는 그대로(버튼 12.5px).
- **PC** 는 예전 모양 그대로(이름표 위·버튼 아래). 시트 높이 553px 로 고치기 전과 같음(실측).
- **곁가지 수리**: 시트 안 «🗑 대화 초기화» 가 **흰 기본 버튼**으로 보였습니다 — 스타일이
  `.top .clear-btn` 에만 있어 시트로 옮겨진 뒤 빠졌던 것. `.sheet-danger .clear-btn` 으로 같은 빨간 스타일을 되살림(PC·폰 공통).
- 브라우저 검사 `test-harness/manual/ai-friend-header-browser.mjs` 에 추가:
  폰(폭 ≥360) «스크롤 없이 전부» · 여섯 줄이 이름 붙은 묶음 · «폰은 이름표 왼쪽 / PC 는 위»(짝) ·
  대화 초기화 버튼 색 · 묶음 안 속도 버튼을 눌러 그것만 켜지는가.

## 3. 검토했다가 버린 방법

- **글자·버튼을 줄여 맞추기** — 아이가 누르는 버튼이라 버림(PC 쪽 «글자가 작다»(2026-07-13) 지시와도 반대).
- **이름표에 고정 폭 주기** — 한국어는 맞아도 영어(«Correction:» 68px)가 버튼 위로 겹침. 그래서 `max-content` 열.
- **CSS 만으로 이름표를 줄 왼쪽에(음수 여백·float 꼼수)** — 섹션마다 «줄을 새로 시작» 시킬 방법이 없어
  읽기 어렵고 깨지기 쉬움 → 시트를 만들 때 묶음으로 감싸는 쪽을 택함.
- **«🏆 오늘의 퀘스트:» 이름표 숨기기** — 칩만으로는 «퀘스트» 인지 알기 어려워 안 함.

## 4. 확인한 방법

- 실측(폰 에뮬레이션 — 실제 폰처럼 스크롤바가 폭을 안 먹음), 고친 뒤 시트 내용 높이:

  | 화면 | 한국어 | 영어 |
  |---|---|---|
  | 412x780 · 390x664 | 571px — 스크롤 없음 | 390x664: 587px — 없음 |
  | 360x640 | 571px — 없음 | 622px / 칸 622 — 없음 |
  | 360x600 | 571px — 없음 | 622 / 칸 587 — **35px 넘침** |
  | 375x548(아이폰 SE 사파리 정도) | 571 / 칸 535 — **36px 넘침** | — |
  | 320x568 | 778px — 넘침 | 789px — 넘침 |

  ⟹ 한국어는 «창 높이 약 585px 이상», 영어는 «약 635px 이상» 인 폭 360~412 폰에서 스크롤 없음.
  PC 용 크로미움(스크롤바가 폭을 먹음)에서도 한국어 360x640 은 609px 로 들어감.
- PC 1920x1080 · 1366x640 · 1024x700 은 553px(영어 498px) 그대로(고치기 전과 같음), 스크린샷으로도 같은 모양.
- `ai-friend-header-browser.mjs`: 고친 뒤 **99 PASS / 11 실패**, main **85 PASS / 25 실패**.
  남은 11건(대화창 비율·헤더 넘침·이름 잘림)은 main 에서도 똑같이 실패하는 기존 항목.
  새 검사 14건은 main 에서 실제 FAIL(폰 스크롤 2 · 묶음 5 · 버튼 색 5 · 영어 폰 스크롤·이름표 2).
  ⚠️ 영어 폰 절만 «폰 에뮬레이션» — PC 크로미움은 스크롤바가 폭 15px 를 먹어 버튼이 한 줄 더 넘어가는 연쇄로
  656px 가 나오는데, 실제 폰은 스크롤바가 폭을 안 먹어 622px 입니다.
- 변이(고친 판을 일부러 되돌려 검사가 잡는지 — 전부 실제 FAIL):
  - 폰 2열(`.opt-row{display:contents}`)을 빼면 → «폰은 이름표가 왼쪽» 3건 + «360x640 스크롤 없음».
  - 폰 배치가 PC 에도 새면(미디어쿼리 무력화) → «PC 는 이름표가 위» 2건.
  - 아래 줄 여백 규칙을 옛 특이성(`.sheet-danger`)으로 되돌리면 → «영어 폰 스크롤 없음»(634/627).
  - 좁은 폰(≤340) 레벨 줄 규칙을 빼면 → «작은 폰은 레벨 줄만 이름표 아래».
- 회귀 하니스 `node test-harness/run.mjs --fast`: 이 브랜치·main 사본 모두 PASS 638 / SKIP 20,
  실패 목록 38건이 한 줄도 다르지 않음(컨테이너에 `node_modules` 가 없어 생기는 환경 사유) → 새 실패 0건.
- 함정 대조(trap-check)가 «여백 규칙이 특이성에 져 안 먹음»·«INDEX 가 영어 조건 없이 스크롤 0 이라 적음» 을 잡아 둘 다 고쳤습니다.

## 5. 남은 것 / 주의할 것

- **사람이 실제 폰에서 한 번 봐야 끝**입니다(원격 컨테이너는 mangoi.ai 화면을 못 봄).
- 아이폰 SE 처럼 창이 아주 낮은 폰(약 550px)과 320폭 옛 폰은 아직 조금 스크롤됩니다.
  더 줄이려면 퀘스트 이름표를 숨기거나 버튼을 줄여야 해서 사람이 정할 일입니다.
- 영어 화면은 창이 약 635px 보다 낮으면 조금 스크롤됩니다(퀘스트 칩이 길어 세 줄).
- 레벨 버튼 폭: 폭 341~359 의 영어 화면에서 약 27px(360폭 27.8px 실측)로 main(35.9px)보다 좁습니다 — 높이 38.7px · 간격 4px.
- 시트에 새 설정 줄을 넣을 때는 «이름표 span 다음에 버튼들» 모양으로 — span 이 묶음의 시작 표시입니다.
- 폰에서 시트 머리(닫기)가 sticky 가 아닌 것은 그대로 — 이제 스크롤이 없어 닫기가 늘 보입니다(작은 폰 제외).
