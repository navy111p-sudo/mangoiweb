# 교재 연습 «자유대화» 교정 방식 — 교정 카드만, 고친 문장은 말하지 않기 (2026-11-04)
# Textbook practice «Free talk» correction mode — card only, no spoken correction

- 날짜: 2026-11-04
- 작업자: Claude Code (요청: 사장님)
- 브랜치 / PR: `warmup-free-talk-card-only` / PR 은 이 기록과 함께 올림

## 1. 왜 했나

2026-11-03 A.i 친구하기 균형 교정 작업([작업기록](261103_AI친구_균형교정_음성_다시묻기_정직한칭찬.md))에서
교정 방식 약속을 이렇게 정했다(사장님 정의).

| 교정 방식 | 약속 |
|---|---|
| 자유대화 | 교정 카드만 — 고친 문장을 말로 하지 않는다 |
| 균형 | 교정 카드 + 고친 문장을 질문보다 먼저 **한 번** 말한다 |
| 집중교정 | 교정 카드 + "You can say..." 고친 문장 **3번** |

A.i 친구하기는 이 약속대로 고쳤지만, **교재 연습(웜업)의 자유대화**는 여전히 고친 문장을 말로 했다.
그때 남긴 «알아 두실 점»에 대해 사장님이 「교재 연습 자유대화도 교정 말 없이 카드만 나오게 해줘」로 정하셨다.

코드에서 확인한 원인은 두 겹이다.

| 원인 | 근거 |
|---|---|
| ① 서버가 모드와 상관없이 고친 문장을 앞에 붙였다 | `src/index.ts` 웜업 핸들러: `if (showFix && honest?.mode !== 'focused') aiText = correctionLeadIn(…)` — 집중교정만 빼고 자유대화·균형 모두 `Let's say it like this: "…"` 가 붙었다 |
| ② 프롬프트가 모든 모드에 «고친 문장을 따옴표로 먼저 말해»를 시켰다 | `src/warmup-correction.ts` 의 `WARMUP_CORRECTION_RULE` — 「⛔ 교정(fix)이 있으면 답장은 «반드시» 고친 문장을 따옴표로 먼저 말하고…」. 자유대화 모드 줄(`MODE_LINES.free_talk`)은 이것을 덮지 않았다 |

⟹ ①만 고치면 서버는 안 붙여도 **모델이 스스로 말한다**. 둘을 함께 고쳤다.

## 3. 검토했다가 버린 방법

1. **서버의 `correctionLeadIn` 조건만 바꾸기 → 버림.** 웜업 기본 [교정] 규칙이 모든 모드에 «고친 문장을 따옴표로 먼저 말해»를 시키므로 모델이 스스로 말한다. 프롬프트도 함께 덮어야 한다.
2. **기본 [교정] 규칙(`WARMUP_CORRECTION_RULE`)에서 그 줄을 지우기 → 버림.** 균형은 그 줄에 기대고(서버도 한 번 더 보장), 중국어·모드 없는 턴도 같은 규칙을 쓴다. 자유대화 모드 줄에서만 «우선»으로 덮었다.
3. **자유대화뿐 아니라 균형도 카드만으로 → 버림.** 사장님 정의상 균형은 «한 번 말하기»다(A.i 친구와 같은 약속).
4. **자연스러운 되말하기(recast)까지 금지 → 하지 않음.** 예: 학생 "I go to school yesterday" → AI "Oh, you went to school yesterday! What did you do there?" 이 저장소는 이것을 «고친 문장을 말한 것»으로 보지 않는다(`warmup-correction.ts` ④ 주석 — 실측상 고친 문장이 말해지지 않았다고 기록). 막으면 대화가 어색해진다. 사장님께 «남아 있는 것»으로 보고하고 원하시면 따로 막는다.
5. **`index.ts` 에 모드 이름을 직접 적기(`!== 'focused' && !== 'free_talk'`) → 버림.** 판정을 정본 함수로 빼야 하니스가 실제로 돌릴 수 있고, A.i 친구처럼 두 벌이 되지 않는다.

## 5. 못 한 것 · 남은 것

- **실제 모델 응답은 못 봤다.** 프롬프트 덮기가 지켜지는지는 가짜 응답과 규칙 글자로만 확인했다. 서버는 더 이상 고친 문장을 붙이지 않지만, 모델이 지시를 어기고 따옴표로 말할 가능성은 남는다(그때는 균형처럼 서버가 «떼어 내는» 단계를 따로 둬야 한다).
- **자연스러운 되말하기(recast)는 남아 있다**(3절 4번) — ✅ 2026-11-04 사장님 결정: **그대로 둔다**(「되말하기는 그대로 둬줘」).
- **배포된 화면은 못 봤다**(작업 환경 프록시가 `mangoi.ai` 를 막음). 교재 연습 › 교정 방식 «자유대화»로 일부러 틀리게 말해 보고, 카드만 뜨고 아바타가 고친 문장을 따로 말하지 않는지 사람이 확인해야 끝난다.
- 중국어 교재 연습은 교정 방식이 없어(서버 `resolveWarmupHonest` 가 null) 예전처럼 고친 문장을 말한다 — 이번 범위 밖.
