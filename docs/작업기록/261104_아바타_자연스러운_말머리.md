# A.i 말하기·A.i 친구 자연스러운 말머리

## 요청과 선택
완성된 답변 앞에 상황에 맞는 Well, Maybe, Sure, Wow, Oh 등을 사용한다. 사용자가 대기 중 선행 음성이 아닌 답변 앞 표현을 선택했다. 발음이 어색해지지 않도록 표준 철자와 보통 문장부호를 사용하고 늘인 철자·발음 흉내·SSML·과도한 말줄임표를 지시에서 금지한다.

## 변경
conversation-connectors.ts의 공용 규칙을 말하기와 친구에만 연결했다. 친구 음성 모드의 skip filler 지시와 충돌을 없앴다. 학생 수준·길이·공감 규칙이 우선이며, 집중교정은 You can say 한 번과 동일 교정문 세 번을 그대로 유지한다. 후처리로 임의 감탄사를 붙이거나 별도 음성을 생성하지 않는다. 중국어·엘리더잼 고정 형식·수업 즉답은 기존 규칙 그대로다.

## 확인 한계
프롬프트 배선·교정 순서는 실행 검증했으나, 실제 모델의 모든 답변 준수나 음성 엔진의 발음 품질을 직접 청취한 것은 아니다. 기존 음성 엔진·속도를 변경하지 않았다. 이전의 이상한 발음 원인은 실제 음성 표본 없이 확정하지 않는다. 배포 완료는 Actions와 운영 BUILD_STAMP 확인 뒤 보고한다.
