## 1. 왜 했나 — 잰 것

  - 학생 「Goodbye yesterday is very nice.」 → 지시는 «좋은 소식 "Oh, cool!" / 평범한 정보 "Oh, okay."» → 답은 «Nice sentence!»

## 2. 원인 — 코드에서 확인한 것

같은 «답의 첫 자리» 를 두 지시가 다퉜다.

- `api-ai.ts`: 첫마디 줄보다 앞에 «잘했으면 칭찬으로 시작 — Rotate freely: Nice!, Great try! … Nice sentence! …(15개)» 가 있었다.
- `warmup-correction.ts`: 맨 끝 출력 형식 줄이 «obey … level, sentence limit, **cheer**, emojis …» 였다(모델이 답을 쓰기 직전에 읽는 줄).
- 첫마디 칸에 «학생이 잘 해냈을 때» 가 없었다 → 고친 문장을 제대로 말한 순간엔 «Great job!» 이 오히려 맞는 반응이다.
- [판단 — 추론] 칭찬 쪽이 더 구체적이고 더 자주, 맨 끝에서도 나오니 모델이 칭찬을 골랐다.

곁가지로 찾은 구멍(틀린 문장 칭찬):

- 틀린 문장이면 칭찬을 떼는 서버 장치는 `warmup-empathy.ts` 의 `CHEER_LEADS` 하나다(웜업 `applyHonestPraise`, AI 친구 `stripPraiseLead`, 두 화면의 미리듣기 문 모두 이 표를 쓴다).
- 그런데 새 첫마디 «Oh, nice! / Oh, cool! / Oh, great! / Oh, wow! / How fun!» 은 그 표에 없어서 **틀린 문장에도 그대로 나갈 수 있었다.**
- AI 친구는 «검증을 통과한 교정이 있을 때만» 칭찬을 뗐다 — 모델이 «틀렸다» 고 교정을 냈는데 검증에서 떨어진 턴은 칭찬이 남았다(미리듣기 문은 그 턴을 이미 «틀린 턴» 으로 봤다 — 두 판정이 어긋남).

## 3. 고친 것

1. `conversation-connectors.ts`
   - «잘 해냈을 때» 칸 `TURN_PRAISE`(Great job! · Nice sentence! · You got it! · Well done! · Perfect!) — 첫마디 표와 **따로** 둬서 칭찬으로 시작한 다음 턴은 쉬지 않는다.
   - 이번 턴 줄이 «이것이 반응이자 칭찬 — 다른 칭찬을 더하지 말고, 틀린 영어는 칭찬하지 마» 를 말하고, 실수가 있으면 «평범한 정보» 칸(Oh, I see. 등)으로 받게 했다.
   - 고정 규칙에서 겹치는 말을 줄여 지시 길이 1,214자(상한 1,221자) — 속도 그대로.
2. `api-ai.ts` — 첫마디 줄이 실리는 턴엔 칭찬 목록을 빼고 «첫마디가 곧 반응이자 칭찬» 한 줄만. 쉬는 턴엔 예전 칭찬 규칙 그대로 + «(never cheer English that has a mistake)».
3. `warmup-correction.ts` — 출력 형식 줄 «cheer» → «opener or cheer».
4. `warmup-empathy.ts` — 칭찬 판정이 앞의 «Oh,» 를 함께 본다(«Oh, nice!» 도 칭찬). «How fun/cool/nice» 추가. ⛔ «Oh» 만으로는 떼지 않는다(«Oh, I see.»·«Oh, really?»·«Oh no.» 는 그대로).
5. `friend-correction-flow.ts` + `api-ai.ts` — AI 친구는 모델이 교정을 내놓은 턴(`rawFix`)이면 검증에서 떨어져도 칭찬을 뗀다(`suspect`). 잃는 것은 칭찬 한마디뿐이라 이쪽으로 실패하게 했다.

적용 범위: A.i 말하기 카드 3장(📘 교재로 연습 · 🎯 상황별 말하기 · 👫 AI 친구하기) × 교정 정도 3가지(자유·균형·집중) 전부. 「상황별 말하기」는 「교재로 연습」과 같은 `/api/warmup/chat` 을 쓰고 역할 지시만 다르게 보낸다(`warmup.html` 4034행).

`src/index.ts`(공동 금지구역)는 한 글자도 안 고쳤다.

## 4. 버린 방법

- **칭찬 규칙을 지우기** — 칭찬은 아이에게 필요하고(2026-08 «정직한 칭찬» 결정), 사장님 지시도 «합쳐» 였다.
- **첫마디 줄을 칭찬 목록보다 앞으로 옮기기만** — 지시를 둘 다 두면 여전히 다툰다. 순서보다 «한 자리» 가 근본이다.
- **칭찬도 «첫마디» 로 쳐서 다음 턴을 쉬게** — 쉬는 턴의 칭찬 규칙과 이어져 «칭찬 → 칭찬» 이 다시 연달아 붙는다.
- **«Oh, nice» 를 표에 낱개로 넣기** — 모델이 «Oh, awesome!»·«Oh, perfect!» 처럼 바꾸면 또 샌다. 판정식에 «Oh,» 머리를 둬서 기존 칭찬 전부를 덮었다.
- **웜업 등급 판정(`finalizeWarmupGrade`)에 모델 교정 여부를 더하기** — `src/index.ts` 호출부를 바꿔야 해서 안 했다(아래 «남은 것»).
