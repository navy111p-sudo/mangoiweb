# 연기·변경한 수업을 원래 날짜에 «⏸ 연기됨 → 새 날짜» 로 남기기

- 날짜: 2026-11-04
- 작업자: Claude Code (요청: 사장님 계정 — 필리핀 매니저 Mai 제보 전달)
- 브랜치: `postponed-stays-on-original-date`

## 1. 왜 했나

- 제보(영문, 「📅 Postpone / move class」 창 스크린샷과 함께):
  «At manager's page and teacher's page, can we not delete the schedule if being cancelled? Can we add another column state it is cancelled or postponed.

- 실측(코드):
  - **취소** 는 2026-11-03(PR «취소수업 지우지 않고 취소·연기 칸»)부터 이미 남아 있다 — 행이 `status='cancelled'` 로 그대로 있고 조회가 받는다.
  - **날짜를 정해 연기·변경** 하면 같은 `class_schedules` 행이 새 날짜로 «옮겨 간다»(PR #1889 규칙 — 되돌리지 말 것).
    ⟹ 원래 날짜의 목록·달력에서 그 수업이 **통째로 사라졌다.** 이것이 남은 «사라짐» 이었다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **취소 버튼 없애기** — 매니저 제안이었지만 사장님 지시가 «표시만» 이었다. 그리고 없애면 생기는 문제(끝내 안 열릴 수업을 닫을 길이 없음 · 연기로 대신하면 빈 방 대기·노쇼 기록·급여 100% · 카페24 잔재가 15분마다 되살아남)는 별도 1장 영문 안내서로 매니저에게 설명했다(아래 6장).
- **연기를 «새 행» 으로 만들기(원래 행은 남기기)** — PR #1889 의 «같은 ID 를 옮긴다» 규칙을 되돌린다(학생 입장·결석 감지·급여가 그 전제 위에 서 있다). ⛔ 그래서 «읽을 때» 원래 날짜 줄을 만들었다 — DB 는 한 글자도 안 바뀐다.
- **`class_audit_log` 하나만 근거로** — 변경 요청 승인 경로(`/schedule-requests/decide`)는 그 로그를 best-effort 로 쓴다(실패해도 승인은 됨). 로그만 보면 그 경우가 조용히 빠진다 ⟹ 승인 행(원자적)을 먼저 보고 로그는 PATCH 이동용 보조로.
- **화면에서 판정** — 세 화면(admin·manager·branch) + 강사 화면이 각자 문구를 만들면 갈라진다 ⟹ 서버 정본이 KO/EN 글자까지 만들고 화면은 그리기만.
- **원래 날짜 줄에도 출결 보강(`enrichClassesToday`)** — 원래 방에는 아무도 안 들어오므로 «결석 / 입장 기록 없음 ⚠» 으로 그려져 거짓이 된다 ⟹ 안 태우고 «모름» 으로 채움.
- **강사 «오늘 목록» 에도 넣기** — 오늘 목록은 입장 버튼·다음 수업 띠·알림이 걸린 «할 일» 목록이라, 수업이 없는 줄이 섞이면 «들어가야 하나?» 로 읽힌다 ⟹ 달력(주간·월간)에만.

## 5. 남은 것 · 알고 둔 한계

- **날짜 없이 연기한 수업**(`status='postponed'`, 같은 날짜)은 원래부터 그 날에 «연기됨» 으로 남아 있다 — 이번 변경과 무관.
- **카페24 수업**(c24-*)은 이 저장소가 행을 옮기지 않으므로 해당 없음.
- **매주 반복 수업의 «그 주 하루만» 연기**는 2026-10-08 부터 원래 날에 `postponed` 자리표시 행이 따로 생겨 이미 보인다.
- 학생 «이력» 창(teacher-student-history)은 이번에 안 건드렸다(새 날짜에만 보임).
- 근거가 둘 다 없는 옛 이동(감사로그·승인 행 모두 없음)은 원래 날짜를 알 수 없어 줄을 만들지 않는다 — 지어내지 않는다.

### 아직 그대로 둔 것(알고 둔 한계 · 사람이 정할 일)
- **원래 날짜 줄의 강사 = «지금» 담당 강사** — 연기하면서 강사도 바꿨다면 원래 날짜 줄이 새 강사 달력에 뜨고 원래 강사 달력에선 안 뜬다(원래 강사를 알려면 변경 요청의 snapshot 을 읽어야 함 — 별건).
- **«옮긴 뒤 취소됨»** 인 줄은 관리자 화면에 뜨지만, 취소된 새 날짜가 보고 있는 범위 밖이면 강사 달력에는 안 뜬다.
- **영구 변경(«변경·앞으로 계속», series-move)** 도 원래 날짜마다 «⏸ 연기됨 →» 으로 뜬다 — 줄 글자를 «변경» 으로 가르려면 이력의 출처(source)를 판정에 넣어야 함(별건).
- 강사 포털은 자동 새로고침마다 이 조회를 한다(이제 범위 스캔).
