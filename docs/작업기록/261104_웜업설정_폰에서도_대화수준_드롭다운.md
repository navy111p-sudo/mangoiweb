# 웜업 설정 화면: 폰에서도 대화 수준을 드롭다운으로

- 날짜: 2026-11-04
- 작업자: Claude (사장님 요청)
- 브랜치 / PR: `claude/warmup-level-dropdown-mobile`

## 1. 왜 했나

사장님이 휴대폰 화면 캡처와 함께 요청하셨습니다.

> 휴대폰에서 대화수준은 드롭다운으로 해서 공간을 스크롤 안하고 한번에 모든 페이지 보게 해줘.
> 이게 공간을 너무 많이 차지하고 복잡해.

A.i 말하기(`warmup.html`) 시작 전 설정 화면의 «🎚️ 대화 수준» 이 폰에서 **8칸 카드 목록**
(첫걸음 ~ 최상급)으로 세로로 늘어서 있었습니다. PC(1100px 이상)는 2026-10-18 B안부터 이미 드롭다운이었고,
폰만 목록이었습니다.

[잰 것 — 390×844, 헤드리스 크로미움]
| | 바꾸기 전 | 바꾼 뒤 |
|---|---|---|
| 대화 수준 묶음 높이 | **757px** | **209px** |
| 설정 화면 전체 높이 | 2,928px | 2,381px |
| PC 1920×945 전체 높이 | 990px | 990px (그대로) |

## 2. 무엇을 바꿨나

`cloudflare-deploy/public/warmup.html` 한 파일.

- **CSS** — 드롭다운 모양을 PC 전용 미디어쿼리에서 꺼내 **폰·PC 공용 한 벌**(`.wus-sel` / `.wus-selnote`)로 합쳤습니다.
  - `#wusLevelSel`·`#wusLevelNote` 는 모든 폭에서 보이고, 8칸 목록 `#wusLevels` 는 모든 폭에서 숨습니다.
  - 나이대 드롭다운(`#wusAgeSel`)은 **PC 에서만** 켭니다 — 폰은 사진 카드 그대로입니다.
  - PC 블록에는 «나이대 켜기 + 글자 18px» 만 남겼습니다(같은 스타일을 두 벌 두지 않게).
  - 글자 17px — 16px 미만이면 아이폰이 누를 때 화면을 확대합니다.
- **이름 정리** — 폰에서도 쓰게 되어 `pc` 를 뗐습니다(전부 이 파일 안에서만 쓰이던 이름, 하니스 참조 0건 확인):
  `.wus-pcsel`→`.wus-sel`, `.wus-pcnote`→`.wus-selnote`, `wusPcSync()`→`wusSelSync()`, `wirePcSelects`→`wireSelects`.
- **동작 로직은 그대로** — 드롭다운 `change` 가 숨은 목록 버튼(`#wusLevels [data-lvl=N]`)을 `click()` 해서
  기존 위임 처리(`wireSetup` → `setLevel` → `renderSetup` → `wusSelSync`)를 그대로 탑니다. 저장·판정·⋮ 메뉴 갱신을 새로 만들지 않았습니다.
- 옛 주석 «수준이 8줄이라 휴대폰에서는 끝까지 내려야 보인다»(시작 버튼 sticky 이유)를 현재 사실에 맞게 고쳤습니다.

브라우저 검사(`test-harness/manual/`, 자동으로 안 돕니다):
- `warmup-setup-browser.mjs` — 수준은 `selectOption('#wusLevelSel')` 로 고릅니다(도우미 `pickLevel`).
  5절(폰 390)에 «드롭다운 보임 · 목록 숨김 · CEFR 8개 · 16px 이상 · 폭 안 · 묶음 300px 이하 ·
  고르면 버튼 선택/설명/⋮ 메뉴/저장이 따라옴(짝)» 을 더했습니다.
  옛 문구 «웜업 시작하기» 를 기대해 **원래부터 늘 FAIL** 이던 시작 버튼 검사를 뜻(«계속하기» 가 아니라 «시작하기»)대로 고쳤습니다.
- `warmup-ui-lang-browser.mjs` · `ai-friend-8levels-browser.mjs` — 숨은 목록 대신 드롭다운을 고르고 읽습니다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **8칸 목록을 지우기** — 버렸습니다. 저장·판정·⋮ 메뉴 갱신이 그 버튼의 위임 처리에 있고, PC 드롭다운도 이미
  «숨은 버튼을 대신 누르는» 방식(2026-10-18)이라 같은 길을 쓰는 것이 가장 적게 바꿉니다. 목록을 지우면 판정을 드롭다운 쪽에 새로 만들어야 하고
  두 벌이 됩니다. HTML 주석에 «⛔ 목록을 지우지 마세요» 를 남겼습니다.
- **폰 전용 드롭다운을 새로 만들기** — 버렸습니다. PC 드롭다운이 이미 같은 값·같은 설명을 그리고 있어, CSS 로 «폰에서도 보이게» 만 하면 됩니다.
- **나이대도 함께 드롭다운으로** — 이번에는 안 했습니다. 요청은 «대화 수준» 이었고, 나이대 사진 카드는 아이가 고르기 쉽게 둔 것이라 사장님 판단이 필요합니다.
- **«스크롤 없이 한 화면» 까지 압축(교정 방식·말하는 방법 설명 숨기기 등)** — 이번에는 안 했습니다. 대화 수준만으로는 2,381px(폰 약 2.8화면)이라
  한 화면은 아닙니다. 남은 큰 칸은 나이대 533px · 교정 385px · 말하는 방법 252px 이고, 교정 3가지 칸은 2026-10-29 사장님 결정(«첫 페이지에, 선택할 수 있게»)이 걸려 있어
  지시 범위 밖이라 먼저 여쭙기로 했습니다(4-1-1 «지시 범위를 벗어나는 것»).

## 5. 남은 것 / 주의할 것

- ⚠️ **폰은 여전히 스크롤이 있습니다**(2,381px). 더 줄이려면 나이대·교정·말하는 방법 칸을 손봐야 하고 사장님 결정이 필요합니다.
- ⚠️ **PC 1920×945 에서 이미 45px 넘칩니다**(990/945, 이번 변경 전부터). B안의 «PC 스크롤 없이 한 화면» 이 깨져 있는 상태라 따로 볼 일입니다.
- 대화 수준을 고르는 브라우저 검사를 새로 쓸 때는 `page.click('#wusLevels …')` 이 아니라 **`page.selectOption('#wusLevelSel', N)`** 입니다(숨은 버튼 click 은 30초 시간초과).
- `ai-friend-8levels-browser.mjs`·`warmup-ui-lang-browser.mjs` 는 크로미움 경로(`chromium-1194`)가 박혀 있어 지금 컨테이너(`chromium-1243`)에서는 경로를 바꿔야 돕니다(이번에 고치지 않음).
- 화면이 바뀌는 작업이라 **배포 뒤 사람이 휴대폰에서 한 번 봐야 끝**입니다(4-1-1).
