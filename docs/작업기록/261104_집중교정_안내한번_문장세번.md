# 집중교정 안내 한 번, 교정 문장 세 번

사용자 요청: A.i 말하기·A.i 친구의 집중교정에서 You can say는 한 번만 말하고 교정된 문장은 총 세 번 말한다.

공통 ensureFocusedFixSpoken에서 안내를 반복문 밖으로 옮겼다. 프롬프트와 기존 검사도 같은 계약으로 맞췄다. 예: You can say... "My favorite animal is a lion." "My favorite animal is a lion." "My favorite animal is a lion." Can you say it with me?

화면별로 따로 고치는 방법은 배제했다. 두 API가 이미 공유하는 정본 한 곳을 바꾸어 누락 복구·저장·재생이 같은 문장을 사용한다. 집중교정 외 모드와 교정 문장 3회, 교정 우선 순서는 유지한다.

검증 결과 및 병합·배포 확인은 PR에 기록한다. 실제 운영 음성 직접 청취는 하지 않았다. 운영 DB 테스트 변경 없음.
