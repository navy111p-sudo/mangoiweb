## 이번 변경

기존 환경에서 403으로 받지 못했던 사용자 소유 Higgsfield 활주로·뗏목 배경을 원래 CDN에서 정상적으로 받았다. 파일 크기는 각각 79,738 / 103,696 bytes이며 두 이미지를 직접 확인했다. 생성 모델을 사용하거나 얼굴·입모양·몸통·음성 함수를 수정하지 않았다.

`warmup-flow.js`의 기존 배경 선택·저장·실패 복귀 경로에 두 이미지를 연결했다. 활주로·뗏목을 명시한 주제만 자동 연결하고 일반 여행/바다의 기존 선택은 유지했다. HTML의 해당 스크립트 버전을 5에서 6으로 올렸다.

## 확인한 범위

- TypeScript noEmit 통과.
- 추가 배경 브라우저 33개 통과: 휴대폰·태블릿·PC 크기, 실제 이미지 로드·선택 저장·주제 변경·세션 유지.
- 기존 검사를 포함한 전체 대화 화면 브라우저 402개 통과.
- 몸통 브라우저 60개 통과.
- 로컬 전체 fast 회귀 결과는 608 PASS / 21 SKIP / 71 FAIL(376초)이다. Windows 절대경로(`C:\C:\...`) 및 sparse checkout에서 제외한 보조 파일 때문에 실패가 발생했다. 통과로 계산하지 않는다. PR의 Linux 전체 checkout CI를 최종 게이트로 사용한다.
- 실제 AI 검증은 D1·KV·R2 local, AI만 remote인 Wrangler 개발 서버에서 수행했다. 첫 기동은 Request.cf 시간 초과/ECONNRESET으로 실패했으나 재시도 후 정상 기동했다. 익명 로컬 세션에 실제 AI 답변 HTTP 200, 실제 TTS HTTP 200(audio/mpeg, 14,544 bytes)을 확인했다. Chrome AudioContext 디코딩 결과 2.424초 / 48kHz / RMS 0.05543 / peak 0.43727로 무음이 아닌 정상 오디오였다. 운영 DB에 테스트 쓰기를 하지 않았다.
- 물리 휴대폰/태블릿 마이크·스피커·소프트키보드와 실제 STT는 미검증이다. 브라우저 크기 검사를 실기기 검증으로 계산하지 않는다.
