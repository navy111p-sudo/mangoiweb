# 강사 소개 창에서 «수업 입장» 버튼 삭제

- 날짜: 2026-11-05
- 작업자: Claude Code (사장님 요청)
- 브랜치: `teacher-gallery-remove-join`

## 1. 왜 했나

사장님 화면 캡처(휴대폰 폭, Teacher Ness 프로필)의 «🎥 수업 입장» 버튼에 빨간 동그라미와 함께:
「수업 입장은 삭제해줘」 · 「교사소개에서 수업입장은 삭제해줘」.

이 버튼은 어제(11/4) 새 강사 소개 창으로 옮길 때 «기능 삭제는 묻고 해야 한다» 며 일부러 남긴 것입니다
([261104 기록 3장 8번](261104_강사소개창_스플릿뷰_힉스필드그림_평점제거.md)). 눌러도 그 강사의 방이 아니라
**공용 수업방**(`mangoiJoinClass('')`)으로 가서, 강사 소개 창에 있을 이유가 약했습니다.

## 3. 검토했다가 버린 방법

1. **CSS 로 버튼만 숨기기(`display:none`)** — 버림. 화면에는 안 보여도 키보드·스크린리더로는 닿고, 문구·동작 코드가 남아 «누가 다시 켜는» 길이 됩니다. 그리는 코드 자체를 뺐습니다.
2. **`window.mangoiJoinClass` 까지 지우기** — 버림(지시 범위 밖). 홈·다른 화면의 실제 수업 입장이 그 함수를 씁니다. 강사 소개 창이 그것을 «부르지 않게» 만 했습니다.
3. **영상 없는 강사에게도 빈 `.tg-d-actions` 줄을 그대로 두기** — 버림. 버튼이 하나뿐이던 강사는 빈 줄 + `gap` 만 남아 이름 밑이 어색하게 벌어집니다. 영상 버튼이 있을 때만 그 줄을 그립니다.
