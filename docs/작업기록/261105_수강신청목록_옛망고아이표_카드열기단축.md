# 수강신청 목록 — 옛 망고아이 표 모양 + 카드 열기 단축 (2026-11-05)

## 왜 했나
사장님 「수강신청 목록이 보기 불편하게 되어 있는데, 기존 망고아이처럼 전체적인 레이아웃을 바꿔주고, 로딩 시간도 더 줄여줘」(옛 LMS «수강신청관리» 화면 사진과 지금 7칸 목록 사진).
지금 목록은 한 칸에 이름·기간·강사·수강료를 줄바꿈으로 몰아 넣어 한 줄이 높고, 한눈에 비교가 안 됐습니다.

## 한 일
1. **표를 16칸으로** (`js/adm-core.js` `_renderEnrollments`·`_enDirectRow`, 머리글 `admin.html`)
   선택 · 번호 · 신청일 · 학생(이름·전화) · 아이디 · 시작일 · 종료일(기간) · 수강료(결제방식) · 과정 · 인원 · 회/주 · 수업시간 · 요일·시간(배정우선) · 강사 · 상태 · 관리.
   칸 수 정본은 `EN_COLS` 하나(머리글 수·colspan·한 줄 칸 수를 하니스가 대조).
2. **관리 칸을 오른쪽에 고정**(sticky) — 표가 넓어 옆으로 굴려도 버튼은 늘 보입니다(`admin-inline-c.css` 끝 `#card-enrollments` 블록).
   ⚠️ 전역 `table{overflow:hidden}` 이 sticky 를 죽여서 이 표만 `overflow:visible !important`.
   전역 `details.menu-card button` 의 큰 padding 은 ID 두 개 선택자로 줄였습니다.
3. **로딩 단축** — 카드를 열 때 느렸던 두 곳:
   - `adm-s13.js` 페인터가 닫힌 `<details>` 안까지 전부 훑던 것 → 열린 곳만(TreeWalker), 안쪽 details 를 펼칠 때 그 부분만 다시.
   - `admin.html` 의 «옆으로 굴렸나» 확인이 스크롤마다 넓은 요소 60개의 `scrollWidth` 를 재던 것(강제 레이아웃) → 실제로 굴린 요소만 기억.
