# 퇴사 강사 «남은 수업 넘기기» + 숨긴 계정의 카페24 줄 표시

## 1. 왜 했나

매니저 제보 두 건(관리자 «오늘 수업» 화면, 2026-11-06 시간표 스크린샷):

1. «Krystel 을 강사 명부에서 퇴사로 바꿨는데 수업이 그대로 남아 있다. 오늘 시간표에 `Teacher Krystel` 과 `KRYSTEL` 두 이름이 있다. 퇴사한 강사를 어떻게 비활성화하나?»
2. «mangoai_lee 를 연기해야 하는데 Move 버튼이 없다.»

[잰 것 — 2026-11-05 운영 D1, SELECT 만]

- 퇴사 처리는 **정상**이었다: `teacher_profiles#7.status='퇴사'`(11/3 15:53) → `teachers#16(KRYSTEL).active=0` → `c24_mirror_teachers('16').enabled=0`(자동 차단).
- 그런데 «퇴사» 는 **이미 잡힌 수업을 옮기지 않는다.** 남아 있던 것:
  - 망고아이 수업(이름 `KRYSTEL` = `teachers.name`) **39건** = 수강등록 `adm-enroll:114/115` 22건(lby01, ~2027-04-02) + 카페24 복사본 `c24-mirror` 17건(11/6~11/13, 학생 11명)
  - 카페24 예약(이름 `Teacher Krystel` = `teacher_payroll_auto` 카페24 191번) **68건**, 학생 12명, ~2027-04-30
  - ⟹ 두 이름은 **같은 사람이 두 시스템에 따로 적힌 것**이다. 미러가 막혀 있어서 11/14 부터는 Move 없는 «Teacher Krystel» 줄이 늘어날 상태였다.
- `mangoai_lee` 는 **2026-10-04 사장님 요청으로 «삭제(숨김)» 한 계정**이다(`student_erp_override.hidden=1`). 숨긴 계정은 미러가 일부러 수업을 만들지 않으므로(`c24-mirror.ts` `student_hidden`) 망고아이 시간표에 행이 없고 → 옮길 대상이 없다. 그런데 카페24 예약은 남아 «오늘 수업» 에 계속 떴다. 같은 시각(금 14:00)·같은 강사로 `lby01`(이병엽)의 망고아이 수업이 따로 있다 — 연기는 그 줄에서 해야 한다.

## 2. 무엇을 바꿨나

### ① 퇴사·비활동 강사의 남은 수업 넘기기

- **정본** `cloudflare-deploy/src/teacher-class-transfer.ts`(새 파일)
  - 순수 판정: `isTransferCandidate`(지난·취소·종료·자리표시 제외, 매주 반복은 포함) · `transferKindOf`(수강등록/카페24 복사본/기타) · `summarizeTransfer` · `parseTransferApply`(모르는 값은 거절) · `chunkIds`(50건 묶음)
  - `loadCafe24Remaining` — 카페24 예약 **건수만** 센다. 카페24 번호 → 원부 번호는 정본 `loadTeacherLinks`(c24-mirror.ts — 퇴사자 `leftTeacherId` 까지 가름)를 그대로 쓴다.
  - `handleTeacherClassTransfer` — `POST /api/admin/teacher-profiles/:id`, `{action:'transfer_preview'}` / `{action:'transfer_apply', to_teacher_id, ids, expected}`
    - 본사 전용: `teacherMoveDenyReason`(강사·지사·대리점·스코프 모름 → 막음)
    - 미리보기에서 넘겨받을 강사를 고르면 줄마다 `ok` / `blocked`(겹침·휴가) / **`group`** 판정
    - 넘기기는 «이 강사의 남은 수업» 번호만 받는다(`not_candidate`) → **기존 이동 엔진 `moveSchedulesAtomically`** 로 50건씩
- **라우트** `src/api-admin.ts` — `teacher-profiles/:id` 블록의 비어 있던 POST 에서 정본을 부르기만 한다(`src/index.ts`·`api-mango.ts` 관문은 메서드를 안 가려 손대지 않음).
- **화면** `public/js/adm-teacher-transfer.js`(새 파일, `admin.html` 에 `?v=1`) — «📦 남은 수업 넘기기» 창(KO/EN).
  - 입구 두 곳(`public/js/adm-core.js`, `?v=2611055-tpxfer`): 강사 명부 상태 메뉴 항목 «📦 남은 수업 넘기기», 그리고 상태를 퇴사·비활동으로 바꾼 직후(빠른 메뉴·수정 창 모두) — **남은 수업이 있을 때만** 창이 열린다.

### ② 숨긴(삭제) 계정의 카페24 줄 표시

- **정본** `cloudflare-deploy/src/cafe24-hidden-student.ts`(새 파일, import 0) — `markHiddenCafe24(sessions, hiddenUids, norm)`: 카페24 줄에 `student_hidden=true`, 같은 시각(절대 시각 정확일치)·같은 강사(정규화 이름 정확일치)의 망고아이 수업을 `hidden_twins` 로.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **퇴사 저장 때 남은 수업을 자동으로 옮기기/취소하기** — 버림. 누구에게 넘길지는 사람이 정할 일이고, 자동 취소는 학생 수업이 사라지는 사고가 된다. «보여 주고, 고른 것만 넘긴다».
- **새 UPDATE 로 teacher_id 를 한 번에 바꾸기** — 버림. 강사 변경에는 이미 정본(`moveSchedulesAtomically`)이 있고, 본사 게이트·겹침/휴가 검사·미러 줄 `c24-mirror:manual` 도장·감사 기록·원자 batch·낡은 화면 거절이 거기 다 들어 있다. 따로 UPDATE 하면 그 보호가 전부 빠진다.
- **넘겨받을 강사가 같은 시각에 이미 수업이 있으면 그냥 «가능»** — 버림. 이동 엔진은 «같은 강사·같은 시각·같은 길이» 를 **묶음(그룹) 수업으로 허용**한다(exact-slot 계약). 한 건씩 옮길 때는 사람이 보지만, 수십 건을 한꺼번에 넘기면 1:1 수업이 **조용히 그룹이 된다.** 하니스를 쓰다 발견했다(C11 이 처음엔 «가능» 으로 나옴). 그래서 미리보기가 `group` 으로 따로 알리고 **기본 제외**, 사람이 체크해야만 넘긴다.
- **카페24 예약도 여기서 바꾸기** — 불가. 카페24가 정본이고 쓰기 경로가 없다. 건수·학생·다음 수업 시각만 보여 주고 «카페24에서» 라고 말한다.
- **숨긴 계정의 카페24 줄을 «오늘 수업» 에서 빼기** — 버림. 실측: 숨긴 계정 `정우영2` 는 카페24 강사 161 과의 수업이 **망고아이 쌍둥이 없이** 이어지고 있었다(10/1~11/5, 21건). 빼면 진짜 수업이 화면에서 사라진다. 표시만 한다.
- **mangoai_lee ↔ lby01 을 «같은 사람» 으로 잇기** — 버림. 이름 추측으로 남의 수업이 붙은 사고가 이 저장소에 여러 번 있다. «같은 시각 + 같은 강사» 라는 **사실만** 말한다.
- 파일 이름 `teacher-handover.ts` — 처음 그 이름으로 썼다가 **이미 있는 다른 기능**(강사 인수인계 카드, `api-teacher.ts` 가 import)을 덮었다. tsc 가 잡아 git 으로 되돌리고 `teacher-class-transfer.ts` 로 바꿨다(«handover» 는 이미 셋: daily-handover·handover-board·teacher-handover).

## 5. 남은 것 / 주의할 것

- **사람이 할 일(코드 밖)**: Krystel 의 망고아이 수업 39건은 새 창에서 넘길 강사를 골라 넘긴다. **카페24 예약 68건(학생 12명)은 카페24에서** 강사를 바꿔야 한다. `mangoai_lee` 의 카페24 예약은 숨긴 계정의 잔재이므로 카페24에서 정리할지 사람이 정한다(이 화면은 표시만 한다).
- 매주 반복 줄(날짜 없음)을 넘기면 «앞으로의 모든 주» 의 강사가 바뀐다(지난 기록은 출석·급여 표에 따로 있다).
- 숨김 표시는 «오늘 수업» 두 화면(admin·manager)뿐이다. 관제탑(`classes-now`)·강사 화면은 그대로다.
- `group`(묶음 주의)은 «넘겨받을 강사의 기존 수업» 만 본다. 넘길 줄끼리 원래 묶음이던 것은 그대로 묶음으로 넘어간다.
