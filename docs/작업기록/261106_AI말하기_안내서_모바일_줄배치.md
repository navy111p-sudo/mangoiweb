# AI 말하기 안내서 모바일 설명 줄 배치 수정

- 날짜: 2026-11-06
- 작업자: Codex
- 브랜치: codex/ai-speaking-manual-mobile

## 왜 했나
휴대폰 사용 안내 창에서 자세한 안내서의 화면 설명이 한 글자씩 세로로 나오는 사용자 사진 제보.

## 무엇을 바꿨나
`cloudflare-deploy/public/css/ai-speaking-guide-full.css`의 560px 이하 설명 배치를 마지막 자식이 아닌 모든 직계 span에 적용했다. 두 언어의 설명을 모두 두 번째 열에 둔다. HTML의 CSS 버전도 2로 올렸다.

## 왜 이렇게 풀었나
마지막 자식은 EN 설명이고 KO에서는 숨겨진다. KO 설명은 자동 배치로 번호용 24px 열에 들어갔다. 글꼴 축소나 줄바꿈 금지는 원인을 해결하지 못하므로 사용하지 않았다. PC 3열 배치와 인쇄 설정은 그대로 유지했다.

## 확인
- TypeScript noEmit: exit 0.
- 안내서 하니스: PASS 144 / FAIL 0.
- 실제 로컬 Chrome: 사용 안내 창에서 자세한 판으로 이동하고 KO/EN 전환. 320/360/390/430/560/768/1366px 총 14조합에서 설명 6개 폭 150px 초과, 모바일 제목 아래 정렬, 가로 넘침 없음.
- 전체 fast 회귀 검사: 실행 중, 최종 결과는 PR에 기록.

## 주의
운영 반영은 병합 후 자동 배포 확인이 필요하다. 운영 휴대폰의 육안 확인은 아직 하지 않았다.
