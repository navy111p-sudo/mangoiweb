## 3. 바꾼 것 (이 PR — 공동 금지구역 없음)

### ① 서버 `api-ai.ts` — 집중교정 «교정만 다시 묻기» 를 본 호출과 **동시에**
- 예전: 본 답이 «다» 만들어진 뒤에 `recoverFocusedFix` 를 **차례로** 불렀다(맞는 문장이면 매 턴).
- 이제: 규칙 보완(과거형·콩글리시)이 못 잡는 문장이면 본 호출 직후 한 박자(마이크로태스크) 뒤에 미리 시작(`focusedRecoverP`), 결정 자리에서 받는다(`waitFocusedRecover`).
  - 쓰는 **순서는 그대로** — 모델 교정 → 과거형 → 콩글리시 → 답장 속 «You can say» → 다시 묻기.
  - 미리 부른 것은 첫 모델이다. 본 답이 폴백 모델에서 나왔고 미리 부른 것이 빈손이면 예전처럼 «답한 모델» 로 한 번 더 묻는다.
  - 모델 시간(`latModelMs`)은 «안 겹친 나머지» 만 더한다(균형 다시 묻기와 같은 규칙).
- **맞바꿈**: 모델이 스스로 교정을 준 턴(틀린 문장)에도 다시 묻기가 한 번 돈다 — 결과는 버린다. 호출 하나(짧은 JSON)와 바꾼 기다림이다.

### ② 서버 `api-ai.ts` — 최종 답을 저장 «뒤», 포인트 «전» 에 `final` 이벤트로 먼저
- 예전: 대화 저장(INSERT 2)·포인트(D1 조회 + 적립 여러 번 «차례로»)·지연 기록·발음 채점까지 끝난 뒤 `done` 한 번.
- 이제: `finishFriendReply` 후 대화 INSERT 두 건을 기다리고 `sseSend({ final: 1, ok, reply, …replyOut() })` → 그 뒤 처리는 스트림을 연 채로 이어서(응답 본문을 흘리는 동안 워커가 살아 있음 — Cloudflare 문서) → `done` 에 포인트·발음.
  - final 과 done 의 «답 칸» 은 **같은 함수 `replyOut()`** 로 만든다(두 벌로 적지 않음).
  - JSON 경로(stream 미사용)는 예전 그대로. 옛 화면은 `t` 없는 이 이벤트를 그냥 지나친다.
  - 지연 기록 `ms` 는 스트리밍이면 «final 시각» — ⚠️ **이날부터 chat-friend ms 가 포인트 등 후처리 시간만큼 작게 나온다**(재는 자리가 바뀜 — 비교할 때 감안).

### ③ 화면 `ai-friend.html` — final 을 받는 순간 그리고 읽기
- `stmRead(r, hold, onFinal)` · `sendMsg` 안 `showReply`(말풍선·교정 카드·낭독) / `showRest`(포인트·발음 카드·3번 듣기)로 나눔.
- final 을 그렸으면 done 은 `showRest` 만. done 이 깨져도 오류 말풍선을 안 띄운다(답은 이미 갔다). final 이 없으면(옛 서버) 예전 그대로.
- final 뒤에 늦게 온 미리듣기 문장(`t`)은 받지 않는다.

## 6. 검토했다가 안 한 것

- **최종 답을 문장마다 나눠 읽기** — 첫 문장 음성이 빨리 올 수 있지만 잰 숫자가 없고, `focused_correction_speech` 가 «집중교정은 한 덩어리로 읽는다» 를 못 박고 있어 그 뜻을 풀어야 한다.
- **집중교정에서도 미리듣기 흘리기** — JSON 이 `reply` 다음 `fix` 순서라 «교정 없음» 을 스트림 끝에서야 안다. 순서를 바꾸면 프롬프트 계약·교정 품질이 걸린 결정.
- **TTS R2 캐시 저장 안 기다리기** — `import { waitUntil } from 'cloudflare:workers'` 로 `index.ts` 없이 되지만, `api-games.ts` 를 불러오는 하니스 28개가 Node 에서 그 import 로 깨질 수 있고 버킷이 APAC 라 이득이 작다.
- **말소리 검사와 업로드를 동시에** — «검사 후 업로드» 계약(CLAUDE.md 2장 AI 말하기 첫 줄). 미리 받아쓰기로 검사가 대부분 쉬는 동안에 끝나 이득이 작다.
- **다시 뽑기 예산 9초 → 5초(AI 친구)** — 같은 질문 금지 품질과 맞바꿈(3차에서도 AI 친구는 9초 유지로 결정).
- **모델 바꾸기** — 가장 큰 덩어리(모델 평균 3.3~4초)지만 교정 품질이 걸린 결정.

## 9. PR A 후속 보완 (2026-11-06)
