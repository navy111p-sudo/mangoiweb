# 관리자 API 26개 영역 분리와 실제 Worker 샌드박스 (2026-11-06)

## 결과와 범위

전체 코드 정리의 연속 작업으로 운영 관리자 API의 큰 기능 덩어리를 분리했다. 최신 `main`의 `api-admin.ts` 약 14,500줄 중 약 12,900줄을 26개 도메인 모듈로 옮겼다. 진입 파일은 약 1,800줄로 줄었으며, 기존 라우트 본문·SQL·권한·실패 처리 정책은 유지했다.

작업 중 들어온 #2110·#2114도 보존했다. 특히 #2114의 ‘퇴사 강사 남은 수업 넘기기’와 ‘숨긴 계정의 카페24 줄 표시’가 빠지지 않도록, 최신 `main`에서 분리 절차를 다시 실행했다. 충돌에서 어느 기능을 버리는 선택을 하지 않았다. 대조 기준은 재실행 직전 최신 `main`이다.

## 코드 위치

## 검증

- 최신 `main`과 AST 대조: 원래 진입점의 라우트 문장 221개와 `try/catch` 본문 394개가 정확히 같다. 이는 리팩토링 시점의 대조이며, 앞으로 비즈니스 로직을 바꾸지 못하게 해시로 고정한 검사는 아니다.
- `cloudflare-deploy`에서 정확한 실행 경로 `node node_modules/typescript/bin/tsc --noEmit`로 타입체크했다.
- 실제 관리자 핸들러를 번들링한 경계 하니스 14개가 통과했다. 공지 숨김, 강사 조회·쓰기 제한, 학생 분석 인증, 감사 기록의 요청 격리와 장애 로그, 캐시 장애, 경로 미일치, 소스 선택의 누락·중복 실패를 실행한다.
- 복사본 변이 5종(공지 위임 제거, 강사 프로필 쓰기 차단 제거, 공지 숨김 필터 제거, 감사 기록 행위자 덮어쓰기, 감사 오류 로그 제거)을 모두 검출했다. 컴파일 실패를 검출 성공으로 세지 않았다.
- 실제 `src/index.ts`와 정적 자산을 로컬 workerd에서 실행했다. 별도 로컬 D1·KV·R2·DO만 연결했다. 로컬 DB에는 저장소의 스키마와 가짜 본사·강사 계정만 넣었다. 운영 데이터·시크릿은 복사하지 않았다.
- 로컬 Worker에서 본사 인증 조회 24종, 강사 개인정보/쓰기 제한 3종, 홈·공개 공지·비로그인 관리자 접근 8종을 확인했다. 관리자 접근 6종은 비로그인 상태에서 401이었다.

최종 전체 하니스·Linux CI·실제 활성 배포 버전은 완료 후 PR 본문에 기록한다. 샌드박스 성공을 운영 반영 완료로 적지 않는다.

## 하니스를 함께 정리한 이유

기존 검사 일부는 `api-admin.ts` 한 파일이나 ‘다음 기능의 주석’을 끝 지점으로 삼았다. 코드가 움직이면 검사 대상이 사라졌다. 실제 import 그래프를 읽고, 필요한 라우트 문장은 AST로 고른다. 0개 또는 여러 개가 잡히면 실패한다. 복사본 디렉터리와 소스 override는 유지한다.

취소·이동·복원·반복 수업의 변이들은 새 모듈의 실제 코드 위치를 수정하도록 옮겼다. 변이를 넣지 못했는데 성공으로 세지 않는다. 기존 정상 사례와 변이의 기대 실패 조건은 유지했다. #2114의 새 강사 인계 하니스도 실제 모듈 그래프를 읽도록 맞췄다.

바인드 한도 검사는 AST로 실제 placeholder 빌더만 센다. 주석·예제 문자열은 제외하고, 작은따옴표와 큰따옴표 양쪽을 검사한다. 이동한 빌더는 고정 컬럼·요일·날짜·제외 계정 목록임을 확인했고 새 파일의 빌더 수 상한도 둔다. 이제 빌더가 없는 옛 진입 파일의 허용 항목은 제거했다.

스키마·조용한 catch 부채 목록은 이동한 코드의 파일 키만 재지정했다. CREATE 434개·스키마 불일치 11건은 같다. 조용한 catch 검사의 ‘직전 13줄’ 휴리스틱 보고 수는 61→59로 달라졌지만, 이를 결함 수정으로 세지 않는다. 최신 기준의 실제 예외 처리 본문 394개가 동일하다. 검사 조건을 낮추거나 전체 게이트·기존 제외 수를 완화하지 않았다.

## 남은 코드

전체 서비스의 모든 파일을 리팩토링했다는 뜻은 아니다. 진입 파일의 남은 외부 연동·운영 라우트, 큰 AI·UI 모듈 등은 후속 검토 대상이다. 레거시 루트 폴더, 도메인 배치, DO·cron·문자 정책, 공동 금지구역은 바꾸지 않았다. 원래 작업 폴더의 미커밋 변경은 보존했다.
