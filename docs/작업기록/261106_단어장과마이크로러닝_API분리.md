# 2026-11-06 단어장·마이크로러닝 API 분리

전체 코드 정리의 후속으로 학습 진입 파일의 단어장·마이크로러닝 약 1,040줄을 분리했다. `api-games.ts`는 약 1,560줄에서 약 530줄로 줄었고 배지·스트릭과 기존 export를 유지한다.

| 파일 | 책임 |
|---|---|
| `api-games-vocab.ts` | 단어장 조회·추가·복습·보상 10개 라우트 |
| `api-games-microlearn.ts` | AI 단어·퀴즈·마이크로러닝 발송 8개 라우트 |
| `api-games-vocab-core.ts` | 한국어 뜻 검증, SRS 간격표·계산, 쓰기 권한 정본 |
| `api-games-vocab-context.ts` | 요청별 스키마 초기화, 체험 제한, 조회 권한·뜻 보정 |

기존 라우트 순서와 권한·게스트 10분/3일 제한·포인트 상한·SRS 정책을 유지했다. 요청·환경·학생 상태를 전역으로 옮기지 않았다. 마이크로러닝도 같은 SRS·쓰기 권한 정본을 사용한다. AI 공급자·메시지 발송 정책·UI는 변경하지 않았다.

## 확인한 검증

- 지정된 TypeScript 실행 경로의 `tsc --noEmit` 통과.
- 분리 전후 AST 대조: 기존 라우트 25개와 catch 절 37개가 동일하다.
- 실제 핸들러 번들+메모리 SQLite 동작 검사 13종: 소유자 토큰, 체험 경계·동시 요청, SRS 일치, 중복 제출, 배치 실패 롤백·재시도, 보상 상한, 환경별 격리를 확인했다. 예상 외 네트워크 요청은 실패시킨다.
- 새 변이 7종 전부 검출: 두 디스패처 연결 누락, 읽기 권한 우회, 체험 시간·일수 확대, 재제출 방어 제거, 배치 원자성 제거. 컴파일 실패를 검출로 세지 않는다.
- 기존 쓰기 권한 하니스 82종 통과. 기존 변이 28종도 모두 검출했고 실제 새 파일을 겨냥하도록 실행 경로만 옮겼다.
- 실제 `index.ts`+운영 자산을 실행하는 격리 workerd 샌드박스에서 API 요청 14종 통과. 로컬 D1에 합성 단어·퀴즈만 저장했다. 재제출 후 복습 이력 1건·정답 횟수 1회이며 다른 학생 퀴즈는 미완료인 것을 SELECT로 확인했다. 관리자 발송·기록 조회 무인증 요청은 401이다.
- 샌드박스는 별도 로컬 D1/KV/R2/DO·상태 폴더를 사용하며 운영 시크릿·AI 바인딩이 없다. 운영 DB 쓰기·유료 AI 호출은 하지 않았다.
- 기존 소스 검사와 silent-catch 알려진 항목의 경로만 실제 import 그래프에 맞췄다. 기준선 갱신·검사 제외는 하지 않았다.

최종 전체 fast/PR CI, 병합과 활성 배포 버전은 실제 완료 뒤 PR에 기록한다. 운영 데이터·도메인·cron·DO·SMS·공동 금지구역·레거시는 수정하지 않았다. 유료 AI 생성·실제 문자 발송·사람의 UI 평가는 수행하지 않았다. 전체 서비스 코드 정리 완료를 뜻하지 않는다.
