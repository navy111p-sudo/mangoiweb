# 2026-11-06 복습퀴즈 API·문항 검증·채점 분리

## 목적과 범위

전체 코드 정리의 후속으로 `api-games.ts`에 섞여 있던 복습퀴즈 약 960줄을 분리했다. 음성 분리 다음 단계이며 단어장·배지·스트릭은 기존 진입 파일에 남아 있다. UI와 정책을 바꾸는 작업은 아니다.

| 파일 | 책임 |
|---|---|
| `cloudflare-deploy/src/api-games.ts` | 학습 API 진입, 복습퀴즈 핸들러 호출, 기존 export 유지 |
| `cloudflare-deploy/src/api-games-review-quiz.ts` | 학생·관리자 복습퀴즈 13개 라우트, 교재/문제은행, 응시 기록·보상 |
| `cloudflare-deploy/src/api-games-review-scoring.ts` | 문항 검증·정규화·학생용 응답·추첨·채점의 순수 함수 10개 |

스키마 초기화·AI 생성 클로저는 요청 안에 남긴다. 순수 함수만 모듈 수준으로 옮기며 요청·환경·학생 상태는 저장하지 않는다. 다른 모듈에서 쓰는 기존 `api-games.ts` export와 음성 연결은 유지한다.

## 유지한 경계와 선택

- 학생용 퀴즈 조회에서는 정답·해설·듣기 원문을 숨기고, 말하기의 모범 문장은 기존대로 보여 준다.
- 추첨된 문항은 원래 문제은행 번호를 유지하고 제출의 served 순서대로 채점한다.
- 빈 객관식 답을 0번으로 간주하지 않는다. 병음 성조 정규화, 한글 NFC, 중국어 글자별 부분 점수도 유지한다.
- 목록은 공개이지만 다른 학생의 개인 점수는 익명화한다. 다른 학생 명의의 제출은 막는다.
- 포인트 원장·일일 상한·실패/중복/게스트 사유·판단 이벤트 기록은 기존 코드를 그대로 사용한다.
- 관리자 인증은 원래대로 상위 Worker 진입 게이트에서 한다. 개별 핸들러를 직접 부르는 계약 검사와 실제 Worker 인증 검사를 구분한다.

HTTP 처리·AI 생성·순수 채점 함수를 한 파일로 계속 옮기는 방법 대신 순수 함수를 별도 파일로 나눴다. 다만 채점 방식이나 AI 공급자 개선을 함께 섞지 않았다. 기존 정책과 코드 동등성을 확인할 수 있어야 하기 때문이다. 단어장·마이크로러닝까지 동시에 쪼개는 것은 보상·게스트 체험·SRS 검증을 따로 갖춘 다음 단계로 남겼다.

## 검증

- 정확한 TypeScript 실행 경로로 `tsc --noEmit` 통과.
- 기준 소스와 AST 대조: 기존 라우트 38개와 catch 절 75개가 동일하며 복습퀴즈 13개 라우트를 옮겼다.
- 실제 `handleGamesApi` 번들 + 메모리 SQLite 계약 검사 13종 통과. 추첨 반복 검사는 유형별 개수·중복·원본 불변을 독립 조건으로 본다. 예상하지 않은 외부 fetch는 실패시킨다.
- 변이 6종 모두 검출: 디스패처 연결 제거, served 번호 무시, 학생 응답 정답 노출, 빈 답 0번 처리, 제출 소유자 게이트 우회, 목록의 개인 기록 유출. 컴파일 실패를 검출로 세지 않았다.
- 실제 `index.ts`+운영 자산 workerd 샌드박스 요청 11종 통과. 로컬 D1에 합성 퀴즈를 넣어 조회·채점·제출을 실행했고, SELECT로 합성 게스트의 점수 2/2 기록 한 건만 저장됨을 확인했다. 관리자 조회·저장 무인증 요청은 401이다.
- 샌드박스는 별도 설정/상태 폴더의 로컬 D1/KV/R2/DO만 사용한다. 운영 시크릿·AI 바인딩 없이 실행하며 운영 DB 쓰기·유료 AI 호출은 없다.
- 기존 관련 하니스 8개를 실제 games import 그래프에 연결했다. 제외·판정·기대값은 유지한다. silent-catch 부채 두 항목의 파일 키만 옮겼으며 일괄 기준선 갱신은 하지 않았다. CREATE 434개·스키마 불일치 11건·silent-catch 휴리스틱 59건은 그대로다.
- 최종 전체 fast/PR CI, 병합 및 활성 배포 버전 결과는 실제 완료 뒤 PR에 기록한다. 검사나 배포가 아직 끝나지 않은 것을 완료로 적지 않는다.

운영 데이터·도메인·cron·DO·SMS·공동 금지구역·레거시는 수정하지 않았다. 실제 유료 문제 생성·음성 공급자 호출과 사람의 UI 평가는 수행하지 않았다. 전체 서비스 코드 정리 완료를 의미하지 않는다.
