# 더빙 재생 안정화와 무지개 등불 음향 조정

음원이 이동 가능한 범위를 아직 제공하지 않을 때 감상 화면의 위치 이동이 영상만 옮기고 음성을 0초로 되돌리는 문제가 있었다. 기존 연습 화면의 범위 판정을 core의 `canSeekMedia`로 옮겨 감상·연습·자동 동기 보정이 공유한다. 빈 범위/0초 범위/범위 사이의 빈 구간에서는 이동하지 않는다. 모든 트랙이 준비되면 감상 이동 막대가 다시 활성화된다. 제목 건너뛰기도 전체 트랙이 가능한 경우에만 한다. 로딩 중 일반 재생과 기존 일시정지·녹음 흐름은 유지한다.

## 8편 연출

- 기존 BGM 6개를 다시 믹싱했다. 대사와 앞뒤 여백에서는 0.8배, 대사 사이에서는 장면별 1.3~2.1배로 부드럽게 전환한다. 부드러운 피크 제한과 장면 앞뒤 0.25초 페이드를 적용했다. 새 작곡이나 생성 음원은 아니다.
- 기존 효과음 엔진의 새소리·빛·바람·나뭇잎·문·드럼롤·마법·팡파르를 13곳에 낮은 강도(0.12~0.25)로 배치했다. 시작 시각은 대사 사이로 한정했다. 원래 BGM에 포함된 효과음도 유지한다.
- 마지막 단체 화해 숏(EP6 59초 이후)에 최대 2%의 느린 균일 확대를 적용했다. 원래 카메라 이동과 프레임 순서는 유지한다. 새 인물/입모양 생성이나 프레임 보간은 없다.
- 6장 / 182대사 / 약 668.333333초 및 캐릭터별 음원 30개를 유지한다. 기존 미디어 42개(음원·영상·포스터)는 SHA-256 불변이고, 새 BGM/마지막 영상은 새 파일명으로 연결한다.
- 유료 생성 크레딧 0. 새 런타임 의존성 0.

## 확인

- 더빙 하니스 PASS 537 / FAIL 0. 감상 조작·연습 프레임·문장 연속성 하니스 통과. 감상 조작 검사에 준비 전 전체 이동 거부, 범위 준비 후 복구, 0초 범위, 범위 사이 공백, 제목 건너뛰기 실패 보호를 포함했다.
- 브라우저에서 기존 음성과 새 BGM의 재생, 4.5초 새소리 신호를 확인했다. 이동 불가능 음원을 넣은 상태에서 90초 이동을 요청해도 영상·음성이 모두 현재 위치를 유지했다.
- 마지막 영상 1,769프레임 / 24fps / 73.708333초. 전체 디코딩 성공, -50dB·0.7초 멈춤 및 0.1초 검은 화면 검출 없음. 5시점 전후 화면 검토.
- 파일 믹스에서 기존 음성 합계 + 보정 BGM의 최대 절댓값 0.847 미만. 실제 스피커/휴대폰별 청취 품질을 보장하는 수치는 아니다.

## 남은 한계

입모양과 영어 발음이 맞지 않는 원본 구간은 이번 변경으로 고쳐지지 않는다. 캐릭터 음원을 다시 생성하거나 일괄적으로 당기지 않았다. 일부 브라우저에서는 미디어가 이동 가능한 상태가 될 때까지 위치 이동이 비활성화될 수 있다. 실물 iPhone 마이크 녹음과 모든 기기에서의 청취 검사는 수행하지 않았다.
