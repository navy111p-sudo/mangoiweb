# 휴대폰 AI 말하기 소음 속 발화와 미리 받아쓰기

- 날짜 2026-11-07
- 작업자 Codex
- 브랜치 `codex/ai-speaking-noisy-phone`

## 배경

휴대폰으로 말할 때 주변 소음 속의 작은 목소리를 놓치지 않고 아바타 응답을 빠르게 시작해 달라는 요청입니다. 교재·상황 연습은 웜업 녹음 경로를 공유하고, AI 친구도 같은 미리 받아쓰기 모듈을 사용합니다.

## 변경

- `voice-has-speech.js`는 기존 판정에서 놓친 발화를 배경 음량과 다시 비교합니다. 교재·상황·친구 모드에서만 이 판정을 요청합니다. 일정한 소음과 160ms 미만의 단발성 충격음은 추가 판정을 통과하지 않습니다.
- `mangoi-voice-early.js`는 지원되는 녹음에서 미리 전사를 시작하는 대기를 500ms에서 350ms로 줄입니다. 부분 전사가 빈 경우 전체 녹음을 전사합니다.

## 판단

마이크를 더 일찍 닫으면 학생이 숨을 고른 뒤 덧붙이는 말이 잘릴 수 있어 기존 종료 기준을 유지했습니다. 아이폰 WebKit은 녹음 중 추출한 조각의 호환성이 실기기에서 확인되기 전까지 전체 녹음을 한 번 전사합니다.

## 검증

모의 PCM과 가짜 마이크 시계로 약한 발화, 일정한 소음, 충격음, 빈 부분 전사, 이어 말하기를 확인했습니다. 실제 휴대폰의 마이크별 인식률과 전체 응답 시간은 측정하지 않았습니다.
