# 2026-11-07 AI 친구 기본 응답 호출 정리

스트림 첫 시도, 스트림 실패 후 같은 모델의 JSON 호출, 일반 JSON 호출, 모델 재시도가 공유하는 메시지·토큰 수·온도를 한 함수로 모았다. 스트리밍 허용은 기존 첫 시도 분기에만 있다. 교정 보완, 문장 분할, 응답 파싱과 저장, 오류 처리·호출 집계는 유지한다. 새 모듈이나 의존성은 없다.

타입체크와 관련 하니스 275개를 통과했다. Miniflare에서 실제 Worker 진입점과 합성 모델로 JSON, SSE, SSE 실패 후 JSON, 스트림 대신 객체 응답, 전체 실패 후 비스트리밍 재시도를 검증했다. 호출 설정·문장 이벤트·최종 응답·격리 D1 저장을 대조했다. 전체 검사와 배포 결과는 PR에 기록한다.
