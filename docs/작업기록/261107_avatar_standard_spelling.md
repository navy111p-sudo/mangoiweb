# 아바타 발음: 사용자 청취로 선택한 B 적용

- 사용자가 실제 브라우저 녹음 A/B를 듣고 B가 더 자연스럽다고 선택했으며 두 기능 반영·병합·배포를 요청했다.
- A.i 친구의 `a home run` → `uh home run` 음성 전용 치환을 제거했다. A.i 말하기는 이미 표준 철자를 보내므로 소스 변경 없이 실행 검사로 유지한다.
- 화자·속도·화면 문구·집중교정 조립은 바꾸지 않는다. 집중교정은 You can say 한 번, 교정문 세 번이다.
- 자동 전사만으로는 B의 일괄 개선이 입증되지 않아 앞선 감사에서는 변경을 보류했다. 이번 채택 근거는 사용자의 실제 청취 선택이다. 모델은 직접 청취하지 못한다.
- 타입체크 통과. 표준 철자 실제 음성 진입점 검사 통과. 집중교정 서버/스트림/첫 턴 검사 71개 및 재생 큐 검사 20개 통과.
- 전체 CI·브라우저 재생·배포 결과는 연결된 PR에 기록한다. 이 문서 자체는 배포 완료 증거가 아니다.
