# A.i 친구 미리보기 정리 중복 제거

- 새 대화 초기화, 최종 응답 표시, 오류 처리에서 반복하던 미리보기 DOM 제거를 stmClearPreview 한 곳으로 모았다.
- 화면만 지울 때 음성 큐를 취소하면 집중교정 재생이 끊기므로 stmReset과 분리했다. 응답·발음·속도·교정 반복 횟수는 바꾸지 않는다.
- 최신 main의 다른 작업자 응답 생성·교정 후보 리팩터링을 보존했다. 공용 TTS 전체 개편은 변경 범위가 커서 이번 정리에서 제외했다.
- 타입 검사 통과. 집중교정 서버/첫 턴 검사 71개, 응답 속도 검사 44개, 음성 큐/미리보기 검사 23개 통과. 전체 CI 및 배포 결과는 PR에 남긴다.
