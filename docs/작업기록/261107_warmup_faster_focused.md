# A.i 말하기 집중교정 응답 시간 (2026-11-07)

- 운영에서 동일한 영어 테스트 발화 세 번에 첫 음성까지 9.0~11.5초가 걸렸다. 해당 응답의 지연 기록은 모델 호출 1회, 모델 처리 4.5~4.7초, 서버 나머지 처리 약 2.4초였다.
- 일반 영어 집중교정에서 모델이 고친 문장을 한 번만 작성하게 한다. 서버가 실제 학생 발화와 모델의 교정문을 기존 검증기에 넣어 카드 형식으로 복원한다. 이전 모델 응답 형식도 읽고, 유효하지 않은 간결 교정은 기존 재시도로 넘긴다.
- 집중교정은 확인 전 말할 내용이 없어 모델의 중간 스트림을 받지 않는다. 브라우저의 SSE 완료 응답 계약은 유지한다. 세션 시작·교정 진단·지연 기록은 응답 경로에서 분리하되 `waitUntil`로 완료를 보장한다. 다음 대화에 필요한 히스토리와 교정 상태는 응답 전에 저장한다.
- 새 모델로 바꾸면 지연과 교정 품질이 함께 바뀌므로 기존 모델을 유지하고 출력 중복과 불필요한 대기를 줄였다.
- 첫 운영 재측정에서 70B 모델 처리 시간이 줄지 않았다. 일반 영어 집중교정의 짧은 발화만 경량 Granite 모델에 먼저 보내고, 2.2초 안에 기존 교정 검증을 통과한 결과만 사용한다. 긴 발화나 교정 없음, 검증 실패, 모델 장애는 기존 대화 모델과 전체 출력 형식으로 처리한다.
- 운영 화면의 `withCtx`는 자유 대화에도 `guided: 1`을 보낸다. 검증된 교정은 바로 따라 말하는 차례여서 새 질문의 답변 도움말이 필요 없다. 일반 대화로 넘어갈 때는 기존 도움말 형식을 그대로 사용한다. 화면과 같은 요청으로 경량 모델 호출을 회귀 검사한다.
- 경량 모델을 실제 화면에서 세 번 호출했으나 모두 70B로 넘어갔다. 추가 모델 요청은 제거했다. 대신 영어 집중교정에서 `It is + 형용사 + for + 목적격 대명사 + 동사원형`의 명확한 오류만 `to`를 끼워 넣고 기존 검증기에 건다. 해당 패턴은 모델을 0회 호출하고, 그 밖의 문장은 기존 대화 경로에서 처리한다.
