# 2026-11-07 웜업 무응답 안내의 입모양

25초 안내 음성은 이전에 음량으로 입을 움직였다. 안내 문장이 고정돼 있어 영어 음성 네 종류의 실제 MP3에서 Rhubarb로 입모양 타이밍을 각각 계산했다. 오디오와 타이밍은 같은 버전으로 관리한다. 음성을 다시 만들 때는 해당 타이밍도 재생성하고 경로 버전을 올린다.

안내가 재생될 때 기존 아바타가 오디오의 재생 위치를 읽어 해당 입모양을 그린다. 일반 답변의 실시간 분석을 켜면 모델 다운로드와 분석이 응답을 늦추므로 기본 설정을 유지했다.

Chrome에서 엠마의 안내를 끝까지 재생해 5가지 입모양을 관찰했다. 자동 말하기 검사와 스트림 검사는 기존 속도 설정에서 네 안내 파일 모두 타이밍을 받는지 확인한다.
