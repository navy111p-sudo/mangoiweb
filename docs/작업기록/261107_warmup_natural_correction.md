# A.i 말하기 집중교정 낭독 (2026-11-07)

- 제보 화면에서 같은 교정문을 세 번 보여 주고 읽어, 학생 차례가 늦게 돌아왔다.
- 영어 집중교정 답변은 검증된 카드 문장을 한 번만 권한다. 제보의 `really helpful` 교정 예시는 카드·말풍선·다시 듣기에 모두 `actually helpful`로 쓴다.
- 기존 브라우저 음성인식과 녹음 대기는 유지했다. 더 줄이면 문장 중간의 짧은 쉼을 발화 종료로 처리할 수 있다. 공용 교정 생성기도 유지해 A.i 친구하기의 반복 설정에는 영향이 없다.
- 타입체크와 교정·자동 말하기·첫 문장 낭독·스트리밍 하니스가 통과했다. 로컬 Chrome에서 일반 JSON·SSE 응답을 모의해 교정 카드·말풍선·자동 TTS 요청·카드 듣기를 확인했다.
