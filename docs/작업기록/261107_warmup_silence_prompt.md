# 2026-11-07 A.i 말하기 무응답 음성 안내

학생이 질문을 듣고 답하지 않을 때 영어로 말하기를 권해 달라는 요청이다. 독립 영어 연습 화면에서 기존 25초 무응답 감지에 아바타 음성을 연결했다. 질문과 도움말을 유지하고 한 턴에 한 번만 안내한다.

마이크가 열린 채로 안내하면 아바타 음성을 학생 답변으로 받을 수 있어 녹음이 끝난 상태에서만 재생한다. 새 말풍선 대신 기존 낭독을 호출해 대화 화면에는 질문을 남긴다.

타입 검사와 자동 말하기 하니스 99건 통과. 하니스는 25초 지연, 반복 방지, 학생 응답 시 취소, 녹음·재생 중과 음소거·중국어 모드에서의 미재생을 확인한다.
