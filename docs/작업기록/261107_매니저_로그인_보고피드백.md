# 2026-11-07 매니저 로그인 직후 보고 피드백 표시

- 로그인 첫 화면에서 미확인 피드백 본문을 읽을 수 있게 했다. 기존 화면은 받은 보고 API가 제출 현황 등 다른 조회까지 마쳐야 본문을 표시했다.
- 기존 확인창과 보고 작성자 권한을 재사용했다. 로그인 경로 변경은 딥링크 동작에도 영향을 주므로, 화면에서 피드백을 독립적으로 불러오게 했다. 받은 보고 조회가 느리거나 실패해도 확인창을 표시한다.
- 타입체크와 피드백 권한 하니스 통과. 로컬 Chrome에서 매니저 화면의 받은 보고 조회를 실패시켜도 본문 표시, 새로고침 후 표시, 순서대로 확인, 발신자 쪽 확인 상태 갱신을 검증했다.
