# 2026-11-07 매일보고와 결재 대기 통합

- 매일보고 맨 위에 받은 보고 미응답과 결재 대기를 모았다. 팀 보고판의 기준일과 결재 대기는 별개이며, 이미 지난 날짜에 올라온 대기 건도 표시된다.
- 건수와 링크만 추가하면 두 화면을 열어야 한다. 결재 UI를 복제하면 승인·반려와 첨부 동작이 갈라진다. 같은 사이트의 결재 화면에서 대기 목록만 표시하는 보기를 사용해 기존 요청 카드, 서버 권한과 승인·반려를 재사용했다.
- 결재 조회 실패는 빈 목록과 구분한다. 처리 결과를 확인하지 못하면 새로고침을 안내한다. 기존 결재함과 같은 대기 목록 상한을 사용한다.
- 타입체크와 자산 버전 검사를 통과했다. 로컬 Chrome에서 미응답 보고, 지난 날짜 결재, 원문, 첨부, 승인, 사유를 남기는 반려, 건수 갱신과 조회 실패 후 복구를 테스트 데이터로 확인했다.
