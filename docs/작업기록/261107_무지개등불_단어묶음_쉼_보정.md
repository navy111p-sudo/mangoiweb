# 무지개 등불: 미니·올리·그린의 단어 묶음과 쉼 보정

문장 전체를 같은 폭으로 이동하는 대신, 기존 녹음의 쉼을 경계로 발음 묶음을 분리해 각각 배치했다. 후보 7문장을 프레임·파형·기존 단어 전사와 비교했고, 세 문장의 5초 전후 비교본에서 개선을 확인한 배치만 적용했다. 얼굴/입 합성, 영상 재생성, 음성 재합성, 음높이·말하는 속도 변경은 없다.

|---|---|---|
| 미니 EP1 | Look! A butterfly! | Look! 유지. A는 +0.10초, butterfly는 +0.40초. 두 발음 사이에 쉼을 추가해 입이 닫힌 47.42~47.56초의 발화를 줄이고 열린 47.28초와 47.70~48.10초에 발화를 배치 |

미니의 문장 끝 cue만 47.688125→48.088125초로 늘려, 연습에서 옮긴 마지막 단어를 자르지 않게 했다. 다음 대사는 50.71초에 시작해 겹치지 않는다. 다른 cue·182개 대사 내용/순서·6장 전체 668.333333초는 그대로다. 미니의 처음 +0.18초 묶음 이동 및 butterfly +0.30초 시험은 채택하지 않았다.

## 보존 및 검사

- 이동한 발음 구간의 내부 PCM 샘플은 그대로이며 양 끝 5ms의 절댓값 0.005 미만인 저음량 구간에만 페이드를 적용했다. 이음부 클릭을 줄이기 위한 처리이며 발음 길이·속도를 바꾸지 않는다.
- 기존 음성 위에 덮어쓰지 않는지, 이동한 구간이 겹치지 않는지, 편집 범위 밖 PCM 동일성을 assert로 확인했다.
- 새 MP3는 320kbps. 미니/올리/그린의 구간 밖 재인코딩 SNR은 63.47/64.92/67.30dB, 상관계수는 각각 0.999999775/0.999999839/0.999999907.
- 48kHz stereo sample 수는 기존과 같은 5,700,000 / 9,166,000 / 8,440,000. 유한값·피크 1 미만 및 5초 비교 믹스 클리핑 없음 확인.
- 현재 사용 중인 원본 자산 48개 해시 불변. 영상 6개, 배경음/효과음, 앞서 반영한 블루·버블스·퍼피 보정을 유지.
- manifest 변경은 음원 URL 3곳과 미니 cue 끝 1곳. 생성 크레딧 0, 새 런타임 코드·의존성 없음.

## 한계

시작/끝·쉼 타이밍의 개선이며 모든 음소의 입 모양 일치를 보장하지 않는다. 얼굴 자체를 재생성하지 않았고 실제 휴대폰 청취는 검증하지 않았다. 미니 Yes! Right there!, 그린 Look! The light!/Wait. Where is the light?/Yes. Right here. 후보는 명확한 개선을 확신하지 못해 유지했다.
