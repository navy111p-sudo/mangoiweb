# 무지개 등불: 두 캐릭터 발화 타이밍 보정

다른 캐릭터 5명의 후보 8곳을 영상 프레임과 해당 음원의 에너지로 비교했다. 앞 무음이 길어도 화면에서 아직 말을 시작하지 않은 경우가 있어, 일괄 이동하지 않았다. 5초 전후 비교본으로 시작과 끝의 개선을 확인한 두 문장만 반영한다.

| 캐릭터 | 구간 | 적용 |
|---|---|---|
| 버블스 | EP1 “I have cookies!” | 기존 발음 전체를 0.50초 앞당김. 크게 입을 열고 있던 29.824~30.235초의 무음을 줄이고, 입을 닫은 30.647~30.921초에 남던 발화를 제거 |
| 퍼피 | EP6 “Hold it with me.” | 0.25초 시험은 채택하지 않고 0.55초 이동본 채택. 입이 열리는 6.904~7.071초에 발화를 맞추고, 닫힌 7.907~8.074초의 뒤늦은 발화를 줄임 |

퍼피는 작은 /h/·숨소리를 자르지 않도록 편집 범위를 6.5~8.576125초로 잡아 전체 녹음과 잔향을 이동했다. 이동 전에 제거하는 앞 0.55초는 정확히 무음이다. 더빙 연습에서도 작은 시작 소리가 잘리지 않도록 해당 문장의 cue 시작만 6.836667→6.5초로 앞당겼다. 앞 문장은 4.566583초에 끝나므로 겹치지 않으며, 문장 끝과 다음 대사 시각은 그대로다.

## 보존과 확인

- 기존 영상 6개를 포함한 현재 사용 미디어 48개 해시 불변. 이전 블루 보정도 보존.
- 캐릭터별 기존 발음 샘플을 이동했으며 음높이·속도 변경이나 새 음성 생성 없음.
- 이동된 PCM 샘플 전체와 편집 범위 밖 PCM 동일성 확인. 배포 MP3는 320kbps 재인코딩.
- 구간 밖 재인코딩 SNR: 버블스 53.74dB / 퍼피 70.93dB. 상관계수 0.99999788 / 0.99999996.
- 에너지 시작/끝: 버블스 30.3667~31.0867 → 29.8667~30.5867초. 퍼피 7.41~8.38 → 6.86~7.83초. 10ms RMS 기준이며 음소 판정 수치는 아니다.
- 두 파일 모두 기존과 같은 stereo sample 수(48kHz): 5,700,000 / 3,538,000. 전체 668.333333초, 182개 대사와 순서 유지.
- manifest 변경은 음원 URL 두 곳과 퍼피 cue 시작 한 곳뿐. 다른 28개 캐릭터 음원, 모든 영상·배경음·효과음 그대로.
- 발음 손실·클리핑·길이 변경 방지 assert 및 기존 등불 하네스로 검증. 생성 크레딧 0, 새 의존성·플레이어 코드 변경 없음.

로컬 증거: `work/lipsync-cast-20261107/`의 `trial.py`, `verification.json`, `*-comparison.jpg`, `*-before.mp4`, `*-after.mp4`. 첫 퍼피 시험은 `puffy-rejected-250ms.jpg`와 `verification-first-trial.json`에 보존했다.

## 보류

그린 “Look up there!”는 실제 입 움직임이 늦어 앞 무음만으로 오류를 확정할 수 없다. 그린 “Hold this side.”, 미니 “Can I have one?”/“Yes! Right there!”, 올리 “Was it here?”/“Let us listen.”도 문장 내부 입 모양과 발화 리듬의 개선을 확신할 수 없어 유지했다. 이번 두 문장은 시작·끝 타이밍의 개선이며 음소별 완전한 립싱크는 아니다. 실제 휴대폰 청취와 전체 영상의 모든 음소 검증은 하지 않았다.
