# 상황별 말하기 19개 운영 음성 검사

2026-11-07. 병원을 제외한 19개 상황에서 4턴씩 운영 음성 인식, 대화 생성, 브라우저 음성 재생을 검사했다. 테스트용 영어 WAV를 Chrome의 마이크 입력으로 사용했다.

- 물건 교환에서 구매처와 영수증을, 운동회에서 준비 과정과 난이도를 물음표 하나에 묶어 물었다. 같은 질문 제한을 미리듣기와 최종 응답에 적용해, 명시적인 독립 질문 절을 두 개 붙이면 첫 질문만 남긴다. 양자택일과 같은 내용을 확인하는 짧은 꼬리 질문은 보존한다.
- 가격과 시각에서 숫자가 사라졌다. 운영 응답의 스트리밍 유무를 비교한 뒤 Workers AI 원본에서 response가 숫자 20이고 delta.content가 문자열 20인 조각을 확인했다. 기존 파서는 문자열 response만 읽었다. 웜업 스트리밍에서 문자열 response가 없으면 delta.content의 원래 표기를 사용한다.
- 테스트 도구에서 응답 표시와 음성 완료 시점이 달라 음성이 다음 턴에 포함되는 경우는 aiDone으로 경계를 잡아 재검사했다.
- 회귀 검사와 배포 결과는 PR의 CI 및 운영 음성 재검사 기록을 참조한다.

두 질문을 합친 모든 자연어 표현을 분리하는 문법 분석기는 추가하지 않았다. 이번에 재현된 and 및 쉼표 뒤 독립 질문 절을 검사한다.

## 배포 후 재검사에서 발견한 음성 중복
길 묻기에서 화면에는 “But you wanted to walk, right?”만 남았지만 같은 음성이 두 번 시작됐다. 첫 모델 응답에 질문 뒤 안내가 붙어 재생성으로 최종 응답이 짧아졌다. 브라우저는 이미 읽기 시작한 질문을 최종 응답에서 다시 읽었다. 상황별 모드에서는 질문 직전까지의 안내만 스트리밍하고 질문은 확정된 답변으로 한 번 전달한다. 길 묻기 재현과 최종 응답 교체를 Worker 하니스에 추가했다.
