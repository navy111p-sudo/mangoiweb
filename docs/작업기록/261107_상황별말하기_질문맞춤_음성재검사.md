# 상황별 말하기 질문 맞춤 음성 재검사

- 학생 역할 AI에 교사가 방금 한 질문과 앞선 대화 내용을 주고, 영어 답을 생성해 WAV로 합성했다. 브라우저의 마이크 입력부터 운영 음성 인식, 교사 응답, 브라우저 음성 재생까지 통과시켰다.
- 생일 파티에서는 아이스크림 맛, 식당에서는 케첩 선택, 길 묻기와 기차역에서는 목적지를 이미 답한 뒤 다시 확인하는 질문이 나왔다. 확인형 질문과 반복 판정을 최종 역할극 질문 검사에도 적용해 새 질문을 받도록 했다. 기존 재생성 경로를 사용하므로 정상 질문에는 추가 모델 호출이 없다.
- 상품 교환에서는 영수증과 상자를 한 질문에 함께 물었다. 선택지 하나를 고르는 질문은 유지하고, 따로 답해야 할 두 소지품을 묻는 경우 첫 번째 항목만 남겼다.
- 새 친구 상황에서 음성 인식 응답의 함수가 문자열로 전달됐다. Workers AI가 돌려주는 객체와 HTTP 응답을 구별하고 실제 문자열만 받도록 했다. 실패 응답은 기존 오류 처리로 보낸다.
- 고정 학생 대본은 직전 질문과 어긋날 수 있어 이번 검사에서는 사용하지 않았다. 배포 전 회귀는 운영에서 관측한 질문과 HTTP 응답 형태를 로컬 워커 하니스에서 재현한다.
- 첫 배포 후 도서관에서 학생이 우주 책을 고르자 맞장구인 “Oh, really?”만 나왔다. 이 표현을 인정으로만 쓰고, 그 뒤에 새 정보를 묻는 질문을 받도록 회귀 사례에 추가했다.
- 두 번째 배포 후 미술에서 “What are you drawing?” → “A cat” → “Is the cat in your drawing?”가 관측됐다. 활동을 묻는 질문과 직접 답한 대상을 함께 확인해 새 질문으로 넘어간다.
- 식당에서 주문을 요약한 뒤 “Is that correct?”만 묻는 사례도 관측됐다. 이미 받은 답을 요약할 때는 새 정보를 묻도록 기존 맞장구 판정에 추가했다.
