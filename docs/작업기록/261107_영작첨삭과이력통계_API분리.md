# 2026-11-07 영작 첨삭·이력·통계 API 분리

## 목적과 선택

전체 코드 정리의 후속으로 `api-ai.ts`에서 영작 첨삭·이력·성장 통계·주간 순위·동화책 POST 위임을 `api-ai-writing.ts` 한 파일로 옮겼다. Ponytail 방식으로 공용 프레임워크나 작은 보조 모듈을 늘리지 않고, 기존 판정·포인트·배지·동화책 모듈을 그대로 사용한다. AI 친구·수업 질문·명령 라우트는 기존 파일에 남긴다.

호출부는 기존 `handleAiApi`의 엘리더 처리 다음, AI 친구 처리 전에 영작 핸들러를 호출한다. `api-mango.ts`와 외부 호출 서명은 유지한다. 영작 주제 칸의 워커 단위 초기화 플래그도 그대로 이동했다. CREATE/ALTER 재시도와 옛 스키마 INSERT 대체 경로를 바꾸지 않았다.

첨삭 결과 정규화·읽을 수 있는 한국어 판정·미션 단어 경계·단어장 저장·꼬리표·포인트 원장·일일 상한·배지·판단 기록을 다시 구현하지 않았다. 새 의존성·설정·UI·정책 변경은 없다. 첨삭과 조회를 다시 여러 파일로 쪼개는 방법은 작은 모듈과 연결 코드를 늘려 이번 범위에서는 택하지 않았다.

## 확인한 검증

- 지정된 실행 경로의 TypeScript 타입체크 통과.
- 분리 전후 AST 비교: 기존 라우트 15개·catch 절 39개 동일하며 영작 라우트 5개를 이동했다. 스키마 보장 함수·초기화 플래그 선언도 동일하다. 비교는 주석과 CRLF/LF 차이만 정규화했다.
- 실제 `handleAiApi` 번들·SQLite·합성 AI 응답으로 동작 계약 12종 통과. 외부 fetch는 실패시킨다. 이력 30건 상한, 소유자 권한, KST 날짜·스트릭·통계, 순위의 이름 가림·게스트 제외·본인 순위, 첨삭 판정, 미션 복수형, 주제 기록, 모델 대체, 스키마/저장 실패, 적립 소유자·원장·일일 상한, 단어장 중복·꼬리표, 동화책 POST 위임을 확인했다.
- 변이 8종 모두 assertion 실패로 검출: 디스패처 누락, 이력·통계 권한 우회, 게스트 순위 유출, 다른 토큰 소유자 적립, 일일 상한 무시, 이력 소유자 조건 제거, 어색한 표현 꼬리표 누락. 컴파일 실패나 단순 크래시는 검출로 세지 않았다.
- 실제 `index.ts`+운영 자산의 격리 workerd API 17종 통과. 합성 영작 5행을 로컬 D1에 넣어 이력·통계·순위와 인증을 확인했다. AI 바인딩이 없을 때 503이며, 관리자 명령·액션 무인증은 401이다.
- 샌드박스는 별도 로컬 D1/KV/R2/DO와 합성 서명 키만 사용한다. 실제 AI·운영 DB·운영 시크릿·알림 발송은 사용하지 않았다.
- 기존 영작 하니스 8개는 새 영작 파일을 읽도록 경로만 맞췄다. 포인트 일일 상한 하니스는 AI 친구와 영작 양쪽을 계속 읽는다. D1 바인드 검사 예외는 LIMIT 10인 기존 SQL의 새 파일로 옮기고 placeholder 빌더 수 1개를 명시해 검사 범위를 유지했다. 기준선·제외 조건은 완화하지 않았다.

최종 전체 하니스·PR CI, 병합·활성 배포 버전은 실제 완료 뒤 PR에 기록한다. 운영 데이터·도메인·cron·DO·SMS·공동 금지구역·레거시는 변경하지 않았다. 실제 유료 AI 결과와 사람의 UI 평가는 수행하지 않았다. 전체 서비스 코드 정리 완료를 뜻하지 않는다.
