# A.i 말하기 실제 평가와 결과 화면 연결

- 날짜: 2026-11-08
- 브랜치 / PR: feature/ai-speaking-learning-progress-20261108 / #2178

## 요청과 연결
학습 결과 모듈을 실제 AI 친구·웜업 화면, 인증된 학생 대화 기록, 기존 포인트·보석·배지에 연결했다. 동시 추가된 교정 시점 커밋을 병합하고 임의 보상 산정 제거 및 5영역이 모두 있어야 종합 점수를 표시하는 규칙을 보존했다.

- 새 결과 API는 인증 토큰의 학생만 접근한다. 서버가 생성한 세션에 실제 정상 응답만 기록한다. 첫 인사 합성 발화·실패 응답은 제외한다.
- 완료 시 Workers AI가 기록된 학생 발화의 문법·어휘·문장 구성을 평가한다. 발음·유창성을 텍스트에서 만들지 않는다. 현재 이 두 영역과 종합 점수는 미측정으로 표시한다.
- 시작·완료·기록 경계는 앱과 소유자를 확인한다. 발화 재전송 키, 완료 claim, 만료 후 복구 및 오래된 평가의 덮어쓰기 방지를 넣었다. 실패·시간 초과에는 점수를 만들지 않는다.
- 원문 기록은 100회·발화당 4000자로 제한하며 일부 기록일 때 화면에 표시한다. 평가 가능한 텍스트 길이를 넘으면 점수를 만들지 않는다.
- 결과 화면은 확정된 포인트 거래·완료 시점 잔액과 보석·배지를 읽는다. 기존 배지 판정을 재사용한다. 만점 배지는 기존 점수 정규화 투영으로 판정해 50/100을 만점으로 취급하지 않는다.
- 포인트 지급 규칙은 유지하고 AI 친구 거래에 결과 세션 메타데이터를 연결했다. 웜업 완료의 기존 지급 요청은 진행 중 Promise를 공유한다. 결과 재조회는 추가 지급 요청을 만들지 않는다.
- 대화 초기화는 복사된 AI 친구 결과 기록도 삭제하고, 실패한 삭제를 성공으로 표시하지 않는다.
- PC·모바일, 한국어·영어를 지원한다. 웜업의 실제 finish 함수와 AI 친구 하단 결과 버튼에 연결했다.

## 검증
새 SQLite/인증/실제 Worker 하니스와 단위 테스트, 실제 HTML 브라우저 검사를 추가했다. CI가 새 테스트를 실제로 실행하도록 기존 브라우저 워크플로에 연결했다.

- 타입 검사 통과.
- 실제 Worker 라우팅의 비로그인 차단, 새 API 연결, 정상 웜업 기록 저장 검증.
- 로컬 메모리 SQLite에서 소유권, 중복 완료, 재전송, 평가 실패·시간 초과, 저장 실패 후 복구, 오래된 작성자 차단, 지갑 불변·배지 중복 방지 검증.
- 실제 AI 친구·웜업 HTML: 390/1360px, 부분 평가·0점·평가 없음, 언어 전환·XSS·재조회 검사 162개 통과.
- 집중 교정 87개, 웜업 스트리밍 127개, 기존 포인트 35개 등 관련 회귀 검사. Windows 줄바꿈에 민감한 스트리밍 하니스는 커밋과 같은 LF 사본으로 실행했다.
- 전체 CI 및 운영 배포 증거는 PR 본문에 최종 기록한다.

## 검증 범위
모든 실행은 로컬 SQLite와 합성 AI/API/음성 응답을 사용했다. 운영 DB 변경이나 유료 AI 호출을 테스트로 실행하지 않았다. 실제 발음·유창성 평가 입력은 현재 대화 파이프라인에 없어 미측정으로 남는다.
