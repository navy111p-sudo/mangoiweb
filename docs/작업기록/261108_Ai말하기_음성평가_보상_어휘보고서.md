# A.i 말하기 음성 평가·보상·어휘 보고서

- #2178 병합 이후 후속 PR #2188에서 발음·유창성을 기존 Azure Speech의 영어 음성 표본과 연결했다. 음성 파일은 저장하지 않고 유효한 측정값만 저장한다. 텍스트 평가와 음성 표본이 모두 있을 때만 5영역 종합 점수가 나온다.
- 웜업과 세션이 연결된 AI 친구 적립은 기존 포인트 원장과 D1 트랜잭션을 사용한다. 재시도 키와 한국 시간 일일 한도를 같은 트랜잭션에서 확인한다.
- 학생 결과의 4주 고유 단어 수와 학부모·학원 월간 보고서의 단어 수, 측정 평균, 표본 수를 완료된 본인 기록에서 집계한다.
- 로컬 Chrome 브라우저 회귀와 녹음 형식 변환, 격리된 로컬 D1의 동시 적립을 확인했다. 실제 Azure 음성 평가를 쓰는 격리 스테이징 검증이 남아 운영 반영을 보류했다.
