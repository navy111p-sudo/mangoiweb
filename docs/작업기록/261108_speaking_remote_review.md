# PR #2178 추가 원격 구현 독립 리뷰 — 출시 차단

후속 상태: 이 문서는 원격 스냅샷 당시의 재현 기록이다. 지적한 수치 표기와 귀속 문제는 [통합 수정 기록](261108_speaking_integration_reconciliation.md)에서 해결·재검증했다. 원래 PR은 다른 작업에서 이미 병합돼 후속 수정으로 진행한다.

검토 대상은 마지막 확인에서 추가된 원격 `42e936283a9857155785a5cf2b0302416a766eed`다. 이 구현은 현재 로컬 브랜치에 병합하지 않았다. 앞선 전체 게이트 PASS 724 / E2E SKIP 20 / FAIL 0은 `80151a638`까지 통합한 로컬 제품 코드와 음성 입력 보강에 대한 결과다. 새 원격 구현까지 통과했다고 보고하면 안 된다.

## 높은 우선순위: 검증되지 않은 모델 수치를 measured로 저장

원격 [ai-speaking-session.ts 129행 이후](https://github.com/navy111p-sudo/mangoiweb/blob/42e936283a9857155785a5cf2b0302416a766eed/cloudflare-deploy/src/ai-speaking-session.ts#L129)는 LLaMA에 문법·어휘·문장 구성의 0~100 수치를 출력하도록 지시한다. 수치 범위/형식을 통과하면 146행에서 `evaluationStatus='measured'`로 저장한다. 검증된 평가 기준·척도 보정·표본 타당성 확인은 이 경로에서 찾지 못했다. 모델 추정 결과를 실제 측정으로 분류하는 것은 미측정 항목을 유지하라는 이번 작업 조건과 충돌한다.

격리 재현에서는 실제 원격 모듈을 번들하고 서명 인증·SQLite를 사용했다. 가상의 한 단어 `Hello` 기록에 대해 모델 fixture가 문법/어휘/문장 구성에 각각 99를 돌려주면 그대로 measured로 저장됐다. fixture 99는 실측도 실제 공급자의 출력도 아니다. 라이브 모델이 항상 그 점수를 낸다는 증명이나 학습자의 점수로 해석하면 안 된다. 확인한 것은 이 경로가 검증되지 않은 모델 수치를 measured로 승인한다는 계약 문제다.

조치 필요: 신뢰할 평가 계약과 검증 근거가 마련될 때까지 이 수치 경로를 미측정으로 유지한다. 텍스트 모델 피드백을 사용하려면 수치 측정과 구분하고, 별도의 평가 기준·범위·검증을 거친 뒤 연결해야 한다. 실제 음성 없는 발음·유창성은 지금처럼 미측정으로 남겨야 한다.

## 통합 차단: 보상 귀속 메타데이터 불일치

원격 [wallet 조회 73~78행](https://github.com/navy111p-sudo/mangoiweb/blob/42e936283a9857155785a5cf2b0302416a766eed/cloudflare-deploy/src/ai-speaking-session.ts#L73)은 AI 친구 거래의 `meta.speaking_session`으로 이번 연습 보상을 집계한다. 현재 로컬의 원자적 지급 경로는 `meta.request_id`를 기록한다. 이 차이는 원격 단독 동작의 오류라고 단정할 수 없지만, 두 작업을 그대로 합치면 발생하는 구체적인 회귀다.

같은 로컬 재현에서 현재 원자적 지급 함수로 실제 SQLite 지갑에 2P를 지급하고 원격 wallet 코드를 실행하면 `pointsBalance=2`, `pointsEarned=0`이 반환됐다. 지급·재시도 식별자와 서버 소유 세션의 관계를 하나의 계약으로 연결한 뒤 보고서도 같은 원장을 읽어야 한다. 원격의 기존 지급 코드로 되돌려 로컬의 동시 지급·중복 방지 및 공통 API 우회 차단을 잃어서는 안 된다.

## 통합 차단: 결과 흐름과 보관 범위 중복

원격은 `ai-speaking-session.ts` / `ai-speaking-progress.js`와 새 결과 dialog를 추가했다. 현재 로컬은 서버 확인 결과를 모으는 `ai-speaking-session.js`, 기존 finish 요약 연결, 인증 성장 이벤트와 별도 보고서 연결을 갖고 있다. 그대로 양쪽을 활성화하면 결과·종료·세션 정의가 중복되고 한 화면에서 미측정/모델 수치 정책이 갈린다. 이슈 #2179의 중복 시스템 금지 조건에 맞게 결과 진입점과 서버 세션 계약을 하나로 정리해야 한다.

또한 원격의 `turns_json`은 웜업 전체 학생/튜터 대화를 지속 D1에 저장한다. 현재 로컬 성장 기록은 제한된 교정 쌍과 판정만 저장하며 화면 집계는 메모리다. 저장 기간·초기화 범위도 다르므로 이 차이를 자동 병합 과정에서 조용히 바꾸지 않는다. 실제 학생 데이터로 시험하지 않았다.

## 확인한 방어와 미확인 범위

원격은 세션 소유자 조건, finish claim, 저장 실패 시 503, 일부 평가 시 종합 점수 null, 텍스트 평가에서 발음/유창성 제외를 갖고 있다. 이 방어를 삭제하자는 리뷰가 아니다. 배지 평가서 척도 정규화 변경도 이번 리뷰에서 되돌리지 않았다. 다만 새 원격 UI 전체 브라우저/실기기 검증과 원격 전체 통합 게이트는 이번 로컬 결과에 포함되지 않는다.

## 재현과 안전 범위

```sh
git fetch origin feature/ai-speaking-learning-progress-20261108:refs/remotes/origin/pr2178
node test-harness/manual/speaking-remote-review.mjs
```

수동 스크립트는 위 원격 SHA를 고정한다. 실제 원격 세션 모듈과 현재 공통 순수 평가·인증 함수를 사용하며, 배지 부작용은 fixture로 끄고 AI는 명시적인 로컬 fixture로 대체한다. 보상 호환성 검사는 현재 원자적 지급 함수를 사용한다. SQLite는 메모리이며 외부 fetch는 실패하도록 막는다. 로그 `/tmp/speaking-remote-review.log`에 fixtureOnly, 단어 수 1, measured 상태, 임의 fixture 수치, 실제 로컬 지급 2P와 귀속 표시 0P, 라이브 공급자 호출 0을 기록했다. 이 스크립트는 문제를 고친 뒤에도 통과해야 하는 제품 회귀 검사가 아니라 특정 원격 스냅샷의 리뷰 재현이다.

현재 안전하게 완료한 범위는 로컬 음성 입력 검증 보강, 기존 인증·보상·성장 기록 보호, 격리 런타임 검사와 위 독립 리뷰다. 원격 `42e936283`은 자동 병합하지 않았고 원격 push·운영 DB 실험·병합·배포도 하지 않았다. 다음 출시 조건은 측정 정책과 결과 흐름 통합, 보상 귀속 계약 정리, 격리 평가 공급자 실측, 원격 staging 및 별도 리뷰·실기기 검증이다.
