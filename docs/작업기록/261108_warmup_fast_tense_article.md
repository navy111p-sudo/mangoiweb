# A.i 말하기 과거형·관사 교정 속도 (2026-11-08)

- 직전 운영 측정에서 과거형·관사 교정은 발화 종료 후 평균 9.9초·8.8초가 걸렸다.
- 영어 집중교정의 명확한 과거 시간 표현과 단순 문장에는 기존 과거형 표를 재사용한다. 단순한 문장에서 알려진 단수 동물 명사의 관사가 빠졌을 때는 a/an을 붙인다. 두 결과 모두 기존 교정 검증기를 거쳐 같은 카드와 음성 경로로 보낸다.
- 문맥이 필요한 관사와 복합 시제는 모델로 보낸다. 이전의 운영 측정에서 경량 모델 추가 호출은 대기를 줄이지 못했으므로 다시 도입하지 않았다.
