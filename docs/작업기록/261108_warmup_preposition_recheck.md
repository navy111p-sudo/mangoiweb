# 2026-11-08 A.i 말하기 전치사 전사 재확인

집중교정 녹음에서 “I am interested on music”이 “I am interested in music”으로 전사되면 교정할 오류가 사라진다. 이전 운영 측정에서 같은 파일 3회 중 1회 발생했다.

영어 집중교정 녹음에서 기존 규칙이 다룰 수 있는 “interested in” 문장만 구 Whisper로 최대 1.7초 동안 재확인한다. 두 전사 결과에서 in/on 외의 단어가 모두 같을 때만 재확인 문장을 채택해 기존 교정 흐름에 전달한다. 오류나 시간 초과 시 첫 전사를 사용한다.

타입체크와 음성 API 하니스 14개를 통과했다. 하니스는 복구, 올바른 발화, 다른 단어까지 바뀐 전사, 인식기 오류, 옵션 미사용을 확인한다.
