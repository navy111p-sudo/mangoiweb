# A.i 말하기에서 검증한 답변 먼저 재생 (2026-11-08)

- 운영의 같은 마이크 음성을 각 두 번 넣어 과거형·관사 교정과 자유 대화 기준 시간을 쟀다. 첫 음성까지 각각 10.7~18.8초, 9.5~10.5초, 5.5~7.9초였다.
- 웜업 화면은 교정과 대화 모두 검증이 끝난 답변 하나를 화면과 음성에 함께 쓴다. 턴 카운터를 미리 읽고, 검증한 답변이 준비되면 저장이 끝나기를 기다리기 전에 재생한다. 다음 턴은 저장이 끝난 뒤 열린다.
- 첫 인사와 기존 스트리밍 호출자는 기존 문장 미리보기 계약을 사용한다. 새 모델을 시도해 응답을 바꾸는 대신 모델 호출 뒤에 직렬로 기다리던 작업을 겹쳤다.
