# AI와 친구하기 — 처음이면 «5분 레벨 진단» 권유 (2026-11-09)

## 왜
사장님: 「AI를 처음 하는 학생은 간단한 테스트라도 있어야 할 것 같다 — 객관적인, 너무 길지 않게」.
AI 도구는 레벨(밴드)에 맞춰 문장을 고르는데, 처음 온 학생은 레벨이 비어 있어 수준을 짐작으로 골랐다.

## 한 것
- 새 시험을 만들지 않고 **이미 있는 AI 자동 진단**(`/level-test-ai.html`, 24문항·약 5분·중간 저장·틀린 문제 해설)을 쓴다.
  결과는 서버가 `students_erp.level` 에 «비어 있을 때만» 적는다(`applyPlacementLevel`).
- `js/idx-allmenu.js`(defer) — 「AI와 친구하기」 목록 맨 위에 «🎯 AI 학습이 처음이세요? 5분 레벨 진단부터» 한 줄.
  판정은 서버 정본 `/api/student/today` 의 `plan.mode === 'unassigned'`(band 없음)일 때만. 비로그인·직원·조회 실패는 안 띄움.
  진단을 하다 멈춘 학생은 «이어서 하기». «나중에» 는 그 탭에서만 숨김. 목록을 막지 않는다.
- `level-test-ai.html` — 채점 성공 시 `mangoi_leveltest_done_v1`(같은 계정) 표식. 명부 행이 없어 레벨이 안 적힌 학생에게 권유가 계속 뜨지 않게.
- `index.html` — `idx-allmenu.js?v=23 → 24`(같은 글자 수 · 첫 화면 예산 0B).

## 검토했다가 버린 것
- 목록을 막고 진단을 강제 — 이미 레벨을 아는 학생·급한 학생을 막는다. 권유로 둠.
- 화면에서 레벨을 추측 — 판정 정본이 서버(today-plan)에 있다.
