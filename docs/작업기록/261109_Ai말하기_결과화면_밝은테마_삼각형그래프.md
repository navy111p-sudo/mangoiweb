# A.i 말하기 결과 화면 — 밝은 바탕·통계 타일·삼각형 그래프

- 날짜: 2026-11-09
- 요청: 사장님 «결과 화면을 더 보기 좋게, 삼각형 그래프 추가, 바탕은 밝은 색으로»

## 바꾼 것
- `public/js/ai-speaking-progress-view.js`(v12): 줄글이던 답변 수·문장 등급을 숫자 타일로, 그 아래 삼각형 그래프(SVG).
  - 웜업 결과: 오류 없음 · 교정 필요 · 미완성 «문장 분포»(서버가 확정한 건수 그대로).
  - AI 친구 결과: 문법 · 어휘 · 문장 구성(측정된 값만 점으로, 셋 다 측정됐을 때만 면을 칠함. 셋 다 없으면 그래프를 안 그림).
  - 영역 줄은 측정값만큼 막대가 차고, 미측정은 점선 칸.
- `public/css/ai-speaking-progress.css`(v6): 카드·AI 친구 결과 창을 밝은 테마로.
- `public/css/warmup-guide.css`(v9): 웜업 요약창(`.wg-summary`)을 흰 바탕으로, 그 창 안의 버튼·안내 글 색만 바꿈.
- KO/EN 모두 지원. 점수·보상 규칙, 서버, 문구의 사실 관계는 그대로.

## 지킨 것
- 점수를 지어내지 않는다 — 그래프는 받은 값만 그리고 미측정 축은 «미측정» 으로 적는다.
- 영역 줄 5개·주간 막대 7개·공유/다음 수업 버튼 구조는 그대로(기존 브라우저 검사 계약).

## 검증
- 단위 `ai-speaking-progress-view.test.cjs` 18개(그래프 2개 추가: 좌표·미측정 축·미제공 시 미표시).
- `ai_speaking_progress_harness`·`ai_speaking_learning_report_harness`·`asset_version_harness` 통과, `--fast` 전체에서 이 변경으로 난 실패 2건(가짜 문서에 `createElementNS` 없음)은 검사 쪽을 보완해 통과.
- 실제 페이지 브라우저 검사 `manual/ai-speaking-progress-browser.mjs` 521건 · `ai-speaking-observations-browser.mjs` 통과(320~1366px, 합성 API).
- 폰 390px·PC 1280px 화면을 직접 그려 눈으로 확인.

## 안 한 것
- 실제 기기·운영 화면에서는 아직 못 봤다(배포 뒤 사람이 한 번 확인 필요).
- 미측정 5줄(발음·유창성 등)은 그대로 둠 — 숨길지는 사람이 정할 일.
