# 2026-11-09 A.i 말하기 전치사 재확인 지연

이전 운영 재생에서 음성 인식에 3.31초를 쓴 뒤 전사가 interested in으로 넘어가 교정 없이 9.62초에 응답했다. 그 요청의 전사 응답과 녹음은 보관되지 않아 보조 인식의 시간 초과 여부는 단정할 수 없다.

영어 집중교정의 제한된 크기 녹음은 주 인식과 보조 인식을 함께 시작한다. 주 인식이 기존 규칙으로 재확인할 수 있는 interested in을 반환했을 때만 전체 3.65초 예산 내에서 보조 인식을 기다린다. 두 전사가 in/on 한 단어만 다를 때만 보조 인식을 채택한다. 모호한 결과를 기다리는 시간을 줄이는 대신 해당 녹음에 보조 인식 호출이 추가된다.

음성 API 하니스에서 두 인식기의 동시 시작, 복구, 올바른 in 유지, 다른 단어가 달라진 경우, 보조 인식 실패를 확인한다.
