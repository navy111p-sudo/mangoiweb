# 2026-11-09 A.i 말하기 전치사 보조 인식 재시도

운영 검증에서 주 인식은 interested in을 반환했고 보조 결과를 받지 못한 한 회는 7.40초에 교정 없이 넘어갔다. 보관한 동일 WebM의 재전송에서는 보조 인식이 on을 반환했다.

모호한 문장에서 보조 인식이 실패하거나 시작 후 1.5초 동안 쓸 수 있는 결과가 없으면 한 번 더 요청한다. 먼저 도착한 유효 전사를 쓰며 전체 3.65초 예산과 전치사 한 단어만 다를 때의 교정 조건을 유지한다. 두 요청이 모두 실패하면 첫 전사를 유지한다.

음성 API 회귀 검사에서 일시 오류, 응답 없는 인식기, 실제 in 유지, 두 요청 모두 실패를 검증한다.
