# 2026-11-09 결재 — 접힌 «대신 결재» 카드에도 «반려 · 피드백» 칸

## 1. 왜 했나
사장님 화면(매일보고 › 내가 처리할 일): 결재권자 몫(by_proxy)으로 접힌 카드에는 「대신 결재하기」 하나뿐이라
피드백을 줄 자리가 안 보였다. 지시: 「여기도 답변이나 피드백 줄 칸이 필요」 · 「승인자에 다시 반려해서 피드백 줄 수 있는 것」.

## 2. 한 것
- `public/work.html`
  - 접힌 카드에 **「반려 · 피드백」** 버튼. 「승인」은 그대로 접힘(2026-09-10 «소액은 장 부장님만» 유지).
  - 반려 칸에 **직접 쓰는 피드백 칸(textarea)** + 「이 피드백으로 반려」. 예전 `prompt()` 를 대신한다. 사유 버튼 5개는 그대로 한 번에 반려.
  - 쓰던 글은 `WHY_DRAFT` 에 담아 60초 자동 갱신이 다시 그려도 남는다. 피드백 칸에 포커스가 있으면 갱신이 다시 그리지 않는다(폰 키보드가 안 닫히게).
  - 매일보고 화면(iframe `?view=handover`)은 건마다 `<details>` 라 다시 그리면 접혔다 — 펼친 「대신 결재」·쓰던 반려 칸이 있으면 `open` 으로 그린다(「대신 결재하기」를 누르면 카드가 접히던 기존 문제도 함께 풀림).
- `src/api-approval.ts` (결정 라우트)
  - 이 단계의 «주» 결재자가 아닌 사람이 **반려**하면 그 단계 결재권자에게도 결과 알림(누른 사람 본인은 제외).
  - `approversFor(…, widen=false)` — 결재권자가 0명(결재권자 본인이 올린 건)일 때 «누를 수 있는 사람 전원» 폴백으로 넓히지 않는다. 기안자가 이미 받으므로 엉뚱한 경영진에게 안 가게(함정 대조가 잡음).
  - 반려 알림 본문에 피드백을 싣는다(200자). 서버가 붙인 영어 번역(`[EN]`)을 앞으로 — 필리핀 기안자가 잘린 한국어만 보지 않게.

## 3. 검토했다가 버린 것
- **결정 없이 «의견만» 남기는 댓글 기능** — 새 표·화면이 필요하다. 요청 문구가 «반려해서 피드백» 이라 반려 + 메모로 충분하다고 봤다.
- **«앞 단계로 되돌리기»(반려 대신 결재권자에게 반송)** — 상태 머신이 바뀌는 큰 변경. 이 카드는 아직 결재권자 단계라 되돌릴 앞 단계도 없다.
- **사유 버튼을 «글 칸에 채우기» 로 바꾸기** — 한 번에 반려하는 기존 동작(«타이핑은 필요할 때만»)이 깨진다.

## 5. 남은 것 (사람이 정할 일)
- 지시 「승인자에 다시 반려해서 피드백」을 **«반려(건 종결) + 피드백»** 으로 읽었다. 만약 뜻이 «건은 대기로 두고 결재권자에게 의견만 보내기» 였다면 별건(댓글 기능)이다.
- 사유 버튼은 확인 없이 한 번에 반려된다(기존 동작). 대표님이 접힌 소액 건을 두 번 눌러 끝낼 수 있게 됐다 — 「승인」은 여전히 접혀 있다.
- 피드백이 잠금화면 푸시 본문에도 보인다(인사·급여 반려 포함).
