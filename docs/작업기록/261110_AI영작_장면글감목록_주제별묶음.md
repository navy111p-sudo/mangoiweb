# 2026-11-10 AI 영작 — 장면·글감 목록을 주제별 묶음으로 (PR #2243)

## 왜
사장님 화면 캡처: «그림 장면과 글감이 기준이나 카테고리 없이 나와 가독성이 떨어진다».
`ai-write.html` 의 «🎬 장면·글감 선택» 목록에 그림 36개·오늘의 글감 35개가 한 덩어리로 나왔다.

## 한 일
- `PIC_SCENES` 각 항목에 `cat`(school·home·out·fancy)·`ic`(아이콘), `TOPICS` 각 항목에 `cat`(me·people·past·dream).
- `AW_GROUPS` 의 pic·topic 에 `subs` — `awBuildPicker` 가 «🎬 그림 장면 · 🏫 학교·친구 (7)» 처럼 작은 optgroup 으로 나눠 그림.
- 값(`pic:N`·`topic:N`)은 그대로 → 고르기·숙제·선생님 글감 동작 무변경.
- `cat` 을 빠뜨린 새 항목은 «기타» 묶음으로(조용히 사라지지 않게).
- 아이콘은 Unicode 12 이하만(처음 고른 🛝 14.0·🪄 13.0 은 바꿈).

## 버린 방법
- 목록을 커스텀 드롭다운으로 새로 만들기 — 폰 기본 선택 UI·접근성을 잃고 범위가 커서.
- 카테고리를 번호(index) 표로 따로 두기 — 순서를 바꾸면 조용히 어긋나서 항목마다 `cat` 을 직접 적음.

## 확인
- `write_topics_harness`(큰 묶음 순서·소묶음 4+4·«기타» 짝 추가) · `ai_write_brainstorm`·`ai_write_guide` 통과.
- 로컬 크로미움으로 목록 렌더·`topic:4` 선택, 콘솔 오류 0.
- 병합 시각이 화 14:12 KST(배포 보류 창)라 업로드는 건너뜀 → 15시 이후 배포.
