# 간단 대화(얼굴 화면)에 ⋮ 설정 버튼 — 교재·상황·친구 모두

- 날짜: 2026-11-10
- 작업자: Claude (사장님 지시)
- 브랜치 / PR: `claude/ftk-settings-menu`

## 1. 왜 했나

사장님 화면 제보: 「왼쪽 간단대화에도 오른쪽 햄버거 점 3개 추가해서 기능들을 넣어줘」 + 「이 기능들 모두 교재·상황·친구에 적용」.
채팅 화면에는 ⋮ 설정(말하는 방법·듣기 속도·대화 레벨·연령대·AI 친구·자막)이 있는데,
«시작 = 얼굴 화면»(2026-11-09) 이 된 뒤로는 그 설정을 바꾸려면 ✕ 로 나가야 했다.

## 2. 무엇을 바꿨나

| 파일 | 내용 |
|---|---|
| `js/ftk-call.js` | 위쪽 줄에 ⋮ 버튼(`.fc-menu`). 손잡이 `menu` 가 있을 때만 보인다. 공개 `setHands`·`setCc` 추가. 좁은 폰(≤400px)은 버튼 38px·제목 17px |
| `js/warmup-facetalk.js` | `CALL.menu` — 채팅 화면의 `#menuPanel`·`#menuMask` 를 `#ftk` 안으로 **잠깐 옮겨** 연다. 나가면 `menuBack()` 이 상단바 ⋮ 로 되돌린다. 교재·상황·간단대화가 전부 이 파일 |
| `js/aifriend-facetalk.js` | `CALL.menu` — 이미 있는 ⚙ 설정 시트(`#optsToggle`)를 누른다(시트 z-index 가 얼굴 화면보다 높아 그대로 위에 뜬다) |
| `warmup.html` · `ai-friend.html` | `?v=` 만 올림 |

- 설정의 «말하는 방법» 을 고르면 얼굴 화면의 자동/버튼도 같이 바뀐다(`FtkCall.setHands`).
- 설정의 «자막» 을 고르면 얼굴 화면 자막(CC)도 같이 — 완전 끄기 = 끔 · 가리기 = 흐리게 · 보이기 = 보임(`FtkCall.setCc`).
- Esc 한 번은 설정만 닫는다(얼굴 화면 유지) — 두 화면 Esc 처리를 캡처 단계로 옮겼다.
- 웜업 얼굴 화면에서는 «화면 밑에서 열리는 것» 네 가지를 감춘다: 연령·수준·교재 다시 고르기 · 그림 고르기 · 새로 시작 · 사용방법.

## 3. 검토했다가 버린 방법

- **얼굴 화면 전용 설정 창을 새로 만들기** — 설정 UI·저장 키·서버 프롬프트 연결이 두 벌이 된다(한쪽만 고쳐지는 사고). 있는 패널을 그대로 쓴다.
- **패널 z-index 만 올리기** — `#menuPanel` 은 상단바(`.menu-wrap`) 안이라 `#ftk`(2147483050) 위로 못 올라온다. 그래서 DOM 을 옮긴다(id·리스너는 그대로 산다).
- **«다시 고르기» 를 얼굴 화면에서도 열기** — 설정 화면이 떠 있으면 `enter()` 가 스스로 막는 구조라, 나갔다 들어오는 흐름을 새로 짜야 한다. 지시 범위(여섯 항목) 밖이라 감췄다.

## 5. 남은 것 · 못 본 것

- 배포된 실제 화면은 못 봤다(프록시) — 사람이 폰·PC 에서 한 번 봐야 한다.
- 넓은 화면 오른쪽 «대화 기록» 은 자막을 꺼도 글이 그대로 보인다(예전과 같음).
- A.i 친구는 설정 시트를 통째로 연다 — «대화 초기화»·«오늘의 퀘스트» 도 함께 보인다.
- 설정 창이 열린 동안 A.i 친구 얼굴 화면의 마이크는 멈추지 않는다(웜업은 자동 말하기가 메뉴 열림을 보고 스스로 기다린다).
