- 작업자: Claude (사장님 요청)

## 1. 왜 했나

사장님 스크린샷(Lily, 코 양옆·입 둘레에 빨간 동그라미): 「코 양옆에 볼쪽이 선이 있어. 부자연스럽고 이상해. 특히 말할 때 더욱더 이상해」.

## 2. 원인 [잰 것 — 헤드리스 크로미움, Lily 480px 캔버스]

- 입모양은 아틀라스(9칸 `lily-mouths.webp` · 288칸 `lily-transitions.webp`)에서 칸 하나를 골라 얼굴 위에 **바로 늘여** 그렸습니다(`composeFrame`).
- 크롬은 이렇게 «큰 그림의 일부» 를 늘일 때 칸 **바깥 옆 칸 픽셀까지** 보간에 섞습니다. 그래서 칸 둘레(원본 x 250·394 = 코 옆 볼, y 294 = 코 밑)에 옆 칸의 턱 그림자·반대쪽 볼이 **1px 선**으로 번졌습니다.
  - 그 줄의 밝기: 주변 195 → 선 182(왼쪽 세로) · 196 → 169(위쪽 가로, «아» 입모양)
  - 말할 때는 칸이 계속 바뀌어 이웃도 바뀌므로 선이 **깜빡였습니다** → 「말할 때 더 이상해」.
- 원본 그림 자체는 깨끗합니다 — 칸 가장자리와 얼굴 바탕의 차이는 평균 0.4/255 (앵커 9칸).
- v21 작업기록 §5 의 «입 칸 경계의 희미한 가로 이음매(v20 부터)» 가 바로 이것이었습니다.
- 어제(v21) 넣은 고개 돌림·턱 내리기도 의심했지만, 끈 판·켠 판을 확대 비교해 보니 **선을 만들지 않았습니다**.
