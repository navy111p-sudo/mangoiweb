# 화상수업 — 떠 있는 얼굴(카메라) 창을 끌어서 옮기기

- 날짜: 2026-11-10
- 작업자: Claude (사장님 전달 강사 제보)
- 브랜치 / PR: `vc-free-camera-drag`

## 1. 왜 했나

강사 제보(화면 사진, 방 `demo-1`): 「오른쪽 아래 카메라 창이 필기도구를 가려서 누르기 어렵다. 카메라 창을 옮길 수 있게 해 달라.」

[잰 것 — 헤드리스 크로미움 1366x650] 사진과 같은 화면이 나오는 조건은 하나였다.

1. 얼굴 칸 우상단의 노란 그립(`#vc-vp-grip`)을 끌면 창이 «자유 크기» 모드(`video-free`)로 떠오른다.
2. 떠오르면 교재 칸이 화면 전체 폭이 되어 필기도구 패널이 오른쪽 끝으로 가고, 떠 있는 얼굴 창이 그 위를 덮는다.
3. 이 창을 옮기는 손잡이는 제목줄(`.video-size-bar`)의 «버튼이 아닌 자리» 인데, 그림 4칸 개편(2026-08-25) 뒤로
   제목줄이 버튼으로 꽉 차 잡을 자리가 거의 없다(얼굴 영역을 끌면 0px 이동).

즉 «옮기는 기능은 있었는데 잡을 곳이 없었다».

## 2. 무엇을 바꿨나

- `cloudflare-deploy/public/js/idx-vc-sizebar.js` (defer) — `armPaneDrag()` 추가.
  - 자유 모드일 때 **얼굴 영역을 잡고 끌면** 창이 옮겨진다(마우스·터치). 위치 계산·저장은 `idx-main.js` 의
    `vcApplyFreeBox`·`vcSaveFreeBox` 를 그대로 쓴다(화면 밖으로 안 나가고, 다음에도 그 자리).
  - 6px 넘게 움직여야 끌기로 본다 — 타일 안 버튼·탭은 그대로 눌린다. 끌고 난 뒤의 click 한 번은 삼킨다.
  - CSS 두 줄을 넣는다: 자유 모드의 얼굴 영역에 `cursor:move; touch-action:none`, 그리고 자유 모드 창에
    `position:fixed!important`.
- `cloudflare-deploy/public/index.html` — 그 파일의 `?v=2` → `?v=3` **한 글자뿐**(공동 금지구역이라 그 외에는 안 건드림).
- `test-harness/vc_free_camera_drag_harness.mjs` (자동) · `test-harness/manual/vc-free-camera-drag-browser.mjs` (수동).

### 덤으로 찾은 것 — 작은 창에서는 그립을 끌면 창이 화면 밖으로 사라졌다

`(max-width:1024px) and (orientation:landscape), (max-height:600px) and (orientation:landscape)` 미디어쿼리가
얼굴 칸을 `position:relative!important` 로 못 박아, 자유 모드의 화면 좌표가 «제자리 + 그만큼» 으로 먹었다
(1024x700 실측: left 1387 — 화면 밖). 높이 600px 이하인 낮은 노트북 창도 같다. 위 `position:fixed!important`
(id 두 개 선택자) 한 줄이 그것을 고친다.

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법

- **제목줄에 빈 손잡이 칸을 새로 만들기** — `index.html`(금지구역) 마크업·CSS 를 고쳐야 하고, 좁은 얼굴 칸에서
  버튼 4칸이 더 좁아진다. 얼굴 영역 자체가 가장 큰 손잡이라 그쪽을 택했다.
- **`idx-main.js` 의 기존 끌기 핸들러를 넓히기** — blocking 파일이라 첫 화면 예산에 걸린다. defer 파일에 두었다.
- **필기도구 패널이 얼굴 창을 피해 가게 하기** — 창이 어디에 있든 무언가는 덮는다. 사람이 옮기는 것이 맞다.
- **그립을 끌어도 자유 모드로 안 가게 하기** — 기존 동작을 없애는 변경이라 지시 범위를 넘는다.

## 5. 남은 것 / 주의할 것

- ⚠️ 배포된 실제 화면은 못 봤다(작업 환경에서 `mangoi.ai` 접근 불가). 병합 뒤 사람이 한 번 봐야 한다.
- ⚠️ 터치 컨텍스트 검사는 «마우스 이벤트 + touch-action 값» 까지다. 진짜 손가락 끌기는 태블릿에서 사람이 확인.
- 자유 모드에서는 얼굴 목록의 터치 스크롤이 끌기에 먹힌다(휠 스크롤은 그대로) — 파일 주석에 `shortcut:` 으로 적어 둠.
- 폰 가로(844x390)는 그립을 끌어도 자유 모드에 안 들어간다(기존 동작) — 이번에 안 건드렸다.
- 강사 안내: 창을 끌어 옮기거나, 크기바의 「기본(Standard)」 을 누르면 원래 자리로 돌아간다.
