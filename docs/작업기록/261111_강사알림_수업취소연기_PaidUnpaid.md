# 2026-11-11 강사 알림 — 수업 취소·연기·변경 푸시 + 연기 수업 «Paid / Unpaid»

## 1. 왜 했나
필리핀 매니저 maimai 질문: 「강사 페이지에 학생 이름·시간과 함께 수업이 취소·연기됐다는 알림이 오나?
30분 안이면 유급, 그 전이면 무급」.
- 조사 결과: 30분 규칙은 급여에 이미 있음(`admin-lesson-fees.ts` — 요청 시점 `fee_type`, 2026-08-13 사장님 결정).
- 하지만 **강사에게 오는 알림이 없었다** — 「📅 수업 연기 요청 💰유료/🆓무료」 알림은 관리자 카톡(`kakao_memo`)으로만 갔다.
- 강사가 Paid/Unpaid 를 보는 곳은 「급여 › 건별 명세」뿐이었다(나중에야 보임).

## 3. 검토했다가 버린 방법
- **15분 크론으로 이력 표를 훑어 알림** — 경로가 20곳 넘어도 한 곳이라 깔끔하지만, 최대 15분 늦어
  «30분 안 변경» 이라는 핵심 경우에 수업 시작 뒤 도착할 수 있어 버림.
- **알림 문구의 Paid/Unpaid 를 «지금 − 시작» 으로 계산** — 관리자가 오래된 요청을 수업 직전에 승인하면 급여(fee_type =
  요청 시점)와 어긋남. 그래서 급여와 같은 근거(그날 마지막 승인 요청 fee_type + `payroll_deduction_rules`)만 씀.
- **급여 식을 새 함수로 옮겨 급여도 그걸 부르게** — 기존 하니스 3개가 급여 코드 글자를 못 박고 있어 반경이 커짐.
  대신 급여 식은 그대로 두고, 하니스가 그 식을 오려 내 120개 조합으로 대조.
- **취소·다른 날로 옮김에도 Paid/Unpaid** — 급여는 취소된 수업을 아예 안 세고, 옮긴 수업은 새 날짜에 셈.
  «30분 안 취소도 지급?» 은 **사장님 결정 대기** — 그 전까지 표시하지 않음(지어내지 않음).
