알려야 하는데, 지금은 줄마다 📩 를 한 명씩 눌러야 했다. 옛 LMS(카페24)는 줄 왼쪽 체크 + 맨 위 전체 체크 +
「MESSAGE SEND」 로 한 번에 보냈다. 사장님: «이전 mangoi 사이트처럼, 관리자들이 잘 쓸 수 있게».

## 3. 왜 그렇게 풀었나 — 검토했다가 버린 방법
- **서버에 일괄 API 새로 만들기** — 버림. 권한(본사 전용)·번호 찾기·«하나도 안 닿으면 못 보냄» 판정이 이미
  `class_notice` 에 있다. 새로 만들면 그 판정이 두 벌이 된다. 화면에서 한 명씩 부르면 서버 0줄.
- **동시에 몰아 보내기** — 버림. 문자 업체에 한꺼번에 몰지 않고, 한 명 실패가 나머지를 막지 않게 «차례로».
- **선택을 학생 아이디로만 기억** — 버림. 날짜를 바꿔도 같은 학생이 고른 채 남는다. «학생+수업 시각» 으로 기억해 날짜를 바꾸면 자연히 풀린다.
- **숨은(걸러 낸) 줄까지 보내기** — 버림. 대상은 언제나 «지금 보이는 줄» 에서만 뽑는다(보이는 숫자 = 보내는 사람 수).

안전장치: 여러 명이면 보내기 전 확인창 · 같은 학생 두 수업이면 한 번만 · 보낸 뒤 버튼은 «못 보낸 N명 다시 보내기» 로 바뀌어 받은 학생에게 두 번 안 간다.
