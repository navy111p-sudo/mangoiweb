# 상황별 말하기 사용성 피드백

녹음 중 보내기는 입력창이 비어 있으면 반환하여 Whisper 녹음을 종료하지 못했다. 기존 마이크 종료 경로를 재사용하고 종료 중 중복 전송을 막는다. 선택형 답변의 조용한 마이크 취소 경로는 유지한다.

상황 대화의 최근 48개 메시지를 같은 탭에 30분간 보관한다. 계정·세션·상황이 일치할 때만 복원하며 녹음과 음성을 자동 시작하지 않는다. 첫 안내와 상황 목록의 이어하기 링크를 추가했다. 서버 저장소와 개인정보 권한은 바꾸지 않는다. 새 대화는 기존 새 세션 생성 기능을 사용한다.

6초 이상 응답 대기 시 안내하며 HTTP/네트워크 실패 때 입력문을 보존한다. 중복 처리 위험이 있어 자동 재전송은 추가하지 않았다. 서버 응답 속도가 빨라졌다고 주장하지 않는다.

기기 음성 폴백의 반복 wide 입 모양을 닫힘으로 바꾸고 움직임 간격을 150→180ms로 완화했다. 서버 음성의 분석 기반 립싱크는 유지한다. 실제 기기의 입 모양은 별도 확인이 필요하다.

검증: 마이크·자동말하기 하니스 105개, 응답 종료 판정 73개, 복원 저장소 테스트 3개 통과. TypeScript 검사 통과. 로컬 Chromium은 socket 권한 제한으로 실행 불가. 기존 GitHub 브라우저 워크플로에 390/768/1366px의 보내기·복원·오류·계정분리 검사를 연결했다. CI 결과는 PR에서 확인한다.

되돌림은 이 PR 변경만 되돌리면 된다. 기존 서버/DB 변경은 없다. 녹음과 토큰을 저장하지 않는다. 탭 종료·30분 경과 후에는 복원하지 않는다.
