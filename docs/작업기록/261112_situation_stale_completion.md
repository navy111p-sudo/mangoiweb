# 상황별 말하기: 이전 음성의 늦은 종료 처리 차단

이전 Audio.play 요청이 취소된 뒤 늦게 실패하면 speak의 done이 새 발화의 입 움직임을 멈추고 같은 다시 듣기 버튼의 재생 표시를 지웠다. 자동 마이크 시작과 생각중 표시는 이미 발화 번호로 보호됐지만 아바타와 버튼은 보호되지 않았다.

수정은 done 진입 시 기존 발화 번호를 비교하고 이전 발화면 즉시 반환하는 한 줄이다. 현 발화의 정상 종료, 끼어들기, 음성 폴백과 문장 분할은 유지한다. 데이터 변경은 없다.

실행 검증: 실제 speak와 _stopSpeak를 VM에서 실행해 오래된 음성 종료와 Audio.play Promise의 늦은 거절을 재현했다. 수정 전 3개 실패, 수정 후 자동 말하기 112개 통과. 첫 문장 TTS 하니스 64개 통과. 정상 종료에서 입이 닫히는 반대 사례도 검증한다. 전체 및 브라우저 CI 결과는 PR에 기록한다.

범위 밖: 실제 기기의 발음별 입 모양 품질과 정상 제공자 응답 시간은 측정하지 않았다. 되돌릴 때는 이 PR의 종료 가드와 회귀 검사만 되돌린다.
