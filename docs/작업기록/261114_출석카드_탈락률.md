# 출석 카드와 탈락률 연결

사용자 요청으로 마이페이지 출석 카드를 월간 수업 횟수, 연속 출석, 결석·지각, 다음 수업으로 바꾼다. 탈락률은 종료 학생 중 미재등록 학생 비율로 정했다.

## 구현과 데이터 한계

- 출석은 기존 월별 수업 이력의 휴강·연기·취소 판정과 LMS 중복 정리를 재사용한다. 같은 시각의 서로 다른 원자료가 남으면 한 회차의 미확인으로 센다. 학부모 API에는 집계 필드만 전달한다.
- 연속 출석은 지난달부터, 다음 수업은 다음 달까지 조회한다. 화면에 조회 범위를 표시한다. LMS 출석에는 실제 입장 시각이 없어 지각 미측정 건수로 표시한다.
- 탈락률은 결제 완료 및 확정 수강 기간에서 선택 기간 내 마지막 종료 건을 학생별로 한 번 센다. 이후 시작하고 더 늦게 끝나는 확정 기간을 재등록으로 인정한다. 취소 결제는 제외한다. 종료일 당일은 아직 종료되지 않은 것으로 본다.
- 기간이 비어 있는 기록으로 재등록 여부를 알 수 없으면 미확인으로 센다. 미확인이 있으면 비율을 표시하지 않는다. 기간 없는 기록만 있는 학생은 종료 모집단을 알 수 없어 제외되며 전체 기간 누락 건수를 표시한다. 조직은 현재 소속이다.
- 현재 학생 원부의 종료일 하나로 과거 재등록 이력을 추정하는 방식은 사용하지 않았다.

## 검증

타입 검사 및 계산·권한·실패 응답 검사가 통과했다. 실제 Chromium에서 합성 자료로 두 화면을 실행하고 휴대폰 폭에서 가로 넘침이 없는 것을 확인했다. 마이페이지 렌더링 중 번역 함수 누락을 발견해 수정한 뒤 다시 실행했다.

로컬 전체 회귀는 기존 안내문/사이드바 검사 실패 및 설치된 Miniflare 버전·Windows 실행 호환 문제를 포함한다. 최종 병합 판단은 PR의 동일 기준선 대조 CI 결과를 따른다. 운영 DB는 SELECT만 실행했다.
