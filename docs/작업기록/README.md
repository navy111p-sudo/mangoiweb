# 작업기록

클로드 코드로 한 작업 중 **팀원이 나중에 알아야 할 것**을 남기는 곳입니다.

- [260919 수업 종료 후 녹화중 상태 복구](260919_수업종료후_녹화중_상태복구.md)

## 왜 필요한가

클로드 코드의 대화 기록은 **작업한 사람의 계정 안에만 있습니다.**
팀원 계정으로 자동으로 넘어가지 않습니다. 그래서 남길 가치가 있는 판단·근거는
**저장소 문서로 옮겨야** 다음 사람이 볼 수 있습니다.

특히 **«검토했다가 버린 방법»** 이 중요합니다. 코드에는 «택한 것» 만 남고
«왜 다른 길로 안 갔는지» 는 대화에만 있어서, 몇 달 뒤 같은 길을 다시 파게 됩니다.

## 쓰는 법

클로드 코드에서 작업을 마친 뒤:

```
/worklog 카페24 급여동기화 수업시간 추가
```

`docs/작업기록/YYMMDD_제목.md` 로 문서가 만들어집니다.

## 파일 이름 규칙

`YYMMDD_짧은제목.md` — 예: `260818_가맹점정산서_B2B매출반영.md`

## 무엇을 남기고 무엇을 남기지 않나

| 남깁니다 ✅ | 남기지 않습니다 ⛔ |
|---|---|
| 왜 이 작업을 했는지 (제보·증상·요청) | 대화 전문 복붙 |
| 검토했다가 버린 방법과 그 이유 | 비밀번호·토큰·API 키 |
| 새로 발견한 함정 | 학생·학부모 실명, 전화번호 등 개인정보 |
| 확인한 방법과 결과 | 아직 확인 안 된 추측을 사실처럼 |

> 🔑 **새로 발견한 함정은 여기 말고 `CLAUDE.md` 2장에도 한 줄 넣으세요.**
> 작업기록은 사람이 찾아 읽어야 하지만, `CLAUDE.md` 는 클로드 코드가 **매번 자동으로 읽습니다.**
