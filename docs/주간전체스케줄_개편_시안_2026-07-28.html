주간 전체 스케줄 — 화면 개편 제안

지금 화면은 교사 29명 = 미니 달력 29장입니다. 같은 시간축이 29번 반복되면서, 정작 관리자가 매일 묻는 질문(“화요일 저녁 7시에 누가 비었나?”)에는 답을 못 합니다. 업계 표준인 리소스 타임라인(교사=행, 시간=열)으로 바꾸는 시안입니다.

제안 단계 — 아직 실서비스 미반영 2026-07-28 대상: /admin/weekly-schedule.html 기존 기능 100% 유지 전제

1지금 화면이 산만한 이유 — 6가지

감이 아니라 현재 코드(weekly-schedule.html)와 보내주신 화면을 근거로 정리했습니다.

원인 1 — 가장 큼
시간축이 29번 반복됩니다
교사 1명당 미니 달력 1개(7열 × 시간행)를 그립니다. 화면 픽셀의 상당 부분이 29번 되풀이되는 요일·시간 라벨입니다. 정보는 한 번만 있으면 됩니다.
원인 2
세로 비교가 불가능합니다
“화요일 19시에 빈 교사”를 찾으려면 카드 29장을 하나씩 눈으로 훑어야 합니다. 관리자 업무 1순위(신규 학생 배정)가 가장 불편한 동작이 돼 있습니다.
원인 3
본문 전에 컨트롤이 4겹
KPI 4장 → 주 이동·검색·필터·뷰토글 → 색상 범례 → 교사 칩바. 보내주신 화면에서 실제 스케줄은 한 칸도 안 보입니다.
원인 4
필터 5개 중 4개가 항상 0
홈 0 · 원어민 0 · 매니저 0 — 전체 29명이 전부 ‘오피스’입니다. 늘 0인 버튼 3개가 자리만 차지하고 눈을 끕니다.
원인 5
색이 의미를 잃었습니다
노랑(오늘·AI매칭·홈버튼·세로탭) + 보라·핑크·파랑·빨강(수업) + 초록·파랑·보라·주황(분류). 강조가 8곳이면 강조가 없는 것과 같습니다.
원인 6
이모지가 라벨마다 붙습니다
한 화면에 아이콘성 이모지 15개 이상. 각각이 시선을 잡아당겨 정작 봐야 할 수업 색 블록과 경쟁합니다.

2경쟁사·업계 표준은 어떻게 하나

“여러 사람 × 시간” 화면은 이미 정답이 굳어진 영역입니다. 조사한 곳 전부 같은 뼈대를 씁니다.

서비스분야레이아웃우리와
Teachworks과외·교습소 관리 Teacher 뷰 = 교사가 행, 시간이 열. 수업은 이름 옆 블록, 휴무는 회색으로 깔아 “빈자리 찾기가 훨씬 쉽다”고 명시. 색상 기준을 학생/교사/장소 중 선택. 우리만 다름
TutorCruncher튜터링 관리 모든 튜터 일정을 하나의 캘린더에서 색상 코드로 관리. 화면을 사람 수만큼 쪼개지 않음. 우리만 다름
Sling / Deputy교대근무 편성 직원 행 × 요일 열 그리드 + 상단에 주간 지표 한 줄(인건비·초과·결근). 드래그로 이동. 지표는 유사
Resource Guru인력 배정 사람 행 × 날짜 열 + 가동률 히트맵(1인당 % 표시, 과부하 경고). 충돌을 즉시 발견하는 게 목표. 가동률 없음
FullCalendar / DHTMLX
Mobiscroll / Syncfusion		스케줄러 부품
(업계 표준 라이브러리)		 이 화면 형태의 공식 이름이 Resource Timeline입니다. 규칙이 셋: ① 시간축은 화면에 하나 ② 리소스(사람) 열은 좌측 고정 ③ 행이 많으면 그룹·접기·가상화. 셋 다 없음

국내 학원관리 제품(에듀클릭·클래스업 등)도 “요일별 시간표 한 장에서 누가 오는지 확인”이 기본 화면입니다. 사람 수만큼 달력을 복제하는 방식은 조사한 곳 어디에도 없었습니다.

4무엇이 달라지나

지금

  • 교사 29명 = 미니 달력 29장, 시간축 29벌
  • 세로 스크롤 약 3,000~4,000px (3열 배치 기준 카드 10줄)
  • “화요일 19시 빈 교사” → 카드 29장 육안 대조
  • 첫 화면에 스케줄 0칸 (컨트롤이 4겹)
  • 가동률·과부하 표시 없음
  • 항상 0인 필터 3개가 상시 노출

시안

  • 교사 29명 = 표 한 장 29행, 시간축 1벌
  • 세로 스크롤 830px(보통) / 688px(촘촘) — 촘촘 모드는 한 화면에 29명 전부 ※ 이 시안에서 실측
  • 세로로 훑기만 하면 끝. ‘빈자리 찾기’는 가능한 칸만 남김
  • 첫 화면에 교사 12~20명분 스케줄이 바로 보임
  • 이름 옆 가동률 막대 — 놀고 있는 교사가 즉시 눈에 띔
  • 빈 분류는 자동으로 숨김 (드롭다운 1개로 통합)
기존 기능은 하나도 빼지 않습니다. 셀 클릭 상세 모달, 빈칸 드래그로 슬롯 추가, 학생 드래그 배정, AI 매칭, 시간대 변환, 휴일 차단, 수업 이동·보강, KO/EN 전환 — 전부 그대로 옮깁니다. 바뀌는 것은 ‘어떻게 배치해서 보여주느냐’뿐입니다.

솔직하게 말씀드릴 위험 3가지.
① 이 파일은 관리자 영역이라 배포 권한자(A) 담당입니다. 병행 세션이 같은 파일을 만지면 충돌합니다.
② 직원분들이 지금 화면에 이미 익숙합니다. 그래서 4단계(병행 토글)를 넣었습니다. 바로 갈아끼우지 않는 편이 안전합니다.
③ 드래그로 새 슬롯 만드는 기능은 좌표 계산 방식이 레이아웃에 묶여 있어, 타임라인으로 바꾸면 그 부분은 다시 짜야 합니다(2~3단계에 포함).
