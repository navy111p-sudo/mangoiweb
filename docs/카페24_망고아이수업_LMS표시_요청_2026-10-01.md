# 망고아이 수업을 **카페24 LMS 강사 시간표에 «보기 전용»으로** 보여 주세요

**받는 분:** 카페24 서버 담당자 (Neo4j :8880 을 관리하시는 분)
**보내는 곳:** 망고아이 개발
**날짜:** 2026-10-01
**성격:** ⚠️ **개발 요청 + 먼저 몇 가지 확인.** 3장의 방법 중 무엇이 그쪽에 맞는지 정해 주시면
저희 쪽 작업을 거기에 맞춰 시작합니다. **일정은 카페24 쪽 사정에 맞춥니다.**

---

## 1. 한 줄 요약

강사 한 명이 **카페24 LMS 수업과 망고아이 수업을 같은 시각에 따로 잡히는** 일이 생기고 있습니다.
LMS 화면에서 망고아이 수업도 함께 보이면 **배정하는 순간** 겹침을 알 수 있습니다.

👉 **망고아이 수업을 LMS 강사 시간표에 «보기 전용» 으로 표시**할 수 있게 해 주세요.
⛔ 출석·급여·결제에는 **절대 들어가면 안 됩니다** (아래 4-2).

## 2. 왜 — 실제로 겹쳤습니다

- **2026-09-30(수) 20:00, 강사 Zee** — 카페24 정규수업(학생 `umc276`)과
  망고아이 반복수업(학생 `yahee`)이 **같은 시각에 둘 다** 잡혀 있었습니다.
- 필리핀 매니저 요청(원문): *"If all Mangoi AI classes are reflected on the LMS,
  we can easily identify and check these conflicts in advance."*
- 저희 쪽은 2026-09-30 에 **망고아이 매니저 화면에서 두 쪽을 대조해 겹침을 보여 주는 기능**을
  넣었습니다. 다만 매니저들은 **배정을 LMS 에서** 하므로, LMS 에서 보이는 것이 가장 확실합니다.

## 3. 방법 세 가지 — 하나를 골라 주세요

### 방법 ① (저희 추천) — 카페24가 «가져가기» (Pull)

```
망고아이 서버 ──(키로 보호된 주소)──▶ 카페24 서버가 15분마다 읽어 감 ──▶ LMS 화면에 «망고아이 수업» 으로 표시
```

- 저희가 **읽기 전용 주소** 하나를 엽니다(예: `GET https://mangoi.ai/api/c24-export/mangoi-classes`).
  - 인증: 공유 키(헤더) — 지금 카페24 서버가 저희에게 **급여·이탈 자료를 보낼 때 쓰는 방식과 같습니다**(방향만 반대).
  - 응답: **오늘부터 14일치 망고아이 수업 «전체 목록»**(아래 4-1).
- 카페24 쪽은 그 목록을 받아 **표시 전용 표에 통째로 갈아 끼우면** 됩니다.
  목록에서 빠진 수업 = 취소된 수업이라, 취소·변경을 따로 주고받을 필요가 없습니다.
- 장점: 카페24 쪽에 «쓰기 API» 를 새로 만들 필요가 없고, 한쪽이 잠깐 멈춰도 다음 회차에 저절로 맞춰집니다.

### 방법 ② — 망고아이가 «보내기» (Push)

- 카페24 쪽이 **쓰기 API**(만들기·바꾸기·취소)를 만들고, 저희가 수업이 바뀔 때마다 부릅니다 + 밤에 한 번 전체 대조.
- 각 수업에 저희 고유번호(`source_id`)를 붙여 보내므로 **두 번 보내도 한 건**이어야 합니다(멱등).
- 단점: 카페24 개발량이 가장 큽니다. 취소·변경을 빠짐없이 보내야 합니다.

### 방법 ③ — 함께 쓰는 Neo4j 에 저희가 직접 기록

- 저희가 Neo4j 에 `:MangoiClass` 같은 **별도 노드**로 써 두고, LMS 화면이 그것을 함께 읽습니다.
- ⚠️ **LMS 강사 시간표가 Neo4j 를 읽는 화면일 때만** 가능합니다(아래 질문 1).
  ⛔ 기존 `:Class` 노드에는 섞지 않습니다 — 출석·급여 집계에 들어갈 수 있습니다.

## 4. 주고받을 내용

### 4-1. 수업 한 건의 칸

| 칸 | 예 | 설명 |
|---|---|---|
| `source_id` | `mangoi:3498:2026-09-30` | 망고아이 수업번호 + 날짜. **같은 값이면 같은 수업** |
| `date` | `2026-09-30` | 한국 날짜 |
| `start_time` | `20:00` | 한국 시각 |
| `duration_min` | `20` | 분 |
| `teacher_no` | `182` | **카페24 강사번호** (저희가 이름으로 맞춰 보냄 — 질문 4) |
| `teacher_name` | `Ana` | 표시용 |
| `student_name` | `정예희` | 표시용. 망고아이에만 있는 학생도 있어 **카페24 회원번호가 없을 수 있습니다** |
| `kind` | `regular` / `trial` / `level_test` | 수업 종류 |
| `recurring` | `true` | 매주 반복 수업이면 true (날짜별로 펼쳐서 보냅니다) |

- 카페24에서 저희가 옮겨 온 수업(미러 사본)은 **보내지 않습니다** — 같은 수업이 두 번 보이게 됩니다.

### 4-2. 꼭 지켜 주셔야 할 것

1. **표시 전용** — 망고아이 수업은 LMS의 **출석·강사 급여·학생 결제·수강 회차**에 들어가면 안 됩니다.
   들어가면 **강사 급여가 두 번** 계산됩니다.
2. 화면에서 **구별되게** — 색이나 「망고아이」 표시로 LMS 수업과 구분해 주세요.
3. 개인정보 — 학생 이름이 들어가므로 **HTTPS + 키** 로만 주고받고, 필요한 칸만 씁니다.
