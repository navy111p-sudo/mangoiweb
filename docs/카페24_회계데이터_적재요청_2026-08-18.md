# 회계 데이터(AccBook) Neo4j 적재 요청

**받는 분:** 카페24 서버 담당자 (Neo4j :8880 을 관리하시는 분)
**보내는 곳:** 망고아이 개발 (워커 쪽은 이미 작업 완료 — 서버에서 적재해 주시기만 하면 됩니다)
**날짜:** 2026-08-18

---

## 1. 한 줄 요약

관리자 대시보드의 「정산·매출 > 카페24 회계 실데이터」 화면이 보는 **Neo4j 회계 노드가
비어 있습니다.** 다른 노드처럼 **`AccBook`(회계장부)을 적재해 주세요.** 나머지 4종
(급여·지출결의·세금계산서·예치금)도 함께 확인 부탁드립니다.

## 2. 실측 근거 (2026-08-18)

같은 Neo4j 에 대해 워커가 실제로 조회한 결과입니다:

| 조회 | 결과 |
|---|---|
| `MATCH (b:Book)` — 교재 명부 | ✅ **62건** 정상 |
| `MATCH (a:AccBook)` — 회계장부 (필터 없이 전체) | ❌ **0건** |
| 월별 손익 집계(summary) | ❌ `months: []`, 합계 전부 0 |

즉 **연결·인증·쿼리 문제가 아니라 `AccBook` 노드 자체가 없습니다.**
망고아이 워커 저장소에는 이 노드를 **쓰는(적재하는) 코드가 없고 읽기만** 하므로,
적재는 Book·Student 등을 넣으신 것과 같은 방식으로 서버 쪽에서 부탁드립니다.

## 3. 워커가 기대하는 필드 (조회 쿼리가 읽는 그대로)

`AccBook` 노드 하나 = 회계장부 한 줄:

| 속성 | 형식 | 뜻 |
|---|---|---|
| `date` | `'YYYY-MM-DD'` 문자열 | 일자 — **월별 집계가 앞 7글자로 자릅니다. 이 형식이 아니면 집계가 통째로 빕니다** |
| `type` | 숫자 `1`=수입, `2`=지출 | 구분 |
| `acc_type` | 문자열 | 구분 표시용 |
| `subject` | 문자열 | 계정과목 |
| `money` | 숫자(원) | 금액 |
| `store` | 문자열 | 거래처 |
| `memo` | 문자열 | 적요 |
| `month` | `'YYYY-MM'` 문자열 | 귀속월 |

- 기간: 있는 만큼 전부 (집계는 `2019-01` 이후만 봅니다)
- 나머지 4종 노드: `Payroll`(급여) · `ExpenseReport`(지출결의) · `TaxInvoice`(세금계산서) · `SavedMoney`(예치금)

## 4. 「케이씨피M」 행도 빼지 말고 그대로 넣어 주세요

하나은행에서 옮긴 운영자금(적요·거래처 「케이씨피M」)도 **원본 그대로** 적재해 주세요.
**매출에서 빼는 판정은 워커가 자동으로 합니다**(2026-08-18 배포 완료). 원본에서 미리
빼시면 오히려 «장부와 원본이 다른» 상태가 됩니다.

## 5. 적재 후 확인 방법

관리자 로그인 상태의 브라우저에서:

- `https://mangoi.ai/api/admin/finance-cafe24/ledger?limit=20` → `count` 가 0보다 크면 성공
- `https://mangoi.ai/api/admin/finance-cafe24/summary` → `months` 에 월별 값이 보이면 성공
- 화면: 관리자 대시보드 → 정산·매출 → 🧾 카페24 회계 실데이터
