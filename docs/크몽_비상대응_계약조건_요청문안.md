## 1. 원하는 계약 형태

- **건별(온디맨드) 비상 대응** — 월 고정비 없음 또는 최소 기본료. 평시 운영·개발은 당사가 직접 수행하며, 귀사는 당사가 요청하는 경우에만 투입됩니다.
- 계약 기간: 6개월 단위(자동 연장), 중도 해지 가능 조건 명시 요청

| # | 항목 | 요청 내용 |

## 3. 당사 환경 (견적 산정용 요약)

- 프런트/백엔드: Cloudflare Workers(서버리스) + 정적 페이지 — 평시 운영은 당사가 직접
- 데이터: Cloudflare D1/R2/KV + 카페24 서버(MySQL·Neo4j, CentOS7 → NCP 이전 예정)
- 모니터링: 외부 가용성 감시 + 장애 시 SMS 자동 발송 체계 구축 완료
- 백업: DB 일일 원격 백업 + 30일 시점 복원 체계 구축 완료
- 상세 시스템 문서(SRS v2.1, 27p)는 계약 논의 확정 시 NDA 후 제공 가능

## 4. 계약 조건 (당사 요청 사항)

1. **접근 권한**: 작업 시마다 당사가 임시 발급(최소 권한) → 작업 종료 후 회수. 상시 계정 보유 없음
2. **비밀유지(NDA)**: 계약서에 포함. 학생·학부모 개인정보 접근 시 개인정보처리 위탁 조항 포함
3. **작업 기록**: 모든 비상 대응 후 작업 내역 서면 보고 (무엇을, 왜, 어떻게 바꿨는지)
4. **산출물 귀속**: 대응 과정에서 생성·수정된 코드·스크립트·문서는 전부 당사 소유
5. **재하청 금지**: 투입 인력은 귀사 소속으로 한정 (변경 시 사전 통지)
