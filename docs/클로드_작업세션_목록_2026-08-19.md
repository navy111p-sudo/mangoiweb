## 0. 먼저 — 세션 «링크» 는 공유가 안 됩니다

클로드 코드 화면 왼쪽 사이드바의 세션 목록은 **계정에 묶여 있습니다.**
`claude.ai/code/session_...` 주소를 그대로 보내도 장 부장 계정에서는 열리지 않고,
GitHub 저장소 권한을 아무리 줘도 달라지지 않습니다 (저장소 권한과 클로드 계정은 별개).

그래서 **목록 자체를 문서로 옮겨** 저장소에 넣었습니다. 이 문서가 세션 사이드바의 사본입니다.

실제로 «내용» 을 같이 보는 자리는 세션이 아니라 **저장소** 입니다 —
세션마다 작업 브랜치가 하나씩 있고, 그 브랜치의 PR 에 무엇을 왜 고쳤는지가 다 적혀 있습니다.
아래 표의 브랜치 링크를 누르면 그 세션이 만든 PR 만 걸러서 보입니다.

| 보고 싶은 것 | 어디를 보나 |
|---|---|
| 어떤 작업을 했나 (목록) | 이 문서 2장 |
| 무엇을 왜 그렇게 고쳤나 | 해당 브랜치의 PR 본문 |
| 검토했다가 버린 방법 | [`docs/작업기록/`](작업기록/) |
| 밟으면 안 되는 함정 | [`CLAUDE.md`](../CLAUDE.md) 2장 |

## 4. 앞으로 같이 보려면

세션을 공유하는 방법은 없으므로, **작업이 끝날 때 저장소에 흔적을 남기는 것** 이 유일한 공유 수단입니다.
이 저장소는 이미 그렇게 굴러가고 있습니다 —

1. 세션마다 브랜치 하나 → PR 로 올림 (PR 본문에 «왜» 를 적음)
2. 끝나면 `/worklog` 로 [`docs/작업기록/`](작업기록/) 에 판단 기록을 남김
3. 새로 밟은 함정은 [`CLAUDE.md`](../CLAUDE.md) 2장 표에 추가

- 작업 목록: https://github.com/navy111p-sudo/mangoiweb/pulls?q=is%3Apr
- 판단 기록: https://github.com/navy111p-sudo/mangoiweb/tree/main/docs/작업기록
