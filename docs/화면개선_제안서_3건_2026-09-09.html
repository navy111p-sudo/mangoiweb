① 레벨테스트 결과 — CEFR 막대에 색이 안 보이는 문제

사장님 말씀: 「A1, A2 이런 단어와 4/4, 3/4 사이에 막대처럼 되어있는데, 이 부분에 색상이 추가되어 시각적으로 내 점수를 더 쉽게 볼 수 있었으면 좋겠음.」

잰 것 — 2026-09-09, 실제 화면을 브라우저에 띄워 측정

색은 이미 코드에 있었습니다(보라 그라데이션). 그런데 채움 막대가 <span> 이고 그 부모가 가로 정렬 상자가 아니라서, 브라우저가 그것을 «글자» 로 취급합니다. 글자에는 폭·높이를 줄 수 없으므로 채움이 0픽셀이 됩니다.

② 수업 전 AI 웜업 — 「학교 싫어」라고 했는데 「Haha nice!」

사장님 말씀: 「학교를 좋아하지 않는다고 했는데 nice라는 답변은 일반적이지 않아 보임.」

잰 것 — AI에게 주는 규칙을 그대로 읽었습니다

웜업 AI의 규칙 12줄 가운데 «칭찬» 규칙은 있는데 «공감» 규칙이 없습니다. 칭찬 규칙은 이렇게 적혀 있습니다:

[칭찬] 학생이 잘 대답하면 크게 기뻐하며 칭찬한 뒤 다음 질문으로 이어가줘. 칭찬 말은 직전 두 번과 다른 것으로 골라 써 — Wow!, Awesome!, Nice one!, That's great!, Yes!, Perfect!, Cool!, You got it!, Well said!, I love that!, Amazing!, Haha nice! 처럼 돌려 쓰고…

AI 입장에서 I don't like school 은 «문장을 잘 만든 대답» 이라 규칙대로 칭찬하고 넘어갔습니다. «무슨 말인지» 를 보라는 지시가 어디에도 없었습니다. 화면에 찍힌 「Haha nice!」는 지어낸 말이 아니라 저 목록에서 뽑은 것입니다.

지금

Emma
Haha nice! What do you like to do after school?

아이 마음을 못 읽은 답. 「내 말을 안 듣는구나」로 남습니다.

고친 뒤 (세 안 공통 모습)

I don't like school
Emma
Oh, really? That's okay. What part is hard? «어떤 게 힘들어?»

먼저 마음을 받아 주고, 그다음에 이야기를 이어 갑니다.

세 가지 안

A안 규칙 한 줄 추가

AI 규칙에 [공감] 항목을 넣습니다 — 「학생이 싫다·힘들다·슬프다고 하면 칭찬 말로 시작하지 말고, 먼저 마음을 받아 준 뒤 이유를 물어봐」.

  • 오늘 바로 반영 가능 · 비용 0원
  • 다른 대화는 하나도 안 건드림
  • «가끔 안 지킬 수 있음» — 이 저장소가 여러 번 겪은 「지시만으로는 안 지켜진다」에 그대로 해당
B안 규칙 + 서버 안전망 추천

A안에 더해, 아이가 부정적인 말(don't like / hate / boring / sad / tired / 싫어 / 힘들어 …)을 했을 때 서버가 답장 앞머리의 칭찬 상투구를 떼어 냅니다. AI가 규칙을 어겨도 「Haha nice!」가 화면까지 못 나옵니다.

  • 말을 지어내지 않고 «떼기만» 합니다 — 뒤 문장은 그대로
  • 판정을 한 파일로 모아 자동 검사로 못 박음
  • A안보다 반나절 더 걸림
C안 B + 대화 흐름까지 바꿈

B안에 더해, 아이가 힘들다고 하면 다음 질문 자체를 바꿉니다 — 캐묻지 않고 위로 한마디 뒤 아이가 좋아하는 화제로 돌립니다.

  • 가장 사람다운 대화
  • 기초 단계(1·2)에서는 여전히 예/아니오 질문만 유지
  • 대화 «성격» 을 바꾸는 일이라 여러 아이 대화를 보고 다듬어야 함 — 먼저 B안으로 막고, 한두 주 지켜본 뒤 판단하시길 권합니다

같이 봐 주셔야 할 것

이 규칙은 수업 전 웜업 화면의 것입니다. 같은 성격의 화면이 하나 더 있습니다(AI 영어친구) — 규칙이 따로 적혀 있어 한쪽만 고치면 화면마다 답이 달라집니다. 세 안 모두 두 화면을 함께 고칩니다.

왜 이렇게 됐는지 — 확인된 것과 확인 못 한 것

확인된 것: 이 덮어쓰기 덩어리(cta-transparent-override)는 2026-09-04 에 홈 파일에 들어왔습니다. 확인 못 한 것: 「투명하게 하자」는 결정이 따로 있었는지는 기록에 없습니다. 일부러 그렇게 정하신 것이라면 말씀해 주세요 — 그때는 되살리는 대신 투명한 채로 테두리와 글자만 더 진하게 하는 방향으로 다시 만들어 드리겠습니다.

추천 — 세 건 모두 B안

1①·③은 «고장 수리» 라 먼저 나가도 됩니다. 두 건 다 지금 화면이 사실과 다른 것을 보여 주고 있어서, 고르시는 안과 무관하게 빨리 고칠수록 좋습니다. 하루면 둘 다 끝납니다.

2②는 B안으로 «두 겹» 을 권합니다. AI에게 부탁만 해서는 이 저장소에서 여러 번 안 지켜졌습니다. 서버가 마지막에 한 번 더 걸러 주는 쪽이 안전합니다.
