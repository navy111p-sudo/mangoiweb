# 성인 소유자 PC의 로컬 실제 음성 시험

공개 Worker/D1/터널/새 구독 없이 기존 망고아이 격리 Worker와 UI를 루프백 Node 서버에서 실행합니다. Cloudflare에는 지정 계정의 AI REST 요청만 직접 전송합니다. 사용자 PC 설치/실행과 실제 마이크·청취·입모양 검증은 아직 수행하지 않았습니다. 실행은 부모와 기존 PC 도우미가 조율합니다.

## 필요한 것

- 기존 사용자 PC의 Node.js 24 이상(내장 node:sqlite). 이 묶음은 npm 설치나 Wrangler 설치가 필요 없습니다. Node가 없으면 도우미가 먼저 설치 승인을 확인합니다.
- 최신 Chrome/Edge, 마이크, 인터넷. 외부 수신 포트/포트 전달/터널/공개 방화벽 허용은 필요 없습니다.
- PC에서 이미 인증된 **정확한 기존 Wrangler OAuth TOML 경로**. 도우미가 이전 인증에 사용한 위치를 확인해야 하며 여기서 경로를 추측하지 않습니다. OAuth의 ai:read 또는 ai:write 범위와 만료를 로컬로 확인합니다. 새 권한 부여/자동 토큰 갱신은 하지 않습니다. 토큰을 채팅·파일 전달·명령줄 인자로 복사하지 않습니다.
- 사용자 본인이 관리하는 PC에서만 실행합니다. 다른 로컬 프로그램/동일 OS 사용자 권한이 침해된 PC에 대한 보안 경계는 아닙니다.

## PC 도우미가 사용자와 확인 후 실행할 명령

압축을 푼 폴더에서 PowerShell:

```powershell
node --version
node .\owner\server.mjs .\build "<PC에 이미 존재하는 Wrangler OAuth TOML의 정확한 경로>" .\owner-budget.jsonl
```

명령에는 비밀번호나 토큰이 들어가지 않습니다. 출력되는 주소는 `http://127.0.0.1:8799/local/setup`입니다. `localhost`나 LAN IP로 바꾸지 마세요. 서버는127.0.0.1에만 바인딩하고 Host/Origin도 검사합니다. 포트가 사용 중이면 덮어쓰지 말고 중지합니다.

1. 실행만으로 AI를 호출하거나 1시간을 시작하지 않습니다.
2. 주소를 본인이 열고 마스킹된 입력란에 ED 비밀번호를 직접 입력합니다. 준비 확인 후 설정 버튼을 누르는 시점에 최대1시간이 시작됩니다. 기존 OAuth가 먼저 만료되면 그 시각에 조기 종료됩니다.
3. 일회용 시작 코드를 본인 화면에서만 확인하고 ED 로그인 → A.i 말하기 → 책 선택 → 시작 코드와 전송 동의를 입력합니다. 화면·비밀번호·코드를 도우미 로그나 채팅으로 보내지 않습니다.
4. 마이크는 명시적으로 답변 녹음을 눌러야 요청됩니다. 최대15초, 수동 종료 가능. 한 번에 한 질문만 진행합니다. 다시 듣기는 메모리 음성을 사용하며 추가 공급자 호출을 하지 않습니다.
5. 종료는 서버 창에서 Ctrl+C. 원시 음성·답변·DB는 파일에 저장하지 않습니다. 종료 후 메모리 DB는 사라집니다.

## 예산 및 재시작

STT20 + 대화20 + TTS21 = 최대61회, AI예약 최대US$0.40. 기존 승인 전체를 사용자에게 남겨두었으며 개발자는 실제호출0회입니다. 각 요청 전 로컬 원장에 동기 기록/fsync하고 한도를 선점합니다. 모델/길이/토큰/오디오 상한도 검사합니다. 불확실한 응답과 실패는 소비 처리하며 자동 재시도/환불/갱신은 없습니다.

`owner-budget.jsonl`에는 종류·예약비용·만료 메타데이터만 남습니다. 토큰·코드·오디오·답변은 없습니다. 원장이 이미 있으면 재시작/재설정을 거부합니다. **원장을 삭제하거나 다른 경로로 바꿔 예산을 초기화하지 마세요.** 중간 종료는 자동 복구되지 않으며 부모에게 소진/미검증 상태를 보고해야 합니다.

원격 Worker와 D1을 생성하거나 호출하지 않습니다. 따라서 공개 Worker 요청/CPU 및 원격 D1 저장 과금 경로가 없습니다. 이는 Cloudflare 전체 계정 청구를 제한하거나 다른 앱의 사용료를 제어한다는 뜻이 아닙니다. 전송 목적지는 `https://api.cloudflare.com/client/v4/accounts/7ae16a3c4bcc84743c70828a5156ebb3/ai/run/…` 하나이며 리다이렉트를 거절합니다.

## 검증 범위

Linux Node24/Chromium에서 로컬 HTTP 설정·기존 ED 로그인·쿠키 변환·테넌트 차단·20턴·정확61회 모의 공급자 호출·원장 재시작 거부·100개 동시 요청 제한을 검증했습니다. 브라우저에서 설정→로그인→A.i 말하기→20개 건너뛰기/힌트/완료/재사용 차단을 검증했습니다. 오디오 재생은 모의이며 실제 공급자·마이크·Windows·립싱크 실증은 아닙니다.
