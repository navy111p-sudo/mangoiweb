# 손으로 돌리는 검사 (manual)

여기 있는 파일은 `test-harness/run.mjs` 가 **자동으로 돌리지 않는다** —
파일명이 `_harness.mjs` 로 끝나지 않으므로 목록에 안 잡힌다.

이유: 실제 브라우저(Chromium)가 필요한데, playwright 는 이 저장소의 의존성이 아니다.
게이트에 넣으면 브라우저가 없는 환경에서 매번 걸린다.

---

## 돌리는 법

```bash
# playwright 를 밖에서 한 번 받아 둔다 (저장소는 그대로 둔다)
mkdir -p /tmp/pw && cd /tmp/pw && npm install playwright-core

# 저장소 루트에서
cd /경로/mangoiweb
PW_DIR=/tmp/pw node test-harness/manual/approval-offline-browser.mjs
PW_DIR=/tmp/pw node test-harness/manual/approval-ui-browser.mjs
```

- Chromium 은 `/opt/pw-browsers` 에서 찾는다(웹 세션 환경에 미리 깔려 있다).
  다른 곳이면 `PLAYWRIGHT_BROWSERS_PATH` 로 알려 준다.
- 준비물이 없으면 **실패가 아니라 «건너뜀»** 으로 조용히 끝난다.
- 두 검사 모두 **서버를 띄우지 않는다.** `fetch` 를 가짜로 바꿔 응답을 물린다.
  그래서 D1(개발·운영 공용 DB)에 아무것도 쓰지 않는다.

## approval-offline-browser.mjs — 끊겨도 잃지 않는가 (17건)

한국↔필리핀 교환에서 가장 아픈 «끊김» 을 눌러서 확인한다.

1. 쓰다 만 기안이 기기에 저장되는가
2. 앱을 다시 열어도 되살아나는가 (같은 건 열쇠까지 그대로)
3. 끊긴 채로 「올리기」를 누르면 사진까지 담아 두는가
4. 연결이 돌아오면 자동으로 보내는가
5. 같은 것을 또 보내도 **기안이 두 건이 되지 않는가**

> **왜 필요했나** — 2026-08-16, 이 검사가 실제 버그를 하나 잡았다.
> `.outbox` 에 `display:none` 이 박혀 있어서 `hidden=false` 로 바꿔도
> «보내지 못한 결재를 저장했습니다» 안내가 **한 번도 뜨지 않았다.**
> CLAUDE.md 에 적힌 «hidden 인데 그대로 보임» 함정의 반대쪽이고, 정적 검사로는 안 보인다.
> (지금은 `approval_policy_harness.mjs` 가 그 줄을 감시한다)

## approval-ui-browser.mjs — 묶어서 승인 · 부재중(대결) (10건)

1. **묶어서 승인이 «점검을 통과한 건만» 묶는가** — 이게 핵심이다.
   중복청구·예산초과·첨부누락 경고가 붙은 건이나 마감을 넘긴 건까지 쓸어 승인해 버리면
   자동 점검이 있으나 마나가 된다. 그 건들은 목록에 그대로 남아야 한다.
2. 부재중(대결)을 켜면 대신할 사람 목록이 뜨고, 기간과 함께 서버로 가는가

## vc-entry-speed-browser.mjs — 수업 입장이 «낭비» 하고 있지 않은가 (11건)

정적 하니스는 「카메라를 몇 번 여는가」를 볼 수 없다. 그래서 진짜로 입장 버튼을 눌러 **센다**.

1. 입장이 정상인가 (예약방으로 감 · 수업화면 전환 · 그 방에 접속 시도 · 살아있는 트랙)
2. **카메라를 한 번만 여는가** ← 이게 핵심
3. **입장 중 TURN 왕복이 1회 이하인가**
4. 열자마자 버리는 트랙이 없는가
5. 첫 카메라부터 해상도 상한이 걸려 있는가 (bare `{video:true}` 금지)

> **왜 필요했나** — 2026-08-22. 권한 선확보가 카메라를 열었다 **버리고**, 입장이 다시 열고 있었다.
> 첫 호출은 상한 없는 `{video:true}` 라 웹캠에 따라 1080p 로 열렸다(곧 버릴 스트림에 CPU·발열).
> TURN 자격증명도 매 입장마다 두 번 받아 왔다.
> **타입체크·회귀 하니스·CI 게이트가 전부 초록불인 채로** 그러고 있었다 — 세는 검사가 없었으니까.

## vc-stuck-relay-browser.mjs — 막힌 회선에서 릴레이로 올라타는가 (6건)

고착 타일을 만들어 놓고 `vcStuckPeerWatch` 가 도는 것을 **실제 시간으로** 기다린다(약 40초).

1. 워치독이 고착을 알아채고 재시도하는가
2. **1차 시도는 직접 연결 그대로인가** (너무 이르게 릴레이로 가지 않는가 = 중계 비용)
3. **2차 시도부터 TURN 릴레이가 강제되는가** (`__vcForceRelay`)

> **왜 필요했나** — 2026-08-22. 그 워치독은 4번을 재시도하면서 **4번 다 «직접 연결» 로만** 걸었다.
> 사무실 대칭NAT·기업 방화벽처럼 직접 경로가 막힌 회선에서는 네 번이 같은 이유로 실패하고
> **릴레이는 한 번도 안 써 보고 포기**했다.
>
> ⏳ **느린 것이 정상이다.** 워치독의 진짜 숫자(9초 고착 판정 + 5초 재판정 유예)를 그대로 쓴다.
> 빨리 끝내려고 그 값을 줄이면 **다른 코드를 시험하는 것**이라 의미가 없다.

⚠️ 두 검사 모두 **`public/` 을 HTTP 로 띄운다**(`python3 -m http.server`).
`file://` 로 열면 `<script src="/js/…">` 가 전부 404 라 `vcJoinRoom` 자체가 없다(CLAUDE.md 2장).
또 `/api/consents/` 를 「이미 동의함」으로 물려야 한다 — `mango-consent.js` 가 `vcJoinRoom` 을
감싸고 동의 모달로 **조용히** 기다리기 때문이다(에러가 안 난다).

## game-lock-preview-browser.mjs — 게임 허브의 잠금·미리보기·버튼 설명 (87건)

게임 카드의 자물쇠가 제목·설명을 가리지 않는지, 잠긴 카드를 눌렀을 때 미리보기가 뜨는지를
**좌표로** 잰다(문자열 하니스로는 볼 수 없는 종류다).

여기에 퀘스트 바 버튼(`🎫 레벨테스트로 한 번에 열기` · `🔓 전체 열기` · `🎯 퀘스트 모드로 하기`)의
**설명 줄**도 함께 본다.

> **왜 필요한가** — 버튼 설명을 `title` 툴팁으로만 달면 **폰에서는 영영 안 뜬다**(마우스 전용).
> 그래서 같은 글을 `.qhint` 로 한 번 더 그리고, 마우스가 있는 넓은 화면에서만 CSS 로 감춘다.
> 그 «감춤/보임» 은 `getComputedStyle` 로 재야 알 수 있어서 여기서 확인한다.
> 마지막 한 판은 `isMobile`·`hasTouch` 로 **진짜 터치 기기**(`hover:none`)를 흉내 내는데,
> 폭만 좁힌 문맥은 헤드리스에서도 `hover:hover` 로 보고되기 때문이다.

폭 세 가지(390·768·1440) + 터치 390 에서 돈다. 게임 카드·잠금·퀘스트 바를 건드리면 사람이 불러야 한다:

```bash
PW_DIR=/tmp/pw node test-harness/manual/game-lock-preview-browser.mjs
```

## vc-fastentry-browser.mjs — 로그인한 학생이 로비를 보지 않는가 (34건)

「로그인했는데 또 로그인하래요」를 없앤 덮개(`js/idx-vc-fastentry.js`)를 좌표로 확인한다.
**문자열 하니스로는 「무엇이 화면 맨 위에 있나」를 볼 수 없어서** 만든 것이다.

1. 로비가 열리는 «즉시»(0ms) 덮개가 있고, 처음부터 불투명한가
2. 입장이 끝날 때까지 아이디 칸 자리를 덮개가 가리는가 (`elementsFromPoint`)
3. 예약된 «내 방»(`class-…`)으로 들어가고 덮개가 남지 않는가
4. 예약이 없고 학생게이트가 켜지면 — 덮개를 걷고, 이유를 한/영으로 적고, 「방 코드 직접 입력」을 펴는가
5. 학생게이트가 꺼진 지금 운영값에서는 **예전 그대로 공용방으로** 들어가는가
   (= 이 덮개가 «입장 결과» 를 바꾸지 않는다는 못)
6. 로그인 안 한 사람에게는 덮개가 아예 안 뜨는가
7. 촬영동의 모달이 뜰 때 덮개가 그 위를 덮고 있지 않은가 (보이는데 안 눌린다 방지)
8. PC 1440×900 에서도 같은가 · 「A.i 상담사」 위젯(z 2,147,483,000)보다 위인가

```bash
PW_DIR=/tmp/pw node test-harness/manual/vc-fastentry-browser.mjs
```

⏳ `js/idx-vc-fastentry.js` · 로비 자동입장(4곳) · `mango-consent.js` 를 건드리면 사람이 불러야 한다.

## 새 검사를 더할 때

- 파일 이름을 `*_harness.mjs` 로 짓지 말 것 — 게이트가 물어 간다.
- 머리에 `import { requireBrowser } from './_pw.mjs';` 를 쓰면
  준비물 확인·건너뜀 처리가 한 줄로 끝난다.
- **운영 DB 를 건드리지 말 것.** 서버를 띄우지 말고 `fetch` 를 가짜로 바꿔 쓴다.
