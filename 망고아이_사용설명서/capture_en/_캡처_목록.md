# 영어 관리자 안내서 — 화면 캡처 요청 목록

## 캡처 전 준비 (중요)
1. `test.mangoi.co.kr/admin.html` 로그인
2. 상단 **EN 버튼**을 눌러 화면을 **영어로** 전환 (영어 안내서라 화면도 영어여야 합니다)
3. 브라우저 창을 **최대화** (넓을수록 좋습니다)
4. `Windows + Shift + S` 또는 `F12 → Ctrl+Shift+P → "capture screenshot"` 으로 캡처

## 저장 방법
- 이 폴더(`망고아이_사용설명서\capture_en\`)에 저장
- **파일명을 아래 번호대로** 지어주세요 (예: `03_dashboard.png`)
- PNG / JPG 아무거나 괜찮습니다
